Paso 1: instalar el motor

Descarga la SQL Server Installation Center (Developer Edition recomendada) desde microsoft.com/sql-server. El instalador guía por pasos; estas son las decisiones que importan:

Paso del instaladorElección recomendadaPor qué
EdiciónDeveloper (gratis, todo)Express solo si RAM mínima
Tipo instalaciónCustom → nueva standaloneControl sobre features
Feature SelectionSolo Database Engine ServicesSSMS se instala aparte ahora
Instance ConfigurationNamed: SQLEXPRESS o default MSSQLSERVERDefine tu cadena de conexión para siempre
Authentication ModeMixed Mode + contraseña SA fuertePermite login SQL además de Windows
Data DirectoriesDefaults OK para aprenderEn producción: discos separados data/log/tempdb

Apunta el nombre de instancia exacto en el paso Instance Configuration: será lo primero que SSMS te pida. En Express suele ser localhost\SQLEXPRESS; Developer default sin nombre: localhost.

Instalación silenciosa / Linux / Docker

# Docker: entorno de práctica en 2 minutos:
docker run -e "ACCEPT_EULA=Y" -e "MSSQL_SA_PASSWORD=TuClave123!" `
  -p 1433:1433 --name sqldev `
  -d mcr.microsoft.com/mssql/server:2022-latest

# Conexión desde el contenedor:
docker exec -it sqldev /opt/mssql-tools18/bin/sqlcmd `
  -S localhost -U sa -P "TuClave123!" -C

# Linux nativo (Ubuntu): repos + paquete mssql-server vía apt.

Paso 2: instalar SSMS

Desde 2016+ SSMS ya no viene con el motor: descárgalo aparte (búsqueda "Download SSMS") — es gratuito y su instalación es trivial (siguiente-siguiente). Al abrirlo:

Ventana "Connect to Server":
  Server type:   Database Engine
  Server name:   localhost\SQLEXPRESS     ← o localhost
                 .                        ← punto = localhost también
                 .\SQLEXPRESS             ← instancia nombrada local
  Authentication:
    Windows Authentication          ← tu usuario de Windows (sin clave)
    SQL Server Authentication       ← usuario sa u otro login creado
Panel de SSMSPara qué sirve
Object Explorer (F8)Árbol completo: bases → tablas → columnas → índices
New Query (Ctrl+N)Ventana T-SQL conectada al contexto actual
MessagesErrores, filas afectadas, prints
Results gridDatos tabulares exportables a CSV/Excel

El Object Explorer permite editar datos "a mano" (clic derecho Edit Top 200 Rows). Es cómodo para jugar pero NO genera transacciones ni validaciones serias: en cuanto salgas de tutoriales, trabaja SIEMPRE con scripts T-SQL versionables y repetibles.

Paso 3: tu primera base de datos

-- Crear y usar una base:
CREATE DATABASE TiendaPrueba;
GO
USE TiendaPrueba;
GO

CREATE TABLE Productos (
    id INT IDENTITY(1,1) PRIMARY KEY,
    nombre NVARCHAR(100) NOT NULL,
    precio DECIMAL(10,2) NOT NULL CHECK (precio >= 0),
    stock INT NOT NULL DEFAULT 0,
    creado_el DATETIME2 NOT NULL DEFAULT SYSUTCDATETIME()
);
GO

INSERT INTO Productos (nombre, precio, stock) VALUES
    (N'Teclado mecánico', 89.90, 25),
    (N'Monitor 27"', 249.00, 10),
    (N' ratón inalámbrico', 29.50, 40);

SELECT * FROM Productos;

Fíjate en el prefijo N'...' para strings: indica literal Unicode (NVARCHAR). Sin la N, caracteres como ñ, á o emojis pueden corromperse según collation. Hazlo hábito desde el día uno.

Cosas básicas de navegación

EXEC sp_help 'Productos';              -- estructura completa
EXEC sp_helpdb;                        -- lista bases y tamaños
SELECT DB_NAME() AS base_actual;       -- ¿dónde estoy parado?
SELECT @@VERSION AS version_motor;     -- build exacta instalada

Error clásico post-instalación: "Login failed for user 'sa' (Error 18456)". Casi siempre es Mixed Mode no habilitado o SA deshabilitado. Solución: conectar por Windows Auth → Properties del servidor → Security → SQL Server and Windows Authentication mode → habilitar login sa → reiniciar servicio.

Ejercicios prácticos

  1. Setup documentado: instala motor + SSMS (o Docker), anota nombre de instancia y método de autenticación en un README propio.
  2. Base de práctica completa: crea InventarioDB con tabla Articulos (5 tipos distintos de columna), inserta 5 filas con N'', consulta con orden y filtro.
  3. Ronda de verificación: ejecuta los 5 checks de la tabla anterior y captura resultados.
  4. Reparador de SA: si tienes Mixed deshabilitado, actívalo siguiendo la nota de peligro y documenta los pasos que hiciste.
  5. Explorador de sistema: usa sp_helpdb, DB_NAME(), @@VERSION y Object Explorer para armar un mini-reporte de tu instalación.
