Paso 1: instalar el motor

Descarga SQL Server Developer Edition desde el sitio oficial de Microsoft, ejecuta el instalador y elige Basic (Básico). Al terminar, anota la cadena de conexión y el nombre de instancia (normalmente localhost\SQLEXPRESS o similar).

Paso 2: instalar SSMS

Desde la pantalla final del instalador puedes descargar SSMS. Instálalo, ábrelo y conéctate con:

  • Server type: Database Engine
  • Server name: el nombre de instancia del paso anterior
  • Authentication: Windows Authentication

Paso 3: primera base de datos

-- Crear y usar una base de datos
CREATE DATABASE Tienda;
GO

USE Tienda;
GO

CREATE TABLE dbo.Productos (
  Id INT IDENTITY(1,1) PRIMARY KEY,
  Nombre NVARCHAR(100) NOT NULL,
  Precio DECIMAL(10,2) NOT NULL
);
GO

INSERT INTO dbo.Productos (Nombre, Precio)
VALUES (N'Laptop HP', 15500.00), (N'Mouse Logitech', 350.00);
GO

SELECT * FROM dbo.Productos;

GO no es SQL: es un separador de lotes que entienden SSMS y sqlcmd. Envía lo anterior al servidor antes de continuar.

Verificar el entorno

SELECT @@VERSION AS version;
SELECT DB_NAME() AS base_actual;
SELECT * FROM sys.databases;   -- todas las bases del servidor
