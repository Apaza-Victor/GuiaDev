Procedimiento básico

CREATE PROCEDURE dbo.sp_ObtenerCaros
  @minPrecio DECIMAL(10,2)
AS
BEGIN
  SET NOCOUNT ON;   -- evita mensajes extra al cliente
  SELECT Nombre, Precio
  FROM dbo.Productos
  WHERE Precio > @minPrecio;
END;
GO

EXEC dbo.sp_ObtenerCaros @minPrecio = 5000;

Parámetros OUTPUT y lógica

CREATE PROCEDURE dbo.sp_ContarPorCategoria
  @categoriaId INT,
  @total INT OUTPUT
AS
BEGIN
  SELECT @total = COUNT(*) FROM dbo.Productos WHERE CategoriaId = @categoriaId;
END;
GO

DECLARE @n INT;
EXEC dbo.sp_ContarPorCategoria @categoriaId = 1, @total = @n OUTPUT;
PRINT CONCAT(N'Total: ', @n);

Dentro de T-SQL dispones de IF/ELSE, WHILE, CASE y variables con DECLARE/SET.

Triggers DML

CREATE TRIGGER dbo.trg_DescuentaStock
ON dbo.Ventas
AFTER INSERT
AS
BEGIN
  SET NOCOUNT ON;
  UPDATE p SET p.Stock = p.Stock - i.Cantidad
  FROM dbo.Productos p
  INNER JOIN inserted i ON i.ProductoId = p.Id;
END;

Las tablas virtuales inserted y deleted contienen las filas afectadas (en UPDATE, deleted trae los valores viejos y inserted los nuevos).

Un trigger dispara por LOTE, no por fila: escribe siempre pensando en múltiples filas, como en el ejemplo.
