¿Qué es SQL Server?

Microsoft SQL Server es un sistema gestor de bases de datos relacionales (RDBMS) empresarial. Su lenguaje es T-SQL (Transact-SQL), una extensión del SQL estándar que agrega variables, control de flujo, procedimientos y funciones propias.

Es ampliamente usado en empresas que trabajan con el ecosistema Microsoft: .NET, Azure, Power BI y ERP como Dynamics.

Herramientas de trabajo

SSMS (SQL Server Management Studio) es el cliente gráfico oficial para escribir consultas y administrar el servidor. Azure Data Studio es una alternativa multiplataforma más ligera.

En SSMS escribirás scripts en ventanas de consulta (New Query) y podrás ver tablas, diagramas y planes de ejecución visualmente.

Instancias y bases de datos

Una instancia es un servidor SQL Server corriendo. Dentro conviven varias bases de datos: las del sistema (master, model, msdb, tempdb) y las tuyas. Cada base contiene esquemas (por defecto dbo) y dentro de ellos las tablas.
