Tipos numéricos

MySQL ofrece enteros de distintos tamaños y decimales exactos o aproximados. Elegir bien el tipo ahorra espacio y evita errores de redondeo.

-- Enteros: TINYINT, SMALLINT, MEDIUMINT, INT, BIGINT
-- Decimales exactos (dinero): DECIMAL(M,D)
-- Decimales aproximados (científicos): FLOAT, DOUBLE
CREATE TABLE ejemplo_numerico (
  edad TINYINT UNSIGNED,          -- 0 a 255
  contador INT,                   -- ~-2.147M a 2.147M
  poblacion BIGINT,               -- miles de millones
  precio DECIMAL(10,2),           -- hasta 99.999.999,99 exacto
  peso DOUBLE                     -- aproximado
);

Para dinero usa siempre DECIMAL. FLOAT y DOUBLE generan errores de redondeo acumulables.

TINYINT(1) se usa como booleano; BOOLEAN es un alias de TINYINT(1).

Tipos de texto

CHAR(n) reserva siempre n caracteres (útil para códigos fijos) y VARCHAR(n) solo lo necesario. Los tipos TEXT almacenan textos largos fuera de la fila.

CREATE TABLE ejemplo_texto (
  codigo CHAR(2),                 -- 'MX', 'ES': longitud fija
  nombre VARCHAR(100),            -- longitud variable
  descripcion TEXT,               -- hasta 65.535 caracteres
  documento LONGTEXT,             -- hasta 4 GB
  estado ENUM('activo','inactivo','suspendido')
);

ENUM limita la columna a una lista de valores. Es cómodo, pero si la lista puede crecer es mejor una tabla catálogo.

Fecha y hora

CREATE TABLE ejemplo_fechas (
  fecha_nacimiento DATE,                          -- solo fecha
  hora_entrada TIME,                              -- solo hora
  registrado_en DATETIME,                         -- fecha y hora literal
  ultimo_login TIMESTAMP DEFAULT CURRENT_TIMESTAMP
    ON UPDATE CURRENT_TIMESTAMP                   -- se actualiza solo
);

DATETIME guarda la fecha tal cual (rango 1000-9999); TIMESTAMP la convierte a UTC internamente (rango 1970-2038) y permite actualización automática.

Ejemplo integral

CREATE TABLE empleados (
  id INT AUTO_INCREMENT PRIMARY KEY,
  rfc CHAR(13) NOT NULL UNIQUE,
  nombre VARCHAR(80) NOT NULL,
  salario DECIMAL(10,2) NOT NULL,
  activo BOOLEAN DEFAULT TRUE,
  contratado_el DATE NOT NULL,
  creado_en TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
