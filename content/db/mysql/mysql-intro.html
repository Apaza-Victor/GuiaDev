¿Qué es MySQL?

MySQL es un sistema gestor de bases de datos relacionales (RDBMS) open source, propiedad de Oracle desde 2010. Almacena datos en tablas compuestas por filas y columnas relacionadas entre sí, y se comunica mediante SQL (Structured Query Language). Es el motor detrás de WordPress, YouTube (históricamente), Shopify, Netflix (parte de su stack) y millones de aplicaciones web.

Motor de almacenamiento: InnoDB

CaracterísticaInnoDB (default desde 5.5)Motores legacy (MyISAM)

Foreign keysSí, aplicadasIgnoradas

Casi nunca necesitas cambiar de motor hoy: InnoDB cubre todo caso serio. Si encuentras tutoriales antiguos mencionando MyISAM para "velocidad", están desactualizados — InnoDB moderno gana en la mayoría de cargas reales.

Tu aplicación (PHP, Python, Node…) nunca toca archivos directamente: abre una conexión TCP al puerto 3306, envía texto SQL y recibe resultados. Esta separación permite escalar, asegurar y monitorizar la base independientemente del código.

Versiones relevantes

  • MySQL 5.7: aún presente en servidores legacy — evita proyectos nuevos.
  • MySQL 8.0: estándar actual — CTEs recursivas, window functions, roles, JSON mejorado.
  • MariaDB: fork comunitario compatible; cuidado con features divergentes.

Este curso asume MySQL 8.x. Las CTEs y window functions NO existen en 5.7: si tu hosting te obliga a 5.7, muchas técnicas modernas no estarán disponibles.

# Docker: entorno limpio en 30 segundos
docker run --name mi-mysql \
  -e MYSQL_ROOT_PASSWORD=secreto123 \
  -e MYSQL_DATABASE=tienda \
  -p 3306:3306 -d mysql:8.0

# Conectar desde el contenedor mismo:
docker exec -it mi-mysql mysql -u root -p

# O desde tu máquina si tienes cliente instalado:
mysql -h 127.0.0.1 -P 3306 -u root -p

Primeros comandos dentro del cliente

SHOW DATABASES;                 -- listar bases existentes
USE tienda;                     -- seleccionar base activa
SELECT VERSION();               -- verificar versión
STATUS;                         -- info completa de conexión
HELP 'SELECT';                  -- ayuda integrada del servidor

En desarrollo local una contraseña root simple es aceptable, NUNCA en producción. Y jamás expongas el puerto 3306 a internet sin túnel SSH/firewall — es uno de los vectores de ataque más escaneados del mundo.

MySQL Workbench y clientes

MySQL Workbench es el cliente visual oficial: editor de queries con autocompletado, modelado ER gráfico, administración de usuarios y export/import. Alternativas populares:

phpMyAdminGratis webHosting compartido clásico (con precauciones)

Flujo típico de trabajo en Workbench

  1. Conexión guardada: host localhost, puerto 3306, usuario root.
  2. Editor SQL (Ctrl+Enter ejecuta sentencia actual; rayo completo ejecuta script).
  3. Panel resultados: grid editable — doble click edita celda directa (genera UPDATE real).
  4. Schema navigator: explorar tablas, columnas, índices con click derecho → Table Inspector.
  5. Reverse engineer: genera diagrama ER automático desde una base existente — ideal para entender bases heredadas.

El grid editable de Workbench aplica cambios SIN confirmación al presionar Apply. Si editas una celda de producción creyendo que era staging… ya está. Trabaja siempre con colores/distintos fondos por conexión (Workbench lo permite en Connection Settings).

Ejercicios prácticos

  1. Entorno Docker: levanta MySQL 8 en contenedor con base "practica_db"; conéctate desde el cliente CLI y desde DBeaver/Workbench simultáneamente.
  2. Explorador: ejecuta SHOW DATABASES, SELECT VERSION(), STATUS; documenta en comentarios qué información aporta cada uno.
  3. Comparador de motores: crea dos tablas idénticas, una InnoDB y otra MyISAM (ENGINE=MyISAM); intenta crear FK sobre ambas y observa la diferencia.
  4. Reverse engineering: usa Workbench → Database → Reverse Engineer sobre cualquier base de ejemplo (sakila); estudia el diagrama generado.
  5. Diagnóstico de conexión: provoca tres errores deliberados (contraseña mala, puerto equivocado, base inexistente tras USE) y registra mensaje exacto + causa de cada uno.
