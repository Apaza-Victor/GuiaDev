any, unknown y never

  • any: desactiva el chequeo; evítalo
  • unknown: seguro: obliga a validar antes de usar
  • never: valores que nunca ocurren (funciones que lanzan o infinitas)
function procesar(x: unknown) {
  if (typeof x === "string") console.log(x.toUpperCase());
}

function fallo(msg: string): never {
  throw new Error(msg);
}
Cuidado: Usa any solo como último recurso: pierdes todos los beneficios del tipado.
