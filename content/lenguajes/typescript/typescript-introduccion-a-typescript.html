¿Qué es TypeScript?

TypeScript es un superconjunto tipado de JavaScript creado por Microsoft. Todo JavaScript válido es TypeScript válido, pero además añade tipos estáticos que se verifican al compilar.

  • Detecta errores antes de ejecutar el código
  • Autocompletado y documentación en el editor
  • Facilita el mantenimiento de proyectos grandes
  • Compila a JavaScript estándar para cualquier navegador

Instalación y primer programa

Instala el compilador globalmente y compila tu primer archivo:

npm install -g typescript

tsc --version

# Crear saludo.ts
let nombre: string = "GuiaDev";
console.log(`Hola desde ${nombre}`);

tsc saludo.ts   # genera saludo.js
node saludo.js
Consejo: Usa tsc --init para generar un archivo tsconfig.json con la configuración recomendada.

De JavaScript a TypeScript

El mismo código JS funciona en TS; los tipos son anotaciones opcionales que agregas progresivamente:

// JavaScript válido en TypeScript
function sumar(a, b) { return a + b; }

// Versión tipada
function sumarTipada(a: number, b: number): number {
  return a + b;
}

sumarTipada(2, 3);      // OK
// sumarTipada("2", 3); // Error de compilación
