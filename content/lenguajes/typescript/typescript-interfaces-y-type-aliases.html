Interfaces

interface Usuario {
  readonly id: number;      // no modificable
  nombre: string;
  email?: string;           // propiedad opcional
  saludar(): void;
}

const u: Usuario = {
  id: 1,
  nombre: "María",
  saludar() { console.log(`Hola ${this.nombre}`); }
};

Type aliases y uniones

type ID = number | string;
type Estado = "activo" | "inactivo" | "pendiente";

type Punto = { x: number; y: number };

let estado: Estado = "activo";
// estado = "borrado"; // Error: no está en la unión

Extensión e intersección

interface Animal { nombre: string }
interface Perro extends Animal { ladrar(): void }

type Admin = Usuario & { permisos: string[] }; // intersección
Consejo: Las interfaces se pueden extender y fusionar; los types permiten uniones. Usa interface para objetos públicos y type para uniones/utilidades.
