Clases con tipos

class Cuenta {
  private saldo: number = 0;

  constructor(public titular: string) {}

  depositar(monto: number): void {
    this.saldo += monto;
  }

  get Saldo(): number {
    return this.saldo;
  }
}
  • public: accesible desde cualquier lugar (por defecto)
  • private: solo dentro de la clase
  • protected: clase y subclases

Interfaces y abstracción

interface Volador { volar(): void }

abstract class Ave {
  abstract cantar(): string;
}

class Aguila extends Ave implements Volador {
  cantar() { return "graznido"; }
  volar() { console.log("Volando alto"); }
}
