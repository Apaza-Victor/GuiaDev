Etiqueta ``

La etiqueta permite reproducir archivos de video directamente en el navegador sin necesidad de plugins externos. Ofrece controles nativos y soporte para múltiples formatos.

Sintaxis Básica

Sintaxis Simple

<video src="ruta/al/video.mp4" controls width="640" height="360">
  Tu navegador no soporta el elemento de video.
</video>

Múltiples Fuentes

<video controls width="640" height="360">
  <source src="video.mp4" type="video/mp4">
  <source src="video.webm" type="video/webm">
  <source src="video.ogg" type="video/ogg">
  Tu navegador no soporta el elemento de video.
</video>

Atributos Comunes de Multimedia

Los atributos controls, autoplay, loop y muted son fundamentales para controlar el comportamiento de elementos multimedia.

Tabla Comparativa de Atributos

AtributoDescripciónUso Recomendado
controls$1 $1 Muestra controles de reproducciónSiempre recomendado para accesibilidad
autoplay$1 $1 Reproduce automáticamenteSolo con muted para evitar molestias
loop$1 $1 Reproduce en bucle infinitoMúsica de fondo, videos decorativos
muted$1 $1 Inicia sin sonidoNecesario para autoplay en la mayoría de navegadores
preload$1 $1 Controla la precargametadata para optimizar carga
poster$1 $1 Imagen de vista previaSiempre usar para mejor UX
playsinline$1 $1 Reproduce en línea (iOS)Importante para móviles

Ejemplos de Uso

controls

<!-- Sin controles (no recomendado sin JavaScript) -->
<video src="video.mp4" width="640" height="360">
</video>

<!-- Con controles (recomendado) -->
<video src="video.mp4" controls width="640" height="360">
</video>
Siempre incluye `controls` para que los usuarios puedan controlar la reproducción.

autoplay

<!-- Autoplay sin muted (bloqueado por navegadores) -->
<video src="video.mp4" autoplay controls>
</video>

<!-- Autoplay con muted (funciona) -->
<video src="video.mp4" autoplay muted controls>
</video>

<!-- Autoplay con muted y playsinline (iOS) -->
<video src="video.mp4" autoplay muted playsinline controls>
</video>
Los navegadores modernos bloquean `autoplay` con sonido. Debes usar `muted` o esperar interacción del usuario.

loop

<!-- Audio en bucle para música de fondo -->
<audio src="musica-fondo.mp3" loop autoplay muted controls>
</audio>

<!-- Video en bucle para fondos animados -->
<video src="fondo-animado.mp4" loop autoplay muted playsinline>
</video>

preload

<!-- No precargar (ahorra ancho de banda) -->
<video src="video.mp4" preload="none" controls>
</video>

<!-- Precargar solo metadatos (duración, dimensiones) -->
<video src="video.mp4" preload="metadata" controls>
</video>

<!-- Precargar todo el video (solo si es crítico) -->
<video src="video.mp4" preload="auto" controls>
</video>
Usa `preload="metadata"` para equilibrar experiencia de usuario y consumo de datos.

Mejores Prácticas

    1. Siempre incluye el atributo controls

    Permite a los usuarios controlar la reproducción y mejora la accesibilidad.

       <video src="video.mp4" controls></video>
    1. Usa múltiples formatos para compatibilidad

    Proporciona alternativas para diferentes navegadores.

       <video controls>
     <source src="video.mp4" type="video/mp4">
     <source src="video.webm" type="video/webm">
   </video>
    1. Optimiza el atributo preload

    Usa metadata para equilibrar rendimiento y experiencia.

       <video src="video.mp4" preload="metadata" controls></video>
    1. Añade poster a los videos

    Mejora la presentación visual antes de la reproducción.

       <video src="video.mp4" poster="miniatura.jpg" controls></video>
    1. Usa muted con autoplay

    Evita que los navegadores bloqueen la reproducción automática.

       <video src="video.mp4" autoplay muted playsinline></video>
    1. Implementa diseño responsive para iframes

    Usa técnicas CSS para que el contenido se adapte a todos los dispositivos.

       .video-responsive {
     position: relative;
     padding-bottom: 56.25%; /* 16:9 */
     height: 0;
   }
   
   .video-responsive iframe {
     position: absolute;
     top: 0;
     left: 0;
     width: 100%;
     height: 100%;
   }
    1. Añade title a los iframes

    Mejora la accesibilidad para lectores de pantalla.

       <iframe src="..." title="Descripción del contenido"></iframe>
    1. Usa loading="lazy" para iframes

    Mejora el rendimiento cargando contenido solo cuando sea necesario.

       <iframe src="..." loading="lazy"></iframe>

Consideraciones de Accesibilidad

La accesibilidad en multimedia es crucial para usuarios con discapacidades visuales o auditivas.

Subtítulos y Transcripciones

<!-- Video con subtítulos -->
<video controls>
  <source src="video.mp4" type="video/mp4">
  
  <!-- Subtítulos en español -->
  <track 
    kind="subtitles" 
    src="subtitulos-es.vtt" 
    srclang="es" 
    label="Español" 
    default>
  
  <!-- Subtítulos en inglés -->
  <track 
    kind="subtitles" 
    src="subtitulos-en.vtt" 
    srclang="en" 
    label="English">
  
  <!-- Descripciones de audio -->
  <track 
    kind="descriptions" 
    src="descripciones.vtt" 
    srclang="es" 
    label="Descripciones">
</video>
