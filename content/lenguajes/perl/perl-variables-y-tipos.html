Escalares: $var

En Perl, todos los datos viven en tres tipos de variables: escalares ($), arreglos (@) y hashes (%). Los escalares representan un valor único: un número, una cadena o una referencia. Se identifican con el prefijo $.

use strict;
use warnings;

my $nombre  = "Ana";          # cadena
my $edad    = 30;             # entero
my $pi      = 3.14159;        # decimal
my $activo  = 1;              # booleano (1/0 o 'true'/'false')
my $vacio   = undef;          # valor indefinido

print "$nombre tiene $edad años\n";
print "El valor es $vacio\n";    # aviso: uso de variable no definida

A diferencia de otros lenguajes, el prefijo $ forma parte del nombre de la variable: $nombre y nombre son cosas distintas. Las variables declaradas con my tienen ámbito léxico (local al bloque donde se declaran).

Perl convierte automáticamente entre número y cadena según el contexto. No necesitas declarar el tipo; la variable "es" lo que se le asigna.

Arreglos: @arr

Un arreglo es una lista ordenada de valores que se indexa desde 0. Se identifica con el prefijo @, pero cada elemento individual es un escalar y se accede con $.

use strict;
use warnings;

my @frutas = ("manzana", "pera", "uva");
my @numeros = (10, 20, 30);

print $frutas[0];      # manzana
print $frutas[-1];     # uva (índice negativo: desde el final)
print scalar @frutas;  # 3 (número de elementos)

# Agregar y quitar
push @frutas, "kiwi";       # agrega al final
unshift @frutas, "mango";   # agrega al inicio
my $ultimo = pop @frutas;   # quita del final
my $primero = shift @frutas; # quita del inicio

# Recorrer con índices
for my $i (0 .. $#frutas) {
    print "$i: $frutas[$i]\n";
}

@frutas es la lista completa; $frutas[0] es un elemento. El prefijo $ indica que estás usando "un escalar", y Perl entiende que viene del arreglo por los corchetes.

Hashes: %hash

Un hash (o "diccionario") es una colección de pares clave → valor, ideal para datos asociativos. Se identifica con el prefijo % y se accede a cada valor con llaves {}.

use strict;
use warnings;

my %usuario = (
    nombre  => "Ana",
    edad    => 30,
    ciudad  => "Lima",
);

print $usuario{nombre};   # Ana
$usuario{edad} = 31;      # modificar
delete $usuario{ciudad};  # eliminar

# Verificar existencia
print exists $usuario{edad} ? "sí" : "no";

# Recorrer pares clave-valor
while (my ($clave, $valor) = each %usuario) {
    print "$clave = $valor\n";
}

# Listar claves y valores
my @claves = keys %usuario;
my @valores = values %usuario;

El operador => (fat comma) es solo azúcar sintáctico: nombre => "Ana" equivale a "nombre", "Ana". Uso combinado con %hash dentro de llaves: $hash{clave}.

Contexto: el concepto clave

El contexto es la característica que diferencia a Perl de casi cualquier otro lenguaje: la MISMA expresión produce resultados distintos según dónde se use. Cuando asignas a un escalar, Perl usa contexto escalar; cuando asignas a una lista o arreglo, usa contexto de lista.

use strict;
use warnings;

my @frutas = ("manzana", "pera", "uva");

my $cantidad   = @frutas;   # contexto escalar: cuenta ELEMENTOS (= 3)
my @copia      = @frutas;   # contexto de lista: copia la lista
my $como_lista = (10, 20, 30); # contexto escalar: toma el ÚLTIMO (= 30)

print "$cantidad\n";     # 3
print "$como_lista\n";   # 30

# Operadores sensibles al contexto:
# - En escalar, la coma "encadena" y devuelve el último valor
# - En lista, la coma crea la lista

# Contexto vacío: el resultado se descarta
@frutas = ();            # vacía el arreglo

El operador scalar fuerza contexto escalar. Es la forma típica de contar elementos: scalar @arr. Entender el contexto te evita la mayoría de sorpresas de Perl.

Operadores

Perl ofrece operadores aritméticos, de comparación (dos juegos: numérico y de cadena) y lógicos.

use strict;
use warnings;

# Aritméticos
my $suma  = 10 + 5;
my $resta = 10 - 5;
my $mult  = 10 * 5;
my $div   = 10 / 3;      # 3.333...
my $modulo = 10 % 3;     # 1
my $pot   = 2 ** 8;      # 256
my $inc   = 5; $inc++;   # incremento

# Comparación numérica:  ==  !=  <   <=  >   >=
# Comparación de cadenas: eq  ne  lt  le  gt  ge
my $a = "10";
my $b = "9";
print "numérico: ", ($a > $b ? "10 > 9" : "?"), "\n";   # 10 > 9
print "cadena:   ", ($a gt $b ? "10 gt 9" : "?"), "\n"; # '10' gt '9'

# Lógicos y de cadena
my $nombre = "Perl";
my $saludo = "Hola, " . $nombre;      # concatenación
my $repetido = "ab" x 3;              # "ababab"
my $ok = ($a == 10 && $b eq "9") || die "algo falló";
Tipo de comparaciónNuméricaDe cadenas
Igual==eq
Distinto!=ne
Menor<lt
Mayor>gt

Mezclar ambos juegos es un error clásico: if ($a == $b) convierte a número ("9" == 9 funciona), pero la intención muchas veces es comparar texto. Usa el operador correcto según el tipo de dato.

Ejercicios prácticos

Practica en orden: cada ejercicio asume lo aprendido en el anterior.

  1. Perfil escalar: crea variables con tu nombre, edad, peso y booleano de "estudia"; imprime un párrafo que las use todas.
  2. Lista de compras: crea un @items para tu lista de compras; agrega con push, quita con pop y el primero con shift; imprime el tamaño con scalar.
  3. Diccionario de datos: crea un %persona con 4 claves; modifica una, borra otra y comprueba con exists; recorre con each.
  4. Contexto experto: experimenta con @frutas en contexto escalar vs lista; explica con comentarios qué devuelve cada asignación y por qué.
  5. Doble comparación: escribe un script que compare "10" y "9" con operadores numéricos y con operadores de cadena, mostrando ambos resultados.
