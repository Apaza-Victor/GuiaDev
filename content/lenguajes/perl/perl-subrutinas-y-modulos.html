Subrutinas y @_

Las subrutinas en Perl se declaran con sub y se invocan con &nombre() o simplemente nombre(). Todos los argumentos llegan en el arreglo especial @_.

use strict;
use warnings;

sub saludar {
    my ($nombre, $edad) = @_;
    return "Saludos, $nombre ($edad años)";
}

print saludar("Ana", 30), "\n";

# Con valores por defecto
sub config {
    my ($clave, $valor) = @_;
    $valor //= "default";     # // es "defined or"
    print "$clave = $valor\n";
}

config("idioma");
config("zona", "Lima");

# Tipado no estricto: recibe lo que sea
sub suma {
    my $total = 0;
    $total += $_ foreach @_;
    return $total;
}
print "Suma: ", suma(1, 2, 3, 4), "\n";   # 10

Siempre copia los argumentos al inicio: my ($a, $b) = @_;. Modificar $_[-1] modificaría el original del llamador, y con @_ "aliasing" es un clásico de bugs.

Retorno y contexto

El return devuelve una lista o un escalar; en ausencia de return, la subrutina devuelve el resultado de la última expresión. Como el resto de Perl, respeta el contexto del llamador.

use strict;
use warnings;

sub datos {
    return ("Ana", 30, "Lima");
}

# Contexto de lista: los tres valores
my ($nombre, $edad, $ciudad) = datos();
print "$nombre, $edad, $ciudad\n";

# Contexto escalar: el último valor
my $solo_ultimo = datos();
print "Escalar: $solo_ultimo\n";     # Lima

# Sin return explícito: devuelve la última expresión
sub ultima {
    "valor devuelto";
}
print ultima(), "\n";

# Prototipos: restricción de aridad (opcional y poco usado)
sub dos { my ($a, $b) = @_; "$a+$b" }
print dos(1, 2), "\n";

En contexto escalar, una subrutina con return @lista; devuelve el número de elementos, y con return (1,2,3); devuelve 3 (el último). Si necesitas forzar lista en contexto escalar usa una referencia; verás por qué en la sección de referencias.

Referencias

Las referencias son "punteros" a otras variables: un escalar que apunta a un arreglo, hash o subrutina. Son indispensables para: pasar estructuras grandes a subrutinas, crear estructuras anidadas y abrir el camino al orientado a objetos.

use strict;
use warnings;

my @frutas = ("manzana", "pera");
my $ref_lista = \@frutas;              # referencia a arreglo
print $ref_lista->[1], "\n";           # pera

my %datos = (a => 1, b => 2);
my $ref_hash = \%datos;
print $ref_hash->{a}, "\n";            # 1

# Referencias anónimas
my $lista_corta = [10, 20, 30];
my $hash_corto  = { x => "ex" };
print "$lista_corta->[0] $hash_corto->{x}\n";

# Estructuras anidadas (listas de listas)
my $matriz = [
    [1, 2, 3],
    [4, 5, 6],
];
print "elemento: $matriz->[1][2]\n";   # 6

# Pasar por referencia a una subrutina (eficiente, y respeta el original)
sub primera {
    my $r = shift;
    return $r->[0];
}
print "Primera: ", primera(\@frutas), "\n";

# Desreferenciar: @$ref_lista, %$ref_hash
my @copia = @$ref_lista;
print "@copia\n";

El operador -> es "flecha de desreferencia": $ref_lista->[1] equivale a ${$ref_lista}[1]. Con Data::Dumper verás estructuras anidadas con claridad: print Dumper($matriz).

CPAN y cpanminus

CPAN (Comprehensive Perl Archive Network) es el repositorio de módulos de Perl: más de 200.000 distribuciones reutilizables. La forma más cómoda de instalar módulos es con cpanm (cpanminus).

# Instalar cpanm
cpan App::cpanminus

# Instalar un módulo
cpanm Moose
cpanm JSON::PP

# Instalar desde un archivo rentable (una lista de dependencias)
cpanm --installdeps .

# Buscar un módulo
perl -MCPAN -e 'CPAN::Shell->autobundle'

# Verificar que un módulo está instalado
perl -MJSON::PP -e 'print JSON::PP::true, "\n"'
# Usar módulos de CPAN
use JSON::PP qw(encode_json decode_json);
use Data::Dumper;

my $perl_hash = { nombre => "Ana", apta => JSON::PP::true };
my $json      = encode_json($perl_hash);
print "$json\n";                    # {"apta":true,"nombre":"Ana"}

my $vueltas = decode_json($json);
print Dumper($vueltas);

use Módulo qw(lista de exports); importa funciones al espacio actual. Los módulos en Perl empezaron como "pragmas" (strict, warnings) y luego llegaron las CPAN dists. El ecosistema Perl "no incluye baterías": casi todo útil está en CPAN.

Módulos útiles

Un puñado de módulos resolverá la mayoría de necesidades cotidianas en Perl moderno.

use strict;
use warnings;

use JSON::PP;                 # JSON
use Data::Dumper;             # depuración
use Path::Tiny;               # rutas y archivos (+ PerlIO)
use Time::Piece;              # fechas
use LWP::Simple qw(get);      # peticiones HTTP (con LWP o lwp-request)
use File::Basename;           # manejo de nombres de ruta

# Fecha
my $t = localtime;
print $t->strftime("%Y-%m-%d"), "\n";

# Rutas
use Path::Tiny;
my $dir = path("logs")->mkpath;
say "Directorio: ", $dir;     # logs

# Leer un archivo entero (Path::Tiny)
my $contenido = path("datos.txt")->slurp_utf8;
print "Primeras 30 chars: ", substr($contenido, 0, 30), "\n";

say "Listo.";

Con `use Mojolicious::Lite` construyes un servicio web en 10 líneas. Con `Test::More` + `prove` pruebas tu módulo en segundos. El módulo `Modern::Perl` activa strict, warnings y características de la versión actual en una sola línea.

Ejercicios prácticos

Practica en orden: cada ejercicio asume lo aprendido en el anterior.

  1. Librería de utilidades: crea subrutinas saludo, suma y area_circulo; usa valores por defecto con //=.
  2. Contexto controlado: escribe una subrutina que devuelva una lista de 3 elementos y llámala en contexto lista, escalar y con scalar; explica cada salida.
  3. Estructuras anidadas: construye una agenda (refs anidadas: día → listas de tareas) y muestra una tarea por cada día.
  4. Primer módulo: instala JSON::PP (o verifica que existe) y codifica/decodifica un hash con un array interno.
  5. Agenda con Time::Piece: muestra la fecha actual en formato YYYY-MM-DD HH:MM y suma un día.

En la próxima lección dominaremos el manejo de archivos, el operador diamante y la automatización de tareas del sistema.
