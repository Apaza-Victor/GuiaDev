¿Qué es Perl?

Perl es un lenguaje de programación creado por Larry Wall en 1987, diseñado originalmente para procesamiento de texto y administración de sistemas en Unix. Su lema dice mucho de su filosofía: "There's more than one way to do it" (TIMTOWTDI), es decir, hay varias maneras de hacer las cosas.

Perl destaca por su potencia con expresiones regulares, su sintaxis flexible y su capacidad para pasar de "one-liner" de terminal a programas completos. Durante los años 90 fue el lenguaje dominante en desarrollo web (CGI) y hoy sigue siendo fundamental en administración de sistemas, automatización y análisis de logs.

Perl es un lenguaje "pragmático": prefiere la utilidad sobre la elegancia. Si puedes expresar una tarea, Perl suele tener una forma casi natural de hacerlo.

Instalación y versiones (perlbrew)

Perl viene preinstalado en casi todos los sistemas Unix/Linux y macOS. Para instalarlo a mano o gestionar varias versiones, la herramienta recomendada es perlbrew, que te permite tener versiones aisladas sin tocar el Perl del sistema.

# Verificar instalación existente
perl -v

# Windows: Strawberry Perl (recomendado) o ActivePerl
# https://strawberryperl.com/ - instalador con CPAN incluido

# macOS / Linux: instalar perlbrew
curl -L https://install.perlbrew.pl | bash
perlbrew init
echo 'source ~/perl5/perlbrew/etc/bashrc' >> ~/.bashrc
source ~/.bashrc

# Instalar la última versión estable de Perl 5
perlbrew install perl-5.40.0
perlbrew switch perl-5.40.0

# Verificar
perl -v

En Windows, Strawberry Perl incluye un compilador C y el cliente cpanm listos para usar. Es la forma más cómoda de trabajar con Perl y CPAN en Windows.

Tu primer script

Un script Perl es un archivo de texto con extensión .pl. La primera línea con #!/usr/bin/perl es el shebang, que indica al sistema qué intérprete usar cuando el archivo es ejecutable.

#!/usr/bin/perl
use strict;
use warnings;

print "Hola, GuiaDev!\n";

my $nombre = "Perl";
my $anio   = 2026;
print "Bienvenido a $nombre ($anio)\n";
# Ejecutar
perl hola.pl
# Salida:
# Hola, GuiaDev!
# Bienvenido a Perl (2026)

# También como archivo ejecutable
chmod +x hola.pl
./hola.pl

Siempre escribes use strict; y use warnings; en tus scripts. Son pragmas que activan restricciones y avisos: detectan errores típicos como variables mal escritas u operaciones poco seguras.

One-liners con perl -e

Una de las mayores fortalezas de Perl es ejecutar one-liners: programas completos en una sola línea desde la terminal, perfectos para procesar texto, logs y archivos de configuración sin escribir un script.

# Imprimir un texto
perl -e 'print "Hola desde un one-liner\n";'

# Sustituir texto en un archivo (in-place, con respaldo)
perl -i.bak -pe 's/cat/gato/g' archivo.txt

# Imprimir las líneas que coinciden con un patrón
perl -ne 'print if /ERROR/' app.log

# Imprimir la columna 3 de un CSV
perl -F',' -ane 'print $F[2], "\n"' datos.csv

# Sumar una columna de números
perl -ane '$sum += $F[2]; END { print "Total: $sum\n" }' datos.csv

Las banderas más usadas son:

FlagSignificado
-eEjecutar el código que sigue (el "one-liner")
-pIterar líneas, ejecutar código e imprimir cada línea
-nIterar líneas sin imprimirlas automáticamente
-iEditar archivos in-place (edición directa, opcional .bak)
-aDividir en columnas (con -F para el separador)
-F','Usar coma como separador de campos

Documentación con perldoc

Perl incluye una documentación completa y navegable en tu propia máquina. El comando perldoc es tu mejor amigo para consultar manuales, funciones y módulos.

# Guía general del lenguaje
perldoc perlintro

# Referencia rápida de funciones integradas
perldoc perlfunc

# Manual de una función concreta
perldoc -f length
perldoc -f map

# Documentación de un módulo de CPAN
perldoc Data::Dumper

# Tutorial de expresiones regulares
perldoc perlretut

# Buscar en la documentación
perldoc -q "split"

Además de perldoc, la librería Data::Dumper es imprescindible para depurar: imprime cualquier estructura de datos de forma legible con solo use Data::Dumper; y print Dumper($variable);.

Ejercicios prácticos

Practica en orden: cada ejercicio asume lo aprendido en el anterior.

  1. Instalación verificada: ejecuta perl -v y comprueba la versión. Si estás en Windows, instala Strawberry Perl.
  2. Primer script: escribe hola.pl que imprima tu nombre, tu lenguaje favorito y el año con use strict y use warnings.
  3. One-liner de sustitución: crea un archivo texto.txt y usa perl -i.bak -pe 's/.../.../' para reemplazar una palabra; verifica el respaldo generado.
  4. Filtro de logs: con perl -ne 'print if /patrón/' filtra las líneas con "ERROR" de un archivo de log de ejemplo.
  5. Resumen de columnas: con -F',' -ane suma numéricamente una columna de un CSV inventado.
  6. Documentación: usa perldoc perlintro y perldoc -f length; apunta tres funciones nuevas que hayas descubierto.
