Leer y escribir archivos

Perl maneja archivos con descriptores (FILEHANDLE), normalmente abiertos con open y siempre cerrados con close. La banda my $fh con open my $fh, '>', $archivo introduce la variable como manejador (recomendado en Perl moderno).

use strict;
use warnings;

# Escribir (modo '>' sobrescribe, '>>' agrega)
my $ruta = "salida.txt";
open my $fh, ">", $ruta or die "No puedo escribir $ruta: $!";
print $fh "Línea uno\n";
print $fh "Línea dos\n";
close $fh;

# Leer línea a línea
open my $in, "<", $ruta or die "No puedo leer $ruta: $!";
my @lineas;
while (my $linea = <$in>) {
    chomp $linea;                     # quita el \n final
    push @lineas, $linea;
}
close $in;
print join(" / ", @lineas), "\n";     # Línea uno / Línea dos

# Leer TODO de golpe
open my $in2, "<", $ruta or die "error: $!";
my $todo = do { local $/; <$in2> };  # modo slurp
close $in2;
print "Longitud: ", length $todo, "\n";

La variable $! contiene el error del sistema: úsala siempre en el or die. Después de open comprueba la falla; Perl lo silencia si no lo pides.

El operador diamante <>

El operador diamante <> (sin manejador) es la forma idiomática de procesar archivos pasados como argumentos en la línea de comandos, igual que hacen cat, sed o awk.

#!/usr/bin/perl
use strict;
use warnings;

# cat archivo1 archivo2 | perl conteo.pl
# perl conteo.pl a.txt b.txt   ->  procesa ambos en orden
while (<>) {
    chomp;
    my @campos = split /\t/;
    print "N:", scalar @campos, " -> $fields[0]\n" if @campos;
}

# Con banderas propias
my $verbose = 0;
while (<>) {
    $verbose = 1 if /^--verbose/;
    print "VERBOSE: $_" if $verbose;
}
# Uso típico en la terminal
perl -ne 'print if /ERROR/' app.log
perl -ane 'print $F[1]' datos.csv

# También con el diamante en un script
perl procesa.pl entradas/*.txt

El diamante es lo que da a los one-liners de Perl su poder de "filtro Unix": recibe archivos de la línea de comandos o de STDIN por pipa. Cada vuelta del while (<>) trae la siguiente línea y la guarda en $_.

Tareas de administración de sistemas

Con -e, -f, -d (entre otros "filetests") y las funciones estándar de Perl (rename, unlink, mkdir, glob) automatizamos tareas del sistema sin instalar nada.

use strict;
use warnings;

# Filetests: operador -X
for my $archivo (<*.log>) {
    print "$archivo: ",
      (-f $archivo ? "archivo" : "especial"),
      (-s $archivo ? sprintf(" %d bytes", -s $archivo) : ""),
      "\n";
}

# Condicionales de existencia
die "Falta datos.txt" unless -e "datos.txt";

# Crear directorios recursivamente
system("mkdir", "-p", "logs/2026/08") if !-d "logs/2026/08";

# Renombrar y borrar
rename "backup.tar", "backup_2026.tar" or warn "no se pudo renombrar: $!";
unlink "temporal.tmp" if -e "temporal.tmp";

# Copiar usando módulo estándar
use File::Copy;
copy("datos.txt", "copia.txt") or die "copia falló: $!";

Procesamiento de texto

Un caso real: analizar un archivo de log y generar un resumen. Combinamos lectura, regex, hashes para conteos y órdenes de salida.

use strict;
use warnings;

# Simulamos contenido de log
my $log = <<'LOG';
2026-08-29 INFO user=ana accion=login
2026-08-29 INFO user=pedro accion=login
2026-08-29 WARN user=ana accion=retry
2026-08-29 ERROR user=ana accion=disk_full
2026-08-30 INFO user=pau accion=logout
LOG

my %nivel;
my %por_usuario;
open my $fh, "<", \$log or die "error";    # lectura desde escalar

while (my $linea = <$fh>) {
    chomp $linea;
    # nivel = segundo token, usuario = primer token tras user=
    my ($nivel) = $linea =~ /^\d{4}-\d{2}-\d{2} (\w+)/;
    my ($usuario) = $linea =~ /user=(\w+)/;
    $nivel{$nivel}++        if defined $nivel;
    $por_usuario{$usuario}++ if defined $usuario;
}
close $fh;

print "Conteo por nivel (ordenado):\n";
for my $n (sort keys %nivel) {
    printf "  %-6s %d\n", $n, $nivel{$n};
}

print "Actividad por usuario:\n";
for my $u (sort { $por_usuario{$b} <=> $por_usuario{$a} } keys %por_usuario) {
    printf "  %-8s %d eventos\n", $u, $por_usuario{$u};
}

sort keys %hash ordena alfabéticamente; sort { $h{$b} <=> $h{$a} } keys %hash ordena por valor numérico descendente. Ese patrón (conteo → orden → printf) cubre el 90% del análisis ad-hoc.

Ejercicios prácticos

Practica en orden: cada ejercicio asume lo aprendido en el anterior.

  1. Backup en una línea: escribe un script que copie datos.txt a datos_2026-08-29.txt usando File::Copy.
  2. Contador de líneas: con while (<>) cuenta las líneas de un archivo y las que no están vacías.
  3. Filtro de logs: procesa un log con el diamante y muestra solo las líneas ERROR junto con su usuario, anclando con regex.
  4. Informe de archivos: lista los *.log del directorio con size en KB usando -s y -d; ordena de menor a mayor.
  5. Automatización completa: escribe un script que: filtre ERROR, cuente por nivel, genere un resumen resumen.txt y lo imprima ordenado.
