¿Qué es Swift?

Swift es el lenguaje de programación moderno de Apple, presentado en 2014 por Chris Lattner y su equipo. Fue diseñado como sucesor de Objective-C para desarrollar apps para iOS, macOS, watchOS y tvOS (y hoy también corre en Linux y Windows). Nació con una idea clara: ofrecer la potencia de un lenguaje compilado con una sintaxis limpia, clara y segura que resultara fácil de leer y aprender.

// Hola mundo
print("Hola")   // imprime: Hola

Swift es de código abierto desde 2015. Su compilador puede ejecutarse fuera del ecosistema Apple, y con Swift Playgrounds puedes empezar a aprender desde el iPad incluso sin saber nada de programación.

VentajaQué aporta

Sintaxis modernaCódigo más legible, conciso y expresivo que Objective-C
RendimientoCombinado con LLVM, se acerca al rendimiento de C/C++
Protocolos y extensionesPermiten programación orientada a protocolos y extender tipos existentes

Sintaxis básica

En Swift declaras los valores con var (variables mutables) y let (constantes inmutables). No se usan punto y coma al final de cada línea, y los comentarios pueden ser de una línea, de varias líneas o de documentación:

var contador = 0            // variable mutable (var)
let nombre = "Ana"          // constante inmutable (let)

print("Hola, \(nombre)")    // imprimir en la consola

// comentario de una línea
/* comentario
   de varias líneas */
/// Comentario de documentación (generate saca Docs)

Inferencia de tipos y anotación explícita

Swift puede inferir el tipo automáticamente a partir del valor asignado, o puedes indicarlo de forma explícita con la sintaxis tipo:

var edad = 30            // Int (inferido)
var precio: Double = 9.99  // anotación explícita
var nombre: String = "Luis" // anotación explícita

Con let declaras valores que nunca cambiarán; con var, valores que sí cambiarán:

Arrays y diccionarios

var frutas = ["manzana", "pera", "uva"]   // Array<String>
frutas.append("mango")                    // añade al final
let primera = frutas[0]                   // "manzana" (índice desde 0)

var edades = ["ana": 30, "luis": 25]      // Dictionary<String, Int>
let edadAna = edades["ana"] ?? 0          // leer SIEMPRE devuelve optional

Al leer un Dictionary obtienes un optional, porque la clave podría no existir. Usa ?? valorPorDefecto o if let para manejarlo con seguridad.

Opcionales (Optionals)

Un optional es un tipo que puede contener un valor o nada (nil). Se declara añadiendo ? al tipo: Int? se lee "un Int o nil". Es el mecanismo con el que Swift elimina los errores de null: el compilador te obliga a comprobar que hay valor antes de usarlo.

var edad: Int? = 30   // puede tener un valor…
edad = nil            // …o no tenerlo

Las cuatro formas de manejarlo

FormaQué hace
if letDesenvuelve de forma segura si hay valor; si no, ejecuta el else
guard letSi no hay valor, sale del ámbito; si lo hay, queda disponible después
! (force unwrap)Desenvuelve a la fuerza; si es nil, el programa crashea
?? (nil coalescing)Devuelve el valor o un valor por defecto si es nil
let nombre: String? = "Ana"

// 1) if let (optional binding): solo entra si hay valor
if let nombre = nombre {
    print("Hola, \(nombre)")
} else {
    print("Sin nombre")
}

// 2) guard let: salida temprana, el valor queda disponible después
func saludar(_ nombre: String?) {
    guard let nombre else { return }
    print("Hola, \(nombre)")   // aquí 'nombre' NO es opcional
}

// 3) force unwrap: ¡arriesgado!
// print(nombre!)  💥 si nombre fuera nil, la app crashea

// 4) nil coalescing: valor o respaldo
let mostrado = nombre ?? "invitado"   // "Ana"

Evita el force unwrap con ! en producción: si el valor resultó ser nil, el programa muere con un Fatal error: Unexpectedly found nil. Prefiere siempre if let, guard let o ??.

Estructuras de control

if / else

let edad = 20
if edad >= 18 {
    print("Mayor de edad")
} else if edad >= 13 {
    print("Adolescente")
} else {
    print("Menor")
}

switch (no necesita break, admite rangos y patrones)

let nota = 8
switch nota {
case 9...10: print("Sobresaliente")   // rango cerrado
case 7...8:  print("Notable")
case 5...6:  print("Aprobado")
case 1...4:  print("Suspenso")        // rango con 1...4
default:     print("Calificación inválida")
}
// Ojo: en Swift el switch NO necesita 'break'

for-in

for numero in 1...5 {
    print("Vuelta \(numero)")
}
let nombres = ["Ana", "Luis"]
for nombre in nombres {
    print(nombre)
}

while y repeat-while

var i = 0
while i < 3 {
    print(i)
    i += 1
}

var j = 0
repeat {              // equivalenta al do-while de otros lenguajes
    print("Ejecuta al menos una vez")
    j += 1
} while j < 3

guard, break y continue

func validar(_ valor: Int?) {
    guard let valor, valor > 0 else {
        print("Dato inválido, saliendo")
        return
    }
    print("Válido: \(valor)")   // 'valor' disponible aquí
}

for numero in 1...10 {
    if numero == 3 { continue }   // salta esta iteración
    if numero == 8 { break }      // sale del bucle
    print(numero)
}

Funciones, clases y protocolos

Funciones

func sumar(a: Int, b: Int) -> Int {
    return a + b
}
let resultado = sumar(a: 2, b: 3)   // 5

// Argumentos etiquetados: una etiqueta para fuera, un nombre para dentro
func desplazar(_ x: Int, por: Int) -> Int {
    return x + por
}
desplazar(10, por: 2)   // 12

Clases (referencia) e inicializadores

class Animal {
    var nombre: String
    init(nombre: String) {          // inicializador
        self.nombre = nombre        // 'self' se refiere a la instancia
    }
    func sonido() -> String { return "..." }
}

class Perro: Animal {               // herencia: ':' + clase padre
    override func sonido() -> String {
        return super.sonido() + " ¡Woof!"   // 'super' llama al padre
    }
}

let firulais = Perro(nombre: "Firulais")
print(firulais.sonido())

Structs (valor) y protocolos

protocol Sonido {                    // define un contrato
    func emitirSonido() -> String
}

struct Gato: Sonido {               // struct que adopta el protocolo
    var nombre: String
    func emitirSonido() -> String { return "¡Miau!" }
}

extension Gato {                    // extension: añade funcionalidad
    func presentarse() -> String { return "Soy \(nombre)" }
}
ElementoQué es
funcDeclara una función
classDefine un tipo por referencia, con herencia
structDefine un tipo por valor, sin herencia
protocolDefine requisitos que otros tipos deben cumplir
extensionAñade métodos y propiedades a un tipo existente
initInicializador: prepara el objeto al crearlo
selfReferencia al propio objeto dentro de sus métodos
superReferencia a la clase padre dentro de una subclase

Regla de oro: let/var para la mutabilidad, optionals para la ausencia de valor y struct por defecto (usa class solo cuando necesites herencia o referencia compartida). Con eso, el 90% del código seguro está resuelto.
