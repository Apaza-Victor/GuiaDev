UI declarativa

SwiftUI describe la interfaz como función del estado: tú declaras QUÉ quieres ver, no cómo dibujarlo.

import SwiftUI

struct ContentView: View {
    @State private var contador = 0

    var body: some View {
        VStack(spacing: 16) {
            Text("Contador: \(contador)")
                .font(.largeTitle)

            Button("Sumar") {
                contador += 1        // la vista se actualiza sola
            }
            .buttonStyle(.borderedProminent)
        }
        .padding()
    }
}

Composición

struct Tarjeta: View {
    let titulo: String

    var body: some View {
        HStack {
            Image(systemName: "star.fill")
            Text(titulo)
            Spacer()
        }
        .padding()
        .background(Color.yellow.opacity(0.2))
        .cornerRadius(12)
    }
}
Consejo: Todo en SwiftUI es una View componibles: domina VStack/HStack/ZStack y podrás construir cualquier pantalla.
