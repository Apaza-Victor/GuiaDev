¿Qué es Swift?

Swift es el lenguaje de programación moderno creado por Apple y presentado en la WWDC de 2014 como sucesor de Objective-C. Los ingenieros de Apple se hicieron una pregunta ambiciosa: ¿cómo sería un lenguaje si pudiéramos aprender de décadas de historia de la programación? El resultado combina el rendimiento de los lenguajes compilados como C++ con una sintaxis clara que elimina por diseño las categorías de errores más frecuentes.

Desde diciembre de 2015 Swift es código abierto (licencia Apache 2.0), lo que permitió que la comunidad contribuyera al propio lenguaje y que este trascendiera los dispositivos de Apple hacia servidores y otros sistemas operativos.

Si vienes de Python o JavaScript te sentirás pronto en casa: Swift también infiere tipos y usa sintaxis ligera. Si vienes de Java o C#, reconocerás las llaves, las clases y el tipado estático.

Tu primer programa

Como manda la tradición, empezamos saludando. Fíjate en dos detalles: no hace falta punto y coma ni función main visible, y cada valor se declara con let (constante, no puede cambiar) o var (variable, puede cambiar).

// El clásico primer programa
print("Hola, GuiaDev!")

// let crea constantes: el compilador te avisará si intentas cambiarlas
let constante = 10

// var crea variables: su valor puede cambiar
var variable = 20
variable += 5
print(variable)   // 25

¿Por qué preferir let sobre var?

La filosofía de Swift es que todo lo que no deba cambiar debería ser inmutable. Declarar con let comunica intención ("esto nunca cambia"), evita modificaciones accidentales y ayuda al compilador a optimizar. La convención profesional es empezar siempre con let y cambiar a var solo cuando Xcode lo sugiera porque el valor realmente muta.

Anotación explícita de tipos

Normalmente Swift deduce el tipo solo, pero puedes escribirlo de forma explícita cuando quieras ser deliberado:

let pi: Double = 3.14159      // Double explícito
let nombre: String = "Ana"    // String explícito
let activo: Bool = true       // Bool explícito

Compilar y ejecutar desde la terminal

Swift es un lenguaje compilado. Con la herramienta swiftc puedes generar un ejecutable nativo sin abrir ningún IDE:

$ swiftc hola.swift -o hola
$ ./hola
Hola, GuiaDev!

Tipado seguro con inferencia

Swift es de tipado estático: el tipo de cada valor se conoce en tiempo de compilación. Pero a diferencia de Java o C#, casi nunca lo escribes: el compilador lo infiere del valor inicial. Obtienes lo mejor de ambos mundos: código breve como el de un lenguaje dinámico, con la seguridad de uno estático.

let edad = 30            // el compilador infiere Int
let precio = 19.99       // infiere Double
let nombre = "Luis"      // infiere String
let esActivo = false     // infiere Bool

print(type(of: edad))    // Int

La seguridad actúa en tiempo de compilación

Mezclar tipos incompatibles no compila; el error aparece antes de ejecutar el programa, que es justo cuando corregirlo cuesta menos:

let numero: Int = 5
// let suma = numero + 2.5
// ❌ error: binary operator '+' cannot be applied
//    to operands of type 'Int' and 'Double'

// ✅ Conversión explícita obligatoria
let suma = numero + Int(2.5)     // 7
let decimal = Double(numero) + 2.5  // 7.5

A diferencia de otros lenguajes, Swift no convierte números silenciosamente: Int y Double son mundos separados. Las conversiones (Int(x), Double(x)) son siempre explícitas.

Nombres descriptivos y convenciones

Swift usa camelCase para variables y funciones (precioTotal) y PascalCase para tipos (ProductoFavorito). Como el tipo ya está claro por inferencia, el nombre debe describir el propósito, no el tipo: prefiere let segundosPorDia = 86_400 a let n = 86400. Por cierto, el guion bajo agrupa dígitos y mejora la legibilidad de números grandes.

Strings e interpolación

El tipo String de Swift es Unicode completo de forma nativa (los emojis cuentan como caracteres válidos) y ofrece una función estrella: la interpolación. Con \(...) insertas cualquier expresión dentro de un texto, algo mucho más legible que concatenar trozos con +.

let nombre = "Mundo"
let saludo = "Hola, \(nombre)!"        // Hola, Mundo!

// Dentro de \( ) cabe cualquier expresión válida
let precio = 19.99
let cantidad = 3
let total = "Total: \(precio * cantidad) €"

// Comparación directa y propiedades útiles
saludo == "Hola, Mundo!"               // true
saludo.count                           // 12 caracteres
saludo.uppercased()                    // HOLA, MUNDO!

Textos multilínea

Con tres comillas dobles puedes escribir bloques de texto largos sin concatenar ni escapar saltos de línea. Ideal para JSON, HTML o mensajes largos:

let factura = """
Factura #1042
Cliente: \(nombre)
Importe: \(total)
"""

Cadenas vacías y comprobaciones rápidas

var mensaje = ""
mensaje.isEmpty                 // true
mensaje += "Primer texto"

let ruta = #"C:\Users\ana\"     // Raw string: sin escapes, \
print(ruta)

Las cadenas en Swift son colecciones de caracteres: puedes recorrerlas con for letra in saludo { } igual que un array, gracias a que conforman el protocolo Collection.

El REPL en acción

Abre una terminal y ejecuta swift; obtienes un entorno interactivo donde cada expresión se evalúa al instante y muestra su resultado:

$ swift
Welcome to Apple Swift version 5.9.
  1> let numeros = [3, 1, 4]
numeros: [Int] = 3 values
  2> numeros.map { $0 * 2 }
$R0: [Int] = [6, 2, 8]

Un Playground mínimo

En Xcode: File → New → Playground. El panel derecho muestra el valor de cada línea en vivo mientras escribes:

var saldo = 100.0
saldo += 250          // el resultado aparece al instante en el panel lateral
saldo *= 1.05         // 367.5

No necesitas un Mac para empezar: en Windows o Linux instala el toolchain desde swift.org y usa VS Code; en iPad, la app gratuita Swift Playgrounds enseña los fundamentos con lecciones interactivas.

Primer vistazo a los optionals

Hay una situación que todo lenguaje debe resolver: ¿qué pasa cuando un valor puede no existir? Un campo que el usuario dejó vacío, un elemento que no está en un diccionario, una descarga que falló. Muchos lenguajes responden con null escondido en cualquier variable… y con los famosos errores de puntero nulo en producción.

La respuesta de Swift es el optional: un tipo que declara honestamente que puede no haber valor. Se marca con ? después del tipo:

var apodo: String? = nil        // aún no tiene valor
apodo = "Toro"                  // ahora sí

// Leerlo exige comprobar primero: el compilador te protege
if let apodoReal = apodo {
    print("Su apodo es \(apodoReal)")   // Su apodo es Toro
}

let edades = ["ana": 30]
let edadAna = edades["ana"]     // Int? : podría no existir la clave

Fíjate en el último caso: buscar una clave en un diccionario devuelve Int?, no Int, porque la clave puede no estar. El sistema de tipos te obliga a decidir qué hacer si falta. Este pequeño cambio elimina de raíz una enorme familia de bugs.

Dominar los optionals es el salto conceptual de esta unidad. En la próxima lección los disecaremos a fondo: qué son realmente, cómo desenvolverlos con seguridad y cuándo evitar la fuerza bruta.

---

Errores comunes del principiante

1. Usar var para todo

// ❌ Innecesariamente mutable
var nombre = "Ana"
var pi = 3.14159

// ✅ Constante por defecto
let nombre = "Ana"
let pi = 3.14159

2. Olvidar que Int y Double no se mezclan solos

let total: Double = 5          // ❌ error: cannot convert Int to Double
let total: Double = 5.0        // ✅ o Double(5) si viene de un Int

3. Nombrar variables sin significado

let d = 3.5        // ❌ ¿días? ¿descuento? ¿distancia?
let diasDeAlquiler = 3.5   // ✅ el nombre documenta el código

4. Intentar forzar optionals sin entenderlos

var entrada: String? = leerUsuario()
// print(entrada!)        // 💥 crash si es nil
if let entrada { print(entrada) }   // ✅ seguro y breve (Swift 5.7+)

El error nº 1 de quien empieza es tratar Swift como su lenguaje anterior y pelear contra el compilador. Cuando Swift rechaza tu código casi siempre está previniendo un fallo futuro: lee el mensaje de error con calma; suelen ser sorprendentemente precisos y hasta proponen la corrección.

Ejercicios prácticos

Resuelve estos ejercicios en un Playground o en el REPL para afianzar lo aprendido. Están ordenados de menor a mayor dificultad:

  1. Tarjeta de presentación: declara constantes con tu nombre, ciudad y año actual, e imprime una frase interpolada que las combine, por ejemplo "Soy Ana, de Madrid, en 2026".
  2. Calculadora de compra: dados precio unitario 4.50 y cantidad 3, calcula el total y muestra el mensaje "3 unidades cuestan 13.5 €" usando interpolación (recuerda: Int y Double requieren conversión explícita).
  3. Texto formateado: crea un String multilínea con tres líneas de una factura (producto, cantidad, importe) usando interpolación, y muestra cuántos caracteres tiene con count.
  4. Conversor de minutos: declara let minutos = 135 y calcula horas y minutos restantes usando el operador módulo % y la división entera; imprime "2 h 15 min".
  5. Mini perfil opcional: crea var email: String? = nil, asígnale un valor y escríbelo con if let dentro de una frase; luego ponlo a nil y comprueba que el bloque if let ya no se ejecuta. (Adelanto de la próxima lección.)
