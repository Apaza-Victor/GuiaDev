Implementación implícita

type Saluda interface {
	Saludar() string
}

// Usuario ya implementa Saluda sin declararlo
func presentarse(s Saluda) {
	fmt.Println(s.Saludar())
}

presentarse(u)  // cualquier tipo con Saludar() sirve
Consejo: En Go las interfaces se satisfacen implícitamente: no hace falta "implements". Esto permite desacoplar paquetes fácilmente.

Interfaces estándar

// error es una interfaz de un método:
// type error interface { Error() string }

type MiError struct{ Msg string }
func (e MiError) Error() string { return e.Msg }

// fmt.Stringer controla cómo se imprime un tipo
func (u Usuario) String() string { return u.Nombre }
