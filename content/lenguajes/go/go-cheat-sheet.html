¿Qué es Go?

Go (también llamado Golang) es un lenguaje de sistemas creado por Google en 2009 por Rob Pike, Ken Thompson y Robert Griesemer. Está diseñado para la simplicidad, la compilación muy rápida y la concurrencia nativa, lo que lo hace ideal para servidores, servicios de red, herramientas de línea de comandos y microservicios.

// Tu primer programa: hola mundo
package main

import "fmt"

func main() {
	fmt.Println("¡Hola, mundo!")
}
VentajaQué aporta
SimplicidadUn lenguaje pequeño con pocas palabras reservadas y una sintaxis limpia que se aprende rápido
Velocidad de compilaciónCompila a binarios nativos en muy poco tiempo, incluso en proyectos grandes
Concurrencia con goroutinesLanza miles de tareas ligeras con la palabra go y algunas líneas
Tipado estáticoEl compilador detecta errores de tipos antes de ejecutar el programa
Compilado a binariosGenera un único ejecutable autónomo sin dependencias de runtime externas

Go brilla en el lado servidor: APIs REST, aplicaciones CLI, herramientas de DevOps y sistemas concurrentes son su territorio natural.

Sintaxis básica

Un programa en Go empieza con package main y una función main que es el punto de entrada. Go no usa punto y coma al final de cada línea (el compilador los inserta automáticamente) y se formatea automáticamente con la herramienta gofmt.

package main

import "fmt"

func main() {
	// Declarar una variable con var
	var nombre string = "Ana"
	// Declarar con inferencia (:=)
	edad := 30

	fmt.Println("Hola", nombre, "tienes", edad)

	// Leer entrada del usuario
	var entrada string
	fmt.Scanf("%s", &entrada)
	fmt.Println("Escribiste:", entrada)
}

No necesitas escribir punto y coma: fmt.Println("hola") y no fmt.Println("hola");. La herramienta gofmt normaliza el estilo de todo el equipo automáticamente.

x := 10

Estructuras de control

Las condiciones en Go no llevan paréntesis (pero las llaves son obligatorias). Además, Go no tiene while ni do-while: todo bucle se expresa con for.

// if / else sin paréntesis
edad := 20
if edad >= 18 {
	fmt.Println("Mayor de edad")
} else {
	fmt.Println("Menor de edad")
}

// if con inicialización (la variable vive solo en el bloque)
if total := suma(3, 4); total > 5 {
	fmt.Println("Mayor que 5")
}

// switch: break implícito, sin fallthrough salvo explícito
switch dia := 3; dia {
case 1:
	fmt.Println("Lunes")
case 2:
	fmt.Println("Martes")
default:
	fmt.Println("Otro día")
}
// for clásico
for i := 0; i < 5; i++ {
	fmt.Println(i)
}

// for como while (no existe while en Go)
n := 0
for n < 5 {
	n++
}

// for infinito
for {
	break
}

// range: itera slices y maps
nums := []int{10, 20, 30}
for i, v := range nums {
	fmt.Println("índice", i, "valor", v)
}
for clave, valor := range map[string]int{"a": 1, "b": 2} {
	fmt.Println(clave, valor)
}

Recuerda: en Go solo existe for. Usa for clásico, for condición (como while) o for infinito. El switch no necesita break: cada caso sale solo salvo que escribas fallthrough.

Funciones, structs y métodos

Las funciones en Go se declaran con func, indicando tipos de parámetros y de retorno. Go admite múltiples valores de retorno (muy usado para devolver valores junto a errores), funciones variádicas y funciones que reciben funciones (callbacks).

// Declaración básica
func sumar(a int, b int) int {
	return a + b
}

// Tipos iguales consecutivos
func restar(a, b int) int {
	return a - b
}

// Múltiples retornos
func div(x, y int) (int, int) {
	return x / y, x % y
}

// Variádica: acepta N argumentos
func total(nums ...int) int {
	s := 0
	for _, n := range nums {
		s += n
	}
	return s
}

// Recibe una función (callback)
func aplicar(f func(int) int, v int) int {
	return f(v)
}
// Definir un struct
type Persona struct {
	Nombre string
	Edad   int
}

// Crear una instancia
p := Persona{Nombre: "Ana", Edad: 30}

// Método con receiver (receptor)
func (p Persona) Saludar() string {
	return "Hola, soy " + p.Nombre
}

// Receiver de puntero para modificar
func (p *Persona) CumplirAnios() {
	p.Edad++
}

fmt.Println(p.Saludar()) // Hola, soy Ana
p.CumplirAnios()
fmt.Println(p.Edad) // 31

Un método es una función con un receiver (receptor) que la vincula a un tipo. Usa receiver por valor para solo leer y receiver por puntero (*Persona) para modificar el struct.

Los callbacks (funciones que reciben funciones) son comunes en Go para ordenamiento, filtrado y manejo de eventos: sort.Slice(s, func(i, j int) bool { ... }).

Paquetes, goroutines y canales

Cada archivo .go pertenece a un paquete declarado con package en la primera línea. Con import usas paquetes de la biblioteca estándar o de terceros, y puedes crear tus propios paquetes reutilizables en tu proyecto.

package main

import "fmt"

// Goroutine: se lanza con la palabra go
func saludar(msg string) {
	fmt.Println(msg)
}

func main() {
	go saludar("Hola desde una goroutine")
}

// Canal: comunicación entre goroutines
ch := make(chan int)

// Hilo de goroutine espera las últimas modificaciones
go func() {
	ch <- 42 // envía al canal
}()

v := <-ch // recibe del canal
fmt.Println(v)
ElementoQué hace
packageAgrupa el código; package main genera un ejecutable
importTrae paquetes de la stdlib o de terceros
go funcion()Lanza una goroutine: ejecución ligera y concurrente
chanCanal para comunicar goroutines de forma segura
ch <- vEnvía el valor v por el canal
v := <-chRecibe un valor del canal
selectEspera varias operaciones de canal a la vez
// select: atiende la primera operación lista
select {
case msg := <-ch:
	fmt.Println("recibido:", msg)
case <-time.After(1 * time.Second):
	fmt.Println("timeout")
}

No digas «hilos» en Go: di goroutines. Son miles de veces más ligeras que un hilo del sistema y se gestionan automáticamente.

Los canales bloquean: enviar espera hasta que alguien reciba, y recibir espera hasta que alguien envíe. Usa select o canales con buffer para evitar bloqueos eternos.
