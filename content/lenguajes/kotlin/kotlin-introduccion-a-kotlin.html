¿Qué es Kotlin?

  • Lenguaje oficial de Android junto a Java
  • 100% interoperable con Java
  • Conciso: menos código que Java para lo mismo
  • Null-safety integrada en el sistema de tipos

Primer programa

# Con IntelliJ IDEA o compilador kotlinc
kotlinc hola.kt -include-runtime -d hola.jar
java -jar hola.jar
