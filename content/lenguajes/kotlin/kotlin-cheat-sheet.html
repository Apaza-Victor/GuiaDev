¿Qué es Kotlin?

Kotlin es un lenguaje de programación moderno, estáticamente tipado y multiparadigma creado por JetBrains (primera versión en 2011, estable en 2016). Compila al mismo bytecode que Java, se ejecuta sobre la JVM y es el lenguaje oficial para Android, además de ser plenamente interoperable con Java.

fun main() {
    println("Hola, mundo")
}
VentajaQué aporta
Nulidad seguraDistingue tipos que pueden ser null de los que no, evitando NullPointerException
ExpresivoMuchas construcciones devuelven valores (if, when, try) y menos código para lo mismo
ConcisoSin punto y coma, sin boilerplate ni getters/setters manuales
Interoperable con JavaUsa librerías Java directamente y se mezcla con código Java en el mismo proyecto
CorrutinasAsincronía ligera y legible sin hilos pesados

Kotlin no tiene new para crear objetos: se usa directamente el nombre de la clase. También permite funciones top-level (fuera de clases), cosa que Java no permite.

Sintaxis básica

Un programa Kotlin empieza con la función main(). La variable val es inmutable (no puede reasignarse) y var es mutable. Kotlin no requiere punto y coma al final de cada línea.

fun main() {
    val nombre = "Ana"         // inmutable (solo lectura)
    var edad = 25               // mutable
    edad = 26                   // ok, es var

    println("Hola, $nombre")    // imprime en consola
    // Comentario de una línea
    /* Comentario
       de varias líneas */
    /// Comentario de documentación (KDoc)
}

Kotlin usa inferencia de tipos: no hace falta indicar el tipo si se deduce del valor. Si quieres, puedes anotarlo explícitamente con dos puntos: val x: Int = 5.

val x: Int = 5    // anotación explícita del tipo
val frase = "Hola" // el tipo String se infiere

Como regla general, usa val siempre que puedas. La inmutabilidad hace el código más predecible y a Kotlin le gusta fomentarla.

Kotlin no tiene operador ternario (cond ? a : b) como otros lenguajes; en su lugar se usa if como expresión que devuelve un valor.

val mayor = if (edad >= 18) "Adulto" else "Menor"

val nombre = "Ana"
val saludo = "Hola, $nombre"             // interpolación con $
val suma = "Total: ${5 + 3}"             // expresiones entre ${}

La interpolación de cadenas con $ o ${expresión} evita la concatenación manual y hace el código mucho más legible.

Nulidad y tipos nullable

La gran diferencia con Java: un tipo String no puede guardar null. Si necesitas que pueda ser nulo, se declara con ? como String?.

val a: String = null   // ERROR: no compila, null no está permitido
val b: String? = null  // ok: tipo nullable

Operador de llamada segura ?.

Accede a una propiedad o método solo si el valor no es null; si lo es, devuelve null sin lanzar error.

val longitud = texto?.length   // Int? ; null si texto es null

Operador de fuerza !!

Fuerza al valor como no-nulo; si realmente es null, lanza una NullPointerException.

val lon = texto!!.length   // peta si texto es null
val nombre: String? = null

Operador elvis ?:

Proporciona un valor por defecto cuando el lado izquierdo es null.

val nombreFinal = nombre ?: "Sin nombre"

Evita el operador !! en la mayoría de casos: es una "bala" que lanza NullPointerException si el valor resulta ser null. Es preferible ?. y ?: para manejar la nulidad de forma segura.

Estructuras de control

if / else

En Kotlin, if es una expresión: puede devolver un valor.

val max = if (a > b) a else b   // if que devuelve valor

when (equivalente a switch)

Sustituye al switch de Java. No necesita break y permite rangos y condiciones arbitrarias.

when (nota) {
    in 9..10 -> println("Sobresaliente")   // rango
    in 7..8 -> println("Notable")
    in 5..6 -> println("Aprobado")
    else -> println("Suspenso")
}

for

for (i in 1..5) println(i)          // rango: 1,2,3,4,5
for (i in 5 downTo 1) println(i)    // descendente
for (i in 1..10 step 2) println(i)  // de 2 en 2
for (letra in "Hola") println(letra) // sobre caracteres

while y do-while

var n = 0
while (n < 5) { println(n); n++ }

var m = 0
do { println(m); m++ } while (m < 5) // ejecuta al menos una vez
for (i in 1..10) {
    if (i == 3) continue   // salta a la siguiente iteración
    if (i == 9) break      // sale del bucle
    println(i)
}

when también funciona como expresión y puede evaluar condiciones booleanas en cada rama, además de rangos con in.

Funciones, clases y data classes

Funciones

fun sumar(a: Int, b: Int): Int {
    return a + b
}

// Cuerpo de expresión (sin return explícito)
fun restar(a: Int, b: Int): Int = a - b

Parámetros por defecto y con nombre

fun saludar(nombre: String, saludo: String = "Hola") = "$saludo, $nombre"

saludar("Ana")                       // usa el valor por defecto
saludar(nombre = "Ana", saludo = "Hey") // argumentos con nombre

Clases

class Persona(val nombre: String, var edad: Int) {
    fun cumplirAnios() {
        edad++
    }
}

val p = Persona("Ana", 30)   // sin "new"
p.cumplirAnios()
println(p.nombre)            // accede a la propiedad

Herencia

open class Animal(val nombre: String)
class Perro(nombre: String) : Animal(nombre)   // hereda con ": Base()"

Data class

data class Usuario(val id: Int, val nombre: String)

// Genera automáticamente equals, hashCode, toString y copy
val u = Usuario(1, "Ana")
println(u)   // Usuario(id=1, nombre=Ana)

Las data classes están pensadas para modelos de datos: con una línea obtienes equals, hashCode, toString y copy sin escribir nada.
