¿Qué es SQL?

SQL son las siglas de Structured Query Language, que en español se traduce como Lenguaje de Consulta Estructurada. Es un lenguaje declarativo para trabajar con bases de datos relacionales: tú describes qué datos quieres y el motor se encarga de cómo obtenerlos.

InglésEspañol
StructuredEstructurada
QueryConsulta
LanguageLenguaje

Así, SQL = Structured Query Language = Lenguaje de Consulta Estructurada. Una consulta es simplemente una pregunta que le haces a la base de datos: por ejemplo "¿qué empleados ganan más de 30000?".

SQL no distingue mayúsculas de minúsculas en las palabras clave (SELECT = select). Por convención se escriben en mayúsculas para que el código sea más legible.

Sublenguajes de SQL (DDL, DML, DCL, TCL)

SQL se divide en varios sublenguajes, cada uno encargado de una tarea distinta. Sus nombres también están en inglés, así que aquí tienes sus traducciones:

SiglasInglésEspañolComandos
DDLData Definition LanguageLenguaje de Definición de DatosCREATE, ALTER, DROP, TRUNCATE
DMLData Manipulation LanguageLenguaje de Manipulación de DatosSELECT, INSERT, UPDATE, DELETE
DCLData Control LanguageLenguaje de Control de DatosGRANT, REVOKE
TCLTransaction Control LanguageLenguaje de Control de TransaccionesCOMMIT, ROLLBACK, SAVEPOINT

El DDL define la estructura (crear o borrar tablas), el DML manipula los datos dentro de esas tablas, el DCL controla los permisos y el TCL gestiona las transacciones.

Consultas SELECT

SELECT es el comando más usado en SQL: sirve para recuperar datos de una o varias tablas. Su estructura básica es:

SELECT columna1, columna2
FROM nombre_tabla
WHERE condicion
ORDER BY columna;

Cada cláusula tiene una función concreta dentro de la consulta:

CláusulaQué haceEjemplo
SELECTElige qué columnas se muestran.SELECT nombre, salario
FROMIndica de qué tabla se leen los datos.FROM empleados
WHEREFiltra filas según una condición.WHERE salario > 30000
ORDER BYOrdena los resultados.ORDER BY salario DESC
LIMIT / FETCHLimita la cantidad de filas devueltas.LIMIT 10
GROUP BYAgrupa filas por una columna.GROUP BY departamento
HAVINGFiltra grupos (tras GROUP BY).HAVING COUNT(*) > 5
JOINCombina datos de varias tablas.JOIN departamentos d

Para mostrar todas las columnas se usa el comodín SELECT *:

SELECT * FROM empleados;

SELECT nombre, salario * 12 AS salario_anual
FROM empleados
WHERE salario > 30000
ORDER BY salario DESC;

DDL: crear y modificar tablas

El DDL (Lenguaje de Definición de Datos) crea y modifica la estructura de la base de datos. Crear una tabla con una clave primaria y restricciones:

CREATE TABLE empleados (
    id          INT PRIMARY KEY,
    nombre      VARCHAR(100) NOT NULL,
    salario     DECIMAL(10,2) NOT NULL,
    departamento_id INT,
    email       VARCHAR(150) UNIQUE
);

Modificar la estructura con ALTER TABLE:

ALTER TABLE empleados ADD COLUMN telefono VARCHAR(20);

ALTER TABLE empleados MODIFY COLUMN salario DECIMAL(12,2);

ALTER TABLE empleados DROP COLUMN telefono;

Eliminar tablas con DROP TABLE y vaciarlas con TRUNCATE TABLE:

TRUNCATE TABLE empleados;   -- vacía los datos, conserva la estructura
DROP TABLE empleados;       -- borra la tabla por completo
ComandoQué hace
CREATE TABLECrea una nueva tabla con sus columnas y restricciones.
ALTER TABLEAñade, modifica o elimina columnas de una tabla existente.
DROP TABLEElimina la tabla completa con todos sus datos.
TRUNCATE TABLEElimina todas las filas pero conserva la estructura.

Restricciones más comunes:

RestricciónQué significa
PRIMARY KEYIdentifica de forma única cada fila (no admite NULL ni duplicados).
FOREIGN KEYRelaciona una columna con la clave primaria de otra tabla.
UNIQUENo permite valores duplicados en esa columna.
NOT NULLObliga a que la columna siempre tenga un valor.
AUTO_INCREMENT / IDENTITYGenera un valor numérico automático y creciente (el nombre varía según el motor).

DML: INSERT, UPDATE y DELETE

El DML (Lenguaje de Manipulación de Datos) trabaja con los datos almacenados. Insertar registros con INSERT:

INSERT INTO empleados (id, nombre, salario)
VALUES (1, 'Ana García', 35000.00);

-- Insertar varios registros en una sola sentencia
INSERT INTO empleados (id, nombre, salario) VALUES
(2, 'Luis Pérez', 40000.00),
(3, 'Marta Ruiz', 32000.00);

Actualizar registros con UPDATE (¡siempre con WHERE!):

UPDATE empleados
SET salario = 38000.00
WHERE id = 1;

Eliminar registros con DELETE:

DELETE FROM empleados
WHERE id = 3;

Peligro: un DELETE FROM empleados; sin WHERE borra todas las filas de la tabla. Siempre revisa la condición y, si es posible, empieza con un SELECT que devuelva las filas que eliminarás.

TRUNCATE borra todo más rápido que DELETE y reinicia los contadores, pero no permite condiciones ni recuperar filas con ROLLBACK en muchos motores. Además, DELETE borra fila a fila (dispara eventos, si los hay) y TRUNCATE no.

Filtros, orden y agrupación

WHERE filtra filas antes de agrupar. Operadores más usados:

OperadorQué haceEjemplo
=Igual aWHERE salario = 35000
> / <Mayor / menor queWHERE salario > 30000
>= / <=Mayor o igual / menor o igualWHERE salario <= 40000
<> (o !=)Distinto deWHERE cargo <> 'Ventas'
LIKEComparación con comodines % y _WHERE nombre LIKE 'Ana%'
INPertenece a una lista de valoresWHERE id IN (1, 2, 3)
BETWEENDentro de un rango (inclusive)WHERE salario BETWEEN 30000 AND 40000
IS NULLEl valor es nulo (no usar = NULL)WHERE email IS NULL
AND / ORCombina condicionesWHERE salario > 30000 AND cargo = 'Ventas'

Ordenar con ORDER BY y limitar con LIMIT:

SELECT nombre, salario
FROM empleados
ORDER BY salario DESC   -- DESC descendente, ASC ascendente
LIMIT 5;

Agrupar con GROUP BY y filtrar grupos con HAVING:

SELECT departamento_id, COUNT(*) AS total
FROM empleados
GROUP BY departamento_id
HAVING COUNT(*) > 5;

WHERE filtra filas antes de agrupar; HAVING filtra grupos ya agregados. No puedes usar funciones de agregado como COUNT() dentro de WHERE.

JOIN y subconsultas

Los JOIN combinan datos de dos o más tablas usando una columna común, normalmente la clave primaria de una tabla y la clave foránea de otra. Tipos de JOIN:

Tipo de JOINQué devuelve
INNER JOINSolo las filas que coinciden en ambas tablas.
LEFT JOINTodas las filas de la izquierda y las coincidentes de la derecha (NULL si no hay).
RIGHT JOINTodas las filas de la derecha y las coincidentes de la izquierda (NULL si no hay).
FULL OUTER JOINTodas las filas de ambas tablas, coincidan o no.

Ejemplo de INNER JOIN entre dos tablas:

SELECT e.nombre, d.nombre AS departamento
FROM empleados e
INNER JOIN departamentos d ON e.departamento_id = d.id;

Una subconsulta es un SELECT anidado dentro de otra consulta. Ejemplo: "empleados que ganan más que el salario promedio":

SELECT nombre, salario
FROM empleados
WHERE salario > (SELECT AVG(salario) FROM empleados);

La clave foránea crea la relación: en el ejemplo, empleados.departamento_id hace referencia a departamentos.id, uniéndose por esa columna en el ON del JOIN.

Funciones de agregado y funciones de texto/fecha

Funciones de agregado

Toman un conjunto de filas y devuelven un único valor. Se usan con GROUP BY:

FunciónQué haceEjemplo
COUNTCuenta filas o valoresCOUNT(*)
SUMSuma los valores de una columnaSUM(salario)
AVGPromedio de los valoresAVG(salario)
MINValor mínimoMIN(salario)
MAXValor máximoMAX(salario)
SELECT departamento_id, COUNT(*) AS total, AVG(salario) AS promedio
FROM empleados
GROUP BY departamento_id;

Funciones de fecha

FunciónQué haceEjemplo
NOW / GETDATE / SYSDATEFecha y hora actuales del sistemaNOW()

SELECT nombre, UPPER(cargo) AS cargo_mayus
FROM empleados

Las funciones varían un poco entre motores: MySQL usa NOW() y DATE_FORMAT, Oracle usa SYSDATE y TO_CHAR, y SQL Server usa GETDATE(). Consulta la documentación de tu motor.

Conceptos importantes

ConceptoQué significa
Base de datosConjunto organizado de datos almacenados y gestionados por un motor.
TablaColección de datos organizados en filas y columnas.
Fila / registroCada entrada individual de una tabla; un conjunto de valores relacionado.
Columna / campoCada atributo o propiedad de los datos (por ejemplo, nombre).
Clave primaria (PK)Columna o conjunto de columnas que identifica de forma única cada fila.
Clave foránea (FK)Columna que referencia la clave primaria de otra tabla para crear relaciones.
ÍndiceEstructura que acelera las búsquedas sobre una columna a costa de más espacio.
VistaConsulta guardada que se usa como si fuera una tabla virtual.
Procedimiento almacenadoConjunto de sentencias SQL guardadas en la base y ejecutables por nombre.
TransacciónConjunto de operaciones que se ejecutan como una unidad (todo o nada).
Commit / RollbackCOMMIT guarda los cambios; ROLLBACK los deshace.
NULLAusencia de valor (no es 0 ni cadena vacía; es "desconocido").
ConsultaSentencia (generalmente SELECT) que pide información a la base de datos.
EsquemaEstructura lógica que agrupa tablas y objetos de la base.
Motor de base de datosSoftware que almacena, gestiona y sirve los datos (MySQL, Oracle, SQL Server...).
RelaciónConexión entre dos tablas establecida mediante claves (1 a 1, 1 a N, N a N).
