Condicionales y bucles modernos

La estructura del control de flujo en C++ es la clásica de la familia C, pero el C++ moderno añade azúcares que reducen errores y mejoran legibilidad: inicializadores dentro de if/switch (C++17) y bucles range-based.

if con inicializador: acotar el alcance

// La variable 'it' SOLO existe dentro del if/else
if (auto it = mapa.find(clave); it != mapa.end()) {
    std::cout << "Encontrado: " << it->second << "\n";
} else {
    // aquí 'it' sigue visible: útil para mensajes de error
    std::cout << clave << " no está\n";
}
// ...fuera, 'it' ya no existe: imposible usarlo por accidente

Este patrón elimina una categoría entera de bugs: variables "temporales" que se filtran a scopes amplios y se reutilizan mal. Úsalo siempre que una condición dependa de un cálculo previo.

switch: saltos discretos

switch (codigo) {
    case 200:
        std::cout << "OK\n";
        break;                       // sin break: CAE al siguiente caso
    case 301:
    case 302:                        // casos apilados = OR
        std::cout << "Redirección\n";
        break;
    default:
        std::cout << "Otro código\n";
}

// switch con init + [[fallthrough]] explícito cuando SÍ quieres caer:
switch (auto d = digito(); d) {
    case 0:
    case 1:
        [[fallthrough]];             // silencia el warning honestamente
    case 2:
        std::cout << "dígito bajo\n";
        break;
}

Los tres bucles

BucleCuándo usarloEjemplo
range-based forRecorrer TODO un contenedor (90% de los casos)for (const auto& x : v)
for clásicoNecesitas índice, salto o recorrido parcialfor (size_t i = 0; i < n; i += 2)
while / do-whileCondición dinámica, iteraciones desconocidasLeer entrada hasta EOF
 
std::vector<int> datos{10, 20, 30, 40};

// Range-based: LA opción por defecto
for (const auto& x : datos) {   // const auto&: sin copias, sin mutar
    std::cout << x << ' ';
}

// Con índice cuando lo necesitas
for (size_t i = 0; i < datos.size(); ++i) {
    std::cout << i << ": " << datos[i] << '\n';
}

// Estructuradas (C++17): pares y mapas elegantes
std::map<std::string, int> edades{{"Ana", 30}, {"Luis", 25}};
for (const auto& [nombre, edad] : edades) {
    std::cout << nombre << " → " << edad << '\n';
}

En range-based for usa const auto& para tipos grandes (strings, vectores) — auto a secas COPIA cada elemento. Reserva auto& (sin const) solo cuando vayas a modificar.

Funciones, sobrecarga y referencias

Sobrecarga y argumentos por defecto

Varias funciones pueden compartir nombre si difieren en parámetros — el compilador elige según los tipos exactos:

int    maximo(int a, int b)             { return a > b ? a : b; }
double maximo(double a, double b)       { return a > b ? a : b; }
int    maximo(const std::vector<int>& v) {
    return *std::max_element(v.begin(), v.end());
}

// Argumentos por defecto: declarados UNA vez (en el header)
void conectar(std::string host, int puerto = 8080, bool ssl = true);

conectar("api.ejemplo.com");              // 8080, ssl
conectar("localhost", 3000);              // ssl=true
// OJO: no puedes omitir 'puerto' y dar solo 'ssl' — son posicionales

Paso por valor vs referencia: LA decisión diaria

FirmaCopiaMuta originalAcepta literales/temporalesUso ideal
f(Tipo x)Sí (costoso si grande)NoSíTipos pequeños (int, double), cuando necesitas copia propia
f(Tipo& x)NoSíNoOut-parameter: función que devuelve por ahí
f(const Tipo& x)NoNoSíLectura de objetos grandes — el estándar de facto
f(Tipo* x)No (copia puntero)Vía *Sí (&var)Puede ser nullptr: opcionalidad estilo C
 
void duplicar(int& n) { n *= 2; }          // muta al llamador

void reporte(const std::vector<int>& datos) {  // sin copia, sin riesgo
    for (int x : datos) std::cout << x << ' ';
}

int valor = 21;
duplicar(valor);
std::cout << valor << "\n";  // 42

Regla mnemotécnica: "const ref para leer, ref pelada para escribir, valor solo para baratos". Si firmas void f(std::string s) para leer un string, pagas una copia completa en cada llamada sin razón.

Retorno múltiple moderno: structured bindings

struct Resultado {
    bool ok;
    std::string mensaje;
};

Resultado procesar(int codigo) {
    if (codigo % 2 == 0) return {true, "par procesado"};
    return {false, "impar rechazado"};
}

// Desempaquetar sin conocer el struct interno:
auto [exito, texto] = procesar(42);   // C++17
std::cout << texto << '\n';           // "par procesado"

// std::pair/tuple también funcionan:
auto [minimo, maximo] = std::minmax({4, 8, 15, 16, 23});

Lambdas: funciones anónimas en línea

Las lambdas capturan variables del entorno y viven donde se usan — fundamentales junto a los algoritmos de la STL:

auto cuadrado = [](int x) { return x * x; };
std::cout << cuadrado(7) << "\n";     // 49

int factor = 3;
auto triplicar = [factor](int x) { return x * factor; };  // captura POR COPIA
auto incrementarY = [&y](int x) { y += x; };              // captura POR REFERENCIA

std::vector<int> v{5, 2, 9};
std::sort(v.begin(), v.end(), [](int a, int b) { return a > b; }); // descendente

Capturar por referencia [&] una variable local y luego invocar la lambda FUERA de su scope es use-after-free. Para callbacks que sobreviven al scope, captura por copia [=] o lista explícita [factor].

Los compiladores modernos inlinean funciones pequeñas automáticamente: dividir código en funciones descriptivas NO cuesta rendimiento. La legibilidad sale gratis.

Ejercicios prácticos

  1. Clasificador HTTP: función que reciba un código int y devuelva su clase (2xx éxito, 3xx redirección…) usando switch con rangos apilados; pruébala con structured bindings retornando (clase, descripción).
  2. Estadísticas sin copias: escribe stats(const std::vector<double>&) que retorne struct con min, max, promedio; verifica con sizeof que no hay copias ocultas (compila con -Wall).
  3. FizzBuzz funcional: resuélvelo tres veces: for clásico, range-based y con std::transform + lambda; compara legibilidad en comentarios.
  4. Contador de palabras: dado un texto, construye map<string,int> de frecuencias recorriéndolo con ranged-for estructurado e imprime ordenado.
  5. Cazador de fallthrough: escribe un switch SIN breaks que clasifique notas (1-5) y observa la salida errónea; corrígelo y añade [[fallthrough]] documentando el único lugar donde sí aplica.
