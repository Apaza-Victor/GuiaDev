Palabras reservadas

C++ hereda todas las palabras clave de C y añade otras propias de la POO (orientación a objetos) y las plantillas (templates). Estas palabras no pueden usarse como nombres de variables, funciones o clases.

C++ es una extensión de C: mantiene su sintaxis de bajo nivel y sus palabras clave, pero añade POO (class, public, virtual…), plantillas (template, typename) y sobrecarga de funciones y operadores, entre otras herramientas.

Sintaxis básica

El punto y coma ; termina las sentencias. La directiva #include inserta el contenido de una cabecera, y la función main es el punto de entrada de todo programa.

#include <iostream>    // cabecera para entrada/salida
using namespace std;    // evita escribir std:: delante

int main() {            // función principal
    cout << "Hola mundo" << endl;  // salida en consola

    int edad;           // declaración de variable tipada
    cout << "Edad: ";
    cin >> edad;        // entrada desde teclado

    return 0;           // 0 = éxito
}

Estructuras de control

if / else

int n = 10;
if (n > 0) {
    cout << "Positivo" << endl;
} else if (n < 0) {
    cout << "Negativo" << endl;
} else {
    cout << "Cero" << endl;
}

switch / case

int opcion = 2;
switch (opcion) {
    case 1:
        cout << "Uno" << endl;
        break;
    case 2:
        cout << "Dos" << endl;
        break;
    default:
        cout << "Otro" << endl;
        break;
}

for

for (int i = 0; i < 5; i++) {
    cout << i << " ";
}

while

int i = 0;
while (i < 5) {
    cout << i << " ";
    i++;
}

do-while (se ejecuta al menos una vez)

int i = 0;
do {
    cout << i << " ";
    i++;
} while (i < 3);

break y continue

for (int i = 0; i < 10; i++) {
    if (i == 3) continue;   // salta el 3
    if (i == 7) break;      // termina el bucle en el 7
    cout << i << " ";
}

break sale por completo del bucle o switch; continue salta a la siguiente iteración sin salir.

Funciones, clases y objetos

Función con tipo de retorno y parámetros

int sumar(int a, int b) {
    return a + b;
}

void saludar(string nombre) {
    cout << "Hola, " << nombre << endl;
}

int main() {
    int r = sumar(3, 4);   // r = 7
    saludar("Ana");
    return 0;
}

Clase con atributos y métodos

class Persona {
private:
    string nombre;
    int edad;

public:
    // Constructor
    Persona(string n, int e) : nombre(n), edad(e) {}

    // Getter
    string getNombre() const { return nombre; }

    // Setter
    void setNombre(string n) { nombre = n; }

    void mostrar() const {
        cout << nombre << ", " << edad << " años" << endl;
    }
};

Crear (instanciar) objetos

// Por valor (en el stack)
Persona p1("Ana", 25);
p1.mostrar();

// Con new (memoria dinámica, en el heap)
Persona *p2 = new Persona("Luis", 30);
p2->mostrar();          // acceso con ->
delete p2;              // liberar memoria

Un método marcado const promete no modificar el objeto, lo que permite llamarlo sobre objetos constantes. Las funciones y operadores pueden sobrecargarse: definir varias versiones con distinto número/tipo de parámetros.

Biblioteca STL y punteros

La STL (Standard Template Library) aporta contenedores genéricos y algoritmos listos para usar. Los más habituales:

ContenedorMétodo/usoQué hace
vector<T>push_back(x)Agrega un elemento al final.
vector<T>size()Número de elementos.
vector<T>v[i]Acceso por índice (sin chequeo).
list<T>push_front(x), push_back(x)Lista doblemente enlazada.
map<K,V>m[clave]Diccionario ordenado clave→valor.
stringlength()Longitud de la cadena.
stringsubstr(pos, n)Subcadena desde pos de tamaño n.

Usando un vector

#include <vector>
std::vector<int> v;
v.push_back(10);
v.push_back(20);
v.push_back(30);

std::cout << "Tamaño: " << v.size() << endl;  // 3
std::cout << "Primero: " << v[0] << endl;    // 10

for (int x : v) std::cout << x << " ";        // recorrido

Usando un string

#include <string>
std::string s = "Hola mundo";
std::cout << s.length() << endl;            // 10
std::cout << s.substr(0, 4) << endl;         // "Hola"
std::string t = s + "!";                    // concatenación

Punteros y referencias

int valor = 42;
int *ptr = &valor;      // * declara puntero; & obtiene la dirección
std::cout << *ptr;       // desreferencia: 42

int *dinamico = new int(7);   // reserva en el heap
std::cout << *dinamico;
delete dinamico;              // libera memoria

// Referencia: alias de una variable (no es puntero)
int &ref = valor;
ref = 50;                     // cambia 'valor' a 50

Toda memoria reservada con new debe liberarse con delete (y new[] con delete[]). En C++ moderno se prefiere std::unique_ptr / std::shared_ptr para gestionar la memoria automáticamente.

Conceptos importantes

ConceptoQué significa
CompiladorPrograma que traduce código fuente a código máquina.
EjecutableArchivo binario resultante que el sistema puede lanzar.
FuenteCódigo legible por humanos (archivos .cpp, .h).
BibliotecaColección de código reutilizable (ej. la STL).
VariableZona de memoria con nombre que guarda un valor.
Tipo de datoRegla que define qué valores y operaciones admite una variable.
FunciónBloque de código reutilizable con entrada y salida.
ParámetroVariable declarada en la definición de la función.
ArgumentoValor concreto que se pasa al llamar a la función.
RetornoValor que la función devuelve al llamador (return).
ClasePlantilla que define atributos y métodos de un tipo.
ObjetoInstancia concreta de una clase.
InstanciaUn objeto particular creado a partir de una clase.
AtributoDato (miembro) que guarda el estado de un objeto.
MétodoFunción miembro de una clase.
ConstructorMétodo especial que inicializa el objeto al crearlo.
HerenciaCrear una clase a partir de otra reutilizando su comportamiento.
PolimorfismoTratar objetos de distintas clases a través de una interfaz común.
EncapsulamientoOcultar los detalles internos y exponer solo la interfaz.
NamespaceMecanismo para agrupar nombres y evitar colisiones.
STLStandard Template Library: contenedores, iteradores y algoritmos.
ContenedorEstructura de datos que almacena colecciones (vector, map…).
IteradorObjeto que permite recorrer los elementos de un contenedor.
PunteroVariable que guarda una dirección de memoria.
ReferenciaAlias de una variable (no puede ser nula ni reasignarse).
Memoria dinámicaMemoria del heap gestionada en tiempo de ejecución.
new / deleteOperadores para reservar y liberar memoria dinámica.
SobrecargaDefinir varias funciones/operadores con el mismo nombre y distintos parámetros.

Con estos conceptos dominas el vocabulario esencial de C++: del fuente al ejecutable, de la clase al objeto, y de los contenedores a la memoria dinámica.
