Contenedores: elegir el correcto

La STL (Standard Template Library) ofrece contenedores genéricos listos para producción. La pregunta diaria no es "¿cómo hago una lista?", sino "¿cuál contenedor encaja en mi patrón de acceso?" — porque cada uno tiene complejidades radicalmente distintas.

Secuenciales: orden por posición

ContenedorMemoriaAcceso iInsertar/eliminar al finalEn medio
vector<T>ContiguaO(1) ⚡O(1) amortizadoO(n)
array<T,N>Contigua (stack)O(1) ⚡N/A (tamaño fijo)N/A
deque<T>BloquesO(1)O(1) ambos extremosO(n)
list<T>Nodos dispersosO(n) 🐌O(1)O(1)* (con iterador)

La respuesta por defecto del C++ moderno es std::vector, el 90% de las veces. La memoria contigua hace que el caché del procesador trabaje a tu favor: un vector de 10.000 ints suele RECORRERSE más rápido que una list de 100, pese al O(n) teórico. Empieza con vector; migra solo con evidencia de perfilado.

#include <vector>
#include <array>

std::vector<int> v{3, 1, 4};
v.push_back(1);              // {3,1,4,1} — crece sola
v[0] = 99;                   // sin chequeo
v.at(0);                     // lanza si fuera de rango

std::cout << v.size() << ' ' << v.capacity();  // tamaño vs espacio reservado
v.reserve(1000);             // evita realojos si sabes cuánto crecerá
v.erase(v.begin() + 2);      // elimina el tercero — O(n), desplaza
for (const auto& x : v) std::cout << x << ' ';

std::array<double, 3> punto{1.0, 2.5, 3.7};   // stack, tamaño FIJO, sin heap

Asociativos: orden por clave

ContenedorEstructura internaBúsquedaMantiene orden

#include <map>
#include <unordered_map>

// map: claves SIEMPRE ordenadas — ideal para reportes
std::map<std::string, int> inventario{{"teclado", 12}, {"mouse", 30}};
inventario["monitor"] += 5;          // inserta o actualiza
inventario["webcam"]++;              // ¡crea con 0 y luego suma!

if (auto it = inventario.find("mouse"); it != inventario.end()) {
    std::cout << it->second << " unidades\n";
}
for (const auto& [producto, cantidad] : inventario) {
    std::cout << producto << ": " << cantidad << '\n';  // alfabético ✅
}

// unordered_map: máxima velocidad cuando el orden no importa
std::unordered_map<int, std::string> codigosHTTP;
codigosHTTP[200] = "OK";
codigosHTTP[404] = "Not Found";      // búsqueda O(1) promedio

mapa[clave] INSERTA la clave con valor por defecto si no existía — usarlo solo para CONSULTAR infla silenciosamente tu mapa. Para consultar sin efectos usa find() o .contains(clave) (C++20).

Iteradores y algoritmos

Iteradores: el pegamento universal

Todo contenedor expone iteradores — objetos tipo "puntero generalizado" que recorren elementos. Los algoritmos operan sobre RANGOS [primero, último) de iteradores: por eso funcionan igual sobre vector, deque, list o arrays crudos:

std::vector<int> v{5, 2, 8};

auto it = v.begin();     // apunta al primero
*it = 10;                // escribir vía iterador
++it;                    // avanzar
it == v.end();           // end() = PASADO el último (sentinela)

// Rango clásico de algoritmo: [begin, end)
std::sort(v.begin(), v.end());

Los algoritmos que usarás cada semana

#include <algorithm>
#include <numeric>

std::vector<int> datos{8, 3, 15, 6, 9};

// Buscar
bool hayPar = std::any_of(datos.begin(), datos.end(),
                          [](int x) { return x % 2 == 0; });

auto minIt = std::min_element(datos.begin(), datos.end());   // → 3
auto pos   = std::find(datos.begin(), datos.end(), 15);
if (pos != datos.end()) std::cout << "15 en índice " << (pos - datos.begin());

// Contar con condición
int grandes = std::count_if(datos.begin(), datos.end(),
                            [](int x) { return x > 7; });     // 3

// Transformar IN-PLACE con lambda
std::transform(datos.begin(), datos.end(), datos.begin(),
               [](int x) { return x * 2; });
// {16, 6, 30, 12, 18}

// Reducir a un valor
long total = std::accumulate(datos.begin(), datos.end(), 0L);

// Ordenar con criterio propio
struct Empleado { std::string nombre; double sueldo; };
std::vector<Empleado> plantilla{{"Ana", 3000}, {"Luis", 2500}};
std::sort(plantilla.begin(), plantilla.end(),
          [](const Empleado& a, const Empleado& b) {
              return a.sueldo > b.sueldo;       // mayor sueldo primero
          });

// Eliminar-compactar idiomático (erase-remove):
datos.erase(std::remove_if(datos.begin(), datos.end(),
                           [](int x) { return x % 4 == 0; }),
            datos.end());

C++20 añade los mismos algoritmos como versión sintáctica directa: std::ranges::sort(v), std::ranges::count_if(v, pred) — sin begin/end repetidos. Si tu compilador soporta C++20, úsalos.

Buenas prácticas

PrácticaRazón concreta
vector por defecto; alternativas solo con perfiladoLocalidad de caché gana casi siempre en hardware real
reserve() antes de push_back masivoEvita N realojos+copias durante el crecimiento
find()/contains() en vez de mapa[] para consultas[] inserta silenciosamente claves inexistentes
Algoritmos estándar antes que bucles manualesProbados, expresivos, paralelizables (execución policy C++17)
Lambdas pequeñas junto al algoritmoEl criterio vive donde se lee: cero contexto mental extra
erase-remove (o std::erase_if, C++20) para filtrarEliminar dentro de ranged-for invalida iteradores = UB
structured bindings al recorrer mapas[clave, valor] es auto-documentado

NUNCA agregues o elimines elementos de un contenedor mientras lo recorres con ranged-for: los iteradores quedan invalidados y el comportamiento es indefinido. Filtra con erase-if ANTES o DESPUÉS del recorrido.

Ejercicios prácticos

  1. Inventario interactivo: map<string,int> de productos; menú en bucle para agregar/vender/listar ordenado; usa structured bindings y contains().
  2. Análisis de texto: dado un párrafo, cuenta frecuencias con unordered_map, muestra top-5 con partial_sort y filtra palabras cortas con erase_if.
  3. Duelo vector vs list: benchmark simple (chrono) de inserción al final y recorrido completo de 100k elementos; documenta resultados reales en comentario.
  4. Top-K eficiente: priority_queue que mantenga los 3 números mayores de un stream infinito de enteros.
  5. Pipeline de empleados: vector<Empleado> → sort por sueldo → count_if sobre umbral → accumulate de nómina total → transform aplicando aumento del 5% — todo con algoritmos STL, sin un solo for manual.
