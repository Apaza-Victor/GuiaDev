Punteros básicos

int x = 10;
int* p = &x;        // p guarda la dirección de x

*p = 20;            // modifica x indirectamente
std::cout << x;     // 20

int arr[3] = {1, 2, 3};
int* q = arr;       // apunta al primer elemento
q++;                // avanza un elemento

Dinámica y smart pointers

#include <memory>

// Manual (evitar en código moderno)
int* viejo = new int(5);
delete viejo;

// Smart pointers (preferir)
auto unico  = std::make_unique<int>(42);        // dueño único
auto compartido = std::make_shared<int>(42);     // conteo de referencias
Consejo: Regla moderna: usa unique_ptr por defecto y shared_ptr solo si realmente compartes propiedad. Nunca uses new/delete crudos.
