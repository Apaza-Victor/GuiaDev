RAII

RAII (Resource Acquisition Is Initialization): adquiere recursos en el constructor y los libera en el destructor. Así, archivos, memoria y locks se limpian solos incluso con excepciones.

#include <fstream>

void leer() {
    std::ifstream file("datos.txt");   // abre
    // ... usar file ...
}                                      // se cierra automáticamente

Compilación y herramientas

g++ -std=c++17 -Wall -Wextra -O2 main.cpp -o app

# Herramientas recomendadas
# clang-tidy  -> análisis estático
# sanitizers  -> -fsanitize=address,undefined
# CMake       -> sistema de build estándar
  • Activa warnings siempre (-Wall -Wextra)
  • Usa -std=c++17 o superior
  • Prefiere contenedores STL sobre arrays crudos
