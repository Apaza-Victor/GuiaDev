1.1 ¿Qué es C++ y por qué sigue siendo relevante?

Un lenguaje nacido del pragmatismo

C++ fue creado por el informático danés Bjarne Stroustrup en los laboratorios Bell a partir de 1979. Su primer nombre fue "C con clases": Stroustrup quería las abstracciones de lenguajes como Simula (clases, herencia) sin renunciar a la velocidad ni al control cercano al hardware que ofrecía C. En 1985, con la publicación de su libro The C++ Programming Language, el lenguaje adoptó su nombre definitivo, un guiño al operador ++: "el siguiente paso de C".

La idea que definió a C++ sigue siendo su sello distintivo más de cuarenta años después: no deberías pagar por lo que no usas. Puedes escribir abstracciones de alto nivel (objetos, plantillas, contenedores de la STL) y obtener código máquina tan eficiente como el que escribirías manualmente en C.

Rasgos que definen al lenguaje

CaracterísticaDescripción
CompiladoSe traduce directamente a código máquina: rendimiento máximo sin intérprete ni máquina virtual
MultiparadigmaSoporta programación imperativa, orientada a objetos, genérica (plantillas) y funcional
Tipado estático y fuerteLos tipos se comprueban en compilación; muchos errores nunca llegan a ejecutarse
Gestión manual de memoriaTú controlas cuándo nace y muere cada objeto (con la ayuda del RAII y los smart pointers)
Cero sobrecosteLas abstracciones no penalizan el rendimiento si no las usas
Estándar ISO vivoNuevas versiones cada 3 años: C++11, 14, 17, 20, 23… el lenguaje evoluciona constantemente

C++ no es "C mejorado": es un lenguaje propio y enorme, aunque mantiene compatibilidad casi total con C. Todo lo que sabes de C te sirve, pero C++ te ofrece herramientas mucho más seguras y expresivas.

1.2 Dónde domina C++: los dominios del rendimiento

C++ reina allí donde cada milisegundo o cada byte importan. Cuando un motor de juego debe dibujar millones de polígonos por segundo, cuando un servidor de trading decide en microsegundos si comprar o vender, o cuando un microcontrolador solo tiene 64 KB de memoria, C++ es (casi siempre) la respuesta de la industria.

Dominios principales

DominioEjemplos reales¿Por qué C++?
Videojuegos y motoresUnreal Engine, CryEngine, id TechControl total de memoria y CPU por frame
Sistemas operativosWindows, macOS, drivers, partes de LinuxAcceso al hardware con abstracciones seguras
Sistemas embebidosAutomóviles, IoT, aviónica, dispositivos médicosPredicibilidad y huella mínima de memoria
Trading de alta frecuencia (HFT)Motores de órdenes en bolsasLatencias de microsegundos, cero garbage collector
NavegadoresChrome, Firefox, Safari (WebKit)Renderizado rápido de páginas complejas
Bases de datosMySQL, MongoDB, Redis (módulos)I/O y consultas de altísimo rendimiento

Aprender C++ te hace comprender cómo funciona realmente una computadora: memoria, punteros, coste de cada abstracción. Ese conocimiento te mejora como programador incluso si luego trabajas en Python o JavaScript.

1.3 El proceso de compilación paso a paso

A diferencia de Python, tu código C++ no se ejecuta tal cual lo escribes: primero debe compilarse. Entender las cuatro fases de este proceso te ahorrará horas de confusión cuando aparezcan errores extraños.

 hola.cpp ──► [Preprocesador] ──► [Compilador] ──► [Ensamblador] ──► [Enlazador] ──► hola.exe
   texto          hola.i             hola.s           hola.o         librerías
              (#include,#define)  (C++ → ensamblador) (código objeto)  (.o + .a/.lib)
FaseQué haceEntrada → Salida
1. PreprocesadorResuelve #include, expande macros y condicionales #ifdef; produce un único archivo de texto "plano".cpp → .i
2. CompiladorAnaliza sintaxis y tipos, optimiza y genera ensamblador para tu CPU.i → .s
3. EnsambladorConvierte el ensamblador en código objeto binario (aún con huecos por resolver).s → .o / .obj
4. Enlazador (linker)Une tus .o con las librerías y resuelve todas las referencias cruzadas.o + libs → ejecutable

Verlo con tus propios ojos

Puedes detener el proceso en cualquier fase con las banderas adecuadas:

# Fase 1: solo preprocesar (ver el resultado de #include <iostream>)
g++ -E hola.cpp -o hola.i

# Fase 2: compilar hasta ensamblador
g++ -S hola.cpp -o hola.s

# Fase 3: compilar hasta código objeto (sin enlazar)
g++ -c hola.cpp -o hola.o

# Proceso completo: compilar Y enlazar de una vez
g++ hola.cpp -o hola

El error clásico "undefined reference to..." viene del enlazador, no del compilador: significa que declaraste una función pero nunca definiste (o no enlazaste) su código. Saber en qué fase falló algo te dice qué tipo de problema buscas.

1.4 Compiladores y banderas: g++, clang++, MSVC

Existen tres grandes familias de compiladores C++. Todos entienden el mismo estándar, aunque difieren en plataformas, mensajes de error y diagnóstico.

CompiladorComandoPlataformas típicasPunto fuerte
GCCg++Linux (nativo), Windows vía MinGW-w64El estándar de facto, omnipresente
Clang/LLVMclang++macOS (Xcode), Linux, WindowsMensajes de error muy claros, modular
MSVCclWindows (Visual Studio)Integración perfecta con Windows SDK

La línea de comandos que deberías usar desde el día uno

g++ -std=c++17 -Wall -Wextra -O2 main.cpp -o main

# Desglose de cada bandera:
#   -std=c++17   usa el estándar C++17 (base de esta guía)
#   -Wall        activa advertencias comunes (warnings)
#   -Wextra      activa advertencias adicionales
#   -O2          optimización estándar para release
#   -g           incluye símbolos de depuración (úsala mientras desarrollas)

./main

Nunca compiles sin -Wall -Wextra. Los warnings no detienen la compilación, pero casi siempre señalan bugs reales. Trátalos como errores y tu código nacerá mucho más sano.

En C++20 puedes usar -std=c++20 para acceder a concepts, ranges y modules. En esta guía usamos C++17 como base e indicamos las novedades de C++20 donde corresponde.

1.5 Tu primer programa explicado línea a línea

#include <iostream>          // 1

int main() {                  // 2
    std::cout << "Hola, GuiaDev!" << std::endl;   // 3
    return 0;                 // 4
}                             // 5
LíneaExplicación
#include <iostream>El preprocesador copia aquí la declaración de la librería de entrada/salida. Sin ella, std::cout no existe
int main()Punto de entrada obligatorio: el sistema operativo llama a esta función para arrancar tu programa. Devuelve un int
std::cout << ...Envía texto a la salida estándar. std:: es el espacio de nombres de la librería estándar; << inserta datos en el flujo
return 0Código de salida: 0 = éxito. Si omites esta línea en main, el compilador moderno devuelve 0 por ti
}Cierra el bloque de main. Las llaves delimitan bloques de código

Leer datos del usuario: cin y getline

#include <iostream>
#include <string>

int main() {
    std::string nombre;
    int edad;

    std::cout << "Nombre: ";
    std::getline(std::cin, nombre);   // lee la LÍNEA completa (admite espacios)

    std::cout << "Edad: ";
    std::cin >> edad;                 // lee un número (se detiene en espacios)

    std::cout << nombre << " tiene " << edad << " años\n";
}

Usa '\n' en lugar de std::endl cuando no necesites vaciar el búfer inmediatamente: endl fuerza un vaciado (flush) en cada uso y puede ralentizar bucles de escritura intensiva.

1.6 Evolución del estándar: de C++98 a C++23

C++ se estandarizó por primera vez en 1998 (ISO). Desde 2011, el comité publica una nueva versión cada tres años, y cada versión ha cambiado la forma de escribir el lenguaje. Conocer este mapa te ayudará a leer código antiguo y a escribir código moderno.

EstándarApodoAportes clave
C++98/03"C++ clásico"Primera norma ISO, STL, std::string, streams, plantillas básicas
C++11"Modern C++" (revolución)auto, lambdas, move semantics, smart pointers, hilos, range-for, nullptr
C++14RefinamientoLambdas genéricas, make_unique, deducción de retorno en funciones
C++17ProductividadStructured bindings, if constexpr, optional/variant, string_view, if/switch con inicializador
C++20El gran saltoConcepts, ranges, coroutines, modules, std::format, operador nave espacial <=>
C++23Pulidostd::print, expected, más comodidades de librería

Si dominas el trío C++11 + C++14 + C++17, ya escribes C++ moderno profesional. C++20 añade herramientas poderosas (concepts, ranges) que verás mencionadas a lo largo de esta guía.

#include <map>
#include <string>

// C++17 en acción: structured bindings descomponen un par en variables
std::map<std::string, int> edades{{"Ana", 30}, {"Luis", 25}};

for (const auto& [nombre, edad] : edades) {
    // 'nombre' y 'edad' nacen aquí, listos para usar
    // (antes de C++17 necesitarías it->first e it->second)
}

1.7 Errores comunes del principiante

Todo programador C++ comete estos errores durante sus primeras semanas. Reconocerlos temprano acelera muchísimo el aprendizaje.

ErrorSíntomaSolución
Olvidar el punto y coma ;error: expected ';' (a veces en la línea SIGUIENTE)Revisa la línea anterior al primer error reportado
Confundir = con ==Una condición siempre verdadera tras asignarLee los warnings: -Wall los detecta
Escribir cout sin std::error: 'cout' was not declaredUsa std::cout (evita using namespace std; global)
Leer cadena con espacios usando cin >>Solo se captura la primera palabraUsa std::getline(std::cin, variable)
Mezclar cin >> y getline sin cuidadogetline "salta" una lecturaVacía el búfer o unifica la estrategia de lectura
Ignorar warningsBugs silenciosos en producciónCompila siempre con -Wall -Wextra
// ❌ Código problemático
#include <iostream>
using namespace std;         // contamina TODO el espacio de nombres global
int main() {
    string nombre;
    cin >> nombre;            // pierde todo lo que venga después de un espacio
    cout << "Hola " << nombre
}                             // falta ';' antes de '}'

// ✅ Versión corregida
#include <iostream>
#include <string>

int main() {
    std::string nombre;
    std::getline(std::cin, nombre);       // captura "Ana García López" completa
    std::cout << "Hola " << nombre << '\n';
}

Ejercicios prácticos

  1. Prepara tu taller: instala un compilador (g++, clang++ o MSVC) y verifica la instalación mostrando su versión. Compila un programa mínimo que imprima tu nombre completo.
  2. Compila con disciplina: toma el programa anterior y compílalo con -std=c++17 -Wall -Wextra. Introduce deliberadamente un warning (por ejemplo, usar una variable sin inicializar) y observa cómo el compilador te lo señala.
  3. Explora las fases: usa -E, -S y -c sobre tu programa y abre los archivos intermedios (.i, .s, .o). ¿Cuántas líneas tiene tu .i solo por #include <iostream>? ¿Qué contiene el .o?
  4. Mini calculadora conversacional: pide dos números decimales al usuario y muestra su suma, resta, multiplicación y división. Controla el caso de división entre cero imprimiendo un mensaje adecuado.
  5. Detectivo de estándares: investiga en cppreference tres características de C++17 (por ejemplo std::optional, structured bindings, std::string_view) y escribe en un comentario de tu programa qué problema resuelve cada una y un ejemplo mínimo de uso.
