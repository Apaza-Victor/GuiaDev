Sintaxis básica

Una regla CSS está formada por un selector y un conjunto de declaraciones. Cada declaración combina una propiedad con un valor, separados por dos puntos y terminados en punto y coma.

selector {
  propiedad: valor;
}

/* Ejemplo con selector de etiqueta */
p {
  color: #333;
  font-size: 16px;
  line-height: 1.5;
}

CSS se puede aplicar de tres formas distintas, cada una con su propio alcance y uso recomendado:

FormaCómo se aplicaUso recomendado
Hoja externaUn archivo .css enlazado con <link rel="stylesheet" href="estilos.css">Proyectos reales. Separa contenido y presentación
InternaBloque <style> ... </style> dentro del <head>Prototipos o páginas únicas
En líneaAtributo style="..." directamente en el elemento HTMLSolo pruebas o estilos dinámicos

CSS no es un lenguaje de programación: no tiene lógica ni variables de ejecución. Es un lenguaje de estilos (hojas de estilo en cascada) que describe cómo se ve el contenido. La cascada es el mecanismo que determina qué regla gana cuando varias afectan al mismo elemento.

Selectores

Un selector indica a qué elemento o elementos del HTML se aplican las reglas. Elegirlos bien es clave para escribir CSS limpio y eficiente.

SelectorQué seleccionaEjemplo
EtiquetaTodos los elementos de una etiquetap → todos los párrafos
ClaseElementos con la clase indicada.clase → <div class="clase">
IdUn elemento con el id indicado (único)#id → <div id="id">
UniversalTodos los elementos* → reset básico con box-sizing
DescendienteElementos dentro de otro (cualquier nivel)div p → párrafos dentro de un div
Hijo directoElementos que son hijos inmediatosdiv > p → solo hijos directos
AdyacenteElemento inmediatamente después de otroh1 + p → primer párrafo tras un h1
AtributoElementos según su atributo o valorinput[type="text"] → inputs de texto
 
/* Combinando selectores */
.clase p { color: green; }              /* descendiente */
nav > ul { list-style: none; }          /* hijo directo */
input[type="email"] { border: 1px solid; } /* atributo */
h2 + p { font-style: italic; }          /* adyacente */

Especificidad: cuando varias reglas afectan al mismo elemento, gana la más específica. Orden general: id > clase > etiqueta. Evita usar demasiados !important y los selectores demasiado largos.

Colores y unidades

CSS ofrece unidades de medida para dimensiones y distintos sistemas de color para fondos, texto y bordes.

UnidadRelativa aUso típico
pxAbsoluta (píxel en pantalla)Bordes finos y elementos de tamaño fijo
%El tamaño del contenedor padreAnchos y alturas de layout
emEl tamaño de letra del elemento actualPadding y márgenes escalables
remEl tamaño de letra de la raíz (<html>)Tipografía accesible en todo el sitio
vw1% del ancho del viewportTamaños relativos a la pantalla
vh1% del alto del viewportSecciones a pantalla completa

Para los colores existen varios formatos con distinta precisión y soporte de transparencia:

FormatoEjemploDetalle
Nombrered, blue140 nombres predefinidos, fáciles de leer
Hexadecimal#fff, #FF5733Notación corta o larga de 6 dígitos
rgb() / rgba()rgb(255,0,0)Rojo, verde, azul; rgba añade alfa (opacidad 0-1)
hsl() / hsla()hsl(120, 100%, 50%)Matiz, saturación, luminosidad; más intuitiva
 
.card {
  background-color: #3498db;
  color: white;
}

.calido {
  background-color: rgba(255, 165, 0, 0.6);
  color: hsl(210, 100%, 20%);
}

Texto y fuentes

CSS controla la tipografía y el estilo del texto mediante propiedades dedicadas. Son las más usadas para legibilidad y diseño.

PropiedadQué hace
colorDefine el color del texto
font-familySelecciona la familia tipográfica
font-sizeTamaño de la letra (px, rem, em, %)
font-weightGrosor (normal 400, bold 700, etc.)
font-styleEstilo: normal, italic, oblique
line-heightAltura de línea / interlineado
text-alignAlineación: left, right, center, justify
text-decorationSubrayado, tachado (underline, line-through)
text-transformMayúsculas/minúsculas (uppercase, capitalize)
letter-spacingEspacio entre caracteres
word-spacingEspacio entre palabras
text-shadowSombra de texto
 
h1 {
  font-family: 'Georgia', serif;
  font-size: 2.5rem;
  font-weight: bold;
  color: #2c3e50;
  letter-spacing: 1px;
}

p {
  font-family: 'Helvetica', Arial, sans-serif;
  font-size: 1rem;
  line-height: 1.7;
  text-align: justify;
  text-shadow: 1px 1px 2px rgba(0,0,0,0.2);
}

Para fuentes personalizadas usa @import de Google Fonts o la regla @font-face. Ejemplo: @import url('https://fonts.googleapis.com/css2?family=Roboto&display=swap');. Carga siempre un fallback (sans-serif, serif) por si la fuente no carga.

Modelo de caja y posicionamiento

El modelo de caja describe cómo cada elemento HTML es una caja rectangular formada por content (contenido), padding (relleno interno), border (borde) y margin (margen exterior).

PropiedadQué hace
width / heightDefine el ancho y alto del contenido
paddingEspacio interno entre el contenido y el borde
marginEspacio externo entre la caja y las demás
borderBorde de la caja (grosor, estilo, color)
border-radiusEsquinas redondeadas
box-sizingControla qué incluye width/height (border-box recomendado)
displayTipo de caja: block, inline, flex, grid, none...
overflowQué ocurre con el contenido desbordado (hidden, scroll, auto)
box-shadowSombra exterior de la caja

Para el posicionamiento, la propiedad position controla cómo se coloca la caja en la página:

ValorComportamiento
staticFlujo normal del documento (por defecto)
relativeDesplazado respecto a su posición normal
absolutePosicionado respecto al ancestro más cercano con position
fixedFijo respecto al viewport (no se mueve al hacer scroll)
stickyCombina relative y fixed; se "pega" al hacer scroll

Junta a position se usan top/bottom/left/right para el desplazamiento, z-index para controlar la superposición en el eje Z y float para flotar cajas a un lado.

.tarjeta {
  box-sizing: border-box;
  width: 300px;
  padding: 20px;
  margin: 16px auto;
  border: 1px solid #ddd;
  border-radius: 8px;
  box-shadow: 0 4px 8px rgba(0,0,0,0.1);
}

.flotante {
  position: fixed;
  bottom: 20px;
  right: 20px;
  z-index: 100;
}

Flexbox y Grid

Flexbox es ideal para distribuir elementos en una dimensión (una fila o una columna). Grid permite crear layouts en dos dimensiones (filas y columnas a la vez).

Flexbox

PropiedadQué hace
display: flexActiva el contenedor flex en el padre
flex-directionDirección del eje principal (row, column)
justify-contentAlinea en el eje principal (center, space-between)
align-itemsAlinea en el eje cruzado (center, stretch)
flex-wrapPermite que los hijos pasen a otra línea
gapSeparación entre los elementos
flexAtajo: flex-grow, flex-shrink, flex-basis
orderReordena visualmente los hijos
 
.barra {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
}

.item {
  flex: 1;
}

Grid

PropiedadQué hace
display: gridActiva el contenedor grid
grid-template-columnsDefine el número y tamaño de columnas
grid-template-rowsDefine el número y tamaño de filas
gapSeparación entre filas y columnas
grid-columnQué columnas ocupa un elemento
grid-rowQué filas ocupa un elemento
 
.galeria {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

.foto-destacada {
  grid-column: span 2;
}

¿Cuál usar? Flexbox para alinear o distribuir elementos en una sola dimensión (menús, filas de tarjetas, centrado). Grid para layouts completos en dos dimensiones con filas y columnas (galerías, tableros, páginas enteras).

Responsivo y media queries

El diseño responsivo adapta la apariencia de la página a distintos tamaños de pantalla. Se consigue con unidades relativas y media queries, que aplican reglas según características del dispositivo (generalmente el ancho).

/* Base móvil (por defecto) */
.contenedor {
  padding: 16px;
}

.columna {
  display: block;
}

/* Pantallas medianas y grandes */
@media (max-width: 768px) {
  .contenedor {
    padding: 8px;
  }

  nav {
    flex-direction: column;
  }
}

Para un buen responsivo usa unidades relativas (%, rem, vw) en lugar de tamaños fijos en píxeles, y reorganiza con Flexbox/Grid en lugar de fijar anchos rígidos.

Punto de corte (breakpoint)Rango típicoDispositivo
Móvilhasta 480pxSmartphones
Tablethasta 768pxTablets y móviles grandes
Escritoriohasta 1024px y másLaptops y monitores

Recomendación: usa la estrategia mobile-first: escribe los estilos base para móvil y añade media queries con min-width para pantallas más grandes.

Pseudoclases y pseudo-elementos

Las pseudoclases seleccionan elementos según su estado o posición, y los pseudo-elementos seleccionan partes concretas de un elemento. Ambas se escriben con un prefijo : (pseudoclase) o :: (pseudo-elemento).

PseudoclaseQué hace
:hoverElemento bajo el cursor del ratón
:activeElemento mientras se hace clic
:focusElemento con foco (inputs, enlaces)
:visitedEnlace ya visitado
:first-childPrimer hijo de su contenedor
:nth-child(n)Enésimo hijo (también par/odd o fórmulas)
:not()Elementos que NO cumplen el selector

Y los pseudo-elementos principales:

Pseudo-elementoQué hace
::beforeContenido insertado antes del elemento
::afterContenido insertado después del elemento
::first-letterPrimera letra del bloque de texto
::first-linePrimera línea del bloque de texto
 
a:hover {
  color: #e74c3c;
}

.boton {
  position: relative;
}

.boton::before {
  content: "★ ";
}

.boton::after {
  content: " →";
}

li:first-child {
  font-weight: bold;
}

p:not(.excluido) {
  color: #444;
}
