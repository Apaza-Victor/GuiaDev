DataFrames.jl y estructuras

DataFrames.jl es el equivalente de pandas en Julia: una tabla con columnas tipadas, ideal para análisis de datos. Se instala con Pkg.add("DataFrames").

using Pkg
# Pkg.add("DataFrames")
# Pkg.add("CSV")
# Pkg.add("Plots")

using DataFrames

df = DataFrame(
    nombre = ["Ana", "Pedro", "Pau"],
    edad   = [30, 25, 35],
    ciudad = ["Lima", "Cusco", "Arequipa"],
)
println(df)

# Inspección
println(size(df))          # (3, 3)
println(names(df))         # nombre, edad, ciudad
println(eltype(df.edad))   # Int64
println(first(df, 2))

# Acceso por columna (símbolo) y fila (número)
println(df.edad)           # Vector de edades
println(df[1, :])          # primera fila (DataFrameRow)
println(df[2, "ciudad"])   # "Cusco"

# Agregar columna
df.promedio = [8.5, 7.0, 9.2]
println(df)

Los DataFrames en Julia son "column-oriented": las columnas son vectores homogéneos, lo que da rendimiento similar a un array plano. DataFrameRow y SubDataFrame permiten vistas sin copiar datos.

Manipulación de datos

DataFrames.jl incluye funciones de transformación: filter, transform, select, groupby, combine y la API con @subset, @select... (macros "query").

using DataFrames

df = DataFrame(
    producto = ["Lapiz", "Lapiz", "Lapiz", "Goma", "Goma"],
    mes      = [1, 2, 3, 1, 2],
    ventas   = [10, 12, 15, 6, 8],
)

# Filtrar filas (macro @subset: legible y rápido)
mayores = @subset(df, ventas .> 7)
println(mayores)

# Seleccionar columnas
println(select(df, :producto, :ventas))

# Transformar (agregar columna calculada)
df_impuesto = transform(df, :ventas => (v -> v * 0.18) => :impuesto)
println(df_impuesto)

# Agrupar y agregar
g = groupby(df, :producto)
resumen = combine(g, :ventas => sum => :total, :ventas => mean => :promedio)
println(resumen)

# Ordenar y valores únicos
println(sort(df, :ventas, rev=true))
println(unique(df.producto))

# Operaciones tipo SQL con macros
using DataFramesMeta   # Pkg.add("DataFramesMeta")
res = @combine(groupby(df, :producto), suma = sum(:ventas))
println(res)

Con DataFramesMeta (macros @select, @where, @transform, @combine) escribir queries es casi tan cómodo como pandas o dplyr, y el rendimiento sigue siendo Julia puro.

Gráficos con Plots.jl

Plots.jl es un front-end unificado que funciona sobre backends (GR, PlotlyJS, UnicodePlots...). Con una línea cambias de backend y la API no cambia.

using Plots, Random

Random.seed!(7)
x = 1:10
y = rand(10)

# Line-plot básico
plot(x, y, label="serie", title="Mi primer plot", xlabel="X", ylabel="Y")

# Múltiples series y estilos
plot(x, x.^2, label="cuadrática")
plot!(x, x .* 2, label="lineal", linestyle=:dash)   # plot! agrega al mismo

# Scatter
scatter(x, y, label="puntos", markersize=6)

# Histograma
histogram(randn(1000), bins=30, label="normal", fillcolor=:steelblue)

# Barplot desde un DataFrame
using DataFrames
df = DataFrame(cat = ["A", "B", "C"], val = [3, 7, 5])
bar(df.cat, df.val, legend=false)

# Guardar
savefig("salida.png")

Uso plot para crear y plot! para sobreescribir la figura actual. Con UnicodePlots puedes incluso renderizar "gráficos" ASCII en la terminal sin abrir ventana.

Estadística

La estadística en Julia usa Statistics (núcleo) y HypothesisTests/Distributions para análisis inferencial.

using Statistics, Distributions

datos = [2.0, 4.0, 4.0, 4.0, 5.0, 5.0, 7.0, 9.0]

println("media:   ", mean(datos))
println("mediana: ", median(datos))
println("varianza:", var(datos))
println("desv.   :", std(datos))
println("quantile75:", quantile(datos, 0.75))

# Distribuciones
n = Normal(0.0, 1.0)
println(rand(n, 5))            # 5 muestras
println(cdf(n, 1.96))          # P(Z <= 1.96) ≈ 0.975

# Correlación
x = 1:10
y = 2 .* x .+ randn(10)
println(cor(x, y))             # cerca de 1

# Test t de Student (comparar dos grupos)
using HypothesisTests
g1 = randn(30)
g2 = randn(30)
t = UnequalVarianceTTest(g1, g2)
println("p-value: ", pvalue(t))

El ecosistema estadístico de Julia cubre desde estadística descriptiva (Statistics) hasta inferencia robusta (HypothesisTests, GLM.jl), a menudo con API coherente y multiplataforma.

Jupyter y Pluto.jl

Dos entornos "notebook" para Julia hacen la experiencia de data science mucho más fluida: Jupyter (vía IJulia) y Pluto.jl, este último con reactividad nativa: cuando editas una celda, todas las dependientes se recalculan solas.

using Pkg

# Pluto: instalar y lanzar
Pkg.add("Pluto")
using Pluto
Pluto.run()   # abre la interfaz web

# En un notebook Pluto comienza así
# using Pluto
# using Plots, Statistics

# Jupyter / IJulia (más clásico, con kernels)
Pkg.add("IJulia")
using IJulia
notebook()   # lanza un Jupyter Notebook con kernel julia
# También puedes conectar Julia a un JupyterLab existente
julia -e 'using IJulia; installkernel("julia")'
# o usar el ejecutable de julia como kernel directamente:
# julia --project -e 'using IJulia; IJulia.install()'

Elegir Pluto vs Jupyter es de gusto: Pluto ofrece reproducibilidad y reactividad; Jupyter integra mejor con otros kernels (Python, R). Para proyectos serios y scripts de producción, usa archivos .jl con --project y ejecución por línea de comandos.

Ejercicios prácticos

Practica en orden: cada ejercicio asume lo aprendido en el anterior.

  1. DataFrame inicial: crea un DataFrame con datos de 4 personas (nombre, edad, ciudad) y muestra sus columnas, tamaños y la fila 2.
  2. Pipeline de transformación: sobre ese DataFrame agrega una columna de "mayoría de edad", filtra mayores de 18 con @subset y agrupa por ciudad con groupby + combine(..., nrow).
  3. Gráfico compuesto: crea un scatter de x vs x.^2 con plot y una línea plot! a la vez; guarda PNG.
  4. Estadística descriptiva: sobre un vector de 20 datos, imprime media, mediana, desviación y el cuantil 90.
  5. Notebook: lanza Pluto.run(), crea una celda con datos, y evalúa si prefieres la reactividad de Pluto o el flujo clásico de Jupyter.

En la última lección del módulo dominaremos el rendimiento literal de Julia: JIT, múltiple dispatch, Pkg y paralelismo.
