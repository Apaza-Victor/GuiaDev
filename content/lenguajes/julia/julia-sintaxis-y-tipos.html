Variables y convenciones

En Julia toda variable es dinamica: no declaras el tipo al crearla, el runtime lo infiere por el valor. La asignacion usa = y una variable puede reasignarse libremente. El lenguaje ademas permite nombres unicode completos, lo que acerca el codigo a la notacion matematica.

x = 10                 # entero
x = 10.0               # reasignada: ahora es Float64
nombre = "GuiaDev"
es_activo = true

# Nombres unicode muy usados en computo cientifico
alpha = 0.05
sigma2 = 2.5
velocidad_media = 120  # snake_case, el estilo recomendado

# Comprobar el tipo con typeof
typeof(x)              # Float64
typeof(nombre)         # String

const ACELERACION = 9.81
ACELERACION = 10.0       # Warning: constant redefinition, se permite (con aviso)
# ACELERACION = "texto"  # ERROR si intentas cambiar de tipo

# La funcion mutante sort! ordena "en su lugar" y devuelve el mismo vector
v = [3, 1, 2]
sort!(v)                 # [1, 2, 3]  (v quedo modificado)
sort([3, 1, 2])          # [1, 2, 3]  (v original intacto)

Usa const para valores que jamas cambian de tipo: ademas de expresar intencion, mejora el rendimiento porque el compilador JIT no recompila ante nuevos tipos.

Tipos numéricos

Julia tiene una jerarquia de tipos numericos excepcionalmente rica: enteros con y sin signo de cualquier ancho, flotantes, racionales exactos, complejos y numeros de precision arbitraria. Casi todo es un subtipo de Real o Complex.

entero   = 42                # Int64 (entero nativo de 64 bits)
flotante = 3.14              # Float64
racional = 1//3              # Rational{Int64}: fraccion EXACTA
complejo = 2 + 3im           # Complex{Int64}: la unidad imaginaria es im

typeof(entero)               # Int64
typeof(racional)             # Rational{Int64}
racional + 1//3              # 2//3 (las fracciones se suman exactas)

# Divisiones
7 / 2                        # 3.5  (division real)
div(7, 2)                    # 3    (division entera)
mod(7, 2)                    # 1    (residuo)
7 % 2                        # 1    (alias de mod)

El ejemplo anterior muestra el detalle determinante de los racionales: 1//3 + 1//3 devuelve 2//3 exacto, mientras que 1/3 + 1/3 en punto flotante produce 0.6666666666666666. Las fracciones exactas nunca pierden precision.

Los flotantes IEEE 754 no son exactos: 0.1 + 0.2 no da 0.3 sino 0.30000000000000004. Usa Rational o BigFloat cuando la exactitud sea critica, y nunca compares flotantes con ==; usa isapprox o ≈.

Strings y caracteres

Los strings inmutables en Julia se escriben entre comillas dobles; los caracteres simples en comillas simples. La interpolacion con $ integra variables y expresiones dentro de un string, y el alfabeto completo puede vivir en cualquier codigo.

saludo = "Hola"
lenguaje = "Julia"
println("$saludo, $lenguaje!")          # Hola, Julia!
println("Suma: $(2 + 3)")               # Suma: 5

# Caracteres y comprobaciones
letra = 'a'
isdigit('5')                            # true
isletter(letra)                         # true

# Operaciones utiles sobre strings
uppercase("julia")                      # "JULIA"
lowercase("JULIA")                      # "julia"
"Julia " ^ 3                            # "Julia Julia Julia "
length("Julia " ^ 3)                    # 18
split("a,b,c", ",")                     # ["a", "b", "c"]
join(["a", "b", "c"], "-")              # "a-b-c"
replace("hola mundo", "mundo" => "julia")  # "hola julia"

Indexacion y substrings

palabra = "GuiaDev"
palabra[1]                  # 'G'
palabra[2:4]                # "uia"
length(palabra)             # 7
lastindex(palabra)          # 7

# Iterar caracter por caracter
for c in "abc"
    print(c, "-")
end                         # a-b-c-

Julia indexa strings por codepoints: el indice 1 es el primer caracter, no el primer byte. Ante un caracter multibyte como "olá"[4] obtendras el caracter, mientras que explorar bytes ciegamente con codeunits puede recorrer el interior de un caracter. Usa eachindex(s) en genericos.

Operadores y funciones matemáticas

Julia soporta operadores aritmeticos clasicos, encadenamiento de comparaciones al estilo matematico y un conjunto enorme de funciones matematicas nativas en Base, sin importar ninguna biblioteca.

# Aritmetica
5 + 3 * 2            # 11
2^10                 # 1024
17 % 5               # 2
-7^2                 # -49  (la potencia une antes que el menos)

# Comparaciones encadenadas: se lee como en matematicas
3 < 5 < 7            # true
5 > 3 > 1            # true
1 < 3 > 5            # false

# Logicos de cortocircuito
true && false        # false
true || false        # true
!true                # false

Composición con pipes

Julia permite componer funciones de tres maneras complementarias: el operador pipe |>, la composicion matematica circ y, opcionalmente, la macro @chain del paquete Chain.jl para cadenas largas. Asi el codigo se lee en el orden natural de las transformaciones, como haria un analista.

# El pipe pasa el valor de la izquierda como primer argumento
[1, 2, 3, 4, 5] |> sum                # 15
[1, 2, 3, 4, 5] |> sum |> x -> x^2   # 225

# Para argumentos multiples se envuelve en una funcion anonima
"hola mundo" |> s -> split(s, " ")    # ["hola", "mundo"]
[1, 2, 3, 4, 5] |> x -> filter(iseven, x)  # [2, 4]
# Composicion con el operador circ (Base)
doblado  = x -> 2x
cuadrado = x -> x^2

f = cuadrado ∘ doblado      # f(x) = cuadrado(doblado(x)) = (2x)^2
f(5)                        # 100

g = doblado ∘ cuadrado      # g(x) = doblado(cuadrado(x)) = 2x^2
g(5)                        # 50
# Chain.jl para pipelines tipo tidyverse (Pkg.add("Chain"))
using Chain
@chain [3, 1, 4, 1, 5] begin
    sort                 # [1, 1, 3, 4, 5]
    reverse              # [5, 4, 3, 1, 1]
    sum                  # 14
end

El pipe |> solo pasa un argumento; para pasar mas, envuelve en una funcion anonima x -> f(x, 10). Alternativamente, @chain entiende el marcador _, de modo que puedes escribir |> f(_, 10) de forma natural.

Ejercicios prácticos

Practica en orden: cada ejercicio asume lo aprendido en el anterior.

  1. Variables dinamicas: crea cotizacion = 125.5, imprime typeof, reasignala a "alza" y vuelve a imprimir el tipo. Responde: pueden convivir valores numericos y texto en una misma variable?
  2. Precision: calcula 1//3 + 1//6, 0.1 + 0.2 y 1/3 + 1/6; compara los tres resultados y explica en el REPL por que difieren.
  3. Strings: usa split y join para transformar "guia;dev;julia" en "guia-dev-julia", y uppercase para gritar tu lenguaje favorito.
  4. Operadores: en una sola linea con pipes, toma [16, 0, -9, 25, 4], aplica sqrt con . (broadcasting), redondea con round y suma todo. Debe dar 10.0.
  5. Composicion: define f = x -> 3x y g = x -> x + 1, calcula (f ∘ g)(4) y (g ∘ f)(4), y verifica a mano cual da 15 y cual 13.

En la proxima leccion aprenderas a tomar decisiones y repetir trabajo: condicionales, bucles, funciones y comprensiones, los ladrillos de todo algoritmo.
