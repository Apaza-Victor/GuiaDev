Arrays unidimensionales

El tipo Vector{T} (alias de Array{T,1}) es el arreglo básico de Julia. Es homogéneo por defecto pero puedes crear vectores de tipos mixtos con Vector{Any}. Los índices empiezan en 1.

v = [1, 2, 3, 4]                 # Vector{Int64}
println(v[1])                    # 1 (índices desde 1)
println(v[end])                  # 4 (end = último)
println(v[2:3])                  # [2, 3] (rebanada: copia)

# Crear vectores con funciones
rango   = 1:10 |> collect         # Collect convierte el rango
zeros   = zeros(4)               # [0.0, 0.0, 0.0, 0.0]
ones    = ones(3)                # [1.0, 1.0, 1.0]
vfill   = fill(7, 3)             # [7, 7, 7]

# Operaciones elementales: mutan con ! (bang)
push!(v, 5)                    # agrega al final
pop!(v)                        # quita del final
pushfirst!(v, 0)               # agrega al inicio
append!(v, [10, 20])           # agrega una lista
sort!(v)                       # ordena destructivamente

# Buscar
println(findfirst(==(3), v))   # índice del 3 o nothing
println(3 in v)                # true

# Rebanadas con step
println(1:2:10 |> collect)     # [1, 3, 5, 7, 9]

Julia distingue funciones con ! (mutantes: push!, sort!) de las puras (sort, reverse). La convención ! es parte del idioma y la respetas.

Matrices y álgebra lineal

Una Matrix{T} es un arreglo bidimensional. La notación M[i, j] accede con dos índices; M[i, :] toma una fila o columna completa.

A = [1 2 3; 4 5 6]             # 2x3 (espacio columnas, ; filas)
println(size(A))               # (2, 3)
println(A[1, 2])               # 2
println(A[2, :])               # fila 2: [4, 5, 6]
println(A[:, 1])               # columna 1: [1, 4]

B = [7 8; 9 10; 11 12]        # 3x2
C = A * B                      # producto (2x3)*(3x2) = 2x2
println(C)

# Matrices cuadradas utiles
I3 = Matrix{Int}(I, 3, 3)      # identidad
Z  = zeros(2, 2)
println(I3)

# Operaciones de álgebra lineal
M  = [2.0 1.0; 1.0 3.0]
println(M' * M)                 # M' = traspuesta conjugada
println(inv(M))                 # inversa
println(det(M))                 # determinante
println(eigvals(M))             # valores propios (LinearAlgebra)

# Concatenar
Bajo  = vcat(A, zeros(1, 3))    # apilar vertical (2+1 filas)
Lado  = hcat(A, ones(2, 1))     # horizontal
println(size(Bajo))             # (3, 3)

Para álgebra lineal avanzada se usa using LinearAlgebra: trae eigvals, svd, qr, norm, etc. Multiplica matrices con *; multiplica elemento a elemento con .* (broadcasting).

Funciones sobre arrays

Julia incluye un conjunto de funciones de alto nivel sobre contenedores: map, filter, reduce, sum, y las abreviaturas con sufijo -!.

nums = [1, 2, 3, 4, 5]

println(map(x -> x^2, nums))      # [1, 4, 9, 16, 25]
println(filter(iseven, nums))     # [2, 4]
println(reduce(+, nums))          # 15
println(sum(nums))                # 15
println(minimum(nums), maximum(nums))   # (1, 5)

# Funciones anónimas cortas
println(map(impar -> impar * 10, filter(isodd, nums)))  # [10, 30, 50]

# Tambien: sort, reverse, unique, count(cond, colección)
println(unique([1, 1, 2, 3, 3]))  # [1, 2, 3]
println(count(x -> x > 3, nums))  # 2

# Con diccionarios (pares clave/valor)
d = Dict("a" => 1, "b" => 2)
println(mapvalues = map(v -> v * 10, values(d)))
println(map((k, v) -> "$k=$v", keys(d), values(d)))  # ["a=1","b=2"]

La sintaxis x -> expresión define una función anónima. Julia anima a usar funciones puras de alto nivel: son más memorables y el compilador las optimiza bien.

Broadcasting: el punto .

El broadcasting (operador .) aplica una función o un operador a TODOS los elementos de un array a la vez, sin escribir bucles. Es el superpoder de Julia para el estilo vectorizado.

x = [1.0, 2.0, 3.0]

println(x .+ 1)       # [2.0, 3.0, 4.0] (suma escalar: broadcast)
println(x .* x)       # [1.0, 4.0, 9.0] (elemento a elemento)
println(sin.(x)       # seno de cada elemento)

# Con función propia: f.(array)
f(x) = x^2 + 2x + 1
println(f.(x))        # [4.0, 9.0, 16.0]

# Broadcast entre dos arreglos
a = [1, 2, 3]
b = [10, 20, 30]
println(a .+ b)       # [11, 22, 33]

# La regla del punto: se aplica a TODA la línea (dotted call fusionado)
resultado = 2 .* x .^ 2 .+ 3 .* x .+ 1   # polinomio vectorizado
println(resultado)

# Comparaciones y lógica vectorizada
println(x .> 1.5)                    # [false, true, true]
println((x .> 1.0) .&& (x .< 3.0))   # [false, true, false]

Confundir * con .* es el error clásico de Julia: en una matriz, * hace álgebra lineal; en un vector, .* combina elemento a elemento. El broadcast . "envuelve" también funciones: Map(f, v) ≈ f.(v).

Rendimiento y tipado

Julia alcanza velocidad de lenguaje compilado porque el código es JIT: se especializa según los TIPOS de las variables. Para rendir bien, evita "type instability" (fluctuar de tipo dentro de una función) y usa arreglos de tipo concreto.

# Arreglos tipados: siempre que sea posible elige el tipo concreto
v_float = Float64[1.0, 2.0, 3.0]  # Vector{Float64}
v_any   = Any[1, "dos", 3.0]      # Vector{Any}: lento (no elijas por comodidad)

# Pre-asignar en lugar de push! en bucles calientes
function suma_n(n)
    s = 0                     # Int (estable)
    for i in 1:n
        s += i
    end
    s
end

@time suma_n(10^7)          # @time desde el workspace

# Anotar tipos ayuda al compilador (y documenta la intención)
function hipotenusa(a::Float64, b::Float64)::Float64
    sqrt(a^2 + b^2)
end
println(hipotenusa(3.0, 4.0))   # 5.0

# El truco de los benchmarks: Julia se "calienta" con la primera llamada
# La primera ejecución compila; las siguientes vuelan
for _ in 1:3
    t = @elapsed suma_n(10^6)
    println("tiempo: ", round(t, digits=6))
end

Regla de oro: "performance in Julia is about types". Con string(@code_warntype f(...)) puedes ver si hay inestabilidad. El rendimiento típico de Julia ronda C/Fortran en operaciones numéricas.

Ejercicios prácticos

Practica en orden: cada ejercicio asume lo aprendido en el anterior.

  1. Vector básico: crea v = [3, 1, 4, 1, 5], agrega y quita elementos con push!/pop!, y ordénalo con sort!.
  2. Matriz de mejor: crea una 3x3 de enteros al azar, extrae la diagonal (diag(M)), calcula det e inv si es invertible.
  3. Funciones de orden superior: sobre [1..10] aplica map con una anónima, filter(isodd, ...) y reduce(+, ...).
  4. Broadcasting: vectoriza la fórmula del área r .^ 2 .* π para radios [1.0, 2.0, 3.0, 5.0].
  5. Benchmark: escribe suma(n) pura; mide con @elapsed su ejecución repetida y comenta si mejora tras el calentamiento del JIT.
