¿Qué es Julia? Ciencia + velocidad

Julia es un lenguaje de programación de alto nivel y de tipado dinámico, creado para resolver el famoso "problema de los dos lenguajes": la comunidad científica prototipa en Python o R (fáciles pero lentos) y luego reescribe todo en C o Fortran (rápidos pero difíciles). Julia nació en 2012 en el MIT con una promesa ambiciosa: rendimiento de C con la productividad de Python, gracias a la compilación JIT y al múltiple dispatch.

# Estimacion de pi por Monte Carlo, sin ninguna libreria extra
function estimar_pi(n)
    dentro = 0
    for _ in 1:n
        x, y = rand(), rand()
        if x^2 + y^2 <= 1
            dentro += 1
        end
    end
    return 4 * dentro / n
end

estimar_pi(1_000_000)   # aprox. 3.1416, en menos de un segundo

Indices base 1, sintaxis legible e interoperabilidad directa con C y Python: llega a Julia desde Python sin friccion, y lo primero que notaras es que los bucles dejan de doler.

Instalación y gestión de versiones (juliaup)

La forma oficial y recomendada de instalar Julia es juliaup, un gestor de toolchains inspirado en rustup. Permite instalar, actualizar y cambiar entre versiones (1.11, 1.12, nightly...) con un solo comando.

# Windows (PowerShell): instalador oficial de juliaup
irm https://install.julialang.org | iex

# Windows alternativo con winget
winget install julia -s msstore

# macOS y Linux
curl -fsSL https://install.julialang.org | sh

# Verificar la instalacion
julia --version   # julia version 1.12.0

# Instalar una version especifica y cambiarse
juliaup add 1.11
juliaup default 1.11

# Ver el estado y actualizar
juliaup status
juliaup update
Comando juliaupQue hace
juliaup add 1.11Instala la version 1.11 de Julia
juliaup default 1.11Fija 1.11 como version por defecto
juliaup statusLista versiones instaladas y la activa
juliaup updateActualiza todas las toolchains
juliaup add nightlyInstala la build nightly en desarrollo

La instalacion descarga varios cientos de megabytes; si usas un proxy corporativo o tienes red limitada, revisa la documentacion de juliaup para configurar el registro de paquetes y el servidor de descarga.

El REPL de Julia

Al escribir julia en la terminal se abre el REPL (Read-Eval-Print Loop): el entorno interactivo donde se escribe codigo y se ve el resultado al instante. El REPL de Julia tiene modos especiales que se activan con una sola tecla y que agilizan muchisimo el trabajo.

julia> 2 + 2
4

julia> nombre = "Julia"
"Julia"

julia> uppercase(nombre)
"JULIA"

julia> 1 / 3
0.3333333333333333

Los cuatro modos del REPL

Paquetes (pkg>)]Gestionar paquetes con Pkg

# En modo shell podemos listar archivos
shell> ls

# En modo pkg gestionamos dependencias
(@v1.12) pkg> add DataFrames

En el prompt de Julia los simbolos unicode se escriben con barras: \pi + TAB inserta pi, \alpha + TAB inserta alpha. Pruebalo en el REPL.

Tu primer programa

Como la mayoria de lenguajes, Julia se puede ejecutar escribiendo un archivo de texto con extension .jl y lanzandolo con julia archivo.jl. El punto de arranque de todo programa es, sin excepciones, la ejecucion secuencial de las lineas del archivo.

# Crear el archivo y ejecutarlo
nano hola.jl
julia hola.jl

hola.jl

# hola.jl
println("Hola desde Julia")

x = 42
y = 3.14
println("x + y = ", x + y)   # x + y = 45.14

# La interpolacion con $ integra expresiones dentro del string
lenguaje = "Julia"
println("Estoy aprendiendo $lenguaje en $(2026)")   # Estoy aprendiendo Julia en 2026

Observa dos detalles: los comentarios usan #, y la funcion println() imprime con salto de linea final. Tambien existe print() (sin salto) y, para salida formateada, el macro @printf.

# Arimetica basica: la sintaxis es matematica pura
(5 + 3) * 2    # 16
2^10           # 1024
7 / 2          # 3.5
7 ÷ 2          # 3  (division entera)

# Admite literales cientificos y notacion rapida de vectores
velocidad = 3e8            # 3.0e8 metros por segundo
precios = [19.9, 24.5, 9.0]  # vector literal

Julia y su ecosistema científico

El ecosistema de Julia esta pensado para la computacion cientifica de punta: simulacion numerica, machine learning, bioinformatica, astrofisica y finanzas cuantitativas. La organizacion JuliaLang mantiene el registro General con miles de paquetes, todos instalables con un comando.

# Instalar varios paquetes de golpe en el REPL (modo pkg) o en codigo
using Pkg
Pkg.add(["Plots", "DataFrames", "Statistics", "DifferentialEquations"])
PaqueteCampoUso habitual
DataFramesCiencia de datosTablas y manipulacion tipo pandas
PlotsVisualizacionGraficos estadisticos y cientificos
StatisticsEstadisticaMedia, mediana, correlacion (stdlib)
LinearAlgebraAlgebra linealMatrices, eigenvalores, SVD (stdlib)
DifferentialEquationsEcuaciones diferencialesODEs, PDEs y simulacion
FluxMachine learningRedes neuronales en Julia puro

La filosofia "small specialized universe" (Universe.jl) permite encadenar paquetes ultraespecializados para campos como astronomia (AstroLib) o quimica (QuantumOptics), manteniendo composicion total: si dos paquetes reciben el mismo tipo, se pueden combinar sin adaptadores.

Comodo de donde vengas, la comunidad ofrece traductores automaticos: PythonCall.jl y RCall.jl permiten llamar Python o R desde Julia, de modo que puedes migrar por partes.

Ejercicios prácticos

Practica en orden: cada ejercicio asume lo aprendido en el anterior.

  1. Instalacion verificada: instala juliaup, ejecuta julia --version, abre el REPL con julia y escribe 2 + 2 para confirmar que responde.
  2. Modos del REPL: escribe ? y consulta la ayuda de round, luego escribe ; y ejecuta ls o dir, y por ultimo entra en modo pkg con ] y ejecuta status.
  3. Primer archivo: crea presentacion.jl que imprima tu nombre, tu ciudad y el anio actual usando interpolacion $(...), y ejecutalo con julia presentacion.jl.
  4. Monte Carlo: copia la funcion estimar_pi de esta leccion, pruebala con n = 1_000, n = 1_000_000 y anota cuanto se acerca a 3.141592653.
  5. Explora el ecosistema: desde el modo pkg instala Statistics y LinearAlgebra, verifica con status y escribe using Statistics y mean([1, 2, 3, 4]) en el REPL.

En la proxima leccion dominaremos la sintaxis de Julia: variables, tipos numericos, strings y operadores, la base de todo codigo cientifico.
