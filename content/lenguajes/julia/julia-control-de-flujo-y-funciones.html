if, elseif, else y ternario

En Julia, if/elseif/else funcionan de forma parecida a Python pero con sintaxis al estilo C. La palabra clave end cierra el bloque. A diferencia de C/Java, el elseif es sin espacio.

edad = 30

if edad >= 18
    println("Mayor de edad")
elseif edad >= 0
    println("Menor de edad")
else
    error("Edad inválida")
end

# El if se puede usar como EXPRESIÓN: devuelve un valor
tipo = if edad >= 18
    "adulto"
else
    "menor"
end
println(tipo)

# Ternario
paridad = edad % 2 == 0 ? "par" : "impar"
println(paridad)

# Comparaciones encadenadas (nativas en Julia)
println(0 <= edad <= 120)         # true

# Valores truthy/falsy: solo false y nothing son falsos
if 0
    println("0 es verdadero en Julia")   # sí: true (pero es mala práctica)
end

En Julia, 0, "" y [] son verdaderos: solo false y nothing son falsos. No escribas condiciones numéricas esperando el comportamiento de C o Python.

Bucles for y while

Julia tiene for (inclusivo en rangos), while, y sentencias break y continue. La instrucción for puede recorrer rangos, arreglos y hasta varias variables a la vez.

# for con rango (1:5 incluye el 5)
for i in 1:5
    println(i)
end

# Paso: 1:2:10 va de 1 a 10 de 2 en 2
for i in 1:2:10
    print(i, " ")
end
println()

# Recorrer un vector
frutas = ["manzana", "pera", "uva"]
for f in frutas
    print(f, " ")
end
println()

# Con índice (eachindex es el idiomático)
for i in eachindex(frutas)
    println(i, ": ", frutas[i])
end

# Varias variables a la vez (producto cartesiano)
for x in 1:3, y in 1:2
    println((x, y))
end

# while
n = 1
while n <= 5
    print(n, " ")
    n += 1
end
println()

# break / continue
for i in 1:20
    i % 2 == 0 && continue      # salta pares (estilo Julia)
    i > 7 && break              # se detiene en 7
    print(i, " ")
end
println()   # 1 3 5 7

El patrón condición && acción (y su hermano accion_uso || error(...)) es el equivalente Julia del one-liner if: elegancia con side-effect mínimo.

Funciones y argumentos

Las funciones se declaran con function ... end o con la forma corta f(x) = .... El valor devuelto es el de la última expresión (no hace falta return). Julia combina esto con múltiple dispatch para crear funciones sobrecargadas por tipos.

# Forma larga
function area_circulo(r)
    π * r^2
end

# Forma corta (azúcar sintáctico)
area_rect(l, a) = l * a

println(area_circulo(2.0))      # 12.5663...
println(area_rect(3, 4))        # 12

# Argumentos con valores por defecto y opcionales
saludar(nombre; saludo="Hola", mayus=false) = 
    mayus ? uppercase("$saludo, $nombre") : "$saludo, $nombre"

println(saludar("Ana"))
println(saludar("Ana"; saludo="Buen día", mayus=true))

# Argumento tipo en la firma (múltiple dispatch básico)
doble(x::Int)   = 2x
doble(x::Float64) = 2.0x
doble(x::String)  = x * x

println(doble(4))        # 8, usa Int
println(doble(2.5))      # 5.0, usa Float64
println(doble("ya"))     # "yaya", usa String

# return explícito (útil en guardas tempranas)
function clamp(x, lo, hi)
    x < lo && return lo
    x > hi && return hi
    x
end
println(clamp(15, 0, 10))   # 10

El argumento aparece con tipo:: para anotar, y las funciones con el mismo nombre pero distinto tipo por argumento son métodos. Es la base del múltiple dispatch que veremos en la lección 6.

Comprensiones y generadores

Una comprensión construye un arreglo evaluando una expresión para cada valor de un iterable, con filtros opcionales. Es una de las formas más idiomas de Julia para transformar datos.

# Comprensión básica: cuadrados
cuadrados = [n^2 for n in 1:10]
println(cuadrados)

# Con filtro (palabra clave if)
pares = [n for n in 1:20 if n % 2 == 0]
println(pares)      # [2,4,...,20]

# Doble iteración
pares_cart = [(x, y) for x in 1:3, y in 1:3 if x != y]
println(pares_cart)

# Mapas de comprensión sobre vectores
usuario = ["ana", "pedro"]
mayus = [uppercase(u) for u in usuario]
println(mayus)      # ["ANA","PEDRO"]

# Generador: igual pero con (...) → sin almacenar, iterable perezoso
suma = sum(n^2 for n in 1:100)
println(suma)       # 338350, sin crear el arreglo

# La comprensión clásica es normalmente más rápida que map+filter
resultado = [n^2 for n in 1:100 if n % 3 == 0]

Prefiere comprensiones sobre map(f, args) acumulado: en Julia son legibles, eficientes y no generan arreglos temporales si las combinas con sum/minimum vía generador.

Excepciones y try/catch

Julia lanza errores con error, ArgumentError, DomainError, etc. y los captura con try/catch, además de finally.

function dividir(a, b)
    b == 0 && throw(ArgumentError("división por cero"))
    a / b
end

# Captura con mensaje
try
    println(dividir(10, 0))
catch e
    println("Error capturado: ", e)   # ArgumentError: división por cero
end

# Verificar tipo del error
try
    sqrt(-1)
catch e
    if e isa DomainError
        println("Dominio inválido")
    else
        rethrow()                     # relanza si no es el esperado
    end
finally
    println("Esto corre siempre")
end

# Estrategia devuelve-valor: try como expresión
resultado = try
    parse(Int, "abc")
catch
    -1
end
println(resultado)   # -1

En Julia las excepciones son lentas en comparación a la vía feliz: úsalas para errores reales, no como control de flujo normal. Si esperas fallos frecuentes, prefiere devolver nothing o un Union{T, Nothing}.

Ejercicios prácticos

Practica en orden: cada ejercicio asume lo aprendido en el anterior.

  1. Clasificador: escribe un programa que clasifique un número como par/impar y positivo/negativo/cero.
  2. FizzBuzz: imprime del 1 al 20 con Fizz para múltiplos de 3, Buzz para múltiplos de 5 y FizzBuzz para ambos, usando un for.
  3. Funciones puras: crea factorial(n), es_primo(n) y suma_digitos(n) con la forma corta.
  4. Comprensión experta: usa una comprensión doble con filtro para generar los pares (a,b) con a+b == 10.
  5. Manejo de errores: una función que intente parse(Float64, ...) y devuelva nothing si falla; prueba con "3.14" y "uvw".
