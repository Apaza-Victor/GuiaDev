Qué es una cadena

Una cadena es una secuencia de caracteres (letras, números, símbolos y espacios). En PSeInt se declaran con el tipo Caracter, aunque también puedes usar Cadena para textos más largos. Las cadenas van entre comillas dobles.

Algoritmo EjemploCadenas
    Definir nombre, saludo Como Cadena
    Definir inicial Como Caracter

    nombre <- "María"
    saludo <- "Hola, ¿cómo estás?"
    inicial <- "M"

    Escribir saludo
    Escribir "Tu nombre es: ", nombre
    Escribir "La primera letra es: ", inicial
FinAlgoritmo

Funciones de cadenas en PSeInt

FunciónQué haceEjemploResultado
Longitud(texto)Número de caracteres.Longitud("hola")4
Subcadena(texto, ini, fin)Extrae un tramo.Subcadena("hola", 2, 3)"ol"
Mayusculas(texto)Convierte a mayúsculas.Mayusculas("hola")"HOLA"
Minusculas(texto)Convierte a minúsculas.Minusculas("HOLA")"hola"
ConvertirANumero(texto)Convierte texto a número.ConvertirANumero("12")12
ConvertirATexto(numero)Convierte número a texto.ConvertirATexto(5)"5"

En PSeInt, Longitud() cuenta también los espacios en blanco. La cadena vacía "" tiene longitud 0.

Concatenación de cadenas

Unir (concatenar) cadenas y valores es muy común. En Escribir puedes separar elementos con comas, o usar la operación de concatenación cuando necesites construir un texto.

Algoritmo Concatenar
    Definir nombre, apellido, completo Como Cadena

    nombre <- "Juan"
    apellido <- "Pérez"

    // Opción 1: con comas en Escribir
    Escribir nombre, " ", apellido

    // Opción 2: construir una sola cadena (concatenación con +)
    completo <- nombre + " " + apellido
    Escribir completo
FinAlgoritmo
Ver código PlantUML 
@startuml

  endif
  :i = i + 1;

El diagrama anterior muestra el flujo para contar cuántas veces aparece una letra en una frase: se recorre carácter a carácter con un bucle y se incrementa un contador cuando coincide.

Para leer una cadena con espacios usa Leer normal; PSeInt lee toda la línea hasta el Enter como parte de la cadena.

Comparar y validar cadenas

Puedes comparar cadenas con = y <> (distinto). Esto es útil para validar contraseñas, menús o detectar si una palabra coincide.

Algoritmo ValidarClave
    Definir clave, correcta Como Cadena

    correcta <- "secreto123"
    Escribir "Ingresa tu contraseña: "
    Leer clave

    Si clave = correcta Entonces
        Escribir "Acceso concedido"
    SiNo
        Escribir "Contraseña incorrecta"
    FinSi
FinAlgoritmo

La comparación de cadenas es sensible a mayúsculas: "Hola" es distinto de "hola". Si no te importa la diferencia, convierte ambas con Mayusculas() o Minusculas() antes de comparar.
