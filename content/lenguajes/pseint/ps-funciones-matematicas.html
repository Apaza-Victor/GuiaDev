Funciones matemáticas básicas

PSeInt incluye funciones matemáticas listas para usar. Reciben un (o varios) valor y devuelven un resultado.

Funciones matemáticas

FunciónQué haceEjemploResultado
raiz(numero)Raíz cuadrada.raiz(16)4
abs(numero)Valor absoluto.abs(-5)5
trunc(numero)Parte entera.trunc(7.9)7
redon(numero)Redondea.redon(7.5)8
seno(numero)Seno (en radianes).seno(0)0
coseno(numero)Coseno (en radianes).coseno(0)1
ln(numero)Logaritmo natural.ln(1)0
exp(numero)Eleva e (2.718...) al número.exp(1)2.718...
Algoritmo Matematica
    Definir x Como Real
    x <- 16

    Escribir "Raíz de 16: ", raiz(x)
    Escribir "Valor absoluto de -5: ", abs(-5)
    Escribir "Parte entera de 7.9: ", trunc(7.9)
    Escribir "Redondeo de 7.5: ", redon(7.5)
    // Potencia con operador ^
    Escribir "2 elevado a 5: ", 2 ^ 5
FinAlgoritmo

Con el operador ^ haces potencias, y con mod obtienes el resto de una división (muy útil para saber si un número es par). La divisiónDiv devuelve el cociente entero.

Números aleatorios con azar()

La función azar(menor, mayor) devuelve un número entero aleatorio entre dos valores (ambos incluidos). Es la base para crear juegos, simulaciones y sorteos.

Algoritmo Dado
    Definir cara Como Entero

    // Un número aleatorio entre 1 y 6 (como un dado)
    cara <- azar(1, 6)
    Escribir "Sacaste un: ", cara
FinAlgoritmo
Ver código PlantUML 
@startuml
:actual = 0;
:intentos = 0;
:azar(secreto, 1, 20);
repeat
  :intentos = intentos + 1;
  :Leer numero;
  if (numero = secreto) then
    :Mostrar "¡Correcto!";
  elseif (numero < secreto) then
    :Mostrar "El número es mayor";
  else
    :Mostrar "El número es menor";
  endif
repeat while (numero <> secreto)
:Mostrar "Lo lograste en " + intentos + " intentos";
stop
@enduml
Algoritmo AdivinaElNumero
    Definir secreto, intento, intentos Como Entero

    secreto <- azar(1, 20)
    intentos <- 0

    Repetir
        Escribir "Adivina el número (1-20): "
        Leer intento
        intentos <- intentos + 1

        Si intento < secreto Entonces
            Escribir "El número es mayor"
        SiNo
            Si intento > secreto Entonces
                Escribir "El número es menor"
            SiNo
                Escribir "¡Correcto en ", intentos, " intentos!"
            FinSi
        FinSi
    Hasta Que intento = secreto
FinAlgoritmo

En PowerShell, azar se usa igual; solo recuerda que cada vez que se ejecuta devuelve un valor distinto. Si no necesitas repetir, genera el número una sola vez antes del bucle.

Aplicaciones de aleatorios y matemáticas

Estas herramientas tienen muchas aplicaciones reales:

Usos comunes

AplicaciónCómo se logra
Juego de dadosazar(1, 6)
Sorteo de premiosÍndice aleatorio sobre un arreglo: azar(1, n).
Simulación de monedaazar(0, 1) para cara/cruz.
Generar contraseñasElegir caracteres aleatorios de una cadena.
Fórmulas científicasUsar raiz, seno, coseno, ln.
Redondeo de preciosredon(precio * 100) / 100.

azar() solo genera enteros. Si necesitas un decimal aleatorio, combina azar con una división, por ejemplo generar décimas: azar(0, 100) / 10.

Ejercicios de matemáticas y azar

Pon en práctica lo aprendido:

Ejercicios

#ProblemaPista
1Leer un número y mostrar su raíz cuadrada.Usa raiz(); cuidado: raíz de negativo da error.
2Simular 10 lanzamientos de un dado y mostrarlos.Bucle Para con azar(1, 6).
3Juego: adivinar un número del 1 al 50 y contar intentos.Combina azar() con un bucle Repetir.
4Leer un precio con decimales y redondearlo a 2 cifras.redon(precio * 100) / 100.
5Generar y mostrar un número aleatorio de 2 dígitos.azar(10, 99).

Los ejercicios con azar() son los más entretenidos porque el resultado cambia cada vez. Perfectos para empezar a crear pequeños juegos.
