Búsqueda lineal

La búsqueda lineal recorre un arreglo de principio a fin comparando cada elemento con el valor buscado. Es simple y funciona aunque el arreglo no esté ordenado.

Algoritmo BusquedaLineal
    Definir a Como Entero
    Definir n, i, x, posicion Como Entero

    Escribir "Número de elementos: "
    Leer n
    Dimension a[n]
    Para i <- 1 Hasta n Con Paso 1 Hacer
        Leer a[i]
    FinPara

    Escribir "Valor a buscar: "
    Leer x

    posicion <- 0   // 0 indica "no encontrado"
    Para i <- 1 Hasta n Con Paso 1 Hacer
        Si a[i] = x Entonces
            posicion <- i
            i <- n   // termina el bucle
        FinSi
    FinPara

    Si posicion = 0 Entonces
        Escribir "No se encontró el valor"
    SiNo
        Escribir "Encontrado en la posición ", posicion
    FinSi
FinAlgoritmo
Ver código PlantUML 
@startuml
start
:Leer arreglo a[n];
:Leer x (valor a buscar);
:posicion = -1;
:i = 1;
while (i <= n) is (¿encontrado?)
  if (a[i] = x) then
    :posicion = i;
  endif
  :i = i + 1;
endwhile
if (posicion = -1) then
  :Mostrar "No encontrado";
else
  :Mostrar "Encontrado en posición " + posicion;
endif
stop
@enduml

La búsqueda lineal se llama así porque avanza en línea recta, elemento por elemento. Su coste es proporcional a n: en el peor caso recorre todo el arreglo.

Búsqueda binaria

La búsqueda binaria es mucho más rápida, pero exige que el arreglo esté ordenado. Divide el arreglo a la mitad y descarta la mitad que no puede contener al valor en cada paso.

Algoritmo BusquedaBinaria
    Definir a Como Entero
    Definir n, izq, der, medio, x Como Entero
    Definir encontrado Como Logico

    Escribir "Valor a buscar: "
    Leer x
    izq <- 1
    der <- n
    encontrado <- FALSO

    Mientras izq <= der Y NO encontrado Hacer
        medio <- trunc((izq + der) / 2)
        Si a[medio] = x Entonces
            encontrado <- VERDADERO
        SiNo
            Si x < a[medio] Entonces
                der <- medio - 1
            SiNo
                izq <- medio + 1
            FinSi
        FinSi
    FinMientras

    Si encontrado Entonces
        Escribir "Encontrado en la posición ", medio
    SiNo
        Escribir "No se encontró"
    FinSi
FinAlgoritmo
PasoMontón a buscar (ordenado: 2 5 8 12 15 20)izqdermedio
1Buscar 1216a[3]=8 (12>8 → izq=4)
2Buscar 1246a[5]=15 (12<15 → der=4)
3Buscar 1244a[4]=12 (¡encontrado!)

Con 6 elementos la búsqueda binaria hace como mucho 3 comparaciones; con un millón, solo unas 20. Por eso es ideal para datos ordenados de gran tamaño.

Ordenamiento de burbuja

El ordenamiento de burbuja (bubble sort) compara parejas de elementos adyacentes y los intercambia si están en el orden equivocado. Los valores grandes "suben" hacia el final como burbujas.

Algoritmo Burbuja
    Definir a Como Entero
    Definir n, i, j, temp Como Entero

    // Llenar y suponer a[] ya con datos, n = longitud
    Para i <- 1 Hasta n - 1 Con Paso 1 Hacer
        Para j <- 1 Hasta n - i Con Paso 1 Hacer
            Si a[j] > a[j + 1] Entonces
                // Intercambiar
                temp <- a[j]
                a[j] <- a[j + 1]
                a[j + 1] <- temp
            FinSi
        FinPara
    FinPara

    Escribir "Arreglo ordenado:"
    Para i <- 1 Hasta n Con Paso 1 Hacer
        Escribir Sin Saltar a[i], " "
    FinPara
FinAlgoritmo

Para intercambiar dos variables siempre necesitas una variable auxiliar temp: guarda un valor, mueve el otro y coloca el primero. Sin la auxiliar perderías un dato.

El burbuja es fácil de entender pero lento con muchos datos (compara muchas veces). Es ideal para aprender; para arreglos grandes se usan ordenamientos más avanzados.

Número primo y factorial

Dos algoritmos clásicos de teoría de números muy usados en ejercicios.

Algoritmo EsPrimo
    Definir n, i Como Entero
    Definir primo Como Logico

    Escribir "Ingresa un número: "
    Leer n

    primo <- VERDADERO
    Si n <= 1 Entonces
        primo <- FALSO
    SiNo
        Para i <- 2 Hasta trunc(raiz(n)) Con Paso 1 Hacer
            Si n mod i = 0 Entonces
                primo <- FALSO
            FinSi
        FinPara
    FinSi

    Si primo Entonces
        Escribir n, " es primo"
    SiNo
        Escribir n, " no es primo"
    FinSi
FinAlgoritmo
Algoritmo Factorial
    Definir n, i, resultado Como Entero

    Escribir "Número: "
    Leer n
    resultado <- 1
    Para i <- 1 Hasta n Con Paso 1 Hacer
        resultado <- resultado * i
    FinPara
    Escribir "El factorial de ", n, " es ", resultado
FinAlgoritmo

Para saber si n es primo basta comprobar divisores hasta raiz(n): si hay algún divisor exacto, no es primo. Así el programa es mucho más rápido que probar todos los números.
