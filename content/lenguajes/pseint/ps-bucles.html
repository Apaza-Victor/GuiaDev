El bucle Mientras

El bucle Mientras repite un bloque mientras se cumpla una condición. Evalúa la condición antes de entrar; si es falsa desde el inicio, el bloque nunca se ejecuta.

Algoritmo Contar
    Definir i Como Entero
    i <- 1

    Mientras i <= 5 Hacer
        Escribir "Vuelta número: ", i
        i <- i + 1      // ¡no olvides aumentar el contador!
    FinMientras

    Escribir "Fin"
FinAlgoritmo
Algoritmo Suma1aN
    Definir n, i, suma Como Entero
    Escribir "¿Hasta qué número sumo?"
    Leer n

    suma <- 0
    i <- 1
    Mientras i <= n Hacer
        suma <- suma + i
        i <- i + 1
    FinMientras

    Escribir "La suma de 1 a ", n, " es: ", suma
FinAlgoritmo
Ver código PlantUML

El bucle Mientras en el diagrama de flujo

ParteSímboloQué hace
Condición i <= nRomboEvalúa si debe continuar; si es falsa, sale del bucle.
Bloque del bucleRectánguloInstrucciones que se repiten (suma e incremento).
RetornoFlecha de cicloVuelve a evaluar la condición tras cada vuelta.

Cuidado con el bucle infinito: si olvidas incrementar la variable de control (i <- i + 1), la condición nunca cambia y el bucle no termina. PSeInt te avisará y podrás detenerlo.

El bucle Repetir-Hasta Que

El bucle Repetir ejecuta el bloque al menos una vez y sigue repitiendo hasta que la condición se cumpla (es decir, repite mientras la condición sea falsa). Evalúa la condición al final.

Algoritmo CuentaRegresiva
    Definir i Como Entero
    i <- 5

    Repetir
        Escribir "Cuenta: ", i
        i <- i - 1
    Hasta Que i = 0

    Escribir "¡Despegue!"
FinAlgoritmo

Cuando necesitas que un menú se muestre siempre al menos una vez, Repetir es muy útil:

Algoritmo Menu
    Definir opcion Como Entero
    Repetir
        Escribir "1. Nuevo    2. Abrir    3. Salir"
        Leer opcion
    Hasta Que opcion = 3
    Escribir "Adiós"
FinAlgoritmo

Diferencia clave: Mientras puede no ejecutarse nunca; Repetir siempre se ejecuta como mínimo una vez. Usa Repetir para menús y validación de entrada.

El bucle Para

El bucle Para repite un número conocido de veces. Lleva una variable de control automática con un valor inicial, un valor final y un paso.

Algoritmo Tabla
    Definir i Como Entero

    // i empieza en 1, avanza hasta 10, sumando 1 cada vez
    Para i <- 1 Hasta 10 Con Paso 1 Hacer
        Escribir "2 x ", i, " = ", 2 * i
    FinPara
FinAlgoritmo

También puedes descender o usar otro paso:

// Descendente: 10, 9, 8, ..., 1
Para i <- 10 Hasta 1 Con Paso -1 Hacer
    Escribir i
FinPara

// Pares: 2, 4, 6, ... 20
Para i <- 2 Hasta 20 Con Paso 2 Hacer
    Escribir i
FinPara

Usa Para cuando sepas de antemano cuántas veces repetir (conteos, recorridos de listas con índice). Usa Mientras/Repetir cuando no lo sepas (validaciones, menús).

Bucles anidados

Igual que con los condicionales, puedes anidar bucles: un bucle dentro de otro. Es típico para tablas y matrices.

Algoritmo Cuadricula
    Definir fila, col Como Entero

    Para fila <- 1 Hasta 3 Hacer
        Para col <- 1 Hasta 3 Hacer
            Escribir "(", fila, ",", col, ")  "
        FinPara
        Escribir ""   // salto de línea al cambiar de fila
    FinPara
FinAlgoritmo

El bucle interno (col) se ejecuta por completo por cada vuelta del externo (fila). Resultado: (1,1) (1,2) (1,3) (2,1) ...

Mantén los bucles anidados en pocos niveles (2-3 máximo). Más niveles dificultan mucho la lectura y la depuración.

Ejercicios prácticos

Practica en orden. Cada ejercicio usa los conceptos de esta lección.

  1. Contar: usa Mientras para mostrar los números del 1 al 10.
  2. Suma: lee un número n y suma del 1 a n usando Mientras (luego haz el mismo con Para).
  3. Repetir: muestra un menú con Repetir que solo salga cuando el usuario escriba la opción de salir.
  4. Tabla: con Para muestra la tabla de multiplicar del 5 (del 1 al 12).
  5. Cuenta atrás: cuenta de 10 a 1 y muestra "¡Despegue!" usando Repetir.

En la próxima lección veremos subprocesos/funciones y ejercicios integradores que combinan todo lo aprendido.
