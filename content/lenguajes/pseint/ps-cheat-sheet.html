Palabras reservadas

Una palabra reservada es una palabra que no puedes usar como nombre de variable porque el lenguaje la usa para su propia sintaxis. En PSeInt la lista principal es:

CategoríaPalabrasQué hacen
Estructura del programaAlgoritmo, FinAlgoritmo, Proceso, FinProcesoAbren y cierran un programa.
VariablesDefinir, Dim, ComoDeclaran variables, arreglos y su tipo.
Tipos de datosEntero, Real, Cadena, Logico, CaracterDefinen el tipo de una variable.
Entrada / SalidaLeer, EscribirLeen datos y muestran resultados.
CondicionalesSi, Entonces, SiNo, FinSiToman decisiones.
Selección múltipleSegun, De Otro Modo, FinSegunEliges entre varias opciones.
BuclesMientras, FinMientras, Repetir, Hasta Que, Para, Hasta, Con Paso, Hacer, FinParaRepiten un bloque de código.
SubprocesosSubProceso, Funcion, FinSubProceso, FinFuncionDefinen trozos reutilizables de código.
Otrosy, o, noOperadores lógicos.

PSeInt no distingue mayúsculas de minúsculas: ESCRIBIR = escribir = Escribir. Por costumbre se usan mayúsculas de inicio para las palabras clave.

Sintaxis básica

Todo programa en PSeInt empieza con Algoritmo y termina con FinAlgoritmo. Dentro declaramos variables, leemos, procesamos y mostramos resultados.

Algoritmo ejemplo
    Definir nombre Como Cadena
    Escribir "¿Cómo te llamas?"
    Leer nombre
    Escribir "Hola, ", nombre
FinAlgoritmo
AcciónSintaxisEjemplo
Declarar variableDefinir var Como TipoDefinir edad Como Entero
Asignar valorvar <- valoredad <- 18
Leer del tecladoLeer varLeer edad
Mostrar en pantallaEscribir exprEscribir "Edad: ", edad

La asignación en PSeInt usa la flecha <- (menor-guion-mayor), no el signo =.

Los arreglos (vectores y tablas) se declaran con Dimension y sus índices empiezan en 1.

Definir notas Como Entero
Dimension notas[10]        // vector de 10 elementos
notas[1] <- 8              // primer elemento (índice 1)

Definir matriz Como Real
Dimension matriz[3,3]      // tabla 3x3

Definir a Como Entero
a <- (5 + 3) * 2      // 16, el paréntesis manda
Si (a > 10) y (a mod 2 = 0) Entonces

Estructuras de control

Condicional: Si / SiNo

Si condicion Entonces
    // código si es verdadera
SiNo
    // código si es falsa
FinSi

Selección múltiple: Segun

Segun valor Hacer
    1: Escribir "Uno"
    2: Escribir "Dos"
    De Otro Modo:
        Escribir "Otro"
FinSegun

Bucle: Mientras (condición al inicio)

Mientras condicion Hacer
    // se repite mientras la condición sea verdadera
FinMientras

Bucle: Repetir (condición al final, se ejecuta al menos una vez)

Repetir
    // se ejecuta al menos una vez
Hasta Que condicion

Bucle: Para (contador con paso)

Para i <- 1 Hasta 10 Con Paso 1 Hacer
    Escribir i
FinPara

En Para, el paso Con Paso es opcional: si no lo pones, avanza de 1 en 1. También puedes usar pasos negativos para contar hacia atrás.

Subprocesos y funciones

Los subprocesos agrupan código reutilizable. Pueden llamarse para ejecutar una tarea (SubProceso) o devolver un valor (Funcion).

SubProceso (sin devolver valor)

SubProceso Saludar(nombre)
    Escribir "Hola, ", nombre
FinSubProceso

Algoritmo principal
    Saludar("Ana")
FinAlgoritmo

Funcion (devuelve un valor)

Funcion area <- AreaCirculo(radio)
    area <- 3.1416 * radio ^ 2
FinFuncion

Algoritmo principal
    Definir r, a Como Real
    Escribir "Radio:"
    Leer r
    a <- AreaCirculo(r)
    Escribir "El área es ", a
FinAlgoritmo

En una Funcion, el resultado se devuelve asignando un valor al nombre de la función (en el ejemplo, area).

Conceptos importantes

ConceptoQué significa
AlgoritmoSecuencia ordenada y finita de pasos para resolver un problema.
PseudocódigoDescripción de un algoritmo con palabras cercanas al español, sin preocuparte por la sintaxis de un lenguaje real.
VariableCaja con nombre que guarda un valor que puede cambiar (ej. edad).
ConstanteValor fijo que no cambia durante el programa.
ExpresiónCombinación de operandos y operadores que produce un valor.
CondiciónExpresión lógica que da Verdadero o Falso.
Bucle / iteraciónRepetición de un bloque de código un número de veces.
AcumuladorVariable que va sumando (ej. total <- total + x).
ContadorVariable que cuenta vueltas (ej. i <- i + 1).
Banderín (flag)Variable lógica que indica si algo ya ocurrió.
DepuraciónProceso de encontrar y corregir errores en el código.

Truco: un contador cuenta (i <- i + 1), un acumulador suma valores (s <- s + valor). No los confundas.
