¿Qué es PSeInt?

PSeInt (PSeudocódigo Intérprete) es un software educativo gratuito creado por Marcelo D. Ibarra (Universidad Nacional de La Plata, Argentina) para aprender lógica de programación en español. Su objetivo es que te centres en la lógica del algoritmo y no en la sintaxis rígida de un lenguaje real, escribiendo en pseudocódigo en español.

Incluye un intérprete (ejecuta tus algoritmos paso a paso), un diagrama de flujo generado automáticamente y herramientas para depurar (ver el valor de las variables en cada línea). Es el estándar en muchas universidades hispanohablantes.

PSeInt no es un lenguaje de producción: es una herramienta pedagógica. Lo que aprendes aquí (variables, condiciones, bucles, funciones) se traslada casi idéntico a Python, Java o C.

Instalación

Instalar PSeInt es muy sencillo: solo descarga e instala el programa en tu sistema operativo.

# 1. Descarga el instalador desde la web oficial de PSeInt
#    (pseint.sourceforge.net) -> la sección "Descargar"
#    Elige la versión para tu SO (Windows / Linux / macOS)

# 2. Windows: ejecuta el .exe y acepta el asistente
#    - Instalador: PSeInt-Windows-x64.exe (siguiente, siguiente, instalar)

# 3. Linux (.deb / .rpm / AppImage / tarball)
#    - Debian/Ubuntu: sudo dpkg -i pseint*.deb
#    - Fedora:        sudo rpm -ivh pseint*.rpm
#    - AppImage:      chmod +x PSeInt*.AppImage && ./PSeInt*.AppImage
#    - Para otros SO: descomprime el tarball y ejecuta: ./pseint

# 4. macOS
#    - Descomprime el .dmg/.zip y arrastra la app a Aplicaciones

# 5. Verifica que se abrió el editor
#    - Debe abrirse la ventana de edición con la plantilla:
#      Algoritmo sin_titulo

Al abrir PSeInt por primera vez te preguntará por el Perfil de lenguaje y el nivel de enseñanza. Elige un perfil "Estricto" o "Flexible" según prefieras, y un nivel "Intermedio" para empezar cómodo. Puedes cambiarlo luego en Configurar → Opciones del lenguaje.

El entorno de PSeInt

La ventana de PSeInt tiene un editor donde escribes tu algoritmo y botones para ejecutar, depurar y ver el diagrama de flujo.

# Barra de herramientas principal:
#   [Editar] [Ejecutar] [Depurar] [Diagrama] [Configurar] [Ayuda]

# Botones más importantes:
#   ▶ Ejecutar (F9)      -> ejecuta el algoritmo completo
#   ⏭ Avanzar (F8)       -> ejecuta línea a línea (depuración)
#   �digramas / Diagrama  -> muestra el diagrama de flujo generado
#   Ver variables         -> panel con el valor actual de cada variable
#   Inspector de expresiones -> evalúa expresiones al vuelo

# Atajos de teclado útiles:
#   Ctrl+N  nuevo algoritmo     Ctrl+O  abrir
#   Ctrl+S  guardar             F9     ejecutar
#   F8      avanzar paso a paso  F10    paso a paso con entrada
#   Ctrl+Space  autocompletar

Cada vez que ejecutes un algoritmo, PSeInt convierte tu pseudocódigo a un diagrama de flujo en tiempo real. Observa cómo cambia el diagrama al modificar tu código: esa es una de sus mayores ventajas para aprender.

Tu primer algoritmo

Todo algoritmo en PSeInt empieza con la palabra Algoritmo y termina con FinAlgoritmo. Vamos a escribir el clásico "Hola mundo".

Algoritmo HolaMundo
    Escribir "Hola, mundo"
FinAlgoritmo

Al pulsar F9 verás en pantalla: Hola, mundo

Ahora un ejemplo un poco más completo que combina entrada de datos y salida formateada:

Algoritmo Saludo
    Definir nombre Como Cadena
    Escribir "¿Cómo te llamas?"
    Leer nombre
    Escribir "Hola, ", nombre, ", bienvenido a PSeInt"
FinAlgoritmo

Estructura de un algoritmo

ParteQué haceEjemplo
EncabezadoInicia el algoritmo y le da nombre.Algoritmo Saludo
DeclaraciónDefine las variables y su tipo.Definir nombre Como Cadena
EntradaLee datos del usuario.Leer nombre
SalidaMuestra resultados en pantalla.Escribir "Hola"
CierreTermina el algoritmo.FinAlgoritmo

Las palabras clave de PSeInt (Algoritmo, Definir, Como, Escribir, Leer, FinAlgoritmo) aparecen en azul en el editor. Escribir en mayúsculas o minúsculas es indiferente.

Ejercicios prácticos

Practica en orden, cada ejercicio asume lo aprendido en el anterior.

  1. Instalación: instala PSeInt y abre el editor con un algoritmo nuevo.
  2. Familiarízate: ejecuta el Algoritmo HolaMundo con F9.
  3. Diagrama: genera el diagrama de flujo de tu "Hola mundo" con el botón Diagrama.
  4. Entrada: escribe un algoritmo que pregunte tu nombre, lo lea con Leer y lo salude.
  5. Depuración: ejecuta tu saludo con F8 (paso a paso) y observa el panel de variables.

En la próxima lección veremos la sintaxis básica: variables, tipos de datos y operadores.
