Estructura básica de un algoritmo

Todo algoritmo sigue esta estructura general: encabezado, declaración de variables, cuerpo y cierre.

Algoritmo NombreDelAlgoritmo
    // 1. Encabezado: usamos 'Algoritmo' + un nombre

    // 2. Declaración de variables (opcional pero recomendable)
    Definir edad Como Entero

    // 3. Cuerpo: secuencia de instrucciones
    Escribir "Tu edad es: ", edad

    // 4. Cierre
FinAlgoritmo

Reglas de nombres: empiezan con letra, usan letras y números, sin espacios ni caracteres especiales (el guion bajo _ sí está permitido). PSeInt no distingue entre mayúsculas y minúsculas en los nombres ni en las palabras clave.

Los comentarios se escriben con // hasta el final de la línea. No se ejecutan; solo documentan tu código.

Tipos de datos

PSeInt tiene cinco tipos de datos básicos, los declaras con la instrucción Definir.

TipoDescripciónEjemplos
EnteroNúmeros enteros5, -3, 0, 400
RealNúmeros con decimales3.14, 2.5, -0.75
CaracterUn solo carácter'a', '5', ' '
CadenaTexto o conjunto de caracteres"Hola", "123"
LogicoValor de verdadVerdadero, Falso
Algoritmo Tipos
    // Declarar varias variables del mismo tipo en una línea
    Definir a, b, c Como Entero

    // O una sola
    Definir precio Como Real
    Definir inicial Como Caracter
    Definir nombre Como Cadena
    Definir activo Como Logico

    // Asignar valores
    a <- 10
    precio <- 19.99
    inicial <- 'V'
    nombre <- "GuiaDev"
    activo <- Verdadero
FinAlgoritmo

El operador de asignación en PSeInt es <- (flecha hacia la izquierda). También puedes usar = si lo prefieres, pero la flecha es la forma canónica y más clara.

---

Operadores

Los operadores permiten realizar cálculos y comparaciones. Se dividen en aritméticos, relacionales y lógicos.

// ARITMÉTICOS
//  +  suma          -  resta
//  *  multiplicación  /  división
//  ^  potencia      mod  módulo (resto)
//  Div  división entera

Definir x, y Como Real
x <- 10 / 3      // 3.333...
x <- 10 Div 3    // 3  (división entera)
x <- 10 mod 3    // 1  (resto de la división)
y <- 2 ^ 3       // 8  (potencia)

// RELACIONALES  (resultado Lógico)
//  =  igual        <>  distinto
//  >  mayor        <  menor
//  >= mayor o igual  <= menor o igual

// LÓGICOS  (trabajan con valores Lógicos)
//  y  AND    o  OR    no  NOT

La precedencia (orden de operación) es: paréntesis → potencias → multiplicación/división/mod → suma/resta → relacionales → lógicos.

mod es el módulo: el resto de dividir. Ejemplo: 10 mod 3 = 1 porque 3 cabe 3 veces en 10 (9) y sobra 1. Sirve mucho para saber si un número es par (x mod 2 = 0).

Entrada y salida de datos

Las dos instrucciones de comunicación con el usuario son Leer (entrada) y Escribir (salida).

Algoritmo EntradaSalida
    Definir n1, n2, suma Como Real

    // Salida: muestra un mensaje
    Escribir "Ingrese el primer número:"
    // Entrada: guarda lo que escriba el usuario en n1
    Leer n1

    Escribir "Ingrese el segundo número:"
    Leer n2

    suma <- n1 + n2
    Escribir "La suma es: ", suma

    // También puedes encadenar textos y valores
    Escribir "El resultado de ", n1, " + ", n2, " = ", suma

    // Salto de línea sin texto:
    Escribir ""
FinAlgoritmo

Escribir acepta varios argumentos separados por comas y concatena texto y variables. Puedes escribir varios valores sueltos o mezclarlos con cadenas entre comillas.

Ejercicios prácticos

Practica en orden. Cada ejercicio usa los conceptos de esta lección.

  1. Variables: declara una variable para tu edad (Entero), tu estatura (Real), tu inicial (Caracter) y si estudias (Logico); asígnales valor y muéstralas.
  2. Suma: lee dos números y muestra su suma, resta, multiplicación y división.
  3. Promedio: lee 3 notas y muestra el promedio (nota1* ?), (nota1+nota2+nota3)/3.
  4. Área: lee la base y la altura de un triángulo y calcula su área (base*altura/2).
  5. Paridad: lee un número y calcula el resto de dividirlo entre 2 usando mod.
