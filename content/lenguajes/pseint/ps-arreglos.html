Arreglos unidimensionales (vectores)

Un arreglo (o vector) es una colección de datos del mismo tipo que se guardan bajo un mismo nombre y se accede a ellos por un índice (posición). En PSeInt los índices empiezan en 1.

Algoritmo EjemploVector
    Definir notas Como Entero
    Dimension notas[5]

    // Asignar valores por índice
    notas[1] <- 7
    notas[2] <- 9
    notas[3] <- 5
    notas[4] <- 8
    notas[5] <- 10

    Escribir "La nota del alumno 3 es: ", notas[3]
FinAlgoritmo
Ver código PlantUML 
@startuml
start
:Leer n (cantidad de notas);
:Dimensionar arreglo notas[n];
:suma = 0;
repeat
  :Leer notas[i];
  :suma = suma + notas[i];
repeat while (i < n)
:promedio = suma / n;
:Mostrar promedio;
stop
@enduml

Para crear un arreglo necesitas dos pasos: declarar el tipo con Definir y reservar el tamaño con Dimension. Sin Dimension, el arreglo no tiene tamaño y PSeInt no sabrá cuántas posiciones guardar.

---

Recorrer y llenar un arreglo

Lo habitual es recorrer el arreglo con un bucle Para, tanto para llenarlo (leer datos) como para mostrarlo o procesarlo.

Algoritmo LlenarYMostrar
    Definir notas Como Entero
    Definir n, i Como Entero
    Escribir "¿Cuántas notas? "
    Leer n
    Dimension notas[n]

    // Llenar
    Para i <- 1 Hasta n Con Paso 1 Hacer
        Escribir "Nota ", i, ": "
        Leer notas[i]
    FinPara

    // Mostrar
    Para i <- 1 Hasta n Con Paso 1 Hacer
        Escribir "Alumno ", i, " - Nota: ", notas[i]
    FinPara
FinAlgoritmo

Usa la variable i como índice dentro del bucle: en la primera vuelta vale 1, en la segunda 2, y así hasta n. Así accedes a notas[i] en cada posición.

Arreglos bidimensionales (matrices)

Una matriz es un arreglo con filas y columnas. Para guardar una tabla (por ejemplo, calificaciones de varios alumnos en varias asignaturas) usas dos índices: matriz[fila][columna].

Algoritmo TablaCalificaciones
    Definir tabla Como Entero
    Definir f, c Como Entero
    Dimension tabla[3, 4]   // 3 filas (alumnos), 4 columnas (asignaturas)

    // Llenar
    Para f <- 1 Hasta 3 Con Paso 1 Hacer
        Para c <- 1 Hasta 4 Con Paso 1 Hacer
            Escribir "Alumno ", f, ", asig ", c, ": "
            Leer tabla[f, c]
        FinPara
    FinPara

    // Mostrar
    Para f <- 1 Hasta 3 Con Paso 1 Hacer
        Para c <- 1 Hasta 4 Con Paso 1 Hacer
            Escribir Sin Saltar tabla[f, c], "  "
        FinPara
        Escribir ""   // salto de fila
    FinPara
FinAlgoritmo

Conceptos de arreglos

ConceptoExplicaciónEjemplo en PSeInt
Posición o índiceNúmero que indica el lugar del elemento (empieza en 1).notas[1]
DimensiónNúmero de elementos reservados.Dimension notas[10]
VectorArreglo de una sola dimensión (una fila).Dimension v[5]
MatrizArreglo de dos dimensiones (filas y columnas).Dimension m[3, 4]
LongitudCantidad de elementos que contiene.Longitud(notas)

Cuidado con el índice fuera de rango: si accedes a notas[6] cuando la dimensión es 5, PSeInt lanzará un error. El índice debe estar siempre entre 1 y la dimensión.

Suma, promedio y máximo

Estas son las operaciones típicas sobre arreglos. La suma se acumula en una variable; el máximo se guarda comparando cada elemento.

Algoritmo Estadisticas
    Definir notas Como Entero
    Definir n, i, suma, maximo Como Entero
    Definir promedio Como Real

    Escribir "Número de notas: "
    Leer n
    Dimension notas[n]

    Para i <- 1 Hasta n Con Paso 1 Hacer
        Leer notas[i]
        // Acumular suma
        suma <- suma + notas[i]
        // Guardar máximo
        Si i = 1 O notas[i] > maximo Entonces
            maximo <- notas[i]
        FinSi
    FinPara

    promedio <- suma / n
    Escribir "Suma: ", suma
    Escribir "Promedio: ", promedio
    Escribir "Máximo: ", maximo
FinAlgoritmo

Para buscar el máximo: toma el primer elemento como valor inicial del máximo y luego compara cada uno. Los operadores relacionales (>, <) funcionan igual sobre arreglos.
