La estructura Si-Entonces

La estructura Si-Entonces ejecuta un bloque de instrucciones solo si se cumple una condición. Es la base para tomar decisiones en un algoritmo.

Algoritmo DecisiónSimple
    Definir edad Como Entero
    Escribir "Ingresa tu edad:"
    Leer edad

    // Si la condición es Verdadera, ejecuta el bloque
    Si edad >= 18 Entonces
        Escribir "Eres mayor de edad"
    FinSi

    Escribir "Fin del programa"
FinAlgoritmo

La condición siempre es una expresión que devuelve un valor Lógico (Verdadero o Falso). Después de Entonces va el bloque, que se cierra con FinSi.

El esquema general es: Si Entonces ... FinSi. Todo lo que esté entre Entonces y FinSi solo se ejecuta si la condición es verdadera.

---

Si-Entonces-SiNo

Cuando quieres hacer una cosa si se cumple y otra distinta si no, añades la rama SiNo.

Algoritmo ParOImpar
    Definir n Como Entero
    Escribir "Ingresa un número:"
    Leer n

    Si n mod 2 = 0 Entonces
        Escribir n, " es par"
    SiNo
        Escribir n, " es impar"
    FinSi

    Escribir "Fin"
FinAlgoritmo
Algoritmo Calificacion
    Definir nota Como Real
    Escribir "Ingresa tu nota (0-10):"
    Leer nota

    Si nota >= 5 Entonces
        Escribir "Aprobado"
    SiNo
        Escribir "Suspenso"
    FinSi
FinAlgoritmo

Ramas de un condicional

RamaPalabra claveCuándo se ejecuta
VerdaderaEntoncesSi la condición es Verdadera.
AlternativaSiNoSi la condición es Falsa (opcional).
CierreFinSiTermina el bloque condicional.

La palabra SiNo va en una sola pieza (no es "sino" del español, es SiNo). Representa la rama "en caso contrario".

---

Condicionales anidados

Puedes poner un Si dentro de otro para evaluar varias condiciones encadenadas.

Algoritmo Rango
    Definir n Como Entero
    Escribir "Ingresa un número:"
    Leer n

    Si n > 0 Entonces
        Escribir "Positivo"
    SiNo
        Si n < 0 Entonces
            Escribir "Negativo"
        SiNo
            Escribir "Es cero"
        FinSi
    FinSi
FinAlgoritmo

Observa que cada Si abre su propio bloque con su correspondiente FinSi. La indentación (sangría) te ayuda a ver qué bloque pertenece a qué Si.

Los anidados funcionan, pero demasiados niveles complican la lectura. Cuando son varias condiciones del tipo "si... si no si...", suele ser mejor usar Según (ver la siguiente sección).

---

La estructura Según

Cuando debes elegir entre muchas opciones según el valor de una misma variable, Según es más limpio que muchos Si anidados.

Algoritmo DiaDeLaSemana
    Definir dia Como Entero
    Escribir "Ingresa un número del 1 al 7:"
    Leer dia

    Segun dia Hacer
        1: Escribir "Lunes"
        2: Escribir "Martes"
        3: Escribir "Miércoles"
        4: Escribir "Jueves"
        5: Escribir "Viernes"
        6: Escribir "Sábado"
        7: Escribir "Domingo"
        De Otro Modo: Escribir "Número inválido"
    FinSegun
FinAlgoritmo

La cláusula De Otro Modo (el "default") es opcional y se ejecuta si el valor no coincide con ninguno de los casos.

Usa Según cuando compares una única variable contra muchos valores posibles. Usa Si cuando las condiciones sean relaciones complejas (por ejemplo, rangos o combinaciones con y/o).

Ejercicios prácticos

Practica en orden. Cada ejercicio usa los conceptos de esta lección.

  1. Mayor de edad: lee una edad y muestra si es mayor o menor de edad.
  2. Par/Impar: lee un número y muestra si es par o impar usando mod.
  3. Positivo/Negativo/Cero: lee un número y clasifícalo (usa condicionales anidados).
  4. Nota: lee una nota y muestra Aprobado (≥5) o Suspenso, y luego con Si anidados: Sobresaliente (≥9), Notable (≥7), Aprobado (≥5), Suspenso.
  5. Menú: usa Según para mostrar un menú de 4 opciones (1..4) y un mensaje distinto para cada una.

En la próxima lección veremos los bucles: Mientras, Repetir y Para.
