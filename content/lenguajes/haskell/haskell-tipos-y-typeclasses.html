Sistema de tipos

Haskell tiene tipado estático, fuerte e inferido: el compilador deduce tipos y rechaza el programa si no cuadran. Tipos básicos: números integrales (Int, Integer), punto flotante (Double, Float), booleanos, caracteres y cadenas, tuplas, listas y funciones.

ghci> :t 42
42 :: Num p => p

ghci> :t 3.14
3.14 :: Fractional p => p

ghci> :t 'a'
'a' :: Char

ghci> :t "abc"
"abc" :: [Char]      -- String es sinónimo de [Char]

ghci> :t (1, "dos")
(1, "dos") :: (Num b, Num a) => (a, b)

ghci> :t [1,2,3]
[1,2,3] :: Num a => [a]

-- Inferencia en definiciones
sumaLista [] = 0
sumaLista (x:xs) = x + sumaLista xs
ghci> :t sumaLista
sumaLista :: Num a => [a] -> a

Cuando ves Num a => significa "para CUALQUIER tipo a que sea instancia de Num". Hacemos sobrecarga por typeclasses en lugar de coercion.

---

Typeclasses (sobrecarga segura)

Una typeclass es una interfaz de funciones aplicable a tipos: Eq (comparación), Ord (orden), Show (convertir a string), Read (parsear), Num, Fractional... Definen el comportamiento en firma.

-- Eq
ghci> (== 3) 5
False
ghci> 5 >= 3
True

-- Show / Read
ghci> show 42
"42"
ghci> read "42" :: Int
42

-- Num / Fractional
ghci> 10 / 4        -- divide en Fractional: 2.5
2.5
ghci> 10 `div` 4    -- div es Integral: 2 (sin resto)

-- Ord: compare, sort, min, max
ghci> compare 3 5
LT
ghci> max 3 5
5

-- Definir tu propia typeclass
class TodoA string where
  hablar :: a -> String

instance TodoA Int where
  hablar n = "Número: " ++ show n

instance TodoA String where
  hablar s = "Text: " ++ s

ghci> hablar (5 :: Int)
"Número: 5"

Maybe: no más null

Adiós al null. Maybe a es Just valor o Nothing; el compilador te obliga a tratar la ausencia. Es la base de la seguridad de Haskell.

-- Definir un tipo de datos
data Color = Rojo | Verde | Azul deriving (Show, Eq)

-- Maybe como contenedor
ghci> Just 5
Just 5
ghci> Nothing
Nothing

-- Función que puede fallar
findIndex :: (a -> Bool) -> [a] -> Maybe Int
findIndex p lista =
  go 0 lista
  where
    go _ []       = Nothing
    go i (x:xs)
      | p x       = Just i
      | otherwise = go (i+1) xs

ghci> findIndex (> 4) [1,4,6]
Just 2
ghci> findIndex (> 10) [1,4,6]
Nothing

-- Extraer con seguridad
ghci> case (findIndex (>4) [1,4,6]) of
  |   Just i -> "índice " ++ show i
  |   Nothing -> "no existe"

Los tipos propios se crean con data Nombre = Constructor1 | Constructor2 .... deriving (Show, Eq) genera automáticamente su representación y comparación.

---

Tipos polimórficos y parámetros

Los tipos paramétricos (Maybe a, Either e a, [a]) funcionan para cualquier tipo a. La combinación de parámetros y typeclasses produce genéricos muy potentes.

-- Either: resultado o error
ghci> :t Left "algo falló"
"algo falló" :: Either [Char] b

ghci> :t Right 42
Right 42 :: Num a => Either b a

-- Uso típico: validación
validarEdad :: Int -> Either String Int
validarEdad n
  | n < 0    = Left "edad negativa"
  | n > 120  = Left "edad imposible"
  | otherwise = Right n

-- Tipos paramétricos definidos por ti
data Arbol a = Vacio | Nodo a (Arbol a) (Arbol a) deriving (Show)

altura :: Arbol a -> Int
altura Vacio         = 0
altura (Nodo _ l r)  = 1 + max (altura l) (altura r)

ghci> altura (Nodo 1 (Nodo 2 Vacio Vacio) Vacio)
2

-- newtype: envolver un tipo para darle significado
newtype Edad = Edad Int deriving (Show, Num)

Either a b es como un Maybe que puede explicar el fallo en Left. Los data pueden ser recursivos (árboles) y polimórficos. La firma lo dice todo.

---

newtype, deriving y seguridad

Con newtype enriqueces tipos básicos con significado sin coste en run-time, y con deriving generas instancias de typeclass automáticamente: así construyes "tipos que no se pueden confundir".

newtype Precio = Precio Double deriving (Show, Eq, Num)
newtype Unidades = Unidades Int deriving (Show, Eq, Num)

-- No puedes asignar un Precio a una Unidades sin convertir:
-- la firma lo prohíbe → error en compilación
total :: Precio -> Unidades -> Precio
total (Precio p) (Unidades u) = Precio (p * fromIntegral u)

ghci> total (Precio 2.5) (Unidades 3)
Precio 7.5

-- deriving genera instancias de Eq, Ord, Show, Read, Enum, Bounded...
data Semana = Lun | Mar | Mie deriving (Show, Eq, Ord, Enum)

ghci> show Lun
"Lun"
ghci> Lun == Lun
True
ghci> succ Lun
Mar

"Make illegal states unrepresentable": que el compilador impida usar el tipo incorrecto es lo que hace confiables los programas Haskell. Es el mismo espíritu que luego verás en Rust y otros lenguajes de tipos "advanced" modernos.

Ejercicios prácticos

Practica en orden: cada ejercicio asumo lo aprendido en el anterior.

  1. Tipos: consulta :t de head, init, (:) y read; escribe su significado.
  2. Typeclass: usa sort, maximum, show y read sobre valores Num y desciende qué typeclass requieren.
  3. Maybe: escribe saferoot :: Double -> Maybe Double (Nothing si es negativo).
  4. Either: valida un Int con Either String Int y maneja ambos casos.
  5. newtype: define newtype Celsius y newtype Farenheit con deriving y una conversión segura.
