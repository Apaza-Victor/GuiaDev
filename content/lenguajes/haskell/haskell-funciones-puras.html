Funciones puras

En Haskell todo es una función pura: mismos argumentos, mismo resultado, sin efectos externos. La definición más simple es nombre arg1 arg2 = expresión, con espacio (no paréntesis) para llamar.

-- Definición con prefijo
sumar a b = a + b

-- Llamar con espacio: sumar 2 3  ⟶  5
-- Llamar con paréntesis para agrupar: sumar (sumar 1 2) 3

duplicar x = 2 * x
areaCirculo r = pi * r * r
esPar n = n `mod` 2 == 0      -- notación infija con `nombre`

-- las funciones se tratan como valores: se pasan, se retornan
aplicar f x = f x
ghci> aplicar duplicar 5
10

-- Todas las funciones de Haskell están "currificadas":
sumar a b = a + b    -- es realmente  (+ b) = (\b -> a + b)

-- Razonar: sumar 2 3 == (sumar 2) 3
-- ✓ transparencia referencial

La "currificación" significa que una función de dos argumentos es una función de uno que devuelve otra función de uno. Eso es lo que abre la puerta a aplicación parcial y composición.

---

Firmas de tipo

Cada función tiene una firma: nombre :: tipoEntrada -> tipoSalida. Haskell infiere los tipos, pero escribir la firma documenta mejor y ayuda al compilador.

-- Tipos básicos: Int, Integer, Double, Bool, Char, String
saluda :: String -> String
saluda nombre = "Hola, " ++ nombre

dobleInt :: Int -> Int
dobleInt x = 2 * x

suma :: Int -> Int -> Int      -- dos entradas, una salida
suma a b = a + b

-- Genéricos: letras minúsculas son "tipo variables"
miIdentidad :: a -> a
miIdentidad x = x

ghci> :t miIdentidad
miIdentidad :: a -> a

-- Tuplas y listas en firmas
par :: (Int, Char) -> String
par (n, c) = show n ++ [c]

La flecha -> es asociativa a la derecha: suma :: Int -> (Int -> Int). Por eso suma 2 es una función que espera un Int. GHCi te devuelve suma 2 :: Int -> Int — lo verás seguido.

---

Guardas (guards) y casos

Para decidir se usan guardas (| condición = resultado) o pattern matching en la definición. Todo se expresa con funciones, no con sentencias if.

-- Guardas
clasificar :: Int -> String
clasificar n
  | n >= 18                          = "adulto"
  | n >= 0                           = "menor"
  | otherwise                        = "inválido"

-- otherwise ≡ True

-- Pattern matching en argumentos
diaTipo :: String -> String
diaTipo "sábado" = "fin de semana"
diaTipo "domingo" = "fin de semana"
diaTipo _ = "laboral o desconocido"

-- if ... then ... else (expresión, no sentencia)
paridad :: Int -> String
paridad n = if even n then "par" else "impar"

ghci> paridad 7
"impar"
ghci> clasificar 20
"adulto"

Los patrones con _ (comodín) capturan "todo lo demás". El orden importa: el compilador evalúa de arriba a abajo. Por eso el caso genérico va al final.

---

Operator sections

Los operadores también son funciones. Una sección (+1, (>3), (`div` 7)) fija un argumento y devuelve una función parcialmente aplicada: ideal para pasar a map/filter.

-- Secciones: aplicar parcialmente con paréntesis
sumaDiez = (+ 10)
ghci> sumaDiez 5
15

-- Aplicación parcial de una función cualquiera (currificación)
dobleLista = map (* 2)
ghci> dobleLista [1,2,3]
[2,4,6]

-- Secciones útiles con filtros
mayoresDe10 = filter (> 10)
ghci> mayoresDe10 [5, 12, 3, 20]
[12,20]

-- Uso de operadores como valores
ghci> :t (+)   -- (+) :: Num a => a -> a -> a
ghci> foldl (+) 0 [1..5]
15

-- Sección con función infija
multiplicarPor7 = (* 7)

(- 3) es AMBIGUO (número negativo o sección); Haskell lo interpreta como número. Para una sección que resta usa subtract 3. Esa es la única excepción famosa.

Composición de funciones

El operador (.) compone dos funciones: (f . g) x = f (g x). La composición permite expresar pipelines declarativos "de derecha a izquierda".

doble :: Int -> Int
doble x = 2 * x

masUno :: Int -> Int
masUno x = x + 1

-- Composición
funcion = doble . masUno
ghci> funcion 3
8    -- doble (masUno 3) = doble 4 = 8

-- Pipeline "natural": (f . g) x = f(g x)
siguienteCuadrado = cuadrado . masUno
  where cuadrado x = x * x
ghci> siguienteCuadrado 4
25

-- Aplicación con $ (menor precedencia)
ghci> doble (masUno (masUno 3))
10
ghci> doble $ masUno $ masUno 3
10    -- $ evita paréntesis

-- $ es "aplicar con baja precedencia": x $ f  ==  f x
-- Común: print $ f $ g 3

. compone funciones (como la pipa de operaciones); $ evita paréntesis. Juntos te permiten escribir pipelines sin anidamiento. Práctica recomendada: map (f . g) no map (\x -> f (g x)).

Ejercicios prácticos

Practica en orden: cada ejercicio asume lo aprendido en el anterior.

  1. Funciones puras: define esDivisible n d = n `mod` d == 0 y apruébala en GHCi.
  2. Firmas: escribe firmas completas para saluda, suma y una genérica swapPair (a,b) = (b,a).
  3. Guardas: implementa nota :: Int -> Char con guardas (A: >=18, B: >=14, C: >=10, D: otro).
  4. Secciones: por secciones, filter (== 5), map (+1), map (`div` 2) sobre una lista.
  5. Composición: define procesa = sort . filter (> 5) y pruébala en GHCi.
