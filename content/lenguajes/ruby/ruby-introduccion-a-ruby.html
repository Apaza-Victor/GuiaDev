¿Qué es Ruby?

Ruby es un lenguaje de programación interpretado, de propósito general y de código abierto, creado por Yukihiro "Matz" Matsumoto en 1995. Su filosofía principal es que la programación debe ser natural y divertida, priorizando la productividad del desarrollador por encima de la velocidad de ejecución.

Ruby combina lo mejor de varios paradigmas: es orientado a objetos (todo es un objeto), imperativo y funcional. Su sintaxis es elegante y cercana al inglés, gracias a su regla de convención sobre configuración.

# Hola mundo en Ruby, una sola línea
puts "Hola, mundo"

# Ruby es muy expresivo: mirá cuán legible es esto
5.times { |i| puts "Iteración número #{i + 1}" }
CaracterísticaDetalle
ParadigmaOrientado a objetos, funcional e imperativo
TipadoDinámico y fuerte
RendimientoInterpretado (CRuby), con JIT desde la versión 3
UsosWeb (Rails), scripting, automatización, data science

El lema oficial de Ruby (escrito en japonés) es "el lenguaje de la felicidad del programador". Matz diseñó el lenguaje pensando en minimizar el esfuerzo mental para quienes lo usan.

Instalación y gestión de versiones (rbenv/RVM)

Para instalar Ruby lo más recomendable es usar un gestor de versiones como rbenv o RVM. Así podrás instalar varias versiones de Ruby y cambiar entre ellas sin afectar el sistema. En Linux y macOS el flujo típico es el siguiente.

Con rbenv podés instalar versiones, establecer una versión global y una versión local por proyecto de forma limpia y sin permisos de administrador.

# Instalar rbenv (macOS con Homebrew)
brew install rbenv

# Instalar una versión de Ruby
rbenv install 3.3.0

# Establecer la versión global
rbenv global 3.3.0

# Verificar la instalación
ruby -v

En Windows se recomienda RubyInstaller (con DevKit) o usar WSL. El gestor de versiones nativo de Windows es menos maduro, aunque rbenv ya funciona bien bajo WSL.

HerramientaVentaja principalIdeal para
rbenvLigero, sin scripts en el shellProyectos que necesitan versiones distintas
RVMGestiona gemsets por proyectoEntornos con muchos gems y aislamiento
RubyInstallerInstalador gráfico para WindowsUsuarios de Windows sin WSL

No instales Ruby con sudo apt-get install ruby en distribuciones de Linux si pensás usar bundler para proyectos serios: la versión del repositorio suele estar desactualizada y puede traer conflictos con librerías nativas.

El REPL: irb y pry

Un REPL (Read-Eval-Print Loop) es una consola interactiva que lee código, lo ejecuta y muestra el resultado de inmediato. El REPL por defecto de Ruby se llama irb (Interactive Ruby) y viene incluido con la instalación estándar.

irb es ideal para probar expresiones, explorar métodos y depurar fragmentos de código sin crear archivos.

$ irb
irb(main):001:0> 2 + 3
=> 5
irb(main):002:0> "ruby".upcase
=> "RUBY"
irb(main):003:0> Time.now
=> 2026-08-28 12:00:00 -0300

pry es una alternativa más potente a irb, con resaltado de sintaxis, autocompletado, navegación de código y soporte para ver documentación al instante.

# Instalar pry como gem
gem install pry

# Usarlo como reemplazo de irb
pry
[1] pry(main)> %w[hola mundo].join(" ")
=> "hola mundo"

En irb, presioná Tabulador dos veces tras un objeto y un punto para explorar todos sus métodos disponibles. Es la forma más rápida de descubrir la API del lenguaje.

Tu primer programa

Vamos a crear un programa real. Guardá el siguiente código en un archivo llamado saludo.rb y ejecutalo con ruby saludo.rb.

Este programa solicita un nombre, lo guarda en una variable y muestra un saludo personalizado con la hora actual.

# saludo.rb
puts "¿Cuál es tu nombre?"
nombre = gets.chomp

hora = Time.now.hour
if hora < 12
  saludo = "Buenos días"
elsif hora < 19
  saludo = "Buenas tardes"
else
  saludo = "Buenas noches"
end

puts "#{saludo}, #{nombre}. Bienvenido a Ruby!"

Al ejecutarlo, el programa espera que ingreses tu nombre y luego responde según la franja horaria del día.

$ ruby saludo.rb
¿Cuál es tu nombre?
María
Buenas noches, María. Bienvenido a Ruby!

gets lee una línea de la terminal (incluyendo el salto de línea) y .chomp elimina ese salto de línea final. Al ejecutar el archivo, la salida real es similar a la mostrada arriba, dependiendo de la hora del día.

puts, p y print

Ruby ofrece varias formas de mostrar datos en pantalla, y cada una tiene un comportamiento distinto. Conocer la diferencia es clave para leer la salida y para depurar tu código.

puts imprime el valor y agrega un salto de línea al final. print imprime sin salto de línea. p imprime una representación "técnica" (incluye comillas en strings y tipos) y agrega salto de línea.

# Cada forma muestra el valor de manera distinta
puts "hola"     # => hola
print "hola"    # => hola (sin salto de línea)
p "hola"        # => "hola" (con comillas)

puts 10         # => 10
p 10            # => 10
MétodoSalto de líneaRepresentaciónUso típico
putsSíLegibleMostrar mensajes al usuario
printNoLegibleConstruir texto sin saltos
pSíTécnica (inspección)Depurar y ver tipos

Usá p en lugar de puts cuando depures code: p te muestra las comillas de los strings y hasta objetos anidados, lo que hace evidente el tipo real del valor.

# Diferencia con arrays y objetos
puts [1, 2, 3]   # imprime cada elemento en una línea
p [1, 2, 3]      # => [1, 2, 3]

Regla mental rápida: puts es para el usuario final, p es para el programador que está depurando. Elegí uno según quién va a leer esa salida.

Ejercicios prácticos

Practicá los conceptos de esta lección ejecutando cada programa con ruby archivo.rb.

  1. Creá un programa que pida tu edad con gets y muestre cuántos días has vivido aproximadamente.
  2. Usá p y puts para mostrar el mismo string y explicá en un comentario la diferencia visible.
  3. Escribí un script que imprima una tabla de multiplicar con puts y sin usar bucles explícitos.
  4. Instalá pry con gem y hacé cinco operaciones distintas dentro del REPL.
  5. Creá un programa que salude con "hola" usando print repetido para formar la palabra sin saltos de línea.
