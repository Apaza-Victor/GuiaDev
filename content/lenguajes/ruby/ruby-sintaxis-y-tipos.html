Variables y constantes

En Ruby las variables se declaran simplemente asignándoles un valor, sin necesidad de indicar su tipo. El lenguaje usa convenciones de nombres que determinan el tipo de identificador según cómo empiece.

Las variables en minúsculas o con guion bajo son variables locales. Las que empiezan en mayúscula son constantes, y Ruby te advertirá si intentás reasignarlas.

nombre = "Ada"          # variable local
edad = 36               # tipo entero
pi = 3.1416             # tipo flotante
Activo = true           # constante (empieza con mayúscula)

Activo = false          # Warning: constant already initialized
# => warning: already initialized constant

Las variables globales con $ son poco recomendadas: al ser visibles desde cualquier parte del programa dificultan el mantenimiento. Preferí variables de instancia o locales.

Números y operadores

Ruby maneja dos tipos numéricos principales: Integer (enteros de precisión arbitraria) y Float (punto flotante). También ofrece operadores aritméticos, de comparación y de asignación directos y muy legibles.

Los enteros en Ruby no tienen límite práctico de tamaño, algo que facilita cálculos aritméticos grandes sin preocuparse por desbordes.

entero = 42
flotante = 3.14

puts 5 + 3   # => 8
puts 5 - 3   # => 2
puts 5 * 3   # => 15
puts 5 / 2   # => 2  (división entera)
puts 5 / 2.0 # => 2.5
puts 5 % 2   # => 1  (módulo o resto)
puts 2 ** 10 # => 1024 (potencia)

a = 10
a += 5   # equivale a a = a + 5 => 15
a -= 3   # => 12
a *= 2   # => 24
a /= 4   # => 6

puts a           # => 6
puts 7 < 6       # => false
puts 10 >= 5     # => true
puts 10 == 10.0  # => true (comparación de valor)

La división de dos enteros trunca el resultado (5 / 2 da 2, no 2.5). Para obtener decimales, al menos uno de los operandos debe ser un Float, por ejemplo 5 / 2.0.

Strings e interpolación

Un string es una secuencia de caracteres. Se crea con comillas simples o dobles. La diferencia clave es que las comillas dobles permiten interpolación: insertar el valor de variables o expresiones dentro del texto con #{...}.

Los strings son flexibles y tienen decenas de métodos: upcase, downcase, capitalize, length, reverse, entre otros.

nombre = "Ada"
puts "Hola, #{nombre}"     # => Hola, Ada
puts 'Hola, #{nombre}'     # => Hola, #{nombre} (sin interpolar)

puts "3 + 4 = #{3 + 4}"    # => 3 + 4 = 7
puts "ruby".upcase         # => RUBY
puts "ruby".capitalize     # => Ruby
puts "ruby".length         # => 4
puts "ruby".reverse        # => ybur

Símbolos y booleanos

Un símbolo es un identificador inmutable precedido por dos puntos (:nombre). A diferencia de los strings, los símbolos siempre referencian al mismo objeto, por lo que se comparan muy rápido y son ideales como claves.

Los booleanos son true y false, y en Ruby todo valor tiene un valor de verdad: solo false y nil se consideran "falsy".

clave = :usuario
puts clave.class        # => Symbol
puts :a == :a           # => true
puts "a".equal?("a")    # => false (strings distintos)
puts :a.equal?(:a)      # => true (mismo símbolo)

puts true.class         # => TrueClass
puts false.class        # => FalseClass

if 0
  puts "0 es truthy en Ruby"   # => 0 es truthy en Ruby
end

En Ruby, a diferencia de otros lenguajes, 0 y los strings vacíos son truthy. Solo nil y false evaluan como falso en una condición.

nil y "todo es un objeto"

nil es un objeto que representa "nada" o ausencia de valor. Es lo que obtenés al referenciar una variable no definida o al llamar a un método que no devuelve nada. La regla de oro de Ruby es que todo es un objeto, incluso los números, los booleanos y el propio nil.

Como todo es objeto, cualquier valor tiene métodos y clase. Esto unifica el lenguaje y aporta consistencia.

puts 5.class          # => Integer
puts 3.14.class       # => Float
puts nil.class        # => NilClass
puts true.class       # => TrueClass
puts [].class         # => Array

puts 5.even?          # => true
puts 5.to_s           # => "5"
puts nil.nil?         # => true
puts 123.nil?         # => false

variable = nil
puts variable         # => (vacío)
puts variable.nil?    # => true

Llamar un método sobre nil que no existe, por ejemplo nil.upcase, lanza NoMethodError. Usá el operador de navegación segura variable&.metodo para evitar errores al encadenar métodos.

Comprender que "todo es un objeto" simplifica muchísimo el aprendizaje: si sabés los métodos que tiene un tipo, podés deducir el comportamiento de cualquier valor de ese tipo.

Ejercicios prácticos

Resolvé estos ejercicios en archivos .rb y ejecutalos con ruby archivo.rb.

  1. Creá tres variables (string, número y float) y mostrá la clase de cada una con p.
  2. Escribí un programa que calcule el área de un círculo a partir de un radio constante definido como constante.
  3. Creá un string con un nombre y mostrá cuántas letras tiene, su versión en mayúsculas y su reverso.
  4. Usá símbolos y compará con equal? dos símbolos iguales y dos strings iguales para notar la diferencia.
  5. Mostrá qué objetos son truthy y cuáles falsy evaluando 0, "", nil y false en una condición con if.
