¿Qué es una gem?

Una gem es un paquete de código Ruby listo para instalar y reutilizar, similar a una librería o módulo. Contiene código, metadatos (versión, autor, licencia) y dependencias. Se distribuyen a través de RubyGems, el gestor de paquetes oficial.

El comando gem install <nombre> instala una gem, y el código de Ruby la carga con require. Algunas gems vienen incluidas en la biblioteca estándar.

# Ver la versión de RubyGems
gem --version

# Instalar una gem
gem install colorize

# Listar gems instaladas
gem list

require "colorize"

puts "¡Mensaje en verde!".colorize(:green)
puts "¡Mensaje en rojo!".colorize(:red)
puts "Esto es Ruby colorido".colorize(:blue).bold
ComandoDescripción
gem install xInstala la gem x
gem uninstall xDesinstala la gem x
gem listLista gems instaladas
gem info xMuestra información de la gem x

Explorá el RubyGems (rubygems.org) para descubrir miles de gems listas para usar: desde manejo de JSON y HTTP hasta análisis de datos y frameworks web.

Bundler y el Gemfile

Bundler gestiona las dependencias de un proyecto Ruby. En lugar de instalar gems manualmente, declarás las que necesitás en un archivo Gemfile y Bundler las instala y mantiene versiones consistentes.

El Gemfile es el corazón de un proyecto Ruby: allí se listan las gems y sus versiones. Luego bundle install instala todas las dependencias con sus versiones exactas.

# Gemfile
source "https://rubygems.org"

gem "sinatra"
gem "json", "~> 2.6"
gem "rake", group: :development

# Instalar dependencias declaradas en el Gemfile
bundle install

# Ejecutar un archivo con el entorno de Bundler cargado
bundle exec ruby app.rb

# Añadir una gem nueva con Bundler
bundle add httparty

El operador ~> en una versión (como ~> 2.6) permite actualizaciones menores pero bloquea cambios mayores. El archivo Gemfile.lock congela las versiones exactas para que el proyecto sea reproducible.

Siempre ejecutá tu aplicación con bundle exec ruby archivo.rb para garantizar que use las versiones del Gemfile.lock y no las instaladas globalmente.

Scripts útiles con File y Regex

Ruby es excelente para scripting: leer archivos, procesar texto y generar reportes. La clase File permite leer y escribir archivos, y las expresiones regulares (Regex) permiten buscar y extraer patrones de texto.

Con estas herramientas puedes automatizar tareas como validar formatos, contar ocurrencias o transformar archivos de configuración.

# Leer un archivo línea por línea
File.foreach("datos.txt") do |linea|
  puts linea.strip
end

# Escribir en un archivo
File.write("salida.txt", "Contenido generado por Ruby\n")
puts File.exist?("salida.txt")   # => true

# Expresiones regulares para validar y extraer
email = "contacto@guia.dev"
puts email =~ /\A[\w\.]+@[\w\.]+\.\w+\z/   # => 0 (posición del match)

texto = "Llama al 351-123-4567 o escribe a soporte@guia.dev"
puts texto.scan(/\d{3}-\d{3}-\d{4}/).inspect   # => ["351-123-4567"]
puts texto.scan(/[\w\.]+@[\w\.]+/).inspect      # => ["soporte@guia.dev"]
Clase/PatrónUso
File.readLeer todo el contenido
File.foreachLeer línea por línea
File.writeEscribir contenido
=~ o matchBuscar un patrón regex

Usá File.foreach en lugar de File.read para archivos grandes: lee de a una línea por vez y no carga todo el archivo en memoria.

Testing con Minitest

El testing es fundamental en la cultura Ruby. Minitest es el framework de pruebas que viene incluido con Ruby, ideal para escribir y ejecutar tests de forma simple y rápida.

Un test verifica que una porción de código se comporta como se espera. Los tests se agrupan en clases que heredan de Minitest::Test, con métodos que empiezan en test_.

# calculadora.rb
def sumar(a, b)
  a + b
end

# test_calculadora.rb
require "minitest/autorun"
require_relative "calculadora"

class TestCalculadora < Minitest::Test
  def test_suma_de_dos_numeros
    assert_equal 5, sumar(2, 3)
  end

  def test_suma_con_negativos
    assert_equal 0, sumar(-2, 2)
  end
end

$ ruby test_calculadora.rb
Run options: --seed 62137
2 runs, 2 assertions, 0 failures, 0 errors, 0 skips

Convención: escribís la lógica en un archivo y los tests en test_nombre.rb, usando assert_equal esperado, actual. Una suite de tests que pasa te da confianza para refactorizar sin romper nada.

Una mirada a Ruby on Rails

Ruby on Rails (simplemente "Rails") es el framework web más famoso escrito en Ruby. Sigue el patrón MVC (Modelo-Vista-Controlador) y su filosofía de convención sobre configuración permite crear aplicaciones web completas con muy poco código.

Con Rails se construyen sitios, APIs y aplicaciones de todo tipo. Al crear un proyecto, Rails genera una estructura de carpetas organizada con modelos, controladores, vistas, rutas y tests.

# Crear una nueva aplicación Rails
rails new blog

# Levantar el servidor de desarrollo
cd blog
rails server

# app/controllers/posts_controller.rb
class PostsController < ApplicationController
  def index
    @posts = Post.all
  end

  def show
    @post = Post.find(params[:id])
  end
end

# app/models/post.rb
class Post < ApplicationRecord
  validates :titulo, presence: true, length: { minimum: 5 }
  validates :cuerpo, presence: true
end

Rails incluye ActiveRecord (ORM para bases de datos), ActionController (lógica HTTP) y ActionView (plantillas), además de migraciones, generadores y el sistema de assets. Es un ecosistema completo.

Si te interesa el desarrollo web con Ruby, Rails es el siguiente paso natural tras dominar el lenguaje base. Empezá con rails new blog y seguí la guía oficial.

Ejercicios prácticos

Integrá todos los conocimientos de Ruby resolviendo estos ejercicios con el ecosistema de gems.

  1. Instalá la gem colorize y creá un script que imprima mensajes con distintos colores según el nivel de severidad.
  2. Creá un Gemfile con las gems json y httparty, ejecutá bundle install y luego bundle exec ruby app.rb.
  3. Escribí un script que lea un archivo de texto y cuente cuántas palabras contiene usando File.foreach y split.
  4. Usá una expresión regular para extraer todos los números de teléfono de un texto y mostrarlos formateados.
  5. Escribí y ejecutá tests con Minitest para una función es_palindromo? que verifiques con al menos tres casos.

¡Felicitaciones por completar el curso de Ruby! Ya conoces la sintaxis, los tipos, el control de flujo, la programación orientada a objetos, las colecciones y el ecosistema de gems. El siguiente paso es construir tu primer proyecto completo con Rails.
