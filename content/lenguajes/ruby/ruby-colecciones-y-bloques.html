Arreglos y operaciones

Un arreglo (Array) es una colección ordenada de elementos que puede mezclar tipos. Se crea con corchetes y se accede a sus elementos con índices enteros, donde el primer elemento es el índice 0.

Los arreglos en Ruby son dinámicos: crecen según se agregan elementos y ofrecen decenas de métodos para manipularlos.

frutas = ["manzana", "banana", "pera"]
puts frutas[0]        # => manzana
puts frutas[-1]       # => pera (último)
puts frutas.first     # => manzana
puts frutas.last      # => pera

frutas << "uva"        # agregar al final
frutas.push("kiwi")
puts frutas.inspect   # => ["manzana", "banana", "pera", "uva", "kiwi"]

puts frutas.length    # => 5
puts frutas.include?("uva")   # => true
puts frutas.sort.inspect      # => ["banana", "kiwi", "manzana", "pera", "uva"]

numeros = [3, 1, 4, 1, 5]
puts numeros.sum       # => 14
puts numeros.max       # => 5
puts numeros.min       # => 1
puts (numeros << 9).inspect  # => [3, 1, 4, 1, 5, 9]
MétodoDescripciónEjemplo
<<Agrega al finalarr << x
push/popAgregar/quitar al finalarr.pop
first/lastPrimer/último elementoarr.last
sortOrdena (devuelve copia)arr.sort

El índice negativo cuenta desde el final: arr[-1] es el último elemento y arr[-2] el penúltimo. Es una de las comodidades que más se agradecen en Ruby.

Hashes y símbolos

Un hash es una colección de pares clave-valor, similar a un diccionario. Se define con llaves y cada entrada asocia una clave (suele ser un símbolo) con un valor.

Como los símbolos se comparan rápido y son inmutables, se usan muchísimo como claves de hash. Desde Ruby 1.9 existe una sintaxis concisa con clave:.

persona = { nombre: "Ana", edad: 30, ciudad: "Córdoba" }

puts persona[:nombre]         # => Ana
puts persona[:edad]           # => 30

persona[:profesion] = "Médica"
puts persona.keys.inspect     # => [:nombre, :edad, :ciudad, :profesion]
puts persona.values.inspect   # => ["Ana", 30, "Córdoba", "Médica"]
puts persona.key?(:edad)      # => true
puts persona.fetch(:pais, "Argentina")   # => Argentina (default)

# Iterar sobre un hash
persona.each do |clave, valor|
  puts "#{clave}: #{valor}"
end
# => nombre: Ana
# => edad: 30
# => ciudad: Córdoba

Preferí símbolos como claves (persona[:edad]) en lugar de strings (persona["edad"]): son más rápidos y la sintaxis clave: resulta más limpia.

Bloques, Proc y lambdas

Un bloque es un fragmento de código que se pasa a un método entre do...end o llaves { }. Muchísimos métodos de Ruby aceptan bloques para ejecutar acciones sobre cada elemento.

Para guardar un bloque y reutilizarlo se convierten a Proc (objeto Proc) o a lambda. La diferencia clave es que la lambda valida la cantidad de argumentos y su return solo sale de la lambda.

[1, 2, 3].each { |n| puts n * 2 }
# => 2
# => 4
# => 6

[1, 2, 3].each do |n|
  puts "Valor: #{n}"
end
# => Valor: 1
# => Valor: 2
# => Valor: 3

doble = Proc.new { |x| x * 2 }
puts doble.call(5)      # => 10

triple = lambda { |x| x * 3 }
puts triple.call(4)     # => 12

Un Proc no verifica la cantidad de argumentos (doble.call sin argumentos pone nil), mientras que una lambda sí lanza error. Usá lambdas si necesitás esa validación.

Enumerable: map, select, reduce

El módulo Enumerable provee métodos de itera­ción potentes a todas las colecciones (arrays, hashes y rangos). Los más usados son map (transformar), select (filtrar) y reduce (acumular).

Estos métodos no modifican el arreglo original, sino que devuelven un nuevo arreglo con el resultado. Es el estilo funcional de Ruby.

numeros = [1, 2, 3, 4, 5]

cuadrados = numeros.map { |n| n * n }
puts cuadrados.inspect      # => [1, 4, 9, 16, 25]

pares = numeros.select { |n| n.even? }
puts pares.inspect          # => [2, 4]

suma = numeros.reduce(0) { |acc, n| acc + n }
puts suma                   # => 15

nombres = ["ana", "juan", "maria"]
puts nombres.map(&:capitalize).inspect   # => ["Ana", "Juan", "Maria"]

mas_de_3 = nombres.select { |n| n.length > 3 }
puts mas_de_3.inspect                      # => ["juan", "maria"]

Dominá map, select y reduce y resolverás la mayoría de los algoritmos sobre colecciones sin escribir bucles manuales. Son la base de la programación funcional en Ruby.

Métodos con y sin bang (!)

Muchos métodos de Ruby tienen dos variantes: una no destructiva que devuelve un nuevo objeto sin tocar el original, y una destructiva con un signo de exclamación (!) que modifica el objeto en el lugar.

El "bang" indica que el método cambia el receptor. Es importante distinguirlos para no alterar datos sin querer.

a = [3, 1, 2]

b = a.sort
puts a.inspect   # => [3, 1, 2]  (original intacto)
puts b.inspect   # => [1, 2, 3]

a.sort!
puts a.inspect   # => [1, 2, 3]  (ahora sí modificado)

texto = "ruby"
puts texto.upcase      # => "RUBY" (nuevo string)
puts texto             # => "ruby" (original intacto)

texto.upcase!
puts texto             # => "RUBY" (modificado en el lugar)
Sin bangCon bang (!)Efecto
sortsort!Modifica el arreglo en el lugar
upcaseupcase!Modifica el string en el lugar
reversereverse!Modifica el arreglo en el lugar

No todos los métodos con ! son destructivos, ni todos los destructivos llevan ! (como push). El bang es una convención de aviso, no una garantía. Leé la documentación cuando tengas dudas.
