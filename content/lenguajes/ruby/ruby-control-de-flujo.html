if, elsif, unless y ternario

Las estructuras de control permiten que tu programa tome decisiones. En Ruby, if evalúa una condición y ejecuta un bloque si es verdadera. Con elsif encadenás varias condiciones y con else cubrís el caso contrario.

A diferencia de muchos lenguajes, Ruby también ofrece unless (ejecuta si la condición es falsa) y una sintaxis en línea para condiciones simples.

nota = 8.5

if nota >= 7
  puts "Aprobado"
elsif nota >= 4
  puts "A recuperación"
else
  puts "Desaprobado"
end
# => Aprobado

dia = "domingo"
puts "Es fin de semana" if dia == "domingo"   # => Es fin de semana

edad = 15
unless edad >= 18
  puts "Es menor de edad"
end
# => Es menor de edad

puts edad >= 18 ? "Mayor" : "Menor"            # => Menor

Usá unless cuando la condición sea naturalmente negativa (por ejemplo unless vacio?) para que el código se lea como una frase en español o inglés. Abusar de él puede confundir, así que reservalo para casos claros.

case/when

case/when es la manera elegante de comparar un valor contra múltiples posibilidades sin encadenar muchos if/elsif. Funciona con cualquier valor y permite rangos y condiciones múltiples por rama.

Es similar al switch de otros lenguajes, pero mucho más poderoso porque cada when puede combinar valores, rangos y hasta expresiones.

calificacion = "B"

case calificacion
when "A"
  puts "Excelente"
when "B", "C"
  puts "Buen trabajo"
when "D"
  puts "Aprobado"
else
  puts "Debes mejorar"
end
# => Buen trabajo

edad = 25
case edad
when 0..12
  puts "Niño"
when 13..19
  puts "Adolescente"
else
  puts "Adulto"
end
# => Adulto

# case con rangos y cuando no hay comparación directa
fecha = 12
case
when fecha <= 7 then puts "Primera semana"
when fecha <= 14 then puts "Segunda semana"
else puts "Resto del mes"
end
# => Segunda semana

El operador case usa internamente === para comparar. Gracias a eso los rangos (0..12) y las clases funcionan de forma natural dentro de when.

Bucles: times, each, while

Los bucles repiten un bloque de código. Ruby ofrece varias formas: times para repetir un número exacto de veces, each para recorrer una colección y while/until para repetir mientras una condición se cumpla.

La forma más idiomática en Ruby es times y each, que se leen casi como inglés y evitan los contadores manuales.

5.times { |i| puts "Vuelta #{i + 1}" }
# => Vuelta 1
# => Vuelta 2
# => Vuelta 3
# => Vuelta 4
# => Vuelta 5

[10, 20, 30].each { |n| puts n * 2 }
# => 20
# => 40
# => 60

contador = 0
while contador < 3
  puts "Contador: #{contador}"
  contador += 1
end
# => Contador: 0
# => Contador: 1
# => Contador: 2

Con while es fácil crear bucles infinitos si olvidás incrementar la variable de control. Usá break para salir de un bucle y next para saltar a la siguiente iteración.

Iteradores y rangos

Un rango (1..5) representa una secuencia de valores entre un inicio y un fin. Los rangos son objetos y pueden iterarse: 1..5 incluye el 5, mientras que 1...5 lo excluye.

Los iteradores son métodos que recorren colecciones o rangos y ejecutan un bloque por cada elemento. Son la forma más elegante de procesar datos en Ruby.

(1..5).each { |n| print n, " " }
# => 1 2 3 4 5

(1...5).each { |n| print n, " " }
# => 1 2 3 4

(1..5).step(2) { |n| print n, " " }
# => 1 3 5

puts (1..5).to_a.inspect   # => [1, 2, 3, 4, 5]
puts ("a".."c").to_a       # => ["a", "b", "c"]

Los rangos también sirven en otros contextos: para validar inclusiones con (1..10).include?(5) o para generar cortes de arrays. Siempre que necesites una secuencia, pensá en un rango antes que en un arreglo armado a mano.

Métodos y argumentos

Un método es un bloque de código reutilizable definido con def y terminado con end. Devuelve automáticamente el valor de su última expresión, sin necesidad de return explícito.

Los métodos aceptan argumentos, pueden tener valores por defecto y argumentos de palabras clave (keyword arguments) que mejoran la legibilidad al llamarlos.

def saludar(nombre, saludo = "Hola")
  "#{saludo}, #{nombre}!"
end

puts saludar("Ana")          # => Hola, Ana!
puts saludar("Ana", "Buenas") # => Buenas, Ana!

def calcular(precio:, iva: 0.21)
  precio + precio * iva
end

puts calcular(precio: 100)         # => 121.0
puts calcular(precio: 100, iva: 0.1) # => 110.0

def maximo(*numeros)
  numeros.max
end

puts maximo(3, 9, 5, 11)   # => 11
puts maximo.class.inspect  # => Integer

Olvidate de escribir return salvo casos excepcionales: Ruby devuelve la última expresión evaluada. Esa convención hace que los métodos queden cortos y expresivos.
