Una palabra reservada es una palabra que no puedes usar como nombre de variable porque Python la usa para su propia sintaxis. La lista principal es:

Condicionalesif, elif, elseToman decisiones según una condición.
Buclesfor, whileRepiten un bloque de código.
Control de buclesbreak, continueInterrumpen o saltan una iteración del bucle.
Else en bucleselseSe ejecuta si el bucle no se rompió con break.

Python distingue mayúsculas de minúsculas y las palabras reservadas son siempre en minúsculas. true, false y none no existen: usa True, False y None.

Sintaxis básica

Python se lee como lenguaje natural: no usa llaves {} ni punto y coma, sino indentación para delimitar bloques. Un programa mínimo con entrada, proceso y salida:

# Mi primer programa
nombre = input("¿Cómo te llamas? ")   # leer del teclado
edad = int(input("¿Cuántos años tienes? "))

print("Hola, " + nombre)               # imprimir en pantalla

if edad >= 18:
    print("Eres mayor de edad.")
else:
    print("Aún eres menor de edad.")

input() siempre devuelve texto (str). Para operar con números hay que convertirlos: int(input("Edad: ")) si esperas un entero.

Tipos de datos

Python es de tipado dinámico: no declaras el tipo, Python lo infiere al asignar. Los tipos básicos son:

TipoQué guardaEjemplo
intNúmeros enteros (sin decimales)42, -7
floatNúmeros con decimales3.14, -0.5, 1e6
strCadenas de texto"Hola", 'Python'
boolVerdadero o falsoTrue, False
listLista ordenada y modificable[1, 2, 3]
tupleTupla inmutable (no se modifica)(1, 2, 3)
dictDiccionario clave → valor{"nombre": "Ana", "edad": 25}
setConjunto sin duplicados ni orden{1, 2, 3}

Listas y diccionarios son las colecciones más usadas:

# Lista: modificar, añadir y recorrer
frutas = ["manzana", "pera", "uva"]
frutas.append("naranja")        # añade al final
frutas[0] = "kiwi"              # cambia el primer elemento
print(len(frutas))              # 4

# Diccionario: datos clave-valor
usuario = {
    "nombre": "Ana",
    "edad": 25,
    "activo": True
}
print(usuario["nombre"])        # Ana
print(usuario.get("edad"))      # 25

Las listas usan corchetes [], las tuplas paréntesis (), los diccionarios llaves {"clave": valor} y los conjuntos llaves {valor} sin pares.

Estructuras de control

Python usa indentación (espacios o tabulaciones) en lugar de llaves para delimitar bloques. Todo lo que está al mismo nivel de sangría pertenece al mismo bloque.

if / elif / else

nota = 8.5

if nota >= 9:
    print("Excelente")
elif nota >= 7:
    print("Aprobado")
else:
    print("Reprobado")

for con rango y sobre lista

# Con range(incio, fin, paso)
for i in range(1, 6):     # 1, 2, 3, 4, 5
    print(i)

# Sobre una lista
nombres = ["Ana", "Luis", "Sofía"]
for nombre in nombres:
    print("Hola, " + nombre)

while

contador = 1
while contador <= 5:
    print(contador)
    contador += 1

break y continue

for i in range(1, 11):
    if i == 3:
        continue      # salta el 3
    if i == 7:
        break         # corta el bucle en el 7
    print(i)          # 1, 2, 4, 5, 6

El bloque que sigue a if, elif, else, for o while debe estar indentado con el mismo número de espacios (se recomiendan 4). De lo contrario Python lanza un IndentationError.

Funciones, clases y módulos

def: definir función con return

def suma(a, b):
    """Suma dos números y devuelve el resultado."""
    resultado = a + b
    return resultado

print(suma(3, 4))   # 7

lambda: función anónima

doble = lambda x: x * 2
print(doble(5))     # 10

numeros = [1, 2, 3]
pares = list(filter(lambda n: n % 2 == 0, numeros))

class: definir clase con método

class Persona:
    def __init__(self, nombre, edad):
        self.nombre = nombre    # atributo
        self.edad = edad

    def saludar(self):          # método
        print(f"Hola, soy {self.nombre}")

p = Persona("Ana", 25)          # crear objeto
p.saludar()                     # Hola, soy Ana

import: usar módulos

import math                # importa todo el módulo
print(math.sqrt(16))       # 4.0

from random import randint # importa una parte
print(randint(1, 6))       # número aleatorio 1-6

import math as m           # alias
print(m.pi)                # 3.141592653589793

Los métodos son funciones que pertenecen a una clase y se llaman sobre un objeto con punto: objeto.metodo(). El primer parámetro de un método es siempre self, que apunta al propio objeto.
