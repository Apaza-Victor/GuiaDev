¿Qué es F#?

F# (F sharp) es un lenguaje funcional de la familia .NET, creado inicialmente por Microsoft Research (2005) y hoy open source, multi-plataforma. Combina expresividad funcional con interoperabilidad total con C# y el resto de .NET.

Su sintaxis prioriza la inmutabilidad, las funciones como ciudadanos de primera clase, el type inference (no escribes tipos casi nunca) y el pattern matching. En campos como finanzas, ciencia de datos y scripting, F# brilla por su seguridad y concisión: con menos código expresa lo mismo que C#.

"Move fast and fix things" es el eslogan de F#: su sistema de tipos te deja refactorizar confiado porque el compilador detecta errores antes de ejecutar.

Instalación

F# se instala con el .NET SDK. Una vez instalado, tienes el compilador F# (dotnet fsi) y puedes crear proyectos F# con plantillas.

# Verificar .NET SDK
dotnet --version

# Instalar SDK en Windows
# winget install Microsoft.DotNet.SDK.8

# en Ubuntu / Debian
# sudo apt-get install dotnet-sdk-8.0   (tras configurar el repo de Microsoft)

# en macOS con brew
# brew install dotnet-sdk

# Plantillas F#
dotnet new list | findstr FSharp

# Crear un proyecto de consola F#
dotnet new console -lang F# -o MiAplicacion
cd MiAplicacion
dotnet run

# Script F#: archivo .fsx ejecutado por el intérprete
dotnet fsi mi_script.fsx

Para escribir lo más rápido, crea un archivo prueba.fsx (Script F#): abres dotnet fsi y lo ejecutas sin compilar. Es la forma ideal para tutoriales, prototipos y automatización.

---

Tu primer programa

Un programa F# es una lista de expresiones, no de sentencias. La función principal se llama main; el orden del código importa (no puedes usar un nombre antes de definirlo).

// Program.fs
let nombre = "F#"            // let: vincula un valor (inmutable)
printfn "Hola, %s!" nombre   // printfn imprime formateado

let anio = 2026
printfn "Estamos en %d" anio

let suma = 2 + 3             // las expresiones producen valores
printfn "2 + 3 = %d" suma

// El último valor es la salida del programa (exit code implícito)
0   // devolver 0 = éxito
# Uso básico
dotnet new console -lang F# -o Hola
cd Hola
dotnet run
# Salida:
# Hola, F#!
# Estamos en 2026
# 2 + 3 = 5

# Versión script
# hola.fsx
dotnet fsi hola.fsx

En F# los valores con let son inmutables por defecto: no puedes reasignar let x = 1; x = 2. Esa es una virtud: evita un montón de bugs. Para mutar se usa let mutable, con reserva.

F# Interactive (FSI)

FSI es el REPL de F#. En un script .fsx cada línea se puede evaluar repetidamente; en la terminal de FSI escribe expresiones y Julia te responde con val y su tipo.

# Lanzar el REPL
dotnet fsi

> let x = 10;;
val x : int = 10

> let y = x * 2;;
val y : int = 20

> x + y;;
val it : int = 30

# Salir del REPL
#quit;;

// En un archivo .fsx puedes combinar en un solo flujo
let celsius = 25.0
let fahrenheit = celsius * 1.8 + 32.0
printfn "%A grados C = %A grados F" celsius fahrenheit

// %A es el formato "bonito" para cualquier tipo
let datos = [ 1; 2; 3; 4 ]
printfn "%A" datos   // [1; 2; 3; 4]

El doble ;; marca el final de una expresión en FSI. Los scripts .fsx no lo necesitan. Para ver el tipo de algo en el REPL sin imprimirlo, solo escribe la expresión.

Inmutabilidad y valores

El corazón de F# es el dato sobre el efecto: defines valores, no "variables". Combinas funciones y "pipes" para construir pipelines declarativos.

// Valores inmutables
let ciudad = "Lima"
let poblacion = 10_000_000

// type inference: F# deduce todos los tipos
let area = 3.14159 * (2.0 ** 2.0)

// let mutable (úselo con moderación)
let mutable contador = 0
contador <- contador + 1      // operador de asignación <-
printfn "%d" contador

// Ninguna función con efectos secundarios escapa del sistema:
// se puede saber qué produce una función literalmente leyéndola
let conImpuesto precio = precio * 1.18
printfn "Precio con impuesto: %A" (conImpuesto 100.0)

// Tipo de unidad: funciones sin return devuelven () "unit"
let saluda() = printfn "Saludos"
saluda()

Esta inmutabilidad por defecto + funciones puras es lo que hace a F# fácil de razonar, testear y paralelizar. Cuando domines los "pipes" del siguiente módulo, escribirás análisis de datos en F# que en C# serían 3 veces más largos.

Ejercicios prácticos

Practica en orden: cada ejercicio asume lo aprendido en el anterior.

  1. Instalación: ejecuta dotnet --version y crea dotnet new console -lang F#; haz dotnet run.
  2. Perfil personal: en un .fsx define tu nombre, edad y ciudad con let, e imprime un párrafo con printfn y %s.
  3. Conversor: convierte pulgadas a centímetros y Fahrenheit a Celsius con funciones puras.
  4. REPL: inicia dotnet fsi, declara un valor, usa ;; y observa la inferencia de tipos.
  5. Inmutabilidad: intenta reasignar un let (verás error), y luego prueba let mutable con <-. Explica en un comentario qué pasó.

En la próxima lección dominaremos la sintaxis: let, funciones, el operador |> (pipe) y las tuplas.
