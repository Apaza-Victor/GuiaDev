let y la vinculación

let es la instrucción base de F#: define un valor, una función, o "destruye" un patrón en nuevo scop. Todo via let ... = expresion.

let usuario = "ana"              // valor
let suma a b = a + b             // función

// Shadowing: redefinir un nombre en un ámbito interno es legal
let x = 1
let resultado =
    let x = 2                     // sombrea x solo aquí
    x * 10
printfn "%d" resultado            // 20
printfn "%d" x                    // 1 (el exterior no cambia)

// let sobre una tupla: liga a la vez
let (nombre, edad) = ("Ana", 30)
printfn "%s tiene %d" nombre edad

// let como EXPRESIÓN: puede devolver valor
let par = 
    let n = 4
    n % 2 = 0
printfn "es par: %b" par          // true

El "shadowing" es intencional y se usa mucho: evita renombrar variables en cada transformación. En otros lenguajes es error; en F# es idioma.

Funciones

Las funciones se definen con let nombre parametros = cuerpo. Se puede encadenar con operadores, invocar con espacio y pasar como argumentos. F# soporta currying nativo: cada función se puede aplicar a un argumento y devolver otra función.

let doble x = x * 2               // toma un int, devuelve int
let suma a b = a + b              // dos args: es (a -> (b -> r))

// Inferencia de tipos automática
let cuadrado x = x * x            // int -> int

// anotación opcional
let incremento (n: int) : int = n + 1

// Currying: suma a b  es realmente  (suma a) b
let sumarCinco = suma 5            // parcial: espera el segundo arg
printfn "%d" (sumarCinco 3)        // 8

// Composición con >> y <<
let cuadradoYmas1 = cuadrado >> doble
printfn "%A" (cuadradoYmas1 3)     // 18

// Funciones como argumento
let aplica f x = f (f x)           // llamar dos veces a f
printfn "%d" (aplica doble 3)      // 12

La sintaxis de tipo de función es arg1 -> arg2 -> resultado. Cada flecha vuelve a ser un parámetro; es la base de las pipes.

No olvides los paréntesis al llamar dentro de otra llamada: suma (doble 2) 3. La adhesión a funciones es altísima en F#.

---

El operador pipe |>

El pipeline |> pasa el valor de la izquierda como ÚLTIMO argumento de la función de la derecha: x |> f equivale a f x. Es la forma canónica de componer transformaciones legibles de izquierda a derecha (como en un shell).

let doble = fun x -> x * 2
let masUno = fun x -> x + 1

// Sin pipes (de dentro hacia fuera)
let a = doble (masUno 5)        // 12

// Con pipes (de izquierda a derecha, se lee naturalmente)
let b = 5 |> masUno |> doble    // 12

// Ejemplo real con listas: 5 -> 5*2=10 ... encadenar
let n = 3
let res =
    n
    |> doble          // 6
    |> masUno         // 7
    |> cuadrado       // 49
printfn "%d" res

// Pipes con funciones anónimas (fun args -> ...)
let lista = [ 1; 2; 3; 4 ]
let resultado =
    lista
    |> List.filter (fun x -> x % 2 = 0)
    |> List.map (fun x -> x * 10)
printfn "%A" resultado     // [20; 40]

|> es tan común que leerás "el resultado se va a..." en prácticas. También existe <| (el reverso) y normalmente lo evitarás. F# incluso permite definir tus propias pipes.
I always recomiendo escribir los pipelines verticalmente para legibilidad.

Cadenas e interpolación

F# tiene varias formas de construir texto. La más moderna es la interpolación $"..." con {expr}, aunque coexistirá para siempre con printf (formatos) y %s.

let nombre = "Ana"
let edad = 30

// Interpolación (preferida)
let mensaje = $"Hola, {nombre}. Edad: {edad} años"
printfn "%s" mensaje

// Interpolación con formato dentro de llaves
let precio = 1250.5
let detalle = $"Total: {precio:N2}"        // 1.250,50 (locale)
printfn "%s" detalle

// printf con placeholders
printfn "Hola, %s (edad %d)" nombre edad

// Texto multilínea con triple comilla
let largo = """Línea uno
Línea dos
Fin"""
printfn "%s" largo

// Concat clásica
let sum = nombre + " tiene " + string edad + " años"
printfn "%s" sum

Los placeholders de printf son tipados: %d para int, %s para string, %b para bool, %f para float, %A "cualquier cosa". Si el tipo no corresponde, el compilador se queja.

PlaceholderTipo
%sstring
%d/%iint
%ffloat
%bbool
%Acualquier tipo (printfn bonito)

Tuplas y destructuring

Las tuplas agrupan valores fijos de distinto tipo: (a, b, c). Se usan para retornos múltiples y para pasar pares "nombre/valor". El pattern matching las extrae sin funciones de acceso.

let coord = (10, 20)                  // int * int
let (x, y) = coord                    // destructurar
printfn "x=%d y=%d" x y

let persona : (string * int) = ("Ana", 30)
let (nom, ed) = persona
printfn "%s %d" nom ed

// Tuplas en argumentos y retorno
let dividirConResto a b : (int * int) = (a / b, a % b)
let (cociente, resto) = dividirConResto 17 5
printfn "17 = 5*%d + %d" cociente resto

// Acceso por posición (fst / snd para 2-tuplas)
printfn "%d" (fst coord)     // 10
printfn "%d" (snd coord)     // 20

// Tuplas en pipelines
let proceso =
    (1, "uno")
    ||> fun n s -> $"{s}={n}"     // ||> "pipe doble" pasa la tupla
printfn "%s" proceso

Para más de ~2-3 valores, prefiere un Record (qué veremos en la lección 4). Las tuplas funcionan para grupos cortos y temporales.

Ejercicios prácticos

Practica en orden: cada ejercicio asume lo aprendido en el anterior.

  1. Funciones puras: define celsiusAFahrenheit y fahrenheitACelsius, y esPar n.
  2. Pipeline: dado n = 7, encadena |> doble |> masUno |> cuadrado y explica el resultado.
  3. Composición: crea procesa = cuadrado >> masUno y aplícala a 4.
  4. Interpolación: construye una ficha con nombre, edad y ciudad usando $"..." y formatos numéricos.
  5. Tuplas: escribe una función que devuelva (pares, impares) de una lista, y destructúrala.
