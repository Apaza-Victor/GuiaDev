Listas

Las List en F# son listas enlazadas inmutables, eficientes por su cabeza. Se construyen con [], se concatenan con :: y admiten todas las funciones de orden superior que veremos de aquí en adelante.

// Construcción
let lista1 = [ 1; 2; 3 ]
let lista2 = [ 1 .. 10 ]            // rango
let lista3 = [ 1; 2 ] @ [ 3; 4 ]    // concatenar con @

// Agregar a la cabeza (cons) — inmutable, new list
let conCabeza = 0 :: lista1         // [0; 1; 2; 3]

// Acceder nada más a la cabeza
printfn "%d" (List.head lista1)     // 1
printfn "%A" (List.tail lista1)     // [2; 3]

// Propiedades
printfn "Longitud: %d" (List.length lista1)
printfn "Vacía: %b" (List.isEmpty lista1)
printfn "Última: %d" (List.last lista1)

// Recursión clásica
let rec sumaLista = function
    | [] -> 0
    | h :: t -> h + sumaLista t
printfn "%d" (sumaLista [1;2;3;4])   // 10

// Pattern matching sobre lista
let describirLista xs =
    match xs with
    | [] -> "vacía"
    | [x] -> $"solo el {x}"
    | x :: y :: _ -> $"empieza con %d{x} y %d{y}"
printfn "%s" (describirLista [1; 2; 3])

Las listas son eficientes para recorrer, no para acceder por índice. Para acceso posicional y mutación usa Array. El patrón head :: tail se usa en match y recursión por igual.

Secuencias y colecciones

F# ofrece tres familias principales: List (materializada), Seq (perezosa) y Array (posicional/mutable). Cada una tiene su módulo List., Seq., Array. con la misma API.

// Seq: perezosa, no genera todos los datos hasta que se consumen
let nums = seq { 1 .. 1_000_000 }
let primero = Seq.head nums             // 1 (no materializa el millón)
let cinco = Seq.take 5 nums |> List.ofSeq
printfn "%A" cinco

// Array: posicional y mutable
let arr = [| 10; 20; 30 |]
arr.[0] <- 99                          // índice con .
printfn "%d" arr.[0]

// Array de rango
let arr2 = [| 1 .. 5 |]

// Otras colecciones útiles del BCL
let delMap = Map.ofList [ (1, "uno"); (2, "dos") ]
printfn "%s" delMap.[1]

let hs = Set.ofList [ 1; 2; 2; 3 ]     // Set elimina dup: [1;2;3]
printfn "%A" hs

// Usa el módulo que corresponda: Seq.map, Array.map, List.filter, ...

Regla: si el tamaño es pequeño y lo recorres entero → List. Si es enorme o infinito → Seq. Si necesitas indexar o mutar → Array. La API (map/filter/fold) es idéntica entre las tres.

Funciones de orden superior

map, filter, fold, collect, sort... son el pan de cada día. Aquí el corazón del estilo F#: transformar datos declarativamente.

let nums = [ 1; 2; 3; 4; 5 ]

// map
let dobles = List.map (fun n -> n * 2) nums
printfn "%A" dobles

// filter
let pares = List.filter (fun n -> n % 2 = 0) nums
printfn "%A" pares

// fold: acumular
let suma = List.fold (fun acc n -> acc + n) 0 nums
printfn "%d" suma

// reduce: fold sin valor inicial
let producto = List.reduce (fun a b -> a * b) nums
printfn "%d" producto     // 120

// sort y unique
let ordenado = List.sort [ 3; 1; 2 ]
printfn "%A" (List.distinct [ 1; 1; 2 ])     // [1; 2]

// find / exists / forall
printfn "%b" (List.exists (fun x -> x > 4) nums)
printfn "%b" (List.forall (fun x -> x > 0) nums)
printfn "%d" (List.find (fun x -> x = 3) nums)

// partition: divide en dos listas
let (paresL, imparesL) = List.partition (fun n -> n % 2 = 0) nums
printfn "Pares: %A\nImpares: %A" paresL imparesL

Nota para mentes OOP: fold es "reduce"; scan es "fold guardo cada paso". Encadena estas y el resultado será código declarativo que se lee como una especificación.

Pipeline real de datos

Combinemos todo: construir una cadena de transformación estilo ETL sobre listas de datos.

type Venta = { Producto : string; Monto : float; Region : string }

let ventas = [
    { Producto = "Laptop"; Monto = 1500.0; Region = "Norte" }
    { Producto = "Mouse";  Monto = 30.0;   Region = "Sur" }
    { Producto = "Teclado";Monto = 80.0;   Region = "Norte" }
]

let totalNorte =
    ventas
    |> List.filter (fun v -> v.Region = "Norte")
    |> List.map (fun v -> v.Monto)
    |> List.sum

printfn "Ventas Norte: %f" totalNorte   // 1580.0

// Con precios por producto y dividendos
let mapaOpciones =
    ventas
    |> List.map (fun v -> v.Producto)
    |> List.distinct
    |> List.sort

printfn "Productos: %A" mapaOpciones

Este pipeline es el patrón más representativo de F# en análisis de datos: filter → map → reduce. Verás la misma fórmula en toda la literatura funcional.

Aplicación práctica y rendimiento

F# materializa listas; para tareas pesadas conviene elegir bien (Seq perezosa) y medir con stopwatch. Veamos una mini aplicación con scripts.

open System.Diagnostics

// Demo: calcular estadísticos de una "serie" grande con Seq
let serie = seq { 1.0 .. 1_000_000.0 }

let stats =
    Serie = serie
    // <- compilar
    serie
    |> Seq.map (fun x -> x * x)
    |> Seq.sum

// cronometrar
let sw = Stopwatch.StartNew()
let sumaEst = 
    serie
    |> Seq.map (fun x -> x * x)
    |> Seq.sum
sw.Stop()
printfn "suma cuadrados 1..1M = %f  (%d ms)" sumaEst sw.ElapsedMilliseconds

// Guardar a CSV sencillo (sin librerías)
open System.IO
File.WriteAllLines("salida.txt",
    [ for i in 1..5 -> $"{i},{i * i}" ])
printfn "%s" (File.ReadAllText("salida.txt"))

Para conjuntos grandes dale una vuelta a las comprensiones seq y a Seq.map enlazadas: evitan intermedios. Y recuerda que F# corre en .NET: tienes todo el BCL (System.IO, System.Text.Json...) a tu alcance.

Ejercicios prácticos

Practica en orden: cada ejercicio asume lo aprendido en el anterior.

  1. Rangos y cons: construye [1..15], agrega 0 :: al frente y suma con List.fold.
  2. Pipeline: de una lista de números, filtra pares, eleva al cuadrado, y suma con pipes |> (sin paréntesis anidados).
  3. Frequency words: dada una lista de palabras, cuenta cuántas veces aparece cada una (usa List.countBy).
  4. Secuencia perezosa: crea con seq los cuadrados de 1..1M y toma los primeros 5 con Seq.take sin materializar.
  5. ETL Venta: con el record Venta, suma por región usando filter|map|sum.
