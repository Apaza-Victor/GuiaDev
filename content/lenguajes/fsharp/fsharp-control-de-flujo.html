if / then / else

En F#, if es una expresión que siempre devuelve un valor. No existe else if: se anidada o se usa elif. Todo if sin else que produzca un valor genera error de tipo (debe devolver unit).

let edad = 20

let resultado =
    if edad >= 18 then
        "Mayor"
    elif edad >= 0 then
        "Menor"
    else
        "Inválido"
printfn "%s" resultado

// if como expresión en una asignación
let categoría = if edad > 65 then "Adulto mayor" else "Adulto"
printfn "%s" categoría

// if para efecto (debe devolver unit: imprimir, no valor)
if edad % 2 = 0 then
    printfn "Edad par"
else
    printfn "Edad impar"

// Operador ternario "funcional"
let permitido = if edad >= 18 then "sí" else "no"

Para decisiones donde devuelves valores distintos, match es más expresión y se lee mejor. if está bien para casos simples o lógica de filtrado.

---

Pattern matching: match

match ... with es la instrucción estrella de F#: compara un valor contra patrones y ejecuta la primera rama que encaje. Cubre constantes, rangos, guards (when), tuplas y uniones.

let dia = "lunes"

let tipo =
    match dia with
    | "sábado" | "domingo" -> "Fin de semana"
    | "lunes" | "viernes"  -> "Laboral"
    | _ -> "Otro"            // comodín: cubre el resto

printfn "%s" tipo

// Guardas con when
let califica nota =
    match nota with
    | n when n >= 18 -> "A"
    | n when n >= 14 -> "B"
    | n when n >= 10 -> "C"
    | _ -> "D"
printfn "%s" (califica 15)

// Matching sobre tuplas y rangos
let (a, b) = (2, 5)
let suma =
    match (a, b) with
    | (0, _) | (_, 0) -> 0
    | (x, y) when x = y -> x * 2
    | (x, y) -> x + y
printfn "%d" suma

// Cubrir TODAS las ramas es requerido por el compilador:
// ventaja de seguridad total

El compilador de F# verifica exhaustividad: si el match no cubre todas las posibilidades (y no tiene comodín _), dará advertencia/aviso. Patrones + tipos = código casi a prueba de estado inválido.

Bucles: for y while

F# tiene bucles convencionales (for, while) pero la comunidad prefiere List.map/List.iter/recursión. Los bucles existen para cuando la iteración se necesita con efecto o rangos.

// for con rango (incluye 1..3)
for i in 1..3 do
    printfn "Número %d" i

// for descendente y con paso
for i in 10 .. -2 .. 2 do
    printf "%d " i
printfn ""

// for sobre un arreglo o lista
let frutas = [ "manzana"; "pera"; "uva" ]
for f in frutas do
    printfn "Fruta: %s" f

// while (úselo con cuidado; antes prefiere recursión)
let mutable n = 1
while n <= 5 do
    printfn "%d" n
    n <- n + 1

// break/continue no existen directamente: se simulan con flags
let mutable encontrado = false
for i in 1..10 do
    if not encontrado && i <= 5 then
        printfn "i=%d" i
        if i = 3 then encontrado <- true   // "break" en i=3

List.iterate/mapear es lo idiomático; el imperativo for queda para operar con índices o interop. F# no tiene break/continue nativos.

---

List / Seq comprehension

Las comprensiones construyen colecciones con la combinación de una expresión + for (yield/->) y filtros when. Son la vía más expresiva para generar secuencias.

// Lista de cuadrados
let cuadrados = [ for i in 1..10 -> i * i ]
printfn "%A" cuadrados

// Con filtro
let pares = [ for i in 1..20 when i % 2 = 0 -> i ]
printfn "%A" pares

// Secuencia (perezosa) — we push data
let cuad1m = seq { for n in 1L .. 1_000_000L do yield n * n }
printfn "%A" (Seq.head cuad1m)     // 1

// yield dentro de un cuerpo
let letras =
    seq {
        for c in 'a'..'e' do
            yield System.Char.ToUpper(c)
    }
printfn "%A" (List.ofSeq letras)

// Comprensiones sobre tuplas
let parejas = [ for x in 1..3 do for y in 1..2 do yield (x, y) ]
printfn "%A" parejas

De estas tres familias:
- List: materializada (corta)
- Seq: perezosa, ideal para streams/grandes
- Array: mutable/posicional
Elige seq ... do yield cuando los datos sean muchos o no sepas el tamaño final.

Ejercicios prácticos

Practica en orden: cada ejercicio asume lo aprendido en el anterior.

  1. Nivel de usuario: con if, clasifica una edad en "niño/adolescente/adulto/adulto mayor".
  2. Día laboral: con match y comodín, decide si un día es fin de semana usando | para varios casos.
  3. Clasificador de notas: con when en match, devuelve la letra (A-F) de una nota de 0-20.
  4. Secuencia de Fibonacci: genera los primeros 10 con una comprensión seq (usa mutable en el cuerpo).
  5. Feature matrix: imprime (i, j) para i en 1..3 y j en 1..2 usando un bucle anidado.
