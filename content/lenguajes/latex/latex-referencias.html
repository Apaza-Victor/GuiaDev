Referencias cruzadas

En un documento largo es molestísimo tener que reescribir «véase la sección 3.2» o «en la figura 5» cada vez que cambia la numeración. LaTeX resuelve esto con referencias cruzadas: marcas un punto con \label{Nombre} y después lo citas con \ref{Nombre}. LaTeX se encarga de insertar el número correcto en cada compilación.

\section{Introducción}
\label{sec:intro}

Como vimos en la sección \ref{sec:intro}, la introducción es breve.

\section{Metodología}
\label{sec:metodo}

La sección \ref{sec:metodo} detalla el método y en \ref{sec:intro} el contexto.

El mecanismo funciona para secciones, subsecciones, figuras, tablas y ecuaciones. Cualquier elemento que genere un número puede llevar una etiqueta. Como el número se calcula durante la compilación, aparece por primera vez como ?? hasta que vuelves a compilar. Por eso la regla de oro: compila dos veces (o incluso tres) para que las referencias queden resueltas.

\begin{figure}
  \includegraphics{grafico.png}
  \caption{Crecimiento anual}
  \label{fig:crecimiento}
\end{figure}

La \ref{fig:crecimiento} ilustra la tendencia.

Las etiquetas deben ser descriptivas (eq:cuadratica, tab:datos, fig:mapa). Pero ojo: la numeración automática se basa en el orden, así que una sección sin numerar (creada con \section*{...}) no puede referenciarse por número, porque no tiene uno.

Tabla de contenidos

Generar el índice de un documento largo en Word es una odisea; en LaTeX es una sola línea. El comando \tableofcontents construye automáticamente el índice a partir de tus \section, \subsection, etc., con sus números y páginas:

\documentclass{article}
\usepackage{amsmath}
\begin{document}

\tableofcontents

\section{Introducción}
...
\section{Resultados}
...
\section{Conclusiones}

\end{document}

Igual que con las referencias, el índice necesita más de una pasada: la primera compila las secciones, la segunda las recoge en el índice. Es habitual compilar dos veces seguidas (o tres si también hay referencias bibliográficas).

También existen listas complementarias: \listoffigures genera el índice de figuras y \listoftables el de tablas, a partir de las líneas \caption dentro de cada entorno. Son opcionales y pueden colocarse junto al índice de contenidos.

Para títulos de índice largos, usa la forma con argumento opcional: \section[Índice corto]{Este es el título completo y pormenorizado}, y el índice usará la versión breve mientras el cuerpo muestra la completa.

Introducción a la bibliografía

La bibliografía es la lista de fuentes citadas en el documento. La forma más sencilla es el entorno thebibliography, donde cada entrada se declara con \bibitem y se le asigna una clave para citarla. Vamos a verla porque es simple y casi todo lo demás es una mejora de esta idea.

\begin{thebibliography}{9}

\bibitem{knuth} Donald E. Knuth.
\textit{The TeXbook}. Addison-Wesley, 1984.

\bibitem{lamport} Leslie Lamport.
\textit{LaTeX: A Document Preparation System}.
Addison-Wesley, 1994.

\end{thebibliography}

Dentro del texto citas cada entrada con \cite{clave} y LaTeX la sustituye por su número entre corchetes ([1], [2]…), además de marcarla en la lista como citada:

El sistema original se describe en \cite{knuth}.
La versión práctica se explica en \cite{lamport}.

En una entrada \bibitem{clave} texto la clave es el identificador interno con el que citas (cualquier nombre sin espacios). El {9} al inicio solo indica la anchura máxima del rótulo y es irrelevante en la práctica.

BibTeX y biblatex

Para documentos grandes no se escriben las referencias a mano: se guardan en un archivo de base de datos con extensión .bib y LaTeX las formatea automáticamente. Un archivo .bib agrupa entradas en campos con una sintaxis clara. Un artículo típico:

@article{einstein1905,
  author  = {Einstein, Albert},
  title   = {On the Electrodynamics of Moving Bodies},
  journal = {Annalen der Physik},
  year    = {1905},
  volume  = {17},
  pages   = {891--921}
}

Cada entrada empieza por el tipo (@article, @book, @inproceedings…), una clave y una serie de campos clave = {valor} separados por comas. Los tipos más comunes:

TipoPara qué sirveCampos clave
@articleArtículo de revistaauthor, title, journal, year, volume, pages
@bookLibro completoauthor, title, publisher, year, edition
@inproceedingsPonencia en congresoauthor, title, booktitle, year, pages
@onlineRecurso webauthor, title, url, urldate

Conectar la base de datos: BibTeX

Con el clásico BibTeX, en el preámbulo indicas el estilo y, en el cuerpo, el archivo .bib y el lugar donde imprimir la bibliografía:

\bibliographystyle{plain}        % en el preámbulo
...
\cite{einstein1905}              % en el texto
...
\bibliography{miarchivo}         % donde va la lista (sin .bib)

La alternativa moderna, biblatex, es más flexible: cargas el paquete con el estilo elegido, conectas el recurso y al final imprimes la lista. Además, requiere compilar con biber (ver lección de compilación):

\usepackage[style=numeric]{biblatex}
\addbibresource{miarchivo.bib}
...
\printbibliography

La gran ventaja de separar la base de datos (.bib) del documento es la reutilización: el mismo archivo sirve para varios documentos, tesis, artículos o informes sin volver a teclear las referencias.

Citar en el texto

Una vez conectada la bibliografía, citas con \cite{clave} y LaTeX coloca la referencia numérica donde toque (p. ej. [1]). Puedes afinar mucho la cita. Para añadir una página o capítulo concreto se usa el argumento opcional entre corchetes:

\cite{knuth}
\cite[cap.~3]{lamport}          % → [2, cap. 3]
\cite[ver p.~4]{einstein1905}   % → [1, ver p. 4]

Múltiples obras se citan a la vez separando las claves con comas: \cite{knuth,lamport} produce [1, 2]. Y en estilos autor-año (ver más abajo) conviene usar la variante textual de biblatex:

Según \textcite{lamport}, LaTeX facilita la escritura.
% con estilo autor-año produce "Según Lamport (1994), ..."

El estilo de la cita

El cómo se formatean las citas depende del estilo. Con BibTeX controlas solo los números (plain, unsrt, alpha…). Con biblatex tienes estilos mucho más ricos y configurables:

EstiloAparienciaDe dónde
numeric[1], [2]…biblatex (por defecto)
alphabetic[Knu84], [Lam94]…biblatex / BibTeX alpha
author-year(Knuth, 1984)biblatex (carga estilo authoryear)
\usepackage[style=authoryear]{biblatex}
...
Según \cite{knuth} y \textcite{lamport}, ambos son fundamentales.

Un buen hábito: decide el estilo antes de escribir las citas, para usar el comando correcto (\cite para numérico, \textcite u otros para autor-año) desde el principio y no tener que reescribir el documento después.

Errores comunes

1. Olvidar compilar con biber/bibtex

Se ve "[?]" o "??" en la salida.
→ Compila con biber (o bibtex) y vuelve a compilar.

2. Citar una clave que no existe

\cite{knuth}    % ✅ existe en el .bib
\cite{kunth}    % ❌ error de ortografía en la clave → Warning: Citation undefined

3. No incluir la bibliografía al final

% Faltan una de estas dos líneas:
\bibliography{miarchivo}       % BibTeX
\printbibliography             % biblatex

4. Repetir la misma obra varias veces en la lista

% ❌ dos entradas para "el mismo" libro (LaTeX no las fusiona)
\bibitem{mc1} Knuth. The TeXbook.
\bibitem{mc2} D. E. Knuth. The TeXbook.

5. No compilar las veces necesarias

Para que salgan las referencias, el índice y la bibliografía, la secuencia usual es: pdflatex, luego biber/bibtex, y de nuevo pdflatex dos veces. Compilar una sola vez casi seguro dejará [?].

Si las citas salen como [?] o el documento no se actualiza, revisa primero la consola de compilación: avisos como Citation 'x' undefined o There were undefined references apuntan directamente a la causa, casi siempre un paso de compilación olvidado.

Ejercicios

Resuelve estos ejercicios para dominar referencias y bibliografía. Están ordenados de menor a mayor complejidad:

  1. Referencia de sección: crea un documento con dos secciones, pon \label{sec:uno} y \label{sec:dos} y en la segunda escribe «véase la sección \ref{sec:uno}». Compila dos veces y comprueba que sale el número correcto, no ??.
  2. Tabla de contenidos: escribe un documento con tres secciones (Introducción, Método, Resultados), añade \tableofcontents al inicio en su propia página y comprueba que el índice aparece tras dos compilaciones.
  3. Base de datos .bib: crea miref.bib con dos libros (usa @book con autor, título, editorial y año) y un artículo (@article).
  4. Cita con página: en el texto cita una de las entradas con \cite[ver p.~3]{clave} y comprueba que el número y la página aparecen entre corchetes.
  5. Cambiar a estilo autor-año: con biblatex carga \usepackage[style=authoryear]{biblatex}, añade \addbibresource y \printbibliography, y compila con biber en vez de bibtex. Observa cómo cambian las citas y la lista.
