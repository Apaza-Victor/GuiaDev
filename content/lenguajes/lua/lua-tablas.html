¿Qué es una tabla?

La tabla es la única estructura de datos de Lua y, con diferencia, la más importante: sirve a la vez como arreglo, diccionario (mapa clave-valor), objeto, conjunto y casi cualquier otra colección. En esencia, una tabla es una colección desordenada de pares clave → valor, donde la clave puede ser cualquier valor excepto nil.

Se crea con llaves {} y se accede a sus elementos con corchetes t[clave] o, cuando la clave es un identificador válido, con punto t.clave.

-- Crear una tabla vacía
local t = {}

-- Añadir pares clave-valor
t["nombre"] = "Lua"
t.version = 5.4          -- equivalente a t["version"]
t[1] = "primero"         -- claves numéricas

print(t["nombre"])       --> Lua
print(t.version)         --> 5.4
print(t[1])              --> primero
CaracterísticaDetalle
ClavesCualquier valor salvo nil (números, strings, tablas, funciones)
ValoresCualquier valor, incluso nil (que «borra» la clave)
TamañoDinámico: crecen y se encogen sin declarar capacidad
Índice inicialLos índices numéricos empiezan en 1, no en 0
ReferenciaLas tablas se pasan por referencia, no por copia

Los arreglos en Lua empiezan en el índice 1, no en 0. Es una regla que sorprende a casi todos al llegar del mundo de C, Java o JavaScript, y olvidarla es la fuente de decenas de errores off-by-one.

Como las tablas son por referencia, asignar local b = a no copia la tabla: b y a apuntan al mismo objeto. Modificar uno cambia el otro. Para copiar necesitas recorrerla o usar table.move.

Tablas como arreglos

Cuando las claves son números consecutivos (1, 2, 3...), la tabla se comporta como un arreglo o lista. Lua optimiza internamente estas tablas «de secuencia», y las maneja con funciones como # (longitud), table.insert, table.remove y table.concat.

-- Un arreglo básico
local frutas = { "manzana", "pera", "uvas" }
print(frutas[1])     --> manzana
print(frutas[#frutas]) --> uvas   (último elemento)
print(#frutas)       --> 3

-- Añadir elementos
table.insert(frutas, "naranja")        -- al final
table.insert(frutas, 2, "plátano")     -- en el índice 2
for _, f in ipairs(frutas) do io.write(f, " ") end
print()  --> manzana plátano pera uvas naranja

Puedes recorrer un arreglo por su índice con un for numérico usando #, o con ipairs para iterar en orden:

local notas = { 90, 85, 96, 88 }

-- Recorrido por índice
for i = 1, #notas do
  print("Nota", i, "=", notas[i])
end

-- Sumar los elementos
local total = 0
for _, n in ipairs(notas) do total = total + n end
print("Promedio:", total / #notas)   --> Promedio: 89.75
FunciónQué haceEjemplo
#tNúmero de elementos#frutas → 5
table.insert(t, v)Inserta al finaltable.insert(a, 9)
table.insert(t, i, v)Inserta en la posición itable.insert(a, 1, 0)
table.remove(t)Quita el últimotable.remove(a)

El operador # solo es fiable en tablas que son secuencias (índices 1..n sin huecos). Si la tabla tiene huecos o claves no numéricas, # puede devolver un valor ambiguo. Usa # en arreglos limpios y pairs para tablas mezcladas.

Tablas como diccionarios

Además de arreglos, las tablas funcionan como diccionarios (mapas clave-valor) para cualquier tipo de clave. Esto permite modelar registros, configuraciones, índices por nombre y en general cualquier relación entre un identificador y un valor.

-- Un diccionario: registros por clave de string
local usuario = {
  nombre  = "Ana",
  edad    = 29,
  correo  = "ana@guia.dev",
  activo  = true,
}

print(usuario.nombre)      --> Ana
print(usuario["edad"])     --> 29

-- Añadir y modificar claves
usuario.pais = "España"    -- crear una clave nueva
usuario.edad = 30          -- actualizar una existente

-- Claves que no son strings: números, tablas, funciones
local contador = {}
contador[1] = "uno"
contador[2] = "dos"
print(contador[2])         --> dos

Los diccionarios son la base para crear conjuntos (set) — una colección de claves únicas donde el valor puede ser true — o para llevar índices inversos:

-- Un conjunto con claves únicas
local vistos = {}
local datos = { "a", "b", "a", "c" }
for _, letra in ipairs(datos) do
  vistos[letra] = true      -- marca la letra como vista
end

if vistos["a"] then print("la 'a' ya se vio") end
-- la 'a' ya se vio

-- Índice inverso: buscar por valor
local paises = { ES = "España", MX = "México", AR = "Argentina" }
local codigo = "MX"
print(paises[codigo])       --> México
print(paises.MX)            --> México

Definir una tabla con { clave = valor } como en usuario es azúcar sintáctico: las claves se convierten en strings. Si necesitas una clave especial (con espacios o guiones), escríbela entre corchetes: { ["clave-compleja"] = 1 }.

Operaciones sobre tablas

La librería table de Lua aporta utilidades para ordenar, insertar, eliminar, concatenar y mover elementos. Dos de las más usadas son table.sort y table.concat. table.sort acepta una función de comparación opcional, lo que le da flexibilidad total.

-- Ordenar en orden ascendente (por defecto)
local numeros = { 30, 10, 50, 20, 40 }
table.sort(numeros)
print(table.concat(numeros, ", "))   --> 10, 20, 30, 40, 50

-- Ordenar descendentemente con comparador
table.sort(numeros, function(a, b) return a > b end)
print(table.concat(numeros, ", "))   --> 50, 40, 30, 20, 10
-- Ordenar un array de registros por un campo
local personas = {
  { nombre = "Carlos", edad = 34 },
  { nombre = "Lucía",  edad = 27 },
  { nombre = "Pedro",  edad = 41 },
}
table.sort(personas, function(a, b) return a.edad < b.edad end)
for _, p in ipairs(personas) do print(p.nombre, p.edad) end
--> Lucía	27
--> Carlos	34
--> Pedro	41

table.concat une todos los elementos de una secuencia en un solo string, con un separador opcional. Es mucho más eficiente que concatenar con .. dentro de un bucle, porque evita crear decenas de strings temporales:

local palabras = { "hola", "mundo", "desde", "Lua" }
print(table.concat(palabras, " "))
--> hola mundo desde Lua

-- Concatenar un rango con separador
print(table.concat(palabras, "-", 2, 4))
--> mundo-desde-Lua
FunciónDescripción
table.sort(t, [cmp])Ordena la tabla en el lugar
table.concat(t, [sep], [i], [j])Une un rango en un string
table.insert / removeInsertar y eliminar elementos
table.move(a, f, e, t)Mueve un bloque de elementos
table.unpack(t)Devuelve los valores como lista de retorno
table.pack(...)Empaqueta argumentos en una tabla con campo n

table.unpack es muy práctico para llamar a funciones con muchos argumentos: math.max(table.unpack(numeros)) devuelve el máximo de una lista sin escribirlos a mano.

Recorrer tablas con pairs e ipairs

Para recorrer una tabla tienes dos iteradores principales: pairs (recorre todas las claves, en orden indeterminado) e ipairs (recorre solo la secuencia numérica 1, 2, 3... de forma ordenada y se detiene en el primer hueco). Elegir el correcto depende del tipo de tabla.

local persona = { nombre = "Sofía", edad = 33, ciudad = "Medellín" }

-- pairs: visita cada par clave-valor (sin orden garantizado)
for clave, valor in pairs(persona) do
  print(clave, "=", valor)
end
-- El orden de salida puede variar entre ejecuciones
-- ipairs: recorre la secuencia numérica en orden, hasta el primer hueco
local lista = { "rojo", "verde", "azul" }
for i, color in ipairs(lista) do
  print(i, color)
end
--> 1	rojo
--> 2	verde
--> 3	azul

La diferencia práctica salta a la vista en esta tabla mixta — parte arreglo, parte diccionario — donde cada iterador se comporta distinto:

local mixta = { "a", "b", etiqueta = "x", "c" }

print("Con ipairs:")     -- solo la secuencia inicial
for i, v in ipairs(mixta) do print(i, v) end
--> 1	a
--> 2	b
--> 3	c

print("Con pairs:")      -- incluye la clave 'etiqueta'
for k, v in pairs(mixta) do print(k, v) end
-- Incluye etiqueta=x junto a 1,2,3 en orden arbitrario
IteradorQué recorreOrdenUso recomendado
ipairsÍndices 1..n de la secuenciaDeterminadoArreglos y listas
pairsTodas las clavesIndeterminadoDiccionarios y mixtas

No confíes en el orden de pairs: para las claves de string no hay garantía de secuencia. Si necesitas orden, ordena las claves primero (table.sort sobre un arreglo de claves) y luego recórrelo tú mismo.

Como regla práctica: usa ipairs para listas indexadas y pairs para mapas. Escribir a mano el nombre de cada variable (clave, valor) con nombres descriptivos hace que los bucles sean mucho más legibles.

Ejercicios prácticos

Practica el manejo de tablas con estos ejercicios. Crea cada uno como un archivo .lua distinto y ejecútalo para comprobar la salida.

  1. Arreglo y promedio: Con local notas = { 80, 75, 92, 100, 88 }, calcula el promedio usando # y un bucle for. Imprime la nota máxima con math.max(table.unpack(notas)).
  2. Diccionario de inventario: Crea una tabla que asocie producto → cantidad, añade dos productos, actualiza uno y borra otro asignando nil. Recórrela con pairs e imprime cada línea.
  3. Contar frecuencias: Dada una lista de palabras repetidas, usa una tabla de diccionario para contar cuántas veces aparece cada una. Recorre el resultado y muestra las frecuencias.
  4. Ordenar por campo: Crea un arreglo de personas ({nombre, edad}) y ordénalo descendientemente por edad usando table.sort con un comparador.
  5. Desafío: Escribe una función invertir(t) que reciba un diccionario y devuelva uno nuevo con las claves y valores intercambiados. Pruébala con { ES = "España", MX = "México" } para obtener { España = "ES", México = "MX" }.
