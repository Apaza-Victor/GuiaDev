if, elseif y else

Las estructuras de control de Lua deciden qué bloque de código se ejecuta según las condiciones. La sintaxis de if sigue el patrón clásico, pero con la palabra clave then y el cierre end. Puedes encadenar tantos elseif como necesites, y terminar con un else opcional.

local nota = 7.5

if nota >= 9 then
  print("Sobresaliente")
elseif nota >= 7 then
  print("Notable")
elseif nota >= 5 then
  print("Aprobado")
else
  print("Suspenso")
end
--> Notable

Recuerda la regla de veracidad de Lua: solo nil y false son falsos. Por eso if tabla.clave then comprueba a la vez que la clave existe y que no es falsa:

local usuario = { nombre = "Mario" }

if usuario.nombre then
  print("Hola, " .. usuario.nombre)
end
--> Hola, Mario

if not usuario.admin then
  print("No eres administrador")
end
--> No eres administrador

-- Combinar condiciones
if usuario.nombre and usuario.edad then
  print("Perfil completo")
else
  print("Falta información")
end
EstructuraComportamiento
if c then ... endEjecuta si c es verdadero
elseif c2 then ...Prueba la siguiente condición si la anterior falló
else ... endEjecuta si ninguna condición se cumplió

Como en Lua no existe un operador ternario (cond ? a : b), se suele usar la expresión lógica cond and a or b. Úsala con cuidado: si a es false o nil puede comportarse mal, así que es más seguro escribir un if normal.

Bucles: for, while y repeat

Lua ofrece tres formas de repetir código. El for numérico itera sobre un rango con un paso opcional; while repite mientras la condición sea verdadera; y repeat...until garantiza al menos una ejecución porque comprueba la condición al final.

-- for numérico: del 1 al 5
for i = 1, 5 do
  io.write(i, " ")
end
print()  --> 1 2 3 4 5

-- for con paso: pares del 0 al 10
for i = 0, 10, 2 do io.write(i, " ") end
print()  --> 0 2 4 6 8 10

-- for descendente
for i = 3, 1, -1 do io.write(i, " ") end
print()  --> 3 2 1
-- while: repite mientras se cumpla la condición
local n = 5
while n > 0 do
  io.write(n, " ")
  n = n - 1
end
print()  --> 5 4 3 2 1

-- repeat...until: se ejecuta al menos una vez
local intentos = 0
repeat
  intentos = intentos + 1
  print("Intento", intentos)
until intentos >= 3

Para salir de un bucle antes de tiempo se usa break; continue no existe, así que para «saltar» una iteración se envuelve el cuerpo en un if:

-- break: detener el bucle
for i = 1, 10 do
  if i == 4 then break end
  io.write(i, " ")
end
print()  --> 1 2 3

-- Simular continue con if/else
for i = 1, 5 do
  if i == 3 then
    -- saltamos esta iteración
  else
    io.write(i, " ")
  end
end
print()  --> 1 2 4 5
BucleCuándo usarloComprobación
for i = a, b, pRango numérico conocidoAl inicio de cada iteración
while c do ... endCondición evaluada antes de cada vueltaAntes de ejecutar el cuerpo
repeat ... until cGarantizar al menos una ejecuciónDespués de ejecutar el cuerpo

Ten cuidado con los bucles infinitos en while y repeat: olvidar actualizar la variable que controla la condición los bloquea para siempre. Cuando escribas un while, revisa siempre que la condición llegará a volverse falsa.

Funciones y múltiples retornos

Una función es un bloque de código reutilizable que recibe argumentos y (opcionalmente) devuelve valores. En Lua la sintaxis es function nombre(args) ... end, y las funciones se consideran valores de primera clase: puedes guardarlas en variables, pasarlas a otras funciones o devolverlas desde una función.

-- Declaración con nombre
local function cuadrado(n)
  return n * n
end

-- Función anónima guardada en una variable
local duplicar = function(n)
  return n * 2
end

print(cuadrado(4))    --> 16
print(duplicar(5))    --> 10

Una característica distintiva de Lua son los múltiples valores de retorno: una función puede devolver varios resultados separados por comas. También pueden recibirse con asignación múltiple o con select:

-- Múltiples retornos
local function dividir(a, b)
  local cociente = a // b
  local resto = a % b
  return cociente, resto
end

local c, r = dividir(17, 5)
print(c, r)      --> 3	2
-- select('#', ...) cuenta cuántos argumentos llegan
local function sumar_todo(...)
  local total = 0
  for i = 1, select("#", ...) do
    total = total + select(i, ...)
  end
  return total
end

print(sumar_todo(1, 2, 3, 4))   --> 10

-- Argumentos con valor por defecto
local function saludar(nombre, apodo)
  apodo = apodo or "Desconocido"
  print(nombre .. ", también conocido como " .. apodo)
end
saludar("Ana", "La veloz")
saludar("Luis")

Función anónimalocal f = function(a)Como valor de primera clase

Usar local function en lugar de function (sin local) envuelve la definición en el ámbito local y evita ensuciar el entorno global. En programas modernos verás casi siempre local function.

Closures y funciones de orden superior

Como las funciones son valores de primera clase, Lua soporta closures — funciones que «capturan» variables de su entorno externo — y funciones de orden superior que reciben o devuelven funciones. Estos conceptos abren la puerta a un estilo de programación muy expresivo.

-- Closure: la función interna recuerda 'contador'
local function crear_contador(inicio)
  local contador = inicio
  return function()
    contador = contador + 1
    return contador
  end
end

local c1 = crear_contador(10)
print(c1())   --> 11
print(c1())   --> 12

local c2 = crear_contador(0)   -- cada closure tiene su propio estado
print(c2())   --> 1

Una función de orden superior recibe funciones como argumentos o las devuelve. Este es el mecanismo detrás de table.sort, los iteradores y las utilidades tipo filter/map:

-- Aplicar una función a cada elemento (map)
local function mapear(lista, fn)
  local resultado = {}
  for i, v in ipairs(lista) do
    resultado[i] = fn(v)
  end
  return resultado
end

-- Filtrar elementos según una condición (filter)
local function filtrar(lista, predicado)
  local resultado = {}
  for _, v in ipairs(lista) do
    if predicado(v) then
      table.insert(resultado, v)
    end
  end
  return resultado
end

local nums = { 1, 2, 3, 4, 5, 6 }
local pares = filtrar(nums, function(n) return n % 2 == 0 end)
local dobles = mapear(pares, function(n) return n * 2 end)
print(table.concat(dobles, ", "))   --> 4, 8, 12
ClosureFunciones de orden superior
Función que captura variables externasFunción que recibe/retorna otras funciones
Mantiene estado privado entre llamadasHabilita map, filter, sort
Se crea al ejecutar la función externaUso típico: callbacks y callbacks

Dominar closures es clave para escribir código Lua idiomático: te permiten contadores privados, memorización, generadores de funciones y callbacks. Cada llamada a la función externa crea una nueva copia de las variables capturadas, como muestran c1 y c2.

Manejo de errores con pcall

Lua maneja errores con dos herramientas: error() lanza un error y pcall() (protected call) lo captura. pcall ejecuta una función de forma «protegida» y devuelve dos valores: un booleano (true si no hubo error) y, en caso de éxito, el retorno de la función, o bien el mensaje de error.

-- Lanzar un error personalizado
local function depositar(saldo, cantidad)
  if cantidad < 0 then
    error("La cantidad no puede ser negativa")
  end
  return saldo + cantidad
end

-- Capturar el error con pcall
local exito, resultado = pcall(depositar, 100, -5)
if exito then
  print("Nuevo saldo:", resultado)
else
  print("Error:", resultado)   --> Error: La cantidad no puede ser negativa
end

También existe xpcall, que permite capturar el error y ejecutar una función de tratamiento que recibe el mensaje:

-- xpcall con función de manejo de errores
local ok, err = xpcall(function()
  error("algo salió mal")
end, function(msg)
  return "Se detectó: " .. msg
end)

print(err)   --> Se detectó: algo salió mal
FunciónQué hace
error(msg)Lanza un error con el mensaje dado
pcall(f, args...)Ejecuta f protegida; devuelve true/false y resultado o mensaje
xpcall(f, h, args...)Como pcall, pero h recibe el error
assert(cond, msg)Lanza msg si cond es falsa
-- assert: conveniente para validar contratos internos
local function raiz(x)
  assert(x >= 0, "La raíz requiere un número no negativo")
  return x ^ 0.5
end

print(raiz(16))     --> 4.0
-- print(raiz(-4))   -- error: assertion failed!

Usa pcall para proteger operaciones que pueden fallar (I/O, redes, módulos de terceros) de bloquear el programa entero. En Lua, un error no capturado en un script principal interrumpe la ejecución por completo.

En el próximo curso verás metatablas y POO; conocer ya pcall/xpcall te servirá cuando quieras ejecutar código de forma segura dentro de sistemas más grandes.
