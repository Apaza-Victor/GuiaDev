¿Qué es Lua y dónde se usa?

Lua es un lenguaje de programación ligero, embebible y de propósito general, creado en 1993 por un equipo de la Pontificia Universidad Católica de Río de Janeiro (Roberto Ierusalimschy, Luiz Henrique de Figueiredo y Waldemar Celes). Su nombre proviene de la palabra portuguesa para «luna» — no es un acrónimo. En solo unos cientos de kilobytes, Lua ofrece funciones de primera clase, tablas como estructura de datos universal y un entorno pensado para incrustarse en aplicaciones grandes escritas en C o C++.

El punto fuerte de Lua es su diseño minimalista: un intérprete veloz, un recolector de basura automático y una API en C que permite que programas host lo usen como lenguaje de scripting. Por eso lo encontrarás dentro de juegos, motores gráficos, herramientas de configuración y servidores embebidos.

Lua suele describirse como un lenguaje «todo lo que no está prohibido está permitido»: pocas reglas y mucha flexibilidad. Eso lo hace rápido de aprender, pero exige disciplina al escribir código en proyectos grandes.

Instalación y entorno

Para ejecutar Lua necesitas el intérprete oficial, disponible en varias versiones (la estable actual es la serie 5.4). La instalación depende de tu sistema operativo. En sistemas Linux y macOS suele venir con el gestor de paquetes; en Windows puedes instalar el binario o usar el instalador oficial.

# Debian / Ubuntu
sudo apt install lua5.4

# macOS (Homebrew)
brew install lua

# Verificar que está instalado y mostrar la versión
lua -v
# Salida: Lua 5.4.6  Copyright (C) 1994-2023 Lua.org, PUC-Rio

Puedes comprobar el estado de tu instalación y ejecutar módulos desde la terminal:

# Ejecutar un script directamente
lua mi_script.lua

# Ejecutar y devolver el código de salida (-e evalúa una expresión)
lua -e "print(2 + 3)"

Cualquier editor de texto sirve para escribir Lua, pero los modernos mejoran la experiencia con resaltado de sintaxis, autocompletado y ejecución integrada:

No necesitas un compilador separado: lua archivo.lua compila e interpreta en un solo paso. El binario luac opcional permite precompilar a bytecode para distribuir scripts sin su fuente, algo habitual en videojuegos.

Tu primer script

Para verificar que tu entorno funciona, crea un archivo hola.lua con tu primer programa. La función print escribe texto en la salida estándar y el operador .. concatena strings.

-- hola.lua
print("Hola desde GuiaDev")           -- texto plano
print(40 + 2)                          -- resultado de una expresión
print("Lua " .. "es genial")           -- concatenación de strings

Ejecútalo y observa el resultado:

lua hola.lua
# Salida:
# Hola desde GuiaDev
# 42
# Lua es genial

Puedes combinar texto y valores directamente con print pasando varios argumentos separados por comas; Lua los imprime en orden separándolos con un tabulador:

local nombre = "Lua"
local version = 5.4
print("Versión:", version, "de", nombre)
-- Salida: Versión:	5.4	de	Lua

Todo lo que va tras -- hasta el final de la línea es un comentario que Lua ignora. Los comentarios son imprescindibles para documentar tu código y, en esta lección, sirven para mostrar la salida esperada de cada programa.

La consola interactiva

Además de ejecutar scripts, Lua incluye un REPL (Read-Eval-Print Loop): una consola que evalúa expresiones al instante, ideal para experimentar y depurar comandos sueltos sin crear un archivo. Se abre invocando lua sin argumentos.

$ lua
Lua 5.4.6  Copyright (C) 1994-2023 Lua.org, PUC-Rio
> print("prueba")
prueba
> 15 * 3
45
> math.sqrt(81)
9.0
> os.exit()

En el modo interactivo puedes asignar variables, definir funciones y probar fragmentos completos sobre la marcha. Cada expresión devuelve su resultado y Lua lo imprime automáticamente cuando no termina en ;:

> local x = 10
> x + 5
15
> function cuadrado(n) return n * n end
> cuadrado(7)
49

En la consola interactiva, la variable especial _ guarda el último valor evaluado. Escribir _ te da acceso al resultado anterior sin recalcularlo: útil para encadenar operaciones mentales cuando estás aprendiendo.

El modo interactivo ignora silenciosamente los errores a veces mostrando poco detalle. Si algo no sale como esperas, usa = expresión para forzar que Lua imprima el valor, o revisa la sintaxis línea por línea.

Un diseño minimalista

Lua destaca por su pequeño tamaño y su sintaxis limpia. El núcleo del lenguaje tiene muy pocos conceptos: ocho tipos básicos, tablas y funciones como piezas reutilizables. Esto convierte a Lua en uno de los lenguajes más fáciles de leer y de estudiar completamente.

CaracterísticaDetalle
Tamaño del intérpreteCompila a unos 250 KB, incluida la librería estándar
Tipos de datos8 tipos: nil, boolean, number, string, function, userdata, thread, table
Estructura de datosUna sola: la tabla (arreglo, diccionario y objeto a la vez)
ParadigmasMultiparadigma: imperativo, funcional y orientado a objetos
MemoriaRecolector de basura automático con finalizadores
PortabilidadSe compila en casi cualquier plataforma con un compilador C

Comparado con lenguajes más grandes, la curva de aprendizaje es muy corta. Un ejemplo sencillo de estilo funcional muestra cuán expresiva es la sintaxis:

-- Aplicar una función a cada elemento de un arreglo usando table.map
local numeros = { 1, 2, 3, 4 }

local function mapear(arreglo, fn)
  local resultado = {}
  for i, v in ipairs(arreglo) do
    resultado[i] = fn(v)
  end
  return resultado
end

local dobles = mapear(numeros, function(n) return n * 2 end)
for _, v in ipairs(dobles) do print(v) end
-- Salida: 2 4 6 8

La filosofía de Lua es «mecanismos, no políticas»: ofrece bloques de construcción potentes (tablas, funciones, metatablas) y deja que tú decidas cómo usar el lenguaje. Esta flexibilidad es la razón de que se adapte tan bien a tantos dominios distintos.

Ejercicios prácticos

Pon a prueba lo aprendido en esta primera lección. Asegúrate de tener el intérprete instalado (lua -v) antes de empezar.

  1. Instalar y verificar: Instala Lua en tu sistema y ejecuta lua -v. Escribe en un archivo verificacion.txt la versión exacta que obtuviste.
  2. Primer script: Crea presentacion.lua que imprima tu nombre, tu lenguaje favorito y el resultado de 7 * 6 usando tres llamadas a print. Ejecútalo con lua presentacion.lua.
  3. Consola interactiva: En el REPL (lua) calcula math.floor(23.7), concatena "hola" .. " mundo" y define una función que sume tres números. Anota los resultados.
  4. Concatena y calcula: Escribe un script que asigne tu edad a una variable y muestre "Tengo " .. edad .. " años". Experimenta añadiendo o restando años y vuelve a imprimir.
  5. Desafío: Busca en qué aplicación instalada usas Lua a diario (juegos, editores, servidores) y escribe una breve nota de dos frases explicando qué papel juega Lua en ella.

En el próximo capítulo, variables-y-tipos, aprenderás a manejar las variables y los tipos de datos de Lua en detalle, la base para escribir cualquier programa real.
