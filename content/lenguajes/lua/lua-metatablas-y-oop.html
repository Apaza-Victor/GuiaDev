Metatablas y metamétodos

Una metatabla es una tabla normal asociada a otra tabla, que define cómo se comporta esa tabla ante operaciones que Lua no puede resolver por defecto: indexar campos inexistentes, sumar, comparar, concatenar o incluso llamarla como función. Los campos de la metatabla son metamétodos, funciones que Lua invoca automáticamente.

Se asocia una metatabla con setmetatable(tabla, meta) y se lee con getmetatable(tabla). El metamétodo más común es __index:

-- Una tabla base y su metatabla
local perro = { nombre = "Rex" }

local perro_meta = {}
perro_meta.__index = function(tabla, clave)
  if clave == "sonido" then
    return tabla.nombre .. " dice guau"
  end
  return nil
end

setmetatable(perro, perro_meta)

print(perro.nombre)       --> Rex  (existe: no usa __index)
print(perro.sonido)       --> Rex dice guau  (no existe: __index lo resuelve)

-- __tostring para una salida legible
local punto = { x = 2, y = 3 }
setmetatable(punto, {
  __tostring = function(t)
    return "Punto(" .. t.x .. ", " .. t.y .. ")"
  end,
})
print(punto)    --> Punto(2, 3)

Cada tabla puede tener una sola metatabla, asignada con setmetatable. Si llamas a setmetatable dos veces, la segunda reemplaza a la primera. Quitar una metatabla es posible con setmetatable(t, nil).

El metamétodo __index es la base de todo el sistema de objetos de Lua: cuando un método no se encuentra en el objeto, Lua lo busca en su metatabla (normalmente la «clase»). Eso es herencia, como verás pronto.

Sobrecarga de operadores

Los metamétodos permiten sobrecargar operadores: definir qué significa, por ejemplo, sumar dos de tus objetos o compararlos. Esto es ideal para valores matemáticos como puntos, vectores o números complejos. Lua busca el metamétodo en la metatabla del primer operando.

-- Una tabla de vector 2D con metatabla compartida
local Vector = {}

local meta = {
  __add = function(a, b)
    return Vector(a.x + b.x, a.y + b.y)
  end,
  __eq = function(a, b)
    return a.x == b.x and a.y == b.y
  end,
  __lt = function(a, b)
    return a.x * a.x + a.y * a.y < b.x * b.x + b.y * b.y
  end,
  __tostring = function(t)
    return string.format("(%.1f, %.1f)", t.x, t.y)
  end,
}

function Vector(x, y)
  local self = { x = x, y = y }
  return setmetatable(self, meta)
end

local v1 = Vector(1, 2)
local v2 = Vector(3, 4)
local suma = v1 + v2          -- invoca __add
print(suma)                   --> (4.0, 6.0)
print(v1 == Vector(1, 2))     --> true   (__eq)
print(v1 < v2)                --> true   (__lt: 1+4 < 9+16)

-- __call: hacer que el objeto se comporte como función
local calculadora = setmetatable({ factor = 3 }, {
  __call = function(self, n)
    return n * self.factor
  end,
})
print(calculadora(10))    --> 30  (invoca __call)

Cuando sobrecargas __eq, Lua ya no usa la comparación por referencia por defecto para ese par: tú decides qué significa «igual». Asegúrate de que __eq sea simétrico y coherente, o crearás bugs difíciles de rastrear.

Sistemas de objetos con tablas

Con metatablas puedes construir sistemas de objetos sin sintaxis especial: una «clase» es una tabla que guarda métodos, y un «objeto» es una tabla cuya metatabla tiene __index apuntando a la clase. Así, cuando el objeto no tiene un campo, Lua lo busca en la clase.

-- Definir la "clase" Libro
local Libro = {}
Libro.__index = Libro

-- Métodos de la clase (se invocan con self)
function Libro.nuevo(self, titulo, autor)
  local obj = setmetatable({}, self)
  obj.titulo = titulo
  obj.autor = autor
  obj.prestado = false
  return obj
end

function Libro.prestar(self)
  if self.prestado then
    print("El libro ya está prestado")
  else
    self.prestado = true
    print("Prestado: " .. self.titulo)
  end
end

-- Crear un objeto
local miLibro = Libro.nuevo(Libro, "1984", "Orwell")
print(miLibro.titulo)     --> 1984
miLibro:prestar()         --> Prestado: 1984  (endulzado con :) 
miLibro:prestar()         --> El libro ya está prestado

Fíjate en el operador dos puntos :: obj:metodo(args) es azúcar sintáctico de obj.metodo(obj, args). Inserta automáticamente el objeto como primer argumento self:

-- Equivalencia entre : y .
function Libro.mostrar(self)
  print(self.titulo .. " - " .. self.autor)
end

miLibro:mostrar()        -- 1984 - Orwell   (con :)
miLibro.mostrar(miLibro) -- 1984 - Orwell   (sin :, manual)
PatrónDescripción
ClaseTabla con métodos y __index que se apunta a sí misma
InstanciaTabla creada con setmetatable({}, Clase)
ConstructorFunción que crea y devuelve la instancia
MétodoFunción que recibe self como primer argumento
Azúcar :obj:metodo(x) = obj.metodo(obj, x)

El azúcar de los dos puntos : simplifica muchísimo la POO en Lua. Cada vez que veas obj:metodo(), recuerda que Lua está pasando obj como un parámetro oculto llamado self.

Este patrón manual de «clases» es ligero y transparente: puedes construirlo con tus propias convenciones. Es la base de la mayoría de librerías de Lua, incluidas las que emulan clases con un class() propio.

Herencia con metatablas

La herencia en Lua surge de forma natural encadenando metatablas: una subclase es una tabla cuyo __index apunta a la clase padre. Al buscar un método en un objeto, Lua lo busca en el objeto, luego en su metatabla (la subclase) y, si no está, en la metatabla de la subclase (la clase base).

-- Clase base Vehiculo
local Vehiculo = {}
Vehiculo.__index = Vehiculo

function Vehiculo.nuevo(self, marca)
  local obj = setmetatable({}, self)
  obj.marca = marca
  obj.velocidad = 0
  return obj
end

function Vehiculo.acelerar(self, cantidad)
  self.velocidad = self.velocidad + cantidad
end

function Vehiculo.describir(self)
  return self.marca .. " a " .. self.velocidad .. " km/h"
end

-- Subclase Coche hereda de Vehiculo
local Coche = setmetatable({}, { __index = Vehiculo })
Coche.__index = Coche

function Coche.nuevo(self, marca, puertas)
  local obj = Vehiculo.nuevo(self, marca)   -- llama al constructor padre
  obj.puertas = puertas
  return obj
end

-- Sobrescribir un método en la subclase
function Coche.describir(self)
  return "Coche " .. Vehiculo.describir(self) .. " con " .. self.puertas .. " puertas"
end

local miCoche = Coche:nuevo("Seat", 5)
miCoche:acelerar(60)                  -- heredado de Vehiculo
print(miCoche:marca)                  -- Seat   (buscado en la cadena)
print(miCoche:describir())            -- Coche Seat a 60 km/h con 5 puertas

La cadena de búsqueda de campos se encadena automáticamente, lo que permite lo que en POO clásica llamarías herencia múltiple de métodos:

-- Estructura de la cadena de herencia
local objeto    = setmetatable({}, { __index = Coche })
local padre     = Coche
local abuelo    = getmetatable(Coche).__index   -- Vehiculo

print(padre == Coche)                 --> true
print(abuelo == Vehiculo)             --> true
-- Al buscar objeto.metodo, Lua recorre: objeto -> Coche -> Vehiculo
Paso de búsquedaDónde mira Lua
1La propia tabla (objeto)
2La metatabla del objeto (__index = clase)
3La metatabla de la clase (__index = clase padre)
4Y así sucesivamente por la cadena

Al sobreescribir un método en la subclase, conserva la referencia al método padre (como Vehiculo.describir(self)). Esto respeta lo que en POO clásica se llama «llamar a super», y evita duplicar lógica.

Ejercicios prácticos

Construye sistemas de objetos con metatablas. Crea cada solución en un archivo .lua y ejecútala para comprobar el comportamiento.

  1. Punto 2D: Implementa una clase Punto con los campos x e y, el método distancia a otro punto, y sobrecarga __add y __tostring. Suma dos puntos y muéstralos.
  2. Contador con metatabla: Crea un objeto contador con un método incrementar que aumente y devuelva el valor actual. Usa __call para que llamar al objeto equivalenta a incrementar.
  3. Herencia de Animal: Define Animal con nombre y sonido, y subclase Gato que por defecto haga «miau». Instancia un gato, hazlo sonar y verifica que hereda el método de la clase base.
  4. Banco con POO: Crea una clase Cuenta con saldo, depositar y retirar (con validación). Añade __tostring para mostrar el saldo formateado.
  5. Desafío: Usa __newindex para registrar en un log cada vez que se crea una propiedad nueva en un objeto. Crea un objeto, añade varias propiedades y recorre el log para confirmar que todas se registraron.
