Variables y ámbito

En Lua una variable es un contenedor con nombre que guarda un valor. Lo más importante desde el principio: por defecto una asignación crea una variable global, visible desde cualquier punto del programa. Para crear variables locales, que solo existen dentro del bloque donde se declaran, usas la palabra clave local. Usar local siempre que sea posible es la norma en código Lua moderno.

-- Variable global: visible en todo el programa
global = 100

-- Variable local: visible solo en este bloque
local local_ = 200

do
  local bloque = 300      -- local dentro de este bloque "do"
  print(bloque)           -- 300
end
-- print(bloque)  -- error: bloque no existe fuera del do...end

print(global)             -- 100
print(local_)             -- 200

La anteposición del guion bajo después de local es una convención para nombres; la variable real se llama local_. Lo esencial es recordar que sin local estás llenando el espacio global con nombres que podrían chocar con los de otras librerías.

FormaÁmbitoCuándo usarla
x = 1Global (todo el programa)Solo en scripts cortos o para APIs públicas
local x = 1Local al bloque actualCasi siempre; la opción recomendada

Una variable sin valor inicial en Lua no es un error: toma automáticamente el valor nil. Esto convierte a Lua en un lenguaje muy tolerante, pero puede ocultar bugs si olvidas inicializar variables importantes.

Tipos de datos

Lua es un lenguaje de tipado dinámico: una misma variable puede guardar valores de tipos distintos a lo largo del programa sin declararlo. Aun así, cada valor pertenece a uno de los ocho tipos básicos que Lua reconoce, y la función type() te dice cuál es.

print(type("hola"))     --> string
print(type(42))         --> number
print(type(3.14))       --> number
print(type(true))       --> boolean
print(type(nil))        --> nil
print(type({}))         --> table
print(type(print))      --> function
print(type(io.stdout))  --> userdata

Como el tipo es una propiedad del valor, no de la variable, puedes reasignar x = 1 y luego x = "texto" sin problemas. Herramientas de análisis estático modernas (como el diagnóstico de sumneko) te ayudan a detectar estos cambios si quieres más rigor.

nil y booleanos

nil representa «la ausencia de valor»: es el valor por defecto de cualquier variable no inicializada, de los índices inexistentes de una tabla y del retorno de funciones que no devuelven nada. boolean tiene dos únicos valores, true y false, usados en condiciones.

local a            -- a vale nil
print(a)           --> nil

local b = 5
b = nil            -- borrar una variable: le devolvemos nil
print(b)           --> nil

print(true and false)   --> false
print(true or false)    --> true
print(not true)         --> false

Un detalle crucial de Lua: solo false y nil se consideran «falsos» en una condición. Todo lo demás — incluyendo el número 0 y la cadena vacía "" — es verdadero. Esto sorprende a quienes vienen de otros lenguajes.

if 0 then print("0 es verdadero") end      --> 0 es verdadero
if "" then print("cadena vacía es verdadera") end  --> sí se imprime
if nil then print("nunca") else print("nil es falso") end  --> nil es falso

-- Asignación múltiple con or: valor por defecto
local nombre = nombre or "Anónimo"
print(nombre)      --> Anónimo

El patrón x = x or valor_predeterminado funciona solo porque nil es falso y false también. Si un valor legítimo pudiera ser false o 0, este atajo devolvería el defecto por error: en esos casos usa una comparación explícita con == nil.

Conocer la «verdad» de un valor es esencial en Lua. Cuando leas código ajeno, recuerda la regla de oro: solo nil y false son falsos.

Números y strings

Lua distingue dos subtipos de number: enteros y flotantes (decimales), manejados de forma transparente. Un número con parte decimal se llama flotante; uno sin ella, entero. La aritmética elige el resultado más preciso automáticamente.

print(7 / 2)        --> 3.5   (división siempre devuelve flotante)
print(7 // 2)       --> 3     (división entera)
print(7 % 2)        --> 1     (módulo / resto)
print(2 ^ 10)       --> 1024  (potencia)
print(math.floor(3.9))  --> 3
print(math.ceil(3.1))   --> 4

Los strings son cadenas inmutables de bytes. Pueden escribirse con comillas simples, dobles y también con llaves dobles [[ ]] para bloques multilínea. La concatenación se hace con .., nunca con + (que solo suma números):

local saludo = "Hola"
local nombre = 'Lua'
print(saludo .. ", " .. nombre .. "!")   --> Hola, Lua!

-- String multilínea con [[ ]]
local poema = [[
Línea uno
Línea dos
]]
print(poema)

-- Tamaño y subcadena
local texto = "GuiaDev"
print(#texto)                 --> 7   (longitud)
print(string.upper(texto))    --> GUIADEV
print(string.sub(texto, 1, 4)) --> Guia
print(string.rep("ab", 3))    --> ababab

Para convertir entre números y textos usa tostring() y tonumber(). tonumber("42") devuelve 42 y tostring(3.14) devuelve "3.14". Utilízalos siempre que cruces la frontera entre tipos.

Operadores

Lua agrupa sus operadores en aritméticos, relacionales, lógicos, de concatenación y de longitud. Conocer la precedencia y el comportamiento de cada grupo evita errores sutiles. Los operadores lógicos and, or y not son de los más usados y tienen un comportamiento especial: and y or devuelven uno de sus operandos, no siempre un booleano.

-- Aritméticos
local a, b = 10, 3
print(a + b, a - b, a * b)   --> 13	7	30
print(a / b, a % b, a ^ 2)   --> 3.3333333333333	1	100

-- Relacionales (devuelven boolean)
print(10 == 10)      --> true
print(10 ~= 3)       --> true  (distinto de, con ~)
print(10 < 3)        --> false
print("abc" < "abd") --> true  (comparación lexicográfica)

-- Lógicos: and/or devuelven un operando
print(nil and "x")   --> nil
print(false or "y")  --> y
print(5 and 7)       --> 7     (ambos verdaderos: devuelve el segundo)

-- Asignación múltiple e intercambio de valores
local x, y = 1, 2
x, y = y, x            -- intercambio sin variable temporal
print(x, y)            --> 2	1

-- Operadores en cadenas de comparación
local edad = 25
if edad >= 18 and edad < 65 then
  print("Adulto en edad laboral")
end

Lua no tiene operadores de incremento como ++ ni de asignación compuesta como +=. Debes escribir x = x + 1 siempre. Es una diferencia notable si vienes de C, Java o JavaScript.

Ejercicios prácticos

Practica variables y tipos creando scripts pequeños y ejecutándolos con lua. Recuerda sustituir cada fragmento por tu propia solución y comprobar la salida.

  1. Type de cada valor: Escribe un script que use type() para imprimir el tipo de "7", 7, 7.0, true, nil y de una función. Comenta el resultado en cada línea.
  2. Ámbito local vs global: Crea una variable global g y otra local l dentro de un bloque do ... end. Intenta imprimir l fuera del bloque y observa el error de nil. Escribe la explicación en un comentario.
  3. Calculadora de números: Con dos variables locales a = 15 y b = 4, imprime suma, resta, multiplicación, división, división entera, módulo y potencia.
  4. Manipular strings: Dado local frase = "GuiaDev aprende Lua", imprime su longitud con #, la versión en mayúsculas, y las subcadenas "Dev" y "Lua".
  5. Desafío: Usa el patrón or con valor por defecto para escribir una función que reciba un nombre y salude con "Anónimo" si no se le pasa ninguno. Prueba con nil y con un nombre real.
