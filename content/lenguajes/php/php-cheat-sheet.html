Palabras reservadas

Una palabra reservada es una palabra que no puedes usar como nombre de variable porque PHP la usa para su propia sintaxis. Recuerda que en PHP toda variable empieza con el símbolo $.

CategoríaPalabrasQué hacen
Control de flujoif, else, elseifToman decisiones según una condición.
Selección múltipleswitch, case, defaultEliges entre varias opciones.
Buclesfor, foreach, while, doRepiten un bloque de código.
Control de buclesbreak, continueCortan el bucle o saltan a la siguiente iteración.
Funcionesfunction, returnDefinen una función y devuelven su resultado.
Clases y herenciaclass, new, extends, interface, implements, abstract, finalCrean clases, objetos, interfaces y herencia.
Visibilidadpublic, private, protected, staticControlan el acceso a propiedades y métodos.
Variablesecho, print, isset, unset, globalMuestran, comprueban, eliminan y amplían el ámbito de variables.
Excepcionestry, catch, throw, finallyCapturan y lanzan errores controlados.
Organizaciónuse, namespaceImportan clases y organizan el código en espacios de nombres.
Incluir archivosrequire, include, require_once, include_onceInsertan el contenido de otro archivo PHP.
Referencia en clases$this, self, parentApuntan al objeto actual, a la clase o a la clase padre.
Literalesnull, true, falseRepresentan "sin valor", verdadero y falso.

Las palabras reservadas no distinguen mayúsculas de minúsculas: IF equivale a if. Por costumbre se escriben en minúsculas.

Sintaxis básica

El código PHP se incrusta dentro del HTML usando las etiquetas de apertura <?php y cierre ?>. Todo lo que esté fuera de ellas se imprime tal cual como HTML.

<!DOCTYPE html>
<html>
<body>
    <h1>Bienvenido</h1>
    <?php
        // Comentario de una línea
        # Otro comentario de una línea (estilo shell)
        /* Comentario
           de varias líneas */

        $nombre = "Ana";      // las variables empiezan con $
        $edad = 25;

        echo "Hola, $nombre"; // imprime: Hola, Ana
    ?>
</body>
</html>

Las variables empiezan con $ y son sensibles a mayúsculas: $nombre y $Nombre son diferentes. La concatenación usa el punto (.).

Tipos de datos

PHP es de tipado dinámico: no declaras el tipo de una variable, se infiere automáticamente del valor asignado y puede cambiar durante la ejecución.

TipoQué guardaEjemplo
int / floatNúmeros enteros y decimales$edad = 25;, $precio = 19.99;
stringTextos con comillas simples o dobles$nombre = "Ana";
boolVerdadero o falso$activo = true;
arrayColecciones de valores con índices o claves$colores = ["rojo", "azul"];
objectInstancias de clases$u = new Usuario();
NULLUna variable sin valor$nada = null;

Con comillas dobles las variables se interpolan dentro del texto; con comillas simples no.

<?php
    $nombre = "Ana";

    // Interpolación en comillas dobles
    echo "Hola $nombre";          // Hola Ana

    // Paso por concatenación con punto
    echo 'Hola ' . $nombre;       // Hola Ana
?>

Puedes comprobar el tipo de una variable con gettype($var) o verificar el tipo con is_int(), is_string(), is_array(), etc.

También están la concatenación con el punto (.) y la asignación con concatenación (.=). La gran diferencia entre == y === es que === exige que ambos lados sean del mismísimo tipo.

<?php
    $a = 10;
    $b = "10";

    var_dump($a == $b);    // bool(true)  -> solo compara el valor
    var_dump($a === $b);   // bool(false) -> 10 no es de tipo string

    // Concatenación y su asignación
    $saludo = "Hola";
    $saludo .= " Mundo";   // equivale a $saludo = $saludo . " Mundo";
    echo $saludo;          // Hola Mundo

    // Ternario: $resultado = (condicion) ? valor_si_true : valor_si_false
    $edad = 18;
    echo $edad >= 18 ? "Mayor de edad" : "Menor de edad";
?>

Usa siempre === en comparaciones con valores que podrían ser ambiguos (0, "", null). Evita sorpresas tipo 0 == "abc".

Estructuras de control

Condicional: if / elseif / else

<?php
    $nota = 7.5;

    if ($nota >= 9) {
        echo "Sobresaliente";
    } elseif ($nota >= 7) {
        echo "Notable";
    } else {
        echo "Debes estudiar más";
    }
?>

Selección múltiple: switch

<?php
    $opcion = 2;

    switch ($opcion) {
        case 1:
            echo "Elegiste uno";
            break;
        case 2:
            echo "Elegiste dos";
            break;
        default:
            echo "Opción no válida";
    }
?>

Bucle: for

<?php
    for ($i = 0; $i < 5; $i++) {
        echo $i; // 0 1 2 3 4
    }
?>

Bucle: foreach (muy usado para arrays)

<?php
    $colores = ["rojo", "verde", "azul"];

    foreach ($colores as $color) {
        echo $color . "<br>";
    }

    // Con clave y valor (arrays asociativos)
    $persona = ["nombre" => "Ana", "edad" => 30];
    foreach ($persona as $clave => $valor) {
        echo "$clave: $valor<br>";
    }
?>

Bucle: while

<?php
    $i = 0;
    while ($i < 5) {
        echo $i;
        $i++;
    }
?>

Bucle: do-while (se ejecuta al menos una vez)

<?php
    $i = 0;
    do {
        echo $i;
        $i++;
    } while ($i < 5);
?>

break y continue

<?php
    for ($i = 0; $i < 10; $i++) {
        if ($i == 3) continue;  // se salta el 3
        if ($i == 7) break;     // termina el bucle en el 7
        echo $i;                // 0 1 2 4 5 6
    }
?>

break sale del bucle o del switch; continue salta a la siguiente iteración. Ambos aceptan un nivel: break 2 sale de dos bucles anidados.

Funciones y arrays

Definir y llamar una función

<?php
    function sumar($a, $b) {
        return $a + $b;
    }

    echo sumar(3, 4); // 7
?>

Arrays indexados y asociativos

<?php
    // Array indexado (los índices empiezan en 0)
    $frutas = ["manzana", "pera", "uva"];
    echo $frutas[0];            // manzana

    // Array asociativo (claves personalizadas)
    $usuario = ["nombre" => "Ana", "edad" => 30];
    echo $usuario["nombre"];    // Ana

    // Agregar y recorrer
    $frutas[] = "naranja";      // agrega al final
    foreach ($frutas as $fruta) {
        echo $fruta;
    }
?>

Funciones útiles de arrays

<?php
    $nombres = ["Ana", "Luis"];

    echo count($nombres);        // 2 (número de elementos)

    array_push($nombres, "Iván");       // agrega "Iván" al final
    sort($nombres);                     // ordena A-Z

    var_dump(in_array("Ana", $nombres)); // bool(true) ¿existe?

    echo implode(", ", $nombres);   // convierte array en string
    $partes = explode(",", "uno,dos"); // convierte string en array

    $a = [1, 2];
    $b = [3, 4];
    $merged = array_merge($a, $b);  // [1, 2, 3, 4]

    $edad = 30;
    if (isset($edad)) { echo "Existe"; }   // comprueba que existe
    unset($edad);                          // elimina la variable
?>

Desde PHP 5.4 los arrays se declaran con corchetes [...] en lugar de array(...). El acceso a elementos se hace siempre con corchetes: $arr[0], $arr["clave"].

POO y formularios web

Clase con constructor, métodos e instanciación

<?php
    class Persona {
        private $nombre;

        // Constructor: se ejecuta al instanciar
        public function __construct($nombre) {
            $this->nombre = $nombre;   // $this->propiedad
        }

        public function saludar() {
            return "Hola, soy " . $this->nombre;
        }
    }

    $persona = new Persona("Ana");    // new + clase
    echo $persona->saludar();
?>

Herencia con extends y parent

<?php
    class Empleado extends Persona {
        private $sueldo;

        public function __construct($nombre, $sueldo) {
            parent::__construct($nombre);  // llama al constructor padre
            $this->sueldo = $sueldo;
        }
    }

    $empleado = new Empleado("Luis", 2000);
    echo $empleado->saludar();
?>

Formulario con $_POST / $_GET y validación

<form method="post" action="procesar.php">
    <input type="text" name="nombre">
    <input type="submit" value="Enviar">
</form>

<?php
    // procesar.php
    if ($_SERVER["REQUEST_METHOD"] == "POST") {
        $nombre = $_POST["nombre"] ?? "";

        if (isset($_POST["nombre"]) && $_POST["nombre"] !== "") {
            echo "Hola, " . htmlspecialchars($nombre);
        } else {
            echo "El campo está vacío";
        }
    }
?>

Los superglobals están disponibles en cualquier parte del script: $_POST (envío POST), $_GET (envío por URL), $_REQUEST (ambos) y $_SERVER (datos del servidor y cabeceras).

Nunca imprimas datos del usuario sin tratarlos. Usa htmlspecialchars() para evitar ataques XSS y valida siempre la entrada con isset(), empty() o filtros.
