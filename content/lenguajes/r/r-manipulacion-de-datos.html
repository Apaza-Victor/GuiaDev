El tidyverse y los pipes %>%

El tidyverse es una colección de paquetes que comparten una filosofía: datos ordenados (tidy data) y expresiones verbales. Su base de manipulación es dplyr y su amortiguador de lectura es el pipe %>%: pasa el resultado de la izquierda como primer argumento de la función de la derecha. Con él, los análisis se leen como una historia, de arriba hacia abajo.

# Instalar y cargar una sola vez
install.packages("tidyverse")
library(tidyverse)   # carga dplyr, ggplot2, tidyr, readr...

# El pipe envía datos hacia la siguiente función
4 %>% sqrt()                 # sqrt(4) = 2
1:10 %>% mean()              # media de 1 a 10
# mpg viene con ggplot2 (incluido en el tidyverse)
mpg

# Cadena anidada SIN pipe: difícil de seguir
head(arrange(filter(mpg, manufacturer == "honda"), year), 5)

# Con pipe: la lectura fluye como un relato
mpg %>%
  filter(manufacturer == "honda") %>%
  arrange(year) %>%
  select(model, year, cty) %>%
  head(5)

---

filter y select

filter() elige las filas que cumplen una condición y select() elige las columnas que te interesan. Juntos son el punto de partida de casi cualquier análisis: primero te quedas con los datos relevantes y luego con las variables necesarias.

# filter: filas según condiciones
mpg %>%
  filter(manufacturer == "honda")

# Varias condiciones se combinan con comas (y lógico)
mpg %>%
  filter(manufacturer == "honda", year == 2008)

# Comparaciones con operadores
mpg %>%
  filter(cty > 25, hwy <= 32)

# Pertenencia y rangos
mpg %>%
  filter(manufacturer %in% c("audi", "volkswagen"))
mpg %>%
  filter(between(cty, 15, 20))
# select: elige columnas por nombre
mpg %>%
  select(manufacturer, model, year)

# Helpers de selección: empieza por, termina en, contiene
mpg %>%
  select(starts_with("m"), ends_with("l"))

# Todo menos una columna
mpg %>%
  select(-model)

# Mover una columna al frente
mpg %>%
  select(class, everything())

Dentro de las condiciones de dplyr usa & y |, por ejemplo filter(cty > 20 & hwy > 30). Los operadores && y || no se vectorizan y producen errores o resultados inesperados al filtrar.

mutate, arrange y rename

mutate() crea o transforma columnas a partir de las existentes (el corazón de la ciencia de datos: la ingeniería de variables). arrange() ordena las filas y rename() cambia los nombres de las columnas. Con esos tres verbos resuelves la mayor parte de la preparación de datos.

# mutate: nuevas columnas que usan otras
mpg %>%
  mutate(consumo_total = cty + hwy,
         economia = if_else(hwy >= 30, "eficiente", "normal")) %>%
  select(manufacturer, model, cty, hwy, consumo_total, economia)

# Las nuevas columnas pueden alimentar a otras en el mismo llamado
mpg %>%
  mutate(efectividad = hwy / displ,
         es_buena = efectividad > mean(efectividad)) %>%
  select(model, efectividad, es_buena)
# arrange: ordenar por una o varias columnas
mpg %>%
  arrange(cty)                     # ascendente por defecto

mpg %>%
  arrange(desc(hwy), cty)          # hwy descendente, desempata con cty

# rename: cambiar nombres (nuevo = viejo)
mpg %>%
  rename(fabricante = manufacturer) %>%
  head(3)

# rename_with: transformar varios nombres a la vez
mpg %>%
  rename_with(toupper)             # nombres en mayúsculas

En mutate() las columnas se evalúan de izquierda a derecha: puedes escribir mutate(base = precio * 0.16, total = precio + base) sin recalcular nada dos veces.

group_by y summarize

El par group_by() + summarize() responde preguntas como "¿cuál es el promedio por fabricante?" o "¿cuántas filas hay por clase?". group_by() marca subgrupos y summarize() colapsa cada grupo a una fila con las estadísticas que pidas.

# Promedio de consumo por fabricante
mpg %>%
  group_by(manufacturer) %>%
  summarize(media_cty = mean(cty),
            n = n()) %>%
  arrange(desc(media_cty))

# Varias medidas a la vez con across
mpg %>%
  group_by(class) %>%
  summarize(across(c(cty, hwy), mean),
            n = n())

# Más de un nivel de agrupación
mpg %>%
  group_by(manufacturer, year) %>%
  summarize(media = mean(hwy), .groups = "drop")
# Datos con valores faltantes: trata los NA
tibble(region = c("norte", "sur", "norte"),
       ventas = c(10, NA, 15)) %>%
  group_by(region) %>%
  summarize(total = sum(ventas, na.rm = TRUE))

summarize() nunca "pierde" las filas si usas na.rm = TRUE en mean(), sum() o sd(). Antes de resumir, pregunta siempre si tus datos tienen faltantes con is.na(x).

Unir tablas con joins

Cuando la información vive repartida en varias tablas, los joins las combinan usando una columna clave común. En dplyr, inner_join() y left_join() cubren la mayoría de los casos: piensa en cliente y pedido, o en película y recaudación.

# Dos tablas conectadas por la columna cliente_id
clientes <- tibble(cliente_id = 1:4,
                   nombre = c("Ana", "Luis", "Eva", "Pablo"))
pedidos <- tibble(cliente_id = c(2, 2, 4),
                  total = c(120, 95, 158))

# inner_join: solo filas con clave en AMBAS tablas
clientes %>%
  inner_join(pedidos, by = "cliente_id")

# left_join: conserva todas las filas de la izquierda
clientes %>%
  left_join(pedidos, by = "cliente_id")
# Join con nombres de clave distintos
clientes2 <- rename(clientes, id = cliente_id)
clientes2 %>%
  inner_join(pedidos, by = c("id" = "cliente_id"))

# anti_join: encuentra filas que NO tienen su par
clientes %>%
  anti_join(pedidos, by = "cliente_id")

# full_join: une todo y rellena con NA lo que falta
clientes %>%
  full_join(pedidos, by = "cliente_id")
JoinQué conservaCaso típico

Si una clave aparece duplicada, los joins multiplican filas (cada par combina una vez). Antes de unir, revisa duplicados con count(tabla, clave) %>% filter(n > 1).

Ejercicios prácticos

Usa el dataset mpg que ya cargaste con el tidyverse.

  1. Filtro selectivo: obtén los autos de toyota del año 2008 con consumo de autopista (hwy) mayor a 30.
  2. Selección quirúrgica: extrae solo manufacturer, model y cty; después aplica select(cty, everything()) y observa cómo queda la tabla.
  3. Ingeniería de variables: con mutate() crea rendimiento = hwy / displ e indica qué fabricante rinde mejor en promedio.
  4. Resumen por clase: con group_by(class) calcula la mediana de cty y el número de autos de cada clase.
  5. Join de negocio: crea dos tibbles (productos y ventas) con una columna producto_id, únelas con left_join() y descubre qué productos no tuvieron ventas con anti_join().

En la próxima lección convertirás tus datos en gráficos impactantes con ggplot2, la pieza estrella del tidyverse.
