La gramática de gráficos

ggplot2 implementa la gramática de gráficos de Leland Wilkinson: cualquier gráfico se construye combinando capas. Declaras los datos (data), mapeas variables a aesthetics con aes() (x, y, color, tamaño) y eliges la geometría (geom_*) que la dibuja. La base de R dibuja con plot(); ggplot2 separa limpiamente estructura, estética y datos.

# La receta básica: datos + aes + geometría
library(ggplot2)

ggplot(data = mpg, aes(x = displ, y = hwy)) +
  geom_point()

# Los datos pasan por el pipe igual que en dplyr
mpg %>%
  ggplot(aes(x = cty, y = hwy)) +
  geom_point() +
  geom_smooth(method = "lm")   # capa de tendencia
# Aesthetics: color según variable y tamaño constante
mpg %>%
  ggplot(aes(x = displ, y = hwy, color = class)) +
  geom_point(size = 2)

# Un color fijo NO va dentro de aes()
mpg %>%
  ggplot(aes(x = displ, y = hwy)) +
  geom_point(color = "#1a8f77")
GeometríaÚsala paraAsociada a
geom_point()Relación numérica vs numéricaDispersión (scatter)
geom_line()Cambio a lo largo del tiempoSeries temporales

Regla mental: dentro de aes() van variables de tus datos (se mapean y generan leyenda automática); fuera de aes() van constantes (un solo color, un solo tamaño).

Gráficos de puntos y líneas

Los puntos exploran la relación entre dos variables numéricas y las líneas describen la evolución en el tiempo. Usos típicos: dispersión para detectar tendencias u outliers, y líneas para series ordenadas por fecha.

# Dispersión con color a una tercera variable
mpg %>%
  ggplot(aes(x = displ, y = hwy, color = drv)) +
  geom_point(alpha = 0.6)      # transparencia para puntos solapados

# Tendencia suave por grupo con una capa más
mpg %>%
  ggplot(aes(x = displ, y = hwy, color = drv)) +
  geom_point(alpha = 0.5) +
  geom_smooth(se = FALSE, method = "lm")
# Serie temporal de ejemplo
ventas_mes <- data.frame(
  mes  = seq(as.Date("2025-01-01"), by = "month", length.out = 8),
  venta = c(120, 135, 110, 148, 152, 143, 165, 178))

ventas_mes %>%
  ggplot(aes(x = mes, y = venta)) +
  geom_line(color = "steelblue", linewidth = 1.2) +
  geom_point()

# Dos series: otra variable de grupo las colorea
tabla <- data.frame(
  mes   = rep(ventas_mes$mes, 2),
  venta = c(ventas_mes$venta, ventas_mes$venta * 1.1),
  tipo  = rep(c("real", "meta"), each = 8))

tabla %>%
  ggplot(aes(x = mes, y = venta, color = tipo)) +
  geom_line()

En versiones recientes de ggplot2 el grosor de una línea se controla con linewidth. El viejo size sigue funcionando, pero puede emitir avisos de deprecación en algunas geometrías.

Barras e histogramas

Las barras dibujan frecuencias de una categórica y los histogramas la distribución de una numérica. Detalle clave: geom_bar() cuenta automáticamente; geom_col() usa los valores que ya tienes en una columna.

# geom_bar: cuenta ocurrencias por categoría
mpg %>%
  ggplot(aes(x = class)) +
  geom_bar()

# Fill apila otra categoría dentro de cada barra
mpg %>%
  ggplot(aes(x = class, fill = drv)) +
  geom_bar()

# geom_col: valores ya precalculados en los datos
resumen <- mpg %>%
  group_by(manufacturer) %>%
  summarize(media_hwy = mean(hwy))

resumen %>%
  ggplot(aes(x = manufacturer, y = media_hwy)) +
  geom_col()
# Histograma: distribución de una variable continua
mpg %>%
  ggplot(aes(x = hwy)) +
  geom_histogram(bins = 20, fill = "gray40", color = "white")

# Densidad: versión suavizada, fácil de superponer
mpg %>%
  ggplot(aes(x = hwy, fill = drv)) +
  geom_density(alpha = 0.4)

# Boxplot: resumen numérico por categoría
mpg %>%
  ggplot(aes(x = drv, y = hwy)) +
  geom_boxplot()

Si usas geom_bar() con un y que ya viene calculado en tus datos, R contará ese y en lugar de mostrarlo. Para valores agregados usa geom_col(): es la confusión número uno en ggplot2.

Facetas y temas

Las facetas cortan los datos y producen un subgráfico por categoría, ideales para comparar grupos sin abarrotar una sola gráfica. Los temas controlan todo lo que no son datos: fondo, títulos, leyenda y ejes.

# facet_wrap: un panel por valor de una variable
mpg %>%
  ggplot(aes(x = displ, y = hwy)) +
  geom_point() +
  facet_wrap(~ drv)

# facet_grid: filas y columnas con dos variables
mpg %>%
  ggplot(aes(x = displ, y = hwy)) +
  geom_point() +
  facet_grid(year ~ drv)

# Escalas libres para que los paneles no se compriman
mpg %>%
  ggplot(aes(x = class)) +
  geom_bar() +
  facet_wrap(~ year, scales = "free_y")
# labs: título, subtítulo y etiquetas de ejes
mpg %>%
  ggplot(aes(x = displ, y = hwy)) +
  geom_point() +
  labs(title = "Consumo vs cilindrada",
       subtitle = "Datos mpg de ggplot2",
       x = "Cilindrada (litros)", y = "Autopista (mpg)")

# Temas listos: quitan la decoración del fondo
mpg %>%
  ggplot(aes(x = displ, y = hwy)) +
  geom_point() +
  theme_minimal()

# theme(): control fino de un elemento concreto
mpg %>%
  ggplot(aes(x = class, y = hwy)) +
  geom_boxplot() +
  theme_minimal() +
  theme(axis.text.x = element_text(angle = 45, hjust = 1))

Empieza tus gráficas con theme_minimal() o theme_classic() y añade limpieza extra solo si hace falta. Si necesitas una imagen institucional, el paquete hrbrthemes ofrece temas pulidos listos para usar.

Guardar y exportar gráficos

Un gráfico solo es útil si se puede exportar. En RStudio el botón Export funciona, pero el camino reproducible es ggsave(): respeta el tamaño y la resolución que decides y se ejecuta dentro del script para que cualquiera regenere el mismo archivo.

# Construir el gráfico y guardarlo en un objeto
g <- mpg %>%
  ggplot(aes(x = displ, y = hwy, color = drv)) +
  geom_point() +
  theme_minimal() +
  labs(title = "Consumo por tipo de tracción")

ggsave("grafico_dispersion.png", plot = g,
       width = 8, height = 5, dpi = 300)

# Si omites plot, se exporta el último gráfico
ggplot(mpg, aes(x = class)) + geom_bar()
ggsave("grafico_barras.pdf", width = 6, height = 4)
# Elegir el formato según el destino final
ggsave("informe.svg", plot = g, width = 8, height = 5)   # vectorial para web
ggsave("diapositiva.png", plot = g, width = 10, height = 5.6, dpi = 150)

# Control explícito del dispositivo gráfico base R
png("dispersion_base.png", width = 700, height = 500, res = 150)
plot(mpg$displ, mpg$hwy)
dev.off()   # no olvides cerrar el dispositivo

Regla práctica: 300 dpi para imprimir, 96-150 dpi para pantalla o web y SVG para elementos vectoriales. Guardar el gráfico en un objeto g te permite reexportarlo al instante cuando cambias una capa.

Ejercicios prácticos

Trabaja con el dataset mpg. Cada ejercicio termina con una exportación.

  1. Dispersión básica: grafica displ vs cty coloreando por year, con puntos semitransparentes. Exporta a dispersion.png a 300 dpi.
  2. Serie de líneas: inventa 10 puntos de ventas mensuales y grafícalos como línea con puntos encima, con títulos claros en labs().
  3. Histograma de grano fino: la distribución de hwy con bins = 30 y bordes blancos; guarda el resultado en SVG.
  4. Facetas con grid: aplica facet_grid(drv ~ year) sobre un scatter de displ vs hwy y observa cómo cambia la relación entre paneles.
  5. Boxplot comparado: boxplot de hwy por class ordenado por mediana (ayúdate de reorder() dentro de aes()) y con theme_minimal().
