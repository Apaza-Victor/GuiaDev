¿Qué es R y por qué usarlo?

R es un lenguaje de programación diseñado para estadística, análisis de datos y visualización. Nació en 1993 de la mano de Ross Ihaka y Robert Gentleman en Nueva Zelanda, y hoy es el estándar en disciplinas como la bioestadística, la econometría o la ciencia de datos. Su sintaxis recuerda a S, pero su verdadero poder está en el ecosistema de paquetes: desde la manipulación de tablas (dplyr) hasta el aprendizaje automático (tidymodels), pasando por gráficos de alta calidad (ggplot2).

# R funciona como una calculadora muy potente
2 + 2
10 / 4
sqrt(81)

# La asignación se hace con la flecha:

Instalación de R y RStudio

Para trabajar necesitas dos piezas: el motor de R (los binarios que ejecutan el código) y un IDE agradable. RStudio, hoy de Posit, es la opción más popular: integra consola, editor de scripts, visor de datos y panel de gráficos. Instala primero R y después RStudio, siempre en ese orden.

Tu primer script y la consola

En R hay dos lugares donde escribir código: la consola (ejecuta y olvida) y un script (archivo .R con tu análisis, guardado y reproducible). En los scripts los comentarios con # son tus aliados: documentan qué hace cada bloque y, sobre todo, por qué.

# Este es tu primer script: se lee de arriba hacia abajo
set.seed(2026)             # hace "aleatorios" reproducibles
n <- 30                    # tamaño de muestra

# Genera una muestra simulada: 30 puntajes entre 50 y 100
puntajes <- round(runif(n, min = 50, max = 100))

# Resumen en la consola
print(puntajes)
summary(puntajes)
# Reglas de la consola: todo lo que escribes "contesta"
x <- 5
x * 2                       # R imprime el resultado al instante
mensaje <- "hola mundo"
print(mensaje)              # imprime con etiquetas
cat(mensaje)                # imprime "limpio", sin etiquetas

# Guardar el historial para retomarlo después
savehistory("mi_historia.Rhistory")

Navegar la ayuda y los paquetes

La documentación de R es extensa y está integrada. Cualquier función tiene su página de ayuda con descripción, argumentos, ejemplos reproducibles y referencias. Dominar la ayuda (en inglés, como casi toda la documentación técnica) te vuelve autodidacta de verdad.

# Formas equivalentes de pedir ayuda
?mean              # atajo más usado
help("mean")       # la forma explícita
args(mean)         # solo la firma de la función

# Buscar en todas las funciones instaladas
??"correlacion"    # búsqueda por tema
help.search("regression")

# Ejemplos reproducibles sin salir de la ayuda
example(mean)
demo(graphics)     # una galería de gráficos base
# Los paquetes son extensiones: instalar una vez, cargar siempre
install.packages("datos")     # datasets con nombres en español

library(datos)                # carga el paquete en la sesión
?millas                       # documentación del dataset interno
vignette("datos")             # tutorial largo del paquete

Tipos de datos básicos

En R todo lo que guardas es un objeto con un tipo subyacente (typeof) y una clase (cómo se comporta). Los tipos básicos son pocos: numéricos, enteros, character (texto), lógicos y factores para categorías. Con estos cinco construyes todo lo demás.

# Crear objetos de cada tipo atómico
n_preciso <- 3.1416          # numeric (doble precisión)
n_entero <- 42L              # integer (sufijo L)
texto <- "ciencia de datos"  # character
logico <- TRUE               # logical (TRUE / FALSE)

# Inspeccionar tipo y clase
typeof(n_preciso)            # "double"
typeof(n_entero)             # "integer"
class(texto)                 # "character"
is.numeric(n_preciso)        # TRUE
is.logical(logico)           # TRUE
# NA (Not Available) es especial: representa el dato faltante
x <- c(1, 2, NA, 4)
mean(x)                        # NA: la media con faltantes no es fiable
mean(x, na.rm = TRUE)          # 2.333333, ignora el NA de forma explícita
is.na(x)                       # nos dice dónde faltan datos

# Comparaciones lógicas
edad <- 25
edad <= 30                     # TRUE
edad > 18 & edad < 65        # TRUE (ambas condiciones)

# Coerción automática hacia el tipo "más capaz"
c(1, "dos")        # character: el texto gana
c(TRUE, 1)         # numeric: TRUE pasa a 1

Ejercicios prácticos

Resuélvelos en tu propio script de RStudio. Todo lo necesario está en esta lección.

  1. Calculadora personal: asigna tu peso y tu altura en variables claras, y calcula con R tu imc (peso dividido entre la altura al cuadrado).
  2. Tipos delator: crea un objeto para cada tipo básico y verifica su tipo con typeof(); confirma que 3.5 es double.
  3. Caza del NA: construye un vector con un NA y calcula su media con y sin na.rm = TRUE, explicando la diferencia entre los dos resultados.
  4. Explorador de ayuda: usa ? y example() sobre runif y seq, y anota en un comentario qué hace cada una.
  5. Hola mundo con clase: crea un script que guarde tu nombre como objeto character, lo imprima y muestre su class() y length().
