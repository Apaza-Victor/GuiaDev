Vectores y operaciones vectorizadas

El vector es la unidad mínima de R: una colección ordenada de valores del mismo tipo. No existen "escalares": incluso x <- 5 crea un vector de longitud 1. La gran ventaja es la vectorización: las operaciones se aplican a todos los elementos a la vez, sin necesidad de bucles explícitos.

# Construcción de vectores
a <- c(1, 2, 3, 4)            # concatenar con c()
b <- 1:10                      # secuencia entera
c <- seq(0, 1, by = 0.25)      # secuencia con paso
d <- rep("tipoA", 3)           # repetir un valor
mezcla <- c("a", "b", 1, 2)    # coerción a character

# Indexado: R empieza a contar en 1
a[1]           # 1
a[c(1, 3)]     # 1 3
b[-3]          # todos menos el tercero
# Operaciones vectorizadas: sin bucles
notas <- c(7, 8, 5, 9, 6)
notas + 1                  # sube 1 a cada nota
notas * 2
sqrt(notas)
notas > 6                   # comparación elemento a elemento

# Reciclaje: el vector corto se repite
c(1, 2, 3, 4) + c(10, 20)   # 11 22 13 24
sum(notas)                  # suma total
mean(notas)                 # promedio

Los bucles for existen en R, pero casi siempre hay alternativa vectorizada más rápida y legible. Si te descubres llenando un vector elemento a elemento, pregúntate si c() o alguna función te lo ahorra.

Factores y variables categóricas

Un factor es un vector con un conjunto fijo de niveles (levels). Representa variables categóricas: sexo, departamento, escala de satisfacción. Internamente guarda los niveles como números y las etiquetas como textos, lo que permite que los modelos estadísticos traten cada categoría de forma correcta.

# Crear un factor simple
region <- factor(c("norte", "sur", "norte", "este"))
region
levels(region)          # en qué categorías se organiza
nlevels(region)         # cuántas hay
table(region)           # recuento por nivel

# Factores ordenados: categóricas con jerarquía
satisfaccion <- factor(c("baja", "alta", "media"),
                       levels = c("baja", "media", "alta"),
                       ordered = TRUE)
satisfaccion > "baja"   # compara jerarquías
# Importar un CSV y decidir qué será factor
datos <- read.csv("ventas.csv", stringsAsFactors = TRUE)

# Recodificar un nivel
levels(datos$region)[levels(datos$region) == "n"] <- "norte"

# Frecuencias y proporciones
tabla <- table(datos$region)
tabla
prop.table(tabla)        # porcentaje de cada nivel

Matrices y arreglos

Una matriz es un vector con dos dimensiones: filas y columnas, todos del mismo tipo. Son la base de los cómputos lineales (álgebra, regresión) y de la lectura natural de grillas de datos. Se rellenan por columnas por defecto, una decisión que conviene conocer.

# Crear matrices
m <- matrix(1:12, nrow = 3, ncol = 4)
m

# Rellena por filas si lo prefieres
m2 <- matrix(1:12, nrow = 3, byrow = TRUE)

# Unir vectores como filas o columnas
rbind(c(1, 2), c(3, 4))       # por filas
cbind(c(1, 2), c(3, 4))       # por columnas

# Dimensiones
dim(m)          # 3 4
nrow(m)         # 3
ncol(m)         # 4
# Indexado con [fila, columna]
m[2, 3]            # elemento fila 2, columna 3
m[1, ]             # toda la fila 1 (devuelve vector)
m[, 2]             # toda la columna 2
m[2:3, c(1, 4)]    # submatriz

# Álgebra matricial
A <- matrix(c(2, 1, 1, 3), nrow = 2)
B <- matrix(c(1, 0, 0, 1), nrow = 2)
A %*% B            # producto matricial
solve(A)           # inversa de A

# Operaciones sobre dimensiones
colSums(m)
rowMeans(m)

matrix() rellena por columnas. Si tus datos vienen por filas, usa byrow = TRUE; la confusión con el orden de llenado es un clásico generador de bugs silenciosos.

Data frames: la estructura central

El data frame es la forma natural de las tablas de datos: columnas como variables y filas como observaciones. Cada columna puede tener su propio tipo, lo que lo vuelve perfecto para datasets reales. Es el objeto que ves con View() en RStudio y el que alimenta a ggplot2.

# Crear un data frame a partir de vectores
nombres <- c("Ana", "Luis", "Eva", "Pablo")
ventas <- c(120, 95, 158, 88)
region <- factor(c("norte", "sur", "norte", "sur"))

df <- data.frame(nombre = nombres,
                 ventas = ventas,
                 region = region)
df
str(df)          # estructura: tipos y primeras filas
summary(df)      # resumen numérico y de factores
# Acceso a columnas
df$ventas                 # vector por nombre
df[["ventas"]]            # equivalente con dobles corchetes
df[, "ventas"]            # por índice de columnas
df["ventas"]              # devuelve un data frame, no un vector

# Filtrado de filas
df[df$region == "norte", ]                    # solo norte
df[df$ventas > 100, ]                        # ventas mayores a 100
df[order(df$ventas, decreasing = TRUE), ]     # ordenado descendente

# Agregar una nueva columna
df$venta_alta <- df$ventas > 100
df

Listas

Una lista es un contenedor heterogéneo: puede guardar vectores, matrices, data frames y hasta otras listas, cada uno con un nombre propio. No exige que los elementos sean del mismo tipo ni del mismo largo; por eso es el encargado de agrupar resultados complejos.

# Crear una lista con nombres
resultado <- list(
  media = 45.2,
  tabla = table(c("a", "b", "a")),
  resumen = c(min = 10, max = 90)
)
resultado             # muestra todos los componentes

# Extraer elementos
resultado$media            # por nombre con $
resultado[["media"]]       # por nombre con dobles corchetes
resultado[[1]]             # por posición

# Ojo con [ frente a [[
resultado[1]      # lista con 1 elemento
resultado[[1]]    # el valor en sí (un numeric)
# Aplicar funciones a cada elemento con lapply
numeros <- list(a = 1:3, b = 4:6, c = 7:9)
lapply(numeros, mean)      # devuelve lista con las medias
sapply(numeros, mean)      # devuelve vector con las medias

# Listas que anidan: los resultados de modelos estadísticos
modelo <- lm(ventas ~ region, data = df)
class(modelo)              # "lm"
modelo$coefficients        # accede a una parte del modelo

# Longitudes y nombres
length(resultado)
names(resultado)

Regla mnemotécnica: lista[[x]] te da el contenido; lista[x] te da la caja. Si un resultado te sale list() donde esperabas un número, casi seguro usaste corchete simple.

Ejercicios prácticos

Resuélvelos en tu script. Todo lo necesario está en esta lección.

  1. Vector de ventas: crea un vector con 6 valores de ventas diarias, calcula su media, el valor máximo y las posiciones donde cada venta supera el promedio.
  2. Factor ordenado: crea un factor con niveles baja, media, alta en orden, y cuenta cuántos casos caen en cada nivel con table().
  3. Matriz 3x4: construye una matriz de 12 números rellena por filas, extrae la segunda fila y la tercera columna, y calcula colSums().
  4. Data frame de nombres: arma un data frame con 5 personas (nombre, edad, ciudad) y filtra las mayores de 25 años.
  5. Lista de resultados: guarda en una lista la media, la mediana y la desviación típica de un vector, y extrae la mediana con [[ y con $.
