Estadística descriptiva

Antes de modelar hay que describir. La estadística descriptiva resume datos con medidas de tendencia central (media, mediana) y de dispersión (desviación típica, rango, cuantiles). R trae todo esto de serie y summary() lo condensa en una sola línea de salida.

# Una muestra numérica de ejemplo
x <- c(12, 15, 15, 18, 21, 22, 24, 27, 30, 42)

# Medidas de tendencia central
mean(x)          # media aritmética
median(x)        # mediana: el valor del centro
table(x)[table(x) == max(table(x))]   # moda (en R nativo se calcula así)

# Medidas de dispersión
sd(x)            # desviación típica muestral
var(x)           # varianza
range(x)         # mínimo y máximo
diff(range(x))   # recorrido
# Cuantiles y resumen rápido
quantile(x, probs = c(0.25, 0.5, 0.75))
IQR(x)                       # rango intercuartílico
summary(x)                   # min, cuartiles, media, max

# Aplicar mediciones a todo un dataset
data(iris)
summary(iris)
apply(iris[, 1:4], 2, mean)  # media de las 4 columnas numéricas

# Ojo con los NA
x_con_na <- c(x, NA)
mean(x_con_na, na.rm = TRUE)   # sin na.rm devolvería NA

Mediamean()El valor promedio "típico"

La media "se asusta" ante un valor extremo: un ingreso de 100.000 en un barrio de ingresos normales dispara la media pero no la mediana. Compara siempre ambas para detectar datos atípicos.

Correlación y regresión lineal

La correlación mide fuerza y dirección de la asociación lineal entre dos variables, en una escala de -1 a 1. La regresión va un paso más allá: modela esa relación para predecir. En R base, cor(), cor.test() y lm() cubren ambos mundos.

# Datos: temperatura en la calle y precio de la cerveza
temp <- c(21, 26, 18, 30, 24, 27, 20, 29, 23, 25)
precio <- c(3.1, 3.8, 2.9, 4.2, 3.4, 4.0, 2.8, 4.4, 3.5, 3.9)

# Coeficiente de correlación de Pearson
cor(temp, precio)                      # cercano a 1: fuerte y positiva
round(cor(temp, precio), 3)

# Alternativa no paramétrica
cor(temp, precio, method = "spearman")

# Prueba formal de significancia
cor.test(temp, precio)
# Matriz de correlaciones para muchas variables
datos_nums <- iris[, 1:4]
round(cor(datos_nums), 3)

# Visualizarla ayuda a intuir patrones
cor(datos_nums) %>%
  as.data.frame() %>%
  mutate(variable = rownames(.)) %>%
  pivot_longer(-variable, names_to = "con", values_to = "r") %>%
  ggplot(aes(x = variable, y = con, fill = r)) +
  geom_tile()

Correlación no implica causalidad: la altura de los pingüinos correlaciona con su peso, pero no "causa" el peso. La correlación describe asociación; la causa requiere diseño experimental o teoría.

Modelos lineales con lm()

La regresión lineal ajusta una recta (o un plano) a tus datos. La función lm() estima los coeficientes por mínimos cuadrados usando la notación de fórmulas y ~ x1 + x2. Los resultados se inspeccionan con summary() y se proyectan a nuevos casos con predict().

# Regresión simple: un predictor
modelo <- lm(precio ~ temp)
modelo                    # coeficientes estimados
coef(modelo)              # (Intercept) y pendiente

# Regresión múltiple con datos clásicos
data(mtcars)
m <- lm(mpg ~ wt + hp, data = mtcars)
coef(m)
# Predecir para valores nuevos
nuevos <- data.frame(temp = c(22, 28, 35))
predict(modelo, nuevos)

# Diagnóstico básico: ajustados y residuales
fitted(modelo)
residuales <- resid(modelo)

# Fórmula con todos los predictores excepto "mpg"
m_todo <- lm(mpg ~ ., data = mtcars)

# Interacciones entre variables
m2 <- lm(mpg ~ wt * hp, data = mtcars)   # wt + hp + su interacción

lm() usa por defecto las filas completas: si una observación tiene NA en alguna variable del modelo, se descarta entera en silencio. Revisa cuántas filas eliminas y documéntalo en tu análisis.

Pruebas de hipótesis

Las pruebas de hipótesis responden con criterio estadístico a la pregunta "¿esta diferencia es real o pudo ser azar?". Declaramos una hipótesis nula (H0, por defecto "no hay efecto") y el p-valor indica qué tan raros son los datos si H0 fuera cierta. R trae las pruebas clásicas listas.

# t de Student: ¿difieren dos medias?
grupo_a <- c(5.2, 6.1, 5.8, 6.4, 5.9)
grupo_b <- c(6.8, 7.2, 6.5, 7.0, 6.6)
t.test(grupo_a, grupo_b)               # dos muestras independientes
t.test(hwy ~ drv, data = mpg)          # usando fórmula y dataset
# Chi-cuadrado: ¿están asociadas dos categóricas?
tabla <- table(mpg$drv, mpg$class)
chisq.test(tabla)

# Prueba no paramétrica: Wilcoxon (no asume normalidad)
wilcox.test(grupo_a, grupo_b)

# Una media contra un valor de referencia
t.test(grupo_a, mu = 6)   # H0: la media es 6
PruebaPregunta que respondeTipo de dato
t.test()¿Difieren dos medias?Numérico, 2 grupos
wilcox.test()¿Difieren dos distribuciones sin asumir normalidad?Numérico, no normal
chisq.test()¿Están asociadas dos categóricas?Frecuencias en tabla
cor.test()¿La correlación es distinta de cero?2 variables numéricas

El p-valor no es "la probabilidad de que la hipótesis nula sea cierta": es la probabilidad de ver datos tan extremos bajo H0. Lo que se evalúa es el proceso, no la verdad absoluta.

Interpretar el resumen de un modelo

El summary() de un lm() parece críptico, pero cada bloque tiene un mensaje: los coeficientes con su significancia, los residuales como diagnóstico de calidad y el R cuadrado como proporción de varianza explicada. Saber leerlo distingue a quien modela de quien solo corre código.

m <- lm(mpg ~ wt + hp, data = mtcars)
resumen <- summary(m)
resumen

# Extraer valores concretos
coef(m)                     # estimaciones de los coeficientes
resumen$r.squared           # R cuadrado
resumen$adj.r.squared       # R cuadrado ajustado
resumen$coefficients        # tabla completa de coeficientes
confint(m)                  # intervalos de confianza al 95%
# Diagnóstico gráfico del modelo en 4 paneles
plot(m)

# Métricas de error de la predicción
rmse <- sqrt(mean(resid(m)^2))
rmse

# Residuos: la diferencia entre lo real y lo predicho
head(residuals(m))
mean(abs(residuals(m)))    # error absoluto medio
Bloque del summary()Qué informa
ResidualsMínimo, cuartiles y máximo del error del modelo
CoefficientsEstimación, error estándar, t y p-valor de cada predictor
Residual standard errorDispersión típica de los errores
Multiple / Adjusted R-squaredVarianza explicada (el ajustado penaliza por más variables)
F-statisticPrueba global de que el modelo predice mejor que la media

Prioriza el R cuadrado ajustado al comparar modelos con distinto número de predictores: premia la simplicidad y castiga meter variables que no aportan.
