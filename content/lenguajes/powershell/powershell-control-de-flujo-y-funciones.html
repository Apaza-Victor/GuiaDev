Condicionales

El if/elseif/else de PowerShell usa operadores de comparación con guion (-eq, -ne, -gt...) en lugar de los símbolos de otros lenguajes.

$edad = 18

if ($edad -ge 18) {
    'Mayor de edad'
} elseif ($edad -ge 13) {
    'Adolescente'
} else {
    'Menor'
}

# Operadores de comparación
# -eq -ne -gt -ge -lt -le : numéricos y de texto
# -like / -notlike        : comodines con *
# -match / -notmatch      : regex
# -contains / -in         : pertenencia a colección
# -and / -or / -not       : lógicos
# -is / -isnot            : tipo de objeto

if ('andrés' -like 'a*') { 'Empieza con a' }
if (5 -in 1..10) { 'Está en el rango' }
if ($archivo -is [System.IO.FileInfo]) { 'Es un FileInfo' }

# switch (varias comparaciones)
$dia = 'lunes'
switch ($dia) {
    'sábado' { 'Fin de semana' }
    'domingo' { 'Fin de semana' }
    default { 'Entre semana' }
}

# switch con expresiones como valores
$nota = 85
switch ($true) {
    ($nota -ge 90) { 'Sobresaliente' }
    ($nota -ge 70) { 'Notable' }
    default { 'A mejorar' }
}

El switch evalúa cada cláusula en orden y no requiere break explícito, aunque break corta la evaluación. La forma de "expresiones" permite encadenar condiciones complejas de forma legible.

Bucles

PowerShell ofrece for, foreach, while y do while/do until. El más cómodo para colecciones es el foreach de pipeline o el foreach de instrucción.

# for clásico (contador)
for ($i = 1; $i -le 5; $i++) {
    "Vuelta $i"
}

# foreach de instrucción (colección)
$nombres = 'Ana', 'Bruno', 'Carla'
foreach ($n in $nombres) {
    "Hola, $n"
}

# foreach de pipeline (objetos)
Get-Service | ForEach-Object {
    "$($_.Name): $($_.Status)"
}

# while (condición al inicio)
$i = 0
while ($i -lt 3) {
    $i++
    "i = $i"
}

# do while (ejecuta al menos una vez)
$password = ''
do {
    $password = Read-Host 'Contraseña'
} while ($password -ne 'secreto')

# do until (invierte la condición)
do { $tecla = Read-Host '¿continúas? (s/n)' } until ($tecla -eq 'n')

# control: break y continue
foreach ($n in 1..10) {
    if ($n -eq 3) { continue }   # se salta el 3
    if ($n -eq 7) { break }      # termina en 7
    "n = $n"
}

Prefiere foreach de instrucción para recorrer colecciones pequeñas y el foreach de pipeline para trabajar con salida de cmdlets. break sale del bucle y continue salta a la siguiente iteración.

Funciones

Las funciones se declaran con function; sus parámetros se declaran con bloques param() y atributos como [Parameter(Mandatory)].

# Función básica
function Saludar {
    param($nombre)
    "Hola, $nombre"
}
Saludar 'Mundo'

# Parámetros tipados y con valor por defecto
function Sumar {
    param(
        [int]$a,
        [int]$b = 10
    )
    return $a + $b
}
Sumar 5 3          # 8
Sumar 5            # 15 (usa el default)

# Parámetros obligatorios
function Renombrar {
    param(
        [Parameter(Mandatory)]
        [string]$ruta
    )
    $nuevo = "$ruta.bak"
    Copy-Item $ruta $nuevo -ErrorAction SilentlyContinue
}

# Parámetros con nombres y switch
function Configurar {
    param(
        [string]$hostname,
        [switch]$Force
    )
    if ($Force) { 'Forzado' } else { 'Normal' }
}
Configurar -hostname 'web01' -Force

# Retornar valores: todo lo que se escribe al pipeline se devuelve
function Factorial {
    param([int]$n)
    if ($n -le 1) { return 1 }
    return $n * (Factorial ($n - 1))
}
Factorial 5

return sale de la función, pero todo valor "suelto" que imprimas también sale como salida. Usa [void], Out-Null o $null = ... si no quieres que un comando intermedio contamine el resultado.

Ámbitos (scopes)

Cada función o bloque tiene su propio alcance (scope). Las variables viven en: Global, Script, Local o el de un bloque. Puedes leer las de fuera, pero no modificarlas, salvo con el prefijo del alcance.

# Variable global vs local
$Global:contador = 0
$local = 'solo aquí'

function Incrementar {
    # lee la global (sin prefijo también la ve)
    $Global:contador++
    # una asignación sin prefijo crea una local
    $otro = 'local a la función'
}
Incrementar
$contador   # ahora es 1
# $otro ya no existe fuera de la función

# Ámbitos relativos
$variable = 'raíz'
& {
    $variable = 'modificada?'
    "dentro: $variable"
}
"fuera: $variable"   # sigue siendo 'raíz'

# Acceso explícito al ámbito
$script:valor = 'tope'
& {
    $script:valor = 'actualizado'
}
$valor   # 'actualizado'

# Get-Variable para inspeccionar ámbitos
Get-Variable -Scope Global | Select-Object -First 3

$script: se usa dentro de funciones para modificar variables de nivel script; $Global: para tocar variables globales. Usarlos con moderación mantienen los scripts predecibles.

Manejo de errores

PowerShell distingue errores de terminación (rompen el flujo) y errores no terminación (continúan). El control se hace con try/catch/finally y ErrorAction.

# try / catch / finally
try {
    $resultado = 10 / 0           # error de terminación
    'No deberías verme'
} catch {
    "Error: $($_.Exception.Message)"
} finally {
    'Esto siempre se ejecuta'
}

# Forzar terminación con -ErrorAction Stop
try {
    Get-Content 'no-existe.txt' -ErrorAction Stop
} catch {
    'El archivo no existe'
}

# Lanzar errores propios
function Validar {
    param($valor)
    if ($null -eq $valor) {
        throw 'El valor no puede ser nulo'
    }
    return $valor
}

# Capturar el tipo específico
try {
    [int]'abc'
} catch [System.FormatException] {
    'Conversión fallida'
} catch {
    "Otro error: $($_.Exception.GetType().Name)"
}

# Errores no terminación: consultar $Error
Get-Item 'x.txt' -ErrorAction SilentlyContinue   # ignora y sigue
$Error | Select-Object -First 1                  # historial de errores

Regla práctica: usa -ErrorAction Stop en operaciones críticas que quieras envolver en try/catch, y SilentlyContinue solo cuando el fallo sea esperado y no necesite tratamiento.

Ejercicios prácticos

Practica en orden: cada ejercicio asume lo aprendido en el anterior.

  1. Condicional: escribe una función que clasifique una nota (0-100) en Suspenso, Aprobado, Notable o Sobresaliente usando switch.
  2. Bucle: imprime los números del 1 al 20, saltando los múltiplos de 3 con continue y parando en el 17 con break.
  3. Función: crea SumaLista que recibe un arreglo de números y devuelve su suma con un bucle foreach.
  4. Scopes: demuestra con un ejemplo que una variable local no puede modificarse desde una función sin el prefijo de ámbito.
  5. Errores: lee un archivo inexistente dentro de try/catch, muestra el mensaje del error y un mensaje final en finally.
