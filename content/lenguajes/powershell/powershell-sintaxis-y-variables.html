Variables

Las variables en PowerShell empiezan por $ y son objetos .NET tipados dinámicamente. Puedes asignar cualquier cosa y, si quieres, forzar un tipo.

# Asignación básica
$nombre = "Ana"
$edad = 30
$pi = 3.14159

# Interpolación directa
"Mi nombre es $nombre y tengo $edad años"

# Variables de entorno y automáticas
$env:USERNAME            # usuario actual
$HOME                    # home
$PSVersionTable          # tabla de versión
$_                      # objeto actual en pipeline

# Tipar variable
[datetime]$nacimiento = "1996-05-12"
[int]$numero = "42"

# Variable como objeto completo
$proceso = Get-Process pwsh
$proceso.Id

# Multivalor simple (splatting después)
$parametros = @{ Name = "pwsh"; ErrorAction = "SilentlyContinue" }
Get-Process @parametros

# Tipos de datos
$texto = "texto"            # string
$num = 42                   # int
$decimal = 1.5              # double
$bool = $true               # bool
$list = @(1, 2, 3)          # array

Con $var.metodo() accedes a los métodos .NET del objeto (ej: $texto.ToUpper()). El splatting (@parametros) pasa un has de parámetros a un comando — idioma profesional.

Tipos .NET y conversiones

Todo en PowerShell es un objeto .NET: strings, números, fechas, GUIDs, enums... Puedes convertir con cast `[tipo]valor` y consultar la clase con `GetType()`.

# Ver el tipo
("hola").GetType().FullName    # System.String
(42).GetType().FullName        # System.Int32
(1.5).GetType().FullName       # System.Double

# Conversión explícita
$json = '{"a": 1}'
$numTexto = "123"
[int]$n = $numTexto
$n + 7                          # 130

# Tipos comunes
[guid]::NewGuid()
[datetime]::Now.ToString("yyyy-MM-dd HH:mm")
[math]::Round(3.14159, 2)       # System.Math estático

# Enumeraciones
[System.DayOfWeek]::Tuesday      # enum

# Null - utilizar $null
if ($nothing) { "no llegamos" }  # $null es falsy
$varNull = $null
[bool]$varNull                   # False

La conversión no es "silenciosa" siempre: [int]"abc" lanza error. PowerShell 7 recomienda $texto.Trim().ToInt32() en .NET para evitar ambigüedades; y usa $null siempre en minúscula/así literal de comparación.

Arrays y "hashtables"

Los arrays (@(...)) y los hashtables (@{...}) son las dos colecciones que verás en el 90% de scripts.

# Arrays
$colores = @("rojo", "verde", "azul")
$nums = 1,2,3,4,5                 # sintaxis coma
$nums[0]                          # 1
$nums[-1]                         # 5
$nums[1..3]                       # 2,3,4
$nums.Count                       # 5

# Agregar (inmutable: crea nuevo)
$colores += "amarillo"
# Rango
1..10                             # 1,2,...,10

# Hashtables (diccionarios)
$persona = @{ nombre = "Ana"; edad = 30; ciudad = "Lima" }
$persona.nombre                   # Ana
$persona["edad"]                  # 30
$persona.email = "ana@guia.dev"   # agregar
$persona.Remove("edad")
$persona.Keys                     # keys (contenido desordenado)

# Para pipeline mejor, usa objetos con propiedades

# Acceder a una "lista" de objetos y proyectar
Get-Process | Select-Object -First 3 -Property Id, ProcessName

En arrays, un operador como + es lento en bucles grandes; prefiere ArrayList o lista. Los hashtables sirven para look-ups $hash[$clave] y para splatting.

Operadores

PowerShell tiene operadores de comparación, lógicos, aritméticos y de texto. Nota: los de comparación admiten like, match (regex), contains y no gustan de `==` (usa -eq).

# Aritméticos
$suma = 10 + 5
$resto = 10 % 3
$pot = [math]::Pow(2, 8)      # potencia (o 2 * 2 * ...)
$div = 10 / 3                 # 3.333...

# Comparación (no == ; usa -eq)
5 -eq 5          # True
5 -ne 3          # True
5 -gt 3          # True
5 -le 5          # True

# Texto
"hola" -eq "HOLA"          # False (case-sensitive)
"hola" -ieq "HOLA"         # True (insensible)
"PowerShell" -like "Power*"   # True
"abc123" -match "\d+"      # True (regex)
"lista de compras" -contains "lista"

# Lógicos
($true -and $false)         # False
($true -or $false)          # True
(-not $false)               # True

# Coalescing y ternario (PowerShell 7)
$a = $null
$resultado = $a ?? "default"     # default
$edad = 20
$categoria = $edad -gt 18 ? "adulto" : "menor"   # 7+

# Range y concatenación de string
"a" + "b"   # ab
"ab" * 3    # ababab

El juego de operadores prefijado con - es lo más importante: -eq, -match, -like, -contains. En PowerShell 7 tienes además ?? y ? :.

Formato y salida

Dominar el formateo de salida hace que tu script sea legible: Format-Table, Format-List, ToString() con formatos, y Out-File/ConvertTo-Json para exportar.

# Formatear en pantalla
Get-Process | Format-Table -AutoSize Name, Id, CPU
Get-Process | Format-List  Name, Path

# Formato con ToString()
$precio = 1234.5678
$precio.ToString("C")          # moneda del locale
( Get-Date ).ToString("dd-MM-yyyy HH:mm")

# Números con formato
"{0:N2}" -f 1234.5678          # 1.234,57 (usa -f, operador de formato)

# Guardar a archivo
Get-Process | Out-File procesos.txt
Get-ChildItem | Export-Csv listado.csv -NoTypeInformation

# JSON (automatización)
@{ nombre = "Ana"; edad = 30 } | ConvertTo-Json

# Sin truncar (importante para depurar)
$null = 1
"El valor es: $($null ?? 'nada')"   # con ?? de PS7

Usa ConvertTo-Json/ConvertFrom-Json para hablar con APIs; Export-Csv para Excel/análisis; Out-File para logs. El operador '{0:N2}' -f $valor es el formateador universal.

Ejercicios prácticos

Practica en orden: cada ejercicio asume lo aprendido en el anterior.

  1. Variables: crea variable de texto, número y fecha; muestralas interpoladas.
  2. Conversión: convierte "123" a [int] y suma; convierte "2026-08-29" a [datetime].
  3. Arrays: construye @(1..10), toma los pares (Where-Object o `% 2 -eq 0`) y muestra count.
  4. Hashtable: crea tu perfil como hashtable, agrega keys, listala y accede por punto.
  5. Formato: da formato a un precio con -f a 2 decimales y exporta un CSV de procesos.
