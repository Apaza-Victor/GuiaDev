¿Qué es PowerShell?

PowerShell es un shell y lenguaje de scripting basado en .NET, creado por Microsoft (Jeffrey Snover, 2006). Su gran diferencia con los shells clásicos: trabaja con objetos (no solo texto), lo que permite componer comandos de formas mucho más potentes.

Desde 2016, PowerShell Core es multi-plataforma (Windows, Linux y macOS) y open source. Es la base de la automatización en Windows (AD, Exchange, Azure, Microsoft 365) y cada vez más en entornos de infraestructura general.

Su lema: "Make IT simple, automate the world". Todo es un objeto .NET: puedes filtrar, ordenar, formatear y reutilizar la salida de un comando sin parsear texto.

Instalación

En Windows 10/11 ya viene la edición "Windows PowerShell 5.1"; la recomendada en 2026 es PowerShell 7+ (core). En Linux/macOS se instala con el gestor de paquetes.

# Windows (elevado)
winget install Microsoft.PowerShell

# O desde el MSI de GitHub releases
# https://github.com/PowerShell/PowerShell/releases

# Linux (Ubuntu/Debian)
sudo apt update
sudo apt install -y powershell

# macOS
brew install --cask powershell

# Linux (paquete directo de Microsoft, distro genérica)
# Download PRE-RELEASE tar.gz y extrae:
# tar -xzf powershell-*.tar.gz
# chmod +x pwsh

# Verificar
pwsh --version

# Ejecutar la consola
pwsh
# o
powershell   # (Windows PowerShell 5.1, si lo quieres)

El ejecutable moderno es pwsh (PowerShell 7). En Windows conviene tener ambos: 5.1 para módulos legacy, 7 para desarrollo moderno. Puedes ejecutar scripts .ps1 con ambos.

La consola interactiva

El REPL de PowerShell es tu laboratorio: escribir comandos, ver resultados, navegar por el historial y explorar ayuda.

# Comandos básicos
Get-Location                  # ruta actual (pwd)
Get-Date                      # fecha y hora
Write-Output "Hola GuiaDev"   # imprimir (o "Hola" directamente)

# Alias típicos (de otros shells)
ls, dir, cd, pwd, echo, cat, grep (≡ Select-String)

# Ayuda
Get-Help Get-Process
Get-Help Get-Process -Examples
Get-Help -Name Get-*          # lista de comandos que empiezan por

# Descubrir comandos
Get-Command -Noun Process
Get-Command -Verb Get

# Tab auto-completado y Ctrl+R historial
# Calculadora inline
1 + 2                          # 3

Nombres Verbo-Sustantivo: Get-, Set-, New-, Remove-, Test-... uniformidad total. Si conoces el sustantivo, adivinas el verbo.

Cmdlets: los comandos

Las cmdlets son el equivalente de los "comandos" de bash pero orientados a objetos y con parámetros tipados. Veamos las más imprescindibles para empezar.

# Procesos
Get-Process                     # lista de procesos (objetos)
Get-Process -Name pwsh          # filtrar por nombre

# Servicios
Get-Service                      # servicios del sistema
Get-Service -Name wuauserv       # uno concreto

# Archivos
Get-ChildItem                    # listar (ls)
Get-ChildItem -Filter *.ps1      # con patrón
Test-Path C:\Windows             # existe?

# Fecha / entorno
Get-Date -Format "yyyy-MM-dd"
$env:USERNAME                    # variable de entorno

# Ayuda por ejemplo
Get-Help Get-ChildItem -Examples

# Algunos ejemplos filtrados
Get-Process | Where-Object { $_.CPU -gt 100 }

Casi todo "Get-*" produce un objeto; puedes pasarlo a Select-Object, Where-Object, Sort-Object o Format-Table. Ese es el ecosistema: objetos en lugar de cadenas.

Versiones y perfil

PowerShell 5.1 vs 7+: compatibilidad con módulos, operadores ternarios, pipelines mejorados y null-coalescing.

# Tu versión
$PSVersionTable.PSVersion
# Majors: 5.1 (Windows PowerShell) vs 7.x (Core)

# Perfil (se carga al abrir pwsh)
$PROFILE                          # ruta del perfil
Test-Path $PROFILE
New-Item -Path $PROFILE -Force   # crear (con mkdir -Force)

# Añadir al perfil: aliases, prompt, funciones
# notepad $PROFILE

# Protocolo de correcto:
# - Validar con "script analysis" (PSScriptAnalyzer)
# - PowerShell Gallery: PSResourceGet (7.4+)
#   Install-PSResource -Name PSScriptAnalyzer

# Diferencias rápidas que notarás:
# - << (append) OK
# - Operador ?? (null-coalescing) en 7
# - @(...) listas automáticas
# - Parallel: ForEach-Object -Parallel (7+)

Mantén el perfil ligero (no cargues miles de funciones en cada arranque) y usa PSScriptAnalyzer para que el código de tus scripts cumpla buenas prácticas desde el principio.

Ejercicios prácticos

Practica en orden: cada ejercicio asume lo aprendido en el anterior.

  1. Instalación: instala/verifica pwsh --version y abre la consola.
  2. Explora: usa Get-Command -Verb Get y elige 3 cmdlets desconocidos para leer su ayuda con Get-Help.
  3. Objetos: muestra Get-Process formateado como tabla con Format-Table Name, Id, CPU.
  4. Perfil: localiza $PROFILE, crea el archivo y añade un alias favorito.
  5. Filtro: lista solo los servicios en ejecución (Get-Service | Where-Object Status -eq 'Running').
