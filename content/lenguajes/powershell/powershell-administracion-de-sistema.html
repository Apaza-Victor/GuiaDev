Trabajar con archivos

PowerShell expone el sistema de archivos con cmdlets Get-ChildItem, Copy-Item, Move-Item, Remove-Item, New-Item y Set-Content.

# Listar
Get-ChildItem .\docs

# Filtros y comodines
Get-ChildItem *.txt
Get-ChildItem -Recurse -Filter "*.log"

# Crear archivos y carpetas
New-Item -Path .\backup -ItemType Directory
New-Item -Path .\nota.txt -ItemType File
Set-Content .\nota.txt -Value 'Contenido inicial'

# Leer
Get-Content .\nota.txt
Get-Content .\log.txt -Tail 20          # últimas líneas (como tail -f)
Get-Content .\nombre.txt | Measure-Object -Line   # contar líneas

# Copiar / mover / renombrar
Copy-Item .\nota.txt .\backup\nota-copia.txt
Move-Item .\nota.txt .\backup\nueva-ubicacion.txt
Rename-Item .\backup\nueva-ubicacion.txt .\final.txt

# Eliminar
Remove-Item .\backup\final.txt

# Buscar dentro de archivos
Select-String -Path .\*.log -Pattern "ERROR"
Get-ChildItem -Recurse | Where-Object { $_.Length -gt 10MB }

-Recurse + -Filter escanean árboles completos de forma eficiente. -Tail en Get-Content es la forma moderna de monitorear logs.

Gestionar procesos

Cmdlets Get-Process, Start-Process, Stop-Process y Wait-Process cubren el ciclo de vida de los procesos.

# Listar procesos
Get-Process | Sort-Object CPU -Descending | Select-Object -First 10

# Buscar por nombre
Get-Process -Name "pwsh","chrome"

# Información útil
Get-Process -Name pwsh | Select-Object Id, CPU, WorkingSet, StartTime

# Iniciar procesos
Start-Process notepad
Start-Process https://example.com          # abre el navegador
Start-Process -FilePath "cmd" -ArgumentList "/c dir"

# Esperar a que termine
Start-Process ping -ArgumentList "8.8.8.8 -n 3" -NoNewWindow -Wait

# Detener procesos
Stop-Process -Name notepad
Stop-Process -Id 1234 -Force

# Matar todo lo que coincide (con cuidado)
Get-Process chrome -ErrorAction SilentlyContinue |
    Stop-Process -Force

# Procesos asociados a servicios
Get-Process -Id (Get-NetTCPConnection -LocalPort 8080).OwningProcess

Stop-Process -Force cierra sin dar la oportunidad de guardar. Usa -Force solo cuando el proceso realmente no responda o en entornos de prueba.

Trabajar con el registro

El registro de Windows se maneja como un árbol de carpetas con Get-Item, Get-ItemProperty, New-Item y Set-ItemProperty. Los psuedodrivos son HKLM:, HKCU:, HKCR: y HKU:.

# Leer un valor
Get-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion"
Get-ItemProperty "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion" -Name ProgramFilesDir

# Listar subclaves
Get-ChildItem "HKCU:\Software"

# Crear una clave
New-Item -Path "HKCU:\Software\MiApp" -Force

# Escribir un valor (string)
Set-ItemProperty -Path "HKCU:\Software\MiApp" -Name Version -Value "1.0"

# Escribir valor hexadecimal (DWORD)
New-ItemProperty -Path "HKCU:\Software\MiApp" -Name Puerto `
    -PropertyType DWord -Value 8080

# Eliminar
Remove-ItemProperty -Path "HKCU:\Software\MiApp" -Name Puerto
Remove-Item -Path "HKCU:\Software\MiApp" -Recurse

# Buscar en el registro
Get-ChildItem "HKLM:\Software" -Recurse -ErrorAction SilentlyContinue |
    Where-Object { $_.PSChildName -like "*MiApp*" }

Editar HKLM: requiere permisos de administrador. Prueba siempre en HKCU:\Software o en una máquina virtual antes de tocar producción.

Red y conectividad

Un set completo de cmdlets (Test-Connection, Test-NetConnection, Get-NetIPAddress, Resolve-DnsName, Get-NetTCPConnection) diagnostica la red sin recurrir a utilidades externas.

# Ping básico
Test-Connection -ComputerName 8.8.8.8 -Count 2

# Comprobar puerto abierto
Test-NetConnection -ComputerName ejemplo.com -Port 443
# TcpTestSucceeded : True

# IP y adaptadores
Get-NetIPAddress -AddressFamily IPv4 | Select-Object InterfaceAlias, IPAddress

# Resolver DNS
Resolve-DnsName google.com -Type A

# Puertos en escucha en tu máquina
Get-NetTCPConnection -State Listen | Select-Object LocalPort, LocalAddress

# Conexiones establecidas
Get-NetTCPConnection -State Established | Select-Object RemoteAddress, RemotePort

# Ver rutas
Get-NetRoute -DestinationPrefix "0.0.0.0/0"

# Prueba automatizada: timeout en segundos
Test-NetConnection -ComputerName 10.0.0.1 -Port 3389 -InformationLevel Detailed -WarningAction SilentlyContinue

Test-NetConnection combina ping + resolución DNS + prueba de puerto. Es el swiss-army-knife del diagnóstico de red en PowerShell.

Remoting y Automatización

PowerShell Remoting (WinRM) ejecuta comandos y scripts en máquinas remotas con Invoke-Command. Conviene combinarlo con PSSession y Enter-PSSession.

# Ejecutar en una máquina remota
Invoke-Command -ComputerName server01 -ScriptBlock { Get-Service }

# Con credenciales
$cred = Get-Credential
Invoke-Command -ComputerName server01 -Credential $cred `
    -ScriptBlock { Get-Process }

# Sesión persistente (varias llamadas a la misma máquina)
$s = New-PSSession -ComputerName server01
Invoke-Command -Session $s -ScriptBlock { $env:COMPUTERNAME }
Invoke-Command -Session $s -ScriptBlock { Get-ChildItem C:\ }
Remove-PSSession $s

# Remoting en paralelo (varias máquinas)
$servidores = "web01","web02","db01"
Invoke-Command -ComputerName $servidores -ScriptBlock {
    $env:COMPUTERNAME
}

# Trabajos en segundo plano (jobs)
Start-Job -ScriptBlock { 1..10 | Measure-Object -Sum }
Get-Job
Receive-Job -Name Job1 -Wait

# ForEach-Object -Parallel (PS7)
1..4 | ForEach-Object -Parallel {
    Start-Sleep 2
    "Tarea $_ terminada"
} -ThrottleLimit 4

ForEach-Object -Parallel llegó con PowerShell 7: paraleliza bucles con una sintaxis sencilla. Para remoting a varias máquinas, Invoke-Command -ComputerName ya reparte la carga.

Ejercicios prácticos

Practica en orden: cada ejercicio asume lo aprendido en el anterior.

  1. Archivos: crea una carpeta `log`, escribe 10 líneas en un archivo y muestra solo las últimas 3 con -Tail.
  2. Procesos: lista los 5 procesos que más CPU consumen y guarda la salida en un CSV.
  3. Registro: crea en HKCU:\Software\GuiaDev una clave con dos propiedades (string y DWord) y verifica que existen.
  4. Red: comprueba con Test-NetConnection que el puerto 443 está abierto en una web pública e imprime el resultado.
  5. Remoting: lanza un Start-Job que sume los números del 1 al 100 y recoge el resultado con Receive-Job.

En la próxima lección montaremos scripts completos: parámetros, módulos, programación de tareas y mejores prácticas.
