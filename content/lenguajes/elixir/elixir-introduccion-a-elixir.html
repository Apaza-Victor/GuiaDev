¿Qué es Elixir?

Elixir es un lenguaje funcional y concurrente creado por José Valim (2011), que corre sobre la máquina virtual de Erlang (BEAM). Hereda de Erlang la fiabilidad (estaba pensado para telecomunicaciones con disponibilidad 24/7) y le aporta una sintaxis moderna y herramientas de productividad.

Sus credenciales: inmutabilidad, pattern matching, pipes |>, procesos ligeros, supervisión y tolerancia a fallos. Lo usan empresas como Discord, Pinterest o WhatsApp (vía Erlang) para servidores con millones de conexiones simultáneas.

"Let it crash" es la filosofía de Elixir/Erlang: ante un error, el proceso falla y un supervisor lo reinicia. Distinto de "mirar y arreglar": el sistema se mantiene vivo.

Instalación

Se instala como paquete del sistema o con versionadores. Necesitas Elixir y, para proyectos, el gestor Hex y la herramienta mix (incluida).

# Windows (chocolatey o scoop)
choco install elixir
# o scoop install elixir

# Linux / macOS (apt, brew)
brew install elixir

# Instalar Hex (gestor de paquetes)
mix local.hex --force
mix local.rebar --force

# Verificar
elixir --version   # Elixir x.y.z (compiled with Erlang/OTP N)
iex --version

# Estructura básica ya disponible
mix help

Con asdf o mise puedes gestionar varias versiones de Erlang+Elixir. Si vienes de JavaScript, piensa en Hex como npm y en mix como tu script de build/scaffolder.

IEx: el REPL interactivo

IEx (Interactive Elixir) es el REPL: evalúa expresiones, ayuda integrada y recompilación. Es tu laboratorio para probar cada idea.

iex

iex> 1 + 2
3

iex> "Hola" <> ", mundo"
"Hola, mundo"

iex> [1, 2, 3] |> Enum.sum
6

# Ayuda de un módulo
iex> h Enum

# Docs de un módulo con tipo
iex> t Integer

# Historial y tab
iex> Str  # + Tab te completa String/Stream...

# Salir con Ctrl+C dos veces o con `System.halt`
# Archivo script: saludo.exs (extensión exs = "script")
IO.puts("Hola desde un script")

suma = 2 + 3
IO.puts("Resultado: #{suma}")   # interpolación con #{}

Los archivos con extensión .ex se compilan (código de tu app); los .exs se interpretan (scripts, tests, tareas). Es una distinción binaria y útil.

Tu primer programa

Un programa Elixir es una serie de expresiones. Lo ejecutas con elixir para scripts o, mejor, creando un proyecto con mix.

# hola.exs
IO.puts("Hola, GuiaDev!")

nombre = "Elixir"
anio = 2026
IO.puts("Aprendiendo #{nombre} en #{anio}")

# Interpolación avanzada
precio = 99.5
IO.puts("Precio: #{precio}")

# Condicionales y funciones
doble = fn x -> x * 2 end
IO.puts("Doble de 4: #{doble.(4)}")   # nota el punto .(4) para anónimas
elixir hola.exs
# Salida:
# Hola, GuiaDev!
# Aprendiendo Elixir en 2026
# Precio: 99.5
# Doble de 4: 8

Elixir es un lenguaje de expresiones: todo devuelve algo, no existe "statement". Las funciones anónimas se invocan como f.(arg) (con punto); las funciones con nombre, Modulo.f(arg).

Mix: el gestor de proyectos

Mix crea, compila, ejecuta y prueba proyectos Elixir. Es la columna que te permite crecer de un script a una aplicación con dependencias y tests.

# Crear proyecto (supervisor argument elige estructura)
mix new mi_app
cd mi_app

# Estructura generada
# mi_app/
#   mix.exs            # definición del proyecto/deps
#   lib/mi_app.ex       # código fuente (.ex)
#   test/mi_app_test.exs  # tests (.exs)

# Compilar
mix compile

# Probar con la consola del proyecto (MIX_ENV)
iex -S mix

# Ejecutar scripts del directorio priv o tasks
mix run lib/mi_app.ex   # ejecuta un archivo en el contexto

# Tests
mix test

# Docs
mix hex.doc
# lib/mi_app.ex
defmodule MiApp do
  def saludar(nombre), do: "Hola, #{nombre}"
end

# En IEx -S mix:
# iex> MiApp.saludar("Ana")
# "Hola, Ana"

iex -S mix arranca tu app con sus módulos y deps cargados. Es el flujo principal de desarrollo: editar módulo, recompilar (R en iex) y probar.

Ejercicios prácticos

Practica en orden: cada ejercicio asume lo aprendido en el anterior.

  1. Instalación: verifica elixir --version e instala Hex.
  2. REPL: en IEx, calcula 10 * 10, concatena strings con <> y usa |> con Enum.sum.
  3. Script: escribe perfil.exs que interpole tu nombre, edad y ciudad con #{}.
  4. Mix new: crea mix new mis_mat_ii, edita lib/mis_mat_ii.ex para exponer cuadrado/1 y pruébalo con iex -S mix.
  5. Tests: agrega un test para cuadrado/1 en test/ y ejecuta mix test.

En la próxima lección veremos la sintaxis básica: tipos, pattern matching y la inmutabilidad.
