Qué es una cadena

Una cadena es una secuencia de caracteres (letras, números, símbolos y espacios). En PseudoFlow se escriben entre comillas y se guardan en variables con declare.

declare nombre = "María"
declare saludo = "Hola, ¿cómo estás?"
declare inicial = "M"

print saludo
print "Tu nombre es: " + nombre
print "El primer carácter es: " + inicial

PseudoFlow no tiene funciones de texto (no hay substring(), uppercase(), etc.). Lo que sí ofrece son: propiedad .length, acceso directo a un carácter con texto[i] y concatenación con +.

---

Longitud y acceso a caracteres

Con .length sabes cuántos caracteres tiene un texto y con texto[i] lees el carácter de la posición i. El primer carácter es la posición 0 (igual que en los arreglos).

declare palabra = "PSEUDO"
print "Longitud: " + palabra.length   // 6

print "Primera letra: " + palabra[0]  // P
print "Última letra: " + palabra[5]   // O
// Recorrer todos los caracteres con un bucle
declare palabra = "HOLA"
declare i = 0

while (i < palabra.length)
    print "Carácter " + i + " = " + palabra[i]
    i = i + 1
endwhile

Cuidado: el acceso a un carácter usa índices desde 0. Si accedes a texto[texto.length] estarías fuera de rango. El último carácter válido es texto[texto.length - 1].

---

Recorrer una cadena y contar

El patrón típico con cadenas es recorrer carácter a carácter y comparar. Por ejemplo, contar cuántas veces aparece la letra "a":

// Contar cuántas "a" tiene una frase
declare frase = "La programación es genial"
declare contador = 0
declare i = 0

while (i < frase.length)
    if (frase[i] == "a")
        contador = contador + 1
    endif
    i = i + 1
endwhile

print "La frase tiene " + contador + " letras 'a'"

Combinar .length con un bucle while es la forma estándar de recorrer cualquier texto en PseudoFlow. Puedes contar vocales, espacios o símbolos cambiando solo la comparación.

---

Comparar cadenas

Las cadenas se comparan con == (igual) y != (distinto). Es útil para validar datos como contraseñas, nombres o respuestas del usuario.

// Validar una contraseña
declare correcta = "secreto123"
declare clave

print "Ingresa tu contraseña:"
read clave

if (clave == correcta)
    print "Acceso concedido"
else
    print "Contraseña incorrecta"
endif

La comparación es sensible a mayúsculas: "Hola" es distinto de "hola". PseudoFlow no tiene función para cambiar mayúsculas, así que si quieres ignorar la diferencia, pide al usuario escribir siempre igual.
