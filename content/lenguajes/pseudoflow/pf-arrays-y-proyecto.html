Arreglos (arrays)

Un arreglo (array) es una lista de valores guardados en una sola variable. Es ideal para manejar colecciones de datos sin crear cientos de variables sueltas.

// Declarar un arreglo con valores iniciales
declare numeros = [4, 7, 2, 9, 3]

// Acceder a un elemento por su índice (empieza en 0)
print numeros[0]     // 4
print numeros[2]     // 2

// Cambiar un elemento
numeros[1] = 100
print numeros[1]     // 100

// Longitud del arreglo (cuántos elementos tiene)
print "El arreglo tiene " + numeros.length + " elementos"

El primer elemento es el índice 0. Si un arreglo tiene 5 elementos, sus índices van de 0 a 4. El último índice es length - 1.

---

Recorrer un arreglo

Para procesar todos los elementos de un arreglo, lo recorres con un bucle: el índice va desde 0 hasta length - 1.

// Mostrar todos los elementos
declare numeros = [4, 7, 2, 9, 3]
repeat (for i = 0 until numeros.length - 1 steps 1)
    print "Elemento " + i + ": " + numeros[i]
endrepeat
// Suma de todos los elementos
declare numeros = [4, 7, 2, 9, 3]
declare suma = 0
repeat (for i = 0 until numeros.length - 1 steps 1)
    suma = suma + numeros[i]
endrepeat
print "Suma total: " + suma

Combinar repeat con numeros.length es el patrón estándar: el bucle se adapta automáticamente a cualquier cantidad de elementos.

Ejercicio: máximo de N números

Este algoritmo típico combina repeat, if y variables acumuladoras. Halla el mayor de los números que escribe el usuario.

declare n, num, max
print "¿Cuántos números vas a ingresar?"
read n

repeat (for i = 1 until n steps 1)
    print "Ingresa el número " + i + ":"
    read num
    // Si es el primer número o es mayor que el máximo, se actualiza
    if (i == 1)
        max = num
    else
        if (num > max)
            max = num
        endif
    endif
endrepeat

print "El máximo es: " + max

La variable max actúa como acumulador del máximo: comienza con el primer número y se actualiza cada vez que aparece uno mayor.

Proyecto integrador: verificador de número primo

Combinemos arreglos, condicionales y bucles en un programa completo. Este verifica si un número es primo usando una variable "bandera".

declare n, esPrimo
print "Ingresa un número:"
read n

esPrimo = 1     // suponemos que es primo (1 = verdadero)

if (n <= 1)
    esPrimo = 0
else
    // Probamos todos los divisores desde 2 hasta n/2
    repeat (for i = 2 until n / 2 steps 1)
        if (n % i == 0)
            esPrimo = 0     // encontramos divisor: no es primo
        endif
    endrepeat
endif

if (esPrimo == 1)
    print n + " es primo"
else
    print n + " no es primo"
endif

La variable esPrimo es una bandera: empieza en 1 y pasa a 0 en cuanto se encuentra un divisor. Al final se decide con el valor de la bandera.

Y con la suma de dígitos vemos el poder del while:

declare num, digito, suma
print "Ingresa un número:"
read num

suma = 0
while (num > 0)
    digito = num % 10          // último dígito
    suma = suma + digito
    num = (num - digito) / 10  // quitar el último dígito
endwhile

print "Suma de dígitos: " + suma

Fíjate en las técnicas: bandera (primo), acumulador (suma), operaciones con módulo (digitos). Son herramientas universales de la lógica de programación.
