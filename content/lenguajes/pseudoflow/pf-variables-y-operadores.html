Variables y declaración

Una variable es un espacio de memoria con un nombre que guarda un valor. En PseudoFlow se crean con la palabra clave declare.

// Declarar una variable (sin valor inicial)
declare edad

// Declarar y asignar valor inicial en la misma línea
declare nombre = "Ana"
declare precio = 19.99
declare activo = true

// Varias variables en una sola línea
declare a, b, c

// Reasignar (cambiar) el valor de una variable
edad = 25
edad = edad + 1    // ahora edad vale 26

Reglas de nombres: empiezan con letra, usan letras y números, sin espacios. El guion bajo _ es válido. Evita nombres reservados (print, if, while...). PseudoFlow es sensible según configuración; por convención usa nombres en español con minúsculas.

Los comentarios se escriben con //. No se ejecutan; son celdas aclaratorias que se ignoran.

Tipos de datos

PseudoFlow es tipado dinámico: las variables no necesitan declarar su tipo, y el valor determina cómo se interpretan. Aun así conviene conocer los tipos de valores que puedes usar.

TipoDescripciónEjemplos
NúmeroEnteros y decimales5, -3, 3.14, 2.5
TextoCadenas de caracteres"Hola", "123", "a"
BooleanoVerdadero o falsotrue, false (o 1, 0)
ArregloLista de valores[4, 7, 2], ["a","b"]
// Ejemplos de cada tipo
declare entero = 42
declare real = 3.14
declare texto = "GuiaDev"
declare logico = true

// Mostrar valores mixtos concatenados
print "Entero: " + entero
print "Real: " + real
print "Texto: " + texto
print "Lógico: " + logico

Puedes cambiar el valor de una variable a otro tipo más adelante (dinámico), aunque conviene mantener la coherencia para evitar errores de lógica.

Operadores

Los operadores permiten calcular, comparar y combinar valores.

// ARITMÉTICOS
//  +  suma           -  resta
//  *  multiplicación  /  división
//  %  módulo (resto)
//  No hay operador de potencia: usa multiplicaciones repetidas

declare x
x = 10 / 3        // 3.333...
x = 10 % 3        // 1 (resto de dividir 10 entre 3)
x = 2 * 2 * 2     // 8 (potencia manual: 2^3)

// RELACIONALES
//  ==  igual a        !=  distinto de
//  >   mayor que      <   menor que
//  >=  mayor o igual  <=  menor o igual

// LÓGICOS (palabras clave and / or)
//  and  y        or  o

declare esMayor = (edad >= 18)
declare permite = (edad >= 18) and (permiso == true)

La precedencia sigue el orden normal de las matemáticas: paréntesis → multiplicación/división/módulo → suma/resta → relacionales → lógicos. Los operadores lógicos se escriben con las palabras and y or (en español también acepta y y o).

Atención: la comparación de igualdad se escribe == (dos iguales). Un solo = es asignación: guardar un valor en una variable.

Entrada y salida

La entrada de datos del usuario se hace con read y la salida con print.

// Salida de texto fijo
print "Ingrese el primer número:"

// Entrada de datos (crea o asigna la variable)
read n1

print "Ingrese el segundo número:"
read n2

// Cálculo y salida combinada
declare suma = n1 + n2
print "La suma es: " + suma

// Concatenar varios valores y textos
print n1 + " + " + n2 + " = " + suma

// Salto de línea vacío
print ""

Con print puedes mezclar textos (entre comillas) y variables (sin comillas) usando el +. Cada print genera un paralelogramo en el diagrama de flujo.

Ejercicios prácticos

Practica en orden. Cada ejercicio usa los conceptos de esta lección.

  1. Variables: declara variables para tu edad (número), tu nombre (texto) y si estudias (booleano); asígnales valor y muéstralas.
  2. Operaciones: lee dos números y muestra su suma, resta, multiplicación y división.
  3. Promedio: lee 3 notas y muestra el promedio: (n1 + n2 + n3) / 3.
  4. Área: lee base y altura de un triángulo y calcula base * altura / 2.
  5. Paridad: lee un número y muestra el resto de dividirlo entre 2 con %.
