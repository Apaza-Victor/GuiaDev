¿Qué es PseudoFlow?

PseudoFlow es una herramienta gratuita y open source (licencia BSD-3) creada por Víctor Talamantes para ayudar a quienes aprenden programación a entender las estructuras de control. Escribes pseudocódigo y la herramienta genera en tiempo real un diagrama de flujo estándar ANSI mientras escribes.

Su gran ventaja: ves el diagrama actualizarse mientras tecleas. Además incluye un intérprete integrado que ejecuta tu pseudocódigo directamente, con soporte bilingüe (palabras clave en inglés o español).

Al igual que PSeInt, PseudoFlow es una herramienta pedagógica. El pseudocódigo que practicas aquí (decisiones, bucles, arreglos) es la base de cualquier lenguaje real de programación.

Instalación

PseudoFlow se puede usar en línea sin instalar nada, o como aplicación de escritorio en tu sistema operativo.

# OPCIÓN A: VERSIÓN WEB (la más rápida)
#   1. Abre https://online.pseudoflow.app en tu navegador
#   2. No necesita instalación ni cuenta
#   3. Ya puedes escribir pseudocódigo y ver el diagrama

# OPCIÓN B: APLICACIÓN DE ESCRITORIO
#   1. Entra a la página de releases del proyecto
#      GitHub -> github.com/talamantesvictor/pseudoflow -> Releases
#      o en la web oficial: pseudoflow.app -> Releases
#   2. Descarga el instalador para tu SO:
#      - Windows:  PseudoFlow-Setup-*.exe
#      - macOS:    PseudoFlow-*.dmg
#      - Linux:    PseudoFlow-*.AppImage
#   3. Ejecuta el instalador y abre la aplicación

# 4. Verifica que funciona:
#    Escribe este pseudocódigo en el editor izquierdo:
#    print "Hola, mundo"
#    Pulsa F5 (o el botón Run) y verás la salida en la consola

La versión web es ideal para empezar. Si vas a usarlo mucho, descarga la de escritorio: funciona sin internet y guarda tus archivos localmente.

El entorno de PseudoFlow

La interfaz de PseudoFlow tiene dos paneles principales: a la izquierda el editor de pseudocódigo y a la derecha el lienzo del diagrama de flujo.

# Editor (panel izquierdo):
#   - Escribes tu pseudocódigo aquí
#   - Resaltado de sintaxis y números de línea
#   - Autocompletado con Ctrl+Espacio
#   - Pestañas para varios algoritmos abiertos

# Diagrama (panel derecho):
#   - Se regenera en tiempo real mientras escribes
#   - Se puede hacer zoom y desplazarse
#   - Muestra óvalos (inicio/fin), rombos (decisiones),
#     rectángulos (procesos) y paralelogramos (entrada/salida)

# Acciones principales:
#   - F5  / botón Run  -> ejecuta el pseudocódigo
#   - Guardar archivo  -> menú de archivo (nativo en escritorio)

# Configuración importante:
#   - Idioma del pseudocódigo: English / Español
#     (Settings / Configuración -> Language / Idioma)
#     Los ejemplos de la doc están en inglés; al cambiar
#     a español las palabras clave cambian (if -> si, etc.)

La clave de PseudoFlow: cada palabra clave (print, if, while...) se convierte en un símbolo del diagrama. Verás cómo un if genera un rombo de decisión y un while un ciclo de retorno.

Tu primer programa

El programa más sencillo imprime un mensaje. En PseudoFlow la salida se hace con print y la entrada con read.

print "Hola, mundo"

Pulsa F5 y verás Hola, mundo en la consola de salida.

Ahora un programa que lee datos del usuario:

declare nombre
print "¿Cómo te llamas?"
read nombre
print "Hola, " + nombre + ", bienvenido a PseudoFlow"

Fíjate en dos cosas: declare crea la variable nombre, y el operador + concatena textos con valores.

Ver código PlantUML 
@startuml
start
:print "Cual es tu nombre?";
:read nombre;
:print "Hola, " + nombre;
stop
@enduml

Instrucciones básicas y su símbolo

InstrucciónQué haceSímbolo en el diagrama
print "..."Muestra un texto en pantalla.Paralelogramo (salida)
read varGuarda la entrada del usuario en var.Paralelogramo (entrada)
declareCrea una variable.Celda/inicio de proceso

Los textos entre comillas se muestran tal cual. Las variables y números se muestran sin comillas. El + une (concatena) cadenas de texto.

Ejercicios prácticos

Practica en orden, cada ejercicio asume lo aprendido en el anterior.

  1. Acceso: abre la versión web de PseudoFlow en tu navegador.
  2. Hola mundo: escribe print "Hola, mundo" y ejecuta con F5.
  3. Diagrama: observa cómo aparece un óvalo (inicio) y un paralelogramo (salida) en el lienzo derecho.
  4. Saludo: escribe el programa del saludo con declare, read y print.
  5. Concatenación: muestra tu nombre y tu edad en una sola línea usando +.
