Declarar y usar arreglos

Un arreglo es una colección de valores del mismo tipo bajo un mismo nombre. En PseudoFlow se declaran con un valor inicial y se accede a cada elemento con su índice entre corchetes arr[i]. A diferencia de PSeInt, aquí los índices empiezan en 0.

// Arreglo con valores iniciales (índices 0, 1, 2, 3, 4)
declare notas = [7, 9, 5, 8, 10]

print "La nota del alumno 0 es: " + notas[0]
print "La nota del alumno 4 es: " + notas[4]
print "El arreglo tiene " + notas.length + " elementos"
// Declarar un arreglo vacío
declare vacio = []
vacio[0] = 100
vacio[1] = 200
print vacio[0] + vacio[1]

Conceptos de arreglos en PseudoFlow

ConceptoExplicaciónEjemplo
ÍndicePosición del elemento (empieza en 0).notas[0]
asignaciónCambiar o crear un elemento.notas[2] = 6
lengthNúmero de elementos.notas.length
Arreglo vacíoSe puede declarar y llenar después.declare a = []

Importante: en PseudoFlow el primer elemento es [0]. Si vienes de PSeInt, recuerda que tu "posición 1" aquí es pos[0]. Acceder a un índice inexistente da error.

Recorrer un arreglo

Para procesar todos los elementos usa un bucle repeat que recorra los índices desde 0 hasta length - 1.

// Sumar todos los elementos
declare notas = [7, 9, 5, 8, 10]
declare suma = 0

repeat (for i = 0 until (notas.length - 1) steps 1)
    suma = suma + notas[i]
endrepeat

print "La suma es: " + suma
print "El promedio es: " + (suma / notas.length)

El patrón general para recorrer es: repeat (for i = 0 until length - 1 steps 1) ... endrepeat. Así visitas todas las posiciones sin pasarte.

Máximo, mínimo y búsqueda

Buscar el valor mayor, el menor o ver si existe un elemento son operaciones típicas. El truco es ir actualizando una variable de referencia al recorrer.

// Encontrar el mayor de un arreglo
declare nums = [3, 8, 1, 9, 4]
declare mayor = nums[0]
declare i = 1

while (i < nums.length)
    if (nums[i] > mayor) then
        mayor = nums[i]
    endif
    i = i + 1
endwhile

print "El mayor es: " + mayor
// Buscar si existe un valor
declare nums = [3, 8, 1, 9, 4]
declare x = 9
declare encontrado = false
declare i = 0

while (i < nums.length and encontrado == false)
    if (nums[i] == x) then
        encontrado = true
    endif
    i = i + 1
endwhile

if (encontrado) then
    print "Encontrado en la posición " + (i - 1)
else
    print "No se encontró"
endif

Para recorrer mientras no se cumpla algo, compara el flag con == false: while (...) and encontrado == false. En PseudoFlow no existe un operador not; los booleanos son true/false y se comparan con ==. Las palabras clave (and, or) van en minúsculas.

Ojo con la comparación: dentro de una condición (if, while) usa siempre == para comparar. Un solo = es solo para asignar valores y PseudoFlow lo rechaza en las condiciones.

Invertir un arreglo

Invertir un arreglo coloca el último elemento primero y el primero al final. La técnica clave es el intercambio (swap) usando una variable temporal para no perder datos.

// Invertir el arreglo usando una variable temporal
declare arr = [1, 2, 3, 4, 5]
declare temp

// i avanza desde el inicio y j desde el final, hasta cruzarse
declare i = 0
declare j = arr.length - 1

while (i < j)
    temp = arr[i]
    arr[i] = arr[j]
    arr[j] = temp
    i = i + 1
    j = j - 1
endwhile

// Mostrar el arreglo invertido
print "Arreglo invertido:"
repeat (for k = 0 until arr.length - 1 steps 1)
    print arr[k]
endrepeat

PseudoFlow trabaja con arreglos unidimensionales: solo puedes acceder a un índice a la vez (arr[i]). No hay matrices de dos dimensiones, así que para modelar una tabla se usan arreglos planos y se calcula la posición fila * nColumnas + columna.

El intercambio con temporal es de los patrones más importantes: se usa en ordenamiento (burbuja, selección) y en invertir arreglos.
