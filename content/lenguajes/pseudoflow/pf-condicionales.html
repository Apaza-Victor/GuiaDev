La estructura if

El if ejecuta un bloque de instrucciones solo si se cumple una condición. Es la forma de tomar decisiones en un algoritmo, y en el diagrama de flujo genera un rombo.

declare edad
print "Ingresa tu edad:"
read edad

// Si la condición es verdadera, ejecuta el bloque
if (edad >= 18)
    print "Eres mayor de edad"
endif

print "Fin del programa"

Las condiciones van entre paréntesis y el bloque se cierra con endif.

Esquema: if (condición) → bloque → endif. Todo lo que esté dentro se ejecuta solo si la condición es verdadera.

---

if y else

Cuando quieres hacer una cosa si se cumple y otra distinta si no, usas else.

declare n
print "Ingresa un número:"
read n

if (n % 2 == 0)
    print n + " es par"
else
    print n + " es impar"
endif

print "Fin"
declare nota
print "Ingresa tu nota (0-10):"
read nota

if (nota >= 5)
    print "Aprobado"
else
    print "Suspenso"
endif

El else indica la rama "en caso contrario". Solo puedes tener un else por if, y va antes del endif.

---

if anidados

Puedes poner un if dentro de otro para evaluar varias condiciones encadenadas.

declare n
print "Ingresa un número:"
read n

if (n > 0)
    print "Positivo"
else
    if (n < 0)
        print "Negativo"
    else
        print "Es cero"
    endif
endif

Cada if abre su propio bloque con su correspondiente endif. La indentación (sangría) te ayuda a ver qué bloque pertenece a cada if.

Los anidados funcionan, pero muchos niveles complican la lectura. Cuando tienes varias opciones según el valor de una variable, usa switch (siguiente sección).

---

La estructura switch

El switch elige entre muchas opciones según el valor de una variable. Es más limpio que muchos if anidados.

declare dia
print "Ingresa un número del 1 al 7:"
read dia

switch (dia)
    case 1:
        print "Lunes"
    endcase
    case 2:
        print "Martes"
    endcase
    case 3:
        print "Miércoles"
    endcase
    case 4:
        print "Jueves"
    endcase
    case 5:
        print "Viernes"
    endcase
    case 6:
        print "Sábado"
    endcase
    case 7:
        print "Domingo"
    endcase
endswitch

Cada caso se cierra con endcase y el conjunto con endswitch. Si el valor no coincide con ningún caso, no se ejecuta nada.

PseudoFlow solo compara valores exactos en switch (no rangos ni default). Si un valor puede no coincidir, simula el "caso por defecto" con un if previo que detecte el valor inválido.

Usa switch cuando compares una variable contra muchos valores concretos. Usa if cuando las condiciones sean relaciones complejas (rangos, combinaciones con and / or).

---

Ejercicios prácticos

Practica en orden. Cada ejercicio usa los conceptos de esta lección.

  1. Mayor de edad: lee una edad y muestra si es mayor o menor de edad.
  2. Par o impar: lee un número y muestra si es par o impar usando %.
  3. Positivo/negativo/cero: lee un número y clasifícalo usando if anidados.
  4. Nota: lee una nota y con if anidados muestra Sobresaliente (≥9), Notable (≥7), Aprobado (≥5) o Suspenso.
  5. Día: usa switch para mostrar el nombre del día según un número del 1 al 7.
