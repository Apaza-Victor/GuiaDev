El bucle dowhile (do-while)

El bucle dowhile ejecuta el bloque al menos una vez y repite mientras se cumpla la condición. Es la diferencia clave frente a while: aquí la condición se evalúa después del bloque.

// Pide la edad hasta que sea válida (0-120)
declare edad
dowhile (edad < 0 or edad > 120)
    print "Ingresa tu edad (0-120):"
    read edad
enddowhile

print "Edad válida: " + edad

Aspectowhiledowhile

La sintaxis es dowhile (condición) ... enddowhile. Es ideal para "preguntar y repetir hasta que responda bien".

Validar la entrada de datos

La entrada del usuario es la fuente de errores más común. Siempre se puede introducir un dato inválido, así que conviene validar con dowhile.

// Validar un número positivo
declare n
dowhile (n <= 0)
    print "Ingresa un número mayor que 0:"
    read n
enddowhile

print "Número válido: " + n
// Validar un menú (opción entre 1 y 4)
declare opcion
dowhile (opcion < 1 or opcion > 4)
    print "1. Registrar"
    print "2. Ver total"
    print "3. Salir"
    print "Elige una opción (1-4):"
    read opcion
enddowhile

print "Opción elegida: " + opcion

Para validar un rango usa una condición con or que capture los valores inválidos: dowhile (n < 0 or n > 100). Así el bloque se repite mientras el dato esté fuera del rango.

Contar intentos

Una variante útil es contar cuántas veces se intentó hasta lograr algo (por ejemplo, acertar una clave).

declare clave
declare correcta = "secreto"
declare intentos = 0

dowhile (clave != correcta and intentos < 3)
    print "Ingresa la contraseña:"
    read clave
    intentos = intentos + 1
enddowhile

if (clave == correcta)
    print "Acceso concedido"
else
    print "Demasiados intentos fallidos"
endif

Ojo con los bucles infinitos: si la condición nunca cambia, el programa no termina. Asegúrate de que dentro del bloque leas datos (read) o modifiques una variable que use la condición.
