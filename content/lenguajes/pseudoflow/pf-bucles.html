El bucle while

El bucle while repite un bloque mientras se cumpla una condición. Evalúa la condición antes de entrar; si es falsa desde el inicio, el bloque nunca se ejecuta.

declare i = 1

while (i <= 5)
    print "Vuelta número: " + i
    i = i + 1
endwhile

print "Fin"
// Sumar del 1 al número n
declare n, i, suma
print "¿Hasta qué número sumo?"
read n

suma = 0
i = 1
while (i <= n)
    suma = suma + i
    i = i + 1
endwhile

print "La suma de 1 a " + n + " es: " + suma

Cuidado con el bucle infinito: si olvidas incrementar la variable de control (i = i + 1), la condición nunca cambia y el bucle no termina. PseudoFlow te permitirá detenerlo.

El bucle repeat (for)

PseudoFlow expresa el bucle de conteo con repeat. Repite un número conocido de veces, recorriendo una variable de control desde un valor inicial hasta un valor final con un paso.

// Mostrar del 1 al 10
// i empieza en 1, llega hasta 10, avanzando de 1 en 1
repeat (for i = 1 until 10 steps 1)
    print i
endrepeat

La estructura general es:

repeat (for variable = inicio until fin steps paso)
    // bloque que se repite
endrepeat

Ejemplo real: la tabla de multiplicar del 2.

repeat (for i = 1 until 12 steps 1)
    print "2 x " + i + " = " + (2 * i)
endrepeat

Usa repeat cuando sepas de antemano cuántas veces repetir. Usa while cuando la condición dependa de algo que puede variar (validaciones, menús).

---

repeat con paso y descendente

El parámetro steps controla cuánto avanza (o retrocede) la variable de control cada vuelta.

// Pares: 2, 4, 6, ..., 20
repeat (for i = 2 until 20 steps 2)
    print i
endrepeat
// Descendente: 10, 9, 8, ..., 1
repeat (for i = 10 until 1 steps -1)
    print i
endrepeat
// Cuenta regresiva con mensaje final
repeat (for i = 10 until 1 steps -1)
    print i
endrepeat
print "¡Despegue!"

Observa el patrón: until indica hasta dónde llega la cuenta (inclusivo) y steps el paso. Con steps -1 desciendes.

El bucle repeat de PseudoFlow equivale al for clásico de otros lenguajes, pero agrupado en una sola línea entre paréntesis.

---

Bucles anidados

Igual que con los condicionales, puedes anidar bucles: un bucle dentro de otro. Es típico para tablas y matrices.

// Cuadrícula fila x columna
repeat (for fila = 1 until 3 steps 1)
    repeat (for col = 1 until 3 steps 1)
        print "(" + fila + "," + col + ")"
    endrepeat
    print ""   // salto de línea al cambiar de fila
endrepeat

El bucle interno (col) se ejecuta por completo por cada vuelta del externo (fila): (1,1) (1,2) (1,3) → (2,1) (2,2) (2,3) → (3,1) (3,2) (3,3).

Mantén los bucles anidados en pocos niveles (2-3 máximo). Más niveles dificultan mucho la lectura y la depuración.

Ejercicios prácticos

Practica en orden. Cada ejercicio usa los conceptos de esta lección.

  1. Contar: usa while para mostrar los números del 1 al 10.
  2. Suma: lee un número n y suma del 1 a n usando while.
  3. Repeat: con repeat (for ...) muestra los números del 1 al 10.
  4. Tabla: muestra la tabla de multiplicar del 5 (del 1 al 12) con repeat.
  5. Cuenta atrás: con repeat ... steps -1 cuenta de 10 a 1 y muestra "¡Despegue!".
