Máximo y mínimo de N números

Encontrar el mayor o el menor es un clásico. La técnica: toma el primer valor como referencia y ve comparando con el resto.

// Máximo de N números leídos
declare n, max, num
print "¿Cuántos números?"
read n

repeat (for i = 1 until n steps 1)
    print "Número:"
    read num
    if (i == 1)
        max = num
    else
        if (num > max)
            max = num
        endif
    endif
endrepeat

print "El máximo es: " + max

Para el mínimo solo cambia la comparación: num < min. El patrón "referencia + comparación en bucle" sirve para máximo, mínimo y muchos otros cálculos.

Ordenamiento de burbuja

El ordenamiento de burbuja ordena un arreglo comparando parejas adyacentes y intercambiándolas si están en el orden equivocado. Los valores grandes "suben" como burbujas.

// Ordenar de menor a mayor (burbuja)
declare arr = [5, 3, 8, 1]
declare i = 0
declare j, temp

while (i < arr.length - 1)
    j = 0
    while (j < arr.length - 1 - i)
        if (arr[j] > arr[j + 1])
            // Intercambio con variable temporal
            temp = arr[j]
            arr[j] = arr[j + 1]
            arr[j + 1] = temp
        endif
        j = j + 1
    endwhile
    i = i + 1
endwhile

// Mostrar el arreglo ordenado
print "Arreglo ordenado:"
repeat (for k = 0 until arr.length - 1 steps 1)
    print arr[k]
endrepeat

Para intercambiar dos valores necesitas una variable auxiliar temp; sin ella, uno de los dos valores se pierde. Este es el patrón de intercambio (swapping) más importante.

El burbuja es fácil de entender pero lento en arreglos grandes. Es perfecto para aprender; para datos reales grandes se usan ordenamientos más avanzados.

Búsqueda lineal en un arreglo

La búsqueda lineal recorre el arreglo comparando cada elemento con el valor buscado. Usamos un flag encontrado para detenernos al hallarlo.

declare arr = [4, 7, 2, 9, 3]
declare x = 9
declare encontrado = false
declare i = 0

while (i < arr.length and encontrado == false)
    if (arr[i] == x)
        encontrado = true
    endif
    i = i + 1
endwhile

if (encontrado)
    print x + " está en la posición " + (i - 1)
else
    print x + " no se encontró"
endif

El patrón del flag: declaras encontrado = false, lo pones en true cuando hallas el valor y lo usas en la condición del while. Cuando terminas, si el flag sigue false, el valor no existe.

Factorial y suma de dígitos

Otros dos clásicos que sirven de repaso de bucles.

// Factorial de n (n! = 1 * 2 * 3 * ... * n)
declare n, fact
print "Ingresa n:"
read n
fact = 1
repeat (for i = 1 until n steps 1)
    fact = fact * i
endrepeat
print "Factorial de " + n + " es " + fact
// Suma de los dígitos de un número
declare sum = 0, num, digit
print "Ingresa un número:"
read num
while (num > 0)
    digit = num % 10
    sum = sum + digit
    num = (num - digit) / 10
endwhile
print "Suma de dígitos: " + sum

El ejemplo de dígitos usa % (módulo) para extraer el último dígito y una división para "quitarle" ese dígito. Es la técnica básica para descomponer números.
