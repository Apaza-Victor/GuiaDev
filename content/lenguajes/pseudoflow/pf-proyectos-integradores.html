Proyecto: menú con switch

Los menús combinan dowhile (repetir hasta elegir salir), switch (elegir opción) y validación. Son la base de casi cualquier programa con interacción.

declare opcion
declare saldo = 100

dowhile (opcion < 1 or opcion > 4)
    // Mostrar el menú
    print "=== CAJERO ==="
    print "1. Ver saldo"
    print "2. Depositar"
    print "3. Retirar"
    print "4. Salir"
    print "Elige una opción:"
    read opcion

    switch (opcion)
        case 1:
            print "Tu saldo es: " + saldo
        endcase
        case 2:
            print "Depósito exitoso"
        endcase
        case 3:
            print "Retiro exitoso"
        endcase
    endswitch
enddowhile

print "¡Hasta luego!"

Al usar dowhile (opcion < 1 or opcion > 4) el menú se repite siempre hasta elegir una opción válida (incluida la 4). Si quieres salir al elegir 4, cambia la condición para que también lo valide.

Proyecto: promedios con arreglos

Combina arreglos, bucles y decisiones. Aquí guardamos notas y calculamos estadísticas.

// Notas fijas de ejemplo (puedes leerlas con read)
declare notas = [7, 9, 5, 8, 10]
declare suma = 0
declare i = 0
declare promedio

while (i < notas.length)
    suma = suma + notas[i]
    i = i + 1
endwhile

promedio = suma / notas.length
print "Promedio: " + promedio

if (promedio >= 7)
    print "Aprobado"
else
    if (promedio >= 5)
        print "Aprobado con notas bajas"
    else
        print "Reprobado"
    endif
endif

Estudia cómo un solo patrón (llenar + recorrer + acumular) resuelve sumas, promedios y conteos. Reconocer patrones es la clave para escribir menos código y con menos errores.

Proyecto: validación combinada

Un formulario real valida varios datos. Aquí combinamos dowhile para rangos y condiciones compuestas.

declare edad, nota
declare i = 1

// Validar edad (0-120)
dowhile (edad < 0 or edad > 120)
    print "Edad (0-120):"
    read edad
enddowhile

// Validar nota (0-20)
dowhile (nota < 0 or nota > 20)
    print "Nota (0-20):"
    read nota
enddowhile

if (nota >= 11)
    print "Aprobado con " + nota
else
    print "Reprobado con " + nota
endif

Cada dowhile resuelve un problema pequeño. Ese enfoque de "validar de una en una" es mucho más fácil de leer y mantener que condiciones gigantes.
