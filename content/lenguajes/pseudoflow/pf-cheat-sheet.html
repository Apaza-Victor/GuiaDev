PseudoFlow usa palabras clave en inglés y siempre en minúsculas. Estas palabras no se pueden usar como nombres de variables:

Todo es minúsculas. No existe IF ni Print: usa siempre if y print.

Sintaxis básica

Un programa en PseudoFlow combina declare, read y print. Los comentarios empiezan con #.

# Mi primer programa
declare nombre
print "¿Cómo te llamas?"
read nombre
print "Hola, " + nombre + ", bienvenido"
AcciónSintaxisEjemplo
Declarar variabledeclare vardeclare edad
Asignar valorvar = valoredad = 18
Leer del tecladoread varread edad
Mostrar en pantallaprint exprprint "Edad: " + edad
Comentario# texto# esto se ignora

La concatenación de texto se hace con +: print "Hola, " + nombre. Los textos literales van entre comillas.

PseudoFlow es de tipado dinámico: la misma variable puede cambiar de tipo. Aun así conviene conocer los valores básicos:

Arreglos (base 0)

Los arreglos se indexan desde 0 y su tamaño se consulta con .length.

declare nums
nums = [10, 20, 30]
print nums[0]        # 10 (primer elemento)
print nums[2]        # 30 (tercero)
print nums.length    # 3 (tamaño)

A diferencia de PSeInt (base 1), en PseudoFlow el primer elemento es arr[0]. Cuidado con los índices al recorrer.

Estructuras de control

if / else

if (condicion)
    # código
else
    # código alternativo
endif

switch

switch (dia)
    case 1:
        print "Lunes"
    endcase
    case 2:
        print "Martes"
    endcase
endswitch

while (condición al inicio)

while (i <= n)
    sum = sum + i
    i = i + 1
endwhile

dowhile (condición al final, se ejecuta al menos una vez)

dowhile (condicion)
    # código que se ejecuta al menos una vez
enddowhile

repeat (bucle contador)

repeat (for i = 1 until 10 steps 1)
    print i
endrepeat

PseudoFlow no tiene funciones (substring, length() como función) ni operadores !, &&, ||. Niega con == false y usa .length.

Cadenas y arreglos en la práctica

Cadenas

Las cadenas tienen .length y se accede a cada carácter por índice (base 0).

declare texto
texto = "Hola"
print texto.length     # 4
print texto[0]         # "H"

Recorrer y buscar el máximo

Patrón clásico para encontrar el máximo de una lista de números:

declare n, i, num, max
print "¿Cuántos números?"
read n
max = 0
i = 1
while (i <= n)
    read num
    if (num > max)
        max = num
    endif
    i = i + 1
endwhile
print "El máximo es: " + max

Para cadenas en PseudoFlow debes guardar el texto y usar índices texto[i] y texto.length; no hay funciones propias como en otros lenguajes.

Conceptos importantes

ConceptoQué significa
Diagrama de flujoRepresentación gráfica de un algoritmo: rectángulos para procesos, rombos para decisiones y flechas para el flujo.
PseudocódigoDescripción de un algoritmo con estructura de lenguaje, sin la sintaxis estricta de un compilador.
VariableEspacio con nombre que guarda un valor que puede cambiar.
CondiciónExpresión lógica que da verdadero o falso.
ContadorVariable que cuenta vueltas (i = i + 1).
AcumuladorVariable que suma valores (sum = sum + valor).
Bucle infinitoBucle que nunca termina porque su condición nunca se vuelve falsa.
DepuraciónBuscar y corregir errores mirando el estado de las variables.

Truco: como PseudoFlow dibuja el diagrama en tiempo real, una forma excelente de depurar es seguir visualmente las flechas y ver dónde el flujo no hace lo que esperas.
