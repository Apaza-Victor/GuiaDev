for: listas, rangos y estilo C

El for de bash itera SOBRE LISTAS DE PALABRAS — no es numérico por defecto. Esta mentalidad ("para cada elemento de esta lista") desbloquea el 90% de los casos reales:

For sobre lista

# Lista literal:
for fruta in manzana pera uva; do
    echo "Me como una $fruta"
done

# Sobre glob (archivos) — EL uso estrella:
for archivo in *.log; do
    [ -e "$archivo" ] || continue      # si no hay matches, evita literal '*.log'
    echo "Procesando $archivo ($(wc -l < "$archivo") líneas)"
done

# Sobre elementos de un array:
servidores=("web01" "db01" "cache01")
for srv in "${servidores[@]}"; do
    ping -c1 "$srv" &>/dev/null || echo "⚠️  $srv no responde"
done

Rangos con seq y brace expansion

# Brace expansion (compilación del shell, instantánea):
for i in {1..10}; do
    echo "Iteración $i"
done

# Rango con paso:
for i in {0..100..5}; do
    echo "$i%"                          # 0, 5, 10... 100
done

# seq para límites DINÁMICOS (variables):
FIN=20
for i in $(seq 1 "$FIN"); do
    touch "pagina_$i.html"
done

For estilo C: control total

for ((i = 0; i < 10; i++)); do
    if ((i % 2 == 0)); then             # aritmética con (( ))
        echo "$i es par"
    fi
done

# Contador regresivo con doble variable:
for ((i = 0, j = 10; i < j; i++, j--)); do
    echo "i=$i j=$j"
done

(( )) evalúa aritmética y devuelve exit code: 0 si el resultado ≠ 0. Por eso if ((x)) funciona como "si x no es cero". Dentro NO necesitas $ en las variables.

while, until y lectura segura de archivos

while: condición al inicio

# Contador clásico:
CONTADOR=1
while [ "$CONTADOR" -le 5 ]; do
    echo "Vuelta $CONTADOR"
    CONTADOR=$((CONTADOR + 1))
done

# Esperar a que un servicio levante (patrón DevOps diario):
until curl -s http://localhost:8080/health &>/dev/null; do
    echo "Esperando al servidor..."
    sleep 2
done
echo "✅ Servicio arriba"

while read: procesar archivos línea a línea

# LA forma correcta (memoria O(1), preserva espacios, maneja última línea sin \n):
while IFS= read -r linea; do
    echo "-> $linea"
done < usuarios.txt

# Con campos separados por delimitador (CSV simple):
while IFS=: read -r usuario uid resto; do
    echo "Usuario: $usuario (uid $uid)"
done < /etc/passwd

# Desde la salida de un comando SIN subshell roto (patrón pro):
while IFS= read -r ip; do
    ssh "admin@$ip" 'uptime'
done < <(cat servidores.txt | grep -v '^#')     # process substitution
PiezaRol crítico
IFS=No recortar espacios/tabuladores de inicio/fin
-rNo interpretar backslashes (raw)
< archivoRedirige stdin AL WHILE (no cat | while)
<<< herestringAlimentar string directo: while ... ; done <<< "$var"

cat archivo | while read x; do CONT=$((CONT+1)); done; echo $CONT imprime 0 SIEMPRE: el pipe crea un SUBSHELL y las variables mueren dentro. Solución: redirección < archivo o process substitution < <(comando). Este bug confunde a todo el mundo exactamente una vez.

break, continue e infinitos

# Menú interactivo infinito:
while true; do
    echo "1) Estado  2) Logs  0) Salir"
    read -rp "> " opcion
    case "$opcion" in
        1) systemctl status nginx --no-pager ;;
        2) tail -f /var/log/nginx/error.log ;;
        0) break ;;
        *) echo "Opción inválida"; continue ;;
    esac
done

TIMEOUT=30
ELAPSED=0
until nc -z "$HOST" 5432; do
    [ "$ELAPSED" -ge "$TIMEOUT" ] && { echo "Timeout esperando BD" >&2; exit 1; }
    sleep 2

Ejercicios prácticos

  1. Generador de páginas: for {1..10} creando pagina_N.html cada una con título numerado dentro; verifica con ls y head.
  2. Analizador de logs: while IFS= read -r sobre access.log contando peticiones por código HTTP con case interno; reporta top de errores.
  3. Cazador del subshell: implementa el contador roto con pipe (imprime 0) y la versión corregida con redirección; documenta AMBOS resultados.
  4. Monitor con timeout: until que espere un puerto abierto máximo 15 segundos con progreso por iteración; falla limpio con exit 1 al expirar.
  5. Batch renamer seguro: for sobre *.txt mostrando mv simulado viejo→nuevo (prefijo fecha); añade flag real para ejecutar de verdad solo con argumento --apply.
