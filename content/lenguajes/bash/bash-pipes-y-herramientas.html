Pipes y redirección

ls -la | grep ".txt"          # salida de uno entra al otro
ps aux | sort -rk 3 | head -5 # top 5 procesos por CPU

echo "log" > salida.txt        # sobrescribe
echo "más" >> salida.txt       # agrega
comando 2>/dev/null            # descarta errores
wc -l < entrada.txt            # redirige entrada

grep, sed, awk, find

grep -rn "TODO" src/           # busca recursivo con línea
sed 's/viejo/nuevo/g' file.txt # reemplaza todo
awk '{print $1}' datos.csv     # primera columna
find . -name "*.log" -mtime +7 -delete   # logs viejos
Consejo: La filosofía Unix: cada herramienta hace UNA cosa bien, y las combinas con pipes para resolver problemas complejos.
