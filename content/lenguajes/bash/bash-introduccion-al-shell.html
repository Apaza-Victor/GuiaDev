Tu primer script

#!/bin/bash
# hola.sh - mi primer script

echo "Hola, GuiaDev!"
echo "Fecha: $(date)"
chmod +x hola.sh   # hacerlo ejecutable
./hola.sh          # ejecutarlo
bash hola.sh       # alternativa sin chmod

El shebang

  • #!/bin/bash indica qué intérprete ejecuta el script
  • Sin ella, depende del shell del usuario
  • #!/usr/bin/env bash es más portable
