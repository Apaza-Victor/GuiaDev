if/elif/else y los tests

En bash, el "if" no evalúa expresiones booleanas como otros lenguajes: ejecuta un comando y decide según su código de salida (0 = éxito = true). Los corchetes son en realidad el comando test disfrazado — entender esto aclara toda la sintaxis extraña:

Estructura con espacios sagrados

if [ "$edad" -ge 18 ]; then
    echo "Mayor de edad"
elif [ "$edad" -ge 13 ]; then
    echo "Adolescente"
else
    echo "Niño"
fi

# Los espacios alrededor de [ ] SON obligatorios:
# [ "$x" = "y" ]   ✅
# ["$x" = "y"]     ❌ ["$x": command not found

Aunque [[ ]] tolera variables sin comillas, comillas igualmente: es hábito que te salva cuando copias líneas a contextos POSIX (sh, test de CI minimalistas).

Operadores: números, strings y archivos

Números vs Strings: NO se mezclan

El error #1 de novatos: comparar NÚMEROS con = o STRINGS con -eq. [ "5" = 05 ] es false (strings distintos); [ 5 -eq 05 ] es true (mismo valor). Elegir mal produce condiciones siempre-false silenciosas.

case: múltiples caminos limpios

Cuando comparas UNA variable contra muchos valores literales, case es más legible que cadenas if/elif — y soporta glob patterns nativamente:

#!/bin/bash
read -rp "Entorno (dev/staging/prod): " entorno

case "$entorno" in
    dev|development)
        URL="http://localhost:3000"
        ;;
    staging)
        URL="https://staging.miapp.com"
        ;;
    prod|production)
        URL="https://miapp.com"
        read -rp "¿Confirmas PRODUCCIÓN? (si/no) " ok
        [ "$ok" = "si" ] || exit 1
        ;;
    *)
        echo "Entorno desconocido: $entorno" >&2
        exit 1
        ;;
esac

echo "Desplegando a $URL"
PiezaRol
patron1|patron2)OR de patrones con glob (*.txt, ?)
;;Fin de rama — OBLIGATORIO (no existe fallthrough accidental)
*)Default (el discard)
esacCierre (if→fi, case→esac)

Buenas noticias frente a C: case de bash NO cae al siguiente caso si olvidas ;; — cada patrón termina su rama explícitamente. Un bug clásico de lenguajes ancestro eliminado por diseño.

Ejercicios prácticos

  1. Clasificador de edad: lee edad con read; valida que sea número con regex [[ =~ ]]; clasifica en rangos con elif; mensaje por categoría.
  2. Health-check de archivos: recibe ruta por argumento; reporta si no existe, es dir, es archivo vacío (-s), o legible/escribible; exit codes diferenciados.
  3. Selector de servidor: script con case que mapee alias (web/db/cache) a IPs y haga ssh simulado (echo); default con error y uso.
  4. Rebuild condicional: compara timestamps fuente vs binario con -nt; reconstruye solo si toca; loguea decisión tomada.
  5. Cazador del unary operator: reproduce el crash con variable vacía sin comillas; corrige; luego prueba la misma línea en [ ] vs [[ ]] documentando diferencias.
