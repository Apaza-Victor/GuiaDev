if / elif / else

edad=20

if [ $edad -ge 18 ]; then
    echo "Adulto"
elif [ $edad -ge 13 ]; then
    echo "Adolescente"
else
    echo "Niño"
fi

Operadores útiles

  • Numéricos: -eq -ne -gt -lt -ge -le
  • Strings: = != -z (vacío) -n (no vacío)
  • Archivos: -f existe archivo, -d existe dir, -r -w -x permisos
  • Lógicos: && || !
