if/else y operadores

La estructura if/else ejecuta un bloque de código únicamente cuando una condición booleana es verdadera. Como en la familia de lenguajes con sintaxis de C, Dart soporta condiciones anidadas, la rama else if y el operador ternario condicion ? valor1 : valor2 para decidir en una sola línea.

void main() {
  int edad = 17;

  if (edad >= 18) {
    print('Eres mayor de edad');
  } else if (edad >= 13) {
    print('Eres adolescente');
  } else {
    print('Eres un niño');
  }

  // Operador ternario
  String entrada = edad >= 18 ? 'acceso libre' : 'acceso restringido';
  print('Resultado: $entrada');

  // Operadores lógicos
  int nota = 9;
  bool aprobado = nota >= 5 && nota <= 10;
  print('Aprobado: $aprobado');
}

// Salida:
// Eres adolescente
// Resultado: acceso restringido
// Aprobado: true

Dart solo admite booleanos reales en las condiciones: no hay valores «truthy» como en JavaScript. if (3) es un error de compilación; debes escribir una expresión que devuelva bool.

switch y pattern matching

Cuando debes comparar un valor contra muchos casos, switch es más claro que una cadena de else if. Desde Dart 3 el switch también funciona como expresión (devuelve un valor) y se beneficia del pattern matching: comparar tipos, objetos o estructuras de datos completas con una sintaxis declarativa.

void main() {
  String dia = 'martes';

  // switch como sentencia
  switch (dia) {
    case 'sabado' || 'domingo':   // patrón OR (Dart 3)
      print('Fin de semana');
      break;
    default:
      print('Día laboral');
  }

  // switch como expresión: produce un valor
  String saludo = switch (dia) {
    'lunes' => 'Buen inicio de semana',
    'viernes' => 'Casi es fin de semana',
    _ => 'Un día más',
  };
  print(saludo);
}

// Salida:
// Día laboral
// Un día más

En un switch sentencia, olvidar el break provoca que el programa continúe con el siguiente caso (fallthrough). Esta confusión clásica es justo la que el switch expresión resuelve: cada caso devuelve un valor y no existe el break.

Bucles: for, while y do-while

Cuando necesitas repetir código, Dart ofrece tres bucles clásicos. for se usa cuando conoces el número de iteraciones o quieres recorrer una colección; while repite mientras una condición sea verdadera y la comprueba al inicio; do-while garantiza al menos una ejecución porque comprueba la condición al final.

void main() {
  // for clásico
  for (int i = 0; i < 3; i++) {
    print('for: $i');
  }

  // while
  int j = 0;
  while (j < 2) {
    print('while: $j');
    j++;
  }

  // do-while: se ejecuta siempre al menos una vez
  int k = 5;
  do {
    print('do-while: $k');
  } while (k < 3);
}

// Salida:
// for: 0
// for: 1
// for: 2
// while: 0
// while: 1
// do-while: 5

Un bucle while cuya condición nunca se vuelve falsa se convierte en un bucle infinito que congela tu programa. Antes de ejecutar, pregúntate siempre «¿esta variable que cambia hará falsa la condición?».

List y Map: lo básico

Las colecciones agrupan datos relacionados. La más usada es List, una secuencia ordenada de elementos, y le sigue Map, un conjunto de pares clave-valor. Ambas tienen sintaxis literal muy compacta y se recorren con for o con forEach.

void main() {
  // List<String> de frutas
  List<String> frutas = ['manzana', 'pera', 'uva'];

  // Map<String, int> de precios
  Map<String, int> precios = {'manzana': 5, 'pera': 3};

  // Recorrer una lista
  for (String fruta in frutas) {
    print('Fruta: $fruta');
  }

  // Acceder a un valor del map
  print('Precio de la manzana: ${precios['manzana']}');

  // Iterar con forEach (función flecha)
  frutas.forEach((fruta) => print('- $fruta'));
}

// Salida:
// Fruta: manzana
// Fruta: pera
// Fruta: uva
// Precio de la manzana: 5
// - manzana
// - pera
// - uva

Las listas se indexan desde cero: lista[0] es el primer elemento y lista[lista.length - 1] el último. Acceder a un índice inexistente lanza RangeError en tiempo de ejecución.

Ejercicios prácticos

Resuelve los ejercicios en un archivo control.dart y ejecuta con dart run control.dart:

  1. Calificaciones: Pide una nota del 0 al 10 y muestra con if/else si es «Suspendido», «Suficiente», «Notable» o «Sobresaliente». Usa también el operador ternario para mostrar «Aprobado» o «Suspenso».
  2. Día de la semana: Declara una variable dia y resuélvela con un switch como expresión que devuelva si es laboral o de fin de semana. Comprueba el patrón OR case 'sabado' || 'domingo'.
  3. Sumar del 1 al 100: Escribe el mismo algoritmo con un for y con un while. El resultado debe ser 5050 en ambos casos.
  4. Lista y Map: Crea una lista con cinco nombres y un mapa que asocie cada fruta con su precio. Imprime cada entrada con el formato Fruta: precio recorriendo la colección.
  5. Desafío FizzBuzz: Recorre los números del 1 al 15 con un for y para cada uno imprime Fizz si es múltiplo de 3, Buzz si es múltiplo de 5 y FizzBuzz si es múltiplo de ambos.
