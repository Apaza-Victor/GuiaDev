¿Qué es Dart y dónde se usa?

Dart es un lenguaje de programación creado por Google, orientado a objetos y con una sintaxis parecida a C, pensado para construir interfaces de usuario modernas. Nació en 2011 y alcanzó su momento más importante con Flutter, el framework multiplataforma de Google: hoy la mayoría de las aplicaciones Flutter del mundo se escriben en Dart, aunque el lenguaje también se usa para servidores, scripts de consola y aplicaciones web.

Una de las claves de Dart es su doble modelo de compilación. Durante el desarrollo se usa el compilador JIT (just-in-time) con la función de hot reload, que recarga la interfaz en milisegundos mientras escribes; para producción se usa el compilador AOT (ahead-of-time), que genera ejecutables nativos y rápidos para Android, iOS, Windows, macOS y Linux.

¿Dart es solo para Flutter? No. Flutter es su aplicación más famosa, pero Dart también se usa en servidores y en herramientas de Google: tiene tipado estático, asincronía integrada y un administrador de paquetes sólido llamado pub.

Instalación del SDK

Para ejecutar y compilar Dart necesitas el Dart SDK, que incluye el compilador, el intérprete, la herramienta dart y el analizador estático. En Windows la vía más rápida es el administrador de paquetes Chocolatey; en macOS se usa Homebrew. En todas las plataformas también puedes descargar el instalador o el ZIP desde dart.dev.

# Windows: terminal como administrador
choco install dart-sdk -y

# macOS:
brew install dart

# Verificar la instalación
dart --version
# Salida: Dart SDK version: 3.5.4 (stable) (o una versión superior)

Tu primer programa: main y print

Todo programa Dart necesita una función main(): es el punto de entrada. Cuando escribes dart run archivo.dart, Dart ejecuta exactamente lo que haya dentro de main. Para mostrar información en la consola se usa la función print().

void main() {
  print('Hola, Dart!');
}

// Salida:
// Hola, Dart!

Las variables se declaran con var o con su tipo explícito, y puedes insertar su valor dentro de un texto usando el símbolo $:

void main() {
  var lenguaje = 'Dart';
  int leccion = 1;
  print('Estás en la lección $leccion');
  print('Lenguaje: $lenguaje');
}

// Salida:
// Estás en la lección 1
// Lenguaje: Dart

Guarda el programa como hola.dart y ejecútalo con dart run hola.dart. Si el código está bien escrito verás la salida al instante; si no, el error te dirá la línea exacta donde falló la ejecución.

DartPad y herramientas

No hace falta instalar nada para probar Dart: DartPad (en la web dartpad.dev) es un editor de código en línea que compila y ejecuta Dart directamente en tu navegador, ideal para practicar sin configurar el entorno. Cuando quieras trabajar en proyectos reales, lo más cómodo es un editor con el plugin oficial de Dart.

Con dart analyze verás tres niveles de aviso: errors (el programa no funciona), warnings (código sospechoso) y lints (sugerencias de estilo). Mantener el código con cero avisos es un buen hábito desde el primer día.

Sintaxis general

La sintaxis de Dart recuerda a C y a Java: cada instrucción termina con ;, los bloques se agrupan entre llaves { } y los nombres siguen la convención camelCase (por ejemplo miVariable). Todo lo que usas en Dart es un objeto, incluidos los números y los booleanos.

void main() {
  // Comentario de una línea
  /* Comentario
     de varias líneas */

  int total = 7 + 3;              // variable con tipo explícito
  var mensaje = 'Resultado';     // var deduce el tipo: String

  bool esCorrecto = total == 10;
  print('$mensaje: $total, correcto: $esCorrecto');
}

// Salida:
// Resultado: 10, correcto: true

Bloques básicos del lenguaje

Dart distingue mayúsculas y minúsculas: void main() es el punto de entrada, pero Void Main() no lo sería. Respeta la convención de nombres y las herramientas dart format y dart analyze te lo agradecerán.

Ejercicios prácticos

Para esta lección te basta con un archivo intro.dart y el comando dart run intro.dart (o el propio DartPad en línea):

  1. Básico: Crea un programa que imprima tu nombre, tu lenguaje favorito y el día de la semana usando tres variables y la interpolación con $.
  2. Verificar la instalación: Instala el Dart SDK y ejecuta dart --version. Anota la versión que obtuviste para saber cuándo cambie en el futuro.
  3. Usar DartPad: Abre dartpad.dev, pega el programa del punto 1 y ejecútalo. Modifica los valores y observa los cambios en la consola.
  4. Leer errores: Quita el ; de una línea de tu programa y ejecuta dart analyze. Lee el mensaje de error y corrígelo.
  5. Desafío: Escribe un programa que declare dos números, los sume y muestre el resultado con el formato Resultado: 12. Repite el ejercicio usando const y razona cuándo es válido usar cada forma.

En la próxima lección conocerás las variables y los tipos de datos: la diferencia entre var, final y const, el sistema de null safety y cómo convertir un tipo en otro.
