Variables: var, final y const

En Dart hay tres formas de declarar variables que se parecen pero significan cosas distintas. var crea una variable cuyo tipo se deduce del valor inicial y que se puede reasignar; final crea una variable que solo se asigna una vez (en tiempo de ejecución); const crea una constante en tiempo de compilación, cuyo valor debe ser conocido antes de ejecutar el programa.

void main() {
  var contador = 0;          // tipo deducido: int, reasignable
  contador = 5;              // correcto

  final String curso = 'Dart';
  // curso = 'Kotlin';       // error: final solo se asigna una vez

  const double pi = 3.1416;  // constante de compilación
  // pi = 3.0;               // error: const nunca cambia

  print('$curso, contador $contador, pi $pi');
}

Regla práctica: usa final por defecto, const cuando el valor se conoce de antemano y var cuando la variable va a cambiar a lo largo del programa. La herramienta dart analyze te avisará si declaras algo constante que nunca cambia.

Cuando una clase (como DateTime) calcula el valor durante la ejecución, no puedes usar const, pero sí final. La diferencia es que const exige que el valor exista antes de ejecutar el programa.

Null safety

Dart incorpora null safety de forma sólida desde la versión 2.12: el sistema de tipos distingue entre valores que pueden ser null y los que no. Por defecto un int, un String o un bool jamás contienen null; para permitirlo se escribe el tipo con un interrogante (int?). El analizador comprueba que no accedas a un valor posiblemente nulo sin protegerte antes.

void main() {
  int prioridad = 1;       // siempre tiene un número
  int? descuento;          // empieza valiendo null

  // print(descuento.isEven);  // error: descuento podría ser null

  descuento = 15;
  if (descuento != null) {
    print('Tienes un descuento de $descuento');
  }
}

// Salida:
// Tienes un descuento de 15

La null safety no es una mera opción: en proyectos modernos ya no existe el «millón-de-dólares» error de acceder a nulos en producción. Los lenguajes como Kotlin, Swift y Rust han popularizado la misma idea porque elimina una familia entera de errores.

Tipos: int, double, bool y String

Dart tiene tipos simples de primera clase: números enteros con int, números reales con double, valores lógicos con bool y cadenas de texto con String. Todos son objetos, así que hasta un entero tiene métodos como isEven o toString(), y todos son inmutables: una operación devuelve un valor nuevo en lugar de modificar el original.

TipoEjemploDescripción
intint edad = 30;Número entero, positivo, negativo o cero

numnum valor = 3;Superclase común de int y double

Los strings admiten comillas simples o dobles y pueden ocupar varias líneas con comillas triples ('''...'''). El tipo dynamic existe por compatibilidad, pero se desaconseja para código nuevo: apaga el analizador y devuelve el problema de los errores en tiempo de ejecución.

Dart puede inferir el tipo de una variable: var edad = 30 es un int aunque no lo digas. Declarar el tipo explícito es opcional y muy útil para que otras personas lean tu intención.

Conversión entre tipos

Convertir entre tipos es una operación cotidiana: lo que llega de un formulario o de un archivo suele ser String y muchas veces necesitas un número. Cada tipo ofrece métodos específicos para la conversión y, si el texto no tiene el formato esperado, Dart lanza una excepción que puedes capturar con try y catch.

void main() {
  // String a int y a double
  int anio = int.parse('2026');
  double altura = double.parse('1.72');

  // Números y booleanos a String con interpolación
  String texto = 'Año $anio y altura $altura';

  // int a double y double a int (trunca los decimales)
  double desdeInt = anio.toDouble();
  int desdeDouble = 42.99.toInt();   // 42

  // String a bool (Dart no tiene un parse nativo directo)
  String activo = 'true';
  bool esActivo = activo == 'true';

  print(texto);
  print('desdeDouble: $desdeDouble, esActivo: $esActivo');
}

// Salida:
// Año 2026 y altura 1.72
// desdeDouble: 42, esActivo: true

Si el texto no se puede convertir, métodos como int.parse() lanzan FormatException. Para entornos donde el fallo es posible, prefiere la variante con paramétrica: int.tryParse('abc') ?? 0 devuelve null o el valor alternativo en lugar de lanzar un error.

Interpolación de strings

La interpolación de strings inserta valores de variables y expresiones dentro de un texto con $variable o ${expresion}. Es la forma más legible de construir mensajes y evita encadenar texto con +, como se hacía en otros lenguajes.

void main() {
  String nombre = 'Andrea';
  int edad = 30;
  double nota = 8.5;

  // Variable simple
  print('Hola, $nombre');

  // Expresión entre llaves
  print('Edad: ${edad + 1}');
  print('Aprobada: ${nota >= 5}');

  // Llamada a métodos
  print('Mayúsculas: ${nombre.toUpperCase()}');
}

// Salida:
// Hola, Andrea
// Edad: 31
// Aprobada: true
// Mayúsculas: ANDREA

Para mostrar un signo $ literal (como en precios) escápalo con contrabarra: print('\$5.00'). La interpolación funciona dentro de comillas simples y dobles por igual.

Ejercicios prácticos

Crea un archivo tipos.dart y resuelve los siguientes retos ejecutando con dart run tipos.dart:

  1. Tres formas: Declara una variable con var, otra con final y otra con const. Intenta reasignarlas y explica con tus palabras cuál de los tres errores aparece.
  2. Null safety: Define un String? que empiece como null, asígnale un valor y muéstralo con una comprobación if. Escribe una línea comentada que provoque un error del analizador por acceso sin comprobar.
  3. Cuatro tipos: Declara un int, un double, un bool y un String, imprímelos todos juntos usando interpolación con ${}.
  4. Conversión: Convierte el texto '42' a int y el texto '3.14' a double, súmalos y muestra el resultado. Prueba después int.tryParse('abc') y observa qué devuelve.
  5. Desafío: Crea un mensaje de bienvenida que use interpolación con una operación (por ejemplo «Te quedan 3 intentos» donde 3 salga de restar 5 - 2) y otro que muestre un símbolo de moneda escapado con \$.
