async/await y Futures

Muchas operaciones no son instantáneas: leer un archivo, consultar una API o esperar la respuesta de un usuario. Dart las modela con Future, un valor que estará disponible más adelante, y con las palabras clave async / await, que permiten escribir código asíncrono con la misma claridad que el síncrono. Una función marcada con async devuelve siempre un Future, y el await pausa su ejecución hasta que ese futuro se complete.

Future<String> pedirDatos() async {
  await Future.delayed(Duration(seconds: 1));
  return 'datos de la API';
}

void main() async {
  print('Cargando...');
  final datos = await pedirDatos();
  print('Recibido: $datos');
}

// Salida:
// Cargando...
// Recibido: datos de la API
Miembro de FutureQué hace
awaitEspera el valor real del futuro
.then(f)Ejecuta una función cuando se complete
.catchError(f)Reacciona ante un error del futuro
Future.wait(lista)Lanza varios futures y espera a todos
Future.delayed(d)Crea un futuro que espera antes de resolver

El orden realmente importa: void main() async espera con await y muestra «Cargando...» antes de «Recibido...». Sin await imprimirías la representación del Future pendiente, no su resultado, y el programa terminaría antes de la respuesta.

Streams

Un Stream es una secuencia de eventos que llegan a lo largo del tiempo: la evolución de una descarga, los datos de un sensor o las pulsaciones de un usuario. Se diferencian de los Future en que pueden emitir cero, uno o varios valores. Se consumen con await for dentro de una función asíncrona, y se producen con generadores marcados con async* y la palabra yield.

import 'dart:async';

Future<void> main() async {
  // Generador asíncrono: emite varios valores
  Stream<int> contador(int max) async* {
    for (int i = 1; i <= max; i++) {
      yield i;
    }
  }

  await for (final numero in contador(3)) {
    print('Tic: $numero');
  }
  print('Fin del stream');
}

// Salida:
// Tic: 1
// Tic: 2
// Tic: 3
// Fin del stream

La diferencia mental: un Future devuelve un resultado (o un error), un Stream devuelve muchos a lo largo del tiempo. Piensa en Future<String> como «la respuesta» y en Stream<String> como «las notificaciones».

Apps de consola con argumentos

Con Dart puedes construir aplicaciones de consola reales que reciban argumentos desde la terminal y lean la entrada del usuario. El paquete args simplifica el análisis de opciones con banderas; la librería dart:io proporciona stdin y stdout para leer y escribir.

import 'dart:io';

void main(List<String> argumentos) {
  if (argumentos.isEmpty) {
    stdout.writeln('Uso: dart saludo.dart <nombre>');
    exit(1);
  }

  final nombre = argumentos.first;
  stdout.writeln('Hola, $nombre');
}

Así se ejecuta desde la terminal: dart run saludo.dart GuiaDev mostrará Hola, GuiaDev; sin argumentos, el programa avisará del uso correcto y terminará con un código de error 1.

ElementoQué hace
argumentosLista con los valores pasados tras el nombre del archivo
stdin.readLineSync()Lee una línea escrita por el usuario
stdout.writeln(texto)Escribe texto con salto de línea
exit(codigo)Finaliza el programa con un código de salida

El código de salida importa: 0 indica éxito y cualquier otro valor un error. Las herramientas de automatización y CI toman decisiones basándose en él, así que usa exit(1) cuando el programa no pueda hacer su trabajo.

pub: paquetes y dependencias

El ecosistema de Dart gira alrededor de pub, el administrador de paquetes que descarga dependencias, las actualiza y las publica. Cada proyecto declara su configuración en pubspec.yaml, un archivo YAML con el nombre, la versión y las dependencias, y el repositorio oficial de paquetes se llama pub.dev.

# Crear un proyecto (genera pubspec.yaml, lib/ y test/)
dart create mi_proyecto
cd mi_proyecto

# Añadir una dependencia desde pub.dev
dart pub add args

# Descargar todo lo declarado en pubspec.yaml
dart pub get
Archivo / carpetaPropósito
pubspec.yamlDeclaración de metadatos y dependencias del proyecto
lib/Código público reutilizable del paquete
bin/Programas ejecutables de línea de comandos
test/Pruebas del proyecto
pubspec.lockVersiones exactas resueltas; se comparte en proyectos de aplicación

Las dependencias se escriben con versionado semántico: args: ^2.4.0 acepta cualquier versión 2.x compatible. El acento circunflejo ^ se lee como «compatible con», y pub se encarga de encontrar una combinación válida para todo tu árbol de dependencias.

Una mirada a Flutter

Y llegamos a la estrella del ecosistema: Flutter, el framework de Google para construir interfaces de usuario compiladas de forma nativa desde un único código en Dart. Cada pantalla se describe como un árbol de widgets: componentes visuales como botones, textos y listas que se combinan para formar la interfaz completa.

WidgetFunción
ScaffoldEstructura base de una pantalla (barra, fondo, body)
Text('Hola')Muestra un texto
ElevatedButtonBotón con acción al pulsarlo
ListViewLista que hace scroll
StatelessWidget / StatefulWidgetWidgets sin estado y con estado controlado

Para empezar: flutter create mi_app genera un proyecto y flutter run lo lanza en Android, iOS, la web o el escritorio. Todo el Dart que has aprendido sirve para la lógica de negocio, los modelos y los servicios; Flutter se encarga de la capa visual.

Con lo visto en estas seis lecciones ya tienes la base completa: variables y tipos, control de flujo, funciones y clases, colecciones, null safety y asincronía. Es exactamente el temario previo que exige cualquier curso de Flutter para aprovecharlo al máximo.

Ejercicios prácticos

Para esta última lección crea un proyecto con dart create async_app y resuelve los retos dentro de la carpeta bin:

  1. Future: Escribe una función esperarYSaludar() que use Future.delayed para esperar dos segundos y después imprima «Listo». Llámala desde un main asíncrono con await.
  2. Stream: Crea un generador async* que emita los números del 1 al 5 con un Duration entre cada uno, consúmelo con await for e imprime el cuadrado de cada valor.
  3. Argumentos: Escribe un programa de consola que reciba dos números como argumentos y muestre su suma. Comprueba el caso con argumentos ausentes usando exit(1).
  4. Paquete: Añade args con dart pub add args y reescribe el punto 3 para soportar las banderas --sumar y --restar usando el analizador de la librería.
  5. Abrir la puerta a Flutter: Instala el SDK de Flutter (o usa DartPad para este paso) y genera un proyecto con la plantilla del contador. Modifica el texto de bienvenida y ejecútalo en el navegador o en un emulador.
