¿Qué es Rust?

Rust es un lenguaje de sistemas creado por Mozilla (hoy mantenido por la Rust Foundation) que destaca por la seguridad de memoria en tiempo de compilación sin recolector de basura, y por un rendimiento comparable al de C/C++. Es la opción moderna para sistemas, embebidos, WASM y herramientas de línea de comandos.

fn main() {
    println!("Hola");
}
VentajaQué aporta
Seguridad de memoriaUnión de reglas de ownership que el compilador verifica; los bugs de memoria no compilan.
Sin recolector de basuraSin GC: la memoria se libera sola cuando el valor sale del ámbito, sin pausas de recolección.
VelocidadBinario nativo tan rápido como C/C++: sin pausas ni máquina virtual.
Concurrencia seguraLas carreras de datos se detectan en compilación: "fearless concurrency".

Rust 1.0 se publicó en 2015. Su lema: rendimiento de bajo nivel sin las vulnerabilidades de memoria de C/C++.

Sintaxis básica

Las variables se declaran con let y son inmutables por defecto; para poder modificarlas se marca mut. La macro println! imprime con salto de línea y los comentarios usan // y /* */.

fn main() {
    let x = 5;              // inmutable: x solo se puede leer
    let mut y = 10;         // mutable: se puede reasignar
    y = 11;                 // ✅ permitido porque tiene mut

    println!("x = {}, y = {}", x, y);   // macro de impresión

    // Comentario de una sola línea
    /* Comentario
       de varias
       líneas */
}
AcciónSintaxisEjemplo
Declarar variable (inmutable)let nombre = valor;let x = 5;
Variable mutablelet mut nombre = valor;let mut contador = 0;
Imprimirprintln!("{}", valor)println!("Hola {}", nombre);
Comentario// texto o /* texto */// nota rápida

println! lleva ! porque es una macro: se expande en tiempo de compilación y valida el formato de los marcadores {} antes de ejecutar.

Tipos de datos

Rust es estáticamente tipado: el tipo de cada variable se conoce en compilación. Los tipos escalares (enteros, flotantes, bool, char) vienen de fábrica; los compuestos (arrays, tuplas, String, &str, Option) cubren la mayoría de casos reales.

TipoQué guardaEjemplo
i32Entero con signo de 32 bitslet n: i32 = -5;
u32Entero sin signo de 32 bits (no negativos)let edad: u32 = 25;
f64Flotante de doble precisiónlet pi: f64 = 3.14159;
boolVerdadero o falsolet ok: bool = true;
charUn carácter Unicode (4 bytes)let c = 'A';
StringCadena de texto propietaria y mutable en el heaplet s = String::from("hola");
&strLiteral o "vista" de una cadena (referencia)let s: &str = "hola";
[T; N]Arreglo de tipo T con tamaño fijo Nlet a = [1, 2, 3];
(T1, T2)Tupla: agrupa valores de tipos distintoslet t = ("Ana", 25);
Option<T>Valor opcional: Some(T) o Nonelet opt: Option<i32> = Some(7);
 
fn main() {
    let entero: i32 = 42;
    let decimal: f64 = 3.14;
    let activo: bool = true;
    let inicial: char = 'R';

    let texto: String = String::from("hola");   // String: propietaria
    let literal: &str = "hola";                 // &str: literal inmutable

    let numeros: [i32; 3] = [1, 2, 3];          // array fijo de 3
    let punto: (f64, f64) = (0.0, 1.5);         // tupla con 2 campos

    let posible: Option<u32> = Some(10);        // opcional: tiene valor
}

String vs &str: String es una cadena propietaria que puedes crecer o modificar; &str es una referencia a un texto (literal fijo o una "ventana" de un String). Si necesitas mutar, usa String; para leer o pasar texto, basta &str.

Propiedad, préstamos y referencias

El concepto central de Rust es el de ownership (propiedad): cada valor tiene un único dueño, y cuando el dueño sale del ámbito, el valor se libera automáticamente. Para usar un valor sin transferir la propiedad se presta mediante referencias: & presta inmutable y &mut presta mutablemente. No puede haber dos préstamos mutables sobre el mismo valor a la vez.

fn main() {
    let mut s = String::from("hola");

    let r1 = &s;            // préstamo inmutable (&): solo lectura
    println!("{}", r1);     // varios préstamos inmutables SÍ conviven

    let r2 = &mut s;        // préstamo mutable (&mut): puede modificarlo
    r2.push_str(", mundo");

    println!("{}", s);
} // aquí s se libera sola: no hay free manual ni GC
ConceptoQué hace
OwnershipCada valor tiene un único dueño que lo libera al salir del ámbito.
BorrowingPrestar temporalmente el valor con & sin transferir la propiedad.
Referencia inmutable&&T: acceso de solo lectura; puede haber varias a la vez.
Referencia mutable&mut T: acceso de escritura; solo una a la vez.
Mover (move)Asignar un valor sin clonar transfiere la propiedad; el origen queda inválido.

Reglas del ownership: (1) cada valor tiene un solo dueño; (2) solo puede existir un &mut a la vez, o varios &, pero no mezclar; (3) las referencias nunca viven más que el valor que apuntan. El compilador lo verifica sin penalizar el rendimiento.

Estructuras de control

if / else

let n = 7;
if n > 0 {
    println!("Positivo");
} else if n < 0 {
    println!("Negativo");
} else {
    println!("Cero");
}

// if también es una EXPRESIÓN que devuelve valor
let estado = if n % 2 == 0 { "par" } else { "impar" };

match (equivalente al switch, mucho más potente)

let numero = 2;
let texto = match numero {
    1 => "uno",
    2 => "dos",
    3..=9 => "tres a nueve",
    _ => "otro",           // _ es el patrón comodín
};
println!("{}", texto);      // dos

loop (bucle infinito), while y for

let mut contador = 0;
loop {
    contador += 1;
    if contador == 3 { break; }   // sale del bucle
}

let mut i = 0;
while i < 5 {
    i += 1;
}

for j in 1..=5 {                  // rango inclusivo: 1,2,3,4,5
    println!("{}", j);
}

for k in 0..3 {                   // rango exclusivo: 0,1,2
    println!("{}", k);
}
EstructuraSintaxisUso
if / elseif cond { } else { }Condicional clásico; también devuelve valores.
matchmatch expr { pat => val, _ => val }Selección múltiple por patrones (exhaustiva).
looploop { }Bucle infinito; se sale con break.
whilewhile cond { }Repite mientras la condición sea verdadera.
for...infor x in 1..=5 { }Itera sobre rangos (..= inclusivo, .. exclusivo) y colecciones.

match es el patrón más potente de Rust: obliga a cubrir todos los casos (_ como comodín) y permite extraer datos de Option, Result y enum sin riesgo.

Funciones, structs y traits

Funciones

fn sumar(a: i32, b: i32) -> i32 {
    a + b                        // sin ";": es el valor de retorno
}

fn saludar(nombre: &str) {
    println!("Hola, {}", nombre);
}

fn main() {
    let r = sumar(3, 4);         // r = 7
    saludar("Ana");
}

Struct: estructura de datos con campos

struct Persona {
    nombre: String,
    edad: u32,
}

let p = Persona {
    nombre: String::from("Ana"),
    edad: 25,
};
println!("{} tiene {}", p.nombre, p.edad);

Métodos con impl y self

impl Persona {
    fn presentarse(&self) {
        println!("Soy {} y tengo {} años", self.nombre, self.edad);
    }
}

p.presentarse();

Traits: comportamiento compartido

trait Sonido {
    fn hacer_sonido(&self) -> String;
}

impl Sonido for Persona {
    fn hacer_sonido(&self) -> String {
        String::from("Hola!")    // "impl Trait for Tipo"
    }
}
ElementoSintaxisQué es
Funciónfn nombre(param: Tipo) -> Retorno { }Bloque reutilizable; la última expresión sin ; es el retorno.
structstruct Nombre { campo: Tipo }Define un tipo compuesto con campos con nombre.
implimpl Tipo { fn metodo(&self) { } }Bloque de métodos asociados al tipo.
self&selfReferencia al objeto actual dentro de un método.
traittrait Nombre { fn metodo(&self); }Interfaz que agrupa comportamiento compartido.
impl Trait for Tipoimpl Sonido for Persona { }Implementa el trait sobre el tipo concreto.

Resumen: struct define qué son los datos, impl define qué pueden hacer, y trait define qué interfaz comparten distintos tipos.

Manejo de errores y Cargo

Rust no usa excepciones: los errores se representan como valores. Result<T, E> devuelve Ok(T) o Err(E), y Option<T> da Some(T) o None. unwrap() y expect() extraen el valor o paniquean; el operador ? propaga el error automáticamente hacia arriba.

fn dividir(a: f64, b: f64) -> Result<f64, String> {
    if b == 0.0 {
        Err(String::from("división por cero"))
    } else {
        Ok(a / b)
    }
}

fn main() -> Result<(), String> {
    let r = dividir(10.0, 0.0)?;   // si es Err, sube el error
    println!("{}", r);
    Ok(())
}

let opcion: Option<i32> = Some(42);
let v = opcion.unwrap();           // 42; con None, paniquea
let v = opcion.expect("faltó el valor");  // con mensaje de pánico
HerramientaQué hace
Result<T, E>Resultado que puede ser Ok(T) (éxito) o Err(E) (fallo).
Option<T>Valor opcional: Some(T) o None.
unwrap()Extrae el valor interno o provoca un panic si falla.
expect(msg)Igual que unwrap pero con mensaje personalizado de error.
?Propaga el error: si hay Err/None, retorna de la función.
panic!Aborta el programa con un mensaje cuando algo es irrecuperable.

Cargo, el gestor de proyectos

Cargo crea proyectos, compila, ejecuta y gestiona dependencias. El manifiesto Cargo.toml declara el paquete y sus dependencias, que se toman de crates.io (el registro oficial de crates).

cargo new mi_proyecto     # crea un proyecto nuevo
cargo build                # compila
cargo run                  # compila y ejecuta
cargo test                 # ejecuta los tests
cargo build --release      # compila optimizado
Comando CargoQué hace
cargo newCrea un proyecto con Cargo.toml y src/main.rs.
cargo buildCompila el proyecto a target/debug/.
cargo runCompila (si hace falta) y ejecuta el binario.
cargo testCompila y ejecuta las pruebas con #[test].
cargo checkValida tipos y ownership sin generar binario (más rápido).
cargo addAñade una dependencia a Cargo.toml desde crates.io.

Evita unwrap() en producción cuando el error es previsible: prefiere ? para propagar y match para decidir qué hacer con cada caso.
