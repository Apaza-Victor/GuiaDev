¿Por qué Rust?

  • Seguridad de memoria sin garbage collector
  • Rendimiento comparable a C/C++
  • Excelente herramienta integrada: cargo, rustfmt, clippy
  • El lenguaje más valorado en encuestas de desarrolladores

Primer proyecto

rustup update
cargo new hola
cd hola
cargo run
fn main() {
    println!("Hola, GuiaDev!");
}

Variables y mutabilidad

let x = 5;          // inmutable por defecto
// x = 6;           // error!
let mut y = 5;      // mutable
y = 6;

let z = 5;
let z = z + 1;      // shadowing: nueva variable
let z = z * 2;      // 12
Consejo: En Rust todo es inmutable por defecto: usa mut solo cuando realmente necesites cambiar el valor.
