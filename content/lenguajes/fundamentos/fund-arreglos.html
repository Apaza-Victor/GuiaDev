¿Qué es un arreglo?

Imagina que quieres guardar las notas de 100 alumnos. ¿Vas a crear 100 variables (nota1, nota2, ... nota100)? Sería un desastre: imposible de escribir, de recorrer y de modificar. Para resolver esto existen los arreglos (también llamados arrays o vectores).

Un arreglo es una colección ordenada de elementos del mismo tipo (todos números o todos textos, por ejemplo) guardados en un solo nombre, y a los que se accede por su posición. Piensa en un armario con casilleros numerados o en una fila de taquillas: todos los compartimentos son de un mismo sitio, y a cada uno lo localizas por su número.

Visualización de un arreglo

Índice:      0    1    2    3    4   ...  n-2  n-1
           ┌────┬────┬────┬────┬────┬───┬────┬────┐
Valores:   │ 12 │  7 │ 20 │  5 │ 18 │...│  9 │ 14 │
           └────┴────┴────┴────┴────┴───┴────┴────┘

En la mayoría de los lenguajes, el primer elemento tiene índice 0 y el último n-1 (donde n es la cantidad de elementos). Este detalle es fundamental y fuente de muchos errores, como verás.

¿Por qué usar arreglos?

  • Guardas muchos datos con un solo nombre en lugar de cientos de variables.
  • Los recorres con un bucle: procesar 5 o 5000 elementos cuesta el mismo código.
  • Puedes operar con ellos de forma uniforme: sumarlos, buscar, ordenar.

Un arreglo con cien variables sueltas sería como un inventario escrito en cien post-its sin ordenar; un arreglo es un cajón con compartimentos numerados: sabes exactamente dónde está cada cosa.

---

Declaración y acceso

Para crear un arreglo en PSeInt usamos la instrucción Dimension. Luego accedemos a cada elemento mediante el nombre y su índice entre corchetes.

Sintaxis en PSeInt

// Declarar un arreglo de 10 posiciones
Dimension arr[10]

// Asignar un valor en la posición 1
arr[1] <- 25

// Leer un valor de una posición
Escribir arr[1]

Un detalle importante: el índice inicial

En PSeInt los índices comienzan en 1, mientras que en la mayoría de los lenguajes (C, Java, JavaScript, Python) comienzan en 0. Siempre verifica qué convención usa tu lenguaje.

LenguajePrimer índiceÚltimo índice (5 elementos)
PSeInt15
C, Java, JavaScript04
Python04

Primer y último elemento

En PSeInt, para un arreglo de n elementos el primero es arr[1] y el último arr[n]. Recuerda respetar los límites: acceder fuera de ellos produce un error o un valor incorrecto.

Ejemplo: arreglo de 5 notas

Algoritmo notas
    Dimension notas[5]
    Definir i Como Entero

    Para i <- 1 Hasta 5 Hacer
        Escribir "Ingrese nota ", i, ":"
        Leer notas[i]
    FinPara

    Escribir "La primera nota es: ", notas[1]
    Escribir "La última nota es: ", notas[5]

FinAlgoritmo

Usa siempre el índice para acceder (nunca inventes nombres como nota1, nota2...). El bucle Para recorre notas[i] con un solo índice i: ahí está la magia de los arreglos.

---

Recorrer un arreglo

La principal operación sobre un arreglo es recorrerlo: visitar cada elemento, normalmente con un bucle Para desde el primer índice hasta el último. Con ese recorrido podemos llenar (leer datos), mostrar, sumar, calcular promedios o buscar valores.

Ejemplo completo: llenar, sumar y mostrar

Algoritmo notas_completo
    Dimension notas[10]
    Definir i, total, promedio Como Real

    // 1. Llenar el arreglo
    Para i <- 1 Hasta 10 Hacer
        Escribir "Nota ", i, ":"
        Leer notas[i]
    FinPara

    // 2. Sumar todos los elementos
    total <- 0
    Para i <- 1 Hasta 10 Hacer
        total <- total + notas[i]
    FinPara

    // 3. Calcular y mostrar el promedio
    promedio <- total / 10
    Para i <- 1 Hasta 10 Hacer
        Escribir "Nota en posición ", i, ": ", notas[i]
    FinPara
    Escribir "El promedio es: ", promedio

FinAlgoritmo

Observa el patrón: siempre recorremos con un Para que va del primer al último índice.

Buscar un valor

// Buscar si existe el valor buscado y en qué posición
encontrado <- Falso
i <- 1
Mientras i <= 10 Y NO encontrado Hacer
    Si notas[i] = buscado Entonces
        Escribir "Encontrado en la posición ", i
        encontrado <- Verdadero
    FinSi
    i <- i + 1
FinMientras

Recorrido por índice vs por elemento

El recorrido con Para i usa el índice: útil cuando necesitas la posición. Muchos lenguajes ofrecen además el for-each, que recorre directamente "cada elemento" sin gestionar el índice; es más breve, pero no sabes la posición a menos que la lleves aparte. Eliges uno u otro según necesites la posición o solo el valor.

El clásico error off-by-one (desviado por uno) ocurre al no respetar el índice inicial: recorrer del 1 al 10 en un lenguaje que empieza en 0 se salta el primer elemento y se sale por el final. Conoce siempre tu convención de índices.

Matrices

Un arreglo bidimensional (llamado matriz) organiza los datos en filas y columnas, como una hoja de cálculo o una tabla. Se accede con dos índices. Es ideal para datos tabulares: calificaciones de varios alumnos en varias materias, una grilla de juego, etc.

Sintaxis en PSeInt

// Matriz de 3 filas y 4 columnas
Dimension matriz[3,4]

// Acceso: fila 2, columna 3
matriz[2,3] <- 15

Recorrer una matriz con bucles anidados

Para visitar todas las celdas usamos dos bucles: el externo recorre filas y el interno columnas.

Algoritmo matriz_3x3
    Dimension mat[3,3]
    Definir f, c, sumaDiagonal Como Entero

    // Rellenar la matriz
    Para f <- 1 Hasta 3 Hacer
        Para c <- 1 Hasta 3 Hacer
            Escribir "Valor en fila ", f, ", columna ", c, ":"
            Leer mat[f,c]
        FinPara
    FinPara

    // Sumar la diagonal principal (fila = columna)
    sumaDiagonal <- 0
    Para f <- 1 Hasta 3 Hacer
        sumaDiagonal <- sumaDiagonal + mat[f,f]
    FinPara

    Escribir "La suma de la diagonal es: ", sumaDiagonal

FinAlgoritmo

Nota cómo la diagonal principal es exactamente donde f = c, así que se recorre con un solo índice f accediendo a mat[f,f].

Tamaño y total de elementos

Una matriz de 3×4 tiene 3 × 4 = 12 elementos. El bucle externo controla las filas y el interno las columnas; si los intercambias, recorres en otro orden (dato a tener en cuenta para ciertos algoritmos).

Piensa en una matriz como "un arreglo de arreglos": cada fila es un arreglo y las filas juntas forman la matriz. Los bucles anidados de la lección anterior son la herramienta natural para recorrerla.

Cadenas de texto

En muchos lenguajes, una cadena de texto (string) no es más que un arreglo de caracteres: puedes acceder a cada letra por su posición. Esta conexión con los arreglos explica por qué existen errores típicos de índices al trabajar con texto.

Funciones típicas de cadena en PSeInt

FunciónQué haceEjemplo
Longitud(cadena)Cuenta los caracteresLongitud("Hola") → 4
Subcadena(cadena, ini, fin)Extrae una porciónSubcadena("Hola",1,2) → "Ho"
Mayusculas(cadena)Pone en mayúsculasMayusculas("hola") → "HOLA"
Minusculas(cadena)Pone en minúsculasMinusculas("HOLA") → "hola"

Ejemplo: contar caracteres y primera letra

Algoritmo nombre_proceso
    Definir nombre Como Cadena
    Escribir "Ingrese su nombre:"
    Leer nombre

    Escribir "Tu nombre tiene ", Longitud(nombre), " caracteres"
    Escribir "La primera letra es: ", Subcadena(nombre, 1, 1)
    Escribir "En mayúsculas: ", Mayusculas(nombre)

FinAlgoritmo

Comparación y búsqueda

Las cadenas se comparan con los operadores normales (=, <>): Si nombre = "Ana" Entonces. Para buscar una subcadena dentro de otra puedes recorrerla y comparar con Subcadena, o usar la función específica que ofrezca tu lenguaje.

Las posiciones de caracteres dependen del lenguaje y suelen heredar la convención de índices de los arreglos (0 o 1). En PSeInt Subcadena usa índices a partir de 1. Verifica siempre la convención antes de extraer letras.

Buenas prácticas

Trabajar con arreglos tiene trucos que evitan errores y hacen el código más claro. Estas son las buenas prácticas esenciales:

  • Predefinir el tamaño con una constante: evita "magia" de números sueltos. Define un tamaño al principio y úsalo en todo el programa; así, cambiarlo es editar un solo lugar.
  • Recorrer siempre con el tamaño real: usa la longitud real del arreglo (o su constante) en los límites del bucle, nunca un número arbitrario.
  • Validar los índices: comprueba que un índice esté dentro de límites antes de acceder; evita lecturas/escrituras fuera de rango.
  • Inicializar los arreglos: da un valor inicial (p. ej. 0) si lo necesitas, para no trabajar con valores basura.
  • Índices significativos: usa i, j, k de forma consistente (filas, columnas, niveles) y respeta su rol.
// Ejemplo: tamaño como constante y recorrido con límite real
Dimension notas[10]
Definir N Como Entero
N <- 10   // tamaño real del arreglo

Para i <- 1 Hasta N Hacer
    Escribir notas[i]
FinPara

Un arreglo bien manejado se asemeja a una tabla bien formada en una hoja de cálculo: tamaño conocido, índices válidos y nombres claros. Esas pequeñas reglas se pagan con mucha menos depuración.

Errores comunes

1. Índice fuera de rango

Acceder a arr[10] cuando el arreglo tiene 10 elementos pero los índices van de 0 a 9 (o de 1 a 10 según lenguaje) provoca errores. Conoce la convención de tu lenguaje y los límites exactos.

2. Confundir filas y columnas en matrices

En una matriz intercambiar mat[f,c] por mat[c,f] cambia el dato que lees o modificas. Da nombre a cada índice (f = fila, c = columna) y respétalo en los bucles.

3. Usar un índice sin definirlo

Usar arr[i] cuando i no está definido o no está inicializado accede a una posición aleatoria. Define e inicializa i antes del acceso.

4. Mezclar tipos entre elementos

Un arreglo debe contener elementos del mismo tipo. Mezclar números y textos viola esa regla (según el lenguaje puede fallar o dar resultados inesperados).

5. Olvidar llenar antes de leer

Dimension notas[5]
// ❌ Leer sin haber llenado: valores basura o error
Escribir notas[1]

// ✅ Llenar primero con un bucle, luego usar

Ejercicios

Resuelve estos ejercicios en PSeInt o en tu lenguaje favorito. De menor a mayor dificultad:

  1. Llenar y mostrar: pide cuántas notas leer (N), llénalas en un arreglo y muéstralas en orden inverso.
  2. Suma y promedio: sobre el arreglo de notas, calcula la suma y el promedio con un recorrido y un acumulador.
  3. Máximo y su índice: recorre un arreglo y encuentra el valor máximo y la posición en la que se encuentra.
  4. Matriz 2×3: rellena una matriz de 2 filas y 3 columnas y calcula la suma de cada fila por separado.
  5. Contar vocales: lee una cadena, recorrela carácter a carácter y cuenta cuántas vocales (a, e, i, o, u) contiene (cuida la convención de índices de los caracteres).
