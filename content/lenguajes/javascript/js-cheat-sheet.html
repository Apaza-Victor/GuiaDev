Palabras reservadas

Las palabras reservadas tienen un significado especial en JavaScript y no pueden usarse como nombre de variables, funciones o identificadores.
Categoría Palabra Qué hace
Declaración var Declara una variable con ámbito de función (antiguo, evitar su uso).
Declaración let Declara una variable con ámbito de bloque que puede reasignarse.
Declaración const Declara una constante con ámbito de bloque que no puede reasignarse.
Funciones function Declara una función reutilizable.
Funciones return Devuelve un valor desde una función y detiene su ejecución.
Condicionales if Ejecuta un bloque solo si la condición es verdadera.
Condicionales else Ejecuta un bloque cuando la condición del if es falsa.
Condicionales switch Evalúa una expresión y ejecuta el caso que coincida.
Condicionales case Define un valor posible dentro de un switch.
Condicionales break Sale de un bucle o de un switch.
Condicionales default Caso por defecto cuando ningún case coincide.
Bucles for Repite código un número determinado de veces.
Bucles while Repite código mientras la condición sea verdadera.
Bucles do Ejecuta el bloque al menos una vez antes de evaluar la condición.
Bucles continue Salta a la siguiente iteración del bucle.
Objetos/clases class Define una clase (plantilla para crear objetos).
Objetos/clases new Crea una nueva instancia de una clase o constructor.
Objetos/clases this Hace referencia al objeto actual en el contexto de ejecución.
Objetos/clases super Accede y llama a métodos del padre desde una subclase.
Objetos/clases extends Crea una clase hija que hereda de otra clase.
Excepciones try Envuelve código que puede lanzar un error.
Excepciones catch Captura y maneja el error lanzado en el try.
Excepciones finally Bloque que se ejecuta siempre, ocurra o no un error.
Excepciones throw Lanza un error personalizado de forma manual.
Módulos import Importa funciones, objetos o valores desde otro módulo.
Módulos export Expone valores de un módulo para que sean importados.
Módulos from Indica la ruta del módulo en una importación.
Módulos as Crea un alias al importar o exportar.
Módulos default Exporta un valor principal por defecto del módulo.
Lógicos && Y lógico: verdadero solo si ambas condiciones lo son.
Lógicos || O lógico: verdadero si al menos una condición lo es.
Lógicos ! Negación: invierte el valor booleano.
Valores null Representa la ausencia intencional de valor.
Valores undefined Representa una variable declarada sin valor asignado.
Valores true / false Valores booleanos de verdadero y falso.
Ámbito in Comprueba si una propiedad existe en un objeto.
Ámbito of Itera sobre los valores de un array u otro iterable.
Ámbito instanceof Comprueba si un objeto es instancia de una clase.
Ámbito typeof Devuelve el tipo de un valor.
Ámbito void Evalúa una expresión y devuelve undefined.
Ámbito delete Elimina una propiedad de un objeto.
Ámbito await Espera la resolución de una promesa.
Ámbito async Declara una función asíncrona que devuelve una promesa.
Ámbito yield Pausa y reanuda una función generadora.
En JavaScript no existe la palabra reservada and ni or: se usan los símbolos &&, || y !.

Sintaxis básica

// Declaración de variables (comentario de una línea)
let nombre = "María";
const edad = 30;

// Imprimir en consola
console.log(nombre, edad);

// Leer entrada del usuario (entornos de navegador)
let ciudad = prompt("¿En qué ciudad vives?");

/*
Comentario de varias líneas
(javascript soporta comentarios)
*/
console.log("Hola " + ciudad);
Acción Sintaxis Ejemplo
Declarar variable let nombre = valor; let edad = 25;
Declarar constante const nombre = valor; const PI = 3.1416;
Imprimir en consola console.log(valor) console.log("Hola");
Leer entrada prompt(mensaje) prompt("Tu nombre:");
Comentario de línea // texto // esto es un comentario
Comentario de bloque /* texto */ /* varias líneas */
El punto y coma al final de cada sentencia es opcional, pero se recomienda usarlo para evitar errores de interpretación. Las cadenas pueden escribirse con comillas simples 'texto', dobles "texto" o plantillas `texto`.

Tipos de datos

Tipo Qué guarda Ejemplo
number Números enteros y decimales. 42, 3.14, -7
string Textos y cadenas de caracteres. "Hola", 'JS', `plantilla`
boolean Verdadero o falso. true, false
undefined Variable declarada sin valor asignado. let x; → x es undefined
null Ausencia intencional de valor. let dato = null;
object Colección de propiedades y métodos. { nombre: "Ana" }
array Lista ordenada de valores. [1, 2, 3]
function Bloque de código ejecutable. function saludar() {}
symbol Valor único e inmutable. Symbol("id")
bigint Números enteros muy grandes. 9007199254740991n 
// Objeto: colección de clave -> valor
const persona = {
    nombre: "María",
    edad: 30,
    ciudad: "Madrid"
};

// Array: lista ordenada de valores
const frutas = ["manzana", "pera", "uva"];
console.log(frutas[0]); // "manzana"

// Comprobar el tipo de un valor
typeof persona;  // "object"
typeof frutas;   // "object" (los arrays también son objetos)
Los arrays se recorren con un índice numérico que empieza en 0 y los objetos mediante su clave o propiedad.

Operadores

Aritméticos

Operador Qué hace Ejemplo
+ Suma (o concatena cadenas con +). 5 + 3 → 8; "a" + "b" → "ab"
- Resta. 5 - 3 → 2
* Multiplicación. 5 * 3 → 15
/ División. 15 / 3 → 5
% Módulo (resto de la división). 5 % 2 → 1
** Exponente. 2 ** 3 → 8
+ (cadenas) Concatenación de strings. "Hola " + "Mundo" → "Hola Mundo"

Relacionales y lógicos

Operador Qué hace Ejemplo
== Igualdad de valor (con conversión de tipo). 5 == "5" → true
=== Igualdad estricta de valor y tipo. 5 === "5" → false
!= Distinto en valor (con conversión de tipo). 5 != "5" → false
!== Distinto estricto en valor y tipo. 5 !== "5" → true
> Mayor que. 5 > 3 → true
< Menor que. 3 < 5 → true
>= Mayor o igual que. 5 >= 5 → true
<= Menor o igual que. 3 <= 3 → true
&& Y lógico (ambas condiciones). true && false → false
|| O lógico (al menos una condición). true || false → true
! Negación. !false → true
? : Operador ternario (condición abreviada). edad >= 18 ? "Mayor" : "Menor" 
// Ejemplos combinados
let nota = 7;
console.log(nota >= 6 && nota <= 10);        // true

// Ternario
let resultado = nota >= 6 ? "Aprobado" : "Suspenso";
console.log(resultado);                          // "Aprobado"

// Concatenación
let mensaje = "Nota: " + nota;                   // "Nota: 7"
Siempre que sea posible usa === y !==. La diferencia clave: == compara solo el valor convirtiendo tipos (5 == "5" es true), mientras que === compara valor y tipo (5 === "5" es false).

Estructuras de control

JavaScript agrupa los bloques con llaves { } y cada sentencia termina (opcionalmente) con punto y coma ;.

if / else

let edad = 18;

if (edad >= 18) {
    console.log("Mayor de edad");
} else {
    console.log("Menor de edad");
}

switch / case

let dia = 2;
let nombreDia;

switch (dia) {
    case 1:
        nombreDia = "Lunes";
        break;
    case 2:
        nombreDia = "Martes";
        break;
    default:
        nombreDia = "Otro día";
}
console.log(nombreDia); // "Martes"

for

for (let i = 0; i < 5; i++) {
    console.log(i); // 0, 1, 2, 3, 4
}

for...of (recorrer arrays)

const frutas = ["manzana", "pera", "uva"];

for (const fruta of frutas) {
    console.log(fruta);
}

while

let contador = 0;

while (contador < 3) {
    console.log(contador);
    contador++;
}

do...while

let x = 0;

do {
    console.log(x); // se ejecuta al menos una vez
    x++;
} while (x < 3);

break y continue

for (let i = 0; i < 10; i++) {
    if (i === 2) continue;    // salta a la siguiente iteración
    if (i === 5) break;       // sale del bucle
    console.log(i);           // 0, 1, 3, 4
}

Funciones, objetos y arrays

Declaración de función

function sumar(a, b) {
    return a + b;
}
console.log(sumar(2, 3)); // 5

Función flecha (arrow)

const sumarFlecha = (a, b) => a + b;
const saludar = nombre => "Hola " + nombre;

console.log(sumarFlecha(4, 6)); // 10
console.log(saludar("Ana"));    // "Hola Ana"

Objetos y sus métodos

const persona = {
    nombre: "María",
    edad: 30,
    presentarse() {
        return "Soy " + this.nombre;
    }
};
console.log(persona.presentarse()); // "Soy María"
console.log(persona.nombre);        // acceso a propiedad

Métodos de array

const numeros = [1, 2, 3, 4];

numeros.push(5);      // añade al final:  [1, 2, 3, 4, 5]
numeros.pop();        // quita del final: [1, 2, 3, 4]

const dobles = numeros.map(n => n * 2);   // [2, 4, 6, 8]
const pares = numeros.filter(n => n % 2 === 0); // [2, 4]

numeros.forEach(n => console.log(n));     // 1, 2, 3, 4
const encontrado = numeros.find(n => n > 2);    // 3
const incluye = numeros.includes(3);            // true
map, filter y forEach son los métodos más usados para trabajar con arrays de forma declarativa. map transforma cada elemento, filter selecciona los que cumplen una condición y forEach recorre sin devolver nada.

Manipular el DOM y eventos

Estas funciones solo están disponibles en el navegador (no en Node.js). El DOM es la representación en objetos de la página HTML.

Seleccionar elementos

// Por id
const titulo = document.getElementById("titulo");

// Por selector CSS (primera coincidencia)
const parrafo = document.querySelector(".texto");

// Todas las coincidencias de un selector
const items = document.querySelectorAll("li");

Modificar contenido y estilo

titulo.innerHTML = "<em>Nuevo título</em>";
titulo.textContent = "Texto simple, seguro";
titulo.style.color = "red";
titulo.classList.add("activo");
titulo.classList.remove("oculto");

Escuchar eventos

const boton = document.getElementById("miBoton");

boton.addEventListener("click", function () {
    document.getElementById("saludo").textContent = "¡Hiciste clic!";
});
Función / propiedad Qué hace
document.getElementById(id) Selecciona un elemento por su atributo id.
document.querySelector(selector) Selecciona el primer elemento que coincida con un selector CSS.
document.querySelectorAll(selector) Selecciona todos los elementos que coinciden con un selector CSS.
elemento.addEventListener(evt, fn) Asocia una función a un evento (click, keyup, submit, ...).
elemento.innerHTML Establece u obtiene el HTML interno del elemento.
elemento.textContent Establece u obtiene el texto plano del elemento.
elemento.style.propiedad Modifica un estilo CSS en línea (por ejemplo color, fontSize).
elemento.classList Permite añadir, quitar o alternar clases CSS.
Usa textContent cuando el contenido sea texto del usuario para evitar ataques XSS. Reserva innerHTML solo para contenido confiable.

Conceptos importantes

Concepto Qué significa
Variable Contenedor con nombre que guarda un valor, declarado con let o var.
Constante Contenedor cuyo valor no puede reasignarse, declarado con const.
Función Bloque de código reutilizable que se ejecuta cuando se llama.
Parámetro Variable que la función recibe al definirla (por ejemplo a en sumar(a, b)).
Argumento Valor concreto que se pasa a la función al llamarla (por ejemplo 2 en sumar(2, 3)).
Retorno Valor que la función devuelve al llamador mediante return.
Objeto Colección de propiedades (clave - valor) que modelan una entidad.
Propiedad Par clave/valor dentro de un objeto (persona.nombre).
Método Función guardada como propiedad de un objeto (persona.presentarse()).
Array Lista ordenada de valores que se recorren con índice numérico.
Índice Posición de un elemento en un array; empieza en 0.
Callback Función que se pasa como argumento a otra y se ejecuta después (por ejemplo en addEventListener).
Evento Acción que ocurre en la página (click, teclado, formulario) y se puede escuchar.
DOM Document Object Model: estructura en objetos del documento HTML que JavaScript manipula.
Scope (ámbito) Región del código donde una variable es accesible (global o de bloque/función).
Closure Función que recuerda las variables de su ámbito externo incluso cuando termina la función que las creó.
Hoisting Comportamiento por el que las declaraciones de function y var suben al inicio de su ámbito.
null vs undefined null es ausencia intencional de valor; undefined es una variable sin asignar.
Comparación estricta Comparar valor y tipo a la vez usando === y !==, evitando conversiones implícitas.
Dominar estos conceptos básicos es la base para avanzar en asincronía (promesas y async/await), programación orientada a objetos y el desarrollo web moderno.
