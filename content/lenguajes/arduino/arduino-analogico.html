Del mundo analógico al digital

La naturaleza es analógica: la temperatura, la luz o la posición de una rueda varían de forma continua, y casi todos los sensores traducen esa magnitud en un voltaje proporcional. Sin embargo, un microcontrolador solo entiende unos y ceros; para leer un voltaje intermedio necesita un conversor analógico-digital (ADC). En el Arduino Uno los pines A0 a A5 son las seis entradas analógicas del ADC: en ellos mides un voltaje entre 0 y 5 V y obtienes un número proporcional. Los pines digitales, en cambio, solo distinguen si hay más o menos de un umbral (~2,5 V): no te dicen cuánto, solo si.

Pines digitalesPines analógicos (A0-A5)
Leen 0 ó 1 (con un umbral)Leen un valor continuo de 0 a 1023
No miden la magnitud realMiden el voltaje conectado
Botones, interruptores, detectoresPotenciómetros, sensores, joysticks

Los sensores que se leen por analógico son la puerta de entrada al mundo real del microcontrolador: potenciómetros (posición), LDR (luz), LM35/TMP36 (temperatura), sensores de gas, joysticks o los ejes de una IMU. La regla práctica: si un sensor devuelve un voltaje que depende de algo externo, lo leerás por una entrada analógica.

---

analogRead y el ADC de 10 bits

La función analogRead(pin) mide el voltaje en un pin analógico y devuelve un entero entre 0 y 1023. El ADC del ATmega328P tiene una resolución de 10 bits y por eso el máximo es 2¹⁰ − 1 = 1023: los 10 bits representan 1024 niveles distintos entre 0 V y la tensión de referencia.

ReferenciaResolución por paso
5 V (por defecto)5000 mV / 1024 ≈ 4,88 mV
3,3 V3300 mV / 1024 ≈ 3,22 mV
1,1 V interna (INTERNAL1V1)1100 mV / 1024 ≈ 1,07 mV

Esos ~4,88 mV por paso significan que no puedes distinguir diferencias menores de unos 5 mV con referencia de 5 V. Cada conversión tarda unas ~100 µs (el ADC corre a ~125 kHz en la Uno), así que hay miles de lecturas por segundo; para señales ruidosas conviene promediar varias. La referencia por defecto es la tensión de alimentación (5 V); puedes cambiarla con analogReference(tipo) antes de llamar a analogRead() para medir rangos pequeños con más detalle, aceptando esa nueva escala en tus conversiones.

// Lee A0 y muestra el valor crudo y el voltaje por el monitor serie
const int PIN = A0;
void setup() {
  Serial.begin(9600);
}

void loop() {
  int lectura = analogRead(PIN);             // 0..1023
  float voltaje = lectura * (5.0 / 1023.0);  // → voltios
  Serial.print("ADC = ");
  Serial.print(lectura);
  Serial.print("  |  ");
  Serial.print(voltaje, 2);
  Serial.println(" V");
  delay(300);
}

Potenciómetro: medir posiciones

El potenciómetro es una resistencia variable con tres patas: dos extremos fijos y un cursor (wiper) central que divide la resistencia total en dos partes. Conectado entre 5 V y GND forma un divisor de tensión: el voltaje del cursor varía de forma continua entre 0 y 5 V según la posición del eje. Al girarlo, analogRead() devuelve valores entre 0 y 1023.

Las tres patas de un potenciómetro formando un divisor:

   5 V ──── pata izquierda
          │
         ┌┴┐
         │ │  ← pista resistiva
         └┬┘
          │
   pata central (cursor) ──► A0
          │
         ┌┴┐
         │ │
         └┬┘
   GND ──── pata derecha
// Potenciómetro en A0: giro convertido a porcentaje
const int PIN_POT = A0;
void setup() {
  Serial.begin(9600);
}

void loop() {
  int lectura = analogRead(PIN_POT);           // 0..1023
  int porcentaje = map(lectura, 0, 1023, 0, 100);
  Serial.print("ADC = ");
  Serial.print(lectura);
  Serial.print("  |  ");
  Serial.print(porcentaje);
  Serial.println(" %");
  delay(50);
}

El potenciómetro es el ejemplo didáctico por excelencia de entrada analógica: barato, lineal, fácil de conectar y sin electrónica adicional. Comprueba las patas antes de cablear: la central es el cursor (conectar las dos externas al revés no rompe nada, son simétricas, pero unir el cursor a GND y una externa a 5 V invierte la curva de lectura). También puede funcionar como resistencia variable (reóstato) usando solo la pata central y una externa, útil para ajustar la sensibilidad de otros divisores.

Sensor de luz (LDR)

Una fotoresistencia o LDR (Light Dependent Resistor) tiene una resistencia que disminuye al recibir luz: a pleno sol baja a unos cientos de ohmios y en la oscuridad puede superar el megaohmio. No devuelve un voltaje por sí sola: necesita una resistencia fija que forme con ella un divisor de tensión. La más habitual es una fija de 10 kΩ.

Opción A (más luz → más voltaje):    5 V ── LDR ── A0 ── 10 kΩ ── GND
Opción B (más luz → menos voltaje):  5 V ── 10 kΩ ── A0 ── LDR ── GND

Eliges una posición u otra según el comportamiento deseado: con el LDR arriba, a más luz mayor lectura; con la fija arriba, a más oscuridad mayor lectura. En ambas, el reparto de caídas depende de la relación entre las dos resistencias.

// Lámpara nocturna: enciende el LED cuando oscurece
const int PIN_LDR = A0;
const int PIN_LED = 9;
const int UMBRAL = 500;   // se ajusta con el monitor serie

void setup() {
  Serial.begin(9600);
  pinMode(PIN_LED, OUTPUT);
}

void loop() {
  int lectura = analogRead(PIN_LDR);
  Serial.println(lectura);
  if (lectura < UMBRAL) {          // pocos lúmenes: de noche
    analogWrite(PIN_LED, 255);
  } else {
    analogWrite(PIN_LED, 0);
  }
  delay(200);
}

El valor UMBRAL se calibra empíricamente: abre el monitor serie, ilumina y tapa el sensor, anota los dos valores y fija un punto intermedio. Recuerda que la respuesta de un LDR no es lineal: no intentes convertir la lectura en "lux" sin una tabla de calibración previa.

Si conectas el LDR sin la resistencia fija, el pin A0 queda a alta impedancia y leerá valores flotantes. El divisor necesita siempre ambas resistencias: el LDR y su compañera fija.

Sensor de temperatura

El LM35 (y su primo el TMP36) es un sensor de temperatura con salida lineal: entrega 10 mV por cada grado Celsius. A 0 °C sale 0 V, a 25 °C salen 0,25 V, y solo tiene tres patas: Vcc, Out y GND. El TMP36, su gemelo de 3 pines, añade un desfase de 0,5 V a 0 °C y su fórmula cambia a (lectura * 5.0 / 1023.0 − 0.5) / 0.01; compruébalo siempre en su hoja de datos.

LM35 (cara plana hacia ti):  Pata 1 → 5 V  ·  Pata 2 (Out) → A0  ·  Pata 3 → GND

La conversión se hace en dos pasos: primero pasas el valor del ADC a voltios y después divides entre 0,01 (10 mV por grado). La fórmula completa es (lectura * 5.0) / 1023.0 / 0.01 grados Celsius.

// Termómetro con LM35 en A0: imprime °C y un estado
const int PIN_SENSOR = A0;
void setup() {
  Serial.begin(9600);
}

void loop() {
  int lectura = analogRead(PIN_SENSOR);
  float voltaje = lectura * (5.0 / 1023.0);
  float temperatura = voltaje / 0.01;    // 10 mV por °C
  Serial.print("Voltaje = ");
  Serial.print(voltaje, 2);
  Serial.print(" V  |  ");
  Serial.print(temperatura, 1);
  Serial.print(" °C  |  ");

  if (temperatura < 18) {                // zona fría
    Serial.println("Frío");
  } else if (temperatura < 28) {         // zona confort
    Serial.println("Cálido");
  } else {
    Serial.println("Caliente");
  }
  delay(500);
}

El LM35 es lineal y barato en el rango de clima ambiente; medir temperaturas bajo cero en la Uno requiere un montaje de polarización extra. Alternativas habituales:

  • Termistor NTC: muy barato y sensible, pero con respuesta no lineal; exige la fórmula de Steinhart-Hart con las constantes B de su hoja de datos.
  • DHT11 / DHT22: temperatura y humedad en un módulo, pero con salida digital y protocolo propio: se lee mediante librería y lo veremos en el tema de librerías.

Escalar valores con map() y constrain()

El ADC devuelve 0-1023, pero casi nunca quieres mostrarlo tal cual: prefieres porcentajes (0-100), grados de servo (0-180) o valores de PWM (0-255). La función map(valor, deMin, deMax, aMin, aMax) reescala de un rango a otro de forma lineal, y constrain(valor, min, max) limita el resultado a un intervalo cerrado.

int lectura = analogRead(A0);                    // 0..1023
int porcentaje = map(lectura, 0, 1023, 0, 100);  // a 0-100 %
int brillo     = map(lectura, 0, 1023, 0, 255);  // a PWM
int angulo     = map(lectura, 0, 1023, 0, 180);  // a servo
int seguro = constrain(porcentaje, 0, 100);      // recorta el rango

La diferencia clave: map() no recorta. Si la entrada supera el rango original, el resultado se sale del rango destino (por ejemplo, 150 %). constrain() sí acota. El patrón habitual es map() + constrain() para proteger la salida cuando el sensor puede sobrepasar los extremos (por contaminación del divisor o montajes imperfectos).

const int PIN_POT = A0;
void setup() {
  Serial.begin(9600);
}

void loop() {
  int lectura = analogRead(PIN_POT);               // 0..1023
  int porcentaje = map(lectura, 0, 1023, 0, 100);  // puede salirse del rango
  porcentaje = constrain(porcentaje, 0, 100);      // ahora está acotado
  Serial.print("ADC = ");
  Serial.print(lectura);
  Serial.print("  |  ");
  Serial.println(porcentaje);
  delay(100);
}

map() trabaja con enteros, truncando en cada paso; no lo uses para precisión decimal. Para floats escala con aritmética manual: float normalizado = lectura / 1023.0; float salida = normalizado * 100.0;

Errores comunes

1. Alimentar sensores a 5 V y leer con referencia de 3,3 V

Si el sensor entrega salidas de 0-5 V pero la placa (o la referencia ADC) trabaja a 3,3 V, la lectura satura en el extremo alto y es inexacta. Revisa la tensión de alimentación del sensor y decide una sola referencia para todos tus cálculos.

2. Leer sin la masa común

Sensor y placa deben compartir GND; sin él, la lectura "flota" y devuelve valores absurdos o erráticos. Es el fallo nº 1 en montajes analógicos.

3. Conectar la salida del sensor sin conocer su rango

// Se esperaba una escala de 0-5 V, pero el sensor entrega 0-1,8 V
// → solo se aprovecha ~el 36 % del ADC (valores de 0 a 368)

Consulta la hoja de datos: si la salida máxima queda lejos de la referencia, adapta con un divisor, un op-amp o cambiando analogReference().

4. Olvidar la referencia en los cálculos

// ❌ Supone 5 V aunque el ADC use la referencia interna de 1,1 V
// float v = lectura * (5.0 / 1023.0);

// ✅ Coherente con analogReference(INTERNAL1V1)
// float v = lectura * (1.1 / 1023.0);

5. Usar map() como si trabajara con float

map() trunca a entero en cada operación y no sirve para precisión decimal. Escala a mano con float, como se explica en la sección anterior.

6. No proteger las entradas de picos superiores a 5 V

Regla de oro del ADC: nunca conectes a un pin analógico un voltaje superior a Vcc + 0,5 V (5 V en la Uno); los pines del ATmega no lo toleran y el daño puede ser permanente. Un transitorio en A0-A5 también puede dañar el ADC: añade resistencias en serie y, en entornos ruidosos, diodos de sujeción o un zener de 5,1 V a tierra. El pin Aref debe mantenerse igualmente dentro de ese margen.

Ejercicios

  1. Barra de brillo con potenciómetro: con un potenciómetro en A0 y un LED en el pin 9, haz que el giro controle el brillo con map() y muestra en el monitor serie el valor crudo, el porcentaje y el valor PWM enviado.
  2. Lámpara nocturna: con el LDR + 10 kΩ en A0 y un LED en el pin 9, enciende el LED cuando oscurezca usando un umbral calibrado con el monitor serie. Añade un segundo umbral intermedio que encienda el LED a media potencia.
  3. Termómetro: con un LM35 en A0, imprime la temperatura en °C por el monitor serie y avisa con distintas frases si está por debajo de 15 °C, entre 15 y 30 °C, o por encima. Cambia el brillo de un LED en el pin 9 según la zona.
  4. Control acotado: lee el potenciómetro, conviértelo a un valor 0-100 con map() y muestra en el monitor serie el resultado sin constrain() y después de aplicarlo, girando hasta los topes. Explica en qué momentos difieren.
  5. Detector con histéresis: con el LDR, enciende el LED solo si la lectura supera 600 y no lo apagues hasta que baje de 400. Comprueba que el LED parpadea mucho menos que con un único umbral. ¿Por qué ocurre?
