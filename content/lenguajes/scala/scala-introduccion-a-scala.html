¿Qué es Scala? Funcional + OOP en la JVM

Scala (del inglés scalable language) es un lenguaje que combina programación orientada a objetos con programación funcional y corre sobre la máquina virtual de Java. Nació en 2003 en la EPFL de Lausana, bajo la dirección de Martin Odersky, el mismo autor del compilador javac. Esto significa que puedes usar bibliotecas de Java directamente desde Scala, y compilar a los mismos .class que la JVM ejecuta.

Su nombre viene de su objetivo inicial: crecer (scalar) con la complejidad del problema. Un script de una línea y un clúster de miles de nodos se escriben con la misma expresividad. Por eso es el lenguaje de referencia de Apache Spark, Akka y gran parte de la infraestructura de empresas como Twitter, LinkedIn y Netflix.

Al correr sobre la JVM, Scala hereda una ventaja única: cualquier biblioteca de Java (JDBC, Log4j, Spring, etc.) se importa y utiliza sin adaptadores.

Instalación: JDK y sbt

Para ejecutar Scala necesitas un JDK (Java Development Kit) y el compilador Scala. La vía más rápida es instalar sbt, la herramienta de construcción estándar del ecosistema: descarga automáticamente el compilador y las dependencias del proyecto. En este curso asumimos Scala 3, la versión actual del lenguaje.

# Verifica tu máquina virtual de Java (requiere JDK 8 o superior)
java -version

# macOS / Linux con Homebrew
brew install sbt

# Debian / Ubuntu (agregando el repositorio oficial)
sudo apt install default-jdk scala sbt

# Windows con scoop
scoop bucket add typesafe
scoop install sbt

# Verificar la instalación y lanzar una sesión interactiva
sbt --version
sbt console

sbt es lento la primera vez porque descarga las dependencias. Corre sí, es normal; una vez listo, las compilaciones posteriores son casi instantáneas.

Si prefieres empezar sin instalar nada, visita la web oficial scastie.scala-lang.org: un playground online con compilador embebido, ideal para las primeras pruebas del curso.

El REPL de Scala

Antes de escribir archivos, conviene conocer el REPL (Read-Eval-Print Loop). Es una consola interactiva que evalúa cada línea al momento y muestra el tipo inferido de cada resultado. Es la forma más rápida de aprender Scala sin crear proyectos.

# Abre la consola interactiva (Puede tardar en la primera carga)
sbt console

# O con scala-cli, una alternativa más ligera:
scala-cli repl
// Dentro del REPL, cada expresión se evalúa de inmediato
val nombre = "Scala"                    // val nombre: String = Scala
val edad = 2026 - 2003                  // val edad: Int = 23
val lista = List(1, 2, 3, 4)            // val lista: List[Int] = List(1, 2, 3, 4)
lista.map(_ * 2)                        // res0: List[Int] = List(2, 4, 6, 8)

// :quit sale del REPL
// :help muestra todos los comandos disponibles

El REPL antepone resN (resultado N) a cada resultado sin nombre, y siempre te muestra el tipo inferido entre dos puntos.

Esta retroalimentación instantánea es tu mejor maestra: escribe una expresión, observa qué tipo te devuelve y vas formando tu intuición sobre Scala.

Tu primer programa: hola.scala

Todo programa Scala que quieras ejecutar de forma independiente necesita un object con un método main. La declaración @main def (Scala 3) es moderna y limpia; la forma clásica Scala 2 también funciona. Crea el archivo hola.scala con el siguiente contenido.

// hola.scala
// Punto de entrada moderno (Scala 3): se ejecuta de forma automática
@main def hola(): Unit =
  val mensaje = "Hola, Scala desde la JVM!"
  println(mensaje)

  // Scala 3 también permite la entrada clásica, para quien usa Scala 2:
  // object Hola { def main(args: Array[String]): Unit = println("Hola") }
# Ejecutar como script suelto con scala-cli
scala-cli run hola.scala

# O dentro de un proyecto sbt: crea src/main/scala/hola.scala y ejecuta
sbt run

# Salida esperada:
# Hola, Scala desde la JVM!

Con scala-cli puedes ejecutar un archivo suelto sin crear un proyecto completo: ideal para entrenar las lecciones de este curso.

object y el punto de entrada

Java exige que el código viva en clases; Scala ofrece además objects: singletons con la misma sintaxis que una clase pero instanciados una sola vez. Al ejecutar un programa, la JVM busca un main executable y sbt solo se encarga de encontrarlo.

// object: es un singleton. No necesita "new" para usarse
object Calculadora:

  // Método estático equivalente a static en Java
  def suma(a: Int, b: Int): Int = a + b

  // Punto de entrada clásico compatible con Scala 2 y 3
  def main(args: Array[String]): Unit =
    println(suma(3, 4))       // 7
    println(Calculadora.suma(10, 20)) // 30

// @main en Scala 3: genera automáticamente el punto de entrada
@main def entrada(): Unit =
  println("Hola desde @main")

Un object no es una clase instanciable: no puedes usar new Calculadora. En su lugar, siempre existe una única instancia disponible en todo el programa.

DeclaraciónQué es
object NombreSingleton global con miembros estáticos
def main(args)Entrada clásica, compatible Scala 2 y 3
@main defEntrada moderna de Scala 3, más limpia

Ejercicios prácticos

  1. Verifica que tu JDK funciona con java -version y que tienes instalado sbt o scala-cli.
  2. Abre el REPL y resuelve en él las operaciones 5 + 8, 10 * 3 - 2 y "Hola" + " Scala". Observa los tipos que infiere el REPL.
  3. Crea hola.scala con tu nombre y tu edad, y ejecútalo con scala-cli run hola.scala.
  4. Define un object Mensajero con un método saludar() que imprima un mensaje y llámalo desde un @main.
  5. En el REPL, escribe :quit y vuelve a abrirlo: confirma que tus definiciones anteriores ya no existen, porque cada sesión es independiente.
