val vs var y los tipos

Scala distingue dos formas de declarar datos: val crea un valor inmutable (recomendado siempre) y var crea una variable reasignable. La inmutabilidad es el pilar del estilo funcional: un val garantiza que un dato nunca cambia, lo que simplifica el razonamiento y evita errores en programas concurrentes.

val nombre = "Ada"          // String inmutable
val vida: Int = 36          // El tipo se puede anotar tras los dos puntos
var dias = 0                // var: reasignable, pero úsalo con moderación
dias = dias + 1             // OK, var se puede reasignar

// nombre = "Grace"          // ERROR: un val no se puede reasignar

// El sistema de tipos es tipado estático, pero con inferencia
val entero: Int = 42
val doble = 3.14            // Double
val booleano = true         // Boolean

Escribe siempre val salvo que tengas una razón clara para mutar. Esta disciplina es lo que hace a Scala funcional.

El REPL imprime el tipo inferido de cada valor: por ejemplo 1 + 1 devuelve Int. Los tipos numéricos de Scala son Byte, Short, Int, Long, Float y Double, con los mismos tamaños que en la JVM.

Funciones y azúcar sintáctico

En Scala las funciones son ciudadanos de primera clase: se pueden guardar en valores, pasar como argumentos y devolver desde otras funciones. Se definen con def, y con la notación moderna de Scala 3 el cuerpo va después de dos puntos y un igual =, sin necesidad de llaves si es una única expresión.

def doble(x: Int): Int = x * 2

def saludar(nombre: String): Unit = println(s"Hola $nombre")

// Sin anotar el tipo de retorno (Scala lo infiere)
def triple(x: Int) = x * 3

// Función anónima (lambda) guardada en un val
val cuadrado = (x: Int) => x * x

@main def demo(): Unit =
  println(doble(21))     // 42
  saludar("GuiaDev")     // Hola GuiaDev
  println(cuadrado(5))   // 25

// La barra baja _ es un comodín para el parámetro
val nums = List(1, 2, 3)
println(nums.map(_ * 10)) // List(10, 20, 30)

La flecha => separa la lista de parámetros del cuerpo de una lambda. En Scala 3, un bloque de varias líneas puede omitir las llaves usando la indentación, igual que en Python.

En Java hay interfaces como Comparator; en Scala escribes una lambda de una sola línea y listo. Esa diferencia de verbosidad es la mayor ventaja percibida del lenguaje en el día a día.

Expresiones y sentencias

Casi todo en Scala es una expresión: algo que produce un valor. Un if, un bloque { } y hasta println devuelven un resultado. Esta es la gran diferencia con Java/Python, donde todo es sentencia (instrucción que solo produce efectos).

// Un if es una expresión: devuelve un valor
val dia = 3
val diaNombre = if dia == 1 then "Lunes" else "Otro día"
println(diaNombre)

// El último valor de un bloque es su resultado (no hace falta return)
def conDescuento(precio: Double): Double =
  val descuento = if precio > 100 then precio * 0.1 else 0.0
  precio - descuento

println(conDescuento(200)) // 180.0

// Las expresiones se pueden anidar
val nota = 85
val calificacion = if nota >= 60 then "Aprobado" else "Reprobado"
println(calificacion)

No escribas return en Scala. El último valor de cada bloque ya es lo que se devuelve, y usar return rompe el flujo funcional (los compiladores lo desaconsejan).

A diferencia de muchas sintaxis, en Scala 3 la palabra clave then y else son opcionales aunque se recomienda usarlas para legibilidad.

Operadores y notación de prefijo

En la mayoría de lenguajes los operadores (+, -, *, ==) son parte de la sintaxis. En Scala son métodos: a + b es azúcar sintáctico de a.+(b). Esto permite inventar operadores propios cuando escribes métodos con símbolos.

val suma = 5 + 3          // Internamente: 5.+(3)
val mezcla = "Scala" + " 3" // También es un método concatenador

// Llamadas sin punto ni paréntesis (notación de infix)
val list1 = List(1, 2)
val list2 = list1 :+ 3    // List(1, 2, 3)
val list3 = 0 :: list1    // List(0, 1, 2)

// Los operadores de comparación son métodos también
println(1.<(2))            // true, usa paréntesis y punto
println(1 < 2)            // true, estilo normal
println("a" == "a")       // true: == compara contenido, no referencia

En Scala, == compara valores (como equals en Java), no referencias. Para comparar referencias se usa eq, que rara vez necesitarás.

Strings e interpolación

Los strings de Scala se basan en String de Java, pero la interpolación los hace mucho más cómodos: al anteponer s a las comillas, cualquier $expresion dentro del texto se evalúa y se inserta en su lugar.

val nombre = "Andrea"
val edad = 28

// Interpolación simple con s
val texto = s"Me llamo $nombre y tengo $edad años"
println(texto)

// Interpolación de expresiones: se evalúa entre llaves
println(s"El doble de $edad es ${edad * 2}")

// Interpolador f: formato numérico estilo printf
val pi = 3.14159265
println(f"Pi con 3 decimales: $pi%.3f")

// Triple comilla: strings en varias líneas sin escapar comillas
val poema = """La JVM es el escenario
               donde Scala baila su danza."""
println(poema)

Si tu string contiene muchos caracteres especiales, las triples comillas """...""" evitan escapar cada comilla o barra. Excelentes para regex y SQL embebido.

Para un literal con $ que no quieras interpolar, usa $$ dentro de un string con prefijo s, o simplemente sin prefijo.

Con el interpolador f puedes formatear como en printf: %d para enteros, %.2f para dos decimales y %s para strings.

Ejercicios prácticos

  1. Define un val para tu nombre, otro para tu edad y muestra ambos con un único println usando interpolación s.
  2. Escribe una función esPar(n: Int): Boolean usando la expresión n % 2 == 0 y compruébala con 4 y con 5.
  3. Crea un val con una lambda que convierta grados Celsius a Fahrenheit y úsala con 0 y 100.
  4. Compara a mano qué devuelve 1 + 2 * 3 y verifica el resultado en el REPL; luego reescribe la expresión para obtener 9.
  5. Construye un texto con el interpolador f que muestre el número 2.0 / 3 con solo dos decimales.
