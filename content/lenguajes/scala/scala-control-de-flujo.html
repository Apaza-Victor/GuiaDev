if como expresión

A diferencia de Java, donde if es una instrucción que no produce valor, en Scala el if es una expresión: siempre devuelve uno de los dos valores posibles. Esto permite asignar directamente un resultado a un val y pensar el código como datos, no como pasos.

val nota = 7.5

// if como expresión: el resultado se guarda en un val
val estado = if nota >= 6.0 then "Aprobado" else "Reprobado"
println(estado) // Aprobado

// Comparación con Java: no hay operador ternario, el if ya lo es
val descuento = if nota > 8.0 then 20 else 5
println(s"Descuento del $descuento%")

// if anidados devuelven el valor de la rama que se ejecuta
val puntaje = 92
val nivel = if puntaje >= 90 then "Experto"
            else if puntaje >= 70 then "Intermedio"
            else "Básico"
println(nivel) // Experto

Al ser una expresión, if debe tener sus dos ramas del mismo tipo. Si una rama no devuelve nada útil, el tipo se combina con Unit y pierdes el valor.

Pattern matching con match

El pattern matching es el switch de Scala llevado al extremo: empareja valores contra patrones (constantes, tipos, estructuras) y desestructura datos. Con case y el guard if puedes crear lógica compleja en una sola expresión limpia.

def clasificar(n: Int): String = n match
  case 0                => "Cero"
  case 1 | 2 | 3        => "Pequeño"
  case x if x < 0       => "Negativo"
  case n if n % 2 == 0  => "Par grande"
  case _                => "Positivo impar"

println(clasificar(0))   // Cero
println(clasificar(2))   // Pequeño
println(clasificar(-7))  // Negativo
println(clasificar(100)) // Par grande
println(clasificar(99))  // Positivo impar

// match también desestructura tuplas
val punto = (3, -2)
val eje = punto match
  case (0, _) => "Sobre el eje Y"
  case (_, 0) => "Sobre el eje X"
  case (x, y) => s"En ($x, $y)"
println(eje) // En (3, -2)

El patrón case _ es el comodín que captura el resto. Si lo omites y un valor no encuentra caso, se lanza una MatchError en tiempo de ejecución.

PatrónQué empareja
case 5El valor exacto 5
case xCualquier valor ligado a x
case x if condValores que cumplen el guard cond
case (a, b)Desestructura una tupla de dos
case _Comodín: captura cualquier cosa

Bucles y for-comprehensions

Scala tiene los clásicos bucles for/while, pero su joya son las for-comprehensions: expresiones que transforman colecciones sin mutar estado. En lugar de "para cada elemento haz algo", piensas en "para cada elemento genera una salida", y se usan con yield para construir una nueva colección.

// for estilo imperativo (aceptable, pero menos funcional)
for i <- 1 to 3 do
  println(s"vuelta $i")

// for-comprehension con yield: crea una nueva colección con resultados
val dobles = for i <- List(1, 2, 3, 4) yield i * 2
println(dobles) // List(2, 4, 6, 8)

// Filtros con guards y rangos de dos dimensiones
val tabla = for
  i <- 1 to 3
  j <- 1 to 3
  if i != j
yield s"$i-$j"
println(tabla) // Vector(1-2, 1-3, 2-1, 3-1, 2-3, 3-2)

// Los rangos 1 to 5 producen Range; usar 1 until 5 excluye el último
(1 until 5).foreach(x => print(x)) // 1234
println()

La flecha <- en un for se lee como "recorre" o "procede de". 1 to 5 es inclusivo y 1 until 5 exclusivo.

while y control de flujo

Para bucles con condición desconocida se usa while, igual que en Java. Usar while implica mutar variables externas para llevar el estado: mejor limítalo a leer entrada de usuario u otros casos donde el estado variable sea inevitable.

var intentos = 0
var adivinado = false
var secreto = "sbt"

while !adivinado do
  intentos += 1
  if intentos >= 3 then
    adivinado = true
    println(s"Usaste $intentos intentos. El secreto era $secreto")
  else
    println(s"Intento $intentos fallido")

// while con un contador (versión no recursiva de un for)
var suma = 0
var i = 1
while i <= 5 do
  suma += i
  i += 1
println(suma) // 15

Un while devuelve Unit, no un valor. Si necesitas acumular resultados, piensa en funciones recursivas o fold, que verás en las próximas lecciones.

En Scala 3 los bucles do separan la condición del cuerpo: while cond do cuerpo. Scala 2 usaba llaves siempre.
