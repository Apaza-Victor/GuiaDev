¿Qué es Groovy?

Groovy es un lenguaje dinámico para la JVM, creado por James Strachan (2003) y hoy mantenido por Apache. Se ejecuta sobre Java con una sintaxis más concisa: soporta scripting, closures, tipado opcional, builders y metaprogramación. Además, es 100% compatible con Java.

Su uso más famoso es Gradle (build scripts), los pipelines de Jenkins, y DSLs de pruebas (Spock). Si trabajas en la JVM y quieres scripts, prototipos rápidos o automatizar tu build, Groovy es la opción natural junto a Kotlin.

La idea central: "Java para personas" — mantiene el rendimiento y las librerías de la JVM, pero con mucho menos código y más dinamismo.

Instalación

Necesitas una JVM (JDK 8+ funciona; se recomienda 17+ en 2026). Luego instalas la distribución Groovy.

# 1. Verificar JVM
java -version

# 2. Instalar Groovy
# Windows (choco)
choco install groovy
# o descargar binario de https://groovy.apache.org/download.html

# Linux/macOS (sdkman recomendable)
curl -s "https://get.sdkman.io" | bash
source ~/.bashrc
sdk install groovy
sdk current groovy

# 3. Verificar
groovy --version
groovyc --version

# 4. REPL / shell interactivo (Groovy Shell)
groovysh

# 5. Ejecutar un script
groovy hola.groovy

Con SDKMAN gestionas versiones de Groovy y de JVM sin fricción. El ejecutable groovy interpreta archivos .groovy; groovyc compila a clases si lo necesitas.

Tu primer script

En Groovy, un script .groovy se ejecuta directamente: sin clase obligatoria, con semicolons opcionales y paréntesis opcionales al llamar funciones.

println "Hola, GuiaDev!"          // se omiten paréntesis
def nombre = "Groovy"             // def = tipado dinámico
int anio = 2026                    // también puedes fijar tipo

println "Aprendiendo ${nombre} en ${anio}"   // interpolación

// TODO devuelve un valor: incluso el if
def clasifica = 20
def tipo = clasifica >= 18 ? "adulto" : "menor"
println tipo

// Closures, listas, maps en una sola idea
def datos = [1, 2, 3]
println datos.sum()                  // 6
println datos.collect { it * 2 }     // [2, 4, 6]
groovy hola.groovy
# Salida:
# Hola, GuiaDev!
# Aprendiendo Groovy en 2026
# adulto
# 6
# [2, 4, 6]

# También por consola
groovy -e "println 'inline'"

El acceso libre a la variable it (parámetro implícito en closures de un argumento) y la interpolación "${x}" hacen que Groovy sea rapidísimo de escribir. Es la vía fácil para prototipar en la JVM.

Dinamismo y tipado

Groovy es dinámico por defecto: las variables con def pueden cambiar de tipo en tiempo de ejecución. También permite anotar tipos (Java-like) o activar compilación estática con @CompileStatic.

// def: tipado dinámico
def valor = 42
println valor.getClass()          // java.lang.Integer
valor = "ahora soy texto"
println valor.getClass()          // java.lang.String

// Tipado estático (opcional)
int numero = 7
// numero = "texto"   // esto fallaría al compilar en modo estático

// Coerciones e igualdades flexibles (Groovy Truth)
def archivo = "hola"
if (archivo) println "no vacío (Groovy Truth)"   // todo "no false/null/vacío" es true

// '==' en Groovy es .equals (con safe equality null-safe)
println ('a' == 'a')                    // true (content)
println new Integer(1) == 1L            // true (valor, no referencia)
ModoUso
def xDinámico total (default)
int/String/List qTipado estático "javoso" en esa variable
@CompileStaticTodo el método compila estáticamente (rendimiento y seguridad de tipos)

El dinamismo es cómodo pero lento en bucles "calientes" y puede ocultar typos. Para código de producción con restricciones de rendimiento, añade @CompileStatic en los métodos críticos.

Compatibilidad con Java

Groovy corre en la JVM y puede usar cualquier clase de Java: ArrayList, HashMap, java.nio, frameworks... sin peaje. El código Java suele ser válido Groovy casi siempre.

// Usar clases de Java directamente
import java.time.LocalDateTime

def ahora = LocalDateTime.now()
println ahora.format(java.time.format.DateTimeFormatter.ISO_LOCAL_DATE)

// Colecciones de Java desde Groovy
def lista = new java.util.ArrayList()
lista.add "uno"
lista.add "dos"
println lista                         // [uno, dos]

// Propiedades Java accesibles como atributos
class Cliente { String nombre; int edad }
def c = new Cliente(nombre: 'Ana', edad: 30)   // constructor con mapa
println c.nombre                              // Ana (getNombre)
c.edad = 31                                    // setEdad
println c.edad

// Llamar a métodos estáticos y estándar
println Math.max(3, 7)
println('hola'.toUpperCase())

// Closures a interfaces Java (como lambda)
def tarea = { println "hola" } as Runnable
new Thread(tarea).run()

Puedes mezclar Groovy y Java en el mismo proyecto sin problemas: los .groovy compilan a .class. Esa interoperación invisible es tu seguro para migrar scripts a aplicaciones y viceversa.

Ejercicios prácticos

Practica en orden: cada ejercicio asume lo aprendido en el anterior.

  1. Instalación: verifica java -version, instala Groovy (sdkman o choco) y ejecuta groovy --version.
  2. Hola: escribe hola.groovy con tu nombre y edad interpolados y ejecútalo.
  3. Dinamismo: crea una variable def, cambia su tipo varias veces e imprime su clase con getClass().
  4. Groovy Truth: comprueba cuáles de '', [], 0, null y '0' son verdaderos en un if.
  5. Java interop: usa java.nio.file.Path para mostrar la ruta actual y listar archivos.
