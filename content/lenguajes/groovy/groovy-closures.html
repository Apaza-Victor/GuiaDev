Closures básicas

Una closure es un bloque de código que se asigna a una variable, se pasa como argumento y se ejecuta. Capturan el ámbito donde se crean. Es la pieza que da vida a collect, findAll, builders y Spock.

// Definición
def saluda = { println 'Hola' }
saluda()                       // Hola

// Con parámetros
def suma = { a, b -> a + b }
println suma(2, 3)             // 5

// Parámetro implícito it
def doble = { it * 2 }
println doble(21)              // 42

// Closure en una variable (primer ciudadano)
def aplicar = { fn, valor -> fn(valor) }
def resultado = aplicar({ it * 10 }, 5)
println resultado              // 50

// Captura de ámbito (values del exterior)
def factor = 3
def mult = { n -> n * factor }
println mult(4)                // 12

// Con defaults y varargs
def saluda2 = { nombre = 'Invitado' -> "Hola $nombre" }
println saluda2()              // Hola Invitado
def rest = { head, ...rest -> [head, rest] }
println rest(1, 2, 3)          // [1, [2, 3]]

Una closure es Closure con métodos call(), curry(), delegate... El parámetro implícito it habilita la sintaxis ultracompacta: [1,2,3].collect { it * 2 }.

Delegación y configuración

El poder oculto de las closures es el delegado (delegate): dentro de una closure, this resuelve contra el método que la creó, y puedes cambiarlo para ejecutar la closure "como si fuera" otro objeto. Es la base del DSL de Gradle.

class Configuracion {
    String host = 'localhost'
    int puerto = 80

    void aplicar(Closure cl) {
        cl.delegate = this     // la closure configurará "this"
        cl.resolveStrategy = Closure.DELEGATE_FIRST
        cl()
    }
}

def config = new Configuracion()
config.aplicar {
    host = 'guia.dev'         // setter del delegado (this.host)
    puerto = 443
}
println config.host     // guia.dev
println config.puerto   // 443

// Este patrón (builders + delegate) es el DSL:
// project { name = 'x'; dependencies { ... } } en Gradle

Esto es lo que permite escribir alcanza,
en Gradle o Jenkins: plugins { id '...' }. La closure ejecuta sobre el delegado (Gradle project), no sobre el script. Memorízalo: resolveStrategy = DELEGATE_FIRST.

Currying y memoria

Con curry(), curry() fijas parámetros parcialmente, creando una closure derivada: patrones de programación funcional sin importar nada.

def multiplica = { a, b -> a * b }

// Fijar primer parámetro
def por2 = multiplica.curry(2)
def por10 = multiplica.curry(10)
println por2(5)        // 10
println por10(5)       // 50

// curry con rcurry (fija al final)
def divide = { num, den -> num / den }
def medio = divide.rcurry(2)
println medio(10)      // 5 (10/2)

// ncurry: fija por índice
def concat = { a, sep, b -> "$a$sep$b" }
def conGuion = concat.ncurry(1, '-')
println conGuion('a', 'b')   // a-b

// Cachear con memoize (para funciones de coste alto)
def lenta = { n -> println 'calculando'; n * n }.memoize()
println lenta(4)      // calculando\n16
println lenta(4)      // 16  (sin "calculando")

curry está en todas las closures: esencial para construir pipelines y reutilizar configuraciones. memoize() te da caché gratis de un argumento — útil en parseo pesado.

Closures con métodos GDK

El 90% del uso de closures ocurre como argumento de métodos de colecciones: collect, findAll, each, find, every, groupBy, inject.

def numeros = [1, 2, 3, 4, 5, 6]

// collect / findAll / find
def dobles = numeros.collect { it * 2 }
def pares = numeros.findAll { it % 2 == 0 }
def primerImpar = numeros.find { it % 2 == 1 }
println dobles          // [2,4,6,8,10,12]
println pares           // [2,4,6]
println primerImpar     // 1

// each (effetto lateral)
numeros.each { print "$it " }
println()

// every / any
println numeros.every { it > 0 }     // true
println numeros.any { it > 5 }       // true

// groupBy
def agrupados = numeros.groupBy { it % 2 == 0 ? 'par' : 'impar' }
println agrupados                    // [par:[2,4,6], impar:[1,3,5]]

// inject (reduce)
def suma = numeros.inject(0) { acc, n -> acc + n }
println suma                         // 21

// Con maps
def datos = [a: 1, b: 2, c: 3]
datos.each { k, v -> println "$k: $v" }

Esta familia (map/filter/reduce en Ruby-lengua) es tu "mochila" de análisis en Groovy. Cuando trabajes en Gradle scripts, verás each/collect/findAll por todas partes.

Builders

Los builders son la cima del DSL con closures: construyen objetos anidados (XML, JSON, HTML, Swing, tree) con sintaxis declarativa.

import groovy.xml.MarkupBuilder

// MarkupBuilder: generar XML/HTML
def xml = new StringWriter()
def mb = new MarkupBuilder(xml)
mb.persona(id: 1) {
    nombre 'Ana'
    edad 30
    direccion(ciudad: 'Lima') {
        calle 'Av. Principal'
    }
}
println xml.toString()
// <persona id='1'>
//   <nombre>Ana</nombre>
//   <edad>30</edad>
//   <direccion ciudad='Lima'>
//     <calle>Av. Principal</calle>
//   </direccion>
// </persona>

// JsonBuilder
import groovy.json.JsonBuilder
def jb = new JsonBuilder()
jb.user {
    nombre 'Ana'
    etiquetas ['dev', 'data']
}
println jb.toString()
// {"user":{"nombre":"Ana","etiquetas":["dev","data"]}}

// BuilderSoporte: tu propio DSL
import groovy.util.BuilderSupport
// usualmente no necesario: el patrón delegate lo cubre

En creadores anidados, la closure "hijita" se evalúa sobre el builder (delegación). Es muy cómodo, pero ojo: nombres de método (como `class`) pueden chocar; usa cadenas cuando sea necesario.

Ejercicios prácticos

Practica en orden: cada ejercicio asume lo aprendido en el anterior.

  1. Básicas: define cuadrado = { it * it } y pásalo a `[1,3,5].collect(cuadrado)`.
  2. Delegación: define una clase rica con aplicar(Closure) y configúrala asignando propiedades desde dentro.
  3. Curry: crea construirUrl = { base, path -> "$base/$path" }.curry('https://api.x.com') y genera varias URLs.
  4. GDK + closures: de una lista de palabras, agrupa por longitud inicial y cuenta cuántas hay con cada inicial.
  5. Builders: genera un JSON de un catálogo con JsonBuilder y un XML con MarkupBuilder.
