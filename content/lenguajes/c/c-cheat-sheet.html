Palabras reservadas

Las palabras reservadas son términos que C reserva para el propio lenguaje: no puedes usarlos como nombres de variables o funciones. C distingue entre mayúsculas y minúsculas, así que Int o INT no son la palabra reservada int.

Palabras como printf, scanf, strlen o malloc no son reservadas por el lenguaje: son funciones de las bibliotecas estándar que debes declarar con #include.

Sintaxis básica

Un programa en C se compone de directivas (#include), funciones y declaraciones. Toda sentencia termina con punto y coma ; y los bloques se delimitan con llaves { }. La función main es el punto de entrada obligatorio.

#include <stdio.h>     // incluye la biblioteca de entrada/salida

int main(void) {        // función principal
    int edad = 25;      // declaración de variable tipada
    printf("Edad: %d\n", edad);   // imprimir en pantalla
    scanf("%d", &edad);           // leer entrada del usuario

    // comentario de una línea
    /* comentario
       de varias líneas */

    return 0;           // 0 = ejecución correcta
}

Olvidar el ; es el error de compilación más común en C. Revisa siempre el final de cada sentencia antes de compilar.

#include no lleva punto y coma: es una directiva del preprocesador, no una sentencia normal.

Tipos de datos

C guarda los datos en variables con un tipo fijo que define qué puedes almacenar y qué operaciones son válidas. El tamaño exacto depende del sistema; en la mayoría de máquinas modernas int ocupa 4 bytes.

Cada tipo tiene su especificador de formato para printf:

int     entero  = 42;
float   real    = 3.14;
double  doble   = 3.1415926535;
char    car     = 'X';
char    texto[] = "hola";

El tamaño no está garantizado por el estándar: depende de la arquitectura. Usa sizeof(int) para conocerlo en tu máquina.

Estructuras de control

C controla el flujo con condicionales y bucles. Los bloques se encierran en llaves { } y cada sentencia termina con punto y coma ;.

// if / else
if (edad >= 18) {
    printf("Mayor de edad\n");
} else {
    printf("Menor de edad\n");
}
// switch / case
switch (dia) {
    case 1: printf("Lunes\n");   break;
    case 2: printf("Martes\n");  break;
    default: printf("Otro dia\n");
}
// for
for (int i = 0; i < 5; i++) {
    printf("%d ", i);            // 0 1 2 3 4
}
// while
int n = 0;
while (n < 3) {
    printf("%d ", n);           // 0 1 2
    n++;
}
// do-while: se ejecuta al menos una vez
int n = 0;
do {
    printf("%d ", n);
    n++;
} while (n < 3);
// break y continue
for (int i = 0; i < 10; i++) {
    if (i == 2) continue;      // salta el 2
    if (i == 5) break;         // termina en el 5
    printf("%d ", i);          // 0 1 3 4
}

Usa switch cuando compares una variable contra muchas constantes: es más legible que una cadena larga de if / else if. No olvides el break para evitar "caer" al siguiente case.

La diferencia clave: while evalúa la condición antes de entrar y do-while la evalúa después, garantizando al menos una ejecución.

Funciones y punteros

Una función es un bloque reutilizable con un nombre, un tipo de retorno y parámetros tipados. Debe declararse antes de usarse (o indicarse su prototipo arriba). La función main es la entrada de todo el programa.

// Declaración/definición de función
int sumar(int a, int b) {
    return a + b;              // retorna el resultado
}

int main(void) {
    int resultado = sumar(5, 3);   // llamada: resultado = 8
    return 0;
}
// Prototipo (antes de usarla), definición después
int cuadrado(int n);           // prototipo

int main(void) {
    printf("%d\n", cuadrado(4));   // 16
    return 0;
}

int cuadrado(int n) {          // definición
    return n * n;
}

Un puntero guarda una dirección de memoria. Se declara con *, se le asigna una dirección con & y se accede al valor con * (desreferenciar).

int numero = 42;
int *ptr = &numero;    // ptr guarda la dirección de numero
*ptr = 100;            // desreferenciar: modifica numero a 100
printf("%d\n", numero);   // 100
SímboloUsoEjemplo
*Declarar punteroint *ptr;
&Obtener dirección de una variable&numero
*Desreferenciar (obtener el valor)*ptr

Las funciones en C pasan parámetros por valor: reciben una copia. Para modificar una variable del llamador, pasa su dirección (puntero).

// Paso por valor: no afecta al original
void sumarUno(int n) { n++; }

// Paso por referencia (puntero): sí modifica el original
void incrementar(int *n) { (*n)++; }

int main(void) {
    int x = 5;
    sumarUno(x);        // x sigue siendo 5
    incrementar(&x);    // x ahora es 6
    return 0;
}

Cuando pasas una variable normal, la función trabaja con una copia. Si quieres cambiar el valor original, tienes que pasar su dirección con & y recibirla como puntero.

Arrays y cadenas

Un array (arreglo) agrupa varios elementos del mismo tipo en posiciones consecutivas, indexadas desde 0. Un string (cadena) es un array de char que termina con el carácter nulo '\0'.

// Arrays de enteros
int arr[5];              // declara 5 enteros: arr[0]...arr[4]
arr[0] = 10;
arr[1] = 20;
int notas[3] = {9, 8, 10};
printf("%d\n", notas[2]);   // 10 (índice 2 = tercer elemento)

// Arrays de caracteres (cadenas)
char texto[] = "hola";   // 5 celdas: 'h' 'o' 'l' 'a' '\0'
printf("%s\n", texto);   // hola

// Función de string.h para longitud
#include <string.h>
int largo = strlen(texto);   // 4 (no cuenta el '\0')

Las funciones de cadenas están en la biblioteca string.h:

FunciónQué haceEjemplo
strlenDevuelve la longitud (sin el '\0')strlen("hola") → 4
strcpyCopia una cadena en otrastrcpy(destino, origen)
strcatConcatena (une) una cadena al final de otrastrcat(nombre, " Perez")
strcmpCompara dos cadenas (0 si son iguales)strcmp(a, b) == 0

En C no existe un tipo "string" nativo: es un array de char terminado en '\0'. Por eso no puedes asignar ni comparar cadenas con = ni ==; debes usar strcpy y strcmp.

Al copiar o concatenar, reserva espacio suficiente en el destino. Sin espacio, la cadena desborda el array y corrompe memoria.

Conceptos importantes

Glosario rápido de los términos clave que necesitas dominar en C:

ConceptoQué significa
CompiladorPrograma que traduce el código fuente (C) a código máquina (gcc, clang).
Enlazador (linker)Une el código compilado con las bibliotecas y produce el ejecutable final.
EjecutablePrograma final listo para correr en el sistema operativo.
FuenteArchivo de texto con código C (.c) que escribes en un editor.
BibliotecaConjunto de funciones reutilizables: stdio.h (entrada/salida), stdlib.h (memoria/conversiones), string.h (cadenas), math.h (matemáticas).
VariableEspacio de memoria con nombre y tipo que guarda un valor.
Tipo de datoDefine el tamaño y qué se puede guardar (int, char, float, double...).
FunciónBloque de código reutilizable con nombre y posible retorno.
ParámetroVariable declarada en la definición de la función que recibe información.
ArgumentoValor concreto que pasas a la función al llamarla.
RetornoValor que una función devuelve con return.
PunteroVariable que almacena una dirección de memoria.
Dirección de memoriaUbicación numérica donde vive una variable; se obtiene con &.

NULLConstante que representa un puntero sin dirección válida (0).

Domina estos conceptos: punteros, memoria y ámbito son la base que diferencia a un programador sólido de C. Practica con ejemplos pequeños y compila a menudo.

Toda memoria asignada con malloc debe liberarse con free. Olvidarlo produce fugas de memoria (memory leaks).
