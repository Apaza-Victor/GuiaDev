Variables y constantes

Una variable es un espacio de memoria con nombre y tipo donde guardas un valor que puede cambiar durante la ejecución. Una constante guarda un valor fijo que el programa no puede modificar. En C, primero declaras la variable (tipo + nombre) y solo después la usas.

#include <stdio.h>

int main(void) {
    int edad = 30;            // variable entera
    const float PI = 3.1416;  // constante: no se puede modificar
    char letra = 'A';

    edad = 31;                // correcto: la variable puede cambiar
    // PI = 3.5;              // error: PI es constante

    printf("Edad: %d, Pi: %.4f, Letra: %c\n", edad, PI, letra);
    return 0;
}

La palabra reservada const bloquea la reasignación: si intentas escribir otro valor en una constante, el compilador marca un error en esa línea.

Regla de nombreCorrectoIncorrecto
Solo letras, números y guion bajonota_finalnota final
No empezar con númeronum22num
Sin caracteres especialestotal_ventastotal-ventas
Evitar palabras reservadascontadorint

Usa nombres descriptivos y en minúsculas separadas por guion bajo (snake_case): total_ventas dice mucho más que tv.

Tipos de datos básicos (int, float, char)

C ofrece tipos básicos para números enteros, números con decimales y caracteres. El tamaño exacto depende de la arquitectura; estos son los valores típicos en una máquina de 64 bits:

TipoTamaño típicoRango aproximado
char1 byte-128 a 127
int4 bytes-2.147.483.648 a 2.147.483.647
float4 bytes6 a 7 dígitos decimales
double8 bytes15 a 16 dígitos decimales
#include <stdio.h>

int main(void) {
    int alumnos = 25;
    float precio = 19.99;
    double peso = 75.123456789;      // más precisión que float
    char inicial = 'C';
    unsigned short edad = 30;        // entero sin signo (no negativo)

    printf("int: %d\n", alumnos);
    printf("float: %.2f\n", precio);
    printf("double: %.9f\n", peso);
    printf("char: %c\n", inicial);
    return 0;
}

El especificador debe coincidir con el tipo: %d para enteros, %f para decimales y %c para caracteres. Si no coinciden, la salida será basura (comportamiento indefinido).

Operadores aritméticos, relacionales y lógicos

Los operadores combinan valores para producir resultados. Se clasifican en aritméticos (matemáticas), relacionales (comparaciones) y lógicos (booleano).

CategoríaOperadoresEjemplo
Aritméticos+ - * / %suma = a + b;
Relacionales== != < > <= >=a <= 5
Lógicos&& || !a > 0 && b > 0
#include <stdio.h>

int main(void) {
    int a = 10, b = 3;

    printf("Suma: %d\n", a + b);            // 13
    printf("Resta: %d\n", a - b);           // 7
    printf("Multiplicación: %d\n", a * b);  // 30
    printf("División: %d\n", a / b);        // 3 (división entera)
    printf("Resto: %d\n", a % b);           // 1

    printf("a > b: %d\n", a > b);          // 1 (verdadero)
    printf("a == b: %d\n", a == b);         // 0 (falso)
    printf("a > 0 && b > 0: %d\n", a > 0 && b > 0);  // 1
    return 0;
}

Con dos enteros, a / b hace división entera y descarta los decimales: 10 / 3 da 3, no 3.33. Para obtener decimales, usa al menos un operando con punto: 10.0 / 3.

Un solo signo = asigna; dos signos == comparan. Confundirlos es uno de los errores más clásicos de C.

Entrada y salida: printf y scanf

Además de imprimir con printf, C lee datos del teclado con scanf. A diferencia de printf, scanf necesita la dirección de cada variable para poder modificarla, por eso se antepone el símbolo & en números y caracteres.

#include <stdio.h>

int main(void) {
    int edad;
    float altura;
    char nombre[50];

    printf("Ingresa tu nombre: ");
    scanf("%s", nombre);

    printf("Ingresa tu edad: ");
    scanf("%d", &edad);

    printf("Ingresa tu altura en metros: ");
    scanf("%f", &altura);

    printf("Hola %s, tienes %d años y mides %.2f m\n",
           nombre, edad, altura);
    return 0;
}
EspecificadorTipoUso típico
%dintprintf("%d", 25);
%ffloatprintf("%.1f", 3.4);
%lfdoublescanf("%lf", &peso);
%ccharprintf("%c", 'A');
%schar[] (cadena)printf("%s", "hola");

Al leer una cadena con %s no se usa &, porque el nombre del arreglo ya es su dirección. Además, %s se detiene en el primer espacio en blanco; más adelante usarás fgets para leer líneas completas.

Conversiones y casting de tipos

Cuando mezclas tipos en una operación, C aplica conversiones implícitas: el tipo más pequeño se promueve al más grande para no perder información. Cuando quieres forzar un tipo de forma explícita, usas el casting escribiendo el tipo destino entre paréntesis.

ConversiónEjemploResultado
Implícita int a float5 + 0.55.5
División entera7 / 23
Casting a double(double)7 / 23.5
Truncado float a int(int)3.993

En el código, el casting es muy útil para divisiones: printf("%.1f\n", (double)7 / 2); muestra 3.5, mientras que 7 / 2 sin casting mostraría 3.

El casting (int) trunca, no redondea: (int)3.99 da 3. Si necesitas redondear al entero más cercano, suma 0.5 antes de convertir: (int)(3.99 + 0.5).

En printf, un double se muestra con %f, pero en scanf un double requiere %lf. La diferencia entre imprimir y leer doubles es un clásico error de principiante.

Ejercicios prácticos

  1. Declara tres variables: un int, un float y un char. Asígnales valores y muéstralos con printf.
  2. Pide al usuario su edad con scanf e imprime cuántos años tendrá dentro de 10 años.
  3. Lee dos números enteros y muestra su suma, resta, multiplicación, división entera y resto.
  4. Calcula el promedio de tres notas usando un double y el casting en la división final para no perder decimales.
