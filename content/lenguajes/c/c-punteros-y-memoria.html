¿Qué es un puntero?

Un puntero es una variable que guarda una dirección de memoria, es decir, indica dónde vive otra variable en lugar de guardar el valor en sí. Se declara con un asterisco (int *p) y se usa con dos operadores: & obtiene la dirección de una variable, y * accede al valor de la dirección apuntada.

#include <stdio.h>

int main(void) {
    int edad = 25;
    int *p = &edad;      // p guarda la dirección de edad

    printf("Valor de edad: %d\n", edad);      // 25
    printf("Dirección: %p\n", (void *)p);     // 0x...
    printf("Valor apuntado: %d\n", *p);       // 25

    *p = 30;              // cambia edad usando el puntero
    printf("Nueva edad: %d\n", edad);         // 30
    return 0;
}
SímboloSignificado
int *pp es un puntero a entero
&edadDirección de la variable edad
*pValor guardado en la dirección apuntada
(void *)pEl formato %p espera un puntero void *

Un puntero que no apunta a algo válido se llama puntero colgante. Decláralo siempre inicializado: int *p = NULL; y compruébalo antes de usarlo.

Aritmética de punteros y arreglos

Los punteros admiten operaciones aritméticas: sumar 1 a un puntero avanza al siguiente elemento del mismo tipo, no al siguiente byte. Esto convierte al puntero en la mano derecha de los arreglos: el nombre de un arreglo es, en realidad, un puntero al primer elemento.

#include <stdio.h>

int main(void) {
    int numeros[4] = {10, 20, 30, 40};
    int *p = numeros;      // apunta a numeros[0]

    printf("Primero: %d\n", *p);         // 10
    printf("Segundo: %d\n", *(p + 1));   // 20
    printf("Tercero: %d\n", *(p + 2));   // 30

    int i;
    for (i = 0; i < 4; i++) {
        printf("%d ", numeros[i]);       // 10 20 30 40
    }
    printf("\n");

    for (p = numeros; p < numeros + 4; p++) {
        printf("%d ", *p);               // 10 20 30 40
    }
    printf("\n");
    return 0;
}
ExpresiónEquivale a
numeros&numeros[0] (dirección del primero)
numeros + 2&numeros[2]
*(numeros + 2)numeros[2]
p++Avanza al siguiente elemento

El compilador calcula el salto automáticamente según el tipo: en int (4 bytes), p + 1 suma 4 bytes a la dirección.

Memoria dinámica: malloc, calloc y free

Las variables y arreglos vistos hasta ahora viven en la pila y su tamaño se fija al compilar. La memoria dinámica se pide en tiempo de ejecución desde el heap, con funciones de stdlib.h: malloc reserva bytes, calloc reserva y pone a cero, y free libera lo reservado.

#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n = 5;
    int *arreglo = (int *)malloc(n * sizeof(int));

    if (arreglo == NULL) {           // malloc falla con NULL
        printf("Sin memoria disponible\n");
        return 1;
    }

    int i;
    for (i = 0; i < n; i++) {
        arreglo[i] = (i + 1) * 10;   // 10 20 30 40 50
    }

    for (i = 0; i < n; i++) {
        printf("%d ", arreglo[i]);
    }
    printf("\n");

    free(arreglo);                   // devolver la memoria al sistema
    return 0;
}
FunciónQué hace
malloc(tamano_bytes)Reserva bytes sin inicializar
calloc(cant, tamano)Reserva y pone todo en cero
realloc(p, nuevo_tamano)Cambia el tamaño de una reserva
free(p)Libera la memoria reservada

Siempre verifica que malloc no devuelva NULL antes de usar la memoria, y libera con free exactamente lo que reservaste. Liberar algo dos veces o liberar sin haber reservado produce errores graves.

Estructuras (struct) y punteros a struct

Una estructura agrupa variables de distintos tipos bajo un solo nombre. Es la antesala de las clases en la programación orientada a objetos. Se accede a sus campos con el punto (.) y, si tienes un puntero a struct, con la flecha (->).

#include <stdio.h>
#include <string.h>

struct Alumno {
    char nombre[30];
    int edad;
    float promedio;
};

int main(void) {
    struct Alumno ana;
    strcpy(ana.nombre, "Ana");
    ana.edad = 21;
    ana.promedio = 9.4;

    struct Alumno *p = &ana;      // puntero a struct

    printf("Nombre: %s\n", p->nombre);    // flecha (->) con puntero
    printf("Edad: %d\n", p->edad);
    printf("Promedio: %.2f\n", (*p).promedio);  // equivalente
    return 0;
}
AccesoCuándoEjemplo
Punto (.)Con la variable structana.edad
Flecha (->)Con un puntero a structp->edad

Definir el tipo con typedef struct permite escribir Alumno ana; en vez de struct Alumno ana;, lo que hace el código más limpio.

Fugas de memoria y buenas prácticas

Una fuga de memoria (memory leak) ocurre cuando reservas memoria con malloc y nunca la liberas con free. El programa crece en consumo y, en ejecuciones largas como un servidor, puede agotar la memoria del sistema.

PrácticaPor qué importa
Liberar con free tras usarDevuelve memoria al sistema operativo
Verificar NULL tras mallocEvita usar memoria inexistente
No liberar dos veces la misma zonaEl doble free provoca fallos graves
Asignar NULL a punteros liberadosEvita punteros colgantes reutilizados
Detectar fugas con valgrindvalgrind ./programa reporta fugas y errores

Hay una regla simple que resume todas las demás: a cada malloc le corresponde un free, en el mismo nivel de lógica (quien reserva, libera).

Herramientas como valgrind y los sanitizers de GCC (-fsanitize=address) detectan fugas, accesos fuera de límites y usos de memoria ya liberada. Ejecútalas en tus ejercicios a partir de esta lección.

Con la disciplina correcta, los punteros dejan de ser peligrosos y se convierten en la herramienta que hace de C un lenguaje tan poderoso.

Ejercicios prácticos

  1. Declara un entero y un puntero a ese entero; modifica su valor a través del puntero y muéstralo por pantalla.
  2. Recorre el arreglo int datos[6] = {2, 4, 6, 8, 10, 12} usando aritmética de punteros en lugar de índices.
  3. Reserva con malloc un arreglo de n enteros leídos por el usuario, rellénalo y libéralo con free.
  4. Define un struct Rectangulo con base y altura, y escribe una función que reciba un puntero a él y devuelva su área.
  5. Compila uno de tus programas con valgrind ./programa o con -fsanitize=address y comprueba que no reporte fugas.
