Declarar y definir funciones

Una función es un bloque de código con nombre que recibe parámetros opcionales, realiza una tarea y devuelve un resultado. Dividir el programa en funciones lo hace legible, reutilizable y fácil de probar. La sintaxis combina el tipo de retorno, el nombre y la lista de parámetros:

#include <stdio.h>

// Definición de la función sumar
int sumar(int a, int b) {
    return a + b;
}

double promedio(double a, double b, double c) {
    return (a + b + c) / 3.0;
}

int main(void) {
    int total = sumar(5, 7);
    printf("Suma: %d\n", total);              // 12

    double media = promedio(7.0, 8.5, 9.0);
    printf("Promedio: %.2f\n", media);        // 8.17
    return 0;
}
FunciónParámetrosRetorna
int sumar(int a, int b)2 enterosEntero con la suma
double promedio(double, double, double)3 decimalesDecimal con el promedio

El void indica ausencia de valor: una función void saludar(void) no recibe parámetros y no devuelve nada.

Prototipos, cabeceras y ámbito

En C, el compilador debe conocer una función antes de usarla. Una opción es definir la función antes de main; la otra es declarar un prototipo: una línea que anuncia la firma (tipo de retorno, nombre y parámetros) sin su cuerpo. Así puedes ubicar las definiciones después de main o repartirlas en otros archivos.

#include <stdio.h>

// Prototipo: le anuncia al compilador la firma de doble
double doble(double x);

int main(void) {
    printf("%.1f\n", doble(3.5));   // 7.0
    return 0;
}

// Definición de la función, después de main
double doble(double x) {
    return x * 2;
}

El ámbito (o scope) define dónde vive una variable: una variable declarada dentro de una función es local y solo existe ahí. Una variable declarada fuera de todo bloque es global y es visible en todo el archivo.

ÁmbitoDónde se declaraVisibilidad
GlobalFuera de cualquier funciónTodo el archivo
LocalDentro de una función o bloqueEse bloque y sus anidados

El #include <stdio.h> del inicio es un conjunto de prototipos listos para usar: la declaración de printf, scanf o fgets viene de ahí.

Las variables globales facilitan errores difíciles de rastrear porque cualquier función puede modificarlas. Prefiere pasar datos por parámetros.

Arreglos y su recorrido

Un arreglo (array) es una colección de elementos del mismo tipo, almacenados uno tras otro en memoria. Se declara indicando tipo, nombre y tamaño entre corchetes. El primer elemento siempre está en el índice 0.

#include <stdio.h>

int main(void) {
    int notas[5] = {15, 18, 12, 20, 17};
    int i;
    int suma = 0;

    printf("Elementos: ");
    for (i = 0; i < 5; i++) {
        printf("%d ", notas[i]);
    }

    for (i = 0; i < 5; i++) {
        suma += notas[i];
    }
    printf("\nPromedio: %.1f\n", suma / 5.0);   // 16.4
    return 0;
}
CaracterísticaDetalle
Índice inicial0 (siempre)
Índice finaltamaño - 1 (nunca el tamaño)
Accesonotas[2] accede al tercer elemento
Las llaves {}Inicializan el arreglo al declararlo

Acceder a notas[5] en un arreglo de tamaño 5 es fuera de límites: lee o escribe memoria que no te pertenece (comportamiento indefinido). La revisión de límites es responsabilidad tuya, no del compilador.

Cadenas: char[] y string.h

En C no existe un tipo string: una cadena es un arreglo de char que termina con el carácter nulo '\0'. La biblioteca string.h ofrece funciones para copiarlas, compararlas y medirlas.

#include <stdio.h>
#include <string.h>

int main(void) {
    char saludo[20] = "Hola";
    char nombre[20] = "Ana";

    strcat(saludo, ", ");            // saludo ahora es "Hola, "
    strcat(saludo, nombre);          // saludo ahora es "Hola, Ana"

    printf("%s\n", saludo);
    printf("Largo: %zu\n", strlen(saludo));       // 9
    printf("Iguales: %d\n", strcmp("ana", "ana"));  // 0

    // Recorrer carácter a carácter hasta el carácter nulo
    int i;
    for (i = 0; saludo[i] != '\0'; i++) {
        putchar(saludo[i]);
    }
    putchar('\n');
    return 0;
}
FunciónQué hace
strcpy(dest, src)Copia src en dest
strcat(dest, src)Agrega src al final de dest
strlen(s)Longitud sin contar el carácter nulo
strcmp(a, b)0 si son iguales; negativo o positivo según el orden

Guarda siempre un carácter extra en el arreglo: char ciudad[11] guarda cadenas de hasta 10 letras, porque el carácter '\0' ocupa el último espacio.

Paso por valor vs por referencia

En C, los argumentos se pasan por valor: la función recibe una copia y no puede modificar la variable original. Para modificar el original necesitas el paso por referencia, que se logra pasando la dirección de la variable con el operador & y recibiéndola con un puntero en la función.

FormaLlamadaFirma¿Modifica el original?
Por valorfuncion(a)void funcion(int x)No
Por referenciafuncion(&a)void funcion(int *x)Sí

Un ejemplo clásico es la función intercambiar: si recibes dos enteros por valor, el cambio se pierde al salir. Con punteros (int *a, int *b) y el operador *x para leer o escribir la dirección apuntada, el intercambio sí queda en el programa que llamó.

Los arreglos se comportan distinto: al pasarlos a una función se pasa su dirección (el nombre del arreglo es un puntero), así que las funciones sí pueden modificar sus elementos.

El paso por referencia con & es exactamente lo que ya usas con scanf("%d", &edad);: scanf necesita la dirección para escribir el valor leído en tu variable.

Ejercicios prácticos

  1. Crea una función int cuadrado(int n) y úsala para imprimir los cuadrados del 1 al 10.
  2. Escribe una función int es_par(int n) que devuelva 1 si el número es par y 0 si no.
  3. Declara un arreglo de 10 notas, pídelas con scanf y calcula el promedio con un bucle for.
  4. Copia la cadena "GuiaDev" a un arreglo char adecuado y muéstrala carácter por carácter.
  5. Implementa una función void incrementar(int *n) usando paso por referencia; llámala desde main y verifica el cambio.
