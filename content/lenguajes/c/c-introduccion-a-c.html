¿Qué es C y dónde se usa hoy?

C es un lenguaje de programación de propósito general con más de 50 años de historia. Es un lenguaje compilado: el código fuente se traduce a instrucciones ejecutables mediante un compilador como gcc antes de ejecutarse. A diferencia de los lenguajes interpretados como Python, un programa en C genera un ejecutable nativo, muy rápido y con control directo sobre la memoria.

C sigue siendo la base del software moderno. Sistemas operativos como Linux y Windows, bases de datos como MySQL, controladores de dispositivos, firmware de microcontroladores y hasta los intérpretes de Python y JavaScript están escritos en C.

Comprender C te enseña cómo funciona una computadora por dentro: la memoria, los punteros y el compilador dejan de ser conceptos abstractos.

Historia: de Bell Labs al kernel

C nació en los Laboratorios Bell de AT&T entre 1969 y 1973. Ken Thompson había creado el lenguaje B para reescribir el sistema operativo Unix, y Dennis Ritchie lo evolucionó hasta convertirlo en C: más potente, con tipos de datos definidos y capaz de generar código portable entre máquinas.

En 1978, Brian Kernighan y Dennis Ritchie publicaron "The C Programming Language", el famoso "libro K&R" que durante años fue la referencia no oficial del lenguaje. En 1989 la ANSI publicó el estándar formal ANSI C (C89), seguido después por las revisiones C99, C11 y C17.

El mejor ejemplo de su alcance es el kernel de Linux: más del 95% de su código está escrito en C. Ese kernel impulsa servidores, supercomputadoras, Android y gran parte de la nube.

Instalación de un compilador (GCC/Clang)

Para compilar C necesitas un compilador. Los dos más usados son GCC (GNU Compiler Collection) y Clang (del proyecto LLVM). Ambos son gratuitos, multiplataforma e incluyen herramientas de depuración.

# Debian / Ubuntu / WSL
sudo apt update
sudo apt install gcc -y

# macOS con Homebrew
brew install gcc

# Windows con MSYS2 (terminal UCRT64)
pacman -S mingw-w64-ucrt-x86_64-gcc

# Verificar la instalación
gcc --version

En Windows también puedes instalar WSL (Windows Subsystem for Linux) para compilar con GCC dentro de una terminal Linux nativa, sin salir de Windows.

No necesitas un IDE pesado: cualquier editor de texto sirve. VS Code con la extensión C/C++ de Microsoft ofrece resaltado de sintaxis, autocompletado y depuración integrada.

Tu primer programa: hola.c

Crea un archivo llamado hola.c con el siguiente contenido. Todo programa en C debe tener una función main: es el punto de entrada que el sistema operativo ejecuta al iniciar el programa.

#include <stdio.h>

int main(void) {
    printf("¡Hola, mundo!\n");
    return 0;
}

Desde la terminal, entra a la carpeta del archivo y compílalo con gcc:

gcc hola.c -o hola
./hola

# Salida esperada:
# ¡Hola, mundo!

La opción -o hola define el nombre del ejecutable. Sin ella, GCC genera un archivo llamado a.out por defecto.

Anatomía del programa y printf

El programa hola.c se compone de partes bien identificables:

Parte del códigoQué hace
#include <stdio.h>Trae la biblioteca estándar de entrada y salida
int main(void)Función principal; devuelve un entero al sistema
{ y }Delimitan el bloque de instrucciones de main
printf("...")Imprime texto en la pantalla
return 0;Finaliza el programa con código de éxito 0

printf admite especificadores de formato que se sustituyen por los valores que pasas después de la coma:

printf("Edad: %d años\n", 25);
printf("Altura: %.2f metros\n", 1.75);
printf("Inicial: %c\n", 'A');
printf("Lenguaje: %s\n", "C");

El \n no es la letra n: es la secuencia de escape que produce un salto de línea. Sin él, todas las salidas quedarían pegadas en una sola línea.

Errores comunes del principiante

Los primeros errores de C suelen venir de su sintaxis rígida. El compilador los detecta y los reporta con número de línea, así que el mensaje es tu mejor pista para corregirlos.

Error típicoConsecuencia
Olvidar el punto y coma ( ; )Error de sintaxis del compilador
Olvidar #include <stdio.h>Warning o error: printf no está declarada
Comillas mal balanceadasError de sintaxis en cadenas
Llaves de más o de menosBloques mal cerrados al compilar
Confundir mayúsculas y minúsculasprintf no es lo mismo que Printf

C distingue entre mayúsculas y minúsculas, y reserva palabras clave como int y return: no las uses como nombres de variables.

Un excelente hábito desde el primer día es compilar con advertencias activadas: gcc -Wall -Wextra programa.c detecta problemas que no frenan la compilación pero que sí producen errores en tiempo de ejecución.

Ejercicios prácticos

  1. Escribe, compila y ejecuta tu propio hola.c que imprima tu nombre en la primera línea y tu edad en la segunda.
  2. Usa printf con %d, %.2f y %s para mostrar tu edad, tu estatura y el nombre de tu ciudad.
  3. Modifica el programa para que imprima "¡Hola, mundo!" tres veces usando un único printf y los saltos de línea adecuados.
  4. Compila con gcc -Wall un programa que declare una variable sin usarla y copia la advertencia que emite el compilador.
  5. Quita el return 0; y vuelve a compilar: observa que el programa funciona, pero recuerda que un programa bien formado siempre retorna su código de salida.

En la próxima lección aprenderás las variables, los tipos de datos y los operadores para darle datos reales a tus programas.
