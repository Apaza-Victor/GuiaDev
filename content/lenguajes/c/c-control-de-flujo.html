Condicionales: if, else if, switch

Un condicional ejecuta un bloque de código solo si se cumple una condición. El if evalúa una expresión; si es verdadera (distinta de cero), ejecuta su bloque; si no, prueba los else if siguientes y, en último caso, el else. Cuando comparas un valor contra muchas constantes, switch suele ser más legible.

#include <stdio.h>

int main(void) {
    int nota = 85;

    if (nota >= 90) {
        printf("Excelente\n");
    } else if (nota >= 60) {
        printf("Aprobado\n");
    } else {
        printf("Reprobado\n");
    }

    int dia = 3;
    switch (dia) {
        case 1:
            printf("Lunes\n");
            break;
        case 2:
            printf("Martes\n");
            break;
        default:
            printf("Otro día\n");
    }
    return 0;
}

En C, cualquier valor distinto de cero es verdadero y el cero es falso. Por eso if (1) siempre ejecuta su bloque.

Cada case termina con break; si lo olvidas, la ejecución continúa al siguiente case (esto se llama fall-through). Si lo quieres a propósito, escribe un comentario /* fall-through */ para avisar.

Bucles: for, while, do-while

Los bucles repiten un bloque de código mientras se cumpla una condición. for es ideal cuando conoces el número de iteraciones; while cuando depende de una condición que puede cambiar dentro; y do-while garantiza al menos una ejecución.

#include <stdio.h>

int main(void) {
    int i;

    printf("Con for: ");
    for (i = 1; i <= 5; i++) {
        printf("%d ", i);
    }

    printf("\nCon while: ");
    i = 1;                          // inicializar antes
    while (i <= 5) {
        printf("%d ", i);
        i++;                        // avanzar dentro del cuerpo
    }

    printf("\nCon do-while: ");
    i = 1;
    do {
        printf("%d ", i);
        i++;
    } while (i <= 5);

    printf("\n");
    return 0;
}
// Salida: los tres bucles imprimen 1 2 3 4 5
BucleCuándo usarloSe ejecuta al menos...
forNúmero conocido de vueltas0 veces
whileDepende de una condición0 veces
do-whileDebe ejecutarse sí o sí una vez1 vez

Un bucle while sin instrucción que modifique la condición es un bucle infinito. Si ejecutas while (1) a propósito, asegúrate de tener una salida con break.

Los tres bucles son intercambiables: casi todo for puede escribirse como while y viceversa. La elección es de estilo y claridad.

break, continue y goto

C ofrece sentencias para alterar el flujo dentro de bucles. break sale del bucle por completo; continue salta a la siguiente iteración; y goto brinca a una etiqueta (su uso es muy discutido y hoy casi no se recomienda).

#include <stdio.h>

int main(void) {
    int i;

    for (i = 1; i <= 10; i++) {
        if (i == 3) {
            continue;      // salta el 3
        }
        if (i == 8) {
            break;         // termina el bucle en el 8
        }
        printf("%d ", i);
    }
    printf("\n");
    return 0;
}
// Salida: 1 2 4 5 6 7
SentenciaQué haceEjemplo típico
breakSale del bucle o del switchSalir al encontrar el elemento buscado
continuePasa a la siguiente iteraciónIgnorar valores no válidos
gotoSalta a una etiquetaSalir de bucles anidados (raro)

Usa break también dentro de switch para cortar cada caso, y dentro de while (1) para crear bucles que salen en el medio de la iteración.

goto debe limitarse a situaciones extremas, como salir de varios bucles anidados a la vez. El abuso de goto convierte el programa en "código espagueti", difícil de leer y mantener.

Bucles y condiciones anidadas

Puedes colocar un bucle dentro de otro. Cada iteración del bucle externo ejecuta completo el bucle interno. Es el mecanismo perfecto para tablas, matrices y patrones. Aquí generamos la tabla de multiplicar del 1 al 3:

#include <stdio.h>

int main(void) {
    int i, j;

    for (i = 1; i <= 3; i++) {         // bucle externo
        for (j = 1; j <= 5; j++) {     // bucle interno
            printf("%2d ", i * j);
        }
        printf("\n");                 // nueva fila
    }
    return 0;
}
// Salida:
//  1  2  3  4  5
//  2  4  6  8 10
//  3  6  9 12 15

Las condiciones también pueden combinarse dentro de bucles para filtrar iteraciones, por ejemplo imprimir solo los pares con if (i % 2 == 0).

El operador % (módulo) te da el resto de una división: i % 2 == 0 es verdadero cuando i es par. Es una de las condiciones más usadas junto a los bucles.

Ejercicios prácticos

  1. Pide al usuario un número y clasifícalo en positivo, negativo o cero usando if / else if.
  2. Usa switch para imprimir el día de la semana a partir de un número del 1 al 7, con un caso default.
  3. Suma los números del 1 al 100 con un bucle for e imprime el resultado (debe ser 5050).
  4. Reescribe el ejercicio anterior con while y luego con do-while para comparar las tres versiones.
  5. Imprime las primeras 10 potencias de 2, salta la iteración cuando el exponente sea par usando continue.
