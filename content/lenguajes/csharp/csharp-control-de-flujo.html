Condicionales: if/else y operadores modernos

La estructura condicional básica funciona como en C/Java, pero C# moderno añade azúcares potentes: patrones relacionales, combinadores lógicos y expresiones condicionales compactas.

if clásico con mejoras de patrón (C# 9)

int temperatura = 35;

// Patrones RELACIONALES: comparación declarativa
if (temperatura is >= 30) {
    Console.WriteLine("Calor extremo");
} else if (temperatura is > 15 and < 30) {   // combinador 'and' sin &&&
    Console.WriteLine("Agradable");
} else {
    Console.WriteLine("Frío");
}

// Verificar rango con patrones:
bool enHorario = horaActual is >= 8 and < 18;

// Null-check idiomático:
string? nombre = null;
if (nombre is not null) {           // preferible a != null
    Console.WriteLine(nombre.Length);
}

Los operadores cortocircuito && y || no evalúan el segundo término si el primero decide — protege accesos: if (lista != null && lista.Count > 0) nunca lanza NRE porque la segunda parte solo se evalúa si la primera fue true. En C# moderno: lista?.Count > 0.

Switch expressions: el switch renacido

C# 8 transformó el switch: ahora es una expresión que devuelve un valor, con sintaxis flecha y pattern matching exhaustivo comprobable por el compilador:

Switch expression básico

// El clásico switch-statement (aún válido):
switch (codigo) {
    case 200: Console.WriteLine("OK"); break;
    case 404: Console.WriteLine("No encontrado"); break;
    default: Console.WriteLine("Otro"); break;
}

// Switch EXPRESSION moderno: compacto, valor-retornante
string descripcion = codigo switch {
    200 => "OK",
    301 or 302 => "Redirección",           // múltiples valores con 'or'
    >= 400 and < 500 => "Error del cliente", // patrones relacionales
    _ => "Desconocido"                      // discard _: el default
};
Console.WriteLine(descripcion);

Pattern matching sobre objetos y propiedades

Aquí el switch expression brilla: desestructura objetos y decide por SU CONTENIDO:

public record Pedido(decimal Total, bool EsVip, int AniosFidelidad);

decimal calcularDescuento(Pedido p) => p switch {
    { Total: > 1000 }                     => 0.15m,   // property pattern
    { EsVip: true, AniosFidelidad: >= 5 } => 0.10m,
    { EsVip: true }                       => 0.05m,
    _                                     => 0m
};

// Posicional + when: condiciones adicionales
static string clasificar(int edad, bool licencia) =>
    (edad, licencia) switch {                    // tuple pattern
        (< 16, _)             => "Menor: sin conducir",
        (< 18, false)         => "Sin licencia aún",
        (< 18, true)          => "Con permiso especial",
        (_, true) when edad > 80 => "Renovación médica requerida",
        (_, true)             => "Conductor pleno",
        _                     => "Sin licencia"
    };

Si todas las ramas cubren todos los casos posibles de una enum o de los patrones definidos, el compilador AVISA si falta alguno al añadir nuevos valores — bugs de exhaustividad atrapados antes de ejecutar. Esto era imposible con el switch statement clásico.

Bucles: for, foreach, while

BucleCuándo usarloEjemplo canónico
foreachRecorrer colecciones (95% de casos)foreach (var x in lista)
forNecesitas índice o pasos controladosTablas, matrices, saltos
whileCondición dinámica pre-evaluadaLeer hasta EOF/sentinelas
do-whileEjecutar AL MENOS una vezMenús, validación de input
 
var frutas = new List<string> {"manzana", "pera", "uva"};

// foreach: simple, seguro, imposible off-by-one
foreach (var fruta in frutas) {
    Console.WriteLine(fruta);
}

// Con índice cuando lo necesitas:
for (int i = 0; i < frutas.Count; i++) {
    Console.WriteLine($"{i}: {frutas[i]}");
}

// do-while: menú que se muestra mínimo una vez
string opcion;
do {
    Console.WriteLine("[1] Sumar [2] Restar [0] Salir");
    opcion = Console.ReadLine();
} while (opcion != "0");

// break / continue / goto-less control:
foreach (var n in new[] {1, 7, -3, 9}) {
    if (n < 0) continue;              // saltar este elemento
    if (n == 9) break;                // terminar todo el bucle
    Console.WriteLine(n);             // 1, 7
}

// Rango infinito con for vacío + condición central:
for (;;) {
    var linea = Console.ReadLine();
    if (linea == "salir") break;
    Console.WriteLine($"Eco: {linea}");
}

NUNCA modifiques (Add/Remove) la colección DENTRO de su propio foreach: InvalidOperationException garantizada ("Collection was modified"). Si necesitas filtrar mientras recorres: itera sobre ToList() (copia) o usa RemoveAll() fuera del bucle.

Ejercicios prácticos

  1. Calculadora de tarifas: switch expression que clasifique edad (niño/joven/adulto/senior) y aplique descuentos combinando tuple patterns con when.
  2. Menú robusto: do-while con menú de 4 opciones usando switch expression; valida entrada inválida sin romper el ciclo.
  3. Clasificador HTTP: recibe códigos int y devuelve categoría con patrones relacionales (1xx info, 2xx ok, 3xx redirect, 4xx cliente, 5xx servidor).
  4. FizzBuzz patterns: resuelve con switch expression usando tupla de booleanos ((n%3==0, n%5==0)) y compara con versión if tradicional en comentario.
  5. Guard-clause refactor: toma una función con 4 niveles de anidamiento (escríbela primero así) y reescríbela con guard clauses; compara líneas e indentación.
