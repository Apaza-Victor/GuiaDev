Records (inmutables)

public record Punto(int X, int Y);

var a = new Punto(1, 2);
var b = a with { X = 10 };   // copia cambiando X
Console.WriteLine(a == b);   // false: compara valores

async / await

static async Task<string> DescargarAsync(string url)
{
    using var http = new HttpClient();
    return await http.GetStringAsync(url);
}

string html = await DescargarAsync("https://example.com");
Consejo: Los métodos async devuelven Task o Task<T>. El compilador transforma await en una máquina de estados sin bloquear el hilo.
