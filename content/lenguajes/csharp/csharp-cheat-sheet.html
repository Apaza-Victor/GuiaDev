La palabra null también es reservada: representa la ausencia de valor de una variable de referencia o nullable.

Sintaxis básica

Un programa de consola en C# necesita un namespace, una clase y, para ser ejecutable, un método Main. Cada instrucción termina con punto y coma ; y los bloques se delimitan con llaves {}.

using System;                        // trae la librería base

namespace HolaMundo
{
    class Program
    {
        static void Main(string[] args)   // punto de entrada
        {
            // Comentario de una línea
            int edad = 25;                    // variable tipada
            var nombre = "Ana";               // var deduce el tipo: string
            Console.WriteLine("Hola, mundo"); // imprime en consola
            Console.Write("Escribe tu nombre: ");
            string entrada = Console.ReadLine(); // lee lo que escribe el usuario
        }
    }
}

El punto y coma ; al final de cada sentencia es obligatorio. Las llaves {} agrupan bloques de código: clases, métodos y condiciones. El método Main es el punto de entrada: por ahí arranca el programa; sin él, no hay nada que ejecutar.

var NO es un tipo dinámico: el compilador deduce el tipo en tiempo de compilación. var edad = 25; es exactamente igual a int edad = 25;.

La interpolación $"..." es la forma moderna de construir texto con variables:

string nombre = "Ana";
int edad = 25;
Console.WriteLine($"Hola, {nombre}, tienes {edad} años");
Console.WriteLine($"El año: {2026 + 1}");   // se evalúa cualquier expresión

Valor vs referencia: asignar int b = a; copia el número; asignar una List u objeto copia la referencia: ambas variables apuntan al mismo objeto. Los tipos de valor no pueden ser null por defecto; los de referencia sí.

Estructuras de control

Condicional: if / else

int edad = 18;
if (edad >= 18)
{
    Console.WriteLine("Eres mayor de edad");
}
else if (edad > 12)
{
    Console.WriteLine("Eres adolescente");
}
else
{
    Console.WriteLine("Eres menor de edad");
}

Selección múltiple: switch / case

int dia = 2;
switch (dia)
{
    case 1:
        Console.WriteLine("Lunes");
        break;
    case 2:
        Console.WriteLine("Martes");
        break;
    default:
        Console.WriteLine("Otro día");
        break;
}

// switch moderno (C# 8+) sin break obligatorio
string categoria = dia switch
{
    >= 1 and <= 5 => "Laborable",
    >= 6 and <= 7 => "Fin de semana",
    _ => "Inválido"
};

Bucle: for (ideal para recorrer por índice)

for (int i = 0; i < 5; i++)
{
    Console.WriteLine("Vuelta " + i);
}

Bucle: foreach (ideal para colecciones, evita índices)

int[] numeros = { 1, 2, 3, 4, 5 };
foreach (int n in numeros)
{
    Console.WriteLine(n);
}

Bucle: while (condición al inicio)

int i = 0;
while (i < 5)
{
    Console.WriteLine(i);
    i++;
}

Bucle: do-while (se ejecuta al menos una vez)

int j = 0;
do
{
    Console.WriteLine(j);
    j++;
} while (j < 5);

break y continue

for (int i = 0; i < 10; i++)
{
    if (i == 3) continue;        // salta el 3, sigue con la siguiente vuelta
    if (i == 7) break;           // termina el bucle en el 7
    Console.WriteLine(i);
}

Para colecciones prefiere foreach sobre for: es más legible, evita errores de índice y funciona con cualquier colección (List, Dictionary, arrays...). Usa for solo cuando necesites modificar la colección o trabajar con índices concretos.

En C# moderno cada case ya no exige break explícito si el bloque termina claramente; el switch que devuelve un valor (switch expression) ni siquiera lo usa.

Clases, POO y colecciones

Una clase es la plantilla que define atributos (propiedades con datos) y métodos (comportamiento). Con new creamos un objeto (instancia) de esa clase.

Definir una clase con propiedades, constructor y método

public class Persona
{
    // Propiedades con get/set (encapsulan el atributo)
    public string Nombre { get; set; }
    public int Edad { get; set; }

    // Constructor: inicializa el objeto
    public Persona(string nombre, int edad)
    {
        Nombre = nombre;
        Edad = edad;
    }

    // Método
    public void Saludar()
    {
        Console.WriteLine($"Hola, soy {Nombre}");
    }
}

Instanciar con new y usar el objeto

var ana = new Persona("Ana", 25);   // llama al constructor
ana.Saludar();
ana.Edad = 26;                       // set
int anios = ana.Edad;                // get
Console.WriteLine($"{ana.Nombre} tiene {ana.Edad} años");

Herencia con ": Base" y polimorfismo con virtual/override

public class Estudiante : Persona          // ":" indica herencia
{
    public string Carrera { get; set; }

    public Estudiante(string nombre, int edad, string carrera)
        : base(nombre, edad)               // llama al constructor de Persona
    {
        Carrera = carrera;
    }

    public override void Saludar()         // override completa al método virtual
    {
        Console.WriteLine($"Hola, soy {Nombre}, estudio {Carrera}");
    }

    public void Estudiar()
    {
        Console.WriteLine("Estudiando " + Carrera);
    }
}

Colecciones: Array, List<T> y Dictionary<TKey,TValue>

using System.Collections.Generic;

int[] numeros = { 1, 2, 3 };               // Array: tamaño fijo

var nombres = new List<string>();          // List: dinámica
nombres.Add("Ana");                        // método Add
nombres.Add("Luis");
Console.WriteLine(nombres.Count);          // 2: cantidad de elementos
Console.WriteLine(nombres.Contains("Ana")); // True

var edades = new Dictionary<string, int>(); // pares clave-valor
edades["Ana"] = 25;                        // agregar o actualizar con [clave]
edades["Luis"] = 30;
Console.WriteLine(edades["Ana"]);          // 25
Console.WriteLine(edades.ContainsKey("Luis")); // True

foreach (var persona in edades)
{
    Console.WriteLine($"{persona.Key} → {persona.Value}");
}

List<T> y Dictionary<TKey,TValue> son colecciones genéricas: el tipo va entre <> y el compilador lo verifica. Métodos útiles de List: Add, Remove, Contains, Count, IndexOf.

LINQ: consultas estilo SQL sobre colecciones

LINQ (Language Integrated Query) trae consultas tipo SQL directamente al lenguaje para trabajar con colecciones de forma declarativa. Vive en using System.Linq.

using System.Linq;

var estudiantes = new List<Estudiante>
{
    new Estudiante("Ana", 25, "Informática"),
    new Estudiante("Luis", 22, "Ciencias"),
    new Estudiante("Sara", 27, "Informática"),
    new Estudiante("Pepe", 19, "Arte")
};

// Sintaxis de métodos: Where (filtro), Select (proyección), OrderBy (orden)
var mayores = estudiantes
    .Where(e => e.Edad > 21)
    .OrderBy(e => e.Nombre)
    .Select(e => $"{e.Nombre}, {e.Edad} años");

foreach (var dato in mayores)
{
    Console.WriteLine(dato);
}

// Sintaxis de consulta (query syntax): muy parecida a SQL
var informaticos =
    from e in estudiantes
    where e.Carrera == "Informática" && e.Edad > 24
    select e;

foreach (var e in informaticos)
{
    e.Saludar();
}

Los métodos LINQ no modifican la colección original: devuelven una consulta diferida (lazy) que se evalúa al recorrerla. Úsalos junto con foreach, Count(), Any(), FirstOrDefault(), ToArray() o ToList().
