¿Qué es C#?

C# (pronunciado "C sharp") es el lenguaje principal de la plataforma .NET: moderno, tipado y orientado a objetos. Se usa en web (ASP.NET), escritorio, juegos (Unity) y nube.

  • Tipado fuerte con inferencia (var)
  • Multiplataforma: Windows, Linux y macOS
  • Gran ecosistema: NuGet, ASP.NET Core, Entity Framework

cd HolaApp
dotnet run

La CLI de dotnet

  • dotnet new crea proyectos
  • dotnet build compila
  • dotnet run ejecuta
  • dotnet add package instala librerías NuGet
