IDEs recomendados

IntelliJ IDEA: El IDE más popular para Java. La versión Community es gratuita.

Visual Studio Code: Ligero, con la extensión *Extension Pack for Java*.

Eclipse: Clásico, abierto y con muchos plugins.

Organización del código

  • Una clase pública por archivo, con el mismo nombre del archivo.
  • Paquetes en minúscula: com.miapp.servicios.
  • Indentación de 4 espacios y llaves en la misma línea (estilo estándar).
  • Nombres de clases en PascalCase, métodos y variables en camelCase, constantes en MAYUSCULAS.

Documentación con JavaDoc

JavaDoc genera documentación HTML desde comentarios especiales:

/**
 * Calcula el área de un círculo.
 * @param radio El radio del círculo
 * @return El área calculada
 */
public static double area(double radio) {
    return Math.PI * radio * radio;
}

Genera la documentación con javadoc -d doc MiClase.java.

Pruebas unitarias con JUnit

JUnit es el framework estándar para pruebas en Java:

import org.junit.jupiter.api.Test;
import static org.junit.jupiter.api.Assertions.*;

class CalculadoraTest {

    @Test
    void sumaDosNumeros() {
        assertEquals(5, Calculadora.sumar(2, 3));
    }

    @Test
    void divisionPorCeroLanzaExcepcion() {
        assertThrows(ArithmeticException.class, () -> Calculadora.dividir(1, 0));
    }
}

Gestión de dependencias

Maven (pom.xml) y Gradle (build.gradle) gestionan dependencias, compilación y empaquetado.

Ejemplo de dependencia en Maven:

<dependency>
    <groupId>com.google.code.gson</groupId>
    <artifactId>gson</artifactId>
    <version>2.10.1</version>
</dependency>

Comandos útiles: mvn clean install, mvn test, gradle build.
