La palabra null también es reservada: representa la ausencia de valor de una variable de referencia.

Sintaxis básica

Un programa Java necesita una clase y, para que sea ejecutable, un método main. Cada instrucción termina con punto y coma ; y los bloques se delimitan con llaves {}.

public class HolaMundo {
    public static void main(String[] args) {
        // Comentario de una línea
        int edad = 25;                    // variable tipada
        System.out.println("Hola, mundo"); // imprime en consola
    }
}
AcciónSintaxisEjemplo
Declarar variabletipo nombre = valor;int edad = 25;
Imprimir en consolaSystem.out.println(texto);System.out.println("Hola");
Definir clasepublic class Nombre { ... }public class Persona { ... }

Los comentarios no se ejecutan:

TipoSintaxisUso
De línea// textoUna sola línea.
De bloque/* texto */Varias líneas.
Documentación/** texto */Genera documentación con Javadoc.

El punto y coma ; al final de cada sentencia es obligatorio. Sin él, el programa no compila. Las llaves {} agrupan bloques de código: todo lo que está dentro de una clase, un método o una condición.

Los String se comparan con .equals(), nunca con ==. El operador == compara referencias (direcciones de memoria), no el contenido, por lo que puede dar resultados inesperados: nombre.equals("Ana").

Estructuras de control

Condicional: if / else

int edad = 18;
if (edad >= 18) {
    System.out.println("Eres mayor de edad");
} else {
    System.out.println("Eres menor de edad");
}

Selección múltiple: switch / case

int dia = 2;
switch (dia) {
    case 1:
        System.out.println("Lunes");
        break;
    case 2:
        System.out.println("Martes");
        break;
    default:
        System.out.println("Otro día");
}

Bucle: for

for (int i = 0; i < 5; i++) {
    System.out.println("Vuelta " + i);
}

Bucle: while (condición al inicio)

int i = 0;
while (i < 5) {
    System.out.println(i);
    i++;
}

Bucle: do-while (condición al final, se ejecuta al menos una vez)

int j = 0;
do {
    System.out.println(j);
    j++;
} while (j < 5);

break y continue

for (int i = 0; i < 10; i++) {
    if (i == 3) continue;        // salta el 3, sigue la vuelta siguiente
    if (i == 7) break;           // termina el bucle en el 7
    System.out.println(i);
}

Bucle for-each (recorrer colecciones)

int[] numeros = {1, 2, 3, 4, 5};
for (int n : numeros) {
    System.out.println(n);
}

El break en un switch evita que se ejecuten los casos siguientes (fall-through). Olvidarlo es un error muy común.

Clases, objetos y herencia

Una clase es la plantilla que define atributos (datos) y métodos (comportamiento). Con new creamos un objeto (instancia) de esa clase.

Definir una clase

public class Persona {
    private String nombre;
    private int edad;

    public Persona(String nombre, int edad) {
        this.nombre = nombre;
        this.edad = edad;
    }

    public void saludar() {
        System.out.println("Hola, soy " + nombre);
    }

    public String getNombre() {
        return nombre;
    }

    public void setNombre(String nombre) {
        this.nombre = nombre;
    }
}

Crear y usar un objeto

Persona p = new Persona("Ana", 25);
p.saludar();
String n = p.getNombre();
p.setNombre("Ana María");

Herencia: extends y super

public class Estudiante extends Persona {
    private String carrera;

    public Estudiante(String nombre, int edad, String carrera) {
        super(nombre, edad);   // llama al constructor de la clase padre
        this.carrera = carrera;
    }

    public void estudiar() {
        System.out.println("Estudia " + carrera);
    }
}

La sobrecarga de métodos (overloading) permite tener varios métodos con el mismo nombre pero distintos parámetros. Los getters y setters son métodos que leen y modifican atributos privados, respetando el encapsulamiento.

Excepciones: try / catch / finally

try {
    int resultado = 10 / 0;
    System.out.println(resultado);
} catch (ArithmeticException e) {
    System.out.println("Error matemático: " + e.getMessage());
} finally {
    System.out.println("Este bloque se ejecuta siempre");
}

Lanzar excepciones: throw

public void setEdad(int edad) {
    if (edad < 0) {
        throw new IllegalArgumentException("La edad no puede ser negativa");
    }
    this.edad = edad;
}

Un método que puede lanzar una excepción comprobada debe declararla con throws en su firma para que quien lo llame la maneje: public void leerArchivo() throws IOException.
