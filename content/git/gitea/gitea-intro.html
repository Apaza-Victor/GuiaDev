¿Qué es Gitea y cuándo usarlo?

Gitea es un servicio de hospedaje Git autoalojado (self-hosted), ligero y open source (licencia MIT). Es un fork comunitario de Gogs. Ofrece repositorios ilimitados, issues, pull requests, wiki, usuarios y organizaciones con una interfaz muy similar a GitHub.

Úsalo cuando:

  • Necesitas control total del código: servidores propios, sin terceros.
  • Tienes restricciones legales (datos que no pueden salir de tu país/red).
  • Quieres hospedar Git en una máquina modesta: corre bien con 512 MB de RAM.
  • Enseñas o aprendes cómo funciona un servidor Git por dentro.
GitHub/GitLab → alguien más administra tu código
Gitea         → tú administras todo: repos, usuarios, backups

Forgejo es un fork de Gitea mantenido por la comunidad (impulsado por Codeberg), con gobernanza más abierta. Funcionalmente casi idéntico; ambas opciones son válidas.

Requisitos del servidor

Una de sus grandes virtudes es lo poco que exige:

  • CPU: 2 núcleos es suficiente para equipos pequeños.
  • RAM: 512 MB mínimo; 1-2 GB cómodo con base de datos externa.
  • Disco: el tamaño de tus repos + logs (planifica crecimiento).
  • Base de datos: SQLite (cero mantenimiento), PostgreSQL o MySQL/MariaDB.
  • Sistema: Linux recomendado; también corre en Windows y macOS.
  • Opcional: Git 2.x instalado en el host, dominio y proxy inverso para HTTPS.

Características principales

  • Repositorios privados y públicos ilimitados, con issues, PRs, labels, milestones y wiki por repo.
  • Organizaciones y equipos con permisos granulares.
  • Gitea Actions: CI/CD compatible con workflows de GitHub Actions.
  • Container Registry integrado y paquetes (npm, PyPI, Maven...).
  • Webhooks y API REST completa para automatización.
  • Autenticación empresarial: LDAP, OAuth2, 2FA (TOTP/WebAuthn).
  • Bajo consumo: ideal hasta decenas de miles de repos en hardware humilde.

Si algún día creces hacia necesidades DevOps complejas (grupos CI avanzados, seguridad integrada), la migración típica es hacia GitLab self-hosted exportando repos.
