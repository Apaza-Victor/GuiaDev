Instalación y primeras impresiones

Fork es un cliente Git para Windows y macOS destacado por su velocidad y fluidez: arranca casi instantáneo incluso con repositorios enormes. Disponible en git-fork.com.

El modelo de licencia es honesto: prueba gratuita completa e ilimitada en tiempo; si te resulta útil, pagas una licencia única (gratis para uso no comercial tras evaluación según versión).

Lo primero que notarás: todo está a un doble clic o atajo de teclado. La curva de aprendizaje es mínima si ya conoces los conceptos de Git.

Interactive rebase visual

La función insignia de Fork: selecciona un rango de commits y ábrelos en una tabla editable donde cada fila se puede reordenar (arrastrar), squashear, editar mensaje o eliminar.

Antes:                        Después (squash + reorder):
● wip ajustes                 ● feat: formulario completo (S)
● fix typo                    ● docs: comentarios
● feat base formulario
                              [Apply Rebase]
  • Clic derecho sobre un commit → Start Interactive Rebase from Here.
  • Modo por defecto: squash automático de commits marcados.
  • Vista previa del resultado antes de aplicar; abort seguro si algo falla.
# Equivale a esto, pero sin tocar el editor:
git rebase -i HEAD~3
# pick/squash/drop editados manualmente en vim...

Gestión de stashes

Fork trata los stashes como ciudadanos de primera clase en el panel lateral:

  • Stash: arrastra tus cambios al área de stashes o usa el botón dedicado.
  • Aplica un stash con doble clic; pop (aplicar + borrar) con clic derecho.
  • Cada stash muestra su diff completo al seleccionarlo.
  • Aplica un stash directamente sobre otra rama sin cambiarte.
Panel Stashes:
├── WIP on feat/login     ← doble clic = aplicar
├── Ajustes CSS pendientes ← clic derecho = pop/eliminar
└── Config temporal

Con estos cinco atajos cubres el 80% del trabajo diario sin soltar el teclado. Fork también soporta integración con GitHub/GitLab/Bitbucket para clonar y crear PRs.
