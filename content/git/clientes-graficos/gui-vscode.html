Source Control integrado

VS Code trae Git integrado sin instalar nada. Abre cualquier carpeta con repositorio y verás el número de cambios pendientes en el icono de Source Control (barra lateral, Ctrl+Shift+G).

El panel muestra:

  • Cambios: archivos modificados no staged (U = untracked, M = modified, D = deleted).
  • Staged Changes: los preparados para commit.
  • Merge Changes: conflictos activos durante una fusión.
Iconos de estado en el explorador:
M naranja → modificado
U verde   → nuevo (untracked)
D gris    → eliminado

Pasa el mouse sobre un archivo y usa los botones: + (stage), ↩ (discard cambios), clic para abrir el diff lado a lado.

Commits, ramas y sync desde el editor

Flujo completo sin tocar la terminal:

  1. Escribe el mensaje en el campo superior del panel Source Control.
  2. Botón Commit — con "Auto Stage All" si quieres incluir todo directo.
  3. Botón Sync Changes hace pull + push en un paso; muestra ↑n ↓n pendientes.
  4. Rama actual en la esquina inferior izquierda: clic → crear, cambiar o comparar ramas.
Barra inferior de VS Code:
⑂ main*   ↕3↑1↓2   ⚠0 ✗0
 │        │
 rama     sync (pull+push)

Habilita en settings git.enableSmartCommit y git.autofetch para agilizar aún más el ciclo.

GitLens: blame e historial

La extensión GitLens (gratuita, de GitKraken) es casi obligatoria:

  • Git Blame inline: al final de cada línea muestra autor, fecha y mensaje del último commit que la tocó.
  • Current Line Holograph: hover sobre la anotación abre el commit completo con diff.
  • File History / Line History: navegación temporal de un archivo o línea concreta.
  • Commit Graph: grafo visual completo dentro de VS Code (la vista interactiva es parte de pago).
# Instalar desde terminal:
code --install-extension eamodio.gitlens

Resolución de conflictos en el editor

VS Code detecta marcadores de conflicto y ofrece botones directamente sobre cada bloque:

<<<<<<< HEAD          [Accept Current Change]
tu versión           [Accept Incoming Change]
=======              [Accept Both Changes]
su versión           [Compare Changes]
>>>>>>> feature/x

Tras aceptar bloques, guarda y haz stage desde Source Control; el merge termina con el commit automático que sugiere el propio editor.

  • Merge Editor (visual): comando Git: Open Merge Editor — tres columnas (incoming/current/result) para resolver conflictos complejos arrastrando.
