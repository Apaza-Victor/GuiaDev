Descarga y registro

Sourcetree es un cliente Git gratuito de Atlassian para Windows y macOS. Descárgalo desde sourcetreeapp.com; requiere crear una cuenta Atlassian gratuita (la licencia se activa online una sola vez).

En el asistente inicial puedes conectar cuentas Bitbucket, GitHub o GitLab, configurar tu identidad Git y decidir si Sourcetree usa su Git embebido (recomendado en Windows) o el sistema.

El grafo de commits

La vista estrella es el grafo completo del historial: todas las ramas dibujadas como líneas que nacen, divergen y se fusionan, con commits coloreados según autor.

●─●─● main            ● commit   │ merge
 │     \              línea = referencia de rama
 ●─●───┼─ feature/x
     ●─● develop

Haz clic en cualquier commit para ver su diff completo, archivos tocados y metadatos. El filtro por archivo (File Status / Log) muestra quién cambió cada cosa y cuándo.

Staging selectivo por fragmentos

En File status, Sourcetree divide cada archivo modificado en chunks (hunks). Puedes:

  • Marcar solo algunos hunks y hacer Stage selected lines — equivalente a git add -p pero con clics.
  • Crear commits parciales limpios: lógica en un commit, formato en otro.
  • Descartar cambios concretos (Discard line/hunk) sin perder el resto.
# Lo que haces con clics equivale a:
git add -p archivo.js
# ...seleccionar fragmentos interactivamente...

Stash, rebase y cherry-pick visual

  • Stash: botón superior guarda cambios sin commit; el panel Stashes los lista para aplicar/pop cuando quieras.
  • Interactive Rebase: clic derecho sobre un commit → "Rebase children interactively". Arrastras, reordenas, squasheas o editas commits en una tabla.
  • Cherry-pick: arrastra un commit de una rama a otra, o clic derecho → Cherry pick. Ideal para portar hotfixes entre ramas.
  • Reset: clic derecho sobre cualquier commit → Reset current branch (soft/mixed/hard) con confirmación clara.
Interactive rebase en Sourcetree:
[↑↓] reordenar   [S] squash   [E] edit   [✕] drop
pick a1b2c3 feat: base del formulario
squash d4e5f6 fix: typo
pick g7h8i9 docs: comentarios
