Instalación y planes

GitKraken es el cliente Git más visual y pulido del mercado, disponible para Windows, macOS y Linux desde gitkraken.com/download. Está construido con Electron e incluye su propio Git embebido: no necesitas instalar nada más.

PlanQué permite
FreeRepos públicos + privados locales; sin apps privadas en la nube
Pro (pago)Repos privados remotos, merge conflict editor completo, perfiles
Teams/EnterpriseWorkspaces compartidos, insights de equipo, SSO

El plan gratuito sirve perfectamente para aprender y para repos públicos o locales.

Conectar tus cuentas remotas

Al primer arranque, inicia sesión con tu identidad Git. Luego ve a Preferences → Integrations y conecta GitHub, GitLab, Bitbucket o Azure DevOps vía OAuth:

  • Clona cualquier repo de tus cuentas desde una lista navegable (sin copiar URLs).
  • Crea repos nuevos directamente en el hosting.
  • Abre pull requests y edítalos sin salir de la app.
File → Clone Repo → pestaña del hosting conectado
→ lista de todos tus repos → clic → clonado

Navegar el grafo de commits

El panel central es un grafo interactivo elegante: cada nodo es un commit, las líneas son ramas. Interacciones clave:

  • Doble clic sobre una rama local para cambiarte (checkout).
  • Arrastra una rama sobre otra para hacer merge.
  • Arrastra un commit sobre una rama para cherry-pick.
  • Clic derecho en cualquier commit: reset, revert, rebase, crear rama ahí.
  • Busca commits por mensaje, autor o hash con Ctrl+F.
Arrastrar feat/login ────sobre────→ main
                    = git checkout main && git merge feat/login

Edición visual de conflictos

Cuando surge un conflicto durante un merge, GitKraken abre su Conflict Editor: pantalla dividida con tu versión (ours) a la izquierda, la remota (theirs) a la derecha y el resultado abajo.

  • Botones por hunk: "Use ours", "Use theirs", "Edit inline".
  • Barra de progreso de resolución por archivo.
  • Al terminar, botón Commit para cerrar el merge.
<<<<<<< HEAD          ← ours (tu rama)
precio = 100
=======               ← theirs (rama entrante)
precio = 120
>>>>>>> feature/descuento

Resuelves con clics: [Use theirs] → precio = 120 ✓

Funciones de los planes de pago

  • Workspaces: agrupa muchos repos por proyecto y ve su estado (ramas pendientes, cambios) de un vistazo.
  • Focus View / Commit Graph completo: grafo global de la organización con filtros avanzados.
  • Cloud patches: comparte cambios entre compañeros sin push intermedio.
  • Insights: métricas de contribución y actividad por repo/equipo.
  • Perfiles: separa identidad y configuración entre trabajo y personal.

Si solo necesitas lo básico, el plan Free + terminal cubre el 90% del trabajo diario.
