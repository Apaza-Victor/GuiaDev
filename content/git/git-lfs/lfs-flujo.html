Migrar un repositorio existente

Si los binarios ya contaminan tu historial, git lfs migrate reescribe los commits pasados convirtiéndolos a punteros:

# Migrar TODA la historia de los *.psd
git lfs migrate import --include="*.psd" --everything

# Migrar solo ramas recientes (más rápido, menos seguro)
git lfs migrate import --include="*.psd" \
  --include-ref=refs/heads/main

# Ver qué archivos pesan en tu historial antes de decidir
git lfs migrate info --include="*" --everything

Trabajo diario con LFS

Bien configurado, LFS es transparente: haces add/commit/push/pull normal. Comandos útiles cuando algo falla:

# ¿Qué archivos son LFS y su tamaño?
git lfs ls-files

# Descargar manualmente el contenido real (si clonaste sin él)
git lfs pull

# Solo traer metadatos (útil en CI donde no tocas los binarios)
GIT_LFS_SKIP_SMUDGE=1 git clone url-del-repo

# Verificar integridad de objetos LFS locales
git lfs fsck

# Push explícito de objetos LFS pendientes
git lfs push origin main --all

Error típico al pushear: missing objects in LFS → ejecuta git lfs push --all antes del push normal.

Cuotas y límites por plataforma

LFS consume dos recursos medidos: almacenamiento y ancho de banda mensual:

GitHub bloquea subidas al agotar el paquete; se compran data packs (por ejemplo 50 GB). En equipos con muchos binarios esto escala rápido: calcula antes de migrar.

Buenas prácticas y alternativas

  • Rastrea por extensión, no archivo por archivo: reglas estables en .gitattributes evitan sorpresas.
  • Define la política antes del primer push: migrar después duele (reescritura + force push).
  • Documenta qué es LFS en el README: quien clone sin git lfs install verá punteros raros de 130 bytes.
  • No versiones artefactos generables: builds, node_modules o datasets derivados pertenecen a CI/artefactos, no al repo.

Alternativas según el caso:

  • DVC / LakeFS: para datasets de machine learning con versionado tipo Git.
  • S3/Cloud Storage + referencias: activos enormes (video 4K) fuera del repo con hash en un manifest.json.
  • Git Annex: predecesor flexible de LFS para casos exóticos multi-servidor.
