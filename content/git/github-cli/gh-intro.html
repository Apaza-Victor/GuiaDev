¿Qué es gh?

GitHub CLI (gh) es la herramienta oficial de línea de comandos de GitHub. Mientras Git maneja tu historial local, gh habla directamente con la API de GitHub: crea pull requests, revisa issues, mira pipelines y hasta clona repos — todo sin abrir el navegador.

git  → control de versiones (local ↔ remoto)
gh   → plataforma GitHub   (issues, PRs, Actions, releases)

Se complementan: sigues usando git para commits y push; usas gh para todo lo social/colaborativo.

Instalación en Windows, Linux y macOS

# Windows (winget)
winget install --id GitHub.cli

# Windows (Chocolatey)
choco install gh

# macOS
brew install gh

# Debian/Ubuntu
sudo apt install gh

# Verificar
gh --version

Tras instalar, reinicia la terminal para que gh entre al PATH.

Autenticación con gh auth login

Un solo comando configura todo, incluidas las credenciales Git:

gh auth login

# ? What account do you want to log into?  → GitHub.com
# ? Preferred protocol?                    → HTTPS
# ? Authenticate Git with your credentials? → Yes   ← clave:
#     configura credential.helper por ti
# ? How to authenticate?                   → Login with a web browser

# Te muestra un código de un solo uso:
# ! First copy your one-time code: XXXX-XXXX
# Abre https://github.com/login/device e ingresa el código
  • Ventaja clave: al aceptar "Authenticate Git", tus git push/pull por HTTPS funcionan sin tokens manuales.
  • Verifica sesión y permisos con gh auth status.
  • Cierra sesión o cambia de cuenta con gh auth switch / gh auth logout.

Comandos esenciales

ComandoFunción
gh repo clone usuario/repoClonar (equivalente a git clone con URL completa)
gh repo create nombre --public --cloneCrear repo remoto + local de una vez
gh pr createAbrir pull request desde tu rama actual
gh pr list / view / checkoutListar, ver o bajarte el PR de otro a tu máquina
gh issue list / createGestionar issues
gh run list / watchVer y seguir workflows de Actions
gh browseAbrir el repo/PR actual en el navegador
