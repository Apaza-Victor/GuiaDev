Alias útiles

gh alias crea atajos personales para tus comandos más usados. Se guardan en tu configuración (~/.config/gh/config.yml).

# Sintaxis
gh alias set NOMBRE "comando a expandir"

# Mis alias favoritos:
gh alias set co 'pr checkout'          # gh co 58
gh alias set vp 'pr view --web'        # ver PR en navegador
gh alias set il 'issue list --assignee @me'
gh alias set rw 'run watch'

Los alias aceptan argumentos posicionales con $1, $2:

gh alias set bug 'issue create --title "$1" --label bug'
# Uso: gh bug "El botón no responde"

Listalos todos con gh alias list y elimina con gh alias delete NOMBRE.

Extensiones de la comunidad

Cualquiera puede publicar extensiones (binarios o scripts) que se instalan como subcomandos gh nombre:

# Buscar e instalar
gh extension search dashboard
gh extension install dlvhdr/gh-dash

# Listar, actualizar y desinstalar
gh extension list
gh extension upgrade --all
gh extension remove gh-dash

Extensiones populares:

  • gh-dash: panel TUI con PRs e issues de varios repos en tiempo real.
  • gh-copilot: asistente IA en la terminal (gh copilot suggest).
  • gh-eco: estadísticas de contribución estilo tarjeta de perfil.

gh api para casos avanzados

Cuando un subcomando no cubre algo, gh api expone la API REST completa autenticada:

# Info del usuario actual
gh api user --jq .login

# Estrellas de un repo
gh api repos/torvalds/linux --jq .stargazers_count

# Crear un release con assets
gh api repos/:owner/:repo/releases \
  -f tag_name=v1.2.0 -f name="v1.2.0"

# GraphQL (más eficiente para consultas complejas)
gh api graphql -f query='
  { viewer { login repositories(first: 5) { totalCount } } }'

El flag --jq filtra la respuesta JSON sin necesitar jq instalado.

Scripts y automatización

Combina gh con bash para automatizar rutinas. Ejemplo: cerrar issues obsoletas con label "stale":

#!/usr/bin/env bash
# cierra-issues-stale.sh
for issue in $(gh issue list --label stale --json number --jq '.[].number'); do
  gh issue close "$issue" -c "Cerrada por inactividad tras 30 días."
done

Otro clásico: abrir PR automático al terminar el día si hay cambios pendientes.

if [[ -n $(git status --porcelain) ]]; then
  git checkout -b backup/$(date +%F)
  git add -A && git commit -m "chore: backup diario"
  git push -u origin HEAD
  gh pr create --fill --draft
fi

En GitHub Actions, gh ya viene instalado en los runners: usa la variable GITHUB_TOKEN para scripts dentro de tus workflows.
