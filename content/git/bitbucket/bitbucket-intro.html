¿Qué es Bitbucket?

Bitbucket es la plataforma de hospedaje de repositorios Git de Atlassian. Aunque es menos popular que GitHub para open source, es muy común en empresas que ya usan el ecosistema Atlassian (Jira, Confluence, Trello), porque la integración entre herramientas es nativa y muy profunda.

Jira (tareas) ←→ Bitbucket (código) ←→ Confluence (docs)
                    Atlassian

Ofrece plan gratuito ilimitado en usuarios privados con límite de usuarios por workspace, y versiones cloud y Data Center (self-hosted corporativo).

El ecosistema Atlassian

La ventaja competitiva de Bitbucket no está solo en el repositorio sino en cómo conecta el ciclo completo del trabajo:

  • Jira: los commits y pull requests se vinculan automáticamente a historias/tickets citando su clave (PROY-123).
  • Confluence: documenta decisiones de diseño junto al código.
  • Trello: paneles ligeros para equipos pequeños.
  • Pipelines: CI/CD incluido sin configurar servicios externos.

Si tu equipo gestiona tareas en Jira, tener el código en Bitbucket elimina fricción: desde el ticket ves las ramas y PRs asociados, y desde el PR ves el ticket.

Crear cuenta y workspace

  1. Regístrate en bitbucket.org con correo o cuenta Google/Atlassian.
  2. Crea un workspace: el contenedor de proyectos, repositorios y usuarios de tu organización.
  3. Dentro del workspace crea projects para agrupar repositorios por producto o equipo.
  4. Invita miembros con roles: Admin, Write o Read.

Primer repositorio

Desde el botón Create → Repository elige nombre, lenguaje del .gitignore inicial, tipo de versión por defecto de main y visibilidad. Luego trabaja igual que en cualquier remoto Git:

# Opción A: clonar el repo vacío recién creado
git clone https://tu-usuario@bitbucket.org/acme-corp/api-ventas.git

# Opción B: conectar un proyecto local existente
git init
git remote add origin git@bitbucket.org:acme-corp/api-ventas.git
git add .
git commit -m "feat: estructura inicial"
git push -u origin main

Configura tus claves SSH desde Personal settings → SSH keys para evitar escribir contraseñas en cada push.
