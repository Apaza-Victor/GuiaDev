Azure Repos: características

Azure Repos ofrece hospedaje Git ilimitado dentro de tu proyecto. Lo que lo distingue de GitHub/Bitbucket:

  • Políticas de rama obligatorias muy granulares (mínimo de revisores, builds vinculados, work items vinculados).
  • Soporte además de TFVC (Team Foundation Version Control), su sistema centralizado legacy.
  • Integración profunda con Visual Studio y el ecosistema Microsoft.
  • Autenticación corporativa con Entra ID (Azure AD) de serie.

Clonar y trabajar con tu repositorio

# Clonar por HTTPS (usará credenciales de Git Credential Manager)
git clone https://dev.azure.com/acme-corp/Ecommerce/_git/tienda-web

# Clonar por SSH (configura antes la clave en User Settings → SSH keys)
git clone git@ssh.dev.azure.com:v3/acme-corp/Ecommerce/tienda-web

# Flujo normal de trabajo
git checkout -b feature/carrito
git add . && git commit -m "feat: carrito persistente"
git push -u origin feature/carrito

Todos los comandos estándar funcionan; Azure Repos es un servidor Git más para tu cliente local.

Pull Requests y políticas de rama

Los PRs se abren desde Repos → Pull requests. El punto fuerte son las branch policies: en Branches → ⋯ → Branch policies sobre main puedes exigir:

  • Número mínimo de revisores y quién debe aprobar.
  • Bloquear push directo (solo vía PR completado).
  • Build de validación exitoso antes del merge.
  • Vincular al menos un work item de Boards.
  • Comentarios resueltos obligatorios.

Con estas políticas activas, nadie puede romper main ni siquiera siendo admin: el merge queda literalmente bloqueado hasta cumplirlas.

Integración con Visual Studio y VS Code

  • Visual Studio: clona desde Team Explorer / Git menu con tu cuenta Microsoft; los PRs se crean y revisan desde el IDE.
  • VS Code: extensión "Azure Repos" para autenticación, o simplemente usa Git nativo con Credential Manager.
  • CLI: la extensión azure-devops de az cli permite operar desde terminal: 
    az extension add --name azure-devops
az repos list --organization https://dev.azure.com/acme-corp --project Ecommerce
