¿Qué es Azure DevOps?

Azure DevOps (antes Team Foundation Server / Visual Studio Online) es la plataforma de gestión del ciclo de vida de desarrollo de Microsoft. Cubre planificación, repos, CI/CD, pruebas y paquetes. Es la opción dominante en empresas corporativas, especialmente en el mundo .NET y Windows.

Puede usarse en la nube (dev.azure.com) o instalado on-premises como Azure DevOps Server.

Los cinco servicios principales

ServicioFunción
BoardsGestión ágil: work items, sprints, Kanban
ReposHospedaje Git ilimitado (y TFVC legacy)
PipelinesCI/CD con YAML o editor clásico
Test PlansPruebas manuales y exploratorias
ArtifactsFeeds de paquetes NuGet, npm, Maven, PyPI

No estás obligado a usarlos todos: muchos equipos usan solo Repos + Pipelines y mantienen Jira para tareas.

Organizaciones y proyectos

La jerarquía en Azure DevOps es:

Organización: https://dev.azure.com/acme-corp/
├── Proyecto: Ecommerce
│   ├── Boards / Repos / Pipelines / Test Plans / Artifacts
└── Proyecto: Intranet
    └── ...
  • La organización agrupa usuarios, permisos globales y facturación.
  • Cada proyecto tiene sus propios repos, pipelines y tableros.
  • Los permisos se gestionan con grupos de seguridad (Project Valid Users, Contributors...).

Crear tu organización gratuita

  1. Entra a dev.azure.com e inicia sesión con cuenta Microsoft (o crea una gratis).
  2. Acepta los términos: se crea tu organización con nombre único.
  3. Dentro, pulsa + New project, elige nombre, visibilidad (private/public) y control de versiones Git.
  4. El plan gratuito incluye: 5 usuarios Basic, pipelines gratuitos de código abierto y 1800 minutos/mes de CI en Microsoft-hosted agents para proyectos privados (2000 min según región).
