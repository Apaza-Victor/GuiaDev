Extensiones esenciales para escribir más rápido

Estas extensiones atacan lo que más tiempo roba al programar: completar nombres, reformatear código y corregir errores al toque. Están pensadas para instalar de una y olvidarte.

Error Lens

Muestra los errores y warnings inline, justo al lado de la línea, sin pasar el ratón. Corriges al instante.

Prettier

Formateador automático: guarda y el código se ordena solo. Olvídate de alinear corchetes y comas a mano.

ESLint

Analiza tu código y te avisa de errores y malas prácticas mientras escribes, antes de ejecutarlo.

Auto Rename Tag

Renombra la etiqueta HTML de apertura y cierre a la vez. Se acabó editar dos veces.

Auto Close Tag

Cierra automáticamente las etiquetas HTML y agrega el comentario de cierre cuando escribes la apertura.

Better Comments

Colorea y clasifica tus comentarios (todos, destacados, pendientes) para leer el código más rápido.

IA y autocompletado: menos teclear

La IA en el editor convierte un comentario en código y completa funciones enteras mientras tecleas. Son la mayor ganancia de velocidad de los últimos años.

GitHub Copilot

El autocompletado más potente: completa líneas, funciones y archivos enteros con IA en tu contexto real. Con plan gratuito.

Amazon Q

Asistente de IA gratuito para autocompletar y chatear sobre tu código. Interesante alternativa sin pagar.

Codeium

Autocompletado de IA gratuito con soporte de multitud de lenguajes y búsqueda semántica en la nube.

TabNine

Mentalidad en el autocompletado clásico: sugiere el siguiente token según todo tu código. Ligero y veloz.

Thunder Client

Prueba APIs REST y GraphQL desde el editor. Evitas abrir otra app para hacer un GET.

Git sin salir del editor

Entender qué cambió y cuándo es clave para no perder tiempo. Estas extensiones hacen que Git viva dentro de VS Code.

GitHub Pull Requests

Revisa y administra pull requests y issues directamente desde el editor. Menos cambios de ventana, más velocidad.

GitLens

La navaja suiza de Git: blame inline, historia de líneas, comparación de ramas y mucho más.

Git Graph

Visualiza el grafo de commits en una vista interactiva y haz operaciones de Git con clic.

Git History

Explora el historial de un archivo o línea y compara versiones antiguas de un vistazo.

Formato, snippets y productividad extra

Emoji, coloreado de corchetes y atajos que multiplican tu productividad diaria. Pequeñas instalaciones, grandes ahorros de tiempo.

Bracket Pair Colorizer

Colorea cada par de corchetes con un color distinto, por lo que encontrar el bloque que abre o cierra es instantáneo. (Ya integrado en VS Code reciente).

Material Icon Theme

Iconos de archivos y carpetas que te dejan reconocer cada tipo de archivo de un vistazo en el explorador.

Path Intellisense

Autocompleta las rutas de archivos e imports de forma inteligente, evitando errores de ruta al teclear.

Indent Rainbow

Pinta cada nivel de indentación con un color distinto, para leer las jerarquías del código de un vistazo.

Code Spell Checker

Revisa la ortografía de tus variables y comentarios en español: evitas typos que rompen nombres.

SQL Formatter

Formatea consultas SQL largas en un clic para legibilidad inmediata.

Live Server

Levanta un servidor local y recarga la página automáticamente al guardar. Imprescindible para frontend.

Temas y fuentes

Instala un tema y una fuente de programación con ligaduras (Fira Code) para leer código más cómodo y rápido.
