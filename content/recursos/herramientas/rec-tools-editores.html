Editores e IDEs

Un buen editor con extensiones adecuadas multiplica tu productividad. Combina un editor ligero para el día a día con un IDE completo cuando el proyecto lo pide.

VS Code

El editor más popular. Extensiones para todo.

Sublime Text

Editor ligero, rápido y con package control.

Neovim

Vim moderno: LSP, treesitter y config en Lua.

Vim

El editor de la terminal por excelencia, en cualquier sistema.

GNU Emacs

Extensible hasta límites insospechados, gratis y open source.

Zed

Editor de alto rendimiento hecho en Rust, colaborativo.

Notepad++

Editor ultra ligero para Windows, con plugins.

Geany

IDE pequeño y veloz para Linux/Windows.

IDEs de JetBrains

IntelliJ IDEA

IDE referente para Java/Kotlin (Community gratis).

PyCharm

El mejor para Python, con Community gratuita.

WebStorm

JavaScript/TS full-stack con soporte Node y Vue/React.

PhpStorm

PHP de JetBrains con composer y frameworks integrados.

GoLand

IDE oficial de JetBrains para Go.

Rider

.NET/C# de JetBrains, excelente para Unity.

CLion

IDE para C y C++ con soporte CMake.

DataGrip

Cliente de bases de datos con todas las queries.

RubyMine

Ruby y Rails en el IDE de JetBrains.

IDEs por plataforma y lenguaje

Visual Studio

IDE completo para .NET, C++ y Azure.

Android Studio

IDE oficial para apps Android.

Xcode

IDE oficial para iOS y macOS (solo Apple).

Eclipse

IDE multilingüe open source, clásico de Java.

Apache NetBeans

IDE de Java/PHP/C++ mantenido por Apache.

Code::Blocks

IDE ligero de C/C++, ideal para empezar.

Arduino IDE

Programa microcontroladores Arduino.

Anaconda

Distribución de Python con conda: paquetes y entornos científicos listos.

Spyder

IDE científico para Python (viene con Anaconda): editor, consola y plots.

Editores potenciados con IA

Cursor

Editor basado en VS Code con IA integrada (Copilot-style).

Windsurf

Editor de IA con agente que edita el proyecto por ti.

GitHub Copilot

Autocompletado con IA para VS Code, JetBrains y neovim.

Regla práctica: usa un editor ligero (VS Code, Zed o Neovim) para el 80% del trabajo y reserva el IDE pesado para cuando el proyecto lo pida (ej. Android Studio, Xcode o Rider). No necesitas instalarlos todos a la vez.

Terminal, Git y colaboración

La terminal y el control de versiones son pan de cada día.

Git

Documentación y libro Pro Git gratuito.

GitHub

Docs de GitHub: repos, PRs, Actions.

GitHub CLI (gh)

Crea repos, PRs e issues sin salir de la terminal.

GitLab

Alternativa a GitHub con CI/CD integrado.

Windows Terminal

Terminal moderna para Windows.

Oh My Zsh

Framework para Zsh con temas y plugins.

WezTerm

Terminal configurable por Lua, multiplataforma.

Warp

Terminal moderna con autocompletado y bloques de comandos.

tmux

Multiplexor de terminales: varias sesiones en paneles.

lazygit

Git visual desde la terminal, en TUI.

lazydocker

Gestiona contenedores Docker desde una TUI.

ripgrep

Busca en código a velocidad de rayo (rg).

fd

Alternativa moderna y rápida a `find`.

fzf

Buscador difuso para comandos, archivos e historial.

bat

Versión de `cat` con resaltado de sintaxis.

tldr pages

Manuales de comandos con ejemplos prácticos.

Starship

Prompt de terminal rápido y bonito para cualquier shell.
