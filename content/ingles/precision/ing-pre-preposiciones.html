Preposiciones de Dependencia

Objetivo

Las preposiciones que no se traducen 1 a 1 del español. Memoriza el verbo + preposición COMPLETO: ahí está el 80% del progreso.

Verbo + preposición: la lista que salva

ColocaciónTraducción directaEjemplo real Escuchar
depend ondepender deThis service depends on Redis.
consist ofconsistir enThe pipeline consists of three stages.
based onbasado enThe rating is based on response time.
connect toconectarse aThe client connects to the database.
integrated withintegrado conOur auth is integrated with Okta.
✗ It depends OF the input.          → ✓ It depends ON the input.
✗ Consists IN two parts.             → ✓ Consists OF two parts.
✗ Based IN real data.                → ✓ Based ON real data.
✗ Connect WITH the server.           → ✓ (se matiza, ver nota)
✗ Integrated TO our CRM.             → ✓ Integrated WITH our CRM.
Connect admite "to" (dirigir al server) y "with" (conectar dos cosas). Usa connect to cuando hablas del destino: "I can't connect to the VPN." Junto con tu colega: "integrated with" es siempre la apuesta segura.

Sí vs NO (errores que delatan)

Tres reglas de oro: 1) depend siempre lleva on. 2) consist siempre lleva of. 3) based siempre lleva on. Si memorizas estas tres, te ahorras el 90% de las correcciones en PR.

Práctica

Completa con on / of / to / with:

  1. "The recommendation engine depends ______ the event feed."
  2. "The test suite consists ______ integration and unit tests."
  3. "The SLA is based ______ p99 latency."
  4. "The CLI connects ______ the admin API."

Modelo: "The recommendation engine depends on the event feed." / "The test suite consists of integration and unit tests." / "The SLA is based on p99 latency." / "The CLI connects to the admin API."

✗ Deploy at staging.              → ✓ Deploy TO staging.
✗ It runs in Node.                → ✓ It runs ON Node.
✗ Built on React.                 → ✓ Built WITH React.   ("built IN React" también)
✗ Compare against? — "compare to" es más común en dev casual.

La frase completa en un standup:
"We deploy to staging, run the suite on Node 22, and filter by environment."
En standups la combinación estrella es responsible for: "I'm responsible for the auth service this sprint." Y en Jira: "search for the ticket" (no "search the ticket"), "the log is attached to the ticket."

Compare with vs Compare to

  • compare to: resaltar similitudes, lenguaje casual: "compare this to the previous build."
  • compare with: a la par, examinar diferencias: "compare the benchmark with the baseline."
  • En code review: "compare main with your branch" es lo habitual.

Práctica

Corrige las preposiciones y completa:

  1. "We deploy at prod and it runs in a container."
  2. "This API is built on Go and filters at status."
  3. "I'm responsible ______ the migrations and I'll search ______ the missing index in the codebase."

Modelo: "We deploy to prod and it runs in a container." / "This API is built with/in Go and filters by status." / "I'm responsible for the migrations and I'll search for the missing index in the codebase."

Frases puente para documentación

Note that... / Keep in mind that...
In this section, we cover... / We will go over...
The following table summarizes...
For more details, refer to the API reference.

Phrasal unido:
"Refer to section 4" (NO "refer section 4").
Cuando escribas docs como hispanohablante, tus errores típicos: "refer the docs" (falta to), "depends of" (debe ser on), "in base to" (debe ser based on). Con estas tres colocaciones te leen como nativo técnico.

Práctica

Completa con la colocación correcta (refer to / apply to / deal with / account for):

  1. "This rule only ______ unauthenticated requests."
  2. "The retry logic ______ transient network errors."
  3. "______ the configuration guide before touching env vars."
  4. "The budget must ______ the new region costs."

Modelo: "This rule only applies to unauthenticated requests." / "The retry logic deals with transient network errors." / "Refer to the configuration guide before touching env vars." / "The budget must account for the new region costs."
