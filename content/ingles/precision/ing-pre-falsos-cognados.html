Falsos Amigos del Día a Día

Objetivo

Palabras que se parecen al español pero significan otra cosa. En código y en reuniones, un falso cognado cambia todo el mensaje.

Los que más se cuelan en reuniones

InglésParece español…PERO significa
assistasistir (a una reunión)ayudar (asistir a reunión = attend)
discussdiscutir (pelear)conversar, debatir con calma
actuallyactualmenteen realidad / de hecho (actualmente = currently)
currentlycorrientementeen este momento, actualmente
eventuallyeventualmente (quizá)finalmente / al final (eventualmente = occasionally)
supportsoportar (aguantar)dar soporte / apoyar (soportar a alguien = put up with)
deliver“deleverar” (entregar algo puntual)hacer y entregar un resultado
issueel “issue” técnicoproblema/pero también mejoría de temas
"Asistir a la reunión" = attend the meeting, jamás "assist". Y "soportar" en el sentido de aguantar = put up with / stand: "I can't put up with this flaky test anymore." No digas "I can't support this bug in my machine".

Issue no es solo problema

  • "There's an issue with the parser" = hay un problema.
  • "A known issue" en docs = limitación documentada.
  • "Topic/security issue" = tema / asunto de seguridad: "The security issue is being tracked in ticket #42."

Un problem es más directo y negativo. En taquilla se dice "there's a known issue", que suena más neutral que "there's a problem". En git: "please open an issue" — no "open a problem".

Práctica

Traduce a inglés evitando los falsos amigos:

  1. "Asistiré a la reunión y, si puedo, te ayudo con el release."
  2. "Actualmente el equipo no está entregando tan rápido como antes."
  3. "Al final vamos a migrar todo a la nube, pero por ahora local."

Modelo: "I'll attend the meeting and, if I can, assist you with the release." / "The team isn't delivering as fast as before right now." / "We're going to migrate everything to the cloud eventually, but for now, it stays on-prem."

Falsos Amigos Técnicos

Verbos técnicos traicioneros

InglésParece español…PERO significa
assumeasumir (responder por)dar por hecho / suponer (asumir responsabilidad = take responsibility)
applyaplicar (llevar a cabo)postularse / aplicar como parche o política: "apply a patch to config"
deprecatedesaprobar (rechazar)marcar como obsoleto
data / criteria / mediasustantivos "singulares"son plurales: data ARE · criteria ARE · media ARE
✗ "The data is inconsistent with the criteria that our company set."
✓ "The data ARE inconsistent with the criteria that our company set."
✗ "The media is covering the outage."
✓ "The media ARE covering the outage."
"data", "criteria", "media" son latinismos plurales. En chats informales se le perdona "data is", pero en un reporte o documento formal destaca quien los conjuga bien: the data are.

Assumed y Apply en contexto dev

  • assume: "The package assumes you're running Node 20." = da por hecho (no "asume responsabilidades").
  • take responsibility: "I'll take responsibility for that fix." = asumir la responsabilidad.
  • apply + sustantivo: "apply the patch", "apply the changes". Y apply for un puesto: "I applied for the backend role."
  • En JS existe Function.prototype.apply: "pass the arguments array to apply."
No digas "I'm going to assume this task". Di "I'll take responsibility for this task". Y no traduzcas implementar directamente: implement existe y se usa ("I implemented the feature"), el problema es USARLO DEMASIADO en boca de hispanos para todo. Varía: build, ship, add, wire up.

Práctica

Corrige o elige la palabra correcta:

  1. "I assumed the bug report and I'll applied the fix today."
  2. "The data shows that the media is focusing on the outage."
  3. "This endpoint is ______; you should use /v2 instead." (deprecate / reject)

Modelo: "I took responsibility for the bug report, and I'll apply the fix today." / "The data show that the media are focusing on the outage." / "This endpoint is deprecated; you should use /v2 instead."

El Spanglish Técnico a Evitar

Verbos inventados y calcos que delatan

Inglés realSignificadoNo digas
implement / build / shipllevar a cabo / construir / entregar~~"to realize a feature"~~
attend the meetingestar presente~~"assist the meeting"~~
take responsibilityasumir (un cargo)~~"assume this task"~~
put up with / standaguantar/soportar~~"support the bug"~~
grant permissionsdar permisos~~"give access"~~ en docs formales

Por qué el spanglish técnico duele

  • imply ≠ implement: "imply" significa insinuar. Decir "I implied the feature" es un ERROR real de mezcla de idiomas: nada que ver con "implement".
  • "the feature went live": muy natural, mejor que "the feature was realized".
  • En vez de "I will realize this ticket", usa: "I'll take this ticket" o "I'll work on this task".
✗ I imply that... (cuando quieres decir implement)
✗ The feature was realized.
✗ Assist the meeting.
✓ I'll implement the feature and ship it by Thursday.
✓ I'll attend the standup.
El Spanglish se combate con colocaciones. Aprende frases completas, no palabras sueltas: attend a meeting, take responsibility, apply a patch, mark as deprecated. A tu cerebro le cuesta menos recordar un bloque que traducir sobre la marcha.

Práctica

Reescribe cada frase en inglés técnico correcto:

  1. "Voy a asistir a la demo y al final realizar el feature del checkout."
  2. "No soporto más este test inestable, lo voy a marcar como obsoleto."
  3. "La política se aplica a todos los servicios y da acceso de lectura."

Modelo: "I'll attend the demo and I'll implement the checkout feature right after." / "I can't stand this flaky test anymore, I'm going to deprecate it." / "The policy applies to all services and grants read access."
