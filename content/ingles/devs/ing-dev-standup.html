Dar tu Daily en Inglés

Objetivo

Sobrevivir —y brillar— en tu daily de 15 minutos: tres preguntas, frases cortas, cero pánico.

La estructura de las tres respuestas

1. YESTERDAY   "Yesterday I finished the auth flow and
                started reviewing Maria's PR."
2. TODAY       "Today I'm focusing on the payment
                integration. Should be done by EOD."
3. BLOCKERS    "No blockers." / "I'm blocked on the API
                keys — waiting on DevOps."
Escucha y repite las tres respuestas modelo: yés-ter-dei ái fí-nisht di aut flou and stár-ted ri-view-in ma-rí-as pi-arAyer terminé el flujo de autenticación y empecé a revisar el PR de María · tu-déi áim fóu-cu-sin on di péi-ment in-te-gréi-shon. shud bi dan bai i-ou-diHoy me enfoco en la integración de pagos. Debería estar lista para fin de día · nou bló-kers. áim blókt on di éi-pi-ái kís — uéi-tin on dé-vo-opsSin bloqueos. Estoy bloqueado por las claves de API — esperando a DevOps

Práctica

Graba tu daily de hoy en inglés (30 segundos). Usa: 1 verbo fuerte + 1 estado + 1 blocker o "no blockers". Repite hasta que salga sin leer.

Blockers y Updates

Reportar un problema como profesional

"Quick heads-up: the staging environment is down,
 so QA is blocked until infra restarts it."

FÓRMULA: heads-up + qué pasa + a quién afecta +
         qué necesitas (o que ya hiciste)
Escucha y repite el heads-up modelo: kuik jeds-ap: di stéi-yin en-vái-ron-ment is dáun, sóu kiu-ei is blókt an-til ín-fra ri-stárts itAviso rápido: el entorno de staging está caído, así que QA está bloqueado hasta que infraestructura lo reinicie

"Status update on the migration:
 ✅ Data model migrated

 ⚠️ Found an edge case with legacy timestamps;
    documenting a workaround here: [link]"
Escucha el update asíncrono modelo: sté-tus ap-déit on di mai-gréi-shon: déi-ta mó-del mai-gréi-ted. ri-rái-tin kuí-ris — sík-sti per-sent dan, i-ti-ei zérs-dei. fáund an e-y kéis uiz lé-ga-si táim-stamps, dó-ku-men-tin a uor-ka-ráund jirActualización del estado de la migración: modelo de datos migrado. Reescribiendo consultas — 60% listo, llegada estimada el jueves. Encontré un caso límite con timestamps heredados, documentando un workaround aquí
Los nativos valoran el mal pronóstico temprano ("flag early"): avisar HOY que irás tarde el viernes es profesional; avisar el viernes es un problema.

Sprint planning: vocabulario de estimación

"This story looks like a 3-pointer for me."
"That's a big one — can we split it?"
"I need clarification on acceptance criteria."
"What's our definition of done here?"
"Dependency alert: this blocks on the API team."
"Should we spike it first?"  (spike = investigación rápida)
"Capacity check: I have PTO Thursday and Friday."
Escucha y repite frases de planning: dis stó-ri luks laik a zrí-póin-ter for miPara mí esta historia es de 3 puntos · dats a big uan — kan ui split it?Esa es grande — ¿podemos dividirla? · di-pén-den-si a-lér-t: dis bloks on di éi-pi-ái timAlerta de dependencia: esto depende del equipo de API
Frases comodín cuando no entiendes la dinámica: "Can you walk me through that again?" kan yu uok mi zrú dat a-gén?¿Puedes explicármelo de nuevo? · "So what I'm hearing is... — is that right?" sou uat áim jí-rin is... — is dat ráit?Entonces, lo que escucho es... — ¿es correcto? Parafrasear demuestra atención, no debilidad.
