Dar tu Daily en Inglés

Objetivo

Sobrevivir —y brillar— en tu daily de 15 minutos: tres preguntas, frases cortas, cero pánico.

La estructura de las tres respuestas

1. YESTERDAY   "Yesterday I finished the auth flow and
                started reviewing Maria's PR."
2. TODAY       "Today I'm focusing on the payment
                integration. Should be done by EOD."
3. BLOCKERS    "No blockers." / "I'm blocked on the API
                keys — waiting on DevOps."

Frases listas por situación

SituaciónFrase
Avanzaste bienMade good progress on X / Almost done with X
TerminasteX is done / wrapped up / shipped
Estás a mitadI'm halfway through X / in the middle of...
Estás atascadoI'm stuck on X / hitting an issue with X
Esperando a alguienStill waiting on feedback from design
Cambiaste de planPivoted to X after yesterday's findings
Nada nuevoSame as yesterday, still on X
La daily NO es para resolver problemas: si el tema se alarga, di "Happy to go deeper after standup" o "Let's take it offline" (= lo hablamos aparte).

Práctica

Graba tu daily de hoy en inglés (30 segundos). Usa: 1 verbo fuerte + 1 estado + 1 blocker o "no blockers". Repite hasta que salga sin leer.

Blockers y Updates

Reportar un problema como profesional

"Quick heads-up: the staging environment is down,
 so QA is blocked until infra restarts it."

FÓRMULA: heads-up + qué pasa + a quién afecta +
         qué necesitas (o que ya hiciste)
SituaciónFrase modelo
Vas a llegar tarde"Running 10 min late, starting right away though."
Te vas a enfermar"I'm feeling under the weather — taking a sick day. Ping me if anything's urgent."
Pedido urgente fuera de alcance"I can do it, but it'll push feature X to next week. Which takes priority?"
No sabes algo"Good question — let me check and get back to you by noon."
Escala técnica"This needs more investigation than expected. I'd suggest we timebox it to one day."

Updates asíncronos (Slack/email)

"Status update on the migration:
 ✅ Data model migrated
 🚧 Rewriting queries — 60% done, ETA Thursday
 ⚠️ Found an edge case with legacy timestamps;
    documenting a workaround here: [link]"
Los nativos valoran el mal pronóstico temprano ("flag early"): avisar HOY que irás tarde el viernes es profesional; avisar el viernes es un problema.

Retros y Planning

Retrospective: hablar del equipo con tacto

Quieres decirForma segura en retro
Hubo caos con los requisitos"Requirements changed mid-sprint — maybe we could lock scope earlier?"
Había demasiado trabajo"We overcommitted this sprint. Let's size stories smaller next time."
Las reuniones sobran"Could we try async updates for status instead of meetings?"
Alguien ayudó muchísimo"Big shoutout to Ana for jumping in on the release!"
Aprobar una idea"+1 to that" / "Love that idea"
Proponer acción concreta"Action item: document the deploy process before Friday."

Sprint planning: vocabulario de estimación

"This story looks like a 3-pointer for me."
"That's a big one — can we split it?"
"I need clarification on acceptance criteria."
"What's our definition of done here?"
"Dependency alert: this blocks on the API team."
"Should we spike it first?"  (spike = investigación rápida)
"Capacity check: I have PTO Thursday and Friday."
Frases comodín cuando no entiendes la dinámica: "Can you walk me through that again?" · "So what I'm hearing is... — is that right?" Parafrasear demuestra atención, no debilidad.
