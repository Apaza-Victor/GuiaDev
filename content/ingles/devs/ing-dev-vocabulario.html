Términos del Día a Día

Objetivo

Usar con precisión los términos que ya conoces pero que en contexto anglo tienen usos que quizás no dominas.

Verbos de ciclo de vida

Vocabulario de bugs y calidad

TérminoEjemplo natural
edge case"Works fine, but there's an edge case when the token expires"
race condition"It's a race condition between two fetches"
bottleneck"The DB query is the bottleneck"
downtime / outage"We had an outage last night" (outage = caída total)
workaround"Temporary workaround until we fix the root cause"
root cause"We found the root cause of the memory leak"
flaky (test)"That test is flaky — it fails randomly"
tech debt"We're accumulating tech debt fast"
"Bug" no se conjuga como piensas: hay a bug, bugs, buggy code (adjetivo), y el verbo es "break": this change breaks Safari support.

Verbos de Desarrollo

VerboEjemplo

Colocaciones verbo + sustantivo tech

push a commit · open a PR · merge a branch · resolve conflicts
raise an issue · file a bug report · triage tickets
set up CI/CD · configure the pipeline · scale the service
write tests · run the suite · meet requirements
gather requirements · scope the work · estimate effort
ship a feature · sunset a product · hand off the project

Práctica

Traduce estas líneas a inglés usando verbos fuertes:

  1. "Hice una API de pagos y la conecté con Stripe."
  2. "Arreglé el bug del login y escribí tests."
  3. "Estoy migrando el proyecto a TypeScript este mes."

Modelo: "I built a payments API and integrated it with Stripe." / "I fixed the login bug and added test coverage." / "I'm migrating the project to TypeScript this month."
