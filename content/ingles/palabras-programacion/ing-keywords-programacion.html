Keywords de Control de Flujo

Objetivo

Dominar las palabras reservadas que dirigen el flujo del código (condiciones, bucles y saltos) con su significado en español y un concepto corto.

Bucles

KeywordSignificadoConcepto corto Escuchar
forforparaparaBucle que repite un bloque un número conocido de veces.

Ejemplo combinado

for (let i = 0; i < 10; i++) {
  if (i % 2 === 0) {
    continue;      // saltar pares
  }
  if (i > 7) break; // salir del bucle
  doSomething(i);
}
En español/Spanglish a menudo mezclamos: "hace un if", "le meto un return". En inglés técnico se usan igual (como sustantivos y verbos): "the if branch", "just return early".

async function fetchUser(id) {
  try {
    const res = await get(`/users/${id}`);
    if (!res.ok) throw new Error("request failed");
    return res.data;
  } catch (err) {
    console.error(err);
  } finally {
    cleanup();
  }
}
Para leer en voz alta: los nativos leen "async" como "éi-sinc" y "await" como "a-uéit". En una entrevista di "I'm using async await for the API calls".
