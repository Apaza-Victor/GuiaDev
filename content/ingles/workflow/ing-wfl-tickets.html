Regla práctica anglosajona: priority = cuándo lo hacemos, severity = cuánto duele. En Jira vienen juntos, pero un bug cosmetic con high priority puede existir: lo arreglas pronto porque molesta a un cliente importante.

User Stories y Acceptance Criteria

La fórmula "As a... I want... So that..."

La user story clásica describe quién, qué y para qué. Escribirla bien en inglés es mitad skill de producto, mitad skill de idioma:

ParteEjemplo Escuchar
As a... (quién)As a returning customer,as a ri-túr-nin kás-to-me-rcomo un cliente que vuelve
I want... (qué)I want to save my payment method,ai uánt tu séiv mai péi-ment mé-zodquiero guardar mi método de pago
So that... (para qué)so that I can check out faster on my next order.sou dat ai kan chek áut fás-ter on mai nekst ór-derpara finalizar la compra más rápido en mi próximo pedido

Acceptance criteria y Definition of Done

STORY: As a returning customer, I want to save my
       payment method so that I can check out faster.

ACCEPTANCE CRITERIA:
- [ ] User can save a card from the checkout page
- [ ] Saved cards show masked (e.g. **** 4242)
- [ ] Card can be removed from Settings
- [ ] Saving a card requires 2FA

DEFINITION OF DONE:
- Code merged into main
- Covered by automated tests
- QA signed off

"Done" no significa "yo ya codeo": significa definition of done cumplida. Los equipos anglo se quejan en la retro: "We marked it done but QA never signed off." Done sin DoD es medio trabajo.

Práctica

Escribe en inglés:

  1. Una user story para "recordar el carrito cuando el usuario cierra sesión" con las tres partes (As a / I want / So that).
  2. Los criterios de aceptación de esa historia (2 a 3, en frases "the user can..." / "the cart is...").

Frases para decirlas en voz alta (di la tuya y compara):

  • As a logged-in user, I want my cart to be saved so that I can finish my purchase later.as a logd-in iú-ser, ai uánt mai kart tu bi séivd sou dat ai kan fí-nish mai púr-chas léi-terComo usuario con sesión iniciada, quiero que mi carrito se guarde para poder terminar mi compra después.
  • We're moving this to done, QA signed off.ui ar mú-vin dis tu dan, kiú-ei sáind ofEstamos moviendo esto a Done; QA dio el visto bueno.
  • I'm flagging this ticket as blocked — we're waiting on the API credentials.ai am flé-gin dis tí-ket as blokt, ui ar wéi-tin on de éi-pi-ái kre-dén-shalsEstoy marcando este ticket como bloqueado; esperamos las credenciales del API.
  • This ticket was reopened because the payment flow regressed in QA.dis tí-ket uas ri-ó-pend bi-kós de péi-ment flou ri-grést in kiú-eiEste ticket fue reabierto porque el flujo de pago volvió a fallar en QA.
