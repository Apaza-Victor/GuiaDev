Tipos de Test

Objetivo

Hablar con QA y con tu equipo sobre qué tipo de test estás escribiendo y por qué, usando el nombre correcto en inglés.

El mapa de los tipos de test

Tipo de testQué cubre Escuchar
unit testuna función o clase aislada, sin red ni BD
integration testvarias piezas juntas: módulo + BD, API + servicio
end-to-end test (E2E)el flujo completo como usuario real
smoke testchequeo rápido: "¿el build respira?"
regression testconfirmar que arreglar una cosa no rompió otra
snapshot testcaptura la salida y avisa si cambia
contract testverifica que dos servicios acuerdan el mismo contrato

El orden de "quiénes lo ejecutan"

TestSe ejecuta en... Escuchar
UnitCI, en cada PR, muy rápido
IntegrationCI y también en PRs de mayor riesgo
E2Epre-release, en staging (más lentos)
No digas "the proof" para test: es "the test" / "the tests". Y "covered" es la palabra clave: "Is this covered by tests?" es LA pregunta de todo reviewer anglohablante.

TDD y BDD con sus frases

SiglaQué es Escuchar
TDDtest-driven development: el test se escribe antes del código
BDDbehavior-driven development: Given / When / Then
red-green-refactorver fallar, ver pasar, refactorizar
"Push again? CI is red — the auth tests are failing."

"This case covers the edge case where the cart is

 we should add tests before merging."
Frase de oro del reviewer anglo: "Let's not merge this until the flaky test is fixed." Un flaky test mata la confianza en la suite; arreglarlo es prioridad, no detalle.

QA y Releases

El vocabulario del pase a producción

TérminoQué significa Escuchar
QAquality assurance: el equipo (o proceso) de aseguramiento
sign offdar el visto bueno formal
release candidateversión candidata a salir a producción (RC)
stagingambiente casi idéntico a producción, para validar
quality gateregla que frena el deploy si no se cumple (ej. coverage mínima)
shiplanzar / publicar el cambio

La conversación de release

Dev:    "RC-1 is deployed to staging. Smoke tests pass."
QA:     "I walked the checkout and payment flow, all good.
         Signing off now."
Dev:    "Great — shipping to production today at 5 pm."
DevOps: "Quality gate: coverage is above 80%, approved."

Práctica

Completa estas frases en inglés (QA/team te las dirán; responde pensando en real):

  1. "_____ do you need for this release?" (¿qué necesitas...?) → "What do you need..."
  2. "Who is going to _____ off the E2E run?" → sign
  3. "Is this change _____?" (seguro para lanzar) → shippable
  4. "CI is red. You have a _____ test." → flaky

Di en voz alta:

  • The suite is green and QA signed off. We can ship it.
  • This RC was rejected because one smoke test failed in staging.
  • The quality gate requires at least 80% coverage before merging.
  • I'm leaving the tests in a running state, you can pick up from my branch.
