Cómo armar la frase del error

"I'm getting a 'cannot find module' error when I
 run the tests."
"Which directory is it looking in? The module is
 in node_modules, right?"
"It's throwing 'permission denied' on the logs
 folder. Probably a Docker volume issue."
Kit de primeros auxilios del error: 1) copia el stack trace, 2) di la primera línea del error (no leas 40 líneas en voz alta), 3) añade qué comando ejecutabas. Eso es el 90% del bug report oral.

Describir un Error a un Colega

La fórmula para pedir ayuda técnica

Los devs anglohablantes piden ayuda con una estructura fija: qué comando/cuándo + qué error exacto + qué intentaste. Nada de "it doesn't work".

PasoFrases modelo Escuchar
1. Cuándo/cómoI'm getting 'Cannot find module X' when I run the tests.aim gé-tin ká-not fáind mó-diul eks wen ai ran de testsRecibo 'Cannot find module X' cuando ejecuto los tests.
2. Lo que vesThe stack trace points to jwt.ts, line 42.de stak treis poins tu yei-dá-bliu-ti-es, láin for-ti-tuEl stack trace apunta a jwt.ts, línea 42.
3. Lo que intentasteI already tried clearing node_modules and reinstalling.ai ol-ré-di traid klí-rin noud-mó-diuls and ri-ins-tó-linYa intenté limpiar node_modules y reinstalar.
4. Lo que esperasShould I just pin the package version, or is there a better fix?shud ai yast pin de pá-kech vér-shon, or is der a bé-ter fiks?¿Fijo la versión del paquete, o hay una mejor solución?

Errores que verás en logs ajenos

  • Time out / timed out: "The request timed out after 10 seconds." (no "se hizo late")
  • It hangs / it's hanging: el proceso se queda colgado sin responder
  • It keeps crashing: se cae una y otra vez (loop)
  • It's intermittent: falla de forma intermitente, no reproducible a la primera
