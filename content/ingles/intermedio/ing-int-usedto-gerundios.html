Used To, Be Used To, Get Used To

Objetivo

Tres estructuras parecidas con significados distintos: confundirlas delata al hispanohablante al instante.

Las tres formas

EstructuraSigue deEjemplo
used to + verbo basehábito del pasado que YA NO pasaI used to play videogames all night
be used to + -ing/sustantivoestar acostumbrado A algoI'm used to working at night
get used to + -ing/sustantivoacostumbrarse (proceso)You'll get used to waking up early

Compara los tres

I used to smoke        → fumaba antes, ya no
I am used to smoking   → fumo habitualmente y me resulta normal
I'm getting used to it → poco a poco me acostumbro
  • Negativa de hábito: didn't use to like coffee (ojo: use sin -d).
  • Pregunta: Did you use to live here?
Después de be/get used to va SIEMPRE -ing o sustantivo (¡to aquí es preposición!). ❌ I'm used to work late. ✅ I'm used to working late.

Verbos + Gerundio

Verbos que exigen -ing como objeto

VerboEjemplo
enjoyI enjoy reading
avoidAvoid using var in JS
finishShe finished writing the docs
mindDo you mind closing the window?
suggest / recommendI suggest taking a break
keep / practice / quitKeep practicing! Quit procrastinating

Preposición = gerundio, siempre

Después de CUALQUIER preposición el verbo va en -ing:

  • good at solving problems · interested in learning
  • instead of complaining, act · before going to bed
  • thank you for helping · tired of waiting
El gerundio también funciona como sujeto: Swimming is fun. Learning English takes time. En español usamos infinitivo ("nadar"), en inglés siempre -ing.

Verbos + Infinitivo

Verbos que exigen TO + verbo base

VerboEjemplo
want / need / hopeI want to improve
decide / plan / agreeWe decided to migrate to Vue
promise / offer / refuseHe promised to help
learn / try / forget / rememberLearn to type fast. Remember to save
would like / would love / would preferI'd love to visit Japan

Patrón con persona intermedia

Muchos verbos aceptan verbo + persona + infinitivo:

  • I told him to wait. · She asked me to send it.
  • They invited us to join. · I advised her to apply.
Truco mnemotécnico: los verbos de FUTURO/DECISIÓN piden infinitivo (want, decide, plan, hope); los de DISFRUTE/EVASIÓN piden gerundio (enjoy, avoid, finish, keep).

Cambios de Significado

Los 4 verbos camaleón

Par+ Gerundio+ Infinitivo
stopStop smoking = dejar de fumarStopped to smoke = paró PARA fumar
rememberRemember locking = recuerdas haberlo hechoRemember to lock = acuerdate de hacerlo

En contexto dev

"The server stopped responding."          (dejó de responder)
"I stopped to check the logs."            (me detuve para revisar)
"Remember to commit before pulling."      (acuérdense)
"I remember pushing that branch."         (recuerdo haberlo hecho)
"Try clearing your cache."                (sugerencia)
"We tried to connect, but it timed out."  (intento fallido)

Práctica final

Elige la forma correcta:

  1. Please remember ___ (lock) the office. / I remember ___ (lock) it yesterday.
  2. He stopped ___ (drink) coffee. / He stopped ___ (buy) a coffee.
  3. If the app freezes, try ___ (restart) your phone.
