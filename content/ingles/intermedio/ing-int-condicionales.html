Zero y First Conditional

Objetivo

Hablar de reglas y consecuencias reales: la estructura que más repites al explicar lógica de negocio o código.

Zero Conditional: verdades generales

If + present simple, present simple. Para cosas siempre ciertas:

  • If you heat water to 100°C, it boils.if yú jit uó-ter tu uan-jan-dred di-grís, it bóilsSi calientas agua a 100 grados, hierve
  • If the token expires, the API returns 401.if de tóu-ken eks-páiers, di éi-pí-ái ri-térns for-óu-uanSi el token caduca, la API devuelve 401
  • If I don't sleep well, I'm tired all day.if ai dóunt slip uél, aim táierd ol déiSi no duermo bien, estoy cansado todo el día

First Conditional: futuro probable

If + present simple, will + verbo. Situaciones reales del futuro:

  • If it rains tomorrow, we'll stay home.if it réins tu-mó-rou, uíl stéi jóumSi llueve mañana, nos quedaremos en casa
  • If you finish early, you'll have time to review.if yú fí-nish ér-li, yúl jav táim tu ri-viúSi terminas temprano, tendrás tiempo de revisar
  • If she doesn't reply, I'll call her.if shi dásent ri-plái, ail kol jérSi ella no responde, la llamaré
Error típico: ❌ If it will rain... Después de if, NUNCA va will. El will vive en la otra mitad.

Variantes útiles

VarianteEjemplo Escuchar
unless = if notUnless you hurry, you'll miss it (= if you don't hurry)an-lés yú jér-i, yúl mis itA menos que te apures, lo vas a perder

Second Conditional: Hipotéticos

Futuros imaginarios o poco probables

If + past simple, would + verbo base:

  • If I had more time, I would learn Japanese.if ai jad mor táim, ai wúd lern ya-pa-nísSi tuviera más tiempo, aprendería japonés
  • If we won the lottery, we would travel the world.if uí uan de lá-te-ri, uí wúd trá-vel de uérldSi ganáramos la lotería, viajaríamos por el mundo
  • If I were you, I would accept the offer. (fórmula fija)if ai uér yú, ai wúd ak-sépt di ó-ferSi yo fuera tú, aceptaría la oferta

First vs Second: la diferencia mental

TipoCertezaEjemplo Escuchar
Firstposible, realistaIf I have time tomorrow, I'll help youif ai jav táim tu-mó-rou, ail jelp yúSi tengo tiempo mañana, te ayudaré
Secondimaginario, improbableIf I had time tomorrow, I'd help you (pero no tengo)if ai jad táim tu-mó-rou, aid jelp yúSi tuviera tiempo mañana, te ayudaría (pero no tengo)

Frases hipotéticas cotidianas

  • What would you do if you got a job offer abroad?uát wud yú du if yú gat a yab ó-fer a-bród¿Qué harías si recibieras una oferta de trabajo en el extranjero?
  • I wouldn't work there even if they paid double.ai wúdent uérk der í-ven if déi péid da-belNo trabajaría ahí aunque pagaran el doble
  • If money weren't an issue, where would you live?if mó-ni uérnt an í-shu, uér wud yú livSi el dinero no fuera un problema, ¿dónde vivirías?
En inglés formal se usa were para todas las personas: "If I were rich..."if ai uér richSi yo fuera rico. En conversación también escuchás was, pero were es lo estándar.

Third Conditional: Pasados Imaginarios

Repensar el pasado (que ya no se puede cambiar)

If + had + participio, would have + participio:

  • If I'd studied harder, I would have passed.if aid stá-did jár-der, ai wúd jav pastSi hubiera estudiado más, habría aprobado
  • If we'd left earlier, we wouldn't have missed the flight.if uíd left ér-li-er, uí wú-dent jav mist de fláitSi hubiéramos salido antes, no habríamos perdido el vuelo
  • She would have won if she hadn't fallen.shí wúd jav uan if shi jádent fó-lenElla habría ganado si no se hubiera caído

Uso profesional: post-mortems y retrospectivas

"If we had written tests, the bug wouldn't have
reached production."
"If they had told us about the deadline, we
would have prioritized differently."

Forma contraída (la que usan los nativos)

CompletaContraída Escuchar
If I had known...if aid nóunSi hubiera sabidoIf I'd known...
I would have calledai wúd jav koldHabría llamadoI've called / I'a called (woulda)
Escucharás "if I'd known, I would've helped"if aid nóun, ai wú-dav jelptSi hubiera sabido, habría ayudado. Reconoce las contracciones al escuchar; al escribir, usa las formas completas.

Mixed Conditionals

Cuando los tiempos se cruzan

A veces el tiempo de la condición y del resultado son distintos:

Las dos mezclas frecuentes

TipoEstructuraEjemplo Escuchar
Pasado → PresenteIf + past perfect, would + baseIf I'd saved money then, I would be rich nowif aid séivd mó-ni den, ai wúd bi rich náuSi hubiera ahorrado dinero entonces, sería rico ahora
Presente → PasadoIf + past simple, would have + participioIf he were braver, he would have asked her out yesterdayif jí uér bréi-ver, jí wúd jav askt jér aut yés-ter-déiSi él fuera más valiente, le habría pedido salir ayer

Truco de comprensión

No memorices la tabla: pregúntate ¿cuándo ocurre cada mitad?

  • "If I'd taken that job..." → pasado (no lo tomé)if aid téi-ken dat yabSi hubiera aceptado ese trabajo
  • "...I would be living in Canada now" → presente (no vivo ahí)ai wúd bi lí-vin in ká-na-da náuEstaría viviendo en Canadá ahora

Práctica final: los 4 condicionales seguidos

  1. Zero: If the server (go) down, the status page turns red.
  2. First: If you (send) the CV today, they'll read it this week.
  3. Second: If I (speak) perfect English, I'd apply for remote jobs.
  4. Third: If she (prepare) more, she would have nailed the interview.

Solución: goes · send · spoke · had prepared
