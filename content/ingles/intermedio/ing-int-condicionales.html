Zero y First Conditional

Objetivo

Hablar de reglas y consecuencias reales: la estructura que más repites al explicar lógica de negocio o código.

Zero Conditional: verdades generales

If + present simple, present simple. Para cosas siempre ciertas:

  • If you heat water to 100°C, it boils.
  • If the token expires, the API returns 401.
  • If I don't sleep well, I'm tired all day.

First Conditional: futuro probable

If + present simple, will + verbo. Situaciones reales del futuro:

  • If it rains tomorrow, we'll stay home.
  • If you finish early, you'll have time to review.
  • If she doesn't reply, I'll call her.
Error típico: ❌ If it will rain... Después de if, NUNCA va will. El will vive en la otra mitad.

Variantes útiles

VarianteEjemplo
unless = if notUnless you hurry, you'll miss it (= if you don't hurry)
imperativo en el resultadoIf you feel sick, go home
modal en el resultadoIf he calls, tell him I might be late

Second Conditional: Hipotéticos

Futuros imaginarios o poco probables

If + past simple, would + verbo base:

  • If I had more time, I would learn Japanese.
  • If we won the lottery, we would travel the world.
  • If I were you, I would accept the offer. (fórmula fija)

First vs Second: la diferencia mental

TipoCertezaEjemplo
Firstposible, realistaIf I have time tomorrow, I'll help you
Secondimaginario, improbableIf I had time tomorrow, I'd help you (pero no tengo)

Frases hipotéticas cotidianas

  • What would you do if you got a job offer abroad?
  • I wouldn't work there even if they paid double.
  • If money weren't an issue, where would you live?
En inglés formal se usa were para todas las personas: "If I were rich...". En conversación también escuchás was, pero were es lo estándar.

Third Conditional: Pasados Imaginarios

Repensar el pasado (que ya no se puede cambiar)

If + had + participio, would have + participio:

  • If I'd studied harder, I would have passed.
  • If we'd left earlier, we wouldn't have missed the flight.
  • She would have won if she hadn't fallen.

Uso profesional: post-mortems y retrospectivas

"If we had written tests, the bug wouldn't have
reached production."
"If they had told us about the deadline, we
would have prioritized differently."

Forma contraída (la que usan los nativos)

CompletaContraída
If I had known...If I'd known...
I would have calledI've called / I'a called (woulda)
Escucharás "if I'd known, I would've helped". Reconoce las contracciones al escuchar; al escribir, usa las formas completas.

Truco de comprensión

No memorices la tabla: pregúntate ¿cuándo ocurre cada mitad?

  • "If I'd taken that job..." → pasado (no lo tomé)
  • "...I would be living in Canada now" → presente (no vivo ahí)

Práctica final: los 4 condicionales seguidos

  1. Zero: If the server (go) down, the status page turns red.
  2. First: If you (send) the CV today, they'll read it this week.
  3. Second: If I (speak) perfect English, I'd apply for remote jobs.
  4. Third: If she (prepare) more, she would have nailed the interview.

Solución: goes · send · spoke · had prepared
