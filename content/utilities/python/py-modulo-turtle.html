¿Para qué sirve y cuándo usarla? Concepto

`turtle` es una mini-API de dibujo que mueve una "tortuga" por una ventana dejando un rastro. Es la forma clásica de aprender bucles, coordenadas, funciones y lógica espacial mientras se ve el resultado dibujado al instante.

¿Para qué se usa?

  • Mover la tortuga y dibujar con `forward`, `backward`, `left` y `right`.
  • Cambiar color, grosor y relleno de las figuras con `color`, `pensize` y `begin_fill`.
  • Repetir pasos con bucles para crear polígonos, espirales o fractales sencillos.
  • Controlar la ventana y el lápiz con `speed`, `penup` y `pendown`.

¿En qué casos conviene usarla?

  • Practicar el pensamiento algorítmico viendo cada instrucción dibujada.
  • Enseñar o aprender bucles, funciones y operaciones con ángulos.
  • Crear ejercicios visuales interactivos para alumnado principiante.

No la uses para gráficos reales: es lenta y pensada para educación. Para visualización de datos usa `matplotlib`, para animaciones `pygame` y para interfaces web `canvas` del navegador.

Import

import turtle

`turtle` es una mini-API de dibujo que mueve una "tortuga" por una ventana. Es la forma clásica de aprender loops, coordenadas y lógica espacial creando figuras visuales.

import turtle

t = turtle.Turtle()     # crea la tortuga
t.forward(100)          # avanza 100 unidades
t.left(90)              # gira 90° a la izquierda
t.forward(100)

turtle.done()           # mantiene la ventana abierta

Muévela Paso 1

import turtle

t = turtle.Turtle()
t.speed(3)                  # 1=lento ... 10=rápido

# Movimientos básicos
t.forward(80)               # avanza
t.backward(40)              # retrocede
t.right(45)                 # gira derecha 45°
t.left(90)                  # gira izquierda 90°

# Posición y dirección
t.goto(120, -60)            # ir directo a una coordenada
t.penup()                   # levanta el lápiz (no dibuja)
t.goto(-100, 100)
t.pendown()                 # vuelve a dibujar
t.home()                    # vuelve al centro (0,0) mirando al norte
# t.setheading(0)           # fija dirección en grados

turtle.done()

`forward/backward` desplazan y `left/right` rotan. `penup/pendown` permiten volar sin dibujar, y `home()` resetea posición y rumbo. Todo se mide en pasos y grados.

Figuras y Colores Paso 2

import turtle

t = turtle.Turtle()

# Cuadrado
for _ in range(4):
    t.forward(100)
    t.left(90)

# Colores básicos
t.pencolor("red")            # color del trazo
t.fillcolor("dodgerblue")    # color de relleno

t.begin_fill()               # empieza a rellenar
for _ in range(3):
    t.forward(120)
    t.left(120)
t.end_fill()                 # rellena el triángulo

# Grosor y estilo
t.pensize(4)
t.pencolor("#f59e0b")

# Dibujar un círculo
t.circle(60)                 # radio 60
t.circle(60, 180)            # medio círculo

turtle.done()

Los colores aceptan nombres (`"red"`), hex (`"#f59e0b"`) o RGB. `begin_fill`/`end_fill` rellenan la forma cerrada dibujada entre medias. `circle(r)` y `circle(r, ángulo)` dibujan arcos.

Bucles y Fractales Paso 3

import turtle

t = turtle.Turtle()
t.speed(10)

# Polígono regular con un solo bucle
lados = 8
largo = 90
for _ in range(lados):
    t.forward(largo)
    t.left(360 / lados)      # los giros suman 360°

# Espiral con tamaño creciente
for i in range(1, 30):
    t.forward(i * 4)
    t.left(15)

# Estrella con colores
paleta = ["red", "yellow", "blue", "green", "purple"]
for giro in range(5):
    t.pencolor(paleta[giro % len(paleta)])
    t.forward(120)
    t.right(144)             # constante angular de la estrella

turtle.done()

Los polígonos salen de "gira 360/lados cada vez". Con esta idea haces mandalas, espirales y estrellas. Cuidado: `speed(0)` dibuja a máxima velocidad (con `tracer(0)` + `update()` para instantáneo).

Eventos con el Teclado Paso 4

import turtle

t = turtle.Turtle()
t.speed(0)

def avanzar():
    t.forward(30)

def girar_izq():
    t.left(15)

def girar_der():
    t.right(15)

def volver():
    t.home()

# Vincular teclas
turtle.listen()
turtle.onkey(avanzar, "space")     # pasa una FUNCIÓN, no llames con ()
turtle.onkeypress(girar_izq, "Left")
turtle.onkeypress(girar_der, "Right")
turtle.onkey(volver, "h")

turtle.done()

`onkey`/`onkeypress` reciben la función sin paréntesis (tipo `avanzar`, no `avanzar()`). Para mantenerla pulsada usa `onkeypress`. Termina siempre con `turtle.done()` o `mainloop()` para que la ventana siga escuchando.

Ejercicios prácticos Reto

  1. Dibuja un cuadrado, un pentágono y un hexágono con un solo bucle parametrizado.
  2. Crea una casa: dos cuadrados (paredes) + un triángulo (techo).
  3. Haz una espiral que crezca de 10 a 200 pasos.
  4. Dibuja una estrella de 5 puntas con colores por punta.
  5. Convierte el modelo en un mini-juego: mueve la tortuga con las flechas y la tecla espacio.
