¿Para qué sirve y cuándo usarla? Concepto

`datetime` es la forma correcta de trabajar con fechas y horas en Python: crear fechas, calcular diferencias con `timedelta`, manejar zonas horarias y convertir entre objetos y texto para logs, APIs o bases de datos.

¿Para qué se usa?

  • Obtener la fecha u hora actual y construir fechas a medida con `date` y `datetime`.
  • Sumar y restar días, semanas o meses con `timedelta` sin errores de rango.
  • Formatear a texto con `strftime` y analizar cadenas con `strptime`.
  • Comparar fechas, calcular antigüedades o saber el día de la semana de una fecha.

¿En qué casos conviene usarla?

  • Registrar timestamps en logs y filenames finalizados en fecha.
  • Calcular vencimientos, plazos o antigüedad de registros en una app.
  • Convertir fechas de un JSON o CSV hacia el tipo `date` para compararlas.

Para medir tiempos de ejecución usa `time.perf_counter`, no `datetime`: no está pensado para crono precisos. Y para zonas horarias complejas tira de `zoneinfo` con la base de datos IANA en vez de saltos manuales de horas.

---

Fechas y Horas Base

Import

from datetime import date, datetime, timedelta, timezone

hoy = date.today()                 # 2026-08-29
ahora = datetime.now()             # 2026-08-29 14:30:00.123456
utc = datetime.now(timezone.utc)   # con zona horaria

`datetime` reúne `date` (año-mes-día), `time` (hora) y `datetime` (ambos), más `timedelta` para matemática de duraciones. Todo en la biblioteca estándar.

---

Crear y Operar Paso 1

from datetime import date, datetime, timedelta

# Crear fechas y horas concretas
fecha = date(2026, 8, 29)
momento = datetime(2026, 8, 29, 14, 30, 0)

# Leer componentes
fecha.year      # 2026
fecha.month     # 8
fecha.day       # 29
momento.hour    # 14
momento.minute  # 30
momento.second  # 0

# Día de la semana: 0 = lunes ... 6 = domingo
fecha.weekday()     # 5 (sábado)
fecha.isoweekday()  # 6 (según ISO, lunes = 1)

# Sumar y restar
fecha + timedelta(days=7)               # una semana después
momento - timedelta(hours=2)            # hace 2 horas

`timedelta` suma días/horas/minutos/segundos a fechas e instantes y es **inmutable** al igual que date/datetime: las operaciones devuelven objetos nuevos.

---

Formato y Parseo Paso 2

from datetime import datetime

ahora = datetime.now()

# Dar formato a una fecha: strftime
ahora.strftime("%Y-%m-%d")          # '2026-08-29'
ahora.strftime("%d/%m/%Y")          # '29/08/2026'
ahora.strftime("%H:%M:%S")          # '14:30:00'
ahora.strftime("%A, %d de %B de %Y")  # 'sábado, 29 de agosto de 2026'

# Leer una fecha desde texto: strptime
fecha_texto = "2026-08-29"
fecha = datetime.strptime(fecha_texto, "%Y-%m-%d")

# ISO (muy usado en APIs)
ahora.isoformat()                   # '2026-08-29T14:30:00.123456'
datetime.fromisoformat("2026-08-29T14:30:00")

`strftime` convierte fechas -> texto y `strptime` texto -> fecha. La directiva debe coincidir con el texto real: `%d` es día, `%m` mes en número, `%B` el nombre completo, `%A` el día de la semana.

timedelta: duraciones Paso 3

from datetime import date, datetime, timedelta

# Crear duraciones
semana = timedelta(days=7)
duracion = timedelta(hours=2, minutes=30)

# Operar con fechas
inicio = date(2026, 1, 1)
fin = inicio + timedelta(days=100)

# Diferencia entre fechas (da un timedelta)
delta = fin - inicio
delta.days                     # 100
delta.total_seconds()          # 8640000.0

# Ejemplo real: vencimiento de licencia
hoy = date.today()
licencia = date(2026, 9, 30)
dias_restantes = (licencia - hoy).days
print(f"Tu licencia vence en {dias_restantes} días")

`timedelta` maneja días, horas, segundos y microsegundos. Si necesitas "hace 3 meses" o "el próximo lunes", `relativedelta` (del paquete `dateutil`) añade lo que falta: `pip install python-dateutil`.

Aplicaciones Prácticas Paso 4

from datetime import datetime, timedelta, timezone

# Zonas horarias
from zoneinfo import ZoneInfo
lima = datetime.now(ZoneInfo("America/Lima"))
tokyo = lima.astimezone(ZoneInfo("Asia/Tokyo"))

# Calcular cuánto tardó una tarea
t0 = datetime.now()
# ... hacer algo ...
t1 = datetime.now()
print(f"Tomó {t1 - t0}")

# Primer y último día del mes actual
hoy = datetime.now().date()
primero = hoy.replace(day=1)
ultimo = (primero + timedelta(days=31)).replace(day=1) - timedelta(days=1)

# Vencer cookies / tokens
expira = datetime.now(timezone.utc) + timedelta(days=30)

Con `ZoneInfo` (py3.9+) manejas zonas horarias reales del IANA. Para medir tiempos usa `datetime` (o mejor `time.perf_counter` para micro-segundos) y registra fechas de expiración siempre en **UTC**.
