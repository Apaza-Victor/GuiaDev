¿Para qué sirve y cuándo usarla? Concepto

`math` es la caja de herramientas matemáticas de la biblioteca estándar: constantes como `pi` y `e`, funciones trigonométricas, logaritmos, redondeos, potencias y operaciones de teoría de números, todas optimizadas en C.

¿Para qué se usa?

  • Usar constantes y funciones trigonométricas con `pi`, `sin`, `cos`, `tan`.
  • Redondear con criterios comerciales o de mercado con `floor`, `ceil` y `trunc`.
  • Calcular raíces, potencias y logaritmos con `sqrt`, `pow` y `log`.
  • Hacer cálculos de teoría de números con `gcd`, `lcm`, `factorial` y `comb`.

¿En qué casos conviene usarla?

  • Cálculos geométricos o de estadística sencilla dentro de un script.
  • Comprobar divisibilidad o generar combinaciones sin recursión manual.
  • Redondeos de precios o mediciones donde importan los decimales.

Para vectores y matrices usa `numpy`, `math` opera número a número. Y cuando necesites precisión decimal exacta (dinero), tira de `decimal` en vez de floats.

---

Importar math Base

Import

import math

# O funciones sueltas
from math import sqrt, ceil, floor, pi

`math` expone constantes y funciones matemáticas (aritmética, trigonometría, logaritmos, combinatoria) en C puro: rápida y parte de la biblioteca estándar, sin instalar nada.

---

Constantes y Redondeo Paso 1

import math

math.pi        # 3.141592653589793
math.e         # 2.718281828459045
math.tau       # 6.283185307179586 (2π)
math.inf       # infinito
math.nan       # no es un número
math.tau / 2   # equivalente a pi

# Redondeo
math.ceil(3.1)     # 4   (hacia arriba)
math.floor(3.9)    # 3   (hacia abajo)
math.trunc(3.9)    # 3   (trunca)
math.fabs(-5)      # 5.0 (valor absoluto)
math.copysign(3, -1)  # -3.0 (magnitud de 3, signo de -1)

`ceil`/`floor` redondean hacia el entero más cercano arriba/abajo; `trunc` ignora los decimales. Para configurar píxeles de UI casi siempre querrás `ceil` ("no quepo si bajo").

Potencias y Raíces Paso 2

import math

math.sqrt(144)            # 12.0  raíz cuadrada
math.isqrt(150)           # 12    raíz entera (rápida, sin flotantes)
math.pow(2, 10)           # 1024.0 (siempre flotante)
2 ** 10                   # 1024   (int, preferible en Python)
math.cbrt(27)             # 3.0    raíz cúbica
math.hypot(3, 4)          # 5.0    √(a²+b²), distancia euclidiana

# Distancia entre dos puntos del plano
distancia = math.hypot(x2 - x1, y2 - y1)

# Factorial -- ejemplo: cuántas formas de ordenar a 5 personas
math.factorial(5)         # 120

`pow` devuelve float, `**` mantiene int (mejor para números enteros grandes). `hypot` evita desbordes al calcular distancias. Para signos en cálculos, `math.copysign` es tu amigo.

Trigonometría Paso 3

import math

angulo = math.radians(60)        # convierte grados -> radianes
math.degrees(angulo)             # 60.0 radianes -> grados

math.sin(math.radians(30))       # 0.49999...
math.cos(math.radians(60))       # 0.50000...
math.tan(math.radians(45))       # ~1.0

# Inversas
math.asin(1)                     # π/2
math.atan2(4, 3)                 # ángulo del vector (3,4)

# Posición de un punto en un círculo
radio, t = 100, math.radians(90)
x = radio * math.cos(t)
y = radio * math.sin(t)

Las funciones trigonométricas trabajan SIEMPRE en **radianes**: convierte con `radians()` o `degrees()` explícitamente. Un error clásico es pasar grados sin convertir y recibir ángulos sin sentido.

Logaritmos y Combinatoria Paso 4

import math

math.log(1000)             # logaritmo natural (base e) ≈ 6.9077
math.log(1000, 10)         # log en base 10 = 3.0
math.log2(8)               # 3.0
math.log10(100000)         # 5.0

# Combinaciones y permutaciones
math.comb(49, 6)           # 13983816 (lotería: combinaciones)
math.perm(10, 3)           # 720 (permutaciones de 10 tomadas de 3)

# Producto y suma de precisión
math.fsum([0.1, 0.2, 0.3]) # 0.6 exacto (vs float(0.1+0.2+0.3))
math.prod([1, 2, 3, 4])    # 24  (producto de una lista)

`comb`/`perm` evitan fórmulas a mano y Python 3.8+ con `math.fsum` y `math.prod` dan resultados numéricos estables. Los logaritmos son la herramienta para medir complejidad de algoritmos y magnitudes (sonido, terremotos).
