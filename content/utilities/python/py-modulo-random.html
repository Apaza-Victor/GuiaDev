¿Para qué sirve y cuándo usarla? Concepto

`random` genera números pseudoaleatorios con distribución uniforme o controlada: sirve para elegir elementos al azar, mezclar listas, simular dados o crear datos de prueba. Los valores se basan en el Mersenne Twister, así que el resultado depende de la semilla inicial.

¿Para qué se usa?

  • Generar números en un rango con `random()`, `randint` y `uniform`.
  • Elegir al azar con `choice`, `choices` (con pesos) y `sample` sin repetición.
  • Revolver una lista en el sitio con `shuffle`.
  • Reproducir resultados fijando la semilla con `seed`, útil en demos y tests.

¿En qué casos conviene usarla?

  • Juegos, sorteos y decisiones aleatorias simples dentro de un script.
  • Generar datasets sintéticos o mutar inputs en pruebas.
  • Simulaciones de Monte Carlo mientras el volumen y la precisión lo permitan.

Nunca uses `random` para contraseñas, tokens o cualquier cosa relacionada con seguridad: no es criptográficamente seguro. Para eso existe el módulo `secrets`.

Importar random Base

Import

import random

# O funciones concretas
from random import randint, choice, shuffle

`random` forma parte de la biblioteca estándar de Python: genera números pseudoaleatorios, elige elementos de secuencias y baraja colecciones. Es la base para juegos, sorteos y simulaciones.

---

Números Aleatorios Paso 1

import random

random.random()                 # flotante en [0.0, 1.0)
random.uniform(10, 20)          # flotante en [10, 20]
random.randint(1, 6)            # entero entre 1 y 6 (LANZAR DADO)
random.randrange(0, 100, 5)     # entero: 0, 5, 10, ... 95 (paso 5)

# Precisión decimal para dinero o notas
random.uniform(8, 20)           # nota de una evaluación
round(random.uniform(0, 10), 2) # nota con 2 decimales

`random()` nunca alcanza 1.0, `randint` incluye ambos extremos y `randrange` respeta el paso (como `range`). Para números "nada de juego" usa `secrets` (criptográfico).

Elección y Muestreo Paso 2

import random

alumnos = ["Ana", "Bruno", "Carla", "Diego", "Elena"]

random.choice(alumnos)                  # un elemento al azar
random.choices(alumnos, k=2)            # con reposición (puede repetir)
random.sample(alumnos, 3)               # sin reposición (únicos)

# Con pesos: gana "panqueque" el 90% de las veces
amenaza = random.choices(
    ["panqueque", "bomba"],
    weights=[90, 10],
    k=1
)[0]

`choice` elige uno, `sample` da un subconjunto único y `choices` permite repeticiones con `weights` (control de probabilidad). Ideal para sorteos justos o misiones aleatorias en juegos.

Barajar y Distribuciones Paso 3

import random

cartas = [f"{n} de {pal}" for pal in ("corazones", "diamantes", "tréboles", "picas")
                             for n in range(1, 14)]
random.shuffle(cartas)          # mezcla IN-PLACE (modifica la lista)
mano = cartas[:2]

# Distribuciones (crear datos "realistas")
random.gauss(mu=175, sigma=8)   # estaturas (campana)
random.expovariate(1.0 / 60)    # tiempos de espera
random.paretovariate(alpha=2)   # ingresos (cola larga)

`shuffle` modifica la lista original y no devuelve nada (ojo al mezclar la lista "maestra"). Para datos con forma de curva normal, `gauss`/`normalvariate` reproducen poblaciones reales mejor que `uniform`.

Simular con Semilla Paso 4

import random

random.seed(42)                 # fija la secuencia
print(random.randint(1, 100))   # SIEMPRE el mismo número
print(random.choice(["a", "b", "c"]))

# Volver a empezar: misma semilla = misma secuencia
random.seed(42)
print(random.randint(1, 100))   # idéntico al primero

# Simulación: lotería sin repetidos
random.seed(20260501)
numeros = random.sample(range(1, 46), 6)
print(sorted(numeros))

La semilla hace reproducible la "aleatoriedad": tests, demos y análisis que dependen del azar devuelven siempre lo mismo. Sin `seed()`, Python usa la hora del sistema. Usa `SystemRandom` / `secrets` si necesitas verdadera imprevisibilidad.
