¿Para qué sirve y cuándo usarla? Concepto

`argparse` convierte tus scripts en herramientas de línea de comandos reales: define argumentos posicionales, opciones con valor y flags booleanos, y genera automáticamente la ayuda con `--help` y los errores cuando falta algún dato.

¿Para qué se usa?

  • Recibir argumentos desde la consola, como `python app.py datos.csv --limite 100`.
  • Declarar opciones con tipo (`int`, `float`, `bool`) que Python valida antes de ejecutar.
  • Mostrar ayuda y mensajes de error sin escribir ni una línea extra de texto.
  • Construir CLIs con subcomandos (estilo git o pip) mediante subparsers.

¿En qué casos conviene usarla?

  • Cuando un script necesita más de uno o dos parámetros y quieres nombrarlos con claridad.
  • Cuando quieres que los fallos de uso se expliquen solos al usuario final.
  • Cuando distribuyes una herramienta que otros ejecutarán desde su terminal.

Si solo lees un parámetro, `sys.argv` o una variable de entorno bastan. Y si la CLI crece demasiado, `click` o `typer` ofrecen una sintaxis más declarativa y ergonómica.

---

Primer parser Paso 1

import argparse

parser = argparse.ArgumentParser(
    description="Saluda a un usuario desde la consola"
)
parser.add_argument("nombre", help="nombre a saludar")

args = parser.parse_args()
print(f"Hola, {args.nombre}")

Uso

python app.py Ana
# Hola, Ana

python app.py
# error: the following arguments are required: nombre

Cada `add_argument` declara una pieza de la CLI. Al ejecutar `parse_args()` obtienes un objeto con los atributos (`.nombre` en este caso) y Python lanza ayuda y errores automáticamente.

Tipos y Valores por Defecto Paso 2

import argparse

parser = argparse.ArgumentParser()
parser.add_argument("--edad", type=int, default=18,
                    help="edad del usuario")
parser.add_argument("--precio", type=float, required=True)
parser.add_argument("--tamaño", choices=["small", "medio", "grande"])

args = parser.parse_args()

print(args.edad)       # 18 si no se pasa
print(args.precio)     # obligatorio: falla sin él
print(args.tamaño)     # None si no se usa

python app.py --edad 25 --precio 9.99 --tamaño medio
python app.py --precio 9.99 --tamaño extra   # error: invalid choice

Con `type=` argparse convierte el texto automáticamente (int, float, Path...), con `default=` define el valor si no se pasa y `required=True` obliga a pasarlo. `choices` valida la lista permitida.

Flags Booleanos Paso 3

import argparse

parser = argparse.ArgumentParser()
parser.add_argument("-v", "--verboso", action="store_true",
                    help="muestra información extra")
parser.add_argument("-q", "--quieto", action="store_true")
args = parser.parse_args()

if args.verboso:
    print("Modo detallado activado")

# Alternativa compacta para dos caminos
parser = argparse.ArgumentParser()
g = parser.add_mutually_exclusive_group()
g.add_argument("-v", "--verbose", action="store_true")
g.add_argument("-q", "--quiet", action="store_true")

`action="store_true"` crea un flag booleano: `-v`/`--verboso` pone `True`, ausente pone `False`. Un `add_mutually_exclusive_group` prohíbe pasar `-v` y `-q` juntos (arbitraje de conflictos gratis).

Mejora la Experiencia Paso 4

import argparse

parser = argparse.ArgumentParser(
    prog="deploy",
    description="Sube la app a un entorno",
    epilog="Ejemplo: python deploy.py -e prod --no-deps"
)
parser.add_argument("entorno", choices=["dev", "staging", "prod"])
parser.add_argument("--no-deps", action="store_true",
                    help="no instalar dependencias")
parser.add_argument("--timeout", type=int, default=60,
                    help="tiempo límite en segundos (default: %(default)s)")

args = parser.parse_args()
print(f"Desplegando en {args.entorno}...")
if args.no_deps:
    print("Omitiendo dependencias")

# El texto de ayuda ya incluye los defaults y ejemplos
# python deploy.py -h

`%(default)s` interpola el valor por defecto dentro del texto de ayuda, `epilog` añade ejemplos al final y `prog` renombra el comando mostrado. La CLI queda profesional sin escribir nada más.
