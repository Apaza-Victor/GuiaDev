¿Para qué sirve y cuándo usarla? Concepto

`json` es el puente entre los objetos de Python y el formato JSON, el estándar de intercambio de datos en APIs y configuraciones. Con `dumps` y `loads` serializas y deserializas datos en una sola llamada, sin librerías externas.

¿Para qué se usa?

  • Convertir un dict o lista a texto JSON con `json.dumps` (con `indent` para leerlo).
  • Analizar la respuesta de una API o un fichero JSON con `json.loads` y `json.load`.
  • Guardar y recuperar configuración o estado de una app en un fichero legible.
  • Controlar el formato con parámetros como `sort_keys`, `ensure_ascii` o claves propias.

¿En qué casos conviene usarla?

  • Consumir o exponer APIs: la mayoría devuelven y aceptan JSON.
  • Mantener configuraciones de proyecto que sean fáciles de revisar y versionar.
  • Intercambiar datos entre servicios escritos en distintos lenguajes.

No uses el módulo `pickle` para intercambiar datos: no es seguro y no es interoperable. Si el JSON es enorme o fluye de forma continua, valora `ijson` para streaming o `orjson` si necesitas máxima velocidad.

Serializar con dumps Paso 1

import json

usuario = {
    "nombre": "Ana",
    "edad": 30,
    "activo": True,
    "hobbies": ["leer", "correr"],
    "nada": None
}

# Python -> texto JSON
texto = json.dumps(usuario)
print(texto)
# '{"nombre": "Ana", "edad": 30, "activo": true, "hobbies": ["leer", "correr"], "nada": null}'

# Opciones útiles
json.dumps(usuario, indent=2)         # formateado bonito
json.dumps(usuario, ensure_ascii=False)   # "ñ" / "á" no escapadas
json.dumps(usuario, sort_keys=True)   # claves ordenadas

`dumps` da una cadena; `dump` escribe a un archivo. `ensure_ascii=False` es imprescindible si tu JSON lleva tildes o ñ y quieres texto legible.

Deserializar con loads Paso 2

import json

texto = '{"nombre": "Ana", "edad": 30, "activo": true}'

# JSON -> Python
datos = json.loads(texto)
datos["nombre"]       # 'Ana'
datos["activo"]       # True (bool de Python)

# JSON contiene listas y arrays anidados
respuesta = json.loads('{"resultado": [1, 2, 3], "ok": true}')
respuesta["resultado"]   # [1, 2, 3]

# Tupes y fechas NO vienen listos: hay que convertir
json.loads('{"fecha": "2026-08-29"}')["fecha"]   # str, no date

`loads` recibe una cadena; `load` lee desde un archivo. Los booleans llegan como `True/False` correctamente, pero fechas y `tuple` llegan como texto/listas: tendrás que convertirlos a mano.

Archivos con load y dump Paso 3

import json

# Guardar un diccionario en un archivo
config = {"tema": "dark", "volumen": 0.8, "guardado": True}
with open("config.json", "w", encoding="utf-8") as f:
    json.dump(config, f, indent=2, ensure_ascii=False)

# Leer de vuelta
with open("config.json", "r", encoding="utf-8") as f:
    datos = json.load(f)

print(datos["tema"])       # 'dark'

# Guardar una lista de registros (típico de exportar)
usuarios = [{"id": 1, "nombre": "Ana"}, {"id": 2, "nombre": "Bruno"}]
with open("usuarios.json", "w", encoding="utf-8") as f:
    json.dump(usuarios, f, indent=2, ensure_ascii=False)

`dump`/`load` trabajan con archivos: abre siempre con `encoding="utf-8"` para que los acentos se lean bien. Son la base para persistir configuraciones o exportar datos.

Errores y Opciones Paso 4

import json

# JSON mal formado lanza JSONDecodeError
try:
    json.loads('{"nombre": "Ana",}')
except json.JSONDecodeError as e:
    print(f"JSON inválido en línea {e.lineno}: {e.msg}")

# Parsear de forma tolerante con default
def fecha_a_str(obj):
    if hasattr(obj, "isoformat"):
        return obj.isoformat()
    raise TypeError(f"Tipo {type(obj)} no serializable")

from datetime import datetime
payload = {"creado": datetime.now()}
print(json.dumps(payload, default=fecha_a_str, indent=2))

# ¿Papelera? skipkeys para claves no str
json.dumps({("a", "b"): 1}, skipkeys=True)   # {} sin error

Para tipos como `datetime`, `Decimal` o clases propias, pasa una función `default` que los convierta. Atrapar `JSONDecodeError` es obligatorio al consumir datos que vienen de fuera (APIs).
