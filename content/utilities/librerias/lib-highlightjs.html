¿Para qué sirve y cuándo usarla? Concepto

highlight.js aplica resaltado de sintaxis a bloques de código en más de 190 lenguajes. Detecta el lenguaje automáticamente o mediante la clase `language-*`, y en producción se usa el core con gramáticas registradas a mano para reducir el peso.

¿Para qué se usa?

  • Resaltar código en documentación, blogs o tutoriales con una sola llamada.
  • Usar detección automática para bloques sin lenguaje declarado.
  • Registrar solo los lenguajes necesarios con `hljs.registerLanguage`.
  • Cambiar el aspecto con themes CSS: github, atom-one-dark, etc.

¿En qué casos conviene usarla?

  • Sitios de documentación que muestran snippets de código constantemente.
  • Blogs técnicos con tutoriales en múltiples lenguajes.
  • Aplicaciones que renderizan respuestas de API con fragmentos de código.

La detección automática consume CPU y falla en fragmentos cortos; declara siempre `language-*` cuando sepas el lenguaje. Para editores de código en vivo, Prism o Shiki son alternativas según el caso.

Import

import hljs from 'highlight.js/lib/core';
import javascript from 'highlight.js/lib/languages/javascript';
hljs.registerLanguage('javascript', javascript);

highlight.js resalta 190+ lenguajes con detección automática. Para producción se recomienda el `core` + registro manual de gramáticas: mucho más ligero que el bundle completo.

Uso Básico Paso 2

<pre><code class="language-javascript">
  const saludar = (n) => `Hola ${n}`;
</code></pre>

// Resaltar todos los bloques con language-*
document.querySelectorAll('pre code').forEach((block) => {
  hljs.highlightElement(block);
});

// Por API directa (devuelve HTML escapado)
const html = hljs.highlight('const x = 1;', { language: 'javascript' }).value;

// Detección automática si no hay clase language-
const resaltado = hljs.highlightAuto(codigo);

Usa la clase `language-*` explícita siempre que sepas el lenguaje: la detección automática consume más CPU y puede fallar en fragmentos cortos.

Lenguajes Parciales y Alias Paso 3

import hljs from 'highlight.js/lib/core';
import bash from 'highlight.js/lib/languages/bash';
import python from 'highlight.js/lib/languages/python';
import sql from 'highlight.js/lib/languages/sql';

hljs.registerLanguage('bash', bash);
hljs.registerLanguage('python', python);
hljs.registerLanguage('sql', sql);

// Alias: una misma gramática con otros nombres de clase
hljs.registerAliases(['sh', 'shell'], { languageName: 'bash' });

// Cargar una gramática bajo demanda (code splitting)
async function highlight(bloque) {
  const lang = bloque.className.match(/language-(\w+)/)?.[1];
  if (lang && !hljs.getLanguage(lang)) {
    const mod = await import(`highlight.js/lib/languages/${lang}`);
    hljs.registerLanguage(lang, mod.default);
  }
  hljs.highlightElement(bloque);
}

El registro bajo demanda permite mantener el bundle inicial pequeño y cargar solo las gramáticas que encuentres en la página.

Temas y Personalización Paso 4

/* Temas disponibles (styles/): github, atom-one-dark, dracula, nord, tokyo-night... */
@import 'highlight.js/styles/atom-one-dark.css';

/* Tema manual: sobrescribir variables de color */
.hljs {
  background: #1e1e2e;
  color: #cdd6f4;
}
.hljs-keyword { color: #cba6f7; }
.hljs-string  { color: #a6e3a1; }
.hljs-number  { color: #fab387; }

/* Cambiar tema claro/oscuro con media query */
@media (prefers-color-scheme: dark) {
  .hljs { background: #1e1e2e; color: #cdd6f4; }
}

Los temas son archivos CSS: puedes alternarlos por media query, atributo `data-theme` o clase en el `` sin tocar JavaScript.

Integración con Marcos y SEO Paso 5

// React: resaltar al montar (useEffect) y al cambiar contenido
function CodeBlock({ code, lang }) {
  const ref = useRef();
  useEffect(() => {
    const el = ref.current;
    if (el) {
      delete el.dataset.highlighted;
      hljs.highlightElement(el);
    }
  }, [code]);
  return <pre><code ref={ref} className={`language-${lang}`}>{code}</code></pre>;
}

// Contenido dinámico (SPA): re-resaltar los frentes nuevos
function renderizado() {
  document.querySelectorAll('pre code:not([data-highlighted])').forEach(hljs.highlightElement);
}

// Evitar doble resaltado
// highlight.js marca `data-highlighted="yes"` automáticamente; respétalo en el selector

Marca con `data-highlighted` (lo pone la librería) y siempre re-ejecuta el resaltado tras cambios en el DOM. Evita el doble resaltado consultando `:not([data-highlighted])`.
