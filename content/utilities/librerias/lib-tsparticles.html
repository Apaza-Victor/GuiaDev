¿Para qué sirve y cuándo usarla? Concepto

tsParticles genera fondos de partículas configurables: confeti, lluvia, luciérnagas, conexiones de red o estrellas. Es el sucesor moderno de particles.js, con presets listos, soporte para frameworks y render en canvas o WebGL.

¿Para qué se usa?

  • Crear fondos animados de partículas en segundos con una config JavaScript.
  • Usar presets listos (firefly, confetti, links, snow) cargados por módulo.
  • Configurar interacciones: velocidad, gravedad, colisiones y reacción al mouse.
  • Integrar en React, Vue o Svelte con los paquetes oficiales.

¿En qué casos conviene usarla?

  • Landing pages y hero sections con fondos vivos y branding propio.
  • Celebraciones o estados de carga con confeti o lluvia animada.
  • Webs de presentación que buscan un toque visual distintivo.

Un fondo de partículas permanente lastra el rendimiento y puede distraer al usuario. Úsalo como acento puntual. Para físicas muy específicas o controles a medida, valora una solución propia con canvas.

Configuración Básica Paso 2

// Instancia en modo bundle (window.tsParticles)
tsParticles.load('fondo', {
  particles: {
    number: { value: 80 },
    move: { enable: true, speed: 1.5 },
    opacity: { value: 0.6 },
    size: { value: { min: 1, max: 4 } }
  }
});

import { loadSlim } from '@tsparticles/slim';
import { tsParticles } from '@tsparticles/engine';

async function init() {
  await loadSlim(tsParticles);
  await tsParticles.load('fondo', {
    particles: { number: { value: 80 }, move: { enable: true } }
  });
}

HTML

<div id="fondo" style="position:absolute; inset:0; z-index:-1"></div>

El contenedor recibe las partículas; `fullScreen.enable: true` los convierte en un canvas fijo de toda la pantalla. Recuerda subir el `z-index` del contenido para que el fondo quede detrás.

Formas y Colores Paso 3

tsParticles.load('fondo', {
  particles: {
    color: { value: ['#f59e0b', '#fbbf24', '#fde68a'] },
    shape: {
      type: ['circle', 'square', 'star'],
      options: { star: { sides: 5 } }
    },
    size: { value: { min: 2, max: 8 } },
    number: { value: 110 },
    opacity: {
      value: { min: 0.2, max: 0.9 },
      animation: { enable: true, speed: 1 }
    },
    move: {
      enable: true,
      speed: 2,
      direction: 'top',       // suben como ceniza
      outModes: 'out'
    }
  }
});

Puedes mezclar tipos de forma y paletas de color en arrays. `opacity.animation` pulsa el brillo de cada partícula, dando sensación de vida al fondo.

Interacción con el Mouse Paso 4

tsParticles.load('fondo', {
  fullScreen: { enable: true },
  particles: {
    number: { value: 90 },
    color: { value: '#38bdf8' },
    shape: { type: 'circle' },
    size: { value: { min: 1, max: 4 } },
    move: {
      enable: true,
      speed: 2,
      links: { enable: true, distance: 140, color: '#3b82f6', opacity: 0.4 }
    }
  },
  interactivity: {
    events: {
      onHover: { enable: true, mode: 'bubble' },
      onClick: { enable: true, mode: 'repulse' }
    },
    modes: {
      bubble: { distance: 160, size: 8, duration: 0.4 },
      repulse: { distance: 180, duration: 0.4 }
    }
  },
  background: { color: '#0f172a' }
});

`links` une partículas cercanas (efecto "red de nodos"). Con `interactivity` el cursor agranda (`bubble`) o empuja (`repulse`) las partículas al pasar o hacer clic.

Rendimiento y Múltiples Instancias Paso 5

// Reducir número de partículas en móviles
const ligero = matchMedia('(prefers-reduced-motion: reduce)').matches;

tsParticles.load('fondo', ligero
  ? { particles: { number: { value: 20 }, move: { enable: false } } }
  : { particles: { number: { value: 110 }, move: { enable: true } } });

// Múltiples instancias separadas
tsParticles.load('confeti-a', { ...confeti });
tsParticles.load('confeti-b', { ...confeti });

// Destruir y recrear cuando hace falta
tsParticles.dom().forEach((p) => p.destroy());
await tsParticles.load('fondo', nuevaConfig);

// Preset aleatorio de partículas
await loadRandom(tsParticles);
await tsParticles.load('random', { preset: 'random' });

/* El canvas de partículas no debe bloquear la interacción */
#fondo canvas { pointer-events: none; }

Para fondos decorativos, `prefers-reduced-motion` o bajar la densidad en móviles marca la diferencia de batería. `pointer-events: none` evita que el canvas robe clics y scroll al contenido de arriba.

Ejercicios prácticos Reto

  1. Carga el preset `firefly` y haz un fondo de luciérnagas doradas para un hero.
  2. Configura partículas en forma de estrella que suban lentamente como ceniza.
  3. Añade el modo `bubble` al hover y `repulse` al clic.
  4. Crea dos instancias en distintas secciones de la misma página.
  5. Desactiva las partículas si el usuario prefiere `prefers-reduced-motion`.
