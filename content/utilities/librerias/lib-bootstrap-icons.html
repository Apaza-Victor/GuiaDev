¿Para qué sirve y cuándo usarla? Concepto

Bootstrap Icons es un set de iconos SVG open source creado por el equipo de Bootstrap. Se usa como fuente de iconos mediante clases `bi` o como SVG individuales, con estilos coherentes y sin depender de JavaScript.

¿Para qué se usa?

  • Insertar iconos de UI (flechas, redes, acciones) con la clase `bi bi-nombre`.
  • Escalar y colorear iconos con propiedades de tipografía: font-size y color.
  • Usar iconos como SVG inline para rutas, colores y efectos más avanzados.
  • Acompañar botones, enlaces y formularios con símbolos claros.

¿En qué casos conviene usarla?

  • Proyectos que ya usan Bootstrap y quieren una familia de iconos coherente.
  • Formularios y navegación que necesitan iconos de forma consistente.
  • Prototipos rápidos que evitan gestionar recursos SVG a mano.

Si precisas iconos de marca o un catálogo mucho más amplio, Font Awesome ofrece más cobertura. También valora iconos SVG unitarios con tree-shaking cuando el peso del bundle importa mucho.

import 'bootstrap-icons/font/bootstrap-icons.css';

Opción 3: HTML

<!DOCTYPE html>
<html>
<head>
  <!-- Usando CDN -->
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.10.0/font/bootstrap-icons.css">
  
  <!-- O usando archivo local -->
  <link rel="stylesheet" href="/node_modules/bootstrap-icons/font/bootstrap-icons.css">
</head>
<body>
  <!-- Usando clases CSS -->
  <i class="bi bi-heart-fill"></i>
  
  <!-- Usando SVG -->
  <svg class="bi" width="32" height="32">
    <use xlink:href="#heart-fill"/>
  </svg>
</body>
</html>

Uso con Módulos

// Importar estilos
import 'bootstrap-icons/font/bootstrap-icons.css';

// Crear un icono dinámicamente
function createIcon(name, size = '1em') {
  const icon = document.createElement('i');
  icon.className = `bi bi-${name}`;
  icon.style.fontSize = size;
  return icon;
}

// Ejemplo de uso
const heartIcon = createIcon('heart-fill', '2em');
document.body.appendChild(heartIcon);

Vue.js

<style>
@import 'bootstrap-icons/font/bootstrap-icons.css';
</style>

<script>
export function Icon({ name, size = '1em', className = '' }) {
  return (
    <i 
      className={\`bi bi-\${name} \${className}\`}
      style={{ fontSize: size }}
    />
  )
}

// Uso
<Icon name="heart" size="2em" className="text-danger" />
</script>

Personalización Paso 5

CSS Custom Properties

/* styles/custom.css */
.bi {
  /* Tamaño */
  font-size: 1.5rem;
  
  /* Color */
  color: var(--bs-primary);
  
  /* Transiciones */
  transition: color 0.3s ease;
}

.bi:hover {
  color: var(--bs-primary-dark);
}

SCSS

// styles/icons.scss
.icon {
  &-sm { font-size: 1rem; }
  &-md { font-size: 1.5rem; }
  &-lg { font-size: 2rem; }
  
  &-primary { color: $primary; }
  &-secondary { color: $secondary; }
}

Mejores Prácticas Recomendado

Accesibilidad

<!-- ✅ Bueno: Usar aria-label -->
<button class="btn" aria-label="Me gusta">
  <i class="bi bi-heart"></i>
</button>

<!-- ✅ Bueno: Usar aria-hidden con texto -->
<button class="btn">
  <i class="bi bi-heart" aria-hidden="true"></i>
  Me gusta
</button>

Rendimiento

<!-- ✅ Bueno: Usar SVG sprite para múltiples iconos -->
<svg class="bi" width="16" height="16">
  <use xlink:href="#icon-sprite"/>
</svg>

<!-- ❌ Malo: Cargar iconos individuales -->
<img src="path/to/icon.svg" alt="icono">
