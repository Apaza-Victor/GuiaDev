¿Para qué sirve y cuándo usarla? Concepto

GSAP (GreenSock Animation Platform) es el estándar profesional de animación web: anima cualquier propiedad de cualquier objeto (CSS, SVG, canvas) con rendimiento optimizado y control total del timeline. Plugins como ScrollTrigger añaden animaciones basadas en scroll.

¿Para qué se usa?

  • Animar DOM, SVG y canvas con tweens sobre cualquier propiedad.
  • Orquestar secuencias complejas con timelines (`gsap.timeline`).
  • Vincular animaciones al scroll con ScrollTrigger: pin, scrub y parallax.
  • Aplicar easing y stagger avanzados incluso con cientos de elementos.

¿En qué casos conviene usarla?

  • Landing pages con efectos de scroll robustos: reveals, pins y parallax.
  • Prototipos de producto o presentaciones animadas con control fino.
  • Animaciones de logo y SVG con plugins avanzados (MorphSVG, DrawSVG).

Algunos plugins avanzados requieren licencia comercial en empresas grandes. Para animaciones simples de entrada, CSS puro o Anime.js bastan; GSAP brilla cuando necesitas timeline y scroll complejos.

Tweens Básicos Paso 2

// Animación de un solo elemento
gsap.to('.caja', { x: 300, duration: 1, ease: 'power2.out' });

// Desde un estado inicial
gsap.from('#titulo', { y: 40, opacity: 0, duration: 0.8, delay: 0.2 });

// Efecto alternando desde y hacia
gsap.fromTo('.logo', { scale: 0.8, rotation: -8 },
                    { scale: 1, rotation: 0, duration: 0.6, ease: 'elastic.out(1, 0.4)' });

// Varias propiedades y stagger para listas
gsap.to('.card', {
  y: -10,
  opacity: 1,
  stagger: 0.08,      // escalonado
  duration: 0.5
});

// Callbacks
gsap.to('#btn', { x: 50, onComplete: () => console.log('listo') });

`.to()` anima hacia el valor dado, `.from()` parte de ese valor y llega al actual, y `.fromTo()` fija ambos extremos explícitamente. `stagger` reparte el delay en colecciones de nodos.

Timelines Paso 3

// Secuencia de pasos con control global
const tl = gsap.timeline({ defaults: { duration: 0.5, ease: 'power2.out' } });

tl.from('#panel', { opacity: 0, scale: 0.9 })
  .from('.fila h3', { x: -30, opacity: 0, stagger: 0.1 })
  .to('#panel', { boxShadow: '0 20px 40px rgba(0,0,0,0.3)' })
  .add(() => emitirEvento(), '-=0.2');   // callback con offset

// Controles
tl.pause();
tl.play();
tl.reverse();
tl.timeScale(2);   // acelerar 2x
tl.progress(0.3);  // saltar al 30%

Una timeline encadena animaciones en orden y permite offsets (p. ej. `'-=0.3'`) para solapar pasos. Es la forma más legible de coreografiar una experiencia completa.

Easing y Control Paso 4

// Easings comunes
gsap.to('.a', { x: 200, ease: 'power1.inOut' });      // acelerar y frenar
gsap.to('.b', { x: 200, ease: 'back.out(1.7)' });     // rebote antes de asentarse
gsap.to('.c', { x: 200, ease: 'elastic.out(1, 0.4)' }); // elástico
gsap.to('.d', { x: 200, ease: 'steps(6)' });           // cuadro a cuadro

// Repetir y alternar
gsap.to('#pelota', {
  y: 200,
  repeat: -1,       // infinito
  yoyo: true,       // va y viene
  duration: 0.6,
  ease: 'sine.inOut'
});

// Pausar / hacer ping-pong desde cualquier estado
const tween = gsap.to('.caja', { rotation: 90, duration: 1 });
tween.pause();
tween.tweenTo(tween.duration() / 2);

El easing define la "personalidad" del movimiento. `back` y `elastic` añaden vida; `power`/`expo` dan profesionalismo; `steps` es ideal para animación por frames.

ScrollTrigger Paso 5

gsap.registerPlugin(ScrollTrigger);

// Animar cuando la sección entra en el viewport
gsap.from('.seccion .item', {
  opacity: 0,
  y: 60,
  stagger: 0.1,
  duration: 0.7,
  scrollTrigger: {
    trigger: '.seccion',
    start: 'top 80%',       // top de la sección al 80% del viewport
    toggleActions: 'play none none reverse'
  }
});

// Pin: fijar un elemento mientras se hace scroll
ScrollTrigger.create({
  trigger: '.sticky',
  start: 'top top',
  end: '+=600',
  pin: true
});

// Progress bar de scroll
gsap.to('.barra-progreso', {
  scaleX: 1,
  ease: 'none',
  scrollTrigger: { start: 0, end: 'max', scrub: 0.5 }
});

Con `scrub: true` el progreso va ligado al scroll (efectos parallax). Usa `toggleActions` y `pin` con moderación: varios `pin` simultáneos pueden penalizar el rendimiento en móviles.

Ejercicios prácticos Reto

  1. Crea una entrada escalonada con `.from()` y `stagger` para 5 tarjetas de una sección.
  2. Encadena en una timeline: aparece logo, se deslizan los 3 menús y sube la sombra.
  3. Haz una pelota que rebote infinitamente con `yoyo` y `elastic.out`.
  4. Con ScrollTrigger, anima una galería "sticky" mientras el usuario sigue scrolleando.
  5. Una barra de progreso superior que avance con `scrub` sincronizada al scroll total.
