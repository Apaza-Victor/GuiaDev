¿Para qué sirve y cuándo usarla? Concepto

AOS (Animate On Scroll) dispara animaciones CSS en el momento en que los elementos entran en el viewport durante el scroll. Con un par de atributos `data-aos` en el HTML consigues entradas suaves para secciones, cards e imágenes sin escribir CSS ni JS de detección.

¿Para qué se usa?

  • Revelar secciones, cards o imágenes conforme el usuario hace scroll.
  • Aplicar efectos fade, zoom, slide y flip con solo atributos `data-aos`.
  • Configurar duración, delay, easing y offset desde la inicialización.
  • Animar una sola vez (`once`) para entradas elegantes sin repetición.

¿En qué casos conviene usarla?

  • Landing pages con muchas secciones que deben aparecer progresivamente.
  • Portafolios y blogs donde el contenido largo se revela al avanzar.
  • Páginas estáticas sin framework donde no quieres montar un motor de animación.

Si necesitas animaciones continuas, drag o control total del timeline, AOS es demasiado limitado. Además, el exceso de elementos en movimiento puede distraer: úsalo de forma moderada.

AOS (Animate On Scroll) dispara animaciones cuando los elementos entran en el viewport al hacer scroll. Suma micro-interacciones a landing pages con solo atributos `data-aos`.

Activación y Atributos Básicos Paso 2

<!-- Inicializar al cargar la página -->
<div data-aos="fade-up">Sección 1</div>
<div data-aos="fade-right">Sección 2</div>
<div data-aos="zoom-in">Cards</div>

document.addEventListener('DOMContentLoaded', () => {
  AOS.init({
    duration: 700,          // duración en ms
    easing: 'ease-in-out',  // curva
    offset: 120,            // px antes de dispararse
    once: true,             // animar una sola vez
  });
});

// Con umbral y delay
AOS.init({ offset: 80, delay: 60, once: false });

`once: true` es lo más usado para landing: el elemento se anima la primera vez que entra y no vuelve a saltar al hacer scroll hacia arriba.

Animaciones Disponibles Paso 3

<!-- Deslizamientos -->
<div data-aos="fade-up"> fade-up </div>
<div data-aos="fade-down"> fade-down </div>
<div data-aos="fade-left"> fade-left </div>
<div data-aos="fade-right"> fade-right </div>

<!-- Zoom -->
<div data-aos="zoom-in"> zoom-in </div>
<div data-aos="zoom-in-up"> zoom-in-up </div>
<div data-aos="zoom-out"> zoom-out </div>

<!-- Giro y flip -->
<div data-aos="flip-left"> flip-left </div>
<div data-aos="flip-right"> flip-right </div>

<!-- Variantes de fade con dirección -->
<div data-aos="fade-up-right"> fade-up-right </div>

La nomenclatura es `efecto-dirección`: `fade`, `zoom`, `flip`, `slide` combinados con `up`, `down`, `left`, `right`. Revisa la documentación para el catálogo completo.

---

Control y Personalización Paso 4

<!-- Duración, delay y easing por elemento -->
<div data-aos="fade-up" data-aos-duration="1000" data-aos-delay="200" data-aos-easing="linear">
  Hero
</div>

<!-- Anclado a otro elemento (para EU en 2 ejes) -->
<div data-aos="fade-right" data-aos-anchor="#titulo" data-aos-anchor-placement="top-center">
  Trigger
</div>

<!-- Desactivar en móvil -->
<div data-aos="fade-up" data-aos-disable="phone">Solo desktop</div>

// Refrescar tras carga dinámica de contenido
function cargarMas() {
  renderContenido();
  AOS.refresh();   // recalcular posiciones (clave tras SPA/fetch)
}

// Listener de estado
AOS.init();
document.querySelector('.aos-init').addEventListener('aos:in', (e) => console.log('entró'));

Si añades elementos al DOM después de iniciar AOS (tabs, lazy load, routing), llama a `AOS.refresh()` para recalcular cuándo deben dispararse. Con `data-aos-disable` puedes apagarlo en móviles.

Rendimiento y Producción Paso 5

// Usa IntersectionObserver (ya lo hace internamente AOS) pero limita el número de targets animados

// Respetar prefers-reduced-motion
if (window.matchMedia('(prefers-reduced-motion: reduce)').matches) {
  AOS.init({ disable: true });   // sin animaciones
} else {
  AOS.init({ once: true, duration: 600 });
}

// No animar todo: elige elementos clave (hero, cards, imágenes) y evita los que ya están 100% visibles

Regla práctica: `once: true` + animar solo secciones visibles + respetar `prefers-reduced-motion`. Así obtienes impacto visual sin penalizar el scroll de contenido largo.

---

Ejercicios prácticos Reto

  1. Activa AOS con `once: true` y aplica `fade-up` a tres secciones alternas.
  2. Usa `fade-left`/`fade-right` en una fila de dos columnas para dar sensación de entrada lateral.
  3. Dale a una tarjeta `data-aos-duration="800"` y `data-aos-delay="150"`.
  4. Carga contenido dinámico con fetch y refresca AOS con `AOS.refresh()`.
  5. Deshabilita animaciones en móviles con `data-aos-disable="phone"`.
