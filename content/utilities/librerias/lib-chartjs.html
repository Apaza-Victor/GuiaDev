Instalación Paso 1

npm

npm install chart.js

CDN

<script src="https://cdn.jsdelivr.net/npm/chart.js@4.4.3/dist/chart.umd.min.js"></script>

Import

import Chart from 'chart.js/auto';

Chart.js renderiza gráficos en canvas (HTML5) con HTML/CSS para títulos y leyendas. Soporta barras, líneas, doughnut, radar, polar y scatter con animaciones por defecto.

---

Primer Gráfico Paso 2

<canvas id="ventas"></canvas>

const ctx = document.getElementById('ventas');
new Chart(ctx, {
  type: 'bar',
  data: {
    labels: ['Ene', 'Feb', 'Mar', 'Abr'],
    datasets: [{
      label: 'Ventas 2026',
      data: [120, 190, 140, 210],
      backgroundColor: 'rgba(59,130,246,0.7)',
    }],
  },
  options: {
    responsive: true,
    maintainAspectRatio: false,
    plugins: {
      legend: { position: 'top' },
    },
  },
});

Un `` de cada gráfico con un único `id`. Con `responsive: true` y un contenedor con altura fija se adapta a cualquier pantalla.

  },

// Dispersión (scatter)
new Chart(ctxScatter, {
  type: 'scatter',
  data: {
    datasets: [{

    }],
  },
});

Para cada dataset se definen datos y colores. Los ejes, herramientas de tooltip y legendas se personalizan desde el bloque `options`.

Datos Dinámicos y Actualización Paso 4

const grafico = new Chart(ctx, { /* ... */ });

// Actualizar datos en caliente
grafico.data.datasets[0].data = [200, 180, 240, 300];
grafico.data.labels.push('May');
grafico.update();

// Añadir datos (gráfico en tiempo real)
function pushRealTime(valor) {
  grafico.data.labels.push(new Date().toLocaleTimeString());
  grafico.data.datasets[0].data.push(valor);
  grafico.update();
}
setInterval(pushRealTime, 1000, Math.random() * 100);

// Filtros por fecha/periodo: recarga el dataset
function cambiarPeriodo(desde, hasta) {
  grafico.data.datasets[0].data = obtenerDatos(desde, hasta);
  grafico.update();
}

// Destruir antes de reutilizar el canvas
grafico.destroy();

Nunca crees un nuevo `Chart` sobre el mismo canvas sin `destroy()`, o acumularás gráficos invisibles y mermas de rendimiento.

Plugins, RWD y Producción Paso 5

// Importar módulos bajo demanda (tree-shaking)
import { Chart, BarController, BarElement } from 'chart.js';

// Registro manual de componentes
Chart.register(BarController, BarElement);

// Tooltip personalizado en formato dinero
options: {
  plugins: {
    tooltip: {
      callbacks: {
        label: (item) => `${item.dataset.label}: S/ ${item.parsed.y.toLocaleString()}`,
      },
    },
  },
}

// Modo escalable en un contenedor con altura
// .grafico-wrap { height: 320px; }

<div class="grafico-wrap">
  <canvas id="kpi"></canvas>
</div>

En producción registra solo los componentes que usas (`chart.js` completo incluye todos los tipos). Combinado con árbol de contenidos (imports), reduce el bundle.

Ejercicios prácticos Reto

  1. Renderiza un gráfico de barras con 4 meses y formato de moneda en el tooltip.
  2. Crea un gráfico de líneas con dos series (ventas y gastos) y leyenda en la parte inferior.
  3. Usa un doughnut para mostrar la distribución de tecnologías de un proyecto.
  4. Implementa un gráfico en tiempo real que reciba datos cada 2 segundos sin fugas de memoria.
  5. Haz el gráfico responsive dentro de un contenedor de 300px de alto y verifícalo al rotar el dispositivo.
