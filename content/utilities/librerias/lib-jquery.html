¿Para qué sirve y cuándo usarla? Concepto

jQuery es una librería clásica que simplifica la selección de elementos, la manipulación del DOM, el manejo de eventos, las animaciones y las peticiones AJAX con una sintaxis concisa. Su amplia compatibilidad con navegadores antiguos la mantiene presente en miles de proyectos.

¿Para qué se usa?

  • Seleccionar y encadenar operaciones del DOM con el objeto `$()`.
  • Gestionar eventos delegados y efectos de animación simples.
  • Hacer peticiones AJAX (`$.ajax`) con una API estable.
  • Garantizar compatibilidad con navegadores legacy como Internet Explorer.

¿En qué casos conviene usarla?

  • Mantenimiento de proyectos legacy o plugins que dependen de jQuery.
  • Sitios que necesitan funcionar en navegadores muy antiguos.
  • Prototipos rápidos donde la concisión del `$` acelera el desarrollo.

En proyectos nuevos, `querySelector`, `fetch` y los selectores nativos cubren lo esencial sin dependencias. Evita añadir jQuery a codebases nuevas salvo que integres plugins o librerías que lo exijan.

Selectores y Manipulación DOM Paso 2

// Selección
const $lista = $('.lista');          // todos los .lista
const $item = $('#item1');           // por id
const $combinado = $('div.menu, a.btn');

// Iteración implícita
$('.tarjeta').css('border', '1px solid #ddd');
$('.tarjeta').addClass('activa').removeClass('inactiva');

// Contenido
$('#titulo').text('Nuevo título');
$('#caja').html('<strong>HTML</strong> en vivo');
$('#input').val('valor inicial');
$('#enlace').attr('href', '/destino');

// Crear y anexar elementos
const $nuevo = $('<li>').text('Item nuevo').addClass('item');
$('#lista').append($nuevo);

Todo selector devuelve una colección: los métodos se aplican a todos los elementos seleccionados y permiten encadenar operaciones.

Eventos Paso 3

// Eventos básicos
$('#btnGuardar').on('click', function () {
  console.log('Guardado');
});

// Delegación de eventos (funciona con elementos creados después)
$('#tabla').on('click', 'tr.fila-activa', function () {
  alert($(this).data('id'));
});

// Eventos de formulario
$('#miForm').on('submit', function (e) {
  e.preventDefault();
  const datos = $(this).serialize();
  enviarDatos(datos);
});

// Keyboard / mouse
$(document).on('keydown', (e) => {
  if (e.key === 'Escape') cerrarModal();
});
$('.cards').on('mouseenter', function () {
  $(this).toggleClass('hover');
});

La delegación con `$(contenedor).on(evento, selector, handler)` es la forma correcta de manejar listas dinámicas sin re-bindear eventos.

Efectos y Animaciones Paso 4

// Mostrar / ocultar
$('#panel').show();
$('#panel').hide('slow');
$('#panel').toggle(400);

// Desvanecido y deslizamiento
$('#aviso').fadeIn(300);
$('#sidenav').slideDown(300);

// Animación de propiedades CSS
$('#caja').animate({ left: '300px', opacity: 0.5 }, 600);

// Cola de animaciones
$('#caja')
  .animate({ opacity: 0 }, 300)
  .animate({ width: '50%' }, 300)
  .slideUp();

// Con callback al terminar
$('#panel').fadeOut(400, () => {
  console.log('Terminó la animación');
});

Para UI importante prefiere CSS transitions/`requestAnimationFrame` en proyectos modernos. jQuery animate es útil en bases legacy y prototipos rápidos.

AJAX con jQuery Paso 5

// GET
$.get('/api/usuarios', { rol: 'admin' })
  .done((data) => renderTabla(data))
  .fail(() => mostrarError());

// POST
$.post('/api/usuarios', { nombre: 'Ana' })
  .done((nuevo) => console.log('Creado', nuevo.id));

// Config completa con $.ajax
$.ajax({
  url: '/api/perfil',
  method: 'PUT',
  contentType: 'application/json',
  data: JSON.stringify({ edad: 31 }),
  timeout: 5000,
}).done((r) => toast('Perfil actualizado'))
  .fail((xhr) => {
    if (xhr.status === 401) location.href = '/login';
  });

// Cargar HTML parcial en un contenedor
$('#contenido').load('/secciones/intro.html');

`.done`/`.fail` devuelven el objeto de promesa propio de jQuery; para proyectos nuevos se recomienda `fetch`, pero en proyectos jQuery existentes `$.ajax` sigue siendo la vía natural.
