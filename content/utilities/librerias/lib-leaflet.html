¿Para qué sirve y cuándo usarla? Concepto

Leaflet es la librería de mapas interactivos más ligera y extendida (unos 42 kB). Carga teselas (tiles) de OpenStreetMap u otros proveedores, añade marcadores, polylines, popups y controla zoom y panorámica con una API minimalista.

¿Para qué se usa?

  • Mostrar mapas interactivos con capas de tiles de OSM u otros proveedores.
  • Añadir marcadores, popups y rutas dibujadas con polyline o polygon.
  • Manejar eventos de mapa (click, zoom) y la geolocalización del usuario.
  • Construir mapas con clusters o controles personalizados mediante plugins.

¿En qué casos conviene usarla?

  • Sitios de contacto con mapas de ubicaciones y marcadores.
  • Dashboards con visualización de puntos de interés geográficos.
  • Apps de delivery o rutas donde la ligereza del mapa importa.

Para SIG avanzado, raster analysis o mallas muy pesadas, MapLibre o Mapbox ofrecen más (vector tiles y 3D). Leaflet es ideal cuando quieres mapas simples y rápidos sin plataforma de pago.

Mapa Básico Paso 2

// Coordenadas: latitud, longitud (Lima)
const mapa = L.map('mapa').setView([-12.0464, -77.0428], 12);

// Capa de teselas (tiles) de OpenStreetMap
L.tileLayer('https://tile.openstreetmap.org/{z}/{x}/{y}.png', {
  maxZoom: 19,
  attribution: '&copy; OpenStreetMap'
}).addTo(mapa);

// Destruir y recrear para "refrescar"
mapa.remove();
const mapa2 = L.map('mapa').setView([...], 12);

El mapa en sí es solo un "visually" sobre una capa de mosaicos. La capa define el proveedor gráfico; el mapa maneja zoom y panorámica. Recuerda dar altura al contenedor o no verás nada.

Marcadores y Popups Paso 3

const marker = L.marker([-12.0464, -77.0428])
  .addTo(mapa)
  .bindPopup('<b>Plaza de Armas</b><br>Lima, Perú')
  .openPopup();

// Icono personalizado
const icono = L.icon({
  iconUrl: '/img/pin.png',
  iconSize: [32, 42],
  iconAnchor: [16, 42],     // punta del pin
  popupAnchor: [0, -42]
});
L.marker([-12.0551, -77.0462], { icon: icono })
  .addTo(mapa)
  .bindPopup('Palacio de Gobierno');

// Círculo de área
L.circle([-12.0464, -77.0428], {
  radius: 1200,
  color: '#f59e0b',
  fillOpacity: 0.15
}).addTo(mapa);

`bindPopup` asocia un globo al marcador y `openPopup()` lo abre al cargar. Alinear bien `iconAnchor`/`popupAnchor` es clave para que el pin "apunte" al lugar exacto.

Capas y GeoJSON Paso 4

// Cargar un GeoJSON (provincias, rutas, POIs) y pintarlo
fetch('/data/distritos.json')
  .then((r) => r.json())
  .then((geo) => {
    L.geoJSON(geo, {
      style: () => ({ color: '#3b82f6', weight: 1, fillOpacity: 0.1 }),
      onEachFeature: (feature, layer) => {
        layer.bindPopup(`<b>${feature.properties.name}</b>`);
      }
    }).addTo(mapa);
  });

// Varias capas con control para encender/apagar
const capaCafes = L.layerGroup([...]).addTo(mapa);
const capaParques = L.layerGroup([...]);

L.control.layers({
  'Cafés': capaCafes,
  'Parques': capaParques
}).addTo(mapa);

Leaflet consume GeoJSON directamente con `L.geoJSON`, incluyendo estilos y popups por feature. Los `layerGroup` + `L.control.layers` dan un panel de capas sin escribir UI.

Interacción y Eventos Paso 5

// Eventos de mapa
mapa.on('click', (e) => {
  console.log('Coordenadas:', e.latlng.lat, e.latlng.lng);
  L.marker(e.latlng).addTo(mapa);   // colocar marcador donde clicaste
});

mapa.on('zoomend', () => {
  console.log('Zoom actual:', mapa.getZoom());
});

// Fit al contenido
const bounds = L.latLngBounds([[ -12.08, -77.09 ], [ -12.01, -77.01 ]]);
mapa.fitBounds(bounds);   // encuadra el rectángulo completo

// Actualizar centro/zoom
mapa.setView([-13.5250, -71.9722], 13);   // Cusco

`fitBounds` es la forma robusta de encuadrar puntos: en vez de calcular el centro a mano, deja que Leaflet resuelva el zoom. Para "mi ubicación", usa la Geolocation API del navegador y `mapa.locate()`.
