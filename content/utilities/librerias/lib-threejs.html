¿Para qué sirve y cuándo usarla? Concepto

Three.js es el motor 3D más popular para la web: abstrae WebGL y deja construir escenas con objetos, luces, cámaras y materiales de forma declarativa. Es la opción por defecto para 3D interactivo en el navegador, publicable como sitio estático.

¿Para qué se usa?

  • Renderizar escenas 3D: geometrías, mallas, luces y cámaras.
  • Animar objetos en el bucle de render con materiales y texturas propias.
  • Cargar modelos externos (glTF, OBJ, FBX) y entornos con iluminación realista.
  • Integrar experiencia VR/AR y efectos de postprocesado avanzados.

¿En qué casos conviene usarla?

  • Visualizadores de productos 3D en webs comerciales.
  • Experiencias interactivas, configuradores y portafolios inmersivos.
  • Prototipos y demos 3D publicados en GitHub Pages u hosting estático.

WebGL puro o Babylon.js son alternativas según el control que necesites o si el proyecto está orientado a juegos. Three.js es enorme: importa módulos específicos desde `three/addons` para reducir el bundle.

Primera Escena Paso 2

import * as THREE from 'three';

// 1. Escena
const scene = new THREE.Scene();
scene.background = new THREE.Color(0x1e293b);

// 2. Cámara (perspectiva: fov, aspect, near, far)
const camera = new THREE.PerspectiveCamera(75, innerWidth / innerHeight, 0.1, 100);
camera.position.z = 5;

// 3. Renderer
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);

// 4. Un cubo
const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshStandardMaterial({ color: 0xf59e0b });
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);

// 5. Luz (MeshStandardMaterial la necesita)
const light = new THREE.DirectionalLight(0xffffff, 2);
light.position.set(2, 3, 4);
scene.add(light);

// 6. Dibujar un frame
renderer.render(scene, camera);

La escena es un árbol de objetos, la cámara define el punto de vista y el renderer pinta el frame en un ``. Sin luz, un material PBR se ve completamente negro.

Geometrías y Materiales Paso 3

// Geometrías
const esfera = new THREE.Mesh(
  new THREE.SphereGeometry(1, 32, 32),
  new THREE.MeshStandardMaterial({ color: 0x10b981, roughness: 0.2 })
);

const toro = new THREE.Mesh(
  new THREE.TorusGeometry(1, 0.35, 16, 64),
  new THREE.MeshStandardMaterial({ color: 0x3b82f6, metalness: 0.7 })
);

// Textura desde una imagen
const texture = new THREE.TextureLoader().load('/texturas/madera.jpg');
const suelo = new THREE.Mesh(
  new THREE.PlaneGeometry(10, 10),
  new THREE.MeshStandardMaterial({ map: texture })
);

// Agrupar objetos
const grupo = new THREE.Group();
grupo.add(esfera, toro);
scene.add(grupo);

Cuanto más altos sean los segmentos (32, 64...), más suave es la geometría pero más costosa. Para escenas con muchos objetos prefiere `InstancedMesh` en lugar de usar miles de meshes sueltos.

Luces y Cámara Paso 4

// Luces comunes
const ambiente  = new THREE.AmbientLight(0xffffff, 0.4);          // ilumina todo
const direccional = new THREE.DirectionalLight(0xffffff, 2);      // sol
const punto     = new THREE.PointLight(0xf59e0b, 1, 20);          // bombilla
punto.position.set(2, 3, 1);

scene.add(ambiente, direccional, punto);

// Cámara que sigue a un objetivo (para juegos / orbit)
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';
const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;   // inercia suave
controls.target.set(0, 0, 0);

Combina una luz ambiental suave con una direccional para dar volumen, y añade puntuales para acentos. `OrbitControls` te da navegación estilo "ver modelo 3D" con el ratón y zoom con el scroll.

Animación y Render Loop Paso 5

const clock = new THREE.Clock();

function animate() {
  requestAnimationFrame(animate);

  const t = clock.getElapsedTime();   // segundos desde el inicio

  // Rotar y flotar
  cube.rotation.x = t * 0.5;
  cube.rotation.y = t * 0.7;
  cube.position.y = Math.sin(t) * 0.5;

  // Escalamiento pulsante
  const s = 1 + Math.sin(t * 3) * 0.1;
  cube.scale.set(s, s, s);

  // Cámara en órbita personalizada
  camera.position.x = Math.sin(t * 0.5) * 5;
  camera.position.z = Math.cos(t * 0.5) * 5;
  camera.lookAt(0, 0, 0);

  renderer.render(scene, camera);
}
animate();

// Redimensionar el canvas
addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});

El bucle de render (requestAnimationFrame) es obligatorio para animar: con `clock.getElapsedTime()` obtienes el tiempo transcurrido y evitas desincronías entre dispositivos con distinto refresh rate.

Ejercicios prácticos Reto

  1. Renderiza una escena con tres esferas de colores distintos y una luz direccional.
  2. Anima un toro rotando alrededor del eje Y dentro de una escena con fondo oscuro.
  3. Añade `OrbitControls` y comprueba cómo la inercia (damping) mejora la navegación.
  4. Haz una estrella 8 puntas con `RingGeometry` o `ConeGeometry` rotando sobre un grupo.
  5. Redimensiona el canvas correctamente con el evento `resize` y prueba pestaña a pantalla completa.
