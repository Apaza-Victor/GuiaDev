¿Para qué sirve y cuándo usarla? Concepto

D3.js (Data-Driven Documents) es la librería de referencia para visualización de datos: une los datos con el DOM y SVG mediante selecciones, data joins, escalas, ejes y transiciones. No ofrece gráficos predefinidos; te da las piezas para construir los tuyos.

¿Para qué se usa?

  • Crear visualizaciones a medida: scatter, sankey, mapas, chord, etc.
  • Escalar datos a coordenadas visuales con `d3.scaleLinear` y `d3.scaleBand`.
  • Enlazar datos con el DOM usando enter/update/exit (`data` + `join`).
  • Añadir ejes, grids y transiciones animadas a los SVG generados.

¿En qué casos conviene usarla?

  • Informes de datos a medida donde Chart.js no da el control necesario.
  • Mapas interactivos y visualizaciones científicas con grandes datasets.
  • Dashboards con gráficos custom que cambian dinámicamente con los datos.

Su curva de aprendizaje es pronunciada y el código se vuelve verboso. Si tu necesidad son gráficos estándar (barra, línea, doughnut), Chart.js o ECharts son opciones mucho más rápidas de implementar.

Selecciones y DOM Paso 2

// Seleccionar y crear SVG
const svg = d3.select('#grafico')
  .append('svg')
  .attr('width', 600)
  .attr('height', 400);

// Añadir círculos y ligarlos a datos (data join)
svg.selectAll('circle')
  .data([10, 25, 40, 60])
  .join('circle')
    .attr('cx', (d, i) => 50 + i * 80)
    .attr('cy', 200)
    .attr('r', (d) => d)
    .attr('fill', '#f59e0b');

// Actualizar atributos con estilo y texto
svg.selectAll('text')
  .data([10, 25, 40, 60])
  .join('text')
    .attr('x', (d, i) => 50 + i * 80)
    .attr('y', 220)
    .style('text-anchor', 'middle')
    .text((d) => d);

La selección por datos (`join`) es el corazón de D3: crea, actualiza y elimina elementos según los datos que cambian. Es una declaración "sincroniza el DOM con esta serie de datos".

Escalas y Ejes Paso 3

// Escala lineal para el eje X (dominio de datos -> rango de píxeles)
const x = d3.scaleLinear()
  .domain([0, 100])
  .range([0, 500]);

// Escala de banda para barras (categorías)
const y = d3.scaleBand()
  .domain(['Lun', 'Mar', 'Mié', 'Jue'])
  .range([0, 300])
  .padding(0.2);

// Crear el eje
svg.append('g')
  .attr('transform', 'translate(50, 360)')
  .call(d3.axisBottom(x));

svg.append('g')
  .attr('transform', 'translate(50, 0)')
  .call(d3.axisLeft(y));

// Escala de color
const color = d3.scaleOrdinal(d3.schemeTableau10);
console.log(color('A'));   // '#4e79a7'

Las escalas traducen datos a píxeles (o colores). `scaleOrdinal` + `schemeTableau10` da paletas listas para categorías sin diseñar nada.

Data Join Paso 4

// Modelo de tres fases: enter / update / exit
function dibujaBarras(datos) {
  const barras = svg.selectAll('rect')
    .data(datos, (d) => d.nombre);   // key de identidad

  // ENTER: barras nuevas
  barras.enter()
    .append('rect')
    .attr('width', x.bandwidth())
    .attr('height', 0)
    .attr('y', (d) => valorY(d.valor))
    .merge(barras)                    // combina enter + update
    .transition()
    .duration(400)
    .attr('height', (d) => alto(d.valor));

  // UPDATE: re-used via merge
  //
  // EXIT: barras que ya no existen
  barras.exit()
    .transition()
    .duration(300)
    .attr('height', 0)
    .remove();
}

Usa una **key** (`.data(datos, d => d.nombre)`) para que D3 sepa qué elementos actualizar cuando el array cambia de orden o contenido; sin key, D3 casa por posición y las transiciones se ven erróneas.

Gráficos con Datos Dinámicos Paso 5

// Cargar datos externos (CSV/JSON)
d3.json('/api/ventas.json').then((datos) => dibujaBarras(datos));

// Transición con easing
function actualiza(datos) {
  svg.selectAll('rect')
    .data(datos, (d) => d.nombre)
    .join(
      enter => enter.append('rect')
        .attr('y', 300)
        .attr('height', 0)
        .call((sel) => sel.transition().duration(500).attr('height', (d) => alto(d.valor))),
      update => update
        .call((sel) => sel.transition().duration(500)
          .attr('y', (d) => valorY(d.valor))
          .attr('height', (d) => alto(d.valor))),
      exit => exit.transition().duration(300).attr('height', 0).remove()
    );
}

Con `join(enter, update, exit)` declaras qué hace cada fase. Las transiciones animan entre valores y D3 escala los ticks y los ejes automáticamente.

Ejercicios prácticos Reto

  1. Dibuja un scatter plot con 10 puntos usando `scaleLinear` para ambos ejes.
  2. Construye un gráfico de barras vertical con `scaleBand` y `d3.axisBottom`.
  3. Añade una transición que anime las barras desde altura 0 al cargar.
  4. Haz que las barras respondan a un botón "ordenar": mueve los datos con `datum.sort` y re-anima.
  5. Colorea cada barra de la paleta `schemeTableau10` según su índice.
