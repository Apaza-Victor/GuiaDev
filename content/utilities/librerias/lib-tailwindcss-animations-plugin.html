¿Para qué sirve y cuándo usarla? Concepto

El plugin `@midudev/tailwind-animations` añade clases de animación listas para usar dentro de Tailwind CSS: fade, slide, zoom, shake y más, con variantes de entrada y salida controladas por dirección como `animate-fade-in` o `animate-fade-out`.

¿Para qué se usa?

  • Activar animaciones predefinidas con clases tipo `animate-fade-in` sin escribir CSS.
  • Cambiar entradas y salidas con las variantes `-in` y `-out` según la dirección.
  • Combinar animaciones con utilidades de Tailwind: delay y duration.
  • Mantener el flujo utility-first sin mantener keyframes propios en CSS.

¿En qué casos conviene usarla?

  • Landing pages en Tailwind donde se añade movimiento sin tocar CSS.
  • Prototipos con reveals de secciones y micro-interacciones rápidas.
  • Proyectos que ya usan Tailwind y quieren animación declarativa.

Es un set de animaciones prescriptivas: para secuencias, stagger y control fino del timeline, GSAP o Framer Motion ofrecen mucho más. Verifica además que la versión del plugin coincida con la de Tailwind que usas.

Instalación Paso 1

npm

    npm install @midudev/tailwind-animations

CDN

    <!-- Próximamente disponible via CDN -->

Configuración Paso 2

tailwind.config.js

/** @type {import('tailwindcss').Config} */
module.exports = {
  // ...resto de tu configuración
  plugins: [
    require('@midudev/tailwind-animations')
  ],
}

styles.css

@import 'tailwindcss';
@plugin "@midudev/tailwind-animations";

Uso Básico Paso 3

Animaciones Predefinidas

<!-- Fade In -->
<div class="animate-fade-in">
  Aparece suavemente
</div>

<!-- Slide In -->
<div class="animate-slide-in">
  Desliza desde la izquierda
</div>

<!-- Bounce -->
<div class="animate-bounce-in">
  Rebota al entrar
</div>

Modificadores

<!-- Duración -->
<div class="animate-fade-in duration-300">
  Rápido
</div>

<!-- Retraso -->
<div class="animate-slide-in delay-300">
  Espera antes de animar
</div>

<!-- Dirección -->
<div class="animate-slide-in-left">
  Desde la izquierda
</div>
<div class="animate-slide-in-right">
  Desde la derecha
</div>

Animaciones Avanzadas Paso 4

Combinando Animaciones

<div class="
  animate-fade-in
  hover:animate-bounce
  group-hover:animate-shake
">
  Múltiples estados
</div>

Animaciones Encadenadas

<div class="group">
  <div class="animate-fade-in">Primero</div>
  <div class="animate-fade-in delay-200">Segundo</div>
  <div class="animate-fade-in delay-400">Tercero</div>
</div>

Mejores Prácticas Recomendado

1. Rendimiento

<!-- Usar animaciones ligeras para elementos frecuentes -->
<div class="animate-fade-in">
  Contenido frecuente
</div>

<!-- Reservar animaciones complejas para eventos importantes -->
<div class="animate-bounce-in-scale">
  Contenido destacado
</div>

2. Accesibilidad

<!-- Respetar preferencias de movimiento reducido -->
<div class="
  motion-safe:animate-slide-in
  motion-reduce:opacity-100
">
  Contenido accesible
</div>

3. Responsive

<div class="
  animate-fade-in
  sm:animate-slide-in
  md:animate-bounce-in
">
  Adaptativo
</div>
