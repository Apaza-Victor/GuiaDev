¿Para qué sirve y cuándo usarla? Concepto

Babylon.js es un motor 3D para el navegador orientado al desarrollo de juegos y experiencias inmersivas. Ofrece engine y scene al estilo de los motores profesionales, con física integrada, GUI, sprites, partículas y un editor visual para armar escenas.

¿Para qué se usa?

  • Construir escenas 3D interactivas con cámara, luces y mallas.
  • Desarrollar juegos web con física, colisiones y control de input.
  • Renderizar modelos importados (glTF, OBJ) y entornos de realidad virtual y aumentada.
  • Montar interfaces dentro de la escena con la capa GUI de Babylon.

¿En qué casos conviene usarla?

  • Juegos y demos 3D que exigen física y animación de personajes.
  • Visualización de productos o configuradores 3D complejos.
  • Proyectos AR/VR con WebXR donde Babylon aporta soporte directo.

Para mostrar modelos 3D simples o panoramas ligeros, Three.js es más sencillo y ligero. Babylon brilla en proyectos tipo motor de juego que justifican su tamaño y su API corporativa.

Primera Escena Paso 2

import { Engine, Scene, FreeCamera, Vector3, } from '@babylonjs/core';
import { HemisphericLight, MeshBuilder, StandardMaterial, Color3 } from '@babylonjs/core';

// 1. Engine sobre el canvas
const canvas = document.getElementById('escena');
const engine = new Engine(canvas, true);

// 2. Escena
const scene = new Scene(engine);

// 3. Cámara libre con controles WASD/flechas
const camera = new FreeCamera('cam', new Vector3(0, 2, -8), scene);
camera.setTarget(Vector3.Zero());
camera.attachControl(canvas, true);

// 4. Luz hemisférica + direccional para un sol creíble
const light = new HemisphericLight('luz', new Vector3(0, 1, 0), scene);
light.intensity = 0.8;

// 5. Un cubo
const cubo = MeshBuilder.CreateBox('cubo', { size: 2 }, scene);
const material = new StandardMaterial('mat', scene);
material.diffuseColor = new Color3(0.96, 0.62, 0.04);
cubo.material = material;

// 6. Bucle de render
engine.runRenderLoop(() => scene.render());
addEventListener('resize', () => engine.resize());

Babylon usa un sistema de "engine + scene": el engine gestiona el canvas y el render loop, la escena guarda los objetos. `attachControl` conecta la cámara con los controles del usuario.

Cámara y Controles Paso 3

import { ArcRotateCamera } from '@babylonjs/core';

// Cámara orbital (como OrbitControls): gira con el ratón
const cam = new ArcRotateCamera('cam', -Math.PI / 2, Math.PI / 3, 10,
                                new Vector3(0, 1, 0), scene);
cam.attachControl(canvas, true);
cam.lowerRadiusLimit = 3;   // zoom mínimo
cam.upperRadiusLimit = 25;  // zoom máximo
cam.wheelPrecision = 20;

// Movimiento táctil (escritorio y móvil)
cam.panningSensibility = 100;

// Física básica: escenas de juego
import { PhysicsAggregate, PhysicsShapeType } from '@babylonjs/core';
import '@babylonjs/core/Physics/v1/physicsEngineComponent.js';

const pelota = MeshBuilder.CreateSphere('p', { diameter: 1 }, scene);
pelota.position.y = 5;
new PhysicsAggregate(pelota, PhysicsShapeType.SPHERE, { mass: 1 }, scene);

Babylon trae física con un clic: `PhysicsAggregate` + `PhysicsShapeType` añade gravedad y colisiones sin instalar nada. Es ideal para prototipos de juegos.

Materiales y Texturas Paso 4

import { StandardMaterial, Color3, Texture } from '@babylonjs/core';

// Textura entrelazada (mipmap) y escala
const textura = new Texture('/texturas/ladrillo.jpg', scene);
textura.uScale = 2;   // repetir 2 veces en U
textura.vScale = 2;

const material = new StandardMaterial('mat', scene);
material.diffuseTexture = textura;
material.specularColor = new Color3(0.1, 0.1, 0.1);
material.ambientColor = new Color3(0.2, 0.2, 0.2);

// Emisión (objetos que brillan)
const brillo = new StandardMaterial('brillo', scene);
brillo.emissiveColor = new Color3(0, 1, 0.5);

// Transparencia
const vidrio = new StandardMaterial('vidrio', scene);
vidrio.alpha = 0.4;

Las texturas deben estar bajo el mismo dominio (GitHub Pages la sirve desde `/repo/...`) o usar rutas relativas al proyecto. Carga texturas grandes con `loading="async"` y opciones de compresión para no penalizar el arranque.

Animación y Scene events Paso 5

// Animación declarativa por keyframes
import { Animation } from '@babylonjs/core';

const anim = new Animation('girar', 'rotation.y', 60,
                           Animation.ANIMATIONTYPE_FLOAT,
                           Animation.ANIMATIONLOOPMODE_CYCLE);
anim.setKeys([
  { frame: 0,   value: 0 },
  { frame: 60,  value: Math.PI * 2 },
]);
cubo.animations.push(anim);
scene.beginAnimation(cubo, 0, 60, true);

// Movimiento manual en cada frame
scene.onBeforeRenderObservable.add(() => {
  cubo.position.y = 1 + Math.sin(scene.getTime() / 500) * 0.5;
});

Usa `Animation` con keyframes para animaciones reutilizables y programadas, y `onBeforeRenderObservable` para lógica por frame (IA, físicas, partículas). Ambos coexisten sin conflictos.

Ejercicios prácticos Reto

  1. Crea una escena con un suelo con rejilla (`MeshBuilder.CreateGround`) y un cono encima.
  2. Usa `ArcRotateCamera` y limita el zoom y el ángulo vertical.
  3. Añade una esfera con física que caiga sobre el suelo y rebote.
  4. Anima un cubo girando en bucle infinito con `Animation` y keyframes.
  5. Pon dos puntos de luz (punto y spot) y observa las sombras con `light.generateShadowMap = true`.
