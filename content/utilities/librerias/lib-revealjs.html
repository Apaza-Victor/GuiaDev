¿Para qué sirve y cuándo usarla? Concepto

Reveal.js convierte HTML en presentaciones: cada `

` es una diapositiva y entre ellas navegas con flechas, swipe o mouse. Incluye temas, fragmentos animados, código resaltado, notas del presentador y modo de pantalla completa.

¿Para qué se usa?

  • Crear slides para charlas y workshops partiendo de HTML.
  • Organizar diapositivas horizontales y verticales con estructura jerárquica.
  • Añadir fragmentos que se muestran paso a paso dentro de una diapositiva.
  • Embeber código resaltado, embeds y notas para el orador.

¿En qué casos conviene usarla?

  • Documentación interactiva o tutoriales en formato presentación.
  • Charlas técnicas distribuibles como página estática.
  • Workshops con código y demos embebidas en cada slide.

Para contenido no lineal o muy largo, un sitio web normal con secciones y navegación propia es mejor. Reveal encaja cuando el formato es secuencial y tipo diapositiva.

Estructura de Diapositivas Paso 2

<div class="reveal">
  <div class="slides">

    <section>Diapositiva 1</section>

    <section>
      <section><h2>Vertica: sub-diapositivas (flecha abajo)</h2></section>
      <section><h2>Segunda vertical</h2></section>
    </section>

    <section>
      <h2>Código resaltado</h2>
      <pre><code data-trim data-noescape>
        function hola() { return "Hola"; }
      </code></pre>
    </section>

  </div>
</div>

Reveal.initialize({
  hash: true,            // permite enlazar diapositivas por #/2/1
  transition: 'slide',
  controls: true,
  progress: true
});

Las secciones anidadas crean diapositivas verticales: navegación con flechas arriba/abajo dentro de un tema. `hash: true` da URLs compartibles (`#/2/1`).

Temas y Diseño Paso 3

<!-- Cambia el CSS del tema en el head -->
<link rel="stylesheet" href="reveal/dist/theme/black.css">   <!-- dark por defecto -->
<link rel="stylesheet" href="reveal/dist/theme/white.css">   <!-- claro -->
<link rel="stylesheet" href="reveal/dist/theme/moon.css">    <!-- azulado -->
<link rel="stylesheet" href="reveal/dist/theme/custom.css">  <!-- tu propio SCSS -->

<section data-background-color="#0f172a">
  <h2>Fondo de color por diapositiva</h2>
</section>

<section data-background-image="/img/fondo-codigo.jpg" data-background-size="cover">
  <h2>Fondo con imagen</h2>
</section>

<section class="text-left"><!-- utilidades de alineación -->
  <p>Texto a la izquierda.</p>
</section>

Los atributos `data-background-*` permiten fondos (color, imagen, gradiente o vídeo) por diapositiva sin tocar CSS. Revisa `dist/theme/` para cambiar la línea visual completa.

Fragmentos y Transiciones Paso 4

<section>
  <h2>Aparecen paso a paso</h2>
  <p class="fragment fade-in">1º elemento</p>
  <p class="fragment">2º (por defecto fade)</p>
  <ul>
    <li class="fragment fade-left">Item A</li>
    <li class="fragment fade-right">Item B</li>
    <li class="fragment grow">Item C</li>
  </ul>
</section>

Reveal.configure({
  transition: 'slide',        // slide | fade | convex | concave | zoom | none
  transitionSpeed: 'fast',
  backgroundTransition: 'fade',
  slideNumber: 'c/t',         // "página n de m"
  autoSlide: 5000             // avance automático en ms (0 = desactivado)
});

Usa `fragment` con moderación: demasiados "clics por diapositiva" cansan al público. El modo "speaker view" (pulsa `S`) muestra notas y siguiente diapositiva en otra ventana.

---

Panel del Presentador Paso 5

<section>
  <h2>Notas del orador</h2>
  <aside class="notes">
    - Recordar el caso real de la empresa.
    - Preguntar por dudas antes de continuar.
  </aside>
</section>

// Eventos útiles
Reveal.on('slidechanged', (event) => {
  console.log('Diapositiva', event.indexh, event.indexv);
});

// Controles desde el teclado o API
Reveal.next();
Reveal.prev();
Reveal.slide(3);            // ir a la diapositiva índice 3
Reveal.toggleOverview();    // vista general de la presentación

// Autoplay solo durante el deck
Reveal.configure({ autoSlide: 4000 });
Reveal.on('autoslideend', () => Reveal.configure({ autoSlide: 0 }));

El panel del presentador (tecla `S`) abre la nota con "notas + siguiente diapositiva + reloj". Es la forma profesional de dar una charla sin imprimir apuntes.

Ejercicios prácticos Reto

  1. Crea una presentación de 5 diapositivas sobre un tema técnico que domines.
  2. Anida dos sub-diapositivas dentro de una sección y navega verticalmente.
  3. Dale fondo de color a una diapositiva y una imagen a otra.
  4. Convierte una lista en fragmentos que aparezcan uno a uno.
  5. Escribe notas del orador y abre el panel del presentador con la tecla `S`.
