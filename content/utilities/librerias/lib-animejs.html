Instalación Paso 1

npm

npm install animejs

CDN

<script src="https://cdn.jsdelivr.net/npm/animejs@3.2.2/lib/anime.min.js"></script>

Import

import anime from 'animejs';

Anime.js anima propiedades CSS, transformaciones, SVG y atributos de JavaScript con una API declarativa y potente curva de easing. Es el motor que usa GuiaDev para sus micro-interacciones.

---

Animaciones Básicas Paso 2

// Mover y rotar un elemento
anime({
  targets: '.caja',
  translateX: 250,
  rotate: '1turn',
  duration: 800,
});

// Opacidad y color
anime({
  targets: '#aviso',
  opacity: [0, 1],
  backgroundColor: ['#f59e0b', '#10b981'],
  easing: 'easeOutQuad',
});

// Múltiples propiedades con diferentes duraciones
anime({
  targets: '.tarjeta',
  scale: [1, 1.15],
  translateY: -12,
  delay: anime.stagger(80),   // escalonado entre elementos
  duration: 600,
});

// Función de tiempo (easing)
anime({
  targets: '.pelota',
  translateY: [0, 300],
  direction: 'alternate',
  loop: true,
  easing: 'easeInOutSine',
});

`anime.stagger()` reparte retrasos entre los elementos seleccionados, logrando ondas/efectos cascada sin calcular índices manualmente.

Timelines (secuencias) Paso 3

// Crear una secuencia de pasos
const tl = anime.timeline({
  easing: 'easeOutExpo',
  duration: 400,
});

tl.add({ targets: '.paso1', opacity: [0, 1], translateY: [20, 0] })
  .add({ targets: '.paso2', opacity: [0, 1], translateX: [-20, 0] })
  .add({ targets: '.paso3', scale: [0.8, 1] });

// Sincronizar un paso con el anterior
tl.add({ targets: '.fondo', opacity: 0.6 }, '-=200');

// Pausar y continuar
tl.pause();
tl.play();
tl.restart();
tl.seek(500); // posición en ms

Las timelines encadenan animaciones de forma legible; el tercer argumento de `.add` (offset) permite solapamientos en milisegundos.

SVG y Control Fino Paso 4

// Animación de trazo SVG (efecto "dibujado")
anime({
  targets: '.linea',
  strokeDashoffset: [anime.setDashoffset, 0],
  easing: 'easeInOutSine',
  duration: 1200,
});

// Atributos numéricos de SVG
anime({
  targets: '.circulo',
  r: [10, 40],
  opacity: [1, 0.5],
});

// Animación de propiedades numéricas de un objeto JS
const estado = { valor: 0 };
anime({
  targets: estado,
  valor: 100,
  round: 1,
  update: () => { contador.textContent = estado.valor; },
});

// Cursos con callback por actualización
anime({
  targets: '.caja',
  translateX: 300,
  easing: 'easeOutQuad',
  complete: () => { /* al terminar */ },
});

Animando un objeto JS cualquiera puedes sincronizar números en pantalla (contadores, barras de progreso) con la misma curva de easing del resto de la UI.

Buenas Prácticas y Rendimiento Paso 5

// Respetar prefers-reduced-motion
const reduceMotion = matchMedia('(prefers-reduced-motion: reduce)').matches;
if (reduceMotion) return; // no animar elementos decorativos

// Detener animaciones antes de desmontar
const animacion = anime({ targets: '#modal', scale: [0.9, 1] });
animacion.pause();
animacion.seek(0);

// Priorizar transform/opacity (no tocan layout)
anime({ targets: '.card', translateX: 40, opacity: 0.8 });
// Evita animar width/height/top/left en listas largas

// Batches: animar selecciones pequeñas, no el documento entero
anime({ targets: document.querySelectorAll('.fila.visible'), opacity: [0, 1] });

Anima `transform` y `opacity` (compuestas por la GPU), respeta la preferencia de movimiento reducido y pausa animaciones al desmontar componentes. Eso basta para una UI fluida.
