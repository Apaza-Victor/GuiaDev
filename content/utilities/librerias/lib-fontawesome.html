¿Para qué sirve y cuándo usarla? Concepto

Font Awesome es la colección de iconos más extendida: miles de iconos en estilos solid, regular, brands y duotone, servidos como fuente o como SVG. Se integra por CSS (clases `fas`, `far`, `fab`) o mediante componentes en frameworks.

¿Para qué se usa?

  • Insertar iconos con `` sin gestionar SVGs a mano.
  • Añadir iconos de marca: `fab fa-github`, `fab fa-twitter`, etc.
  • Estilizar iconos con font-size, color, rotación y animaciones.
  • Montar iconos SVG en Vue o React con los componentes oficiales.

¿En qué casos conviene usarla?

  • Sitios corporativos con iconografía de calidad sin diseñar SVGs propios.
  • Redes sociales, enlaces y botones con iconos de marca reconocible.
  • Prototipos rápidos con un catálogo enorme disponible al instante.

Cargar la fuente completa pesa en el bundle; para producción importa solo los iconos que usas o usa SVGs individuales. En iconos decorativos añade `aria-hidden` para no romper la accesibilidad.

---

Instalación Paso 1

npm

    npm install @fortawesome/fontawesome-free

CDN

    <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css">

Integración Paso 2

JavaScript Vanilla

<!-- Usando clases CSS -->
<i class="fas fa-user"></i>

<script>
  // Importar desde node_modules
  import '@fortawesome/fontawesome-free/css/all.min.css';
</script>

Vue.js

<!-- App.vue -->
<template>
  <i class="fas fa-user"></i>
</template>

<script>




library.add(faUser, faHeart, faGithub)

// Uso
<FontAwesomeIcon icon="user" />`} lang="javascript" />

## Mejores Prácticas <Badge text="Recomendado" variant="success" />

### Componente Reutilizable
<Code code={`// components/Icon.jsx


export function Icon({ 
  name, 
  type = 'fas',
  size = '1x',
  className = '',
  ...props 
}) {
  return (
    <FontAwesomeIcon
      icon={[type, name]}
      size={size}
      className={className}
      {...props}
    />
  )
}

// Uso
<Icon name="user" type="far" size="2x" className="text-primary" />`} lang="javascript" />

### Accesibilidad
jsx

// Bueno: Usar title y aria-label

icon="user"

title="Perfil de usuario"

aria-label="Ver perfil de usuario"

/>

// Bueno: Icono decorativo

icon="user"

aria-hidden="true"

/>

```
