¿Para qué sirve y cuándo usarla? Concepto

Swiper es el slider y carrusel más completo para web y móvil: soporta gestos táctiles, scrollbar, rueda del mouse, autoplay, breakpoints responsive y una arquitectura modular por la que cargas solo los módulos que usas (navigation, pagination, etc.).

¿Para qué se usa?

  • Crear carruseles de imágenes, testimonios o productos con gestos táctiles.
  • Configurar breakpoints para mostrar 1, 2 o N slides según la pantalla.
  • Añadir navegación, paginación, autoplay, loop y espacio entre slides.
  • Usar modos virtual, thumbs o efectos coverflow y cube para galerías.

¿En qué casos conviene usarla?

  • Homepages con destacados en slider y catálogos de productos.
  • Tarjetas o recomendaciones que deben deslizarse en móvil.
  • Galerías con thumbs y efectos de transición atractivos.

Para carruseles muy simples, un scroll horizontal con `overflow-x: auto` y CSS puede bastar. Swiper aporta valor cuando necesitas gestos, autoplay, loop y control de módulos avanzado.

Slider Básico Paso 2

const swiper = new Swiper('.swiper', {
  loop: true,                 // bucle infinito
  slidesPerView: 1,           // cuántos a la vez
  spaceBetween: 16,
  speed: 600,
  grabCursor: true
});

// Instancias independientes
const cardSwiper = new Swiper('#cards', {
  slidesPerView: 3,
  breakpoints: {
    320:  { slidesPerView: 1 },
    768:  { slidesPerView: 2 },
    1024: { slidesPerView: 3 }
  }
});

La estructura es fija: `.swiper` > `.swiper-wrapper` > `.swiper-slide`. Inicializar con `new Swiper(el, opciones)` bastará para una galería básica responsive.

Navegación y Paginación Paso 3

<div class="swiper">
  <div class="swiper-wrapper">...</div>
  <div class="swiper-pagination"></div>
  <div class="swiper-button-prev"></div>
  <div class="swiper-button-next"></div>
  <div class="swiper-scrollbar"></div>
</div>

import { Swiper, Navigation, Pagination, Scrollbar } from 'swiper';
Swiper.use([Navigation, Pagination, Scrollbar]);

const swiper = new Swiper('.swiper', {
  navigation: { nextEl: '.swiper-button-next', prevEl: '.swiper-button-prev' },
  pagination: { el: '.swiper-pagination', clickable: true },
  scrollbar: { el: '.swiper-scrollbar', draggable: true }
});

Con módulos, registra solo los que usas (`Swiper.use([...])`). `pagination.clickable` permite saltar a cualquier slide desde los puntos.

Módulos y Opciones Paso 4

import { Swiper, Autoplay, EffectFade, Parallax } from 'swiper';
Swiper.use([Autoplay, EffectFade, Parallax]);

const swiper = new Swiper('.swiper', {
  effect: 'fade',             // transición suave en vez de slide
  autoplay: {
    delay: 3500,
    disableOnInteraction: false,
    pauseOnMouseEnter: true
  },
  parallax: true,
  speed: 800
});

// Altura automática según el contenido
new Swiper('.documento', { autoHeight: true });

// Un slide por "página" con snap
new Swiper('.libro', { slidesPerView: 'auto', centeredSlides: true });

`autoplay.pauseOnMouseEnter` evita que el carrusel "se escape" cuando el usuario quiere leer. `effect:'fade'` es ideal para hero banners con texto sobre imagen.

Autoplay y Breakpoints Paso 5

const swiper = new Swiper('.swiper', {
  slidesPerView: 1,
  spaceBetween: 12,
  loop: true,

  breakpoints: {
    640:  { slidesPerView: 2, spaceBetween: 16 },
    1024: { slidesPerView: 4, spaceBetween: 24 }
  },

  autoplay: { delay: 2500, disableOnInteraction: false }
});

// API de control
swiper.slideNext();
swiper.slidePrev();
swiper.slideTo(3, 500);       // índice, velocidad
swiper.autoplay.stop();
swiper.autoplay.start();
swiper.update();              // tras añadir slides dinámicamente

Los `breakpoints` permiten cambiar `slidesPerView`, espacio y navegación según el ancho del viewport. Si añades slides con AJAX, llama a `swiper.update()` (o `slideTo`, etc.) después de re-renderizar.

Ejercicios prácticos Reto

  1. Monta una galería de 6 imágenes con loop, navegación por flechas y puntos clicables.
  2. Haz un hero slider con `effect:'fade'`, autoplay y pausa al pasar el ratón.
  3. Configura una versión responsive: 1 slide en móvil, 3 en tablet y 5 en escritorio.
  4. Añade una barra de scroll con `scrollbar` y prueba arrastrarla.
  5. Controla el slider desde un botón externo con `slideNext` y `slidePrev`.
