¿Para qué sirve y cuándo usarla? Concepto

p5.js es la librería de creative coding que transforma el navegador en un boceto: dibujas formas, imágenes y texto en un canvas usando funciones globales (`ellipse`, `fill`, `mouseX`) y un bucle `draw()` que corre unas 60 veces por segundo.

¿Para qué se usa?

  • Dibujar arte generativo y visuales interactivas en canvas.
  • Crear sketches que responden al input del usuario: mouse, teclado o cámara.
  • Animar elementos con el bucle `draw()` y pausarlo con `noLoop()`.
  • Prototipar ideas visuales con una API muy accesible.

¿En qué casos conviene usarla?

  • Landing pages y webs con fondos de arte generativo o partículas propias.
  • Talleres y educación donde se enseña lógica visual a principiantes.
  • Prototipos de visuales, juegos sencillos o experimentos interactivos.

Su rendimiento se degrada con demasiados objetos por frame. Para partículas masivas o efectos de producción, tsParticles o shaders con WebGL son mejores; y para juegos serios encaja mejor un motor como Phaser.

p5.js es la puerta de entrada al creative coding: dibujas en un canvas con funciones globales (`ellipse()`, `fill()`, `mouseX`...) y cada frame vuelve a ejecutar `draw()`. Perfecto para arte generativo.

setup y draw Paso 2

function setup() {
  createCanvas(600, 400);
  background(30, 30, 45);
}

function draw() {
  // Se ejecuta ~60 veces por segundo
  ellipse(mouseX, mouseY, 20, 20);
}

function setup() {
  createCanvas(400, 400);
}

function draw() {
  background(0, 0, 0, 10);   // semitransparente: rastro difuso
  noStroke();
  fill(245, 158, 11);
  circle(random(width), random(height), 12);
}

`setup()` se ejecuta una vez y `draw()` en bucle. El truco del "rastro" usa un `background` con alfa bajo: cada frame deja una estela sin borrar del todo.

Formas y Color Paso 3

function setup() {
  createCanvas(600, 400);
}

function draw() {
  background('#1e293b');

  // Formas básicas
  circle(80, 80, 60);                 // círculo (x, y, diámetro)
  rect(160, 80, 90, 60, 8);           // rectángulo redondeado
  line(280, 80, 340, 140);            // línea
  triangle(370, 140, 400, 80, 430, 140);
  arc(500, 110, 70, 70, 0, PI / 2);   // arco (en radianes)

  // Color con alfa
  noStroke();
  fill(16, 185, 129, 120);            // RGB + transparencia
  circle(120, 260, 90);
  fill(59, 130, 246, 120);
  circle(180, 260, 90);
  fill(245, 158, 11, 120);
  circle(150, 210, 90);
}

Los verbos son intuitivos: `fill()` rellena, `stroke()` el borde, `noStroke()`/`noFill()` los desactivan. Los ángulos van en radianes con `PI`. El alfa permite composiciones de patrones superpuestos.

Interacción con el Mouse Paso 4

function setup() {
  createCanvas(600, 400);
}

function draw() {
  background(20);

  // Paleta según posición del ratón
  const r = map(mouseX, 0, width, 0, 255);
  const g = map(mouseY, 0, height, 255, 0);
  fill(r, g, 150);

  noStroke();
  push();
  translate(width / 2, height / 2);
  scale(map(mouseX, 0, width, 0.5, 2));
  circle(0, 0, 120);
  pop();
}

function mousePressed() {
  console.log('clic en', mouseX, mouseY);
}

function mouseDragged() {
  stroke(255);
  strokeWeight(4);
  point(mouseX, mouseY);   // dibuja mientras arrastras
}

`map()` re-escala un valor de un rango a otro (aquí convierte la posición en color/escala). `push()`/`pop()` guardan y restauran el sistema de coordenadas para transformaciones locales.

Aleatoriedad y Ruido Paso 5

// ruido: valores suaves y orgánicos (Perlin noise)
let t = 0;

function setup() {
  createCanvas(600, 400);
  background(10);
}

function draw() {
  const x = noise(t * 0.01) * width;        // 0..1 suavizado
  const y = noise(t * 0.01 + 5) * height;
  fill(245, 158, 11, 40);
  noStroke();
  circle(x, y, 6);
  t++;
}

// tirada aleatoria clásica
function setup() {
  createCanvas(300, 300);
  background(0);
}

function draw() {
  noStroke();
  fill(random(60, 255), random(100), random(140, 255));
  square(random(width), random(height), random(5, 30));
  if (frameCount > 300) noLoop();   // se detiene tras 300 frames
}

Evita `random()` puro para el movimiento de fondo: cada frame da saltos bruscos. Para desplazamientos "orgánicos", `noise()` produce cambios correlacionados; incrementa `t` poco a poco para transiciones suaves.

Ejercicios prácticos Reto

  1. Dibuja un círculo que siga al ratón cambiando de color según su posición.
  2. Genera una lluvia de partículas que deje un rastro con `background` alfa bajo.
  3. Crea una roseta de 12 triángulos rotados alrededor del centro con `push/translate/rotate`.
  4. Usa `noise` para mover una "serpiente" de puntos orgánicamente por el canvas.
  5. Detén la animación con `noLoop()` y actívala de nuevo con el clic (`mousePressed`).
