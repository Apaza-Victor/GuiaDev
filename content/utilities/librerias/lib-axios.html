Instalación Paso 1

npm

npm install axios

CDN

<script src="https://cdn.jsdelivr.net/npm/axios@1.7.2/dist/axios.min.js"></script>

Import

import axios from 'axios';

Axios es un cliente HTTP basado en Promesas, compatible con Node y navegador. Aporta interceptors, cancelación, progreso de descarga y transformación de datos sobre la API de `fetch`.

---

Peticiones Básicas Paso 2

// GET con promesa
axios.get('https://api.example.com/usuarios')
  .then(r => console.log(r.data))
  .catch(e => console.error(e.message));

// GET con async/await
async function cargarUsuarios() {
  const { data } = await axios.get('/usuarios');
  return data;
}

// POST con cuerpo
const res = await axios.post('/usuarios', {
  nombre: 'Ana', edad: 30,
});

// PUT / PATCH / DELETE
await axios.put('/usuarios/1', { edad: 31 });
await axios.delete('/usuarios/1');

// Parámetros de query
axios.get('/usuarios', { params: { rol: 'admin', page: 2 } });

// Encabezados personalizados
axios.get('/protegido', {
  headers: { Authorization: 'Bearer token' },
});

En GET los datos viajan en `params` (axios los serializa a query string). El cuerpo ya viene parseado en `res.data`; con fetch habría que hacer `res.json()`.

Instancia y Configuración Global Paso 3

// Cliente con baseURL y defaults
const api = axios.create({
  baseURL: 'https://api.example.com/v2',
  timeout: 10000,
  headers: { 'Content-Type': 'application/json' },
});

api.get('/dashboard');   // => https://api.example.com/v2/dashboard

// Configuración global
axios.defaults.baseURL = 'https://api.example.com';
axios.defaults.withCredentials = true;

// Manejo común de errores
api.interceptors.response.use(
  (r) => r,
  (error) => {
    if (error.response?.status === 401) redirectToLogin();
    return Promise.reject(error);
  }
);

Crear una instancia con `baseURL` evita repetir la URL a cada llamada y facilita apuntar a un entorno distinto (dev/staging/prod) cambiando una sola línea.

Interceptors y Manejo de Errores Paso 4

// Interceptor de petición: añadir token dinámicamente
api.interceptors.request.use((config) => {
  const token = sessionStorage.getItem('token');
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});

// Estructura del objeto de error
try {
  await api.get('/usuarios');
} catch (error) {
  if (error.response) {
    // el servidor respondió con un status fuera de 2xx
    console.log(error.response.status, error.response.data);
  } else if (error.request) {
    // no hubo respuesta (red caída, timeout)
    console.log('Sin respuesta del servidor', error.request);
  } else {
    console.log('Error configurando la petición', error.message);
  }
}

// Error con respuesta esperada (ej. 404)
axios.isAxiosError(error);

Diferencia los tres escenarios de error: respuesta con status (server reachable), sin respuesta (problema de red/timeout) y error de configuración. Trátalos por separado y muestra UX distinta.

Cancelación y Concurrencia Paso 5

// Cancelar peticiones con AbortController
const controller = new AbortController();
axios.get('/grande', { signal: controller.signal });

setTimeout(() => controller.abort(), 2000);

// Peticiones en paralelo
const [user, posts] = await Promise.all([
  api.get('/usuario'),
  api.get('/posts'),
]);

// Cancelar búsquedas antiguas (patrón usa de tipoahead)
let current = null;
async function buscar(term) {
  current?.abort();
  current = new AbortController();
  const { data } = await api.get('/search', {
    params: { q: term },
    signal: current.signal,
  });
  showResults(data);
}

El patrón de cancelar la petición anterior es la forma correcta de implementar autocompletado sin carreras (respuestas fuera de orden). `signal` funciona igual en `fetch`.

Ejercicios prácticos Reto

  1. Crea una instancia de axios con `baseURL` a `https://jsonplaceholder.typicode.com` y haz un GET a `/users` mostrando nombres.
  2. Implementa un post con `axios.post` enviando un JSON y lee la respuesta con `status` 201.
  3. Agrega un interceptor de petición que inyecte el token de `sessionStorage`.
  4. Simula un error 404 y captura `error.response.status` para mostrar "recurso no encontrado".
  5. Usa `AbortController` para cancelar una búsqueda de largo tiempo y evita carreras.
