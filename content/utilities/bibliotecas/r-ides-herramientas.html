RStudio (ahora Posit) incluye integración con renv, paquetes (devtools), Git y Shiny. Es lo primero que se instala tras R.

---

renv, pak y radian Entorno

# renv: aislamiento de librerías por proyecto
install.packages("renv")
renv::init()          # crea .renv + lockfile
renv::snapshot()      # guarda estado
renv::restore()       # recrea entorno desde lockfile

# pak: instalación rápida y consistente (paralela, binarios)
install.packages("pak")
pak::pak("tidyverse")
pak::install_github("r-lib/conflicted")

# radian: consola R mejorada para terminal (autocompletado, history)
pip install radian
radian

Mantén un lockfile con renv y compatívelo en git. `pak` acelera las instalaciones y `radian` hace el uso de R en terminal placentero.

Depuración y perfilado en R Diagnóstico

# Depuración interactiva
browser()             # pausa la ejecución y entra al debugger
traceback()           # pila tras un error
debug(función)        # ejecutar paso a paso esa función

# Perfilado
Rprof("perfil.out")
# ... código lento ...
Rprof(NULL)
summaryRprof("perfil.out")

# Alternativas
# profvis::profvis({ ... }) gráfico de llamadas interactivo
library(profvis)
profvis({
  for (i in 1:1000) { mean(rnorm(1000)) }
})

# Memoria: pryr::mem_used(), bench::mark() para microbenchmarks

`profvis` visualiza cuellos de botella; `bench::mark()` compara implementaciones al instante. Depurar desde el botón "Debug" de RStudio es lo natural.

Estilo y linting: styler y lintr Calidad

install.packages(c("styler", "lintr"))

# Formateo automático (estilo tidyverse)
styler::style_file("analisis.R")
styler::style_active_file()      # en RStudio
# pre-commit: precommit::use_precommit() para hooks de git

# Linting
lintr::lint("analisis.R")
# RStudio: Addins -> Style active file / Check with lintr

`styler` normaliza el código al estilo tidyverse y `lintr` señala problemas de base: espacios, longitud de línea y malas prácticas.
