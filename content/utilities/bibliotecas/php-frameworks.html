¿Para qué sirve y cuándo usarla? Concepto

PHP tiene frameworks maduros para cada tamaño de proyecto. Esta página compara Laravel, el más popular y completo; Symfony, robusto y modular; y Slim, minimalista para microservicios, para elegir según la complejidad que necesites.

¿Para qué se usa?

  • Desarrollar aplicaciones completas con ORM, autenticación y más con Laravel.
  • Montar aplicaciones modulares y de largo recorrido con Symfony.
  • Publicar APIs y microservicios ligeros con Slim.

¿En qué casos conviene usarla?

  • En aplicaciones de negocio con plazos ajustados que buscan productividad.
  • En equipos que prefieren piezas reutilizables y estándares.
  • En backends de API donde sobra el peso de un framework completo.

No elijas framework por popularidad: Laravel resuelve rápido pero impone convenciones, Symfony es más explícito y Slim te deja todo por hacer. Mide la mantenibilidad a largo plazo, no las tendencias.

Elegir framework PHP Guía

# Laravel: el más productivo y popular (ORM Eloquent + Blade)
composer create-project laravel/laravel mi-app
# Symfony: componentes y rigor empresarial (Twig + Doctrine)
composer create-project symfony/skeleton mi-app
# Slim: micro-framework para APIs y apps minimalistas
composer create-project slim/slim-skeleton mi-app

# Alternativas: Laminas (Zend), CakePHP, CodeIgniter, Phalcon
# La tendencia moderna: Laravel API + JSON hoy en día con SPA/Inertia

Laravel para velocidad de desarrollo y ecosistema (Forge, Nova, Livewire); Symfony para componentes estándar y larga vida; Slim para REST minimalista.

Laravel: rutas, Eloquent y Blade Framework

<?php
// routes/web.php
Route::get('/usuarios', [UsuarioController::class, 'index']);

// Eloquent: ORM fluido
use App\Models\Usuario;
$adultos = Usuario::where('edad', '>=', 18)
                  ->orderBy('nombre')
                  ->paginate(10);

// Blade: template con sintaxis amigable
// <h1>{{ $titulo }}</h1>
// @forelse($usuarios as $u) ... @empty ... @endforelse

// Artisan: herramientas
php artisan make:model Usuario -m     # modelo + migración
php artisan migrate
php artisan make:controller UsuarioController --resource

Artisan genera código, Eloquent abstrae la BD y Blade evita mezclar PHP/HTML. Ese trío te da apps web completas en muy pocos comandos.

Symfony: estructura estándar de la industria Framework

<?php
// config/routes.yaml
# usuarios:
#   path: /usuarios
#   controller: App\Controller\UsuarioController::index

// src/Controller/UsuarioController.php
namespace App\Controller;
use Symfony\Bundle\FrameworkBundle\Controller\AbstractController;
use Symfony\Component\HttpFoundation\JsonResponse;

class UsuarioController extends AbstractController {
  public function index(): JsonResponse {
    return $this->json(['usuarios' => [['id' => 1, 'nombre' => 'Ana']]]);
  }
}
// console: php bin/console server:run, make:entity, d:m:m

Symfony es "de facto" el estándar PHP: sus componentes (HttpKernel, Console, DependencyInjection) viven dentro de Laravel y de muchas plataformas (como el propio Composer).

Slim: micro APIs API

<?php
use Slim\Factory\AppFactory;
use Psr\Http\Message\ResponseInterface as Response;
use Psr\Http\Message\ServerRequestInterface as Request;

require __DIR__ . '/../vendor/autoload.php';

$app = AppFactory::create();

$app->get('/saludo/{nombre}', function (Request $req, Response $res, array $args) {
    $payload = json_encode(['saludo' => 'Hola ' . $args['nombre']]);
    $res->getBody()->write($payload);
    return $res->withHeader('Content-Type', 'application/json');
});

$app->post('/usuarios', function (Request $req, Response $res) {
  $datos = json_decode($req->getBody()->getContents(), true);
  // ... guardar ...
  return $res->withStatus(201);
});

$app->run();

Slim trae routing, middleware y PSR-7 sin capas extra. Perfecto para microservicios REST o prototipos que luego escalan a Laravel/Symfony.

PHPUnit y Pest Calidad

<?php
// PHPUnit clásico
use PHPUnit\Framework\TestCase;

class CalculadoraTest extends TestCase {
  public function testSuma(): void {
    $this->assertEquals(5, Calculadora::suma(2, 3));
  }
}

// Pest (Laravel): sintaxis funcional
it('suma dos números', function () {
  expect(suma(2, 3))->toBe(5);
});

// Correr: vendor/bin/phpunit --testdox
// TDD en Laravel: $this->get('/usuarios')->assertOk();

PHPUnit es el estándar; Pest lo envuelve con sintaxis moderna (muy adoptado en Laravel). Ambos se ejecutan con el binario de Composer.
