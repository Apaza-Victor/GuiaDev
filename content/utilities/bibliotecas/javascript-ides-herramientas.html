// eslint.config.js (flat config moderno)
import js from "@eslint/js";
export default [
  js.configs.recommended,
  {
    files: ["src/**/*.js"],
    rules: {
      "no-unused-vars": "warn",
      "eqeqeq": ["error", "always"],
      "quotes": ["error", "double"],
      "curly": "error",
    },
  },
];

// .prettierrc
{
  "semi": true,
  "singleQuote": false,
  "trailingComma": "all",
  "printWidth": 100
}

ESLint flat config (9+) con `recommended` + tus reglas; Prettier para formato "opinionado" sin discusiones. Evita que ambos se pisen (reglas de formato fuera de ESLint).

Debug y rendimiento Diagnóstico

# Navegador: DevTools -> Sources con breakpoints, watch & call stack
# Performance panel: graba y busca "long tasks"
# Node: node --inspect y attach del editor
node --inspect dist/server.js

# CPU: node --prof
node --prof app.js && node --prof-process isolate-*.log
# Memoria: (DevTools Memory) o en Node --heapsnapshot
# npm runs: `node --trace-gc` para ver ciclos de GC

El profiler del navegador muestra "long tasks" y el panel Performance; para bibliotecas grandes, chrome.devtools "Memory" con heap snapshot. Todo gratis.

Bundlers: Vite, esbuild, Webpack Build

# Vite: arranque instantáneo, HMR y bundle final con Rollup (lo recomendado)
npm create vite@latest
# esbuild: transformador rápido para libraries/tooling
npx esbuild src/main.js --bundle --minify --outfile=dist/main.js
# Webpack/Rspack: completo y configurable (legacy en muchos proyectos)
# tsup: wrappers sobre esbuild para librerías (genera CJS/ESM/d.ts)
# Yet another: Parcel (zero-config), Rollup (librerías puras)
# knip: detecta dependencias y exports sin usar
npx knip

Para apps nuevas: Vite. Para librerías: tsup/Rollup. Webpack sigue existiendo en proyectos heredados; Rspack es su sucesor en velocidad.

Guardas de despliegue JS Cloud

# GitHub Actions típico para un paquete Node
- uses: actions/setup-node@v4
  with: { node-version: 20, cache: 'npm' }
- run: npm ci
- run: npm run lint
- run: npm test -- --coverage
- run: npm run build

FROM node:20-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci --omit=dev
COPY dist ./dist
COPY --from=build /app/node_modules ./node_modules
CMD ["node", "dist/index.js"]

CI: `npm ci` (lockfile) + lint + test + build. Deploy: multi-stage con `--omit=dev` y solo el dist. Para Vite/SPA, sirve el dist estático desde cualquier CDN o con Nginx.
