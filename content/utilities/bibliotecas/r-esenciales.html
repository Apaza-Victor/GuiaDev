ggplot2: visualización Gráficos

library(ggplot2)

# Gramática de gráficos: capas de datos, estética y geometría
ggplot(mtcars, aes(x = wt, y = mpg, color = cyl)) +
  geom_point(size = 3) +
  geom_smooth(method = "lm", se = FALSE) +
  labs(title = "Peso vs consumo",
       x = "Peso (1000 lbs)", y = "Mpg") +
  theme_minimal()

# Barras y cajas
ggplot(diamonds, aes(x = cut)) + geom_bar()
ggplot(iris, aes(x = Species, y = Sepal.Length)) + geom_boxplot()

# Guardar y animar
ggsave("grafico.png", width = 8, height = 5, dpi = 300)
# gganimate + gifski para gráficos animados

ggplot2 separa datos, estética y geometría en capas; es el estándar para publicaciones. Para interactivos: `plotly::ggplotly()` convierte cualquier ggplot.

data.table y bases de datos Datos

library(data.table)

# data.table: velocidad en datasets grandes
dt <- data.table(id = 1:1e5, grupo = sample(letters[1:5], 1e5, TRUE), valor = rnorm(1e5))
dt[grupo == "a", mean(valor)]              # filtro + agregación
dt[, .(media = mean(valor)), by = grupo]   # agrupar en una línea

# Conectar a BD: DBI + duckdb / odbc
library(DBI)
con <- dbConnect(duckdb::duckdb(), dbdir = ":memory:")
dbWriteTable(con, "ventas", dt)
ventas <- dbGetQuery(con, "SELECT grupo, AVG(valor) FROM ventas GROUP BY grupo")

# Leer CSV fast: readr::read_csv (o fread de data.table)
```

`data.table` y `dplyr` coexisten bien; elige `data.table` para tablas enormes o sintaxis compacta y `dplyr` para claridad en pipelines.

purrr y stringr: funciones y texto Utilidad

library(purrr)
library(stringr)

# purrr: aplica funciones por columnas/listas
nums <- list(1:3, 4:6, 7:9)
nums |> map(sum) |> unlist()

# map con tipos
map_dbl(iris[1:4], mean)     # media de cada columna numérica

# stringr: manipulacion moderna de texto
frases <- c("  Hola Mundo  ", "guia, de, desarrollo")
str_trim(frases[1])                      # eliminar espacios
str_to_title(frases[1])                  # " Hola Mundo "
str_split(frases[2], ", ") |> unlist()   # separar
str_detect(frases, "guia")               # lógico

# combo: glue escribe strings
library(glue)
nombre <- "Ana"; edad <- 30
glue("Hola {nombre}, tienes {edad} años")

`purrr::map*`, `stringr::str_*` y `glue::glue` son la tríada funcional/texto del tidyverse con la que se escribe R idiomático moderno.
