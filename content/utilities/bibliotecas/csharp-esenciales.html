¿Para qué sirve y cuándo usarla? Concepto

La Base Class Library de .NET (BCL) ofrece colecciones, LINQ, I/O, JSON, HTTP y muchas utilidades dentro del SDK. Esta página repasa lo esencial de la BCL y de librerías auxiliares habituales que conviene conocer para desarrollar en C# sin reinventar la rueda.

¿Para qué se usa?

  • Estructuras de datos y consultas expresivas con colecciones y LINQ.
  • Entrada y salida, serialización JSON y acceso HTTP desde el propio SDK.
  • Fechas, reflexión, opciones y utilidades de programación general.
  • Complementos comunes como paquetes NuGet para dominios concretos.

¿En qué casos conviene usarla?

  • En casi cualquier aplicación .NET: la BCL cubre la mayoría de necesidades base.
  • Para proyectos web, de escritorio, de datos o de automatización en el ecosistema .NET.
  • Cuando quieres tipado fuerte, rendimiento y un ecosistema maduro de paquetes.

No instales paquetes NuGet si la BCL ya lo resuelve: muchas utilidades de JSON, LINQ y HTTP vienen incluidas. Revisa primero la documentación base antes de añadir dependencias adicionales.

BCL y .NET: la librería base Base

La BCL (Base Class Library) incluye colecciones, LINQ, I/O, JSON, HTTP, DateOnly, Reflection y mucho más dentro del SDK.

using System;
using System.Collections.Generic;
using System.Linq;
using System.Text.Json;

// Colecciones y LINQ
var lista = new List<int> { 5, 1, 4, 2, 3 };
var pares = lista.Where(n => n % 2 == 0).OrderBy(n => n).ToList();
var promedio = lista.Average();

var dict = new Dictionary<string, int> { ["Ana"] = 30, ["Bruno"] = 25 };
dict.TryGetValue("Ana", out int edadAna);

// JSON nativo (System.Text.Json)
var json = JsonSerializer.Serialize(new { Nombre = "Ana", Edad = 30 });
var doc   = JsonDocument.Parse(json);
string nombre = doc.RootElement.GetProperty("Nombre").GetString()!;

// I/O moderno
string texto = File.ReadAllText("datos.txt");
File.WriteAllLines("out.txt", lista.Select(x => x.ToString()));

.NET (BCL) te da casi todo: LINQ para pipelines, System.Text.Json para JSON y System.Net.Http para peticiones. Con lo que trae el SDK resuelves el 80% de tareas.

Configuración y logging con Microsoft.Extensions Utilidad

// appsettings.json
{
  "Conexion": "Server=db;Database=app;User Id=sa;",
  "DominiosPermitidos": ["localhost", "guia.dev"]
}

using Microsoft.Extensions.Configuration;
using Microsoft.Extensions.Logging;

var config = new ConfigurationBuilder()
    .AddJsonFile("appsettings.json")
    .AddEnvironmentVariables()
    .Build();

string? conexion = config["Conexion"];
var dominios     = config.GetSection("DominiosPermitidos").Get<string[]>();

// Logging: abstracción estándar (Microsoft.Extensions.Logging)
ILogger<Program> log = ...;   // llega inyectado en ASP.NET Core
log.LogInformation("Servicio en puerto {Puerto}", 8080);
log.LogWarning("Memoria al {Porcentaje}%", 87);
log.LogError(ex, "Falló el inicio");
// En consola: builder.Services.AddConsole(); AddDebug(); Aplicar a file (Serilog)

La configuración tipada con strong-typed Options + logging por abstracción son el estándar ASP.NET Core, reutilizables en cualquier app .NET.

FluentValidation y AutoMapper Diseño

// FluentValidation: validación declarativa
using FluentValidation;

public class UsuarioValidator : AbstractValidator<Usuario> {
  public UsuarioValidator() {
    RuleFor(u => u.Email).NotEmpty().EmailAddress();
    RuleFor(u => u.Edad).InclusiveBetween(18, 120)
      .WithMessage("Edad inválida");
  }
}
var resultado = new UsuarioValidator().Validate(usuario);

// AutoMapper: mapeo DTO ↔ entidad
using AutoMapper;

var config = new MapperConfiguration(cfg =>
    cfg.CreateMap<Usuario, UsuarioDTO>()
       .ForMember(d => d.EdadEn, o => o.MapFrom(s => DateTime.Now.Year - s.AnioNacimiento)));
var mapper = config.CreateMapper();
UsuarioDTO dto = mapper.Map<UsuarioDTO>(usuario);

FluentValidation se integra con ASP.NET.Core (validación automática en controllers). AutoMapper evita mapeos manuales repetitivos en capas DTO/Entity.

Instalación del SDK de .NET Inicio

# Windows: instalador dotnet cli
winget install Microsoft.DotNet.SDK.8

# Linux/macOS
curl -fsSL https://dot.net/v1/dotnet-install.sh | bash
# o: sudo apt install dotnet-sdk-8.0 (Debian/Ubuntu)

# Verificar y hola mundo
dotnet --list-sdks
dotnet new console -o Hola && cd Hola && dotnet run
dotnet new webapi -o Api          # API mínima ASP.NET Core

Elige la versión LTS (8 actualmente). Visual Studio o VS Code + C# Dev Kit son los editores; Rider alternativa potente.
