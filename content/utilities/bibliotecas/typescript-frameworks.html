tRPC: APIs tipadas de extremo a extremo API

// Server (trpc/router.ts)
import { initTRPC } from "@trpc/server";

const t = initTRPC.create();

export const appRouter = t.router({
  saludar: t.procedure
    .input((i: unknown) => i as string)
    .query(({ input }) => `Hola ${input}`),
  crearUsuario: t.procedure
    .input(UsuarioSchema)
    .mutation(async ({ input }) => {
      return await usuariosInserto(input);
    }),
});
export type AppRouter = typeof appRouter;

// Client (trpc/Client.ts): tipos inferidos desde el server
import { createTRPCProxyClient, httpBatchLink } from "@trpc/client";
import type { AppRouter } from "@/server/router";

const trpc = createTRPCProxyClient<AppRouter>({
  links: [httpBatchLink({ url: "/api/trpc" })],
});

const saludo = await trpc.saludar.query("GuiaDev");
// autocompletado y chequeo de tipos en el cliente sin generar tipos

tRPC elimina el "puente" REST: el cliente conoce el contrato directamente. Excelente para apps full-Stack con Next.js/nod servers perezosos.

NestJS: arquitectura empresarial Backend

import { Controller, Get, Body, Post, Injectable } from "@nestjs/common";

@Injectable()
export class UserService {
  private datos = [{ id: 1, nombre: "Ana" }];
  findAll() { return this.datos; }
  create(u: { nombre: string }) { return this.datos.push({ id: 2, ...u }); }
}

@Controller("usuarios")
export class UserController {
  constructor(private readonly svc: UserService) {}

  @Get()
  lista() { return this.svc.findAll(); }

  @Post()
  crear(@Body() body: { nombre: string }) { return this.svc.create(body); }
}

NestJS ofrece DI (inyección), módulos, guards, pipes y validación con class-validator. Ideal para equipo que ya usa Angular en estructura.

Prisma + tRPC: datos con tipos Datos

// schema.prisma
model Usuario {
  id     Int      @id @default(autoincrement())
  nombre String
  email  String   @unique
  ordenes Orden[]
}
model Orden {
  id        Int @id @default(autoincrement())
  total     Decimal
  usuarioId Int
  usuario   Usuario @relation(fields: [usuarioId], references: [id])
}

npx prisma migrate dev --name init
npx prisma generate        # genera tipos para el cliente

import { PrismaClient } from "@prisma/client";
const prisma = new PrismaClient();

const usuario = await prisma.usuario.findUnique({
  where: { email: "ana@x.com" },
  include: { ordenes: true },
});

Prisma genera el cliente TS tipado directamente de tu schema; combinado con tRPC el flujo de datos queda con tipos de extremo a extremo.

Testing: Vitest y React Testing Library Calidad

// Vitest: ejecutor rápido (compatible con Vite)
import { describe, it, expect, vi } from "vitest";

describe("suma", () => {
  it("suma correcta", () => {
    expect(suma(2, 3)).toBe(5);
  });
});

// React Testing Library: probar componentes por comportamiento
import { render, screen, fireEvent } from "@testing-library/react";
import Contador from "./Contador";

it("incrementa al pulsar", async () => {
  render(<Contador />);
  fireEvent.click(screen.getByRole("button", { name: /increment/i }));
  expect(await screen.findByText("1")).toBeInTheDocument();
});

Vitest + RTL (para React) o similar para cada framework + happy-dom/jsdom: testea por comportamiento de usuario, no por detalles internos.
