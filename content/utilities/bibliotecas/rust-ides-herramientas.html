rustfmt, clippy y análisis Calidad

cargo fmt                 # formato obligatorio (no configurable)
cargo fmt -- --check      # para CI
cargo clippy -- -D warnings   # lint estricto (falla en warnings)

# Más herramientas
cargo audit                # vulnerabilidades en dependencias (cargo-audit)
cargo deny                 # licencias/duplicados/seguridad en un solo comando
cargo expand               # expande macros (depuración)
cargo nextest              # runner de tests paralelo y rápido

# evalúa estas en CI: fmt, clippy, test, audit

rustfmt (sin config) elimina las discusiones de estilo; clippy con `-D warnings` hace el lint automático; cargo-audit para vulnerabilidades.

Depuración y perfilado Rust Debug

# Debugger nativo: gdb (Linux) / lldb; en VS Code con extension vadimcn
# estrategias:
#   println!/eprintln! a secas (rápido en desarrollo)
#   assert! en invariantes
#   log + env_logger para logs estructurados
RUST_LOG=debug cargo run

# Perfilado
#   criterion (benchmarks)
cargo add --dev criterion
#   cargo flamphram / samply / perf para hot spots
#   tokio-console para ver tareas async (con feature inside)

# sanity: cargo test -- --nocapture para ver prints en tests

Compila `--release` para rendimiento real; en debug los asserts y usualmente son más lentos. Para benchmarks usa criterion, no un `time` a secas.

Compilación y despliegue Ops

# Binario estático (sin libc para Linux x86_64)
cargo build --release --target x86_64-unknown-linux-musl
# o con Docker multistage

FROM rust:1.80 AS build
WORKDIR /app
COPY Cargo.toml Cargo.lock ./
RUN mkdir src && echo "fn main(){}" > src/main.rs \
  && cargo build --release
COPY src src
RUN touch src/main.rs && cargo build --release

FROM alpine:3.20
WORKDIR /app
COPY --from=build /app/target/release/mi_app .
EXPOSE 3000
CMD ["./mi_app"]

Compila estático y tendrás un binario de ~10-20MB sin runtimes: la imagen final cabe en menos de 20MB y arranca en milisegundos.

Ejercicios prácticos Reto

  1. Instala rust-analyzer en VS Code y explora "go to definition" en tu crate.
  2. Pon `clippy -D warnings` en CI y corrige 4 lints en tu código.

  4. Añade criterion y un benchmark de 3 implementaciones de una función.
  5. Construye el binario estático y ejecútalo en una imagen alpine.
