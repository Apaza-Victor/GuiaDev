¿Para qué sirve y cuándo usarla? Concepto

Perl tiene un ecosistema web consolidado sobre PSGI y Plack. Esta página compara las opciones principales: Mojolicious, moderno y autosuficiente; Dancer2, minimalista y expresivo; y las bases de Plack para montar servicios a medida.

¿Para qué se usa?

  • Crear aplicaciones web o APIs con Mojolicious, con tareas y WebSocket incluidos.
  • Construir servicios ligeros y legibles con Dancer2.
  • Montar middleware HTTP personalizado sobre Plack y PSGI.

¿En qué casos conviene usarla?

  • En aplicaciones web de tamaño medio donde Perl ya no da miedo hoy.
  • Para migrar aplicaciones CGI antiguas hacia modelos PSGI modernos.
  • En APIs sencillas sobre infraestructura donde Perl viene instalado.

El catálogo de CPAN es enorme, pero no todo módulo está bien mantenido. Antes de adoptar uno revisa su antigüedad, su autor y sus dependencias, y para web quédate con los frameworks citados.

PSGI/Plack es la base común; Mojolicious es completo y moderno; Dancer2 minimalista; Catalyst MVC grande. Todos corren en Plack para producción.

---

Mojolicious: web moderno Web

# cpanm Mojolicious

use Mojolicious::Lite;

get '/' => sub { shift->render(text => 'Bienvenido') };

get '/saludo/:nombre' => sub {
  my $c = shift;
  $c->render(json => { saludo => "Hola $c->stash('nombre')" });
};

post '/usuarios' => sub {
  my $c = shift;
  my $datos = $c->req->json;
  $c->render(json => { recibido => $datos });
};

app->start;
# Ejecutar: perl app.pl daemon -l http://*:3000

Mojolicious trae todo de serie (router, JSON, templates, WebSocket, tests) sin depender Plack para desarrollarlo; producción con `daemon -l` o Starman+Gunilla.

Dancer2 y Catalyst Frameworks

# cpanm Dancer2

# Dancer2 (estilo Python Flask: simple)
use Dancer2;

get '/saludo/:nombre' => sub {
    my $nombre = route_parameters->get('nombre');
    return { saludo => "Hola $nombre" };
};

set(serializer => 'JSON');   # respuestas JSON automáticas
start;

# Catalyst (MVC): más estructura
#   cpan Catalyst::Runtime Catalyst::Devel
#    catalyst.pl MyApp ; cd MyApp ; MyApp\cgi\app.pl
#   rutas via MyApp::Controller::Root (Action + View TT)

Dancer2: micro-framework con serializer JSON y templates (Template Toolkit); Catalyst: MVC con Model/View/Controller completo, plugin de admin y Auth.

Persistencia: DBI, DBIx::Class Datos

use DBI;

my $dbh = DBI->connect("dbi:mysql:database=app", "root", "",
                       { mysql_enable_utf8 => 1 });
$dbh->do("INSERT INTO users (name) VALUES (?)", undef, 'Ana');
my $sth = $dbh->prepare("SELECT id, name FROM users WHERE id > ?");
$sth->execute(2);
while (my @row = $sth->fetchrow_array) { print "@row\n"; }
$dbh->disconnect;

# DBIx::Class (ORM): esquema declarativo estilo Active Record
#   cpanm DBIx::Class::Schema::Loader

DBI es el driver universal a BD (SQLite, MySQL, Postgres) con prepared statements. DBIx::Class construye un ORM con esquema declarativo si quieres OO.

Testing Perl: prove y Test::More Calidad

# t/basica.t
use strict; use warnings;
use Test::More;

sub suma { $_[0] + $_[1] }

is(suma(2, 3), 5, 'suma correcta');
ok(suma(1, 1) > 0, 'positivo');

done_testing;

# Correr: prove -l (dale a tests/ y lib/) o distbuild
prove -l t/
# Cobertura: Devel::Cover (cpanm Devel::Cover)
perl -MDevel::Cover -e1
prove -l && cover -report html
# TDD con TAP (Test Anything Protocol): interoperable entre lenguajes

Perl inventó TAP y `Test::More`; `prove` corre todos los tests de `t/`; Devel::Cover da informes de cobertura. Pruebas a HTTP: Test::Mojo (Mojolicious).
