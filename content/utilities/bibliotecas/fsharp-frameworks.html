Giraffe: HTTP funcional Backend

open Giraffe
open Microsoft.AspNetCore.Http
open Microsoft.Extensions.Hosting
open Microsoft.AspNetCore.Hosting

// HttpHandlers componibles
let webApp =
    choose [
        GET >=> route "/saludo/:nombre"
            >=> fun next ctx ->
                let nombre = ctx.GetRouteValue("nombre").ToString()
                json {| saludo = $"Hola {nombre}" |} next ctx
        POST >=> route "/datos" >=> bindJson >> (fun d -> json d)
        setStatusCode 404 >=> text "No encontrado"
    ]

[<EntryPoint>]
let main _ =
    Host.CreateDefaultBuilder()
        .ConfigureWebHostDefaults(fun wb ->
            wb.UseUrls("http://0.0.0.0:8080")
              .Configure(fun app ->
                  app.UseGiraffe(webApp)) |> ignore)
        .Build().Run()
    0

Giraffe expone composición de HttpHandlers con `>=>`, routing combinador y serialización a JSON. Corre en ASP.NET Core/Kestrel; muy natural para F#.

Saturn y SAFE Stack FullStack

open Saturn

let port = 8080us

let api =
    router {
        get "/saludo/:nombre" (fun next ctx ->
            let nombre = ctx.GetRouteValue("nombre").ToString()
            json {| saludo = $"Hola {nombre}" |} next ctx)
        post "/datos" (fun next ctx -> bindJson (fun d -> json d) next ctx)
    }

[<EntryPoint>]
let main _ =
    application {
        use_router api
        url "http://0.0.0.0:8080"
    } |> run
    0

// SAFE: Saturn server + Fable/Elmish cliente (React F#) + Azure
//  → s.t. El ecosistema SAFE comparte tipos F# cliente/servidor

Saturn simplifica con `router { }` la sintaxis de Giraffe y viene con pipelines de configuración. SAFE reúne lo mismo + Elmish para el frontend F# en JS.

Datos .NET: EF Core y Mio Datos

// EF Core (share con C#): ORM de Microsoft
open Microsoft.EntityFrameworkCore

type Context(dbc: DbContextOptions<Context>) =
    inherit DbContext(dbc)
    [<DefaultValue>] val mutable Usuarios: DbSet<Usuario>
    member _.UsuariosProp with get() = this.Usuarios and set v = this.Usuarios <- v

// Eliges por el estilo del equipo: siempre interoperable con C#

EF Core es el ORM del universo .NET y funciona en F#; Marten (Postgres document) encaja con el estilo funcional; FSharp.Data.SqlClient es para SQL directo tipado.

Testing: xUnit + FsUnit Calidad

// xUnit (estándar .NET) + FsUnit (matchers F#)
module Tests

open Xunit
open FsUnit.Xunit

[<Fact>]
let ``suma es correcta`` () =
    suma 2 3 |> should equal 5

[<Fact>]
let ``dividir por cero lanza`` () =
    (fun () -> divide 1 0 |> ignore) |> should throw typeof<System.DivideByZeroException>

// FsCheck (property testing, como QuickCheck)
open FsCheck.Xunit
[<Property>]
let ``suma conmuta`` a b = suma a b = suma b a

// Correr: dotnet test

xUnit es el marco .NET; FsUnit trae matchers idiomáticos; FsCheck hace property testing. Framework de mocks: NSubstitute/Moq (de C#) interoperan sin fricción.
