¿Para qué sirve y cuándo usarla? Concepto

Lua brilla dentro de otros sistemas y sus frameworks siguen esa filosofía. Esta página explora LÖVE para juegos 2D, OpenResty para el servidor Nginx, Lapis para aplicaciones web y el uso de Lua embebido en módulos.

¿Para qué se usa?

  • Crear juegos y prototipos 2D con el framework LÖVE.
  • Configurar y ampliar Nginx con Lua mediante OpenResty.
  • Desarrollar servicios web rápidos sobre OpenResty con Lapis.

¿En qué casos conviene usarla?

  • En prototipos de juegos donde importa iterar rápido.
  • En cachés, gateways y APIs de alto rendimiento configurables con Nginx.
  • Para ampliar aplicaciones que ya embeben Lua como motor de automatización.

LÖVE es 2D: para 3D pesado necesitas otro motor, y OpenResty exige conocer bien Nginx. No uses Lua para un backend complejo sin más motivo; úsalo donde el sistema anfitrión ya lo espera.

LÖVE: juegos 2D en Lua Juegos

-- main.lua de un LÖVE
function love.load()
  x, y = 400, 300
  vel = 300
end

function love.update(dt)
  if love.keyboard.isDown("left")  then x = x - vel * dt end
  if love.keyboard.isDown("right") then x = x + vel * dt end
end

function love.draw()
  love.graphics.circle("fill", x, y, 20)
  love.graphics.print("Pulsa flechas", 10, 10)
end

function love.keypressed(k)
  if k == "escape" then love.event.quit() end
end
-- Ejecutar: love .  (dentro de carpeta del proyecto)

LÖVE da callbacks (load/update/draw), input, audio, física (Box2D), sprites. Es el framework 2D más querido para prototipos y juegos indie en Lua.

Datos: SQLite + LuaSQL Datos

-- LuaSQL: SQL genérico (SQLite/Postgres/MySQL)
local luasql = require "luasql.sqlite3"
local env = luasql.sqlite3()
local conn = env:connect("app.db")

conn:execute("CREATE TABLE IF NOT EXISTS users (id INTEGER, name TEXT)")
conn:execute("INSERT INTO users VALUES (1, 'Ana')")

local cur = conn:execute("SELECT * FROM users")
row = cur:fetch({}, "a")
while row do
  print(row.id, row.name)
  row = cur:fetch(row, "a")
end
cur:close(); conn:close(); env:close()

-- En Lapis: el módulo "lapis.db" para modelos (query selector)

LuaSQL es la capa driver genérica (SQLite/Postgres/MySQL); en Lapis, `lapis.db` da un mini-ORM select de funciones para tus modelos.

Testing: busted y luaunit Calidad

-- busted (BDD, con pendiente)
describe("suma", function()
  it("suma dos números", function()
    assert.are.equal(5, suma(2, 3))
  end)
  it("maneja negativos", function()
    assert.are.equal(-1, suma(-2, 1))
  end)
end)
-- ejecutar: busted

-- luaunit (XUnit clásico)
local lu = require "luaunit"

TestSuma = {}
function TestSuma:test_sum()
  lu.assertEquals(suma(2,3), 5)
end
os.exit(lu.LuaUnit.run())

busted (BDD, magnífico con LuaJIT) o luaunit (simple). Se integran en CI: `busted` se instala con luarocks y deja salida TAP interoperable.
