Frameworks de CLI: shellcheck y bashly Calidad

# shellcheck: linting estático de Bash (imprescindible)
shellcheck deploy.sh
# bashate: estilo (indentación, líneas largas)
# shamirs/cli: generar comandos estructurados:
# args: bash-cli --flag valor

# Bats: framework de testing para Bash
git clone https://github.com/bats-core/bats-core
./install.sh /usr/local
# test_script.bats
@test "suma funciona" {
  run ./mi-script.sh 2 3
  [ "$status" -eq 0 ]
  [ "$output" = "5" ]
}
bats test_script.bats

shellcheck evita los bugs clásicos (unquoted vars, globbing); Bats hace tus scripts testeables igual que en otros lenguajes.

Ejecución en paralelo y control Concurrencia

# Precaución: los & son procesos en background; espera con wait
trabajo1() { sleep 2; echo "fin1"; }
trabajo2() { sleep 1; echo "fin2"; }
trabajo1 & trabajo2 &
wait                 # espera ambos

# xargs -P: paralelizar N ejecuciones
seq 1 8 | xargs -P 4 -I {} sh -c 'echo "proceso {}"; sleep 1'

# tareas programadas: cron / systemd timers
# 0 2 * * *  /ruta/backup.sh
# systemd: mi-job.timer permite calendar en logs y control de estado

# señales: trap, kill -TERM, nohup/disown para desmontar del terminal

Solo paraleliza con `&` + `wait` para reuso de recursos; un mal `&` puede lanzar trabajo duplicado. Cron/systemd timers son lo fiable para programar.

Bash dentro del DevOps: contenedores y CI Ops

# Docker la orquesta scripts: docker/Compose + entrypoint
# - Volunteers/CI usan bash -c "..." en cada 'run'
# Ejemplo de step en GitHub Actions:
#   run: bash scripts/validar.sh

# jq para leer respuesta de APIs (deploy checks)
STATUS=$(curl -s http://localhost:8080/health | jq -r '.status')
[[ "$STATUS" == "ok" ]] || { echo "health check falló"; exit 1; }

# terraform/ansible llaman shell modules — aprender a escribir scripts
# reutilizables (salida limpiable, errores claros, no variables secretas)

Los scripts de CI/CD e infra no difieren del resto: `set -euo pipefail`, funciones, checks de estado y salida clara. Con eso se mantienen bien en cualquier pipeline.
