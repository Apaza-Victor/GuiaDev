std y core: las librerías base Base

use std::collections::HashMap;
use std::fs;
use std::error::Error;

fn main() -> Result<(), Box<dyn Error>> {
    // Colecciones
    let mut mapa = HashMap::new();
    mapa.insert("a".to_string(), 1);
    let v = vec![3, 1, 4, 1, 5];
    let suma: i32 = v.iter().sum();

    // Archivos y errores con ?
    let contenido = fs::read_to_string("datos.txt")?;
    for linea in contenido.lines() {
        println!("{linea}");
    }

    // Fechas y opciones
    let ahora = std::time::Instant::now();
    let opcional: Option<i32> = Some(5);
    if let Some(x) = opcional { println!("{x}"); }
    Ok(())
}

La std de Rust: colecciones, I/O, threads (std::thread), error `Result`, protocols (`std::net`) y sistema. Todo tipado, sin runtime y eficiente.

Cargo: el gestor de paquetes Deps

cargo new mi_app && cd mi_app
cargo add serde serde_json            # añade deps
cargo build                           # compila (release:  --release)
cargo run
cargo test
cargo fmt && cargo clippy             # formato y lint
cargo doc --open                      # docs de tus deps

# Cargo.toml
[package]
name = "mi_app"
version = "0.1.0"
edition = "2021"

[dependencies]
serde = { version = "1.0", features = ["derive"] }
serde_json = "1.0"

[dev-dependencies]
criterion = "0.5"

Cargo es build + dependency manager + test runner + documentación todo-en-uno. `cargo add` es lo equivalente a npm/pip y es la puerta al ecosistema crates.io.

serde, anyhow, thiserror Utilidad

use serde::{Deserialize, Serialize};
use anyhow::{Context, Result};

#[derive(Serialize, Deserialize, Debug)]
struct Usuario {
    nombre: String,
    edad: u8,
}

fn main() -> Result<()> {
    // Serializar
    let u = Usuario { nombre: "Ana".into(), edad: 30 };
    let json = serde_json::to_string(&u)?;
    println!("{json}");

    // Deserializar y propagar errores con contexto
    let texto = std::fs::read_to_string("usuario.json")
        .context("no pude leer usuario.json")?;
    let parsed: Usuario = serde_json::from_str(&texto)
        .context("formato JSON inválido")?;

    // thiserror para enums de error con display
    Ok(())
}

serde es el framework de serialización universal (JSON/YAML/TOML/imágenes con `serde_derive`); anyhow simplifica errores en binarios y thiserror en librerías.

Instalación de Rust Inicio

# rustup: gestor de toolchain
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
# O con winget (Windows)
winget install Rustlang.Rustup
# update y versiones
rustup update
rustup show
rustc --version
cargo --version

rustup instala `rustc`, `cargo`, `clippy`, `rustfmt` y las std de cada toolchain. Edita binariens y mantenlo actualizado mensualmente.
