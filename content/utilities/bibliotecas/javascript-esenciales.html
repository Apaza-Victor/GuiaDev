¿Para qué sirve y cuándo usarla? Concepto

JavaScript moderno ha incorporado muchas utilidades que antes exigían librerías. Esta página presenta lo esencial actual: las APIs nativas de ECMAScript, manejo de fechas, validación de datos, testing y el tooling mínimo de cualquier proyecto.

¿Para qué se usa?

  • Manipular datos con APIs nativas como map, filter y destructuring.
  • Validar estructuras en el límite de entrada con zod o yup.
  • Escribir y ejecutar tests cómodos con vitest o jest.

¿En qué casos conviene usarla?

  • En proyectos modernos con bundler y tooling integrado.
  • Cuando la validación de formularios y APIs externas es crítica.
  • Para reforzar el testing sin infraestructura pesada.

Muchas utilidades clásicas como Lodash ya no hacen falta con ECMAScript moderno. Antes de instalar una dependencia, comprueba si una función nativa resuelve el caso en el navegador o Node actual.

ECMAScript moderno: utilidades nativas Base

// Colecciones y utilidades sin dependencias
const lista = [5, 1, 4, 2, 3];
lista.filter(x => x % 2 === 0).map(x => x ** 2).sort((a, b) => a - b);
const unico = new Set([1, 1, 2, 3]);          // {1,2,3}
const mapa  = new Map([["a", 1]]);
const total = lista.reduce((acc, n) => acc + n, 0);

// Objects y promesas
const { a, ...resto } = { a: 1, b: 2, c: 3 };
const copia = structuredClone(mapa);          // deep clone nativo
const espera = await Promise.all([fetch("/a"), fetch("/b")]);

Antes de añadir una utilidad, revisa si la resuelve el estándar: `Set`, `Map`, `structuredClone`, `Array.at`, `Object.hasOwn`, `AbortController`.

HTTP: fetch estándar y axios Red

// fetch es parte de Node/browser
const res = await fetch("https://api.github.com/users/octocat", {
  headers: { "User-Agent": "GuiaDev" },
});
if (!res.ok) throw new Error(`HTTP ${res.status}`);
const data = await res.json();

// axios: interceptores, timeout y errores
import axios from "axios";

const api = axios.create({ baseURL: "/api", timeout: 5000 });
api.interceptors.request.use((cfg) => {
  cfg.headers.Authorization = `Bearer ${token}`;
  return cfg;
});

try {
  const resp = await api.post("/usuarios", { nombre: "Ana" });
} catch (err) {
  if (axios.isAxiosError(err)) {
    console.error(err.response?.data);
  }
}

fetch nativo cubre casi todo; axios añade interceptores, cancelación por token y errores más cómodos. AbortController funciona también con fetch.

Fechas, números y formato con Intl Utilidad

const now = new Date();
new Intl.DateTimeFormat("es-ES", { dateStyle: "medium" }).format(now);
new Intl.NumberFormat("es-MX", { style: "currency", currency: "MXN" }).format(1200.5);
new Intl.RelativeTimeFormat("es", { numeric: "auto" }).format(-2, "day");

// date-fns para lógica de fechas
import { addDays, subMonths, isWeekend, formatDistance } from "date-fns";
addDays(now, 3);
isWeekend(now);

// Agrupación (nueva API nativa de ES2024)
const agrupado = Object.groupBy(lista, (n) => (n % 2 ? "impar" : "par"));

Intl es nativo para formato localizado de fechas, números y relativo (i18n). date-fns/luxon solo cuando necesitas lógica (aritmética) más pesada.

Validación y utilidades extra Más

import { z } from "zod";        // tipos en runtime
const Perfil = z.object({ username: z.string().min(3), seguido: z.boolean() });

import { debounce, throttle, groupBy } from "lodash-es";
const guardar = debounce(props => enviaAPI(props), 400);

// Array helpers modernos
const first = arr.at(0), last = arr.at(-1);
const sum = arr.reduce((a, n) => a + n, 0);
const fila = arr.find((x) => x.id === id);

// NN (intl para número grande)
const intl = new Intl.NumberFormat("es", { notation: "compact" }).format(1200000);

Combinación pragmática: estándar (fetch/Intl/structuredClone) + un par de utilidades (lodash-es, date-fns) + Zod si la entrada de datos es externa.
