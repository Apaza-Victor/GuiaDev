¿Para qué sirve y cuándo usarla? Concepto

El CSS moderno ya es una herramienta potente por sí mismo: Grid, Flexbox, custom properties, funciones y media queries permiten resolver casi todo el layout sin guerrillas. Esta página reúne los recursos esenciales de CSS puro antes de recurrir a frameworks o preprocesadores.

¿Para qué se usa?

  • Diseñar layouts flexibles con Flexbox y Grid sin librerías externas.
  • Mantener temas y valores reutilizables con custom properties (variables CSS).
  • Crear animaciones, transformaciones y transiciones con CSS puro.
  • Adaptar el diseño con media queries, contenedores y funciones utilitarias.

¿En qué casos conviene usarla?

  • Para proyectos pequeños o componentes donde el CSS nativo es suficiente.
  • Cuando quieres control total y mínimo peso sin dependencias.
  • Como base sólida antes de introducir Tailwind o preprocesadores como Sass.

No subestimes CSS puro ni asumas que necesitas siempre un framework: Grid y Flexbox cubren la mayoría de layouts. Reserva herramientas adicionales para equipos grandes, temas complejos o productividad en proyectos extensos.

CSS moderno: Grid, Flexbox, custom properties Base

:root {
  --azul: #2563eb;
  --radio: 12px;
  --pad: 1rem;
}

/* Flexbox: una dimensión */
.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: var(--pad);
}

/* Grid: dos dimensiones + responsive sin queries */
.tarjetas {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: var(--pad);
}

.tarjeta {
  border-radius: var(--radio);
  padding: var(--pad);
  background: #fff;
  box-shadow: 0 2px 8px rgb(0 0 0 / .1);
}

h1 { font-size: clamp(1.6rem, 4vw, 2.4rem); }

Flexbox (1D), Grid (2D) y custom properties son el core moderno. `auto-fit/minmax` + `clamp()` resuelven responsive sin breakpoints en muchos casos.

Selectores, unidades y capas Sintaxis

/* Especificidad: id > clase > tipo */
#header { color: black; }        /* 1-0-0 */
.card .titulo { color: blue; }   /* 0-2-0 */
.card > div > p { color: gray; } /* 0-1-2 */
h1 { color: red; }               /* 0-0-1 */

/* :root custom properties + cálculos */
.card { width: calc(100% - var(--pad) * 2); }

/* Unidades: rem, %, vw/vh, em */
:root { font-size: 16px; }
body { font-size: 1rem; }        /* 16px */
.card { padding: 1.5rem; max-width: 60ch; }

/* @layer: control de orden (moderno) */
@layer base, components, utilities;
@layer base { body { margin: 0; } }
@layer utilities { .mx-auto { margin-inline: auto; } }

Entiende especificidad para evitar !important; usa rem/clamp/ch para escalado; `@layer` decide el orden de cascada sin guerras de especificidad.

Pseudo-clases, transiciones y responsive Interacción

/* Estados: hover/focus/active */
.boton {
  transition: transform .2s ease, background .2s ease;
  background: var(--azul);
}
.boton:hover  { transform: translateY(-2px); }
.boton:focus-visible { outline: 3px solid #60a5fa; }

/* Media queries + prefers-* */
@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; transition: none !important; }
}
@media (prefers-color-scheme: dark) {
  :root { --fondo: #0f172a; --texto: #f8fafc; }
}
@media (min-width: 900px) {
  .lado { grid-template-columns: 1fr 1fr; }
}

/* Keyframes */
@keyframes flotar {
  from { transform: translateY(0); }
  to   { transform: translateY(-8px); }
}

Transiciones/keyframes dan las micro-interacciones; `:focus-visible` y `prefers-reduced-motion` son señal de calidad; media queries se guardan para cuando la estructura lo pide.

Empezar y verificar CSS Inicio

# CSS "se usa" con cualquier HTML; así verificar tu trabajo:
#   - DevTools (F12) → pestaña Computed/Styles: inspección exacta
#   - Can I Use (caniuse.com) → soporte de features
#   - W3C CSS validator (jigsaw.w3.org/css-validator)
# Normalización: Normalize.css (igualar estilos entre navegadores)
#   o reset propio: * { margin:0; box-sizing: border-box }
# Las clases/frameworks se abordan en el siguiente módulo (frameworks)

Para empezar basta un ``. Normalize.css/sanitize.css igualan diferencias; DevTools y W3C validator miden la salud de tu CSS.
