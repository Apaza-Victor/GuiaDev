Flutter: UI multiplataforma Framework

import 'package:flutter/material.dart';

void main() => runApp(const MiApp());

class MiApp extends StatelessWidget {
  const MiApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'GuiaDev',
      home: const Inicio(),
    );
  }
}

class Inicio extends StatefulWidget {
  const Inicio({super.key});
  @override
  State<Inicio> createState() => _InicioState();
}

class _InicioState extends State<Inicio> {
  int contador = 0;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Contador')),
      body: Center(
        child: Text('Valor: $contador', style: Theme.of(context).textTheme.headlineMedium),
      ),
      floatingActionButton: FloatingActionButton(
        onPressed: () => setState(() => contador++),
        child: const Icon(Icons.add),
      ),
    );
  }
}

Un solo código en Dart para Android, iOS, web y desktop. Compila a nativo (Impeller) y usa widgets de Material/Cupertino.

Gestión de estado: Riverpod y Bloc Estado

// Riverpod: simple y testeable
import 'package:flutter_riverpod/flutter_riverpod.dart';

final contadorProvider = StateProvider<int>((ref) => 0);

class Widget extends ConsumerWidget {
  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final valor = ref.watch(contadorProvider);
    return Text('$valor');
  }
}

// Bloc: arquitectura robusta para equipos grandes
// package:bloc con eventos/estados explícitos

// Otros: Provider, GetX (ligero), MobX (reactivo)

Riverpod es la recomendación moderna (simple, tipado, testeable con `ProviderContainer`); Bloc si te gusta la arquitectura por eventos/estados.

Dart fuera de Flutter: backend con Shelf/Lighthouse Backend

// Shelf: middleware HTTP estilo Express
import 'package:shelf/shelf.dart';
import 'package:shelf/shelf_io.dart' as io;

Response saludar(Request req) {
  return Response.ok('{"saludo": "Hola"}',
    headers: {'content-type': 'application/json'});
}

void main() {
  io.serve(
    const Pipeline()
        .addMiddleware(logRequests())
        .addHandler(saludar),
    InternetAddress.anyIPv4, 8080,
  );
}

// Alternatives: Lighthouse (Framework), dart_frog (equipo de VeryGoodVentures)
// SQLite/Postgres: package:sqlite3 y package:postgres incluyen drivers reales.

Shelf es el estándar server-side de Dart. Con `shelf_router`, `dart_frog` o `lighthouse` montas APIs REST en el mismo lenguaje de tu app móvil.

Testing: flutter_test y golden Calidad

// flutter_test: unit + widget tests
import 'package:flutter_test/flutter_test.dart';

void main() {
  test('suma correcta', () {
    expect(suma(2, 3), 5);
  });

  testWidgets('renderiza contador', (tester) async {
    await tester.pumpWidget(const Inicio());
    expect(find.text('Valor: 0'), findsOneWidget);
    await tester.tap(find.byType(FloatingActionButton));
    await tester.pump();
    expect(find.text('Valor: 1'), findsOneWidget);
  });
}
// Ejecutar: flutter test
// Golden tests: flutter test --update-goldens (screenshots como reference)

`flutter_test` integra unit y widget tests. Golden tests aseguran que la UI no cambie visualmente sin querer.

Paquetes y decisiones del ecosistema Flutter Extras

# Navegación: go_router (declarativa con rutas y shields)
dart pub add go_router
# Networking: dio (además de http) con interceptores
dart pub add dio
# Estado: riverpod / bloc
dart pub add flutter_riverpod
# Caché local: shared_preferences / hive / isar
dart pub add shared_preferences
# BD local: drift / sqflite / isar
# Imágenes y effetos: cached_network_image, lottie, shimmer
# Servicios plataforma: local_auth (biometría), geolocator, camera

El "favorito" de estado/paquetes cambia: revisa el repo `itsallwidgets.com` para ver stacks populares en apps reales públicas.
