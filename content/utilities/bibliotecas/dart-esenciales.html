¿Para qué sirve y cuándo usarla? Concepto

Dart incluye una serie de librerías esenciales: dart:core con colecciones y matemáticas, dart:async, dart:io y paquetes del pub.dev como http o intl. Esta página reúne las utilidades que más conviene conocer para escribir Dart idiomático.

¿Para qué se usa?

  • Colecciones, strings, matemáticas y utilidades base con dart:core.
  • Programación asíncrona con Futures, Streams y dart:async.
  • Entrada y salida, procesos y red con dart:io.
  • Complementos de la comunidad como http, intl o collection desde pub.dev.

¿En qué casos conviene usarla?

  • Para casi todo código Dart: la base resuelve colecciones, textos y asíncronía.
  • Para aplicaciones consola, servidor o la lógica de apps Flutter.
  • Cuando necesitas paquetes de la comunidad bien mantenidos para tareas concretas.

No añadas paquetes externos si dart:core o dart:async ya lo resuelven: muchas utilidades de colecciones y asíncronía vienen en la base. Revisa el SDK antes de depender de librerías de terceros.

Paquetes core y dart:core Base

// dart:core viene implícito: colecciones, contexto, math, durations
import 'dart:convert';
import 'dart:math';
import 'dart:async';

void main() {
  // Colecciones
  final nums = [3, 1, 4, 1, 5];
  final ordenados = List.of(nums)..sort();
  final pares = nums.where((n) => n % 2 == 0).toList();

  final mapa = {'a': 1, 'b': 2};
  mapa.putIfAbsent('c', () => 3);

  // JSON y string
  final json = jsonEncode({'nombre': 'Ana', 'edad': 30});
  final decodificado = jsonDecode(json);

  // Fechas
  final hoy = DateTime.now();
  final enSemana = hoy.add(const Duration(days: 7));

  // math
  final r = Random();
  print(max(1, 9)); // 9
}

dart:core/codec/math/async y collection cubren base en Dart. `jsonEncode/Decode` y `DateTime` sin dependencias y con tipos.

pub: gestor de paquetes Deps

# pub (del SDK de Dart) y pubspec.yaml
dart create mi_proyecto
cd mi_proyecto
dart pub add http      # añade dependencia y actualiza pubspec.lock
dart pub get           # descarga
dart pub upgrade       # actualiza dentro de constraint
dart pub outdated

# pubspec.yaml
name: mi_proyecto
description: Aplicación de ejemplo
environment:
  sdk: ">=3.3.0 <4.0.0"

dependencies:
  http: ^1.1.0
  path: ^1.9.0

dev_dependencies:
  test: ^1.24.0
  lints: ^3.0.0

pub.dev es el repositorio central. El `pubspec.lock` se debe comprometer para reproducibilidad; los rangos con `^` permiten actualizaciones menores.

http, json y utilidades frecuentes Utilidad

import 'package:http/http.dart' as http;
import 'dart:convert';

Future<void> obtenerUsuarios() async {
  final res = await http.get(
    Uri.parse('https://api.github.com/users/octocat'),
    headers: {'User-Agent': 'GuiaDev'},
  );
  if (res.statusCode == 200) {
    final usuario = jsonDecode(res.body) as Map<String, dynamic>;
    print('Nombre: ${usuario['name']}');
  }
}

// uuid y path son clásicos
import 'package:uuid/uuid.dart';
import 'package:path/path.dart' as p;

final id = const Uuid().v4();
final nombreCompleto = p.join('carpeta', 'archivo.txt');

// intl: internacionalización (números, fechas, plurales)
import 'package:intl/intl.dart';
final f = NumberFormat.currency(locale: 'es-MX', symbol: '\$');
print(f.format(1234.5));

El trío http + uuid + intl cubre HTTP, IDs e i18n. En Flutter usarás también `package:flutter/services` para los sensores/plataforma.

Instalación del SDK de Dart y Flutter Inicio

# Dart CLI
winget install Dart.Dart        # Windows
brew install dart               # macOS
sudo apt install dart           # (o manual del SDK)

# Flutter (incluye Dart SDK), para móvil/desktop/web
git clone https://github.com/flutter/flutter.git -b stable
# o: winget install Flutter.Flutter
flutter doctor                   # verifica toolchain

# Verificar Dart
dart --version
dart run                          # ejecuta bin/main.dart

Si te instalan Flutter, usa su Dart (no dos Dart). `flutter doctor` verifica Android SDK, Xcode, Chrome y más para saber qué falta.
