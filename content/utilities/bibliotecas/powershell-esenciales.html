Módulos core: Microsoft.PowerShell.* Base

# Los módulos "Microsoft.PowerShell.*" son la base del shell
Get-Command                    # cmdlets disponibles
Get-Module -ListAvailable      # módulos instalados

# Objects pipeline (no texto): el sello de PowerShell
Get-Process | Sort-Object CPU -Descending | Select-Object -First 5
Get-Service | Where-Object Status -eq 'Running'

# Colecciones y utilidades
Get-ChildItem -Recurse -Filter *.ps1 | Select-Object FullName, Length
Read-Host -Prompt 'Nombre'
Get-Date -Format 'yyyy-MM-dd HH:mm'
ConvertTo-Json @{ nombre = 'Ana'; edad = 30 }

# Strings, hash, comparaciones
$saludo = "Hola, $(whoami)"
'texto'.ToUpper()
0 -eq 0 -and 'a' -eq 'a'

PowerShell es object-oriented pipeline: casi todo devuelve objetos (no texto). Los módulos core traen cmdlets de archivos, procesos, servicios, JSON y red.

PowerShellGet y PSGallery Deps

# PowerShell Gallery: repositorio público de módulos
Install-Module -Name Pester -Scope CurrentUser -Force
Find-Module -Name '*Az*' | Select-Object -First 10
Update-Module -Name Pester

Install/Find/Update-Module gestionan PSGallery (NuGet por debajo). Para infra en cloud usa los SDK: Az.* / AWS.Tools.*; para shell, posh-git y oh-my-posh.

I/O, JSON y objetos Utilidad

# Leer/escribir archivos
$datos = Get-Content -Raw datos.json | ConvertFrom-Json
$datos.nombre

# JSON a objeto y de vuelta
$obj = [pscustomobject]@{ nombre = 'Ana'; edad = 30 }
$obj | ConvertTo-Json | Set-Content out.json

# CSV y Excel
Import-Csv datos.csv
Export-Csv -NoTypeInformation datos.csv
# ImportExcel (módulo) para Excel real: Install-Module ImportExcel

# Red y web
$r = Invoke-RestMethod -Uri 'https://api.github.com/users/octocat'
$r.login

# Regex y strings
'solo-letras-y-num-123' -match '^[a-z-]+\d+$'

ConvertFrom-Json/ConvertTo-Json, Import/Export-Csv, Invoke-RestMethod y la línea `-match` con regex cubren la mayoría de utilidades de scripting de datos y web.

Instalación de PowerShell 7 Inicio

# Windows: PowerShell 7+ (no el 5.1 integrado)
winget install Microsoft.PowerShell   # pwsh en PATH
# Linux/macOS
sudo apt install powershell           # Microsoft repo (deb)
brew install --cask powershell        # macOS
# O descargar .tar.gz/.msi de github.com/PowerShell/PowerShell

pwsh --version
pwsh -c 'Write-Host "Hola desde PowerShell 7"'
# Ejecutar scripts: pwsh ./script.ps1 (o .\ con Set-ExecutionPolicy)
# Profile: $PROFILE define el auto-start personal

Usa pwsh (PowerShell 7+, cross-platform). Para Windows legacy hay 5.1 presente solo en `powershell` (Widows PowerShell). en Linux/MAC es igual de potente.
