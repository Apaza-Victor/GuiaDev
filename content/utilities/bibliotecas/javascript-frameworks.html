React + hooks y estado UI

import { useState, useEffect } from "react";

function Contador() {
  const [valor, setValor] = useState(0);

  useEffect(() => {
    document.title = `Valor: ${valor}`;
  }, [valor]);

  return (
    <button onClick={() => setValor((v) => v + 1)}>
      Pulsado {valor} veces
    </button>
  );
}

// Estado global: Zustand (ligero) / Redux Toolkit (clásico) / Jotai
import { create } from "zustand";
const useStore = create((set) => ({
  usuario: null,
  setUsuario: (u) => set({ usuario: u }),
}));

Hooks + Zustand cubren la mayoría de apps modernas. Para datos remotos, React Query (TanStack Query) maneja caché y revalidación.

Backend: Express y Fastify Backend

// Express: clásico y minimal
const express = require("express");
const app = express();
app.use(express.json());   // middleware de JSON

app.get("/usuarios", (req, res) => {
  res.json([{ id: 1, nombre: "Ana" }]);
});

app.post("/usuarios", (req, res) => {
  console.log(req.body);
  res.status(201).json({ ok: true });
});

app.listen(3000);

// Fastify: más rápido, schema JSON y plugins
const fastify = require("fastify")({ logger: true });
fastify.get("/hola", async () => ({ mensaje: "hola" }));
fastify.listen({ port: 3000 });

Express domina por inercia y tutoriales; Fastify rinde más y valida payloads. Para empresas: NestJS (está en la ficha de TypeScript).

Persistence: Sequelize y Mongoose Datos

// Sequelize (SQL)
const { Sequelize, DataTypes } = require("sequelize");
const db = new Sequelize("postgres://usuario:pass@localhost:5432/app");

const Usuario = db.define("Usuario", {
  nombre: { type: DataTypes.STRING, allowNull: false },
  email:  { type: DataTypes.STRING, unique: true },
});
await Usuario.sync();
await Usuario.create({ nombre: "Ana", email: "ana@x.com" });

// Mongoose (MongoDB)
const mongoose = require("mongoose");
await mongoose.connect("mongodb://localhost:27017/app");
const User = mongoose.model("User", new mongoose.Schema({ name: String, age: Number }));
await User.create({ name: "Ana", age: 30 });

Sequelize/TypeORM/Prisma para SQL; Mongoose para MongoDB directo. Elige en función de tu BD y de si quieres tipos (Prisma brilla en TS).

Testing: Jest y Vitest Calidad

// Vitest (o Jest)
import { describe, it, expect, vi } from "vitest";
import { suma } from "./math.js";

describe("matemáticas", () => {
  it("suma", () => expect(suma(2, 3)).toBe(5));
});

// Mockear módulos
vi.mock("./mailer", () => ({ enviarMail: vi.fn() }));

// Supertest: probar endpoints HTTP
import request from "supertest";
import app from "./server.js";
it("GET /", async () => {
  const res = await request(app).get("/");
  expect(res.statusCode).toBe(200);
});

Vitest/Supertest + React Testing Library (para UI) es el stack más fino de testing JS. Cobertura integrada con `--coverage`.
