¿Para qué sirve y cuándo usarla? Concepto

El ecosistema de librerías de C es amplio y maduro: GLib ofrece estructuras y utilidades, libcurl HTTP, OpenSSL criptografía y SQLite almacenamiento. Esta página presenta las librerías más populares del ecosistema C y cuándo conviene incorporarlas sobre la librería estándar.

¿Para qué se usa?

  • Obtener estructuras de datos, listas y utilidades multiplataforma con GLib.
  • Realizar peticiones HTTP y manejar protocolos de red con libcurl.
  • Añadir cifrado, TLS y seguridad con OpenSSL.
  • Almacenar y consultar datos con SQLite o bases integradas en el programa.

¿En qué casos conviene usarla?

  • Cuando la librería estándar de C se queda corta para un dominio concreto.
  • Para aplicaciones de red, criptografía o GUI donde estas librerías son el estándar de facto.
  • Al preferir dependencias probadas y estables en lugar de reimplementar funcionalidad.

No añadas librerías sin necesidad: cada dependencia complica el build y el mantenimiento del código C. Evalúa si la stdlib o una librería pequeña del sistema ya cubre el caso antes de introducir un proyecto completo.

GLib: utilidades y estructuras Ecosistema

// GLib es la base de GTK: listas, hashes y utilidades multiplataforma
#include <glib.h>

int main(void) {
  GHashTable *tabla = g_hash_table_new(g_str_hash, g_str_equal);
  g_hash_table_insert(tabla, g_strdup("clave"), g_strdup("valor"));

  // Listas enlazadas
  GList *lista = NULL;
  lista = g_list_append(lista, g_strdup("a"));
  lista = g_list_append(lista, g_strdup("b"));

  // Menoría gestionada
  g_autofree char *s = g_strdup_printf("Hola %d", 42);
  g_print("%s\n", s);

  g_hash_table_destroy(tabla);
  g_list_free(lista);
  return 0;
}
// Compilar: gcc app.c $(pkg-config --cflags --libs glib-2.0)

GLib aporta estructuras seguras (hash, list, queue, tree), utilidades de string y gestión de memoria con `g_autofree`. Es lo más parecido a la "stdlib moderna" de otros lenguajes.

ncurses: interfaces de texto TUI

// ncurses crea interfaces en la terminal (TUI)
#include <curses.h>

int main(void) {
  initscr();               // iniciar modo curses
  cbreak();
  noecho();

  mvprintw(3, 5, "Hola desde ncurses");
  refresh();
  getch();                 // esperar tecla

  endwin();                // restaurar terminal
  return 0;
}
// Compilar: gcc app.c -lncurses

ncurses permite menús, ventanas y colores en la terminal. Programas como `htop`, `vim` y `screen` lo usan.

libcurl, OpenSSL y zlib Red y datos

// libcurl: descargar contenido HTTP
#include <curl/curl.h>

size_t escribir(void *datos, size_t t, size_t n, void *buf) {
  fwrite(datos, t, n, (FILE *)buf);
  return t * n;
}

int main(void) {
  curl_global_init(CURL_GLOBAL_DEFAULT);
  CURL *c = curl_easy_init();
  FILE *out = fopen("pagina.html", "wb");

  curl_easy_setopt(c, CURLOPT_URL, "https://example.com");
  curl_easy_setopt(c, CURLOPT_WRITEFUNCTION, escribir);
  curl_easy_setopt(c, CURLOPT_WRITEDATA, out);
  curl_easy_perform(c);

  curl_easy_cleanup(c);
  fclose(out);
  return 0;
}
// Compilar: gcc app.c -lcurl

// zlib: compresión/decompresión
// OpenSSL: crypto y TLS (HTTPS seguro, certificados)

El trío `libcurl` (HTTP/FTP), `OpenSSL` (TLS/crypto) y `zlib` (compresión) resuelve la mayoría de tareas de red y datos en C.

SQLite: base de datos embebida Datos

#include <sqlite3.h>
#include <stdio.h>

int main(void) {
  sqlite3 *db;
  char *err = NULL;

  sqlite3_open("app.db", &db);
  const char *sql =
    "CREATE TABLE IF NOT EXISTS usuarios (" \
    "id INTEGER PRIMARY KEY, nombre TEXT);";
  sqlite3_exec(db, sql, NULL, NULL, &err);

  sqlite3_stmt *st;
  sqlite3_prepare_v2(db,
    "SELECT nombre FROM usuarios;", -1, &st, NULL);
  while (sqlite3_step(st) == SQLITE_ROW) {
    printf("%s\n", sqlite3_column_text(st, 0));
  }
  sqlite3_finalize(st);
  sqlite3_close(db);
  return 0;
}
// Compilar: gcc app.c -lsqlite3

SQLite es una BD completa en un solo archivo. Perfecto para apps de escritorio y herramientas CLI sin servidor ni configuración.

¿Cómo elegir? Guía

// Trabajo con archivos/compresión   -> zlib + libarchive
// Red / HTTP via CLI o API           -> libcurl
// Seguridad / certificados           -> OpenSSL (o BearSSL si es liviano)
// GUI de escritorio                  -> GTK4 (GLib) / Qt (C++ más común)
// Juegos / gráficos                  -> SDL2, Raylib, Allegro
// Numeréérica / álgebra lineal       -> BLAS, LAPACK, GSL
// Serialización                      -> libjson-c, cJSON, protobuf-c
// BDD embebida                       -> SQLite

Regla: usa la librería probada de la comunidad para cada necesidad, con licencia compatible con tu proyecto, en lugar de escribir todo desde cero.
