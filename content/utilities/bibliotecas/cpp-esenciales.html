La librería estándar de C++ (STL) Base

La STL es el estándar de facto de C++: contenedores, iteradores, algoritmos, streams y utilidades modernas. Todo dentro de std:: y sin coste adicional de enlace.

#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <map>

int main() {
  std::vector<int> v = {4, 1, 3, 2};
  std::sort(v.begin(), v.end());     // {1,2,3,4}

  std::map<std::string, int> edad;
  edad["Ana"] = 30;
  edad["Bruno"] = 25;

  std::for_each(v.begin(), v.end(), [](int x) {
    std::cout << x << " ";
  });

  std::string saludo = "Hola";
  saludo += " mundo";
  std::cout << saludo << '\n';
  return 0;
}

La STL proporciona `vector`, `string`, `map`, `set`, `deque`, `array` y algoritmos como `sort`, `find`, `transform`. Es lo primero que hay que dominar.

C++ moderno: smart pointers y utilidades Moderno

#include <memory>
#include <optional>
#include <variant>
#include <tuple>
#include <chrono>

// Gestión de memoria sin new/delete
auto p = std::make_unique<int>(42);   // unique_ptr
auto s = std::make_shared<double>(3.14);

// Ausencia de valor sin punteros
std::optional<int> buscar(const std::vector<int>& v, int x) {
  auto it = std::find(v.begin(), v.end(), x);
  if (it == v.end()) return std::nullopt;
  return *it;
}

// Unión segura de tipos
std::variant<int, std::string> val = "texto";
if (std::holds_alternative<int>(val)) {
  std::get<int>(val);
}

// Cronometrado moderno
using namespace std::chrono;
auto t0 = steady_clock::now();
// trabajo...
auto ms = duration_cast<milliseconds>(steady_clock::now() - t0).count();

Desde C++11/14/17/20: `unique_ptr`/`shared_ptr`, `optional`, `variant`, `string_view`, `filesystem` y `std::format` (C++20) eliminan gran parte del código manual.

fmt y spdlog: formato y logs Utilidad

// fmt: formato seguro y rápido (base de std::format)
#include <fmt/core.h>
#include <fmt/chrono.h>

fmt::print("Hola {}, tienes {} a\u00f1os\n", "Ana", 30);
fmt::print("PI = {:.2f}\n", 3.14159);
fmt::print("Fecha: {:%Y-%m-%d}\n", fmt::localtime(std::time(nullptr)));

// spdlog: logging asíncrono multiplataforma
#include <spdlog/spdlog.h>

spdlog::info("Sistema iniciado");
spdlog::warn("Disco al {}%", 92);
spdlog::error("Error de red: {}", 503);
// A rotación diaria
auto file = spdlog::rotating_logger_mt("app", "logs/app.log", 5MB, 3);
file->info("Evento {}", 1);

fmt y spdlog son la pareja estándar moderna para texto y registro. `std::print` (C++23) adopta fmt nativamente.

nldohmann/json: JSON fácil Datos

#include <nlohmann/json.hpp>
#include <fstream>
using json = nlohmann::json;

// Construir
json j = {
  {"nombre", "Ana"},
  {"edad", 30},
  {"habilidades", {"C++", "Linux", "Git"}},
  {"activo", true}
};

// Leer con safe access
auto nombre = j["nombre"].get<std::string>();
int edad = j.value("edad", 0);
for (auto& h : j["habilidades"]) std::cout << h << '\n';

// Serializar / deserializar desde archivo
std::ofstream("datos.json") << j.dump(2);
std::ifstream f("datos.json");
json cargado = json::parse(f);

Usa `.value(key, default)` o comprueba `.contains()` antes de acceder por índice para evitar excepciones con datos desconocidos.

Boost está "un paso" por delante del estándar (ASYNC, regex, filesystem, uenvolverse en telecomunicaciones y finanzas). Muchas piezas acaban migrando al estándar.

Ejercicios prácticos Reto

  1. Con `std::vector` y `std::sort` ordena un arreglo de enteros y muestra con rangos.
  2. Usa `std::optional` para una función de búsqueda que devuelva "sin valor" cuando no hay match.
  3. Escribe logs con spdlog en consola y a un archivo rotativo de 1MB.
  4. Crea y lee un JSON con nldohmann/json desde un archivo, con `.value()` y defaults.
  5. Levanta un servidor TCP mínimo con boost::asio que responda "OK" a cualquier cliente.
