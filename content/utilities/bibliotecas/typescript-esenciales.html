TypeScript y su ecosistema de tipos Base

// npm init -y && npm install -D typescript
// npx tsc --init  =>  tsconfig.json

interface Usuario {
  id: number;
  nombre: string;
  email: string;
  edad?: number;          // opcional
}

type Resultado<T> =
  | { ok: true; valor: T }
  | { ok: false; error: string };

function guardar(u: Usuario): Resultado<Usuario> {
  if (!u.email.includes("@")) {
    return { ok: false, error: "email inválido" };
  }
  return { ok: true, valor: u };
}

const r = guardar({ id: 1, nombre: "Ana", email: "ana@x.com" });
if (r.ok) console.log(r.valor.nombre);   // narrowing de tipo

Los tipos (interfaces, uniones discriminadas, genéricos) son comprobados en compilación. El ecosistema ofrece utilidades: `Partial`, `Pick`, `ReturnType`, `Record`.

Zod: validación en runtime Datos

import { z } from "zod";

const UsuarioSchema = z.object({
  id: z.number().int().positive(),
  nombre: z.string().min(3).max(100),
  email: z.string().email(),
  edad: z.number().min(18).optional(),
});

// Infiere el tipo desde el schema
type Usuario = z.infer<typeof UsuarioSchema>;

const dato = JSON.parse('{"id":1,"nombre":"Ana","email":"ana@x.com"}');
const resultado = UsuarioSchema.safeParse(dato);
if (resultado.success) {
  console.log(resultado.data.email);
} else {
  console.error(resultado.error.flatten());
}

Zod valida datos que llegan en runtime (API, archivos): `safeParse` nunca lanza excepción y te da errores legibles por campo. Ideal junto a tRPC/formularios.

// fp-ts: programación funcional con tipos
import { pipe } from "fp-ts/function";
import * as O from "fp-ts/Option";
import * as E from "fp-ts/Either";

const dividir = (a: number, b: number): E.Either<string, number> =
  b === 0 ? E.left("División por cero") : E.right(a / b);

const r = pipe(
  E.right(10),
  E.chain((n) => dividir(n, 2)),
);

`lodash-es` trae utilidades con tree-shaking (imports por función). fp-ts añade Option/Either para manejo funcional sin excepciones.
