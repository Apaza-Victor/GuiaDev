FSharp.Core: la base de F# Base

// FSharp.Core lo trae todo: listas, sequence, option, resultado
let nums = [ 3; 1; 4; 1; 5 ]
let pares = nums |> List.filter (fun x -> x % 2 = 0) |> List.map ((*) 10)
let suma = List.sum nums

// records y pattern matching
type Persona = { Nombre: string; Edad: int }

let ana = { Nombre = "Ana"; Edad = 30 }
let describir p =
    match p with
    | { Edad = e } when e > 18 -> sprintf "%s es mayor" p.Nombre
    | _ -> sprintf "%s es menor" p.Nombre

// option / result
let op: int option = Some 5
let dividir a b =
    if b = 0 then Error "div por cero"
    else Ok (a / b)

// function composition |>
let add1 = (+) 1
let dup = (*) 2
let f = add1 >> dup     // f(3) = 8

FSharp.Core da listas/secuencias, options/results, records/union, pattern matching y composición `|>`/`>>`. Corre en .NET (interoperable con C#).

Gestión de deps: Paket y NuGet Deps

# NuGet: el gestor de paquetes de .NET (shared con C#)
dotnet add package FSharp.Data
dotnet add package FsToolkit.ErrorHandling
# Paket: alternativa para F#-first (con paket.dependencies)
dotnet paket add FSharp.Data

# Saber:
#   FSharp.Data: type providers (JSON/CSV/HTML/XML tipados)
#   Suave/Saturn (web), Giraffe (web)
#   FsUnit es un wrapper de NUnit/Xunit para F#

dotnet (SDK .NET) gestiona NuGet; Paket es la opción F#-primera. Todos interoperan con la rica librería de C# (System.*, EF Core, etc.).

FSharp.Data: Type Providers Utilidad

open FSharp.Data
open FSharp.Data.JsonExtensions

// Type provider de JSON: define tipos desde una muestra
type Perfil = JsonProvider<"https://api.github.com/users/octocat">

let perfil = Perfil.GetSample()
printfn "%s login=%s" perfil.Name perfil.Login

// CSV
type Datos = CsvProvider<"https://ejemplo.com/datos.csv">
let filas = Datos.GetSample().Rows

// JsonNative para acceso dinámico sin tipos
let j = JsonValue.Parse("""{"a": 1}""")
let a = j?a.AsInteger()

FSharp.Data usa Type Providers: tipos generados en compilación desde una muestra (JSON/CSV/XML/HTML). Esa es la característica estrella de F# para datos externos.

Instalación de F# Inicio

# .NET SDK incluye F# (fsc, dotnet fsi)
# Windows: instalar .NET SDK desde dotnet.microsoft.com
winget install Microsoft.DotNet.SDK.8
# Linux/Mac: script dotnet-install.sh o distro packages

dotnet --version
# F# Interactive (REPL)
dotnet fsi
# Compilar/Ejecutar un script
echo 'printfn "Hola desde F#"' > hola.fsx
dotnet fsi hola.fsx
# Proyectos
dotnet new console -lang "F#" -o MiProyecto

El SDK .NET trae `dotnet fsi` (REPL), `fsc` y plantillas F#. VS Code + Ionide o Visual Studio con soporte F# son los editores comunes.
