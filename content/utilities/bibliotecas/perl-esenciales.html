¿Para qué sirve y cuándo usarla? Concepto

Perl lleva décadas en sistemas y textos, y su biblioteca estándar es amplia. Esta página presenta los módulos core, el uso moderno del lenguaje con strict y firmas, el CPAN como repositorio de módulos y las librerías para scripting y administración.

¿Para qué se usa?

  • Procesar texto y datos con las funciones de cadenas y expresiones regulares.
  • Automatizar tareas del sistema con módulos core de ficheros y procesos.
  • Ampliar el lenguaje con módulos instalados desde el CPAN.

¿En qué casos conviene usarla?

  • En scripts de administración y DevOps en sistemas con Perl disponible.
  • En transformación y reporte rápido de datos textuales.
  • Para modernizar scripts legacy paso a paso.

Activa siempre use strict, use warnings y firmas de subrutinas. El código Perl sin esas prácticas es la mayor fuente de bugs y de la mala fama del lenguaje.

Módulos core de Perl Base

use strict;
use warnings;
use Data::Dumper;
use List::Util qw(sum max shuffle);
use Scalar::Util qw(blessed);
use POSIX qw(strftime);

my @nums = (3, 1, 4, 1, 5);
my $total = sum(@nums);
my $maximo = max(@nums);

my %hash = (nombre => 'Ana', edad => 30);
print Dumper(\%hash);

my $fecha = strftime('%Y-%m-%d', localtime);
print "Fecha: $fecha\n";
print "suma=$total max=$maximo\n";

La biblioteca estándar de Perl: `strict`/`warnings` para escribenlo bien, `Data::Dumper` depura, `List::Util` para listas, `POSIX` utilidades del sistema.

CPAN: el gigante de módulos Deps

# CPAN: repositorio de ~200k módulos
cpan install JSON            # instalar directo
cpanm JSON PPI DBI           # cpanminus (recomendado, rápido)
# o con App::cpanminus:
curl -L https://cpanmin.us | perl - App::cpanminus

# local::lib para installar en ~/perl5 sin privilegios
cpan App::cpanminus local::lib
# Configuración por proyecto: cpanfile + Carton
cpanfile:
requires 'JSON', '2.90';
requires 'DBI';

CPAN fue el primer ejemplo histórico de repos de paquetes. cpanm + cpanfile + Carton te dan gestión de dependencias moderna en Perl.

Librerías populares: JSON, DBI, MIME Utilidad

use JSON;
use DBI;
use File::Slurp qw(read_file write_file);
use Time::Piece;

# JSON
my $json = encode_json({name => 'Ana', age => 30});
print $json, "\n";

# DBI (base de datos)
my $dbh = DBI->connect("dbi:SQLite:dbname=app.db", "", "", {});
$dbh->do("CREATE TABLE IF NOT EXISTS users (id INTEGER, name TEXT)");
$dbh->do("INSERT INTO users VALUES (1, 'Ana')");
my $rows = $dbh->selectall_arrayref("SELECT * FROM users");

# Fechas
my $t = Time::Piece->new;
print $t->strftime('%Y-%m-%d %H:%M:%S'), "\n";

# Archivos
write_file('salida.txt', "datos\n");
print read_file('salida.txt');

JSON/DBI/Time::Piece/File::Slurp son la dupla esencial: JSON, acceso a BD (DBI es el driver genérico), fechas y archivos. `DBI`+DBD es la vieja escuela robusta.

Instalación de Perl Inicio

# Perl viene en Linux/macOS casi siempre; verifica:
perl --version
# Compilar desde source (si lo necesitas) o usar:
#   ActiveState / Strawberry Perl (Windows, trae cpan)
#   plenv / perlbrew (gestores de versión)
curl -L https://install.perlbrew.pl | bash   # perlbrew
perlbrew install perl-5.40.0
perlbrew switch perl-5.40.0

# Instalar módulos base
cpanm JSON DBI DBI::SQLite

# Ejecutar
perl script.pl

En Windows usa Strawberry Perl (con `cpanm` incluido); en Unix/Linux ya viene. perlbrew para versionar Perl como rbenv/nvm.
