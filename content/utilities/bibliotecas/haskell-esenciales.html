base, containers, text, bytestring Base

import Data.List (sort, nub)
import qualified Data.Map.Strict as M
import qualified Data.Text as T

main :: IO ()
main = do
  -- listas: funciones de foldr/map/filter (Prelude)
  let nums = [3,1,4,1,5]
  print (sort nums, nub nums, sum nums)

  -- Data.Map (contamos frecuencias)
  let freq = foldr (\w m -> M.insertWith (+) w 1 m) M.empty ["hola","mundo","hola"]
  print (M.toList freq)

  -- Data.Text para strings eficientes
  let t = T.pack "Hola, Mundo!"
  print (T.toUpper t, T.length t)

La base: Prelude (funciones de listas), containers (Map/Set/Seq), text/bytestring para strings. La perezosidad y types son lo que definen el resto del ecosistema.

mtl, transformers y efectos Funcional

{-# LANGUAGE OverloadedStrings #-}

import Control.Monad.IO.Class (liftIO)
import Control.Monad.Reader (ReaderT, ask, runReaderT)
import Control.Monad.Except (ExceptT, throwError, runExceptT)

-- transformers: composas transformadores de monadas
data Config = Config { cfgNombre :: String }

saludo :: ReaderT Config IO String
saludo = do
  c <- ask
  liftIO (putStrLn "task...")
  pure ("Hola " ++ cfgNombre c)

main :: IO ()
main = runReaderT saludo (Config "Ana") >>= putStrLn

-- mtl: typeclasses MonadReader/MonadState sobre los transformers
-- para aplicaciones grandes: ReaderT Config IO como base del stack

mtl/transformers dan el patrón de efectos (Reader/State/Except/IO). Esa es la base del estilo moderno; las libs fx de confianza: lens (ópticas) y conduit.

Instalación de Haskell Inicio

# GHCUps general (ghcup): gestor moderno de GHC+cabal
curl --proto '=https' --tlsv1.2 -sSf https://get-ghcup.haskell.org | sh
ghcup install ghc recommended
ghcup install cabal recommended
ghcup set ghc recommended

# stack (capa sobre GHC/Cabal con stackage)
curl -sSL https://get.haskellstack.org | sh

# Verificar y ejecutar
ghc --version
echo 'main = putStrLn "Hola desde Haskell"' > hola.hs
runghc hola.hs

# ghci -- REPL para experimentos

GHC+ghcup y cabal son la base; stack añade resolución LTS (conjunto de versiones curadas). `ghci` funciona como REPL para probar funciones al vuelo.
