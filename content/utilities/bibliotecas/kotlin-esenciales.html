¿Para qué sirve y cuándo usarla? Concepto

Kotlin ofrece una librería estándar concisa y moderna sobre la JVM. Esta página presenta lo esencial: funciones sobre colecciones, tipos nulos seguros, corrutinas para asíncrono y las librerías habituales de serialización y testing.

¿Para qué se usa?

  • Manipular colecciones con funciones de orden superior y extensiones.
  • Escribir código concurrente sencillo con corrutinas y flujos.
  • Serializar y deserializar datos con kotlinx.serialization.

¿En qué casos conviene usarla?

  • En desarrollo Android moderno, donde Kotlin es el lenguaje principal.
  • En backends JVM que buscan menos ceremonia que Java.
  • Para consumir y exponer APIs JSON con modelos tipados.

No conviertas todo en DSL o en extensiones: un abuso de funciones elevadas hace el código difícil de leer. Reserva las extensiones para casos claros de dominio.

Kotlin stdlib: lo que trae de serie Base

// La stdlib de Kotlin extendió Java con sintaxis concisa
fun main() {
    // Colecciones con funciones de orden superior
    val nums = listOf(3, 1, 4, 1, 5)
    nums.filter { it % 2 == 0 }
        .map { it * 10 }
        .sortedDescending()
        .forEach { println(it) }

    val frec = mutableMapOf<String, Int>()
    "hola mundo hola".split(" ").forEach { frec[it] = (frec[it] ?: 0) + 1 }

    // String con trimm, lines, take/whatever
    val saludo = """
        Hola
        desde
        Kotlin
    """.trimIndent()

    // null-safety
    var nombre: String? = null
    nombre?.length          // null
    nombre ?: "anónimo"     // anónimo
}

// Data class: equals/hashCode/toString/copy automáticos
data class Usuario(val id: Int, val nombre: String, val edad: Int?)

La stdlib añade a Java: mutable/immutable collections, `filter/map/forEach`, `data class`, null-safety (`?:`, `?.`), rangos y más. Sin dependencias extra.

Corutinas: asincronía sencilla Async

// kotlinx-coroutines: async/await sin callbacks
import kotlinx.coroutines.*

suspend fun fetchUsuario(id: Int): String {
    delay(500)              // simula red/API
    return "Usuario $id"
}

fun main() = runBlocking {
    val resultados = (1..5).map { id ->
        async { fetchUsuario(id) }   // lanzados en paralelo
    }
    println(resultados.map { it.await() })

    // Dispatchers: IO, Default, Main
    withContext(Dispatchers.IO) { /* I/O pesado */ }
}

kotlinx-coroutines es la pieza clave de Kotlin para asincronía: `suspend`, `async/await`, `Dispatchers` y flujos (`Flow`). Es estándar para apps modernas.

ktor-client y kotlinx-serialization Utilidad

// ktor-client: HTTP multiplataforma
import io.ktor.client.*
import io.ktor.client.request.*
import io.ktor.client.engine.cio.*

suspend fun main() {
    val client = HttpClient(CIO)
    val body = client.get("https://api.github.com/users/octocat").bodyAsText()
    println(body)
}

// kotlinx-serialization: JSON con generación de schema
import kotlinx.serialization.*
import kotlinx.serialization.json.*

@Serializable
data class Usuario(val nombre: String, val edad: Int)

fun main() {
    val json = Json.encodeToString(Usuario("Ana", 30))
    val u = Json.decodeFromString<Usuario>(json)
}

ktor-client (multiplataforma: JVM/JS/Native) + kotlinx.serialization cubren HTTP y JSON. Ktor también sirve como servidor web completo.

Instalación de Kotlin Inicio

# Con SDKMAN (JVM/Linux/Mac)
curl -s "https://get.sdkman.io" | bash
sdk install kotlin
# Owingetter Windows
winget install JetBrains.Kotlin
# IDE: IntelliJ IDEA Community (JetBrains) trae el plugin Kotlin

# Verificar y probar
kotlinc -version
echo 'fun main() = println("Hola desde Kotlin")' > hola.kt
kotlinc hola.kt -include-runtime -d hola.jar
java -jar hola.jar

Kotlin corre en JVM (también compila a JS/Native). IntelliJ IDEA es el IDE natural; también funciona desde Gradle y Maven en proyectos Android/backend.
