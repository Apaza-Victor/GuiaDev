¿Para qué sirve y cuándo usarla? Concepto

El ecosistema de frameworks de Julia cubre dos frentes: Genie para aplicaciones web y el ecosistema de machine learning con Flux y SciML para ciencia computacional. Esta página explica qué elegir en cada caso.

¿Para qué se usa?

  • Crear aplicaciones y APIs web con Genie, el framework full-stack de Julia.
  • Entrenar y ejecutar modelos de aprendizaje con Flux.
  • Resolver problemas complejos de simulación con el ecosistema SciML.

¿En qué casos conviene usarla?

  • En dashboards y paneles que exponen resultados de cómputo Julia.
  • En prototipos de machine learning en el mismo lenguaje de la ciencia de datos.
  • Para publicar resultados de investigación web en equipos pequeños.

Genie no compite en madurez con Django o Rails para aplicaciones cerradas. Usa Julia para el modelo de datos y deja el frontend en herramientas consolidadas si la aplicación crece.

Web y ciencia en Julia Guía

# Web:

Genie es el framework web más completo; Oxygen/HTTP para APIs simples. Pero el fuerte de Julia es el stack científico: SciML, DataFrames, Plots y ML.

---

Genie: web full-stack en Julia Web

using Genie

# Rutas (App.get, Router)
Genie.Router.route("/saludo/:nombre") do params
  "Hola $(params[:nombre])"
end

Genie.Router.route("/datos", method = POST) do params
  # params JSON/query disponibles
  "recibido: $(params[:cuerpo_registrado])"
end

Genie.up(port = 8000)

# Render, templating (Stipple.jl reactivo), channels
# Genie Serve para desarrollo: genie -S

Genie da rutas, params, templates y Stipple (UI reactiva tipo LiveView). Se integra con el stack científico para servir modelos y modelos de datos en la web.

Oxygen y HTTP.jl Micro

# Oxygen.jl: microframework tipo Express
using Oxygen

# GET con parámetro
@get "/saludo/{nombre}" function saludo(nombre)
  Dict("saludo" => "Hola $nombre")
end

@post "/datos" function recibir(req)
  # req.data tiene el body
  Dict("ok" => true, "cuerpo" => req.data)
end

serve(port = 8080)

# HTTP.jl (bajo nivel)
using HTTP
r = HTTP.post("http://localhost:8080/datos", body = "{}")
HTTP.get("http://localhost:8080/saludo/Mundo")

Oxygen es lo más ligero para APIs; HTTP.jl es el cliente/servidor subyacente de todo el ecosistema web. Ambos perfectos para exponer modelos científico.

Ciencia de datos: DataFrames, Plots, GLM Ciencia

using DataFrames, CSV, GLM, Plots

# Cargar CSV
df = CSV.read("datos.csv", DataFrame)
# estadística rápida
describe(df)

# GLM: regresión lineal
# lm viene con ese paquete:
modelo = lm(@formula(edad ~ peso + altura), df)
coef(modelo)
r2(modelo)

# Plots: visualización múltiples backends
scatter(df.peso, df.edad)

# Otras libs: Turing (Bayes), Flux (deep learning),
# SupportVectorMachine, DecisionTree, Clustering

El stack: CSV+DataFrames (datos), GLM (modelos clásicos), Turing (Bayes), Flux/Zygote (redes neuronales), Plots (visualización). Julia lo hace tipado y veloz.

Testing: Test.jl Calidad

using Test

# Adjuntar a tu paquete: test/runtests.jl
@testset "funciones básicas" begin
  @test suma(2, 3) == 5
  @test_broken suma(0, 0) == 1     # espera fallo
  @test_throws DivideError divide(1, 0)
end

# Random en paquetes
# Correr con Pkg.test() desde el REPL (proyecto activo) o `] test`
# CI: suele correr julia --project=. test
# cobertura: coverage.jl (built-in with julia)

Test.jl es el framework oficial; `@testset` agrupa asserts; `- ] test` corre la suite del proyecto. Julia viene con todo, incluyendo testing y coverage built-in.
