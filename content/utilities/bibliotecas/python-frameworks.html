¿Para qué sirve y cuándo usarla? Concepto

Python domina el backend web con tres grandes frameworks que cubren casi todos los casos: Django para proyectos grandes con todo incluido, FastAPI para APIs modernas y tipadas, y Flask para servicios simples con control total. Esta página los compara y orienta la elección según el problema a resolver.

¿Para qué se usa?

  • Aplicaciones web completas con panel de administración y ORM: Django.
  • APIs REST y microservicios con validación y documentación automática: FastAPI.
  • Prototipos y aplicaciones pequeñas con control total: Flask.
  • Tareas HTTP y de datos: requests, httpx y BeautifulSoup para integraciones.

¿En qué casos conviene usarla?

  • Producto con CRUD, usuarios y panel de admin: Django te ahorra meses de decisiones.
  • API pública o microservicio con tipado de contrato: FastAPI.
  • Servicio mínimo o integración simple: Flask.

No elijas framework por moda: Django concede a casi todo, FastAPI brilla en APIs y Flask cuando quieres el mínimo. Acompaña la elección con una base relacional (Django ORM o SQLAlchemy) y no dupliques autenticación ni validación a mano.

Django: web completa y batteries included Framework

pip install django
django-admin startproject mi_sitio .
python manage.py startapp blog
python manage.py runserver

# models.py
from django.db import models

class Post(models.Model):
    titulo = models.CharField(max_length=200)
    cuerpo = models.TextField()
    publicado = models.DateTimeField(auto_now_add=True)

# views.py
from django.shortcuts import render
from .models import Post

def lista(request):
    posts = Post.objects.order_by("-publicado")
    return render(request, "blog/lista.html", {"posts": posts})
# urls.py mapea ruta -> view; admin/referencia/migraciones integrados.

Django trae ORM, admin automático, auth, sesiones, migraciones y templates por defecto. Ideal para CRUDs, CMS y paneles de administración sin ensamblar.

FastAPI: APIs modernas y asíncronas API

pip install fastapi uvicorn pydantic

from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class UsuarioIn(BaseModel):
    nombre: str
    edad: int

@app.get("/usuarios/{id}")
async def obtener(id: int):
    if id <= 0:
        raise HTTPException(status_code=404, detail="No existe")
    return {"id": id, "nombre": "Ana"}

@app.post("/usuarios")
def crear(u: UsuarioIn):
    return {"recibido": u, "status": "ok"}

# App en desarrollo:
# uvicorn main:app --reload
# Documentación interactiva automática en /docs y /redoc (Swagger UI)

FastAPI valida con Pydantic, genera OpenAPI automáticamente y soporta async nativo. Es la elección moderna para APIs REST/JSON y apps de machine-learning serving.

Flask y alternativas ligeras Micro

from flask import Flask, request, jsonify

app = Flask(__name__)

@app.get("/hola")
def hola():
    return jsonify(mensaje="Hola mundo", version=1)

@app.post("/eco")
def eco():
    datos = request.get_json()
    return datos

if __name__ == "__main__":
    app.run(debug=True)

# Otras: Bottle (micro), Starlette (async puro), Litestar,
#        Pyramid (middlee el peso de Django sin rigidez),
#        Tornado / aiohttp (websockets y protocolos),
#        Streamlit/NiceGUI para dashboards internos rápidos.

Elige: Django (todo integrado), FastAPI (APIs veloz, validado), Flask/Bottle (micro y flexible), Starlette/aiohttp (async y websockets de bajo nivel).

SQLAlchemy y SQLModel Datos

pip install sqlalchemy

from sqlalchemy import create_engine, Column, Integer, String, select
from sqlalchemy.orm import declarative_base, Session

engine = create_engine("sqlite:///app.db")
Base = declarative_base()

class Usuario(Base):
    __tablename__ = "usuarios"
    id = Column(Integer, primary_key=True)
    nombre = Column(String(100), nullable=False)

Base.metadata.create_all(engine)

with Session(engine) as s:
    s.add(Usuario(nombre="Ana"))
    s.commit()
    todos = s.scalars(select(Usuario)).all()

# SQLModel (FastAPI + SQLAlchemy + Pydantic en uno) simplifica:
# class Usuario(SQLModel, table=True): id: int | None; nombre: str

SQLAlchemy es el ORM más usado (sync y async con `asyncpg`); SQLModel lo fusiona con Pydantic, perfecto junto a FastAPI.

Testing: pytest Calidad

pip install pytest

# test_calculadora.py
import pytest
from calculadora import suma, divide

def test_suma_basica():
    assert suma(2, 3) == 5

@pytest.mark.parametrize("a,b,esp", [
    (1, 2, 3), (0, 0, 0), (-1, 1, 0)])
def test_suma_param(a, b, esp):
    assert suma(a, b) == esp

def test_divide_por_cero_lanza():
    with pytest.raises(ValueError):
        divide(1, 0)

# Fixtures limpian recursos repetidos
@pytest.fixture
def datos():
    return {"a": 1, "b": 2}
# Ejecutar: python -m pytest -v --cov=calculadora

pytest + fixtures + parametrize cubren el testing estándar. Añade `pytest-cov` y `pytest-httpx`/`responses` para mockear HTTP cuando hables de red.
