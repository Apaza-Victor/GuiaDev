requests: HTTP humano Utilidad

import requests

# GET con parámetros y headers
resp = requests.get("https://api.github.com/users/octocat",
                     params={"per_page": 10},
                     headers={"Authorization": os.getenv("TOKEN")})
print(resp.status_code)
datos = resp.json()

# POST con JSON
requests.post("https://api.ejemplo.com/usuarios",
              json={"nombre": "Ana", "edad": 30},
              timeout=5)

# Sesiones (cookies y pool reutilizable)
with requests.Session() as s:
    s.get("https://login.ejemplo.com")
    pagina = s.get("https://app.ejemplo.com/perfil")

# Manejo de errores
try:
    resp = requests.get("...", timeout=10)
    resp.raise_for_status()
except requests.RequestException as e:
    print("Error de red", e)

Siempre define un `timeout`, usa `raise_for_status()` y reutiliza una Sesión por host. Para HTTP asíncrono de alto volumen mira `httpx` + `httpx.AsyncClient`.

Pydantic y validación moderna Datos

from pydantic import BaseModel, EmailStr, Field, ValidationError

class Usuario(BaseModel):
    nombre: str = Field(min_length=3, max_length=100)
    edad: int = Field(ge=18, le=120)
    email: EmailStr

try:
    u = Usuario(nombre="Ana", edad=30, email="ana@example.com")
    print(u.model_dump())
except ValidationError as e:
    print(e.errors())

# Integración con JSON directamente
datos = '{"nombre":"Bruno","edad":25,"email":"b@x.com"}'
u2 = Usuario.model_validate_json(datos)

Pydantic valida, serializa y documenta. Es la base de modelos en FastAPI y de configs tipadas modernas con `.env` (BaseSettings).

Logging y configuración Utilidad

import logging
logging.basicConfig(level=logging.INFO,
                    format="%(asctime)s %(levelname)s %(name)s %(message)s")
log = logging.getLogger(__name__)
log.info("Servicio en puerto %d", 8080)
log.warning("Memoria al %d%%", 87)
log.exception("Falló el procesamiento")

# Configuración con python-dotenv y pydantic-settings
import os
from dotenv import load_dotenv
load_dotenv()
DB_URL = os.getenv("DATABASE_URL", "postgres://localhost/app")

Estructura el logging con `logging.getLogger(__name__)` en cada módulo para filtros jerárquicos. `dotenv` mantiene secretos en `.env` fuera de git.
