¿Para qué sirve y cuándo usarla? Concepto

PHP es el lenguaje de la web desde hace décadas y su versión moderna es sólida. Esta página presenta lo esencial: la librería estándar, SPL para estructuras, PSR para interoperabilidad, Composer como gestor de dependencias y PDO para bases de datos.

¿Para qué se usa?

  • Crear páginas y APIs dinámicas con el propio lenguaje del servidor.
  • Gestionar dependencias y el autoload con Composer y PSR-4.
  • Acceder a bases de datos de forma segura con sentencias preparadas de PDO.

¿En qué casos conviene usarla?

  • En desarrollo web clásico y rápido en hosting compartido.
  • En APIs y microservicios simples con frameworks ligeros.
  • Para modernizar proyectos que heredan código PHP antiguo.

Mantén PHP actualizado y desactiva funciones obsoletas: el código de hace una década suele ser inseguro o incompatible. Usa tipos, strict_types y sentencias preparadas en lugar de concatenar la entrada del usuario.

Librería estándar y funciones modernas Base

<?php
// La SPL (Standard PHP Library): colecciones e interfaces
use ArrayObject, SplStack, SplQueue;

$pila = new SplStack();
$pila->push("Primero"); $pila->push("Segundo");
echo $pila->top();                       // "Segundo"

// funciones de strings, arrays, archivos y fechas
$texto   = "  Hola Mundo  ";
trim($texto);
str_contains($texto, "Hola");
mb_strtoupper($texto);                   // UTF-8

$nums = [3, 1, 4, 1, 5];
array_map(fn($n) => $n * 2, $nums);
array_filter($nums, fn($n) => $n > 2);
array_reduce($nums, fn($acc, $n) => $acc + $n, 0);

// fechas con DateTime
$fecha = new DateTime();
$fecha->modify("+3 days");
echo $fecha->format("Y-m-d");

// PDO para BD
$pdo = new PDO("sqlite:app.db");
$stmt = $pdo->prepare("SELECT * FROM usuarios WHERE id = ?");
$stmt->execute([1]);

PHP 8 trae arrow functions, match, nullsafe, enums y atributos para modernizar el código de siempre: usa las funciones SPL/core antes de añadir dependencias.

Composer: el gestor de dependencias Deps

# Instalar Composer (el equivalente a npm de PHP)
php -r "copy('https://getcomposer.org/installer', 'composer-setup.php');"
php composer-setup.php && php -r "unlink('composer-setup.php');"
mv composer.phar /usr/local/bin/composer

# Uso
composer init
composer require slim/slim
composer require --dev phpunit/phpunit
composer.json                    # declaración
composer.lock                    # versión exacta (commitéalo)

{
  "autoload": {
    "psr-4": { "App\\": "src/" }
  }
}

Composer descarga desde Packagist, autoloada (PSR-4) y congela versiones en `composer.lock`. Todo proyecto PHP moderno empieza por aquí.

Librerías de utilidad populares Utilidad

<?php
// Symfony String (librería de strings en Unicode)
use Symfony\Component\String\UnicodeString;
$nombre = new UnicodeString("  hola mundo  ");
$nombre->trim()->title();     // "Hola Mundo"

// Carbon: fechas (fruto de Laravel)
use Carbon\Carbon;
echo Carbon::now()->addDays(5)->diffForHumans();   // "5 días"

// Monolog: logging estándar
use Monolog\Logger, Monolog\Handler\StreamHandler;
$log = new Logger("app");
$log->pushHandler(new StreamHandler("php://stderr"));
$log->info("Evento procesado", ["id" => 42]);

// Respect/Validation: reglas encadenadas
use Respect\Validation\Validator as v;
v::email()->validate("ana@example.com");

Carbon, Monolog, Symfony String y Respect/Validation resuelven las tareas repetitivas diarias; con Composer se añaden en una línea.

Usa PHP 8.2/8.3 actual. Instala también `php-curl` y `php-zip` que necesitan la mayoría de las herramientas de Composer.
