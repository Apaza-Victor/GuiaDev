Frameworks de GUI: Qt y GTK Ecosistema

// Qt Widgets: aplicaciones de escritorio multiplataforma
#include <QApplication>
#include <QPushButton>
#include <QLabel>
#include <QVBoxLayout>

int main(int argc, char *argv[]) {
  QApplication app(argc, argv);

  auto *ventana = new QWidget;
  auto *boton = new QPushButton("Hacer clic");
  auto *etiqueta = new QLabel("Texto");
  auto *lay = new QVBoxLayout;

  QObject::connect(boton, &QPushButton::clicked, [boton, etiqueta] {
    etiqueta->setText("¡Clic!");
  });

  lay->addWidget(etiqueta);
  lay->addWidget(boton);
  ventana->setLayout(lay);
  ventana->show();
  return app.exec();
}
// qmake: gcc -fPIC $(pkg-config --cflags --libs Qt5Widgets) app.cpp

Qt es el framework de escritorio más completo para C++: widgets, QML, networking, multimedia y herramientas (Qt Creator, Designer). GTKmm es la alternativa construida sobre GTK.

Gráficos y juegos: SDL2, Raylib y Vulkan Media

// SDL2: ventanas, input y renderizado 2D
#include <SDL.h>

int main(int argc, char* argv[]) {
  SDL_Init(SDL_INIT_VIDEO);
  SDL_Window* win = SDL_CreateWindow("Ventana", SDL_WINDOWPOS_UNDEFINED,
    SDL_WINDOWPOS_UNDEFINED, 800, 600, SDL_WINDOW_SHOWN);
  SDL_Renderer* ren = SDL_CreateRenderer(win, -1, SDL_RENDERER_ACCELERATED);

  SDL_Rect rect = { 100, 100, 50, 50 };
  SDL_SetRenderDrawColor(ren, 255, 0, 0, 255);
  SDL_RenderClear(ren);
  SDL_SetRenderDrawColor(ren, 0, 0, 255, 255);
  SDL_RenderFillRect(ren, &rect);
  SDL_RenderPresent(ren);

  SDL_Delay(2000);
  SDL_DestroyRenderer(ren); SDL_DestroyWindow(win); SDL_Quit();
  return 0;
}
// Raylib: aún más simple para aprender; Vulkan/OpenGL para juegos AAA.

SDL2 es el estándar de facto para juegos 2D independientes; Raylib por su simplicidad; Vulkan/OpenGL/DirectX para 3D de alto rendimiento.

Multithreading: OpenMP, TBB y std::async Concurrencia

// OpenMP: pragmas simples para paralelismo en bucle
#include <omp.h>
#include <vector>

std::vector<double> datos(1000000, 1.5);
long double suma = 0.0;
#pragma omp parallel for reduction(+:suma)
for (int i = 0; i < (int)datos.size(); ++i) {
  suma += datos[i] * datos[i];
}

// std::async (estándar, sin dependencias)
#include <future>
auto f = std::async(std::launch::async, [] {
  return 40 + 2;   // corre en otro hilo
});
int resultado = f.get();   // espera el futuro

// TBB (Intel): tasks más finos y escalables
#include <tbb/parallel_for.h>
tbb::parallel_for(0, (int)datos.size(), [&](int i) {
  datos[i] = datos[i] * 2.0;
});

Paralelizar sin entender la carrera de datos corrompe silenciosamente la memoria. Comienza con reducciones (suma) y evita mutar la misma variable en varios hilos.

Frameworks de testing y profiling Calidad

// GoogleTest (gtest): el estándar de la industria
#include <gtest/gtest.h>

int suma(int a, int b) { return a + b; }

TEST(Matematica, SumaBasica) {
  EXPECT_EQ(suma(2, 3), 5);
  EXPECT_GT(suma(1, 1), 1);
}

TEST(Matematica, SumaNegativos) {
  EXPECT_EQ(suma(-1, 1), 0);
}
// Compilar con CMake + gtest_discover_tests, luego ./test

// Catch2: solo cabecera, más exprés
#include <catch2/catch_test_macros.hpp>
TEST_CASE("Suma funciona") {
  REQUIRE(suma(2, 2) == 4);
}

// Perfiles: perf, gprof, Valgrind --tool=callgrind; Timing con std::chrono

gtest/Catch2 + CMake/CTest es la base de testing en C++. Añade Coverage (gcov/lcov) si quieres medir ramas no probadas.

Red y networking: HPPE y C++ REST SDK Comm¿net

// C++ REST SDK (cpprestsdk): cliente HTTP con promesas
#include <cpprest/http_client.h>
#include <cpprest/filestream.h>
using namespace web; using namespace web::http; using namespace web::http::client;

http_client cliente(U("https://api.example.com"));
auto req = cliente.request(methods::GET, U("/usuarios"))
  .then([](http_response resp) {
    return resp.extract_json();
  })
  .then([](json::value cuerpo) {
    auto nombre = cuerpo[U("nombre")].as_string();
    return nombre;
  });
// Atención: hay que esperar .wait() en main para no destruir el io

// HPPE (High Performance Protocol Engine): más bajó nivel para latencia extrema

Las promesas no bloquean: sin `.wait()` o `.get()` al final el programa termina antes de que llegue la respuesta. Para APIs REST ligeras también puedes usar libcurl con C++.
