Spring Boot: el estándar empresarial Framework

// Spring Boot con Spring Web (REST) + JPA
// @SpringBootApplication (clase principal)
import org.springframework.boot.*;
import org.springframework.boot.autoconfigure.*;

@SpringBootApplication
public class App {
  public static void main(String[] args) {
    SpringApplication.run(App.class, args);
  }
}

// Controlador REST
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api/usuarios")
public class UsuarioController {

  @GetMapping("/{id}")
  public Usuario obtener(@PathVariable Long id) {
    return new Usuario(id, "Ana", 30);
  }

  @PostMapping
  public Usuario crear(@RequestBody Usuario u) {
    return u; // en producción: save en un repositorio
  }
}
// Repositorio JPA, config en application.yml, dependencias en pom.xml/Gradle.

Spring Boot + Spring MVC simplifica todo: inyecta dependencias (@Autowired), REST, seguridad, BD (JPA) y microservicios (Spring Cloud). Contrato "starter" reduce la configuración a casi cero.

Alternativas nativas: Quarkus y Micronaut Nativos

// Quarkus: arranque rápido, bajo consumo, nativo con GraalVM
// @QuarkusMain + paneles /dev; build con:
//   mvn quarkus:dev          # hot reload
//   mvn package -Pnative     # binario nativo GraalVM

// Micronaut: contenedores AOT, sin reflexión
//   mn create-app appRest
// cotizent con inyección por constructor y test sereno

// Comparativa (rendimiento de arranque y memoria — orden de magnitud):
// Spring  ~2-4 s, ~500MB
// Quarkus ~0.3 s, ~80-120MB
// Micronaut ~0.2 s, ~60-90MB

Quarkus/Micronaut brillan en serverless y K8s: menos RAM y arranque en milisegundos gracias a GraalVM y AOT. Spring sigue dominando el ecosistema Java tradicional.

Persistencia: Hibernate, JPA y MyBatis Datos

// JPA + Hibernate: mapeo objeto-relacional
import jakarta.persistence.*;

@Entity
@Table(name = "usuarios")
public class Usuario {
  @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
  private Long id;
  @Column(nullable = false)
  private String nombre;
  private int edad;
  // getters/setters ...
}

// Repositorio con Spring Data JPA
public interface UsuarioRepo extends JpaRepository<Usuario, Long> {
  List<Usuario> findByEdadGreaterThan(int edad);
  // métodos derivados del nombre: findByNombre, findByEdadBetween...
}

// MyBatis: SQL manual con mappers XML/annotations (más control, menos mágica)
// Liquibase/Flyway: versionado de esquema BD

Hibernate (JPA) es el ORM más usado; Spring Data añade repositorios con consultas derivadas del nombre del método. MyBatis es la opción "SQL explícita".

Testing: JUnit 5 y Mockito Calidad

// JUnit 5: el estándar
import org.junit.jupiter.api.Test;
import static org.junit.jupiter.api.Assertions.*;

class CalculadoraTest {
  @Test
  void sumaEsteCorrecta() {
    assertEquals(5, Calculadora.suma(2, 3));
  }

  @Test
  void lanzaExcepcion() {
    assertThrows(ArithmeticException.class, () -> Calculadora.divide(1, 0));
  }
}

// Mockito: simular dependencias
import static org.mockito.Mockito.*;
import org.junit.jupiter.api.extension.ExtendWith;
import org.mockito.InjectMocks;
import org.mockito.Mock;

@ExtendWith(MockitoExtension.class)
class ServicioTest {
  @Mock Repositorio repo;
  @InjectMocks Servicio servicio;

  @Test
  void devuelveUsuario() {
    when(repo.findById(1L)).thenReturn(new Usuario(1L, "Ana"));
    assertEquals("Ana", servicio.obtenerNombre(1L));
  }
}
// Maven: mvn test — Gradle: ./gradlew test — coverage: JaCoCo

Spring Boot incluye `spring-boot-starter-test` con JUnit, Mockito y AssertJ. JaCoCo mide cobertura en el build.
