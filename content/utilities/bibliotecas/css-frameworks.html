Frameworks CSS: Bootstrap y Tailwind Guía

<!-- Bootstrap 5: componentes listos (CDN) -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

  </div>
</div>

<!-- Tailwind: utility-first (CDN para rápido) -->
<script src="https://cdn.tailwindcss.com"></script>
<div class="grid grid-cols-1 md:grid-cols-2 gap-4 p-4">
  <div class="bg-blue-600 text-white rounded-xl p-6">Bloque A</div>

Bootstrap = componentes prefabricados (grid 12, navbar, modal); Tailwind = utilidades atómicas directas (control total). Ambos escalan con Sass/PostCSS al crecer.

---

Sass/SCSS: variables, mixins y anidación Sass

// Instalar: npm i -D sass  |  sass --watch estilos.scss estilos.css
$azul: #2563eb;
$radio: 8px;

@mixin boton($bg, $pad: .6rem 1.2rem) {
  background: $bg;
  padding: $pad;
  border-radius: $radio;
  border: none;
  &:hover { filter: brightness(1.1); }
}

.btn-primario { @include boton($azul); }
.btn-perigro  { @include boton(#dc2626); }

.card {
  .titulo { font-weight: 700; }   // anidación
  &--destacado { border: 2px solid $azul; }
}

Sass (variables, mixins, anidación, funciones) organiza el CSS reutilizable; se compila a CSS puro. Es la base debajo de muchos temas de Bootstrap.

PostCSS y herramientas de build CSS Build

# PostCSS: transforma tu CSS con plugins
npm i -D postcss autoprefixer cssnano

# postcss.config.js
# export default {
#   plugins: {
#     'postcss-preset-env': { stage: 3 },   // features modernas → estándar
#     'autoprefixer': {},
#     'cssnano': { preset: 'default' }      // minificar
#   }
# }

# En Vite se integra automático (vite usa postcss si config existe):
npm create vite@latest mi-css -- --template vanilla
# estilos: SRC=moz; también stylelint ahora
#

PostCSS con preset-env (CSS actual → soportado), autoprefixer (prefijos -webkit-) y cssnano (minificar) forman la cadena de build. Vite/Webpack la corren por ti.

Otras opciones: Bulma, Pico, Open Props Alternativas

<!-- Bulma: clases semánticas, moderna -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bulma@1.0.2/css/bulma.min.css">
<div class="columns">
  <div class="column is-half">Mitad</div>
  <div class="column">Resto</div>
</div>

<!-- Pico.css: mínima (~10KB), classless, dark automático -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@picocss/pico@2/css/pico.min.css">

/* Open Props: custom properties superoptimizadas */
@import "https://unpkg.com/open-props";
.card { box-shadow: var(--shadow-3); border-radius: var(--radius-3);
        font-size: var(--font-size-fluid-1); }

Bulma (flexbox-friendly), Pico (classless ultra mínima) y Open Props (design tokens) son alternativas según filosofía. Elige según el peso que quieras cargar.

Ejercicios prácticos Reto

  1. Reconstruye la grid de tarjetas con Bootstrap (col-md-*).
  2. Repite con Tailwind (grid-cols + gap) y traslada a CDN.
  3. Extrae variables y un mixin a Sass y compílalo.
  4. Configura PostCSS con autoprefixer y observa los prefijos.
  5. Prueba Pico.css/carga en un proyecto de prototipo y mide el peso.
