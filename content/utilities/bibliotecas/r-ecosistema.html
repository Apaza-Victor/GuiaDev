Shiny: aplicaciones web en R Web

library(shiny)

# app.R: UI + server + runApp()
ui <- fluidPage(
  titlePanel("Dashboard simple"),
  sidebarLayout(
    sidebarPanel(
      selectInput("var", "Variable", choices = names(mtcars)),
      sliderInput("bins", "Bins", min = 1, max = 30, value = 10)
    ),
    mainPanel(plotOutput("grafico"))
  )
)

server <- function(input, output, session) {
  output$grafico <- renderPlot({
    hist(mtcars[[input$var]], breaks = input$bins,
         main = paste("Histograma de", input$var))
  })
}

shinyApp(ui, server)
# Local: runApp(); Publicar: shinyapps.io o Shiny Server / Posit Connect

Shiny convierte análisis R en dashboards reactivos sin HTML/JS. `reactive()` y `observeEvent()` gestionan recalculo; combinar con `reactable` para tablas.

tidymodels: machine learning ML

library(tidymodels)

# Dividir datos y preprocesar (recipe)
set.seed(123)
datos <- mtcars
div  <- initial_split(datos, prop = 0.8)
train <- training(div)
test  <- testing(div)

receta <- recipe(mpg ~ ., data = train) |>
  step_normalize(all_numeric_predictors())

# Modelo + workflow
modelo <- linear_reg(engine = "lm")
flujo  <- workflow() |>
  add_recipe(receta) |>
  add_model(modelo)

ajustado <- fit(flujo, train)
# Evaluar: metrics(ajustado, test) con yardstick
# tune() + vfold_cv() para buscar hiperparámetros

tidymodels estandariza preprocesado (recipes), modelado (parsnip) y evaluación (yardstick). Para deep learning: `keras` (TensorFlow) o `torch`.

# Arrow: compartir datos entre R/Python sin copias
library(arrow)

`arrow`/`parquet` para intercambio eficiente, `sparklyr` para escala real, `reticulate` para combinar Python y R en el mismo flujo. `quarto` los une en reportes.

testing (testthat) y empaquetado Calidad

library(testthat)

# test-calculadora.R
test_that("suma funciona", {
  expect_equal(suma(2, 3), 5)
  expect_type(suma(-1, 1), "double")
})

test_that("valida errores", {
  expect_error(suma("a", 1))
})

# Empaquetar un paquete R
usethis::create_package("mipaquete")
usethis::use_testthat()
devtools::test()            # correr tests
devtools::check()           # verificación completa
# Publicar: usethis::use_github_action() + CRAN (futuro)

testthat + devtools + usethis es el flujo para validar código y crear paquetes compartibles. Cobertura con covr::report().
