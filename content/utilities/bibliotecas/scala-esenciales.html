Scala stdlib y collections Base

object Main extends App {
  // Collections inmutables por defecto
  val nums = List(3, 1, 4, 1, 5)
  val pares = nums.filter(_ % 2 == 0).map(_ * 10).sorted
  val suma = nums.sum

  // Vectores y maps
  val mapa = Map("a" -> 1, "b" -> 2)
  val conClave = mapa.getOrElse("c", 0)

  // pattern matching
  def describe(x: Any): String = x match {
    case i: Int if i > 10 => "int grande"
    case s: String => s"texto: $s"
    case _ => "otro"
  }

  // Option, Either y tuple for-comprehension
  val op: Option[Int] = Some(5)
  val res = for { n <- op } yield n * 2
  println(pares, suma, conClave, res)
}

La stdlib de Scala: collections inmutables, pattern matching, Option/Either, implicits y Scala 3 opaque types. El estilo es funcional y conciso.

Librerías funcionales: cats y zio Funcional

// cats: typeclasses y composición
import cats.implicits._

val a: Option[Int] = Some(3)
val b: Option[Int] = Some(4)
val c = (a, b).mapN(_ + _)         // Option(7)

// zio: efectos asíncronos tipados (moderno y potente)
import zio._

val programa: UIO[String] =
  for {
    ahora <- Clock.currentDateTime
    _ <- Console.printLine(s"hora: $ahora")
  } yield "listo"

// scala: la alternativa ligera a zio (scalaz para legacy)

cats (typeclasses: Functor/Monad) y zio (efectos) son el corazón del Scala funcional moderno; scalaz fue la base histórica; cats-effect para streaming Send.

sbt: el build de Scala Build

# sbt (Scala Build Tool): compila, resuelve y paqueta
sbt compile
sbt run
sbt test
sbt scalafmtAll
sbt "scalafixAll"              # lints/auto-fix
sbt assembly                   # fat jar (plugin sbt-assembly)
# Consola interactiva con Tabulador de comandos

// build.sbt
ThisBuild / scalaVersion := "3.3.4"
ThisBuild / organization := "com.ejemplo"

lazy val root = (project in file("."))
  .settings(
    name := "mi-app",
    libraryDependencies ++= Seq(
      "org.scalameta" %% "munit"   % "1.0.0" % Test,
      "com.lihaoyi"   %% "upickle" % "3.3.1",
      "dev.zio"       %% "zio"     % "2.1.6"
    ),
    scalacOptions ++= Seq(
      "-deprecation", "-feature", "-Wunused:all"
    )
  )

sbt maneja deps (%% para versions cross), tasks y plugins; scalafmt estándar; munit para tests de Scala 3; scalafix para lints => pipeline sólido.
