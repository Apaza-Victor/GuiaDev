Base y estándar: arrays y múltiple dispatch Base

# Julia Base: arrays, math, I/O, Unicode, types fuertes
v = [3, 1, 4, 1, 5]
sort!(v)
sum(v)
filter(isodd, v)
map(x -> x^2, v)
println(join(v, ", "))

# lineal: matrices y operaciones vectorizadas vienen de Base (BLAS)
A = [1 2; 3 4]
b = [5, 6]
x = A \ b          # resuelve el sistema lineal

# multiple dispatch (el lenguaje central)
area(radio::Float64) = π * radio^2
area(base::Float64, altura::Float64) = 0.5 * base * altura

# comprehensions y ranges
cuadrados = [n^2 for n in 1:10 if iseven(n)]
aproximar_pi = sum(1/n^2 for n in 1:10_000)

Base de Julia es completa: matrices, funciones matemáticas, missings, docstrings y `@show`. El rendimiento viene del compilador LLVM y del multiple dispatch.

Pkg: el gestor de paquetes de Julia Deps

import Pkg
Pkg.add("DataFrames")
Pkg.add(["JSON", "HTTP", "Plots"])
Pkg.rm("Plots")
Pkg.update()
Pkg.status()

# project/package := Project.toml + Manifest.toml
# Desarrollar un paquete:
Pkg.activate("MiPack")         # entorno nuevo
Pkg.generate("MiPack")         # genera módulo
Pkg.develop(path="MiPack")     # modo dev

# Project.toml (ejemplo)
name = "MiApp"
uuid = "xxxxxxxx-...-xxx"
authors = ["ana"]
version = "0.1.0"

[deps]
DataFrames = "a93c6f00-e57d-5684-b7b6-d8193f3e46c0"
JSON = "682c06a0-de6a-54ab-a142-c8b1cf79cde6"

[compat]
DataFrames = "1"
julia = "1.10"

Pkg maneja Project.toml (declarado) + Manifest.toml (lock de versiones). Julia tiene un registry de producción: General (general.julialang.org) con miles de paquetes.

Librerías populares: DataFrames, JSON, HTTP Utilidad

import Pkg
Pkg.add(["DataFrames", "JSON", "HTTP"])

using DataFrames, JSON

# DataFrames: tablas como pandas
df = DataFrame(nombre = ["Ana", "Luis"], edad = [30, 25])
df[df.edad .> 26, :]
push!(df, ("Rosa", 40))
println(df)

# JSON
j = JSON.parse("{\"clave\": 1, \"lista\": [1,2,3]}")
JSON.json(Dict("a" => [1,2,3]))

# HTTP (cliente simple)
resp = HTTP.get("https://api.github.com/users/octocat")
JSON.parse(resp.body)

El ecosistema de datos: DataFrames (tablas), JSON para serializar, HTTP para red. Además Plots/Plots.jl para gráficos, CSV.jl para archivos, GLM.jl para modelos.

Instalación de Julia Inicio

# Download del installer (julialang.org)
#   Windows .exe, macOS .dmg, Linux tar.gz
# Recomendado: juliaup (version manager multiplataforma)
curl -fsSL https://install.julialang.org | sh
juliaup add release
juliaup default release

# Verificar
julia --version
echo 'println("Hola desde Julia")' > hola.jl
julia hola.jl

# REPL: julia, ? para ayuda, ] para Pkg, ; para shell

juliaup es el instalador oficial multi-versión (recomendado). El REPL es clave: `]` abre el modo Pkg, `?` busca docs de funciones.
