Librería estándar (stdlib) y core Base

# Core: colecciones, enumerables, texto, Time
nums = [3, 1, 4, 1, 5]
nums.map    { |n| n * 2 }
nums.select { |n| n > 2 }
nums.reduce(0) { |acc, n| acc + n }

frec = Hash.new(0)
"hola mundo".split.each { |p| frec[p] += 1 }

require "date"
today = Date.today
today + 30

# Stdlib: csv, json, uri, net/http, securerandom
require "json", "csv", "securerandom"
perfil = JSON.parse('{"nombre":"Ana"}')
SecureRandom.hex(8)

# Arquitectura de módulos
module Utilidades
  VERSION = "1.0"
  def self.saludo(nombre) = "Hola #{nombre}"
end
puts Utilidades::VERSION

La stdlib de Ruby resuelve JSON, CSV, fechas, red (net/http), cripto (openssl) y colecciones. Requiere añadir solo lo que falte vía gemas.

RubyGems y Bundler Deps

# RubyGems: el gestor de paquetes (gemas)
gem install rails nokogiri
gem search "fast nokogiri"
gem list

# Bundler: declarar y congelar dependencias de un proyecto
bundle init                          # crea Gemfile
bundle add faraday rspec             # añade y resuelve versions
bundle install                       # instala según Gemfile.lock
bundle exec ruby app.rb              # ejecuta en el entorno del Gemfile

# Gemfile
source "https://rubygems.org"
gem "sinatra"
gem "puma"
group :test do
  gem "rspec", require: false
end

Bundler garantiza reproducción con `Gemfile.lock` y `bundle exec`. Las gemas son similares a npm/pip: versiones, grupos y dependencias transitivas.

Gemas de utilidad más usadas Utilidad

# pry: REPL mejorado (debugging interactivo)
require "pry"
binding.pry                # pausa y abre consola en ese punto

# faraday: cliente HTTP moderno
require "faraday"
conn = Faraday.new(url: "https://api.github.com")
resp = conn.get("/users/octocat", nil, { "User-Agent" => "GuiaDev" })
JSON.parse(resp.body)

# nokogiri: parseo HTML/XML
require "nokogiri"
doc = Nokogiri::HTML(File.read("pagina.html"))
doc.css("h1")&.first&.text

# dotenv y figaro: config
require "dotenv/load"
ENV.fetch("DATABASE_URL")

pry (debug), faraday (HTTP), nokogiri (HTML/XML) y dotenv (config) son la base de muchas tareas de scripting e integración en Ruby.

Instalación de Ruby Inicio

# Linux/macOS: rbenv o asdf (no utilices el de sistema a menos que sea necesario)
rbenv install 3.3.0
rbenv global 3.3.0
# Windows: RubyInstaller con DevKit
winget install RubyInstallerTeam.Ruby.3.3

# Verificar
ruby -v
gem -v

# Primer script
ruby -e 'puts "Hola desde Ruby"'
echo '3.times { |i| puts "repetir #{i}" }' > hola.rb
ruby hola.rb

En Linux/Mac usa rbenv/asdf para alternar versiones; en Windows, RubyInstaller. Crea versiones por proyecto según tu entorno.
