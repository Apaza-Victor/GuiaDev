¿Qué es la librería estándar? Base

La librería estándar de C es el conjunto de librerías que todo compilador (GCC, Clang, MSVC) incluye. Se dividen en cabeceras con responsabilidades definidas:

CabeceraFunciónApodos
<stdio.h>Entrada/salida: printf, fopen, fscanfI/O
<stdlib.h>Memoria dinámica y conversionesmalloc, qsort
<string.h>Manipulación de cadenas y memoriastrcpy, memcpy
<math.h>Funciones matemáticassqrt, pow
<time.h>Fecha, hora y temporizadorestime, clock
<ctype.h>Clasificación de caracteresisdigit, isalpha
<assert.h>Verificaciones en tiempo de ejecuciónassert
<errno.h>Códigos de error de las llamadas al sistemaerrno

La estándar es portátil: el mismo código compila en Windows, Linux o Mac si solo usas estas cabeceras. Las librerías del sistema operativo (POSIX/WinAPI) ya no lo son.

---

<stdio.h> y <stdlib.h>: las imprescindibles Base

// stdio.h: I/O formateada y archivos
#include <stdio.h>

int main(void) {
  printf("Hola %s, tienes %d a%os\n", "Ana", 30);

  FILE *f = fopen("datos.txt", "r");
  if (f) {
    char linea[256];
    while (fgets(linea, sizeof linea, f)) puts(linea);
    fclose(f);
  }
  return 0;
}

// stdlib.h: memoria, conversiones y ordenamiento
#include <stdlib.h>
#include <string.h>

int comparar(const void *a, const void *b) {
  return *(const int *)a - *(const int *)b;
}

int main(void) {
  int *arr = malloc(5 * sizeof(int));   // arreglo dinámico
  if (!arr) return 1;
  arr[0] = 5; arr[1] = 1; arr[2] = 4;
  qsort(arr, 3, sizeof(int), comparar); // ordenar con qsort

  int n = atoi("123");                  // string -> int
  free(arr);
  return 0;
}

Siempre verifica el retorno de malloc (puede devolver NULL) y libera la memoria con free. Compila con gcc -Wall -Wextra para detectar olvidos.

string, math y time Base

// string.h: cadenas y memoria
#include <string.h>

char destino[64];
strcpy(destino, "Hola");          // copia (¡cuidado con el tamaño!)
strcat(destino, " mundo");
int len  = strlen(destino);
int igual = strcmp("abc", "abd"); // <0: primero es menor

// math.h: operaciones numéricas (vincular con -lm)
#include <math.h>

double r = sqrt(16.0);            // 4.0
double p = pow(2.0, 10.0);        // 1024
double sup = fabs(-3.5);          // 3.5
long   fi = floor(3.9);           // 3

// time.h: medición de tiempo
#include <time.h>

clock_t inicio = clock();
// ... trabajo ...
clock_t fin = clock();
double seg = (double)(fin - inicio) / CLOCKS_PER_SEC;

Las funciones matemáticas requieren enlazar la biblioteca: gcc prog.c -lm. En MSVC no hace falta ese flag.

ctype, assert y errno Utilidades

// ctype.h: clasificar caracteres
#include <ctype.h>

int es_digito = isdigit('5');   // 1
int es_letra  = isalpha('a');   // 1
int es_espacio = isspace(' ');  // 1
char may = toupper('a');        // 'A'

// assert.h: precondiciones en desarrollo
#include <assert.h>

int divide(int a, int b) {
  assert(b != 0);               // falla y aborta en binarios debug
  return a / b;
}

// errno.h: códigos de error
#include <errno.h>
#include <math.h>

errno = 0;
double r = sqrt(-1.0);          // NaN y errno == EDOM
if (errno) perror("sqrt falló");

assert se elimina compilando con -DNDEBUG en producción. errno es la forma clásica de propagar errores en APIs de C; revisa perror/strerror para mensajes.

Descargar e instalar Inicio

# Linux (apt / pacman / dnf)
sudo apt install gcc make

# macOS: clang vienen con Command Line Tools
xcode-select --install

# Windows: MinGW-w64 (msys2 o installer) o MSVC Build Tools
winget install -e --id MSYS2.MSYS2

# Verificar
gcc --version
printf '#include <stdio.h>\nint main(){puts("ok");}\n' > t.c
gcc t.c -o t && ./t

Para proyectos pequeños basta con GCC/Clang; para Windows nativo suele preferirse MSVC con Visual Studio Build Tools.

Ejercicios prácticos Reto

  1. Lee un archivo de texto con fopen/fgets y cuenta sus líneas.
  2. Reserva memoria para 10 enteros, rellena con 1..10 y ordénalos con qsort.
  3. Usa time.h para medir cuánto tarda un bucle de un millón de iteraciones.
  4. Valida con isdigit que una entrada de usuario sea numérica antes de atoi.
  5. Añade assert a una función que reciba un puntero no nulo y úsala con -DNDEBUG y sin él.
