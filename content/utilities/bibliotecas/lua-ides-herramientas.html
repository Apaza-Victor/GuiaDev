selene, stylua y tooling CLI

# stylua: formatter oficial de estilo Lua
cargo install stylua         # desde Rustin (cómo cargo)
stylua src/                  # o con prebuilt
stylua --check src/          # CI
# Alternativa: LuaFormatter (por luarocks)

# selene: linter moderno (reglas de estilo)
cargo install selene
selene src/                  # o via luarocks selene

# luacheck: linter clásico (integra números de línea)
luarocks install luacheck
luacheck src/

# más: luac (compilador bytecode): luac -p file.lua

StyLua (formato) y selene/luacheck (lints) son el trío de calidad en Lua. Ambos se instalan fácil y corren en CI; luac -p valida sintaxis a bytecode.

Depurar Lua Debug

# En ZeroBrane Studio / LÖVE (love --debug) / VS Code (LuaLS debug)
# breakpoints y watch: DAP integrado con LuaLS

# Depurar a mano con pcall y error
local ok, err = pcall(datos)
if not ok then print("FALLO:", err) end

# print/warn clásicos:
print("[DEBUG]", variable)

# Estructura de debug API: debug.getinfo, debug.traceback
print(debug.traceback())
-- En LuaJIT: jit.util y perf (Linux) para profiling

ZeroBrane y LÖVE tienen debug visual conectado al engine; en servidor usa `pcall` + traceback y logs. `debug.traceback()` es tu amigo en errores imprevistos.

Empaquetar y desplegar Lua Ops

# Script directo: solo necesita lua en runtime
# Juegos LÖVE: love *.zip → .love ejecutable
#   (zip del proyecto + love --fused)
# Web: OpenResty se añade como imagen

# Contenedor para scripts (imagen mínima)

FROM lua:5.4-alpine
WORKDIR /app
COPY . .
RUN luarocks install dkjson    # deps
CMD ["lua", "app.lua"]

# Ejecutables standalone: luastatic (compilea usando C compiler)
luastatic app.lua deps -o app
./app

`lua:alpine` a imagen pequeño (Lua es ~250KB). luastatic crea binarios standalone compilando el código con el C compiler; LÖVE para juegos usa .love zips.
