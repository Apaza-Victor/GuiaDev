Qué es y por qué es tan popular

draw.io (también conocido como diagrams.net) es el editor de diagramas gratuito más usado del mundo. Funciona en el navegador sin registro, tiene apps de escritorio para Windows/macOS/Linux y una extensión integrada en VS Code. Todo gratis, sin marcas de agua ni límites artificiales.

Su éxito se explica por tres decisiones de producto:

  • Cero fricción: abres la web y estás dibujando en 5 segundos; no hay cuenta que crear.
  • Almacenamiento a tu elección: los archivos viven donde tú decidas — local, Google Drive, OneDrive, GitHub o GitLab.
  • Formato abierto: los archivos .drawio (o .xml) son XML legible; nada de formatos propietarios opacos.

A diferencia de PlantUML, aquí dibujas arrastrando formas con control visual total sobre posiciones, colores y estilos: libertad completa a cambio de mantenimiento manual.

Formas y plantillas UML

Incluye bibliotecas UML nativas con todas las notaciones estándar, accesibles desde el panel izquierdo (menú "Más formas" → Software → UML):

  • UML 2.5 completo: clases con compartimentos, interfaces lollipop/socket, actores, casos de uso, estados, componentes, nodos de despliegue, marcos de fragmentos de secuencia (alt, opt, loop).
  • Plantillas de arranque: al crear un archivo puedes elegir diagramas UML pre-armados (clases, ER, secuencia) y editarlos sobre la marcha.
  • Conectores inteligentes: las flechas se anclan a puntos de conexión y re-enrutan solas cuando mueves las cajas; con "Edit Connection" eliges ortogonal, curvo o directo.

Atajo clave: selecciona una forma y pulsa Ctrl+M para añadir notas UML, y arrastra desde los puntos azules de los bordes para encadenar conectores sin tocar la paleta. El doble clic en el lienzo crea elementos sueltos al instante.

Integración con repositorios

Es la función que convierte draw.io en herramienta seria de equipo: puede abrir y guardar directamente contra GitHub/GitLab:

  1. File → Open from / Save as → GitHub (autoriza vía OAuth la primera vez).
  2. Elige repositorio, rama y ruta (docs/diagrams/modelo.drawio); guarda con commit y mensaje.
  3. El XML queda versionado: los pull requests muestran diffs del diagrama línea a línea.

![Diagrama de arquitectura](docs/diagrams/arquitectura.svg)

Flujo recomendado: versiona el fuente .drawio junto al exportado (.svg o .png). El fuente permite editar; el exportado se renderiza en GitLab/GitHub sin herramientas extra. La extensión de VS Code automatiza la exportación masiva desde consola.

Trucos útiles

  • Tablas como clases: la forma "Table" (búsqueda "table") crea clases/entidades con filas editables — ideal para modelos de datos y diagramas ER.
  • Estilos globales: edita un elemento, clic derecho → Edit Style, y copia esa cadena de estilo a otros con pegado especial (Ctrl+Shift+V).
  • Capas: agrupa vistas alternativas (versión actual vs propuesta) en capas visibles/invisibles dentro del mismo archivo.
  • Enlaces entre páginas: un documento .drawio puede tener varias páginas y enlaces navegables entre ellas: mini-wiki de diseño.
  • Mermaid importado: Arrange → Insert → Advanced → Mermaid convierte texto Mermaid en formas editables.
  • Exportación selectiva: exporta selección (no todo el lienzo) con File → Export as → Selection only para recortes limpios.

Ejercicio propuesto: abre el último diagrama que tengas hecho a mano y reconstrúyelo en draw.io con plantillas UML nativas. Compara el tiempo invertido versus la calidad obtenida y decide cuándo compensa cada herramienta.
