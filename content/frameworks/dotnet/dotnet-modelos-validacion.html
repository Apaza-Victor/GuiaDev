6.1 Modelos de dominio

Qué es un modelo de dominio

Un modelo de dominio es una clase C# que representa una entidad de negocio. Se usa tanto para guardar datos como para recibirlos de formularios.

Ejemplo: Modelo Usuario

public class Usuario
{
    public int Id { get; set; }
    public string Nombre { get; set; }
    public string Email { get; set; }
    public int Edad { get; set; }
    public bool Activo { get; set; }
}

Combinar con las acciones

[HttpPost]
public IActionResult Crear(Usuario usuario)
{
    if (ModelState.IsValid)
    {
        // guardar el usuario
        return RedirectToAction("Lista");
    }
    return View(usuario);
}

6.2 Data Annotations

Qué son

Los Data Annotations son atributos que decoran las propiedades del modelo para definir reglas de validación, formato y mapeo.

Atributos más usados

AtributoFunción
[Required]Campo obligatorio
[StringLength(20)]Longitud máxima
[Range(1, 120)]Rango numérico
[EmailAddress]Debe ser un email válido
[RegularExpression]Coincide con una expresión

Ejemplo: modelo validado

public class Usuario
{
    [Required(ErrorMessage = "El nombre es obligatorio")]
    [StringLength(50)]
    public string Nombre { get; set; }

    [Required]
    [EmailAddress(ErrorMessage = "Email inválido")]
    public string Email { get; set; }

    [Range(18, 120, ErrorMessage = "Edad entre 18 y 120")]
    public int Edad { get; set; }
}

6.3 Validación con ModelState

Qué es ModelState

ModelState almacena el estado de la validación del modelo enlazado. Contiene los errores de validación detectados automáticamente por las data annotations.

Ejemplo: comprobar la validación

[HttpPost]
public IActionResult Guardar(Usuario usuario)
{
    if (!ModelState.IsValid)
    {
        // Devuelve la vista con los errores
        return View(usuario);
    }

    // Datos válidos, continuar
    return RedirectToAction("Lista");
}

Añadir errores manualmente

if (usuario.Edad < 18)
{
    ModelState.AddModelError("Edad", "Debes ser mayor de edad");
}
La validación del servidor es imprescindible; la del cliente solo mejora la experiencia.

6.4 Tag Helpers de validación

Mostrar errores en la vista

Los Tag Helpers de validación muestran los mensajes de error junto a los campos del formulario.

Ejemplo: formulario con validación

@model Usuario

<form asp-action="Guardar" method="post">
    <div>
        <label asp-for="Nombre"></label>
        <input asp-for="Nombre" />
        <span asp-validation-for="Nombre" class="text-danger"></span>
    </div>

    <div>
        <label asp-for="Email"></label>
        <input asp-for="Email" />
        <span asp-validation-for="Email" class="text-danger"></span>
    </div>

    <div asp-validation-summary="ModelOnly"></div>
    <button type="submit">Guardar</button>
</form>

@section Scripts {
    <partial name="_ValidationScriptsPartial" />
}

6.5 Enlazado de modelos

Qué es el model binding

El model binding convierte los datos de la petición (formulario, query, ruta, JSON) en instancias de modelos C# automáticamente.

Formas de enlazar datos

  • Formulario: body por defecto en POST
  • Query string: parámetros en la URL
  • Ruta: segmentos de la URL
  • Cabeceras y body JSON: para APIs

Ejemplo: distintos orígenes

// /Producto/Buscar?nombre=laptop
public IActionResult Buscar(string nombre)
{
    return Content(nombre);
}

[HttpPost]
public IActionResult Crear(Producto producto)
{
    // Enlazado desde el form del cuerpo
    return Content(producto.Nombre);
}

Evitar sobre-enlazado

[Bind("Nombre", "Precio")]
public class ProductoViewModel
{
    public string Id { get; set; }  // no se enlaza
    public string Nombre { get; set; }
    public decimal Precio { get; set; }
}

Resumen

**Lo que aprendiste en esta sección:** - Los modelos de dominio representan entidades de negocio - Las Data Annotations definen reglas de validación en el modelo - ModelState centraliza el estado y los errores de validación - Los Tag Helpers de validación muestran errores en la vista - El model binding convierte datos de la petición en objetos - Conviene usar ViewModels para evitar el sobre-enlazado
