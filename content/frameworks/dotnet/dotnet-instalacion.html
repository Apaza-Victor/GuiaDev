2.1 Instalar el SDK de .NET

Qué es el SDK

El .NET SDK (Software Development Kit) incluye el runtime, la CLI y las herramientas necesarias para compilar y ejecutar aplicaciones. Para ejecutar solo las apps finales se usa el Runtime; para desarrollar, se instala el SDK.

Cómo instalar

  • Windows: Descarga el instalador desde el sitio oficial de Microsoft (dot.net)
  • Linux/macOS: Vía gestores de paquetes (apt, brew, snap) o desde dot.net
  • Verificar la instalación: Ejecutar el comando de versión

Comprobación desde la terminal

dotnet --version
dotnet --list-sdks
También puedes instalar el SDK con Visual Studio seleccionando la carga de trabajo "Desarrollo web y ASP.NET".

2.2 Crear un proyecto con dotnet new

El comando dotnet new

La CLI de .NET permite generar proyectos con plantillas predefinidas usando dotnet new:

# Proyecto web MVC
dotnet new mvc -o MiApp

# Proyecto Web API
dotnet new webapi -o MiApi

# Aplicación de consola
dotnet new console -o MiConsola

Plantillas más usadas

PlantillaComando
MVCdotnet new mvc
Web APIdotnet new webapi
Blazordotnet new blazor
Consoladotnet new console
Class librarydotnet new classlib

Ejemplo completo

dotnet new mvc -o MiTienda
cd MiTienda
dotnet run

2.3 Estructura de un proyecto

Archivos y carpetas principales

Un proyecto web ASP.NET Core generado incluye:

Archivo/CarpetaFunción
Program.csPunto de entrada de la aplicación
.csprojConfiguración del proyecto y dependencias
Controllers/Controladores MVC
Views/Vistas Razor (.cshtml)
wwwroot/Archivos estáticos (CSS, JS, imágenes)
appsettings.jsonConfiguración de la aplicación

Ejemplo: Program.cs (punto de entrada)

var builder = WebApplication.CreateBuilder(args);
builder.Services.AddControllersWithViews();

var app = builder.Build();

app.UseStaticFiles();
app.MapDefaultControllerRoute();

app.Run();

2.4 El archivo .csproj

Qué es el .csproj

El archivo .csproj es un documento XML que define la configuración del proyecto: versión de .NET, dependencias (paquetes NuGet), propiedades de compilación y más.

Ejemplo de un .csproj

<Project Sdk="Microsoft.NET.Sdk.Web">
  <PropertyGroup>
    <TargetFramework>net8.0</TargetFramework>
    <Nullable>enable</Nullable>
  </PropertyGroup>

  <ItemGroup>
    <PackageReference Include="Microsoft.EntityFrameworkCore.SqlServer"
      Version="8.0.0" />
  </ItemGroup>
</Project>

Elementos clave

  • TargetFramework: Versión de .NET (net8.0, net6.0, etc.)
  • Sdk: Tipo de proyecto (Web, worker, etc.)
  • PackageReference: Dependencias de NuGet

2.5 Ejecutar con dotnet run

Comandos básicos de la CLI

La CLI de dotnet es la herramienta principal para construir, ejecutar y probar:

ComandoFunción
dotnet buildCompila el proyecto
dotnet runCompila y ejecuta
dotnet testEjecuta pruebas
dotnet cleanLimpia archivos generados
dotnet add packageAgrega un paquete NuGet

Ejemplo: Ejecutar y ver resultado

dotnet run

# Salida: la app queda a la espera de peticiones
info: Microsoft.Hosting.Lifetime[14]
      Now listening on: http://localhost:5000
Usa `Ctrl + C` en la terminal para detener la aplicación que se ejecuta con `dotnet run`.

Resumen

**Lo que aprendiste en esta sección:** - El SDK de .NET se instala desde dot.net o con gestores de paquetes - Se verifica con `dotnet --version` y `dotnet --list-sdks` - `dotnet new` crea proyectos con plantillas (mvc, webapi, console) - Un proyecto incluye Program.cs, .csproj, Controllers, Views y wwwroot - El .csproj define la versión de .NET y las dependencias NuGet - `dotnet run`, `dotnet build` y `dotnet test` son los comandos clave
