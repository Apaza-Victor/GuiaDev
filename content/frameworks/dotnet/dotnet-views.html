5.1 Qué es Razor

Definición

Razor es el motor de vistas de ASP.NET Core. Permite combinar HTML con código C# usando el símbolo arroba (@). Los archivos de view usan la extensión .cshtml.

Ejemplo: Sintaxis Razor

@{
    var nombre = "Ana";
    var hora = DateTime.Now;
}

<h1>Hola, @nombre</h1>
<p>Son las @hora.Hour horas</p>

Elementos de Razor

SintaxisUso
@expresionImprime el valor de una expresión
@if / @foreachEstructuras de control
@modelDeclara el modelo de la vista
@{ ... }Bloque de código C#

---

5.2 Archivos .cshtml

Estructura de una vista

Las vistas viven en la carpeta Views/ siguiendo la convención Views/[Controlador]/[Accion].cshtml.

Ejemplo: una vista completa

@model List<Producto>

<h1>Lista de productos</h1>

<table>
    <tr><th>Nombre</th><th>Precio</th></tr>
    @foreach (var p in Model)
    {
        <tr>
            <td>@p.Nombre</td>
            <td>@p.Precio</td>
        </tr>
    }
</table>
La convención de nombres permite que el controlador encuentre la vista automáticamente con View().

---

5.3 Layout y plantillas

Qué es el Layout

El layout define la estructura común de todas las páginas (encabezado, menú, pie). Se encuentra en Views/Shared/_Layout.cshtml y usa la sección RenderBody().

Ejemplo: un layout básico

<!DOCTYPE html>
<html>
<head>
    <title>@ViewData["Title"]</title>
    <link rel="stylesheet" href="~/css/site.css" />
</head>
<body>
    <header>Mi sitio web</header>
    <main>
        @RenderBody()
    </main>
    <footer>© 2026</footer>
</body>
</html>

Forzar un layout desde una vista

@{
    Layout = "_Layout";
}

---

5.4 Vistas parciales

Qué son las vistas parciales

Las vistas parciales son fragmentos de vista reutilizables (por ejemplo, una tarjeta de producto). Se cargan desde otras vistas.

Ejemplo: carga una parcial

@model List<Producto>

<h1>Productos</h1>

@foreach (var p in Model)
{
    <partial name="_TarjetaProducto" model="p" />
}

Parcial: _TarjetaProducto.cshtml

@model Producto

<div class="card">
    <h3>@Model.Nombre</h3>
    <p>Precio: @Model.Precio</p>
</div>

Las parciales llevan prefijo de guion bajo (_Nombre.cshtml).

---

5.5 Tag Helpers

Qué son los Tag Helpers

Los Tag Helpers son atributos en etiquetas HTML que generan HTML del servidor. Ayudan a crear formularios y enlaces fuertemente tipados.

Ejemplo: formularios con Tag Helpers

@model Producto

<form asp-action="Guardar" method="post">
    <input asp-for="Nombre" />
    <input asp-for="Precio" />
    <button type="submit">Guardar</button>
</form>

Tag Helpers comunes

  • asp-action / asp-controller: Enlaces a acciones
  • asp-for: Enlaza campos a propiedades del modelo
  • asp-validation-for: Mensajes de validación

5.6 ViewData, ViewBag y Model

Pasar datos a la vista

Hay varias formas de enviar datos desde el controlador a la vista:

MecanismoDescripción
ModelObjeto fuertemente tipado con @model
ViewDataDiccionario de clave-valor
ViewBagAcceso dinámico sobre ViewData

Ejemplo: desde el controlador

public IActionResult Index()
{
    ViewData["Titulo"] = "Bienvenida";
    ViewBag.Mensaje = "Hola desde ViewBag";

    var productos = new List<Producto> { /* ... */ };
    return View(productos);
}

En la vista

@model List<Producto>

<h1>@ViewData["Titulo"]</h1>
<p>@ViewBag.Mensaje</p>
<p>Hay @Model.Count productos</p>
Prefiere el uso de `@model` fuertemente tipado siempre que sea posible, es más seguro y legible.

---

Resumen

**Lo que aprendiste en esta sección:** - Razor combina HTML y C# con el símbolo @ - Las vistas usan archivos .cshtml en la carpeta Views/ - El layout define la estructura común usando RenderBody() - Las parciales son fragmentos reutilizables - Los Tag Helpers generan HTML fuertemente tipado - Los datos se pasan con Model, ViewData y ViewBag
