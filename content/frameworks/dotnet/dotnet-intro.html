1.1 Qué es .NET

Definición

.NET es una plataforma de desarrollo gratuita, de código abierto y multiplataforma creada por Microsoft. Incluye un runtime, librerías de clases y herramientas para construir aplicaciones. .NET Core es la versión moderna, multiplataforma (Windows, Linux y macOS) y de código abierto que hereda y mejora al antiguo .NET Framework.

Relación con C#

ElementoDescripción
.NETPlataforma de ejecución y librerías
C#Lenguaje principal recomendado
RuntimeEjecuta el código (CoreCLR)
BCLSistema de librerías de clases base

Ejemplo: Hola mundo en C#

Console.WriteLine("Hola, .NET");
Console.WriteLine($"Versión: {Environment.Version}");

1.2 Tipos de aplicaciones

Tipos de apps con .NET

.NET permite crear múltiples tipos de aplicaciones:

  • Web MVC: Aplicaciones web con páginas HTML en el servidor
  • Web API: Servicios RESTful que devuelven datos JSON
  • Blazor: Interfaces web interactivas con C# en lugar de JavaScript
  • Aplicaciones de consola: Herramientas de línea de comandos
  • Aplicaciones de escritorio: Windows Forms, WPF, MAUI
  • Móvil: Aplicaciones iOS y Android con MAUI

Comparativa de tipos web

TipoUso principalFrontend
MVCWeb clásicaVistas Razor
APIBackendJSON
BlazorSPAComponentes C#

Ejemplo: Proyecto API

var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

app.MapGet("/", () => "Hola desde una Web API");

app.Run();

1.3 Por qué usar .NET

Razones principales

.NET es una de las plataformas más completas del ecosistema moderno:

VentajaDescripción
MultiplataformaWindows, Linux y macOS
Alto rendimientoCompila a código nativo (AOT disponibles)
Tipado seguroDetección de errores en tiempo de compilación
Ecosistema ricoNuGet, EF Core, ASP.NET Core
Comunidad y soporteMicrosoft y miles de contribuidores
Open sourceCódigo abierto bajo licencia MIT

Ejemplo: Contar objetos con LINQ

var numeros = new[] { 1, 2, 3, 4, 5, 6 };
var pares = numeros.Where(n => n % 2 == 0).Count();
Console.WriteLine($"Hay {pares} números pares");
Empieza con proyectos web (MVC o API) para aprovechar todo el potencial de ASP.NET Core.

1.4 Características clave

Características de la plataforma

  • Unified Platform: Un único BCL para todas las apps
  • Garbage Collector: Gestión automática de memoria
  • Async/Await: Programación asíncrona nativa
  • Compiler Roslyn: Compilador moderno y extensible
  • Interoperabilidad: Con librerías nativas y COM

Ejemplo: Programación asíncrona

public async Task<string> ObtenerDatosAsync()
{
    await Task.Delay(1000);
    return "Datos listos";
}

await ObtenerDatosAsync();

Escenarios de uso

.NET brilla en:

  • Microservicios: Servicios independientes y escalables
  • Aplicaciones empresariales: ERP, CRM, sistemas internos
  • Servicios en la nube: Azure, AWS, Google Cloud
  • Juegos: Con Unity (C#)

1.5 ASP.NET Core

Qué es ASP.NET Core

ASP.NET Core es el framework web de .NET. Permite crear aplicaciones web, APIs y microservicios con C#. Es modular, ligero y rápido, con soporte nativo para inyección de dependencias, middleware y configuración por convención.

Partes de ASP.NET Core

ComponenteFunción
MVCPatrón Modelo-Vista-Controlador
RazorMotor de vistas con HTML y C#
MiddlewarePipeline de procesamiento de peticiones
DIInyección de dependencias integrada
EF CoreORM para acceso a datos

Ejemplo: App ASP.NET Core mínima

var builder = WebApplication.CreateBuilder(args);
builder.Services.AddControllers();

var app = builder.Build();
app.MapControllers();

app.Run();

Resumen

**Lo que aprendiste en esta sección:** - .NET es una plataforma multiplataforma, open source y de alto rendimiento - C# es el lenguaje principal recomendado para trabajar con .NET - ASP.NET Core permite crear web MVC, Web API y Blazor - .NET ofrece tipado seguro, LINQ, async/await y gran rendimiento - ASP.NET Core es modular, con middleware, DI y EF Core
