7.1 Qué es Entity Framework Core

Definición

Entity Framework Core (EF Core) es un ORM (Object-Relational Mapper) para .NET. Permite trabajar con una base de datos usando objetos C# y LINQ, sin escribir SQL manual para las operaciones comunes.

Beneficios

BeneficioDescripción
ProductividadNo escribir SQL repetitivo
Tipado seguroConsultas con LINQ compiladas
Multi-BDSQL Server, SQLite, PostgreSQL, MySQL
MigrationsSincronizan el esquema de la BD

Instalar

dotnet add package Microsoft.EntityFrameworkCore.SqlServer
dotnet add package Microsoft.EntityFrameworkCore.Tools

7.2 El DbContext

Qué es el DbContext

El DbContext es la clase principal de EF Core. Representa una sesión con la base de datos y contiene conjuntos de entidades (DbSet).

Ejemplo: DbContext de una tienda

public class TiendaContext : DbContext
{
    public TiendaContext(DbContextOptions<TiendaContext> options)
        : base(options)
    {
    }

    public DbSet<Producto> Productos { get; set; }
    public DbSet<Categoria> Categorias { get; set; }
}

Los DbSet<T> exponen cada tabla como una colección consultable.

---

7.3 Modelos y entidades

Qué es una entidad

Una entidad es una clase C# que se mapea a una tabla de la base de datos. Sus propiedades se convierten en columnas.

Ejemplo: entidades y sus relaciones

public class Producto
{
    public int Id { get; set; }
    public string Nombre { get; set; }
    public decimal Precio { get; set; }

    public int CategoriaId { get; set; }
    public Categoria Categoria { get; set; }
}

public class Categoria
{
    public int Id { get; set; }
    public string Nombre { get; set; }
    public List<Producto> Productos { get; set; } = new();
}

Convenciones clave

  • Id: se convierte en clave primaria
  • PropiedadId: clave externa
  • Propiedad de navegación: relación entre entidades

7.4 Migraciones

Qué son las migraciones

Las migraciones son versiones del esquema de la base de datos generadas a partir de los modelos. Permiten crear, actualizar y sincronizar la BD sin escribir SQL.

Comandos

# Crear una migración
dotnet ef migrations add Inicial

# Aplicar migraciones a la BD
dotnet ef database update

Ciclo típico

  • Modificar o crear modelos
  • add migration: genera una migración
  • database update: aplica los cambios
Consulta todas las migraciones con `dotnet ef migrations list`.

7.5 CRUD con LINQ

Operaciones CRUD

Con EF Core se hace CRUD (Create, Read, Update, Delete) usando LINQ y métodos del contexto.

Crear y leer

// Crear
var nuevo = new Producto { Nombre = "Mouse", Precio = 29.99m };
_context.Productos.Add(nuevo);
await _context.SaveChangesAsync();

// Leer todos
var todos = await _context.Productos.ToListAsync();

// Leer con filtro
var caros = await _context.Productos
    .Where(p => p.Precio > 100)
    .OrderByDescending(p => p.Precio)
    .ToListAsync();

Actualizar y eliminar

// Actualizar
var producto = await _context.Productos.FindAsync(1);
if (producto != null)
{
    producto.Precio = 39.99m;
    await _context.SaveChangesAsync();
}

// Eliminar
var eliminar = await _context.Productos.FindAsync(2);
if (eliminar != null)
{
    _context.Productos.Remove(eliminar);
    await _context.SaveChangesAsync();
}

7.6 EF Core en un controlador

Registrar el DbContext

El DbContext se registra en el contenedor de dependencias de Program.cs:

var builder = WebApplication.CreateBuilder(args);

builder.Services.AddDbContext<TiendaContext>(options =>
    options.UseSqlServer(builder.Configuration
        .GetConnectionString("Tienda")));

var app = builder.Build();
app.Run();

Usarlo en un controlador

public class ProductoController : Controller
{
    private readonly TiendaContext _context;

    public ProductoController(TiendaContext context)
    {
        _context = context;
    }

    public async Task<IActionResult> Index()
    {
        var productos = await _context.Productos.ToListAsync();
        return View(productos);
    }
}
La conexión se define en appsettings.json en la sección ConnectionStrings.

Resumen

**Lo que aprendiste en esta sección:** - EF Core es un ORM para trabajar con bases de datos usando C# - El DbContext define las tablas con DbSet y la conexión - Las entidades se mapean a tablas y columnas - Las migraciones sincronizan el esquema de la BD - CRUD se hace con LINQ y SaveChangesAsync - El DbContext se inyecta en controladores y servicios
