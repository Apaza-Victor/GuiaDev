8.1 Qué es una API web

Definición

Una API web (Web API) es un servicio que expone datos y funcionalidad a través de HTTP. En lugar de devolver HTML, devuelve datos (normalmente JSON) que consumen otras aplicaciones, frontends o clientes móviles.

Diferencias con MVC

AspectoMVCWeb API
RespuestaHTML (vistas)JSON / XML
ConsumidorNavegadorClientes, apps, SPA
BaseControllerControllerBase

Ejemplo: controlador de API

[ApiController]
[Route("api/[controller]")]
public class UsuariosController : ControllerBase
{
    [HttpGet]
    public IActionResult ObtenerTodos()
    {
        return Ok(new[] { new { Id = 1, Nombre = "Ana" } });
    }
}

8.2 [ApiController] y JSON

El atributo [ApiController]

[ApiController] habilita convenciones para APIs:

  • Validación automática del modelo (ModelState)
  • Enlazado del body JSON por defecto
  • Respuestas de error automáticas

Serialización JSON

La API convierte automáticamente los objetos C# a JSON y viceversa usando System.Text.Json.

Ejemplo: modelo a JSON

public class Producto
{
    public int Id { get; set; }
    public string Nombre { get; set; }
    public decimal Precio { get; set; }
}

// Devuelve: {"id":1,"nombre":"Mouse","precio":29.99}
[HttpGet("{id}")]
public ActionResult<Producto> Obtener(int id)
{
    return new Producto { Id = id, Nombre = "Mouse", Precio = 29.99m };
}

8.3 Métodos HTTP

Verbos HTTP y su propósito

MétodoAcciónAtributo
GETObtener recursos[HttpGet]
POSTCrear recursos[HttpPost]
PUTActualizar (completo)[HttpPut]
PATCHActualizar parcial[HttpPatch]
DELETEEliminar[HttpDelete]

Ejemplo: CRUD en una API

[ApiController]
[Route("api/productos")]
public class ProductosController : ControllerBase
{
    [HttpGet]
    public IActionResult Listar() => Ok(new[] { new Producto() });

    [HttpGet("{id}")]
    public IActionResult Obtener(int id)
        => id > 0 ? Ok(new Producto()) : NotFound();

    [HttpPost]
    public IActionResult Crear(Producto producto)
        => CreatedAtAction(nameof(Obtener), new { id = 1 }, producto);

    [HttpPut("{id}")]
    public IActionResult Actualizar(int id, Producto producto) => NoContent();

    [HttpDelete("{id}")]
    public IActionResult Borrar(int id) => NoContent();
}

8.4 Códigos de estado

Códigos principales

Las APIs usan códigos de estado HTTP para comunicar el resultado de cada operación.

CódigoSignificadoMétodo helper
200 OKÉxitoOk()
201 CreatedRecurso creadoCreatedAtAction()
204 No ContentÉxito sin contenidoNoContent()
400 Bad RequestPetición inválidaBadRequest()
401 UnauthorizedNo autenticadoUnauthorized()
404 Not FoundRecurso no existeNotFound()

Ejemplo: respuesta 201

[HttpPost]
public IActionResult Crear(Producto producto)
{
    // guardar en BD y obtener el nuevo Id
    return CreatedAtAction(nameof(Obtener), new { id = producto.Id }, producto);
}

8.5 Minimal APIs

Qué son las Minimal APIs

Las Minimal APIs permiten crear APIs con el mínimo de código, sin controladores, definiendo endpoints directamente con lambdas.

Ejemplo: Minimal API completa

var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

var productos = new List<Producto>();

app.MapGet("/productos", () => productos);
app.MapGet("/productos/{id}", (int id) =>

    productos.FirstOrDefault(p => p.Id == id)
        is { } p ? Results.Ok(p) : Results.NotFound());

app.MapPost("/productos", (Producto producto) =>
{
    productos.Add(producto);
    return Results.Created($"/productos/{producto.Id}", producto);
});

app.MapDelete("/productos/{id}", (int id) =>
{
    productos.RemoveAll(p => p.Id == id);
    return Results.NoContent();
});

app.Run();
Elige Minimal APIs para servicios simples y controladores para apps grandes y organizadas.

8.6 Probar la API

Herramientas para probar

Puedes probar las APIs con herramientas visuales o de línea de comandos:

  • Swagger UI: Documentación interactiva incluida en desarrollo
  • Postman: Cliente visual de APIs
  • Insomnia: Alternativa a Postman
  • curl: desde la terminal

Ejemplo con curl

# Obtener todos los productos
curl http://localhost:5000/api/productos

# Crear un producto via POST
curl -X POST http://localhost:5000/api/productos \
     -H "Content-Type: application/json" \
     -d '{"nombre":"Teclado","precio":49.99}'

En desarrollo, Swagger suele estar disponible en /swagger.

Resumen

**Lo que aprendiste en esta sección:** - Una API web expone datos y funcionalidad vía HTTP - Devuelve JSON en lugar de HTML - [ApiController] habilita convenciones y validación - Los verbos HTTP definen las operaciones (GET, POST, PUT, DELETE) - Los códigos de estado comunican los resultados - Las Minimal APIs definen endpoints sin controladores - Swagger, Postman y curl ayudan a probar las APIs
