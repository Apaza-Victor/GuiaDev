Inertia con Laravel + Vite

La integración canónica de Inertia es Laravel como backend + Vite como bundler. El punto de unión son tres archivos:

<!-- resources/views/app.blade.php: raiz SPA -->
<!DOCTYPE html>
<html lang="{{ str_replace('_', '-', app()->getLocale()) }}">
<head>
    @viteReactRefresh
    @vite('resources/js/app.js')
    @inertiaHead
</head>
<body>
    @inertia
</body>
</html>
// resources/js/app.js: bootstrap
import { createInertiaApp } from '@inertiajs/vue3';
import { createApp } from 'vue';

createInertiaApp({
  resolve: (name) => {
    const pages = import.meta.glob('./Pages/**/*.vue');
    return pages[`./Pages/${name}.vue`]();
  },
  setup({ el, App, props, plugin }) {
    createApp({ render: () => h(App, props) })
      .use(plugin)
      .mount(el);
  },
});

Con esto funcionan HMR en desarrollo y builds optimizados con code splitting automático.

Formularios y validación integrada

El helper useForm es la pieza que más se disfruta de Inertia — estado, errores, progreso y reset en un objeto:

<script setup>
import { useForm } from '@inertiajs/vue3';

const form = useForm({
  titulo: '',
  descripcion: '',
});

function submit() {
  form.post(route('posts.store'), {
    onSuccess: () => form.reset(),
  });
}
</script>

<template>
  <form @submit.prevent="submit">
    <input v-model="form.titulo" :error="form.errors.titulo" />
    <textarea v-model="form.descripcion" />
    <button type="submit" :disabled="form.processing">Publicar</button>
  </form>
</template>
  • v-model directo sobre propiedades del form.
  • Errores server-side aparecen en form.errors.campo sin lógica extra.
  • Métodos útiles: put/patch/delete/reset/clearErrors.

Testing E2E con Inertia

  • Laravel Dusk / Playwright: pruebas de navegador reales — login, crear registro, verificar toast. Como Inertia no cambia URLs al navegar, tus selectores apuntan a contenido, no a rutas.
  • Tests HTTP de Laravel: afirman las páginas Inertia directamente:
public function test_panel_muestra_usuario(): void
{
    $user = User::factory()->create();

    $response = $this->actingAs($user)->get('/panel');

    $response->assertInertia(fn (Assert $page) => $page
        ->component('Panel')                       // pagina correcta
        ->has('auth.user')                         // props presentes
        ->where('auth.user.email', $user->email)
    );
}

assertInertia verifica página Y props sin navegador: rápido y estable. Reserva Dusk/Playwright para los flujos críticos de negocio, no para cada pantalla.

Ejercicio propuesto: instala Inertia en un Laravel limpio, integra tu librería de UI favorita y escribe un test assertInertia que valide la página dashboard con sus tres primeras props.
