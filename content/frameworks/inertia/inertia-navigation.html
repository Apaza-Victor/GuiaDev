El componente Link

Inertia convierte tu app en SPA sin API: los enlaces se interceptan y resuelven por XHR sin recargar la página. El componente <Link> reemplaza al <a> tradicional:

<!-- Vue 3 -->
<script setup>
import { Link } from '@inertiajs/vue3';
</script>

<template>
  <Link href="/usuarios">Usuarios</Link>

  <!-- Con datos y metodo -->
  <Link :href="`/usuarios/${usuario.id}`" method="delete" as="button">
    Eliminar
  </Link>

  <!-- Estado activo automatico -->
  <Link href="/panel" :class="{ activo: $page.url.startsWith('/panel') }">Panel</Link>
</template>
  • method="post|put|patch|delete": permite acciones completas sin formularios.
  • data="{ filtro: 'activos' }": envía parámetros.
  • preserve-scroll: mantiene posición de scroll (ideal paginación con filtros).
  • only={['users']}: partial reload — recarga solo esas props.

Navegación programática con router

Para navegar desde JavaScript (tras un submit, una confirmación, un timeout):

import { router } from '@inertiajs/vue3';

// Visitas
router.visit('/usuarios');
router.visit('/login', { method: 'post', data: { email, password } });

// Atajos
router.post('/pedidos', datos);
router.put(`/perfil/${id}`, datos);
router.delete(`/carrito/${itemId}`);
router.reload();                    // refresca props de la pagina actual
router.replace('/nueva-url');       // no agrega al historial

// Opciones utiles
router.visit('/dashboard', {
  preserveState: true,              // no resetea estado local del componente
  preserveScroll: true,
  only: ['notificaciones'],
  onSuccess: (page) => toast('Listo'),
});

Eventos, indicador de progreso y carga

// Barra de progreso integrada (en app.js)
import { createInertiaApp } from '@inertiajs/vue3';

createInertiaApp({
  progress: {
    color: '#29d',
    showSpinner: true,
  },
});

// Hooks globales para spinners propios
router.on('start', () => cargando.value = true);
router.on('finish', () => cargando.value = false);
  • on('start' | 'finish' | 'success' | 'error'): eventos globales.
  • Por visita individual: callbacks onSuccess, onError, onFinish.

Remember: estado entre navegaciones

Inertia guarda el snapshot de cada página en historial. Con remember, también preserva el estado local de componentes al volver atrás:

<script setup>
import { useForm } from '@inertiajs/vue3';

// El formulario sobrevive a navegacion hacia atras/adelante
const form = useForm({
  titulo: '',
  contenido: '',
}, { remember: true });
</script>

Usa remember en filtros de listado y formularios largos. Evítalo en datos sensibles o que caducan rápido (tokens, búsquedas temporales).
