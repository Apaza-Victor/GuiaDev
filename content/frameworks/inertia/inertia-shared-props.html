¿Qué son las props compartidas?

El middleware HandleInertiaRequests define datos que llegan a TODAS las páginas: usuario autenticado, flash messages, configuración global. Es el reemplazo de los "global variables" de Blade:

// app/Http/Middleware/HandleInertiaRequests.php
public function share(Request $request): array
{
    return [
        ...parent::share($request),
        'auth' => [
            'user' => fn () => $request->user()
                ? $request->user()->only('id', 'name', 'email')
                : null,
        ],
        'flash' => [
            'success' => fn () => $request->session()->get('success'),
        ],
        'app' => [
            'nombre' => config('app.name'),
            'url' => config('app.url'),
        ],
    ];
}

Las funciones flecha hacen la resolución LAZY: esa prop solo se calcula si la página la usa. Sin lazy, consultarías el usuario en cada request aunque la página no lo necesite.

Acceder desde el frontend

<script setup>
import { usePage } from '@inertiajs/vue3';
import { computed } from 'vue';

const page = usePage();

// Reactivo: se actualiza en cada visita
const usuario = computed(() => page.props.auth.user);
const nombre = computed(() => page.props.app.nombre);

// En template directamente
</script>

<template>
  <nav v-if="usuario">
    Hola, {{ usuario.name }}
    <Link :href="route('logout')" method="post">Salir</Link>
  </nav>
</template>
  • En Vue también disponible como $page.props... directo en templates sin setup.
  • Úsalo para: usuario actual, permisos/roles, flash, i18n básico, csrf token si necesitas XHR manual.
  • NO lo uses para datos específicos de una página — esos van en sus props propias.

Patrón layout + props compartidas

Combinación típica: props compartidas alimentan el layout persistente (navbar, sidebar, footer):

<!-- resources/js/Layouts/MainLayout.vue -->
<script setup>
import { usePage } from '@inertiajs/vue3';

const page = usePage();
</script>

<template>
  <header>{{ page.props.app.nombre }}</header>
  <aside v-if="page.props.auth.user"><!-- menu --></aside>
  <main>
    <slot />
  </main>
  <Toast />  <!-- lee flash -->
</template>

Cada página envuelve su contenido con el layout y recibe gratis usuario, menú condicionado por rol y toasts flash — sin repetir lógica en ninguna página.

Tipado de props compartidas

Con TypeScript declara la forma de tus props compartidas una vez y úsala en todo el proyecto:

// resources/js/types/index.d.ts
export interface SharedProps {
  auth: { user: { id: number; name: string; email: string } | null };
  flash: { success?: string; error?: string };
  app: { nombre: string; url: string };
}

declare module '@inertiajs/core' {
  interface PageProps extends InertiaPageProps {
    [key: string]: unknown;
  }
}

Ejercicio propuesto: audita tu app — ¿cuántas páginas repiten "traer usuario" o "leer flash" manualmente? Muévelas todas a props compartidas lazy y elimina la duplicación.
