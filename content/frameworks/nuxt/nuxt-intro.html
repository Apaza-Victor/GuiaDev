1.1 Qué es Nuxt

Definición

Nuxt es un framework de alto nivel construido sobre Vue 3 que te permite crear aplicaciones web universales: aplicaciones de una sola página (SPA), renderizadas en el servidor (SSR), renderizadas estáticamente (SSG) o con revalidación incremental (ISR). Nuxt maneja la configuración, el enrutado, la obtención de datos y el SSR por ti, para que te centres en construir tus interfaces.

Características principales

CaracterísticaDescripción
Basado en Vue 3Aprovecha la Composition API y el rendimiento de Vue 3
File-based routingLas rutas se crean a partir de los archivos en pages/
Auto-importsComponentes y composables se importan automáticamente
SSR / SSG / ISRElige cómo y cuándo renderizar tu contenido
Fetching de datosComposables como useFetch simplifican la obtención de datos
Ecosistema de módulosPuedes extender Nuxt con módulos oficiales y de la comunidad

Ejemplo: Hola mundo en Nuxt

<template>
  <div>
    <h1>Hola, Nuxt!</h1>
  </div>
</template>

<script setup>
// El script setup usa la Composition API de Vue 3
const mensaje = ref('Hola desde Nuxt')
</script>

1.2 Por qué Nuxt en vez de Vue

Vue es una librería, Nuxt es un framework

Vue solo es una librería de interfaz de usuario. Con Vue necesitas configurar manualmente el enrutador, el estado, el build tool, el SSR y muchas otras piezas. Nuxt integra todas esas piezas de forma coherente y con convenciones por defecto.

AspectoVue (solo)Nuxt
EnrutadoConfigurar vue-routerAutomático por archivos
SSRConfiguración complejaIncluido por defecto
Build toolConfigurar Vite tú mismoPreconfigurado con Vite
Auto-importsNoSí
Obtención de datosManualuseFetch y useAsyncData

Cuándo usar cada uno

  • Vue: Componentes aislados, SPAs simples o integrarse en proyectos existentes
  • Nuxt: Aplicaciones completas, SEO requerido, landing pages, e-commerce, contenido
Si tu aplicación necesita buen SEO, rendimiento inicial o muchas páginas, Nuxt es la opción natural porque ya trae SSR y SSG listos.

1.3 SSR, SSG e ISR

Modos de renderizado

Nuxt permite elegir cómo se genera y sirve tu aplicación:

ModoSignificadoCuándo usarlo
SSRServer-Side Rendering: cada petición se renderiza en el servidorDatos dinámicos por usuario, tiempo real
SSGStatic Site Generation: se genera HTML estático previamenteBlogs, documentación, contenido fijo
ISRIncremental Static Regeneration: estático con revalidaciónDatos que cambian con poca frecuencia
SPASingle Page Application: todo se renderiza en el clienteAplicaciones internas y paneles de admin

Ventajas del renderizado híbrido

  • Mejor SEO: el contenido está disponible para los motores de búsqueda
  • Menor tiempo de carga inicial: el usuario ve HTML listo
  • Flexibilidad: puedes combinar SSG e ISR en la misma app

Ejemplo: Configurar el modo de renderizado

// nuxt.config.ts
export default defineNuxtConfig({
  ssr: true, // SSR habilitado por defecto
  prerender: { // SSG para rutas específicas
    routes: ['/', '/sobre-nosotros']
  }
})

1.4 Superpoderes de Nuxt

Auto-imports

Nuxt importa automáticamente componentes, composables y funciones de Vue. No necesitas importarlos manualmente en cada archivo. Puedes usar ref, computed, useFetch y componentes directamente.

File-based routing

Cada archivo dentro de pages/ se convierte automáticamente en una ruta. Esta convención elimina la configuración manual del enrutador.

ArchivoRuta generada
pages/index.vue/
pages/contacto.vue/contacto
pages/blog/[id].vue/blog/:id
pages/servicios/index.vue/servicios

Núcleo de Nuxt

app/
├── components/    # Componentes con auto-import
├── composables/   # Composables con auto-import
├── layouts/       # Layouts para estructurar páginas
├── pages/         # Rutas basadas en archivos
├── plugins/       # Plugins de Nuxt
├── server/        # API y middleware del servidor
└── app.vue        # Componente raíz

1.5 Estructura y convenciones

Convenciones por convención

Nuxt sigue el principio de convención sobre configuración: si colocas los archivos en las carpetas correctas, Nuxt los detecta y los usa automáticamente.

CarpetaConvención / utilidad
pages/Rutas de la aplicación
components/Componentes reutilizables con auto-import
layouts/Estructuras de página (navbar, footer)
composables/Lógica reutilizable
plugins/Código que se ejecuta al arrancar la app
server/Endpoints de API y middleware
assets/CSS, imágenes y otros recursos
public/Archivos estáticos servidos tal cual

Cuándo usar Nuxt en proyectos reales

  • E-commerce: buena para SEO de productos y SSG de catálogos
  • Blogs y documentación: perfecto con @nuxt/content
  • Dashboards: funciona como SPA con autenticación
  • Landing pages: carga rápida y buen SEO

1.6 Nuxt 3 y nuevas funcionalidades

Qué trae Nuxt 3

Nuxt 3 es la versión actual del framework, completamente reescrita sobre Vue 3, Vite y Nitro. Ofrece un rendimiento mayor, un desarrollo más rápido y un mejor rendimiento en entornos serverless.

NovedadDescripción
ViteBuild tool ultra rápido para desarrollo y producción
NitroMotor de servidor universal (Node, serverless, edge)
NuxiCLI moderna para crear y gestionar proyectos
Auto-importsComposables y componentes sin importaciones manuales
Nuxt DevToolsHerramientas integradas de depuración en el navegador

Ejemplo: Composable auto-importado

// composables/useContador.ts (se auto-importa)
export function useContador() {
  const contador = ref(0)
  const incrementar = () => contador.value++
  return { contador, incrementar }
}

// En cualquier página o componente:
const { contador, incrementar } = useContador()

Resumen

**Lo que aprendiste en esta sección:** - Nuxt es un framework sobre Vue 3 que añade SSR, SSG, ISR y muchas convenciones - Elegir Nuxt sobre Vue solo te ahorra configurar enrutado, SSR y build tool - Entiendes los modos de renderizado: SSR, SSG, ISR y SPA - El file-based routing y los auto-imports son superpoderes clave - La estructura de carpetas sigue convenciones simples y predecibles - Nuxt 3 está basado en Vite y Nitro para máximo rendimiento
