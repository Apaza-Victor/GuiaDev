4.1 Componentes con auto-import

Qué es el auto-import de componentes

Todo lo que coloques en app/components/ estará disponible en cualquier plantilla sin necesidad de importarlo manualmente. Nuxt detecta los archivos y registra los componentes automáticamente.

Ejemplo: Componente de botón

app/components/
├── BotonPrincipal.vue
└── Tarjeta.vue

<!-- app/components/BotonPrincipal.vue -->
<template>
  <button class="btn" @click="onClick">
    <slot />
  </button>
</template>

<script setup>
const props = defineProps({
  type: { type: String, default: 'button' }
})
</script>

Usar el componente sin importar

<!-- pages/index.vue -->
<template>
  <div>
    <BotonPrincipal type="submit">Enviar</BotonPrincipal>
  </div>
</template>

Componentes en subcarpetas

Si usas subcarpetas, el nombre del componente incluye el prefijo de la ruta:

app/components/ui/Card.vue  ->  <UiCard />
app/components/blog/PostCard.vue  ->  <BlogPostCard />

4.2 Nuestro primer layout

Qué es un layout

Un layout define la estructura común de las páginas: la barra de navegación, el pie de página, la barra lateral, etc. Las páginas se renderizan dentro de un layout.

Layout por defecto

<!-- app/layouts/default.vue -->
<template>
  <div>
    <header>
      <NavBar />
    </header>
    <main>
      <slot />
    </main>
    <footer>
      <p>© 2025 Mi Sitio</p>
    </footer>
  </div>
</template>

Cuándo usar layouts

  • Mantener la misma navegación en muchas páginas
  • Diferenciar secciones: una página de login sin navbar
  • Estructurar el contenido de manera consistente
El layout default.vue se aplica automáticamente si no especificas otro.

---

4.3 Definir layouts personalizados

Crear un layout personalizado

Puedes crear múltiples layouts y asignar cada página al que necesites. Los layouts se guardan en app/layouts/.

<!-- app/layouts/auth.vue -->
<template>
  <div class="auth">
    <main>
      <slot />
    </main>
  </div>
</template>

Asignar un layout a una página

Se usa la propiedad definePageMeta dentro de la página para indicar qué layout usar.

<!-- pages/login.vue -->
<template>
  <div>
    <h1>Iniciar sesión</h1>
    <!-- formulario -->
  </div>
</template>

<script setup>
definePageMeta({
  layout: 'auth'
})
</script>

Layout dinámico por ruta

También puedes elegir el layout de forma dinámica con setPageLayout según alguna lógica.

if (esPanelAdmin) {
  setPageLayout('admin')
}

4.4 NuxtLayout y NuxtPage

Componentes especiales

Dos componentes clave controlan cómo se renderizan layouts y páginas:

ComponenteFunción
<NuxtLayout>Renderiza la estructura del layout y su contenido
<NuxtPage>Renderiza la página activa dentro del layout

app.vue con layouts y páginas

<!-- app/app.vue -->
<template>
  <NuxtLayout>
    <NuxtPage />
  </NuxtLayout>
</template>

Uso con transiciones

Nuxt ofrece soporte integrado para transiciones entre páginas:

<!-- app/app.vue -->
<template>
  <NuxtLayout>
    <NuxtPage transition="page" />
  </NuxtLayout>
</template>

<style>
.page-enter-active, .page-leave-active {
  transition: opacity 0.3s;
}
.page-enter-from, .page-leave-to {
  opacity: 0;
}
</style>

4.5 Ejemplo completo de componentes y layouts

Estructura de una ficha de producto

Veamos un ejemplo combinando componentes y un layout para una tienda sencilla.

app/
├── layouts/
│   ├── default.vue        # Navbar + footer
│   └── auth.vue           # Sin navbar
├── components/
│   ├── NavBar.vue
│   ├── PiePagina.vue
│   └── ProductoCard.vue
└── pages/
    ├── index.vue
    └── login.vue

Componente ProductoCard

<!-- app/components/ProductoCard.vue -->
<template>
  <article class="producto">
    <h3>{{ producto.nombre }}</h3>
    <p>{{ producto.precio }} €</p>
    <slot name="acciones" />
  </article>
</template>

<script setup>
defineProps({
  producto: { type: Object, required: true }
})
</script>

Uso del componente en una página

<!-- pages/index.vue -->
<template>
  <div class="grid">
    <ProductoCard
      v-for="producto in productos"
      :key="producto.id"
      :producto="producto"
    >
      <template #acciones>
        <button>Añadir al carrito</button>
      </template>
    </ProductoCard>
  </div>
</template>

<script setup>
const productos = [
  { id: 1, nombre: 'Laptop', precio: 999 },
  { id: 2, nombre: 'Mouse', precio: 29 }
]
</script>

4.6 Buenas prácticas organizando componentes

Organización recomendada

  • Agrupa componentes por característica o dominio
  • Usa nombres descriptivos con prefijos de carpeta
  • Separa componentes de presentación de los de lógica
  • Evita componentes gigantes: divide en piezas pequeñas

Ejemplo de estructura por dominio

app/components/
├── ui/               # Componentes genéricos (botones, inputs)
│   ├── Boton.vue
│   └── Modal.vue
├── usuario/          # Lógica y vistas de usuario
│   ├── Perfil.vue
│   └── Avatar.vue
└── tienda/           # Componentes de la tienda
    ├── CarritoWidget.vue
    └── ProductoCard.vue
Usa el atributo defineOptions({ name: 'MiComponente' }) para dar nombres explícitos y facilitar la depuración.

---

Resumen

**Lo que aprendiste en esta sección:** - Los componentes en app/components/ se auto-importan automáticamente - Los layouts definen la estructura común de las páginas - Puedes crear layouts personalizados y asignarlos con definePageMeta - NuxtLayout y NuxtPage conectan páginas con layouts - Organiza los componentes por dominio para mantener el código limpio - Agrupa componentes reutilizables en una carpeta ui/
