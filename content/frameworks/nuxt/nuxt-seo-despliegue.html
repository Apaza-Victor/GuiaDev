10.1 Metadatos y SEO con Nuxt

SEO nativo en Nuxt

Gracias al SSR y SSG, Nuxt ofrece un SEO excelente desde el principio: el contenido llega renderizado en el HTML y puede añadir metadatos completos de forma reactiva.

Definir metadatos del sitio

// nuxt.config.ts
export default defineNuxtConfig({
  app: {
    head: {
      htmlAttrs: { lang: 'es' },
      title: 'Mi Sitio',
      titleTemplate: '%s | Mi Sitio',
      meta: [
        { charset: 'utf-8' },
        { name: 'viewport', content: 'width=device-width, initial-scale=1' },
        { name: 'description', content: 'Descripción principal del sitio' }
      ],
      link: [
        { rel: 'icon', href: '/favicon.ico' }
      ]
    }
  }
})

Metadatos por página con useSeoMeta

<script setup>
useSeoMeta({
  title: 'Productos destacados',
  description: 'Los mejores productos con ofertas exclusivas',
  ogTitle: 'Productos destacados',
  ogDescription: 'Descubre nuestras ofertas',
  ogType: 'website'
})
</script>

Estructuras de datos (Schema.org)

Nuxt permite inyectar JSON-LD para que los motores de búsqueda entiendan mejor el contenido.

<script setup>
useHead({
  script: [{
    type: 'application/ld+json',
    children: JSON.stringify({
      '@context': 'https://schema.org',
      '@type': 'Organization',
      name: 'Mi Sitio',
      url: 'https://mistiio.com'
    })
  }]
})
</script>

10.2 Open Graph y redes sociales

Qué es Open Graph

Open Graph (og:) son metadatos que permiten controlar cómo se muestra el sitio al compartirse en redes sociales (Facebook, WhatsApp, etc.).

Ejemplo: Metadatos Open Graph completos

<script setup>
useSeoMeta({
  ogTitle: 'Mi entrada del blog',
  ogDescription: 'Resumen de la publicación',
  ogImage: 'https://mistiio.com/img/portada.jpg',
  ogUrl: 'https://mistiio.com/blog/mi-entrada',
  ogSiteName: 'Mi Sitio',
  ogLocale: 'es_ES',
  twitterCard: 'summary_large_image',
  twitterTitle: 'Mi entrada del blog',
  twitterImage: 'https://mistiio.com/img/portada.jpg'
})
</script>

Recomendaciones de imagen

PlataformaTamaño recomendado
Open Graph estándar1200 x 630 px
Twitter Card1200 x 675 px
Mínimo aceptable600 x 315 px
Usa el validador de Open Graph para comprobar cómo se muestra tu contenido al compartir el enlace.

10.3 Sitemap y robots.txt

Generar sitemap y robots de forma automática

El módulo @nuxtjs/sitemap y @nuxtjs/robots (o el paquete combinado @nuxtjs/seo) generan el sitemap.xml y el robots.txt automáticamente a partir de tus rutas.

Instalar el módulo de SEO

npm install @nuxtjs/seo
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['@nuxtjs/seo'],

  sitemap: {
    hostname: 'https://mistiio.com'
  },
  robots: {
    disallow: ['/privado/']
  }
})

Resultado esperado

/sitemap.xml   -> lista de todas las rutas públicas
/robots.txt    -> reglas para rastreadores de motores de búsqueda

Personalizar el sitemap

// nuxt.config.ts
export default defineNuxtConfig({
  sitemap: {
    hostname: 'https://mistiio.com',
    exclude: ['/admin/**'],
    defaults: {
      changefreq: 'weekly',
      priority: 0.8
    }
  }
})

10.4 build y generate para producción

Diferencias entre build y generate

ComandoResultado
npm run buildGenera una app de servidor (SSR) en .output/
npm run generateGenera archivos estáticos (SSG) en .output/public/

Compilar para el servidor

# Build SSR
npm run build

# El output queda en la carpeta .output/
# Incluye servidor + assets para desplegar en Node o serverless

Generar estático

# Build SSG
npm run generate

# Genera el HTML estático en .output/public/
# Ideal para desplegar en un hosting estático

Configurar el modo de pre-renderizado

// nuxt.config.ts
export default defineNuxtConfig({
  nitro: {
    prerender: {
      routes: ['/', '/acerca', '/contacto']
    }
  }
})
`npm run preview` te deja probar localmente la build de producción ya generada.

10.5 Desplegar en Vercel, Netlify o Node

Opciones de despliegue

Nuxt se puede desplegar en casi cualquier plataforma gracias a Nitro. Solo necesitas el preset adecuado.

Despliegue en Vercel

# Vercel detecta y configura Nuxt automáticamente
npm i -g vercel
vercel deploy
// nuxt.config.ts
export default defineNuxtConfig({
  nitro: {
    preset: 'vercel'
  }
})

Despliegue en Netlify

# Netlify también detecta Nuxt
netlify deploy
// nuxt.config.ts
export default defineNuxtConfig({
  nitro: {
    preset: 'netlify'
  }
})

Despliegue en un servidor Node

# Generar la build SSR
npm run build

# Iniciar el servidor de producción en Node
node .output/server/index.mjs

Despliegue estático con cualquier hosting

# Generar SSG y subir la carpeta public
npm run generate

# Subir .output/public a Netlify, GitHub Pages, etc.
PlataformaPreset
Vercelvercel
Netlifynetlify
Node.jsnode-server (por defecto)
Staticstatic (con generate)

10.6 Buenas prácticas de producción

Recomendaciones finales

  • Establece metadatos y SEO desde el inicio
  • Genera sitemap y robots.txt antes del lanzamiento
  • Optimiza imágenes con componentes y formatos modernos
  • Usa variables de entorno específicas de producción
  • Configura caché con routeRules para contenido estático
  • Realiza pruebas de rendimiento en la build de producción

Configuración de caché con routeRules

// nuxt.config.ts
export default defineNuxtConfig({
  routeRules: {
    '/': { prerender: true },
    '/blog/**': { isr: 60 },
    '/api/**': { proxy: '/api/**' },
    '/admin/**': { ssr: false }
  }
})

Variables de producción

# .env.production
NUXT_PUBLIC_API_URL=https://api.produccion.com
API_SECRETA=clave-segura-de-produccion

Resumen

**Lo que aprendiste en esta sección:** - Nuxt ofrece SEO nativo gracias a SSR y SSG - useSeoMeta y useHead controlan los metadatos de cada página - Open Graph define cómo se comparte el sitio en redes sociales - El módulo @nuxtjs/seo genera sitemap.xml y robots.txt - npm run build genera SSR y npm run generate genera estático - Despliegas en Vercel, Netlify o Node con el preset correcto - Las routeRules permiten cachear y controlar rutas en producción - Sigue las buenas prácticas para un lanzamiento sólido
