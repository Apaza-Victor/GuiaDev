3.1 File-based routing en pages

El sistema de rutas

Nuxt convierte cada archivo dentro de pages/ en una ruta de la aplicación. Esta convención se llama file-based routing y elimina la necesidad de configurar un enrutador manualmente.

Ejemplos de mapeo archivo-ruta

ArchivoRuta resultante
pages/index.vue/
pages/acerca.vue/acerca
pages/contacto/index.vue/contacto
pages/blog/novedades.vue/blog/novedades
pages/tienda/[id].vue/tienda/:id

Ejemplo: Página simple

<!-- pages/acerca.vue -->
<template>
  <div>
    <h1>Acerca de nosotros</h1>
    <p>Esta es la página de información.</p>
  </div>
</template>
La página index.vue siempre corresponde a la raíz (/) de tu aplicación.

3.2 Páginas dinámicas con parámetros

Rutas dinámicas

Cuando un archivo usa corchetes [...] en su nombre, se crea una ruta dinámica que captura un segmento de la URL como parámetro.

pages/blog/[slug].vue   ->  /blog/:slug
pages/productos/[id].vue ->  /productos/:id
pages/[[categoria]]/index.vue -> opcional

Acceder al parámetro

Se usa el composable useRoute() para obtener los parámetros de la ruta actual.

<!-- pages/productos/[id].vue -->
<template>
  <div>
    <h1>Producto {{ id }}</h1>
  </div>
</template>

<script setup>
const route = useRoute()
const id = computed(() => route.params.id)
</script>

Catch-all y rutas opcionales

ConvenciónComportamiento
[id].vueRequiere un segmento obligatorio
[[pagina]].vueSegmento opcional
[...slug].vueCatch-all, captura varios segmentos

3.3 Navegación con NuxtLink

El componente NuxtLink

<NuxtLink> es el componente de Nuxt para navegar entre páginas. Acepta una prop to con la ruta de destino y optimiza el prefetch de las páginas.

Ejemplo: Menú de navegación

<!-- app/components/NavBar.vue -->
<template>
  <nav>
    <NuxtLink to="/">Inicio</NuxtLink>
    <NuxtLink to="/acerca">Acerca</NuxtLink>
    <NuxtLink to="/productos">Productos</NuxtLink>
    <NuxtLink :to="`/productos/${id}`">Ver producto</NuxtLink>
  </nav>
</template>

<script setup>
const id = ref(5)
</script>

Ventajas de NuxtLink vs una etiqueta a

CaracterísticaDescripción
PrefetchCarga la página destino al pasar el ratón
Client-side navigationNo recarga completamente la página
Rutas internasDetecta automáticamente rutas internas
Active statePermite añadir clases cuando la ruta está activa

Ejemplo: Enlace con clase activa

<NuxtLink to="/acerca" active-class="activo" exact-active-class="exacto">
  Acerca
</NuxtLink>

3.4 Navegación programática

Qué es la navegación programática

A veces necesitas navegar desde JavaScript, por ejemplo al completar un formulario o tras una acción. Para eso se usa el composable useRouter().

Ejemplo: Redirigir tras envío

<template>
  <button @click="guardar">Guardar y volver</button>
</template>

<script setup>
const router = useRouter()

function guardar() {
  // guardar los datos...
  router.push('/productos')
}
</script>

Métodos útiles del router

  • router.push(ruta): navega a una nueva ruta (apila)
  • router.replace(ruta): navega sin añadir entrada al historial
  • router.back(): retrocede en el historial
  • router.forward(): avanza en el historial

Ejemplo: Navegar con parámetros de consulta

const router = useRouter()

router.push({
  path: '/busqueda',
  query: { termino: 'vue', pagina: 2 }
})
// Resultado: /busqueda?termino=vue&pagina=2

3.5 Uso de useRoute y parámetros de consulta

El composable useRoute

useRoute() devuelve el objeto de ruta actual con información como la URL, los parámetros y la consulta.

Ejemplo: Leer la query string

<!-- pages/busqueda.vue -->
<template>
  <p>Buscando: {{ termino }}</p>
</template>

<script setup>
const route = useRoute()

// /busqueda?termino=nuxt -> "nuxt"
const termino = computed(() => route.query.termino || '')
</script>

Propiedades útiles del objeto route

PropiedadDescripción
route.pathCamino de la ruta (/productos/5)
route.paramsParámetros dinámicos ({ id: '5' })
route.queryParámetros de consulta ({ termino: 'nuxt' })
route.fullPathRuta completa incluyendo query
route.hashFragmento de la URL (anclas)

3.6 Página 404 y manejo de errores

Página de error personalizada

Puedes crear un archivo app/error.vue para personalizar la página que se muestra ante errores (no encontrado, error del servidor, etc.).

Ejemplo: error.vue

<!-- app/error.vue -->
<template>
  <div class="error">
    <h1>{{ error.statusCode }}</h1>
    <p>{{ error.statusMessage || 'Algo salió mal' }}</p>
    <NuxtLink to="/">Volver al inicio</NuxtLink>
  </div>
</template>

<script setup>
const props = defineProps({ error: Object })
const handleError = () => clearError({ redirect: '/' })
</script>

Iniciar un error desde el código

<script setup>
const { data: producto } = await useFetch(`/api/productos/999`)

if (!producto.value) {
  throw createError({
    statusCode: 404,
    statusMessage: 'Producto no encontrado'
  })
}
</script>

Función clearError

El composable clearError limpia el error actual y, opcionalmente, redirige a otra página:

clearError({ redirect: '/productos' })

Resumen

**Lo que aprendiste en esta sección:** - El file-based routing convierte archivos de pages/ en rutas - Las rutas dinámicas usan corchetes como [id].vue - NuxtLink permite navegación eficiente entre páginas - useRouter() y uso programático controlan la navegación - useRoute() lee parámetros y query de la URL actual - Crea app/error.vue para personalizar los errores y el 404
