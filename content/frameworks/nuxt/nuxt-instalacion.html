2.1 Requisitos previos

Requisitos del sistema

Antes de instalar Nuxt asegúrate de tener instalado Node.js. Nuxt requiere una versión reciente de Node.js para funcionar correctamente.

RequisitoDetalle
Node.jsVersión 18 o superior (se recomienda la 20 LTS)
npm / yarn / pnpmGestor de paquetes incluido con Node.js
Editor de códigoVS Code con la extensión Volar (Vue)

Verificar Node.js instalado

# Verificar versión de Node.js
node --version
# v20.11.0

# Verificar npm
npm --version
# 10.2.4
Si Node.js no está instalado, descárgalo desde el sitio oficial de Node.js. Usar la versión LTS es lo más estable.

2.2 Crear un proyecto Nuxt

Crear con npx nuxi

Nuxt 3 ofrece el comando npx nuxi init para crear un proyecto nuevo de forma rápida e interactiva.

# Crear un nuevo proyecto llamado mi-app
npx nuxi init mi-app

# Entrar a la carpeta del proyecto
cd mi-app

# Instalar las dependencias
npm install

Alternativa con create-nuxt-app

También puedes usar la herramienta clásica create-nuxt-app, que ofrece un asistente con más opciones:

# Uso de la herramienta interactiva
npx create-nuxt-app mi-proyecto

# O bien dentro de una carpeta vacía
npx nuxi init

Opciones de configuración

  • Manager de paquetes: elige entre npm, yarn o pnpm
  • Lenguaje: TypeScript (recomendado) o JavaScript
  • Framework CSS: integra Tailwind, Bootstrap, etc.
  • Módulos: añade Pinia, Axios, ESLint, Prettier
  • Linter: configura ESLint y Prettier
`npx nuxi init` es el método oficial recomendado en la documentación actual de Nuxt.

2.3 Estructura de carpetas del proyecto

Estructura generada

mi-app/
├── app/
│   ├── components/      # Componentes con auto-import
│   ├── layouts/         # Layouts de la aplicación
│   ├── pages/           # Rutas basadas en archivos
│   └── app.vue          # Componente raíz
├── public/              # Archivos estáticos
├── .env                 # Variables de entorno (opcional)
├── nuxt.config.ts       # Configuración de Nuxt
├── package.json         # Dependencias y scripts
├── tsconfig.json        # Configuración de TypeScript
└── tsconfig.app.json    # Configuración de TS para la app

Carpetas principales

CarpetaPropósito
app/Contiene el código fuente de tu aplicación
app/pages/Define las rutas de la aplicación
app/components/Componentes reutilizables con auto-import
app/layouts/Estructura común de las páginas
public/Archivos servidos tal cual (favicon, imágenes)

Scripts disponibles

# Desarrollo con recarga automática
npm run dev

# Construcción para producción
npm run build

# Construcción estática (SSG)
npm run generate

# Previsualizar la build de producción
npm run preview

2.4 Configuración inicial (nuxt.config)

Archivo de configuración

El archivo nuxt.config.ts centraliza toda la configuración del proyecto: SSG, módulos, variables de entorno, CSS global y más.

Ejemplo: Configuración básica

// nuxt.config.ts
export default defineNuxtConfig({
  app: {
    head: {
      title: 'Mi sitio con Nuxt',
      meta: [
        { name: 'description', content: 'Una app creada con Nuxt 3' }
      ]
    }
  },
  css: ['~/assets/css/main.css'],
  modules: ['@nuxtjs/tailwindcss'],
  runtimeConfig: {
    public: {
      apiUrl: process.env.API_URL
    }
  }
})

Opciones de configuración más usadas

  • ssr: habilita o desactiva el renderizado en servidor
  • modules: lista de módulos de Nuxt a cargar
  • runtimeConfig: variables de entorno disponibles en la app
  • app.head: metadatos globales (title, meta)
  • css: hojas de estilo globales
  • nitro: configuración del servidor (carpeta de salida, preset)

2.5 Ejecutar el servidor de desarrollo

Iniciar el desarrollo

# Iniciar el servidor de desarrollo
npm run dev

# Salida esperada:
# VITE v5.x  ready in 500 ms
# ➜ Local:   http://localhost:3000/
# Nuxt 3.12 running at: http://localhost:3000

El servidor de desarrollo se ejecuta por defecto en el puerto 3000. Tiene recarga automática: al guardar un archivo, la página se actualiza al instante.

Cambiar el puerto

# Especificar un puerto distinto
npx nuxi dev --port 8080

# También puedes definir el puerto en el script:
# "dev": "nuxt dev --port 8080"

Probar la aplicación

  • Abre http://localhost:3000 en el navegador
  • Deberías ver la página de bienvenida de Nuxt
  • Edita app/app.vue y guarda para ver cambios en vivo
Si el puerto 3000 está ocupado por otro proceso, Nuxt te preguntará si deseas usar otro puerto automáticamente.

2.6 Verificar el proyecto con Nuxt DevTools

Qué son las Nuxt DevTools

Nuxt DevTools es un panel integrado en el navegador para inspeccionar tu aplicación: componentes, estado, rutas, módulos y más.

Cómo abrirlas

  • Con el servidor de desarrollo en marcha, haz clic en el botón de Nuxt en la esquina inferior
  • O navega a http://localhost:3000/_nuxt/

Funcionalidades principales

FunciónUtilidad
PagesVer las rutas generadas a partir de pages/
ComponentsInspeccionar los componentes y su estado
ImportsRevisar qué se auto-importa
PayloadVer los datos transferidos entre servidor y cliente
Nuxt ConfigExplorar la configuración resuelta del proyecto

Resumen

**Lo que aprendiste en esta sección:** - Nuxt requiere Node.js 18 o superior - Creas proyectos con `npx nuxi init` o `create-nuxt-app` - La estructura incluye app/, public/, nuxt.config.ts y más - nuxt.config.ts centraliza la configuración del proyecto - `npm run dev` inicia el servidor de desarrollo en el puerto 3000 - Nuxt DevTools ayudan a inspeccionar y depurar la aplicación
