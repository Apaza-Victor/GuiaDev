9.1 Estilos con scope

CSS aislado por componente

El bloque <style> de un componente Svelte aplica sus estilos de forma scoped: solo afectan a los elementos de ese componente y no se filtran a otros. Svelte añade una clase única a los elementos y reescribe los selectores durante la compilación.

Ejemplo: estilos de componente

<style>
  p {
    color: #ff3e00;
    font-weight: bold;
  }
</style>

<p>Este párrafo está estilizado</p>

Para estilar elementos internos de un componente hijo de forma puntual se usa la directiva :global(), que rompe el aislamiento.

---

9.2 Clases dinámicas

Aplicar clases según estado

Puedes asignar clases de forma condicional enlazando el atributo class con una expresión, o usando el atajo class:nombre que añade la clase cuando la variable es verdadera.

Ejemplo: clase condicional

<script>
  let activo = true;
</script>

<p class:activo>Elemento con clase dinámica</p>

Cuando activo es true, se añade la clase activo. También puedes enlazar con una expresión como class:rojo={esRojo()}.

9.3 Transiciones fade y fly

Animar entrada y salida

Svelte incluye transiciones integradas como fade, fly, scale y slide que se aplican cuando un elemento entra o sale del DOM. Se usan con la directiva transition: y se importan desde svelte/transition.

Ejemplo: fade y fly

<script>
  import { fade, fly } from 'svelte/transition';
  let visible = true;
</script>

{#if visible}
  <p transition:fade>Aparece y desaparece</p>
  <h1 transition:fly={{ y: 200, duration: 1000 }}>
    Vuela desde abajo
  </h1>
{/if}

<button on:click={() => visible = !visible}>Alternar</button>

---

9.4 Transiciones in y out

Distintas animaciones de entrada y salida

Puedes usar in: y out: para definir animaciones diferentes al entrar y al salir, o animate: para animar el cambio de posición cuando un elemento se mueve dentro de una lista.

Ejemplo: in y out distintos

<script>
  import { fly, fade } from 'svelte/transition';
  let visible = true;
</script>

{#if visible}
  <p in:fly={{ y: 100 }} out:fade>
    Entra volando y sale desvaneciéndose
  </p>
{/if}

---

9.5 Animaciones flip

Reordenar listas con elegancia

La animación flip (First Last Invert Play) mueve suavemente los elementos restantes cuando un elemento se añade, elimina o reordena en una lista. Se usa con la directiva animate: sobre cada elemento de la lista.

Ejemplo: reordenar lista

<script>
  import { flip } from 'svelte/animate';
  let letras = ['a', 'b', 'c'];

  function mover() {
    letras = [letras[2], letras[0], letras[1]];
  }
</script>

{#each letras as letra (letra)}
  <p animate:flip>{letra}</p>
{/each}

<button on:click={mover}>Reordenar</button>

---

9.6 Directivas de movimiento

Comparativa de directivas

DirectivaFunción
transition:Anima entrada y salida igual
in:Anima solo la entrada
out:Anima solo la salida
animate:Anima el cambio de posición en listas
class:Aplica clases de forma condicional
:global()Rompe el scope de los estilos

Combina estas directivas con bloques {#if} y {#each} para crear interfaces fluidas y dinámicas.

---

Resumen

**Lo que aprendiste en esta sección:** - Los estilos son scoped por componente por defecto - class: y :global() controlan el alcance de las clases - transition:fade y transition:fly animan entrada y salida - in: y out: definen animaciones distintas - animate:flip anima el reordenamiento de listas - Combina directivas con bloques de lógica para interfaces dinámicas
