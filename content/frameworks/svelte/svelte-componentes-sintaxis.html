3.1 Qué es un componente .svelte

Definición

Un componente en Svelte es un archivo con extensión .svelte que encapsula un fragmento reutilizable de interfaz junto con su lógica y sus estilos. Cada componente tiene tres bloques opcionales: <script>, template HTML y <style>.

Estructura de un componente

<script>
  // Lógica en JavaScript
  let titulo = 'Mi componente';
</script>

<!-- Template HTML -->
<h1>{titulo}</h1>
<p>Este es el contenido visible.</p>

<style>
  /* Estilos scoped del componente */
  h1 {
    color: #ff3e00;
  }
</style>

Idea clave

Cada componente es independiente y puede reutilizarse en otros componentes. Esto permite construir interfaces complejas a partir de piezas pequeñas y mantenibles.

---

3.2 El bloque <script>

Propósito

El bloque <script> contiene la lógica del componente: variables, funciones, importaciones y props. Solo se ejecuta una vez al crear una instancia del componente.

Cómo usarlo

<script>
  let nombre = 'Ana';
  let edad = 30;

  function saludar() {
    console.log(`Hola, soy ${nombre}`);
  }

  const frutas = ['manzana', 'pera', 'uva'];
</script>

<p>Nombre: {nombre}</p>
<p>Edad: {edad}</p>
<button on:click={saludar}>Saludar</button>

Reglas básicas

  • Puedes importar otros componentes y librerías
  • Las variables declaradas con let y const se pueden usar en el template
  • Las funciones se definen como funciones normales o flecha
  • Los datos se "renderizan" en el HTML usando {variable}

---

3.3 El bloque <style>

Estilos con alcance (scoped)

Los estilos definidos en un componente .svelte son scoped: solo afectan a ese componente. Svelte añade una clase única a cada elemento para garantizar que los estilos no se filtren a otros componentes.

Ejemplo de estilos scoped

<div class="tarjeta">
  <h2>Título de la tarjeta</h2>
  <p>Contenido interno.</p>
</div>

<style>
  .tarjeta {
    border: 1px solid #e0e0e0;
    border-radius: 8px;
    padding: 16px;
    max-width: 300px;
  }

  h2 {
    color: #ff3e00;
    margin: 0 0 8px 0;
  }

  p {
    color: #444;
    margin: 0;
  }
</style>
Aunque los estilos son scoped, los selectores de etiqueta como h2 solo afectan a las etiquetas de ese mismo componente, no a las de los componentes hijos importados.

---

3.4 Estructura del template

El HTML del componente

La parte central del archivo es el template: HTML regular enriquecido con la sintaxis de Svelte para interpolar datos, ejecutar lógica, manejar eventos y enlazar valores.

Interpolación de variables

<script>
  let usuario = {
    nombre: 'Carlos',
    rol: 'admin'
  };
  let precio = 12.5;
  let activo = true;
</script>

<p>Nombre: {usuario.nombre}</p>
<p>Rol: {usuario.rol}</p>
<p>Precio: {precio} €</p>
{#if activo}
  <p class="ok">Cuenta activa</p>
{:else}
  <p class="error">Cuenta inactiva</p>
{/if}

<style>
  .ok { color: green; }
  .error { color: red; }
</style>

Interpolar expresiones

<script>
  let base = 10;
  let cantidades = [3, 5].join(' y ');
</script>

<p>Doble: {base * 2}</p>
<p>Cantidades: {cantidades}</p>
<p>¿Mayor que 5? {base > 5 ? 'Sí' : 'No'}</p>

3.5 Renderizado de variables

Cómo mostrar datos

Cualquier valor definido en el <script> se puede mostrar en el template usando llaves { }. Svelte actualiza automáticamente el valor en pantalla cuando la variable cambia.

Ejemplo completo

<script>
  let primerNombre = 'María';
  let apellidos = 'López García';
  let ciudad = 'Madrid';
  let anioNacimiento = 1995;

  $: nombreCompleto = `${primerNombre} ${apellidos}`;
  $: edad = new Date().getFullYear() - anioNacimiento;
</script>

<h1>{nombreCompleto}</h1>
<p>Vive en {ciudad}</p>
<p>Edad aprox.: {edad} años</p>
<label>
  Cambia el nombre:
  <input bind:value={primerNombre} />
</label>

Casos especiales

  • {variable}: muestra el valor
  • {expresion}: evalúa una expresión JavaScript
  • {@html miHtml}: inyecta HTML crudo (útil pero peligroso con datos externos)
  • {variable ?? 'valor por defecto'}: maneja valores nulos
Ten cuidado con {@html ...}: inyecta HTML directamente sin escapar. Solo úsalo con contenido de confianza para evitar ataques XSS.

---

Resumen

**Lo que aprendiste en esta sección:** - Un componente Svelte es un archivo .svelte - Se estructura en <script>, template HTML y <style> - El bloque <script> guarda la lógica del componente - Los estilos son scoped y no afectan a otros componentes - El template es HTML enriquecido con sintaxis de Svelte - Las variables se muestran con llaves {variable} - {@html ...} inyecta HTML crudo y debe usarse con precaución
