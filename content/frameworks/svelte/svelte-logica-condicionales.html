6.1 Condicionales {#if} y {:else}

Renderizado condicional

En Svelte puedes renderizar contenido de forma condicional con el bloque {#if} y sus variantes {:else}, {:else if} y {:else}. Solo se añade al DOM el contenido que cumple la condición.

La estructura es parecida a un if de JavaScript, pero escrita dentro del template con la sintaxis de llaves de Svelte.

Ejemplo: bloque if/else

<script>
  let conectado = true;
</script>

{#if conectado}
  <p>Usuario conectado</p>
{:else}
  <p>Por favor, inicia sesión</p>
{/if}

---

6.2 Cadenas {:else if}

Múltiples condiciones

Puedes encadenar varias condiciones usando {:else if}, similar a un else if de JavaScript. Solo se evalúa la primera condición verdadera de la cadena.

Ejemplo: clasificación de notas

<script>
  let nota = 85;
</script>

{#if nota >= 90}
  <p>Sobresaliente</p>
{:else if nota >= 70}
  <p>Bien</p>
{:else if nota >= 50}
  <p>Aprobado</p>
{:else}
  <p>Reprobado</p>
{/if}

---

6.3 Bloques {#each} para listas

Iterar sobre arreglos

El bloque {#each} recorre un arreglo u objeto iterable y repite el contenido por cada elemento. Puedes acceder al índice con una variable adicional separada por coma.

Ejemplo: renderizar una lista

<script>
  let frutas = ['Manzana', 'Pera', 'Uva', 'Melón'];
</script>

<ul>
  {#each frutas as fruta, indice}
    <li>{indice + 1}. {fruta}</li>
  {/each}
</ul>

Combinar {#each} con la reactividad permite añadir o eliminar elementos de la lista y que la interfaz se actualice automáticamente.

---

6.4 Keyed each

Rendimiento con claves

Cuando la lista puede reordenarse o cambiar, conviene usar la forma keyed: {#each items as item (item.id)}. La clave entre paréntesis le indica a Svelte qué elemento es cada uno, para reutilizar el DOM y conservar el estado de cada elemento.

Sin clave, Svelte reutiliza los nodos por posición, lo que puede provocar errores al eliminar o reordenar elementos.

Ejemplo: lista keyed

<script>
  let tareas = [
    { id: 1, texto: 'Estudiar Svelte' },
    { id: 2, texto: 'Hacer ejercicios' },
    { id: 3, texto: 'Repasar la teoría' }
  ];
</script>

{#each tareas as tarea (tarea.id)}
  <p>{tarea.texto}</p>
{/each}

---

6.5 Bloques {#await} para promesas

Manejo de datos asíncronos

El bloque {#await} te permite renderizar el estado de una promesa directamente en el template: mientras carga, cuando se resuelve y cuando falla. No necesitas gestionar manualmente el estado de carga con variables.

Ejemplo: cargar datos de una API

<script>
  async function obtenerUsuarios() {
    const res = await fetch('/api/usuarios');
    return res.json();
  }
</script>

{#await obtenerUsuarios()}
  <p>Cargando usuarios...</p>
{:then usuarios}
  <ul>
    {#each usuarios as usuario}
      <li>{usuario.nombre}</li>
    {/each}
  </ul>
{:catch error}
  <p>Error: {error.message}</p>
{/await}

---

6.6 Matriz de bloques de lógica

Resumen de bloques de control

BloqueFunción
{#if}Renderizado condicional
{:else}Rama alternativa del if
{:else if}Nueva condición en la cadena
{#each}Iterar sobre listas y arreglos
{#each ... (key)}Iteración keyed para reordenar listas
{#await}Manejar promesas con estados

Cierra cada bloque con su contraparte invertida: {/if}, {/each} y {/await}.

---

Resumen

**Lo que aprendiste en esta sección:** - {#if} renderiza contenido de forma condicional - {:else} y {:else if} permiten cadenas de condiciones - {#each} recorre listas y accede a su índice - La forma keyed conserva el estado al reordenar elementos - {#await} maneja promesas con estados de carga, éxito y error - Todo bloque se cierra con su marca {/...}
