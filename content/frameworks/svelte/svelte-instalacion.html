2.1 Requisitos previos (Node.js)

¿Qué necesitas instalar?

Svelte se ejecuta sobre el ecosistema Node.js. Para empezar necesitas:

RequisitoDescripción
Node.js 18 o superiorRuntime de JavaScript necesario para Vite y los scripts de build
npmGestor de paquetes que viene incluido con Node.js
Editor de códigoVS Code con la extensión oficial Svelte para resaltado y autocompletado
TerminalSímbolo del sistema, PowerShell o cualquier shell moderna

Verificar la instalación

node --version
# v20.11.0 (o superior)

npm --version
# 10.2.4 (o superior)
Descarga Node.js desde la página oficial nodejs.org. Se recomienda usar la versión LTS (Long Term Support) para mayor estabilidad.

2.2 Crear proyecto con Vite

Comando de creación

Vite es el entorno de desarrollo que Svelte utiliza por defecto. Proporciona recarga en caliente (HMR) y un build optimizado.

npm create vite@latest mi-proyecto -- --template svelte
cd mi-proyecto
npm install
npm run dev

También puedes elegir la variante TypeScript si lo prefieres:

npm create vite@latest mi-proyecto -- --template svelte-ts

Respuesta esperada

Al ejecutar npm run dev, Vite levanta un servidor local (por defecto en http://localhost:5173) y muestra un mensaje como:

VITE v5.0.0  ready in 312 ms
-> Local:   http://localhost:5173
-> Network: use --host to expose

2.3 Crear proyecto con SvelteKit

Crear un proyecto SvelteKit

Si quieres una aplicación completa con routing, SSR y despliegue, usa el CLI oficial de SvelteKit llamado create-svelte:

npm create svelte@latest mi-app
cd mi-app
npm install
npm run dev

Opciones del asistente

El asistente te preguntará varias cosas. Responde lo siguiente según tu preferencia:

  • Project structure: "Skeleton project" (proyecto vacío) para empezar desde cero
  • Add type checking: TypeScript o JavaScript según prefieras
  • Add ESLint / Prettier: Herramientas de calidad de código (recomendado)
  • Playwright / Vitest: Testing opcional
Un proyecto Vite de Svelte es solo la capa de componentes. Un proyecto SvelteKit incluye además routing, SSR y adaptadores de despliegue. Para aplicaciones reales se recomienda SvelteKit.

2.4 Estructura de carpetas

Estructura de un proyecto Vite + Svelte

mi-proyecto/
|- index.html
|- package.json
|- vite.config.js
|- src/
|  |- main.js
|  |- App.svelte
|  |- lib/
|  |  |- Counter.svelte
|  |- vite-env.d.ts
|- static/

Estructura de un proyecto SvelteKit

mi-app/
|- package.json
|- svelte.config.js
|- vite.config.js
|- src/
|  |- app.html
|  |- lib/
|  |  |- components/
|  |  |- stores.js
|  |- routes/
|  |  |- +page.svelte
|  |  |- +layout.svelte
|- static/
|  |- favicon.png
|  |- robots.txt

Archivos clave

ArchivoPropósito
App.svelteComponente raíz de un proyecto Vite
main.jsPunto de entrada que monta la aplicación
routes/Define las rutas de SvelteKit con archivos +page.svelte
lib/Componentes, stores y utilidades reutilizables
static/Archivos estáticos (imágenes, fuentes) servidos tal cual

2.5 Ejecutar el servidor de desarrollo

Comandos principales

ComandoQué hace
npm run devLevanta el servidor de desarrollo con recarga en caliente
npm run buildCompila la aplicación para producción
npm run previewSirve la compilación de producción localmente
npm run checkRevisa tipos y sintaxis (si usas TypeScript o svelte-check)

Edita tu primer componente

Reemplaza el contenido de src/App.svelte por:

<script>
  let saludo = '¡Hola desde Svelte!';
</script>

<main>
  <h1>{saludo}</h1>
  <button on:click={() => saludo = 'Cambiaste el mensaje'}>
    Cambiar mensaje
  </button>
</main>
Con la recarga en caliente (HMR), guarda el archivo y tu navegador se actualizará automáticamente sin recargar la página completa.

Resumen

**Lo que aprendiste en esta sección:** - Necesitas Node.js 18+ con npm para trabajar con Svelte - `npm create vite@latest` crea un proyecto Svelte con Vite - `npm create svelte@latest` crea un proyecto completo de SvelteKit - La carpeta `src/` guarda componentes y código de la aplicación - `npm run dev` inicia el servidor de desarrollo con HMR - `App.svelte` (Vite) o `routes/` (SvelteKit) son el punto de partida
