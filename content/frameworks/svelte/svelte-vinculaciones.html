7.1 Enlace bidireccional con bind

Qué es el binding

Svelte permite la comunicación bidireccional entre el estado del componente y los elementos del DOM mediante la directiva bind:. Cuando el usuario modifica un formulario, la variable se actualiza automáticamente y viceversa.

No hace falta escuchar eventos manualmente ni leer valores con JavaScript: el binding se encarga de todo.

Ejemplo: enlazar un input

<script>
  let nombre = 'Ana';
</script>

<input type="text" bind:value={nombre} />
<p>Hola, {nombre}</p>

Al escribir en el input, el texto del párrafo se actualiza al instante.

7.2 bind:value y tipos de bind

Bindings más usados

DirectivaDescripción
bind:valueEnlaza el valor de inputs, textarea y select
bind:checkedEnlaza el estado de casillas de verificación
bind:groupAgrupa varios inputs de tipo radio o checkbox
bind:filesEnlaza los archivos seleccionados en un input file
bind:thisObtiene una referencia al elemento del DOM

Ejemplo: checkbox y grupo

<script>
  let acepto = false;
  let frutas = [];
</script>

<label>
  <input type="checkbox" bind:checked={acepto} />
  Acepto los términos
</label>

{#each ['Manzana', 'Pera'] as fruta}
  <label>
    <input type="checkbox" bind:group={frutas} value={fruta} />
    {fruta}
  </label>
{/each}

7.3 Tiendas writable

Estado global compartido

Los stores o tiendas permiten compartir estado entre componentes sin pasar props por cada nivel. Un store writable puede ser leído y modificado desde cualquier componente.

Se crean con writable(valorInicial) y ofrecen métodos como set, update y subscribe.

Ejemplo: crear una tienda

<script>
  import { writable } from 'svelte/store';

  export const contador = writable(0);
</script>

Este código se guarda normalmente en un archivo como stores.js para importarlo desde varios componentes.

---

7.4 Suscripción automática con $

Prefijo $

Dentro de un componente puedes acceder al valor de un store anteponiendo el símbolo $ al nombre del store. Svelte se encarga de suscribirse y desuscribirse automáticamente, sin necesidad de llamar a subscribe ni liberar recursos manualmente.

Ejemplo: leer y modificar un store

<script>
  import { contador } from './stores.js';

  function incrementar() {
    contador.update(n => n + 1);
  }
</script>

<p>Valor: {$contador}</p>
<button on:click={incrementar}>Sumar 1</button>

Usar $contador funciona de forma automática y reactiva en el template y en el script.

---

7.5 Tiendas readable y custom

Tiendas de solo lectura

Un store readable expone un valor que no se puede modificar desde fuera: ideal para datos de configuración, relojes o valores calculados en el servidor. Solo se actualiza internamente.

Ejemplo: reloj con readable

<script>
  import { readable } from 'svelte/store';

  export const hora = readable(new Date(), function start(set) {
    const intervalo = setInterval(() => {
      set(new Date());
    }, 1000);

    return function stop() {
      clearInterval(intervalo);
    };
  });
</script>

Las tiendas custom implementan manualmente el contrato subscribe, lo que permite añadir lógica propia antes de notificar a los suscriptores.

Resumen

**Lo que aprendiste en esta sección:** - bind: realiza la comunicación bidireccional con el DOM - bind:value enlaza inputs, select y textarea - Las tiendas writable permiten compartir estado global - El prefijo $ suscribe y desuscribe automáticamente - Las tiendas readable son de solo lectura - Las tiendas custom controlan el contrato de suscripción
