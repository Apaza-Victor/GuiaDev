1.1 Qué es Svelte

Definición

Svelte es un framework de JavaScript para construir interfaces de usuario, creado por Rich Harris. A diferencia de otros frameworks, Svelte trabaja como un compilador: en lugar de ejecutar su lógica en el navegador, convierte tus componentes en código JavaScript puro, eficiente y optimizado durante el build.

La extensión de archivo de un componente Svelte es .svelte, y su sintaxis combina HTML, CSS y JavaScript en un único archivo para cada componente.

Filosofía

La filosofía central de Svelte es "menos código, menos velocidad de ejecución". El framework traslada el trabajo que normalmente se hace en el navegador (reactividad, actualización del DOM) al momento de compilación, obteniendo bundles pequeños y un rendimiento excelente.

Ejemplo: componente básico

<script>
  let nombre = 'Mundo';
</script>

<h1>¡Hola {nombre}!</h1>

<style>
  h1 {
    color: #ff3e00;
    font-family: sans-serif;
  }
</style>

1.2 Compilador vs Virtual DOM

¿Qué diferencia a Svelte?

Frameworks como React y Vue utilizan el Virtual DOM: una representación en memoria del DOM real que se actualiza y después se difunde contra el DOM real en busca de cambios. Este proceso ocurre en tiempo de ejecución en el navegador.

Svelte, en cambio, compila los componentes en tiempo de build. Genera instrucciones imperativas directas que actualizan el DOM únicamente cuando el valor realmente cambió, sin difundir árboles virtuales en el navegador.

Comparativa

AspectoSvelte (Compilador)React (Virtual DOM)
Momento de trabajoEn tiempo de buildEn tiempo de ejecución
Tamaño del bundleMuy pequeñoMayor (incluye runtime)
Actualizaciones DOMDirectas y quirúrgicasDiffing del árbol virtual
RendimientoAlto en runtimeBueno pero con overhead
EstadoSin estado en runtimeRequiere runtime persistente

Ejemplo: qué genera el compilador

<script>
  let contador = 0;

  function incrementar() {
    contador += 1;
  }
</script>

<button on:click={incrementar}>
  Contador: {contador}
</button>

El compilador genera código imperativo que actualiza solo el nodo del texto del contador, sin reconstruir el resto del componente.

1.3 Ventajas de Svelte

Beneficios principales

VentajaDescripción
Bundle pequeñoMenos JavaScript enviado al navegador porque no hay runtime pesado
Curva de aprendizaje cortaLa sintaxis es HTML más JavaScript, muy cercana a lo que ya conoces
Reactividad sencillaBasta asignar una variable para actualizar la interfaz
CSS scoped por defectoLos estilos de cada componente no afectan a otros componentes
Transiciones y animacionesAnimaciones fluidas integradas sin librerías externas
AccesibilidadAvisos automáticos para atributos accesibles durante el build

Ejemplo: reactividad sin APIs complejas

<script>
  let mensaje = 'Hola Svelte';

  function cambiarMensaje() {
    mensaje = 'La reactividad es automática';
  }
</script>

<p>{mensaje}</p>
<button on:click={cambiarMensaje}>Cambiar mensaje</button>

1.4 Svelte vs SvelteKit vs React

Aclaración de conceptos

Svelte es el framework de componentes UI. SvelteKit es el framework de aplicación completo construido sobre Svelte: incluye routing, SSR, optimizaciones y despliegue. React es un ecosistema de librerías que suele combinarse con Next.js para algo comparable a SvelteKit.

Comparativa

AspectoSvelteSvelteKitReact + Next.js
RolFramework UI (compilador)Framework de aplicaciónLibrería UI + framework
RuntimeSin Virtual DOMSin Virtual DOMCon Virtual DOM
RoutingNo incluidoBasado en archivosBasado en carpetas
SSR / SSGNo integradoSí, nativoSí, nativo
BundleMuy pequeñoMuy pequeñoMayor
SintaxisHTML + JS + CSSSvelte + archivos de rutaJSX + hooks

Cuándo elegir cada uno

  • Svelte solo: Widgets, componentes aislados o aprendizaje
  • SvelteKit: Aplicaciones completas con rutas, SSR y despliegue
  • React + Next.js: Ecosistema enorme, herramientas maduras y mucho contenido

1.5 Características principales

Resumen de capacidades

CaracterísticaDescripción
Reactivity statementsDeclaraciones reactivas con $: que se recalculan automáticamente
PropsComunicación entre componentes con export let
StoresTareas globales de estado con suscripción automática mediante $
SlotsComposición de contenido reutilizable entre componentes
Lógica de plantillasBloques de control como {#if}, {#each} y {#await}
BindingsEnlace bidireccional de formularios con bind:value

Ejemplo: todo junto en un componente

<script>
  export let titulo = 'Inicio';
  let contador = 0;

  $: doble = contador * 2;
</script>

<h1>{titulo}</h1>
<p>Contador: {contador}</p>
<p>Doble: {doble}</p>
<button on:click={() => contador += 1}>Sumar 1</button>

Resumen

**Lo que aprendiste en esta sección:** - Svelte es un framework UI que funciona como compilador - No usa Virtual DOM: genera código imperativo eficiente - Produce bundles pequeños y actualizaciones DOM quirúrgicas - Svelte es la capa de componentes y SvelteKit el framework de aplicación - Su sintaxis es HTML + JavaScript + CSS en un solo archivo - La reactividad es automática con simples asignaciones de variables
