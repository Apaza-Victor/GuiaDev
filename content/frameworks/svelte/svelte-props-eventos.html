5.1 Props con export let

Definición

Las props son los datos que un componente padre pasa a un componente hijo. En Svelte se declaran con la palabra clave export delante de let.


<script>
  export let titulo;
  export let descripcion = 'Sin descripción'; // valor por defecto
  export let precio = 0;
</script>

<article class="tarjeta">
  <h3>{titulo}</h3>
  <p>{descripcion}</p>
  <p>Precio: {precio} €</p>
</article>

Valores por defecto

Al declarar export let nombre = 'valor' defines un valor predeterminado que se usa cuando el padre no envía esa prop. De esta forma el componente es más robusto.

---

5.2 Pasar datos entre componentes

Consumo de componentes

El componente padre importa el hijo y le pasa las props como atributos. Puedes pasar literales, variables o expresiones:


<script>
  import Tarjeta from './Tarjeta.svelte';

  let producto = {
    titulo: 'Svelte desde cero',
    descripcion: 'Curso de Svelte para principiantes',
    precio: 19.99
  };
</script>

<Tarjeta
  titulo={producto.titulo}
  descripcion={producto.descripcion}
  precio={producto.precio}
/>

<!-- Con variables individuales -->
<Tarjeta titulo="Guía HTML" descripcion="Base de la web" precio={9.99} />

Atajo para actualizar props

Si el nombre del atributo coincide con la prop, puedes usar la sintaxis breve:

<script>
  import Tarjeta from './Tarjeta.svelte';

  let titulo = 'Astro';
  let descripcion = 'Framework de contenido';
</script>

<!-- Equivale a titulo={titulo} y descripcion={descripcion} -->
<Tarjeta {titulo} {descripcion} />
También puedes pasar todos los props de un objeto con el operador de propagación: <Tarjeta {...producto} />.

---

5.3 Eventos con on:click

Escuchar eventos

Svelte usa el prefijo on: seguido del nombre del evento DOM para escuchar cada evento nativo: on:click, on:input, on:keydown, on:submit, entre otros.

Ejemplo con el objeto del evento

<script>
  let x = 0;
  let y = 0;

  function manejarMover(evento) {
    x = evento.clientX;
    y = evento.clientY;
  }

  function manejarClick(evento) {
    alert(`Clic en (${x}, ${y})`);
  }
</script>

<button on:click={manejarClick} on:mousemove={manejarMover}>
  Mueve y haz clic sobre este botón
</button>

<p>Posición: {x}, {y}</p>

Modificadores de eventos


<button on:click|once={funcion} >Clic único</button>

<!-- detiene la propagación y previene el comportamiento por defecto -->
<a href="/" on:click|preventDefault|stopPropagation={funcion}>Enlace</a>

<!-- ejecuta solo si tienes la tecla Enter pulsada -->
<input on:keydown|enter={funcion} />

5.4 Event forwarding

Reenviar eventos del hijo al padre

Cuando un componente hijo escucha un evento, los componentes padre no lo reciben automáticamente. Para "subir" el evento, el hijo debe reemitirlo con createEventDispatcher o usar la sintaxis de reenvío.

Con createEventDispatcher


<script>
  import { createEventDispatcher } from 'svelte';

  const dispatch = createEventDispatcher();

  export let nombre = 'Hijo';

  function avisarPadre() {
    dispatch('mensaje', { texto: `Hola, soy ${nombre}` });
  }
</script>

<button on:click={avisarPadre}>Enviar mensaje al padre</button>

<script>
  import Hijo from './Hijo.svelte';

  function recibirMensaje(evento) {
    console.log('Mensaje del hijo:', evento.detail);
  }
</script>

<Hijo on:mensaje={recibirMensaje} />

Sintaxis de reenvío directo

Si solo quieres exponer un evento DOM hacia el padre, puedes escribirlo sin pasar una función:


<script>
  export let texto = 'Pulsar';
</script>

<button on:click>{texto}</button>

El padre escucha on:click normalmente y recibe el evento original.

5.5 Cadenas de eventos

Orquestar eventos entre varios componentes

La combinación de props (hacia abajo) y eventos (hacia arriba) permite construir flujos de datos claros y predecibles entre componentes:


<script>
  import Boton from './Boton.svelte';

  let contador = 0;

  function incrementar() {
    contador += 1;
  }

  function reiniciar() {
    contador = 0;
  }
</script>

<h1>Contador: {contador}</h1>
<div class="acciones">
  <Boton texto="Incrementar" on:click={incrementar} />
  <Boton texto="Reiniciar" on:click={reiniciar} />
</div>

<script>
  export let texto = 'Pulsar';
  export let deshabilitado = false;
</script>

<button disabled={deshabilitado} on:click>{texto}</button>

<style>
  button {
    padding: 8px 14px;
    margin-right: 8px;
    cursor: pointer;
    border: 1px solid #ccc;
    border-radius: 6px;
  }
</style>
Recuerda el flujo de datos en Svelte: los datos bajan por props (padre a hijo) y los eventos suben mediante dispatcher (hijo a padre).

---

Resumen

**Lo que aprendiste en esta sección:** - Las props se declaran con `export let` y llegan del componente padre - Puedes definir valores por defecto para cada prop - Se pasan como atributos, con variables o con la sintaxis breve `{prop}` - Los eventos se escuchan con `on:click` y otros prefijos `on:` - Existen modificadores como `once`, `preventDefault` y `stopPropagation` - El hijo puede reenviar eventos con `createEventDispatcher` - Los eventos se encadenan para crear flujos de datos entre componentes
