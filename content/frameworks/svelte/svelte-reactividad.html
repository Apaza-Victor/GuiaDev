4.1 Reactividad con let

Reactividad por asignación

En Svelte, la reactividad es automática. Cuando una variable declarada con let cambia su valor mediante una asignación, el componente se actualiza por sí solo sin llamar a ninguna API especial.

Ejemplo: contador

<script>
  let contador = 0;

  function incrementar() {
    contador = contador + 1;
  }

  function decrementar() {
    contador -= 1;
  }
</script>

<h1>Contador: {contador}</h1>
<button on:click={incrementar}>+1</button>
<button on:click={decrementar}>-1</button>

¿Qué dispara la reactividad?

  • Asignación a una variable: contador = 5
  • Actualización que reasigna la variable: contador += 1
  • No se usa el Virtual DOM: el compilador genera el código que actualiza solo lo necesario

---

4.2 Statements reactivos con $:

Declaraciones reactivas

El prefijo $: convierte una declaración en reactiva: se re-ejecuta automáticamente cuando cualquiera de las variables que usa cambia. Es una de las señas de identidad de Svelte.

Ejemplo básico

<script>
  let precio = 100;
  let impuesto = 0.21;

  $: total = precio * (1 + impuesto);
  $: mensaje = total > 100 ? 'Precio alto' : 'Precio razonable';
</script>

<p>Precio: {precio} €</p>
<input type="range" bind:value={precio} min="0" max="500" />
<p>Total con impuesto: {total.toFixed(2)} €</p>
<p>{mensaje}</p>

Statements con bloques

<script>
  let contador = 0;

  $: if (contador >= 10) {
    console.log('¡Llegaste a la meta!');
  }
</script>

<button on:click={() => contador += 1}>Sumar ({contador})</button>
Las declaraciones reactivas solo se activan cuando los valores que dependen directamente de ellas cambian. Se ejecutan antes de que se actualice el DOM.

---

4.3 Actualización de arrays y objetos

La asignación debe dispararse

Por razones de rendimiento, Svelte solo detecta cambios cuando la variable se reasigna. Por eso, métodos como push(), pop() o splice() que mutan el array original no activan la reactividad.

Forma correcta con arrays

<script>
  let lista = ['manzana', 'pera'];

  function agregar(fruta) {
    lista = [...lista, fruta]; // reasignar
  }

  function eliminar(fruta) {
    lista = lista.filter((item) => item !== fruta);
  }
</script>

<ul>
  {#each lista as fruta}
    <li>{fruta}</li>
  {/each}
</ul>
<button on:click={() => agregar('uva')}>Agregar uva</button>
<button on:click={() => eliminar('pera')}>Quitar pera</button>

Forma correcta con objetos

<script>
  let usuario = { nombre: 'Ana', edad: 28 };

  function cumplirAnios() {
    usuario = { ...usuario, edad: usuario.edad + 1 };
  }

  function cambiarNombre(nombre) {
    usuario = { ...usuario, nombre };
  }
</script>

<p>{usuario.nombre} tiene {usuario.edad} años</p>
<button on:click={cumplirAnios}>Cumplir años</button>
<button on:click={() => cambiarNombre('María')}>Cambiar nombre</button>
En Svelte puedes mutar y reasignar en el mismo lugar: por ejemplo usuario.edad = usuario.edad + 1 también activa la reactividad porque Svelte compila la actualización del objeto. La regla de oro es "reasignar para garantizar la detección".

---

4.4 Reactividad avanzada y múltiples asignaciones

Múltiples asignaciones

Svelte agrupa las asignaciones del mismo tick en una sola actualización del DOM. Es seguro actualizar varias variables a la vez en un mismo controlador de eventos.

<script>
  let ancho = 0;
  let alto = 0;

  function reiniciar() {
    ancho = 0;
    alto = 0;
  }
</script>

<p>Ancho: {ancho} - Alto: {alto}</p>
<input type="range" bind:value={ancho} min="0" max="100" />
<input type="range" bind:value={alto} min="0" max="100" />
<button on:click={reiniciar}>Reiniciar</button>

Reactividad entre componentes y stores

  • Las props (export let) son reactivas dentro del componente hijo
  • Los stores se suscriben automáticamente con el prefijo $
  • Las declaraciones $: pueden depender de otras declaraciones
<script>
  let primera = 'Hola';
  let segunda = 'Mundo';

  $: saludo = `${primera} ${segunda}`;
  $: enMayusculas = saludo.toUpperCase();
</script>

<p>{enMayusculas}</p>

4.5 Ejemplo práctico completo

Calculadora de propinas

Este ejemplo junta asignaciones, statements reactivos y bindings:

<script>
  let cuenta = 50;
  let porcentaje = 10;

  $: propina = cuenta * (porcentaje / 100);
  $: total = cuenta + propina;
  $: formateado = (valor) => valor.toFixed(2);
</script>

<h2>Calculadora de propinas</h2>

<label>
  Total de la cuenta:
  <input type="number" bind:value={cuenta} />
</label>

<label>
  Propina ({porcentaje}%):
  <input type="range" bind:value={porcentaje} min="0" max="30" />
</label>

<p>Propina: {formateado(propina)} €</p>
<p>Total a pagar: {formateado(total)} €</p>

Práctica sugerida

  • Agrega un botón para reiniciar los valores
  • Divide el total entre el número de personas
  • Muestra la propina en verde si el porcentaje es mayor o igual a 15

Resumen

**Lo que aprendiste en esta sección:** - La reactividad en Svelte es automática por asignación - Los statements `$:` recalculan valores automáticamente - Los arrays y objetos deben reasignarse para garantizar la detección de cambios - Múltiples asignaciones se agrupan en una sola actualización del DOM - La reactividad funciona también con props y stores - Los bindings permiten sincronizar inputs con variables
