3.1 El decorador @app.route

Qué es una ruta

Una ruta es una URL que la aplicación reconoce, y la vista es la función Python que responde a esa URL. El decorador `@app.route()` conecta ambas cosas.

Sintaxis básica

from flask import Flask

app = Flask(__name__)


@app.route("/")
def inicio():
    return "Página de inicio"


@app.route("/acerca")
def acerca():
    return "Acerca de nosotros"

Varias rutas con la misma vista

@app.route("/hola")
@app.route("/saludo")
def saludo():
    return "Hola a todos"

Nombres descriptivos de rutas

  • / raíz
  • /usuarios listado de usuarios
  • /productos listado de productos
  • /contacto formulario de contacto
Las rutas deben ser legibles y descriptivas, ya que forman parte de la URL pública de tu aplicación.

---

3.2 Rutas con métodos (GET/POST)

Métodos HTTP

Cada petición HTTP lleva un método que indica la acción a realizar. Por defecto, `@app.route` solo acepta GET.

Especificar métodos

from flask import Flask, request

app = Flask(__name__)


@app.route("/usuarios", methods=["GET", "POST"])
def usuarios():
    if request.method == "POST":
        return "Creando un nuevo usuario"
    return "Listando usuarios"

Métodos más comunes

MétodoAcción
GETObtener datos (lectura)
POSTCrear recursos (envío de datos)
PUTActualizar un recurso completo
PATCHActualizar parcialmente
DELETEEliminar un recurso

Ruta con método único

@app.route("/eliminar", methods=["DELETE"])
def eliminar():
    return "Recurso eliminado"

3.3 Parámetros en la URL

Parámetros dinámicos

Puedes capturar partes variables de la URL usando la sintaxis `<variable>`:

from flask import Flask

app = Flask(__name__)


@app.route("/usuario/<nombre>")
def perfil(nombre):
    return f"Perfil de {nombre}"

Múltiples parámetros

@app.route("/usuario/<nombre>/posts")
def posts_usuario(nombre):
    return f"Posts de {nombre}"

Parámetros con tipo

# <int:> restringe el valor a números enteros
@app.route("/producto/<int:producto_id>")
def producto(producto_id):
    return f"Producto número {producto_id}"


# <float:> acepta números decimales
@app.route("/precio/<float:precio>")
def precio(precio):
    return f"El precio es {precio}"
`/usuario/123` devuelve "Perfil de 123" (string), mientras que `/producto/123` pasa `producto_id` como entero gracias al convertidor `<int:`.

---

3.4 Convertidores de tipo

Qué es un convertidor

Los convertidores indican a Flask qué tipo de dato debe interpretar una parte de la URL y la convierten automáticamente.

Convertidores disponibles

ConvertidorTipoEjemplo de URL
stringTexto (por defecto)/usuario/<string:nombre>
intEntero/producto/<int:id>
floatDecimal/nota/<float:valor>
pathRuta (acepta barras)/archivos/<path:ruta>
uuidIdentificador UUID/tarea/<uuid:id>

Ejemplos completos

from flask import Flask

app = Flask(__name__)


@app.route("/archivos/<path:ruta>")
def archivo(ruta):
    return f"Buscando archivo: {ruta}"


@app.route("/tarea/<uuid:tarea_id>")
def tarea(tarea_id):
    return f"Tarea con UUID: {tarea_id}"
Usa el convertidor `path` cuando necesites capturar rutas con varias carpetas, por ejemplo `/archivos/documentos/manual.pdf`.

---

3.5 Redirecciones (redirect)

Qué es una redirección

Una redirección envía al usuario desde una URL a otra distinta. Flask usa la función redirect() y la constante url_for() para construir las URLs.

Redirección básica

from flask import Flask, redirect, url_for

app = Flask(__name__)


@app.route("/")
def inicio():
    return "Página de inicio"


@app.route("/antigua")
def antigua():
    return redirect(url_for("inicio"))

Redirección con url_for

# url_for genera la URL a partir del NOMBRE de la función
@app.route("/nuevo")
def nuevo():
    return redirect(url_for("perfil", nombre="Ana"))

Redirección con código de estado

@app.route("/movido")
def movido():
    # 301 = movido permanentemente
    return redirect(url_for("inicio"), code=301)
Usar `url_for` en lugar de escribir URLs a mano evita errores cuando el nombre de una función o ruta cambia.

---

3.6 Manejo de errores y abortar

La función abort

abort() finaliza la petición inmediatamente devolviendo un código de error HTTP:

from flask import Flask, abort

app = Flask(__name__)

usuarios = {1: "Ana", 2: "Carlos"}


@app.route("/usuario/<int:usuario_id>")
def obtener_usuario(usuario_id):
    if usuario_id not in usuarios:
        abort(404)  # Recurso no encontrado
    return usuarios[usuario_id]


@app.route("/solo-admin")
def solo_admin():
    # Simulación: sin permisos, devuelve 403 (prohibido)
    abort(403)

Códigos de error comunes

CódigoSignificado
400Petición incorrecta
401No autenticado
403Prohibido (sin permisos)
404No encontrado
500Error interno del servidor

Personalizar páginas de error

from flask import Flask

app = Flask(__name__)


@app.errorhandler(404)
def no_encontrado(error):
    return "Página no encontrada", 404


@app.errorhandler(500)
def error_interno(error):
    return "Ocurrió un error interno", 500
Los manejadores de error (`@app.errorhandler`) permiten mostrar páginas amigables en lugar de mensajes técnicos.

---

Resumen

**Lo que aprendiste en esta sección:** - `@app.route()` conecta una URL con una función de vista - Puedes especificar métodos HTTP como GET, POST, PUT y DELETE - Las URLs dinámicas capturan valores con `<variable>` - Los convertidores (`int`, `float`, `path`, `uuid`) tipan los parámetros - `redirect()` junto a `url_for()` permiten redirigir entre rutas - `abort()` y `@app.errorhandler` gestionan errores HTTP
