1.1 Qué es Flask

Definición

Flask es un microframework web escrito en Python que permite crear aplicaciones web de forma rápida y sencilla. Su filosofía es ser minimalista: incluye lo esencial (enrutamiento, plantillas, peticiones) y deja el resto en manos de extensiones que tú decides agregar.

Origen del nombre

El nombre Flask es un juego de palabras con Bottle, otro microframework de Python. Flask fue creado por Armin Ronacher en 2010 y está construido sobre las librerías Werkzeug (para el manejo de peticiones HTTP) y Jinja2 (para las plantillas).

Características principales

CaracterísticaDescripción
MicroframeworkSolo incluye lo esencial; las funciones extra se agregan con extensiones
Fácil de aprenderCurva de aprendizaje muy corta para principiantes
FlexibleTú decides el ORM, la validación y las herramientas que usarás
ExtensibleGran ecosistema de extensiones oficiales y de la comunidad
Basado en WerkzeugManejo HTTP robusto y probado en producción
Plantillas Jinja2Sistema de plantillas potente y fácil de usar

Ejemplo: la aplicación más pequeña

from flask import Flask

app = Flask(__name__)

@app.route("/")
def inicio():
    return "¡Hola, Flask!"


if __name__ == "__main__":
    app.run()

1.2 Microframework vs full-stack

Qué significa "micro"

Que Flask sea un microframework no significa que no pueda hacer sitios grandes. Significa que el núcleo se mantiene pequeño y enfocado, y las funcionalidades adicionales se incorporan mediante extensiones según las necesites.

Comparativa

CaracterísticaMicroframework (Flask)Full-stack (Django)
NúcleoPequeño y minimalistaGrande y completo
ORMPor extensión (Flask-SQLAlchemy)Incluido (Django ORM)
AdminPor extensiónIncluido
AutenticaciónPor extensiónIncluida
ControlTotal (tú eliges)Sigue sus convenciones
Curva de aprendizajeBajaAlta
Si quieres máxima libertad para elegir cada pieza de tu proyecto, un microframework como Flask es ideal. Si prefieres que el framework traiga todo ya incluido, elige uno full-stack como Django.

1.3 Por qué elegir Flask

Razones para elegir Flask

  • Sencillez: Puedes levantar un servidor web en pocas líneas de código
  • Ligero: Sin dependencias innecesarias, fácil de instalar y mantener
  • Flexibilidad: Tú decides cómo estructurar el proyecto
  • Curva de aprendizaje corta: Ideal para aprender desarrollo web en Python
  • Gran comunidad: Documentación excelente y muchísimos tutoriales
  • Multiusos: Sirve tanto para prototipos pequeños como para APIs y sitios completos

Cuándo elegir Flask

SituaciónFlask es adecuado
Prototipos y MVPs rápidos Sí
APIs REST simples Sí
Microservicios Sí
Aplicaciones empresariales gigantesPosible con buena organización
Aplicaciones con admin y auth ya resueltasMejor Django
Flask no te obliga a seguir una estructura determinada: tú tienes el control total sobre cada parte del proyecto.

1.4 Diferencias con Django y FastAPI

Comparativa de frameworks de Python

TipadoOpcionalOpcionalObligatorio

Cuándo usar cada uno

  • Flask: Prototipos, sitios simples, APIs ligeras, aprender fundamentos
  • Django: Aplicaciones completas con admin, ORM y auth integrados
  • FastAPI: APIs modernas de alto rendimiento con validación automática

Ejemplo: Mismo endpoint en los tres

# Flask
from flask import Flask, jsonify
app = Flask(__name__)

@app.route("/saludo/<nombre>")
def saludo(nombre):
    return jsonify({"mensaje": f"Hola, {nombre}"})

1.5 Extensiones de Flask

Qué son las extensiones

Las extensiones son paquetes que añaden funcionalidades a Flask sin modificar su núcleo. Se instalan con pip y se registran en la aplicación. Así Flask crece según las necesidades del proyecto.

Extensiones más usadas

ExtensiónFunción
Flask-SQLAlchemyIntegración del ORM SQLAlchemy
Flask-WTFFormularios y protección CSRF
Flask-LoginAutenticación y gestión de sesiones
Flask-MigrateMigraciones de base de datos
Flask-RESTfulConstruir APIs REST
Flask-CorsHabilitar CORS

Ejemplo: Instalar y registrar una extensión

# En la terminal: pip install flask-sqlalchemy

from flask import Flask
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
app.config["SQLALCHEMY_DATABASE_URI"] = "sqlite:///datos.db"
db = SQLAlchemy(app)
Las extensiones de Flask suelen seguir el patrón `Flask-Nombre` y se registran en la aplicación pasándole la instancia `app`.

1.6 Casos de uso

Quién usa Flask

  • Pinterest: Usa Flask en parte de su infraestructura
  • Netflix: Herramientas internas y flujo de datos
  • Uber: Prototipos y servicios internos
  • LinkedIn: Aplicaciones internas de administración
  • Reddit: Proyectos internos

Casos de uso típicos

  • Prototipos y MVPs: Validar una idea rápidamente
  • Aplicaciones CRUD: Gestión de usuarios, productos, tareas
  • APIs REST: Backends para aplicaciones móviles o frontends
  • Paneles de administración: Dashboards internos
  • Microservicios: Servicios pequeños e independientes
  • Educación: Aprender desarrollo web con Python

Ejemplo: Aplicación de notas

from flask import Flask, request

app = Flask(__name__)

notas = []

@app.route("/notas", methods=["GET", "POST"])
def manejar_notas():
    if request.method == "POST":
        nota = request.form.get("texto")
        notas.append(nota)
        return f"Nota añadida: {nota}"
    return f"Notas actuales: {notas}"


if __name__ == "__main__":
    app.run(debug=True)

Resumen

**Lo que aprendiste en esta sección:** - Flask es un microframework de Python minimalista y flexible - Incluye lo esencial y deja el resto en manos de extensiones - A diferencia de Django, no trae baterías incluidas, pero te da control total - A diferencia de FastAPI, no genera documentación automática ni es async por defecto - Su ecosistema de extensiones permite escalar según las necesidades - Es ideal para prototipos, CRUD, APIs y paneles de administración
