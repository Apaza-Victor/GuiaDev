7.1 Flask-SQLAlchemy

Qué es Flask-SQLAlchemy

Flask-SQLAlchemy es la extensión oficial recomendada que integra el ORM SQLAlchemy con Flask. Permite trabajar con bases de datos relacionales usando objetos Python en lugar de escribir SQL a mano.

Instalación

pip install flask-sqlalchemy

Configuración básica

from flask import Flask
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
app.config["SQLALCHEMY_DATABASE_URI"] = "sqlite:///datos.db"
app.config["SQLALCHEMY_TRACK_MODIFICATIONS"] = False

db = SQLAlchemy(app)

Tipos de bases de datos soportadas

Base de datosURI de conexión
SQLitesqlite:///archivo.db
PostgreSQLpostgresql://usuario:clave@host/nombre
MySQLmysql://usuario:clave@host/nombre
SQLite es perfecto para desarrollo y pruebas porque no requiere servidor: guarda todo en un archivo local.

7.2 Definir modelos

Qué es un modelo

Un modelo es una clase Python que representa una tabla de la base de datos. Cada atributo de la clase es una columna.

Definir un modelo Usuario

from flask_sqlalchemy import SQLAlchemy

db = SQLAlchemy()


class Usuario(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    nombre = db.Column(db.String(100), nullable=False)
    email = db.Column(db.String(120), unique=True, nullable=False)
    edad = db.Column(db.Integer, default=18)

    def __repr__(self):
        return f"<Usuario {self.nombre}>"

Tipos de columna más comunes

TipoDescripción
IntegerNúmero entero
String(n)Texto de longitud limitada
TextTexto largo
FloatNúmero decimal
BooleanVerdadero o falso
DateTimeFecha y hora

Opciones de columna

  • primary_key=True: Clave primaria
  • nullable=False: Campo obligatorio
  • unique=True: Valor único
  • default=valor: Valor por defecto

7.3 Operaciones CRUD

Crear y guardar registros

# Crear una instancia
nuevo = Usuario(nombre="Ana", email="ana@correo.com", edad=25)

# Añadir a la sesión y guardar
db.session.add(nuevo)
db.session.commit()

Consultar registros

# Todos los usuarios
todos = Usuario.query.all()

# Primero que coincida
primer_ana = Usuario.query.filter_by(nombre="Ana").first()

# Filtrar por ID
usuario = Usuario.query.get(1)

# Filtrar con condiciones
mayores = Usuario.query.filter(Usuario.edad >= 18).all()

# Ordenar
ordenados = Usuario.query.order_by(Usuario.nombre).all()

Actualizar registros

usuario = Usuario.query.get(1)
usuario.edad = 26
db.session.commit()

Eliminar registros

usuario = Usuario.query.get(1)
db.session.delete(usuario)
db.session.commit()
Si usas `.filter()` con objetos, recuerda que el valor devuelto es una consulta; debes finalizarla con `.all()`, `.first()` o `.get()`.

7.4 Relaciones entre tablas

Relación uno a muchos

Un usuario puede tener muchos posts. Se usa ForeignKey y relationship:

class Usuario(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    nombre = db.Column(db.String(100))
    posts = db.relationship("Post", backref="autor", lazy=True)


class Post(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    titulo = db.Column(db.String(200))
    usuario_id = db.Column(db.Integer, db.ForeignKey("usuario.id"))

Usar la relación

# Acceder a los posts de un usuario
usuario = Usuario.query.get(1)
for post in usuario.posts:
    print(post.titulo)

# Acceder al autor de un post
post = Post.query.get(1)
print(post.autor.nombre)

Tipos de relaciones

RelaciónDefinición típica
Uno a muchosForeignKey + relationship
Muchos a muchosTabla de asociación intermedia
Uno a unoForeignKey con unique=True
La tabla intermedia para relaciones muchos a muchos se define con `db.Table()` y luego se referencia en `relationship()`.

7.5 Migraciones con Flask-Migrate

Qué son las migraciones

Las migraciones permiten versionar los cambios en el esquema de la base de datos. Con Flask-Migrate puedes crear, modificar y eliminar tablas sin perder datos.

Instalación y configuración

pip install flask-migrate
from flask import Flask
from flask_sqlalchemy import SQLAlchemy
from flask_migrate import Migrate

app = Flask(__name__)
app.config["SQLALCHEMY_DATABASE_URI"] = "sqlite:///datos.db"

db = SQLAlchemy(app)
migrate = Migrate(app, db)

Comandos de migración (terminal)

# Inicializar la carpeta de migraciones (una vez)
flask db init

# Generar una migración a partir de los modelos
flask db migrate -m "crear tabla usuarios"

# Aplicar la migración a la base de datos
flask db upgrade

Flujo de trabajo

  1. Modificas tus modelos en Python
  2. Ejecutas flask db migrate para generar el script
  3. Ejecutas flask db upgrade para aplicarlo
Flask-Migrate detecta los cambios en tus modelos y genera scripts SQL de forma automática. Es imprescindible en proyectos que crecen.

7.6 Ejemplo práctico completo

Aplicación completa con base de datos

from flask import Flask, request, render_template, redirect, url_for
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
app.config["SQLALCHEMY_DATABASE_URI"] = "sqlite:///tareas.db"

db = SQLAlchemy(app)


class Tarea(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    titulo = db.Column(db.String(200), nullable=False)
    completada = db.Column(db.Boolean, default=False)


@app.route("/", methods=["GET", "POST"])
def index():
    if request.method == "POST":
        nuevo = Tarea(titulo=request.form.get("titulo"))
        db.session.add(nuevo)
        db.session.commit()
        return redirect(url_for("index"))
    tareas = Tarea.query.all()
    return render_template("index.html", tareas=tareas)


@app.route("/completar/<int:tarea_id>")
def completar(tarea_id):
    tarea = Tarea.query.get(tarea_id)
    tarea.completada = not tarea.completada
    db.session.commit()
    return redirect(url_for("index"))


if __name__ == "__main__":
    with app.app_context():
        db.create_all()
    app.run(debug=True)
`db.create_all()` crea las tablas a partir de los modelos. Para proyectos con cambios frecuentes en el esquema, usa migraciones.

Resumen

**Lo que aprendiste en esta sección:** - Flask-SQLAlchemy integra el ORM SQLAlchemy con Flask - Los modelos son clases Python que representan tablas - Las operaciones CRUD usan `db.session` y `db.session.commit()` - Las relaciones se crean con `ForeignKey` y `relationship` - Flask-Migrate versiona los cambios de esquema con migraciones - `db.create_all()` crea tablas rápidamente en desarrollo
