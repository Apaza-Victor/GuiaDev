2.1 Entorno virtual

Qué es un entorno virtual

Un entorno virtual es una carpeta aislada en la que se instalan las dependencias de tu proyecto sin afectar al resto del sistema. De esta forma, cada proyecto tiene sus propias versiones de paquetes.

Crear un entorno virtual

# Windows (PowerShell)
python -m venv venv
# macOS / Linux
python3 -m venv venv

Activar el entorno virtual

# Windows (PowerShell)
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate

Desactivar el entorno

deactivate
No olvides añadir la carpeta `venv` a tu archivo `.gitignore` para no subir las dependencias al repositorio.

---

2.2 Instalar Flask

Instalación con pip

Con el entorno virtual activado, instala Flask usando pip:

pip install flask

Verificar la instalación

pip show flask
python -c "import flask; print(flask.__version__)"

Instalar una versión específica

pip install flask==3.0.0

Dependencias instaladas junto a Flask

PaqueteFunción
WerkzeugServidor WSGI y utilidades HTTP
Jinja2Sistema de plantillas
clickInterfaz de línea de comandos
itsdangerousFirmado de cookies y sesiones
Al instalar Flask, pip también instala sus dependencias automáticamente, así que no tienes que hacer nada más para empezar.

2.3 Crear el primer proyecto

Crea la estructura básica

Empieza por crear una carpeta para tu proyecto y un archivo principal de Python:

miproyecto/
├── app.py

Código de la aplicación mínima

from flask import Flask

app = Flask(__name__)


@app.route("/")
def inicio():
    return "¡Hola, Mundo!"


if __name__ == "__main__":
    app.run()

Explicación del código

  • Flask(__name__): Crea la aplicación; `__name__` ayuda a Flask a encontrar recursos
  • @app.route("/"): Asocia una URL a una función
  • def inicio(): La función que responde en la raíz
  • app.run(): Levanta el servidor de desarrollo

---

2.4 Ejecutar el servidor

Ejecutar la aplicación

Con el entorno activado y dentro de la carpeta del proyecto, ejecuta:

python app.py

Salida esperada

 * Running on http://127.0.0.1:5000

Ahora abre `http://127.0.0.1:5000` en tu navegador: verás el mensaje "¡Hola, Mundo!".

Usar el comando flask run

También puedes usar el comando integrado de Flask:

# Importante: define la variable FLASK_APP
set FLASK_APP=app.py     # Windows
export FLASK_APP=app     # macOS / Linux

flask run

Cambiar el puerto y la IP

app.run(host="0.0.0.0", port=8080)
El valor `0.0.0.0` hace que el servidor sea accesible desde otras máquinas de la red, no solo desde tu equipo.

2.5 Modo debug

Qué es el modo debug

El modo debug es una herramienta de desarrollo que ofrece dos ventajas:

  • Recarga automática: El servidor se reinicia solo al guardar cambios
  • Depurador interactivo: Muestra errores detallados en el navegador

Activar el modo debug

from flask import Flask

app = Flask(__name__)


@app.route("/")
def inicio():
    return "¡Hola, Mundo!"


if __name__ == "__main__":
    app.run(debug=True)

Activar desde variables de entorno

# Windows
set FLASK_DEBUG=1
flask run
# macOS / Linux
export FLASK_DEBUG=1
flask run
Nunca actives el modo debug en producción: expone información sensible y el depurador interactivo puede ejecutar código arbitrario.

2.6 Estructura mínima de un proyecto

Estructura recomendada al empezar

miproyecto/
├── app.py              # Aplicación principal
├── templates/          # Plantillas HTML (Jinja2)
├── static/             # CSS, JS e imágenes
├── requirements.txt    # Dependencias del proyecto
└── venv/               # Entorno virtual (no se sube a git)

requirements.txt

Guarda las dependencias congeladas para poder reproducir el entorno:

pip freeze > requirements.txt

Contenido típico de requirements.txt

flask==3.0.0
Werkzeug==3.0.1
Jinja2==3.1.2
En otra máquina, basta con ejecutar `pip install -r requirements.txt` para instalar todas las dependencias a la vez.

---

Resumen

**Lo que aprendiste en esta sección:** - Un entorno virtual aísla las dependencias de cada proyecto - Flask se instala con `pip install flask` y trae Werkzeug y Jinja2 - Una aplicación mínima necesita crear `Flask(__name__)` y definir rutas - El servidor se ejecuta con `python app.py` o `flask run` - El modo debug activa recarga automática y un depurador interactivo - Una estructura mínima incluye `app.py`, `templates/`, `static/` y `requirements.txt`
