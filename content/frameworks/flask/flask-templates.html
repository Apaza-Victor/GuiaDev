4.1 render_template

Qué es render_template

render_template() carga un archivo HTML desde la carpeta templates/ y lo devuelve como respuesta. Es la forma recomendada de generar contenido HTML dinámico.

Estructura de la carpeta templates

miproyecto/
├── app.py
└── templates/
    └── inicio.html

Uso básico

from flask import Flask, render_template

app = Flask(__name__)


@app.route("/")
def inicio():
    return render_template("inicio.html")


@app.route("/acerca")
def acerca():
    return render_template("acerca.html")
Flask busca las plantillas automáticamente en la carpeta `templates/` que esté junto al archivo de la aplicación.

4.2 Sintaxis de Jinja2

Las dos formas de expresiones

Jinja2 usa dos tipos de marcado dentro de las plantillas:

  • {{ variable }}: Muestra el valor de una variable
  • {% bloque %}: Ejecuta lógica (condiciones, bucles, herencia)

Ejemplo de variable

<p>Hola, {{ nombre }}</p>

Ejemplo de condición

{% if usuario %}
  <p>Bienvenido, {{ usuario.nombre }}</p>
{% else %}
  <p>Inicia sesión</p>
{% endif %}

Ejemplo de bucle

<ul>
{% for producto in productos %}
  <li>{{ producto.nombre }} - {{ producto.precio }}</li>
{% endfor %}
</ul>

4.3 Enviar datos a la plantilla

Pasar variables

Puedes pasar datos desde la vista a la plantilla con argumentos extra en render_template():

from flask import Flask, render_template

app = Flask(__name__)


@app.route("/perfil/<nombre>")
def perfil(nombre):
    return render_template("perfil.html", nombre=nombre, edad=25)

Plantilla que recibe esos datos

<h1>Perfil de {{ nombre }}</h1>
<p>Edad: {{ edad }}</p>

Pasar una lista

@app.route("/productos")
def listar_productos():
    productos = ["Laptop", "Mouse", "Teclado"]
    return render_template("productos.html", productos=productos)

Pasar un diccionario

@app.route("/usuario")
def usuario():
    datos = {"nombre": "Ana", "email": "ana@correo.com"}
    return render_template("usuario.html", datos=datos)

Plantilla que recibe un diccionario

<p>{{ datos.nombre }} - {{ datos.email }}</p>
<p>{{ datos["nombre"] }} - {{ datos["email"] }}</p>
En Jinja2 puedes acceder a los campos de un diccionario con punto (`datos.nombre`) o con corchetes (`datos["nombre"]`).

4.4 Herencia con extends y block

Qué es la herencia de plantillas

La herencia permite definir un layout base (estructura del HTML) y que las demás plantillas lo extiendan, rellenando solo las partes que cambian.

Plantilla base: base.html

<!DOCTYPE html>
<html>
<head>
    <title>{% block titulo %}Mi Sitio{% endblock %}</title>
</head>
<body>
    <header>Cabecera común</header>
    <main>
        {% block contenido %}{% endblock %}
    </main>
    <footer>Pie de página común</footer>
</body>
</html>

Plantilla hija: inicio.html

{% extends "base.html" %}

{% block titulo %}Inicio</title>
{% endblock %}

{% block contenido %}
    <h1>Bienvenido a mi sitio</h1>
{% endblock %}

Ventajas de la herencia

  • Evitas repetir la estructura HTML en cada página
  • Al cambiar el layout, todas las páginas se actualizan
  • Los bloques permiten personalizar solo lo necesario
Cada plantilla hija comienza con `{% extends "base.html" %}` y define únicamente los bloques que necesita cambiar.

4.5 Filtros y url_for en plantillas

Qué son los filtros

Los filtros transforman el valor de una variable dentro de la plantilla. Se aplican con el símbolo | (pipe).

Filtros más usados

FiltroFunciónEjemplo
upperEn mayúsculas{{ nombre|upper }}
lowerEn minúsculas{{ nombre|lower }}
capitalizePrimera letra en mayúscula{{ nombre|capitalize }}
lengthLongitud de una lista{{ lista|length }}
defaultValor por defecto{{ edad|default(18) }}
joinUnir lista con separador{{ tags|join(", ") }}

url_for en plantillas

<a href="{{ url_for('inicio') }}">Inicio</a>
<a href="{{ url_for('perfil', nombre='Ana') }}">Ver perfil de Ana</a>
<link rel="stylesheet" href="{{ url_for('static', filename='css/estilos.css') }}">
Usa siempre `url_for()` para generar enlaces en las plantillas; así los enlaces se mantienen correctos aunque cambien las rutas.

4.6 Ejemplo práctico completo

Vista principal

from flask import Flask, render_template

app = Flask(__name__)

productos = [
    {"nombre": "Laptop", "precio": 999, "stock": 10},
    {"nombre": "Mouse", "precio": 25, "stock": 0},
    {"nombre": "Teclado", "precio": 40, "stock": 3},
]


@app.route("/")
def inicio():
    return render_template("index.html", productos=productos)

Plantilla index.html

{% extends "base.html" %}

{% block contenido %}
  <h1>Lista de productos</h1>
  <table>
    <thead>
      <tr><th>Nombre</th><th>Precio</th><th>Estado</th></tr>
    </thead>
    <tbody>
    {% for p in productos %}
      <tr>
        <td>{{ p.nombre }}</td>
        <td>{{ p.precio }}</td>
        <td>
          {% if p.stock > 0 %}
            Disponible
          {% else %}
            Agotado
          {% endif %}
        </td>
      </tr>
    {% endfor %}
    </tbody>
  </table>
{% endblock %}
Combina `extends`, `block`, bucles y condiciones para construir páginas dinámicas sin repetir el diseño.

Resumen

**Lo que aprendiste en esta sección:** - `render_template()` renderiza archivos HTML desde la carpeta `templates/` - Jinja2 usa `{{ }}` para variables y `{% %}` para lógica - Puedes enviar variables, listas y diccionarios a las plantillas - `extends` y `block` permiten heredar de un layout base - Los filtros transforman valores y `url_for` genera enlaces seguros - Con bucles y condiciones creas contenido dinámico completo
