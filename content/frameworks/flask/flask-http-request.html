5.1 El objeto request

Qué es el objeto request

El objeto request de Flask contiene toda la información de la petición HTTP entrante: método, cabeceras, datos del formulario, argumentos de la URL, JSON, cookies y más.

Método de la petición

from flask import Flask, request

app = Flask(__name__)


@app.route("/info", methods=["GET", "POST"])
def info():
    return f"Se usó el método: {request.method}"

Partes principales del request

AtributoContenido
request.methodMétodo HTTP (GET, POST, etc.)
request.argsParámetros de la query string
request.formDatos de un formulario (POST)
request.jsonDatos enviados en formato JSON
request.filesArchivos subidos
request.headersCabeceras de la petición
request.cookiesCookies del cliente
Para usar `request` debes importarlo: `from flask import request`.

5.2 request.form

Qué es request.form

request.form contiene los datos enviados mediante un formulario HTML con método POST. Cada campo se accede por su atributo name.

Formulario HTML

<form method="POST" action="/registro">
    <input type="text" name="nombre">
    <input type="email" name="email">
    <button type="submit">Registrar</button>
</form>

Recibir los datos en Flask

from flask import Flask, request

app = Flask(__name__)


@app.route("/registro", methods=["POST"])
def registro():
    nombre = request.form.get("nombre")
    email = request.form.get("email")
    return f"Registro: {nombre} - {email}"

Diferencias entre get y notación directa

  • request.form["nombre"]: Lanza un error si el campo no existe
  • request.form.get("nombre"): Devuelve None si el campo no existe
  • request.form.get("nombre", "Anónimo"): Devuelve un valor por defecto
Usa `.get()` siempre que un campo pueda faltar, para evitar errores que detengan la aplicación.

5.3 request.args

Qué es request.args

request.args contiene los parámetros de consulta (query string) que viajan en la URL después del signo ?.

Ejemplo de URL con parámetros

# URL: /buscar?q=laptop&orden=precio

Leer los parámetros en Flask

from flask import Flask, request

app = Flask(__name__)


@app.route("/buscar")
def buscar():
    query = request.args.get("q", "")
    orden = request.args.get("orden", "relevancia")
    return f"Buscando: {query} - Orden: {orden}"

Parámetros repetidos

# URL: /filtrar?a=1&a=2&a=3
@app.route("/filtrar")
def filtrar():
    valores = request.args.getlist("a")
    return f"Valores: {valores}"
`request.args` siempre es mejor accederlo con `.get()` y un valor por defecto, porque el parámetro puede venir o no en la URL.

5.4 request.json

Qué es request.json

request.json contiene los datos que el cliente envía en el cuerpo de la petición con formato JSON, muy habitual en APIs.

Cliente que envía JSON

// Ejemplo con fetch desde JavaScript
fetch("/api/usuario", {
    method: "POST",
    headers: {"Content-Type": "application/json"},
    body: JSON.stringify({nombre: "Ana", edad: 25})
})

Recibir JSON en Flask

from flask import Flask, request, jsonify

app = Flask(__name__)


@app.route("/api/usuario", methods=["POST"])
def crear_usuario():
    datos = request.json
    nombre = datos.get("nombre")
    edad = datos.get("edad")
    return jsonify({"recibido": True, "nombre": nombre, "edad": edad})

Verificar si hay JSON

@app.route("/api/cliente", methods=["POST"])
def recibir_cliente():
    if request.is_json:
        return jsonify(request.json)
    return "El contenido no era JSON", 400
Recuerda que el cliente debe enviar la cabecera `Content-Type: application/json` para que `request.json` funcione correctamente.

5.5 Manejo de GET y POST

Combinar ambos métodos en una ruta

Una vista puede comportarse de forma distinta según el método HTTP recibido:

from flask import Flask, request

app = Flask(__name__)

tareas = []


@app.route("/tareas", methods=["GET", "POST"])
def manejar_tareas():
    if request.method == "POST":
        nueva = request.form.get("tarea")
        tareas.append(nueva)
        return f"Tarea añadida: {nueva}"

    return f"Tareas: {tareas}"

Separar por método

@app.route("/mensajes", methods=["GET"])
def listar_mensajes():
    return "Mostrar mensajes"


@app.route("/mensajes", methods=["POST"])
def crear_mensaje():
    return "Crear mensaje"

Redirección tras un POST (PRG)

from flask import Flask, request, redirect, url_for

app = Flask(__name__)


@app.route("/crear", methods=["POST"])
def crear():
    # Procesar los datos y luego redirigir
    return redirect(url_for("exito"))


@app.route("/exito")
def exito():
    return "Registro creado correctamente"
El patrón POST/Redirect/GET evita reenviar el formulario al actualizar la página.

5.6 Mensajes flash

Qué son los mensajes flash

Los mensajes flash permiten mostrar avisos temporales (éxito, error, aviso) al usuario. Se guardan en la sesión y solo se muestran una vez.

Crear mensajes con flash()

from flask import Flask, flash, redirect, render_template, url_for

app = Flask(__name__)
app.secret_key = "clave_secreta_para_sesiones"  # Necesaria para flash


@app.route("/login", methods=["POST"])
def login():
    flash("Iniciaste sesión correctamente", "exito")
    return redirect(url_for("inicio"))


@app.route("/")
def inicio():
    return render_template("inicio.html")

Mostrar los mensajes en la plantilla

{% with mensajes = get_flashed_messages(with_categories=true) %}
  {% if mensajes %}
    <ul>
    {% for categoria, mensaje in mensajes %}
      <li class="{{ categoria }}">{{ mensaje }}</li>
    {% endfor %}
    </ul>
  {% endif %}
{% endwith %}
Debes definir `app.secret_key` para que los mensajes flash y las sesiones funcionen correctamente.

Resumen

**Lo que aprendiste en esta sección:** - El objeto `request` contiene todos los datos de la petición HTTP - `request.form` lee datos de formularios POST - `request.args` lee parámetros de la URL (query string) - `request.json` accede al cuerpo JSON de una petición - Puedes combinar GET y POST en una misma ruta según `request.method` - Los mensajes flash muestran avisos temporales usando la sesión
