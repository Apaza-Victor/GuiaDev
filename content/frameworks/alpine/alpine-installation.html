Incluir Alpine.js por CDN

Alpine.js se diseñó para añadir interactividad a HTML existente sin build ni tooling. La forma más directa es el CDN:

<!DOCTYPE html>
<html lang="es">
<head>
  <!-- Diferir es OBLIGATORIO: Alpine debe leer el HTML ya renderizado -->
  <script defer src="https://cdn.jsdelivr.net/npm/alpinejs@3.x.x/dist/cdn.min.js"></script>
</head>
<body>
  <div x-data="{ abierto: false }">
    <button @click="abierto = !abierto">Alternar</button>
    <p x-show="abierto" x-transition>¡Hola Alpine!</p>
  </div>
</body>
</html>

Eso es todo: sin npm, sin bundler, sin pasos de build. El atributo defer no es opcional — sin él, Alpine se ejecuta antes de que el DOM exista y no inicializa nada.

Instalación con npm y bundler

En proyectos con Vite, Laravel Mix, Webpack o similares, instala como dependencia e importa explícitamente:

npm install alpinejs
// app.js (punto de entrada)
import Alpine from 'alpinejs';

window.Alpine = Alpine;   // requerido para plugins y debug desde consola
Alpine.start();
  • Asignar window.Alpine permite que los plugins oficiales (intersect, persist, collapse, focus) y tu consola accedan a él.
  • Llama Alpine.start() después de registrar tus componentes y directivas personalizadas.
  • Versión fija en producción: alpinejs@3.14.1 mejor que @3.x.x del CDN.

Tu primer componente con x-data

Todo en Alpine gira alrededor de x-data: define el estado y el alcance de un componente directamente en el HTML:

<!-- Contador minimo -->
<div x-data="{ contador: 0 }">
  <button @click="contador++">+</button>
  <span x-text="contador"></span>
</div>

<!-- Estado extraido a una funcion reutilizable -->
<script>
function dropdown() {
  return {
    abierto: false,
    alternar() { this.abierto = !this.abierto }
  }
}
</script>

<div x-data="dropdown()" @click.outside="abierto = false">
  <button @click="alternar()">Menu</button>
  <ul x-show="abierto" x-cloak>
    <li><a href="#">Perfil</a></li>
  </ul>
</div>

Directivas esenciales para arrancar

DirectivaFunción
x-dataDeclara estado reactivo del componente
x-text / x-htmlEnlaza texto / HTML al elemento
x-show / x-ifVisibilidad (display) / existencia real en el DOM
x-modelEnlace bidireccional en inputs
@click, @submitEscucha de eventos (atajo de x-on)
x-initCódigo que corre al inicializar el componente
x-cloakOculta contenido hasta que Alpine esté listo (usar con CSS)
 
/* Imprescindible junto a x-cloak */
[x-cloak] { display: none !important; }

Regla de adopción: si tu página empieza a necesitar más de tres o cuatro componentes Alpine con lógica compartida compleja, probablemente ya necesitas Vue/Livewire/Inertia. Alpine brilla en dropdowns, tabs, modales y toggles — no en SPAs.

Ejercicio propuesto: toma un HTML estático tuyo con un menú móvil oculto por JavaScript tradicional y reescríbelo íntegramente con Alpine (x-data + x-show + x-cloak). Compara líneas de JS antes/después.
