6.1 Qué es una directiva

Definición

Una directiva es una clase TypeScript decorada que permite extender el comportamiento del DOM: modificar el aspecto de un elemento, cambiar su estructura o añadirle nuevos comportamientos.

En el template, una directiva se identifica porque se usa como un atributo. Ejemplos muy conocidos: *ngIf, *ngFor, ngClass y ngStyle.

Qué diferencian a las directivas de los componentes

ComponenteDirectiva
Tiene template propioNo tiene template propio
Se usa como etiqueta (<app-x>)Se usa como atributo de un elemento
Controla una vista completaAñade comportamiento o modifica la vista existente

Ejemplo de sintaxis en template

<p *ngIf="mostrar">Este párrafo es condicional</p>
<li *ngFor="let tarea of tareas">{{ tarea }}</li>

6.2 Tipos de directivas

Clasificación principal

TipoQué haceEjemplos
EstructuralesModifican el DOM: añaden, eliminan o reemplazan elementos*ngIf, *ngFor, *ngSwitch
De atributoCambian la apariencia o el comportamiento de un elemento existentengClass, ngStyle, ngModel
ComponentesDirectivas con template (vistas completas)Los creados con @Component

Diferencia clave

  • Estructurales: suelen llevar un asterisco (*) delante, que es azúcar sintáctico de Angular. Afectan a la estructura del documento.
  • De atributo: se escriben sin asterisco y afectan al elemento donde se aplican.

Ejemplos de uso

<!-- Estructural: añade/elimina el elemento -->
<div *ngIf="permitido">Contenido protegido</div>

<!-- De atributo: modifica el elemento -->
<div [ngClass]="{'activo': seleccionado}">Elemento</div>

6.3 Directiva *ngIf

Definición

*ngIf es una directiva estructural que incluye o elimina el elemento del DOM según el valor de una condición.

Sintaxis básica

<div *ngIf="usuarioLogueado">
  Bienvenido, {{ usuario.nombre }}
</div>

Con bloque "else"

<div *ngIf="usuarioLogueado; else noLogueado">
  Bienvenido, {{ usuario.nombre }}
</div>

<ng-template #noLogueado>
  <p>Por favor, inicia sesión.</p>
</ng-template>

Con bloque "then" y "else"

<div *ngIf="tieneDatos; then datos; else vacio"></div>

<ng-template #datos>
  <ul><li *ngFor="let item of items">{{ item }}</li></ul>
</ng-template>

<ng-template #vacio>
  <p>No hay datos que mostrar.</p>
</ng-template>

Ejemplo con condición combinada

export class LoginComponent {
  autenticado: boolean = false;
  rol: string = 'admin';
}
<p *ngIf="autenticado && rol === 'admin'">
  Panel de administración disponible
</p>
`*ngIf` elimina el elemento del DOM, a diferencia de `hidden` (que solo lo oculta con CSS). Esto también destruye los componentes hijos y libera recursos.

6.4 Directiva *ngFor

Definición

*ngFor es una directiva estructural que repite un elemento por cada elemento de una colección (array o Observable).

Sintaxis básica

export class TareasComponent {
  tareas: string[] = ['Estudiar', 'Codear', 'Desplegar'];
}
<ul>
  <li *ngFor="let tarea of tareas">{{ tarea }}</li>
</ul>

Índice, primero y último

<ol>
  <li *ngFor="let tarea of tareas; let i = index; let primero = first; let ultimo = last">
    {{ i + 1 }}. {{ tarea }} <span *ngIf="primero">(primera)</span><span *ngIf="ultimo">(última)</span>
  </li>
</ol>

Iterar sobre un array de objetos

export class ProductosComponent {
  productos = [
    { id: 1, nombre: 'Teclado', precio: 45 },
    { id: 2, nombre: 'Monitor', precio: 250 },
    { id: 3, nombre: 'Mouse', precio: 20 }
  ];
}
<table>
  <thead><tr><th>Nombre</th><th>Precio</th></tr></thead>
  <tbody>
    <tr *ngFor="let p of productos">
      <td>{{ p.nombre }}</td>
      <td>${{ p.precio }}</td>
    </tr>
  </tbody>
</table>
Evita usar `let p of productos` con objetos que mutan con frecuencia sin una referencia estable; si quieres, añade `trackBy` para que Angular solo repinte lo que cambia y mejore el rendimiento.

6.5 ngClass y ngStyle

ngClass: clases condicionales

ngClass permite añadir o quitar clases CSS de forma condicional o combinada.

<div [ngClass]="{'activo': estaActivo, 'peligro': tieneError}">
  Estado del sistema
</div>

ngClass con métodos

export class AlertaComponent {
  nivel: string = 'error';

  clasesAlerta(): any {
    switch (this.nivel) {
      case 'ok': return { 'alert-success': true };
      case 'error': return { 'alert-danger': true };
      default: return {};
    }
  }
}
<p [ngClass]="clasesAlerta()">Mensaje de alerta</p>

ngStyle: estilos inline condicionales

<div [ngStyle]="{'color': peligro ? 'red' : 'green', 'font-weight': negrita ? 'bold' : 'normal'}">
  Mensaje importante
</div>

Comparativa

DirectivaQué modificaCuándo usarla
ngClassAtributo classGestos por diseño; mantiene estilos en la hoja CSS
ngStyleEstilos inlineValores dinámicos (position, colores calculados)
Prefiere `ngClass` sobre `ngStyle` siempre que puedas: mantener la lógica de estilos en CSS separa presentación y comportamiento, y facilita el mantenimiento.

6.6 Directivas propias (concepto)

Definición

Angular permite crear directivas personalizadas con el decorador @Directive, tanto de atributo (comportamiento) como estructurales. Se usan para encapsular lógica repetitiva de UI.

Ejemplo: directiva de atributo que resalta

import { Directive, ElementRef, HostListener, Input } from '@angular/core';

@Directive({
  selector: '[appResaltar]'
})
export class ResaltarDirective {
  @Input() color = 'yellow';

  constructor(private el: ElementRef) {}

  @HostListener('mouseenter') entrar() {
    this.el.nativeElement.style.backgroundColor = this.color;
  }

  @HostListener('mouseleave') salir() {
    this.el.nativeElement.style.backgroundColor = 'transparent';
  }
}

Uso en el template

<p appResaltar color="cyan">Pasa el ratón por encima de mí</p>

Cómo declararla

@NgModule({
  declarations: [ResaltarDirective],
  exports: [ResaltarDirective]
})
export class SharedModule {}
En Angular moderno las directivas pueden marcarse como `standalone: true` y usarse sin pertenecer a un NgModule, importándolas directamente desde el componente.

---

Resumen

**Lo que aprendiste en esta sección:** - Las directivas extienden el comportamiento y la estructura del DOM - Hay tres tipos: estructurales, de atributo y componentes - *ngIf muestra u oculta elementos según una condición (con then/else) - *ngFor repite elementos iterando sobre colecciones (con index, first, last) - ngClass y ngStyle modifican clases y estilos de forma condicional - Puedes crear directivas propias con @Directive y @HostListener
