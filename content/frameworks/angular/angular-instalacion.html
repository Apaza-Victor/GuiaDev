2.1 Requisitos: Node.js y npm

Requisitos mínimos

Para trabajar con Angular necesitas tener instalado Node.js (con su gestor de paquetes npm). Angular CLI se distribuye como un paquete de npm.

HerramientaVersión recomendadaRol en el proyecto
Node.jsLTS (última versión estable)Ejecuta Angular CLI y el servidor de desarrollo
npmIncluido con Node.jsInstala y gestiona las dependencias
EditorVS Code (recomendado)Escribir y depurar el código

Verificar la instalación

# Comprobar la versión de Node.js
node --version

# Comprobar la versión de npm
npm --version

Instalar Node.js

  1. Descargar el instalador LTS desde nodejs.org
  2. Ejecutar el instalador y seguir los pasos
  3. Verificar con node --version en la terminal
Usa siempre la versión LTS de Node.js. Las versiones de desarrollo (no LTS) pueden causar incompatibilidades con Angular CLI.

---

2.2 Instalación de Angular CLI

Instalación global

Angular CLI se instala de forma global con npm usando el indicador -g:

# Instalar la última versión estable de forma global
npm install -g @angular/cli

# Verificar la instalación
ng version

Alternativa: ejecución puntual con npx

Si no quieres instalarlo globalmente, puedes ejecutar Angular CLI sin instalarlo con npx:

# Usar la CLI sin instalación global
npx @angular/cli new mi-app

Comandos de comprobación

ComandoDescripción
ng versionMuestra la versión de Angular, la CLI y Node
ng helpLista todos los comandos disponibles
ng configPermite leer o modificar la configuración global
Si quieres actualizar Angular CLI más adelante, ejecuta de nuevo npm install -g @angular/cli y se instalará la versión más reciente.

2.3 Creación de un nuevo proyecto (ng new)

El comando ng new

El comando ng new nombre-del-proyecto crea una carpeta nueva con todo el esqueleto de una aplicación Angular:

# Crear un proyecto llamado mi-app
ng new mi-app

# Angular CLI preguntará:
# - ¿Rutas? (y / n)
# - ¿Qué formato de estilos quieres usar? (CSS, SCSS, Less, etc.)
# - ¿Qué framework de estilos? (opcional)
# - ¿Habilitar SSR/SSG? (opcional)

Opciones útiles

OpciónDescripción
--routingAñade el módulo de rutas app-routing.module.ts
--style=scssUsa SCSS en lugar de CSS plano
--skip-testsNo genera archivos de prueba .spec.ts
--prefix=appPrefijo de los selectores de los componentes
# Ejemplo completo con opciones
ng new mi-app --routing --style=scss --skip-tests

¿Qué crea ng new?

mi-app/
├── src/                # Código fuente
├── angular.json        # Configuración de la CLI
├── package.json        # Dependencias y scripts
├── tsconfig.json       # Configuración de TypeScript
├── .gitignore          # Archivos ignorados por git
└── node_modules/       # Dependencias instaladas

2.4 Estructura de carpetas

Arquitectura del proyecto

Dentro de src/ se encuentra todo el código de la aplicación. Entender esta estructura es clave para trabajar con Angular.

src/
├── app/                      # Código de la aplicación (componentes, servicios)
│   ├── app.component.ts      # Componente raíz
│   ├── app.component.html    # Template del componente raíz
│   ├── app.component.scss    # Estilos del componente raíz
│   ├── app.module.ts         # Módulo raíz
│   └── app-routing.module.ts # Configuración de rutas
├── assets/                   # Imágenes, fuentes y archivos estáticos
├── environments/             # Entornos (environment.ts, environment.prod.ts)
├── favicon.ico               # Icono del navegador
├── index.html                # Página HTML raíz
├── main.ts                   # Punto de entrada de la aplicación
└── styles.scss               # Estilos globales

Archivos de configuración clave

ArchivoFunción
angular.jsonDefine los proyectos, builders y target de build/test/serve
package.jsonLista dependencias y scripts disponibles
tsconfig.jsonConfiguración de TypeScript del proyecto
app.module.tsCablea los componentes y módulos de la aplicación

Scripts disponibles en package.json

"scripts": {
  "ng": "ng",
  "start": "ng serve",
  "build": "ng build",
  "watch": "ng build --watch --configuration development",
  "test": "ng test"
}

2.5 Ejecutar el servidor de desarrollo (ng serve)

Levantar el proyecto

El comando ng serve compila la aplicación en memoria y levanta un servidor de desarrollo con recarga automática:

# Entrar en la carpeta del proyecto
cd mi-app

# Levantar el servidor de desarrollo
ng serve

Resultado esperado

✔ Browser application bundle generation complete.

Watch mode enabled. Watching for file changes...
Application bundle generation complete. [5.1 seconds]

Use the local URL: http://localhost:4200/

Opciones útiles de ng serve

OpciónDescripción
--openAbre automáticamente el navegador
--port 5000Cambia el puerto del servidor
--configuration developmentUsa la configuración de desarrollo
--hmrHabilita la recarga en caliente de módulos
# Abrir el navegador automáticamente
ng serve --open

# Usar otro puerto
ng serve --port 5000
Cada vez que guardes un archivo, Angular recompila automáticamente y recarga el navegador en segundos. No hace falta reiniciar el servidor.

2.6 Comandos útiles de la CLI

Generación de código

La CLI permite generar automáticamente todos los elementos de Angular con la forma ng generate <algo> (abreviada ng g):

ComandoAbreviaturaQué crea
ng g componentng g cUn componente con sus 4 archivos (.ts, .html, .scss, .spec)
ng g serviceng g sUn servicio con @Injectable
ng g moduleng g mUn NgModule
ng g directiveng g dUna directiva
ng g guardng g gUn guard de rutas
ng g interfaceng g iUna interfaz de TypeScript

Ejemplos prácticos

# Crear un componente en la carpeta app/componentes/navbar
ng generate component componentes/navbar

# Crear un servicio de usuarios
ng generate service servicios/usuario

# Crear un módulo de productos
ng generate module productos

Otros comandos importantes

# Compilar para producción
ng build

# Ejecutar pruebas unitarias con Karma
ng test

# Ejecutar el linter del proyecto
ng lint

# Agregar una librería de la comunidad
ng add @angular/material
La generación mediante la CLI asegura que los archivos sigan las convenciones de nombres y la estructura esperada por Angular.

Resumen

**Lo que aprendiste en esta sección:** - Angular requiere **Node.js LTS** y **npm** instalados en el equipo - Angular CLI se instala con npm install -g @angular/cli - ng new mi-app crea un proyecto nuevo con todo el esqueleto - La estructura de carpetas se organiza bajo src/ en módulos, componentes y servicios - ng serve levanta un servidor de desarrollo con recarga automática en http://localhost:4200 - Comandos como ng generate automatizan la creación de componentes, servicios y módulos
