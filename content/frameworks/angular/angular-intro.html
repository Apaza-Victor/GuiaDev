1.1 Qué es Angular

Definición de Angular

Angular es un framework de desarrollo de aplicaciones web mantenido por Google. Está escrito en TypeScript y permite construir aplicaciones de una sola página (SPA) completas y escalables, integrando todas las herramientas necesarias en un solo paquete.

CaracterísticaDescripción
CreadorGoogle
Año2016 (Angular 2+)
TipoFramework completo (no librería)
LenguajeTypeScript
EnfoqueAplicaciones SPA modulares por componentes

Diferencias entre AngularJS y Angular

  • AngularJS (1.x): La versión original basada en JavaScript
  • Angular (2+): Reescritura completa basada en TypeScript
  • Angular no es compatible con AngularJS; son tecnologías distintas

Ejemplo: primer componente

import { Component } from '@angular/core';

@Component({
  selector: 'app-saludo',
  template: '<p>¡Hola desde Angular!</p>'
})
export class SaludoComponent {
  mensaje: string = 'Bienvenido a Angular';
}

1.2 Concepto de SPA (Single Page Application)

¿Qué es una SPA?

Una SPA (Single Page Application) es una aplicación web que carga una sola página HTML y actualiza el contenido de forma dinámica, sin recargar el navegador en cada interacción.

SPA vs. aplicación tradicional

AspectoAplicación tradicionalSPA (Angular)
NavegaciónRecarga la página completaActualiza solo el contenido
VelocidadMás lentaMás rápida y fluida
ServidorGenera el HTMLEnvía datos (JSON)
ExperienciaInterrumpidaSimilar a una app nativa

Flujo de una petición en Angular

Usuario hace clic → Angular intercepta la navegación → Carga el componente
correspondiente → Actualiza el DOM sin recargar la página

Ventajas de las SPA con Angular

  • Experiencia de usuario fluida: Sin parpadeos ni recargas
  • Menor carga de servidor: Solo se intercambian datos
  • Rutas client-side: La navegación la gestiona el router de Angular
Cuando el usuario entra en una ruta, Angular no pide una página nueva al servidor, sino que dibuja el componente correspondiente directamente en el navegador.

1.3 Diferencias con React y Vue

Comparativa de tecnologías frontend

AspectoAngularReactVue
TipoFramework completoLibreríaFramework progresivo
LenguajeTypeScript obligatorioJavaScript/TypeScriptJavaScript/TypeScript
Baterías incluidasRouting, HTTP, formulariosRequiere librerías externasNúcleo + ecosistema
Curva de aprendizajeAltaMediaBaja/Media
Patrón de arquitecturaComponentes + Módulos + DIComponentes (hooks)Componentes (options/composition)

¿Cuándo elegir Angular?

  • Proyectos empresariales grandes y de largo plazo
  • Equipos que valoran la estructura y convenciones fuertes
  • Aplicaciones que necesitan todo integrado (routing, HTTP, formularios, DI)
  • Cuando se desea TypeScript como base obligatoria

Resumen práctico

Angular = Estructura completa, todo integrado, opinativo
React   = Libertad total, eliges tus herramientas
Vue     = Equilibrio entre flexibilidad y sencillez

1.4 Ventajas de Angular

Ventajas principales

VentajaDescripción
Todo incluidoRouting, formularios, HTTP y testing integrados
TypeScriptTipado estático que reduce errores en tiempo de ejecución
Inyección de dependenciasFacilita la creación de código desacoplado y testeable
MódulosOrganización del código en unidades reutilizables
Angular CLIGenera código, compila y despliega con un solo comando
Ciclo de vida claroHooks (ngOnInit, ngOnDestroy) para controlar los componentes

Ejemplo: inyección de dependencias

import { Component, OnInit } from '@angular/core';
import { UsuarioService } from './usuario.service';

@Component({
  selector: 'app-usuarios',
  template: '<p>{{ mensaje }}</p>'
})
export class UsuariosComponent implements OnInit {
  mensaje: string = '';

  constructor(private usuarioService: UsuarioService) {}

  ngOnInit(): void {
    this.mensaje = this.usuarioService.obtenerMensaje();
  }
}
Al ser un framework, Angular ya tomó muchas decisiones por ti. Esto evita discusiones de equipo sobre qué librerías usar y garantiza consistencia.

1.5 Estructura de un proyecto Angular

Carpetas principales

mi-app/
├── src/
│   ├── app/
│   │   ├── app.component.ts      # Componente raíz
│   │   ├── app.component.html    # Template del componente raíz
│   │   ├── app.component.css     # Estilos del componente raíz
│   │   ├── app.module.ts         # Módulo raíz de la aplicación
│   │   └── app-routing.module.ts # Configuración de rutas (opcional)
│   ├── assets/                   # Imágenes y archivos estáticos
│   ├── environments/             # Variables de entorno (dev/prod)
│   ├── main.ts                   # Punto de entrada de la aplicación
│   ├── index.html                # Página HTML raíz
│   └── styles.css                # Estilos globales
├── angular.json                  # Configuración del proyecto (CLI)
├── package.json                  # Dependencias de npm
├── tsconfig.json                 # Configuración de TypeScript
└── node_modules/                 # Dependencias instaladas

1.6 Angular CLI

¿Qué es Angular CLI?

Angular CLI es la herramienta oficial de línea de comandos que facilita crear, desarrollar, probar y compilar aplicaciones Angular de forma rápida y estandarizada.

Comandos más usados

ComandoDescripción
ng new mi-appCrear una nueva aplicación
ng serveLevantar el servidor de desarrollo
ng generate componentGenerar un componente (abreviado g c)
ng buildCompilar la aplicación para producción
ng testEjecutar las pruebas unitarias
ng addAñadir una librería compatible

Ejemplo de uso

# Instalar la CLI de forma global
npm install -g @angular/cli

# Crear una aplicación
ng new mi-app

# Levantar el servidor de desarrollo
cd mi-app
ng serve
El CLI genera el esqueleto del proyecto, los componentes y los servicios. Escribir a mano los archivos solo es necesario en casos muy específicos.

Resumen

**Lo que aprendiste en esta sección:** - **Angular** es un framework completo de Google basado en TypeScript - Las **SPA** cargan una sola página y actualizan el contenido dinámicamente - Angular ofrece **todo integrado**: routing, HTTP, formularios e inyección de dependencias - A diferencia de **React** (librería) y **Vue** (progresivo), Angular es **opinativo y estructurado** - Un proyecto Angular tiene carpetas organizadas y un **módulo raíz** que inicia la app - **Angular CLI** automatiza la creación, generación y compilación del proyecto
