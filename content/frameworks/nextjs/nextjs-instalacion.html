2.1 Requisitos previos: Node.js y npm

Qué necesitas instalar

Next.js se ejecuta sobre Node.js, por lo que necesitas una versión moderna instalada:

  • Node.js: versión 18.17 o superior (recommended LTS)
  • npm: se instala junto con Node.js
  • Opcional: pnpm o yarn como gestores alternativos

Comprobar la instalación

node --version
npm --version
Para comprobar la versión de Node en tu terminal escribe `node -v` y para npm escribe `npm -v`. Descarga Node.js desde la página oficial.

---

2.2 Crear un proyecto con create-next-app

Comando de creación

Next.js ofrece una herramienta oficial llamada create-next-app que genera toda la estructura:

npx create-next-app@latest mi-app

# Te hará preguntas como:
# ? TypeScript? (y/n) -> yes
# ? ESLint? (y/n) -> yes
# ? Tailwind CSS? (y/n) -> yes
# ? App Router? (y/n) -> yes
# ? Turbopack? (y/n) -> yes

Opciones más importantes

OpciónDescripción
--tsHabilita TypeScript
--tailwindConfigura Tailwind CSS
--appUsa el App Router
--use-npmUsa npm como gestor
--eslintConfigura ESLint
Responde "yes" a App Router, ya que es el sistema de rutas recomendado en las versiones modernas.

2.3 Estructura de carpetas: app/ y pages/

Estructura básica de un proyecto Next.js

mi-app/
├── app/               # Directorio del App Router
│   ├── layout.tsx     # Layout raíz
│   ├── page.tsx       # Página de inicio
│   └── globals.css    # Estilos globales
├── public/            # Archivos estáticos (imágenes)
├── next.config.mjs    # Configuración de Next.js
├── package.json       # Dependencias y scripts
├── tsconfig.json      # Configuración de TypeScript
└── node_modules/      # Dependencias instaladas

App Router vs Pages Router

AspectoApp Router (app/)Pages Router (pages/)
RutasLayouts, server components_app.js, _document.js
SoporteRecomendado (nuevo)Compatibilidad
LayoutsNativosManual
FetchingServer ComponentsgetServerSideProps
En el App Router cada carpeta dentro de app/ representa una ruta de la URL.

2.4 Archivos principales: layout y page

layout.tsx: el layout raíz

// app/layout.tsx
import type { Metadata } from "next";

export const metadata: Metadata = {
  title: "Mi App",
  description: "Aplicación creada con Next.js",
};

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="es">
      <body>{children}</body>
    </html>
  );
}

page.tsx: la página de inicio

// app/page.tsx
export default function Home() {
  return (
    <div>
      <h1>Bienvenido a mi app</h1>
    </div>
  );
}
En el App Router los archivos page.tsx y layout.tsx tienen nombres reservados que Next.js reconoce automáticamente.

2.5 Ejecutar el servidor de desarrollo

Iniciar en modo desarrollo

npm run dev

Esto inicia el servidor en http://localhost:3000 con recarga en caliente (hot reload): cualquier cambio en el código se refleja al instante.

Errores comunes al arrancar

ProblemaSolución
Puerto 3000 ocupadoUsa npm run dev -- -p 4000
Dependencias no instaladasEjecuta npm install
Versión de Node antiguaActualiza Node.js a la LTS
El comando `npm run dev` corresponde al script `dev` definido en el `package.json`.

---

2.6 Compilar el proyecto con npm run build

Comando de compilación

npm run build

Genera la versión de producción optimizada y muestra un resumen de cada ruta con su estrategia de renderizado:

Route (app)          Size     First Load JS
┌ ○ /                 1.2 kB   87 kB
├ ○ /about            1.1 kB   87 kB
└ ƒ /posts/[id]       1.4 kB   88 kB

○  (Static)   prerendered as static content
ƒ  (Dynamic)  server-rendered on demand

Scripts más usados

ScriptFunción
npm run devServidor de desarrollo con recarga
npm run buildCompila para producción
npm startEjecuta la versión compilada
npm run lintRevisa el código con ESLint
Antes de desplegar siempre debes ejecutar `npm run build` para detectar errores de compilación.

Resumen

**Lo que aprendiste en esta sección:** - Necesitas Node.js 18.17 o superior para crear proyectos de Next.js - `create-next-app` genera toda la estructura automáticamente - El App Router usa la carpeta app/ con archivos reservados - layout.tsx define la estructura y page.tsx las páginas - npm run dev inicia el servidor en localhost:3000 - npm run build compila la versión de producción
