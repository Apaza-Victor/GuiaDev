7.1 CSS Modules en Next.js

Qué son los CSS Modules

Los CSS Modules permiten escribir estilos con ámbito local: las clases se generan con un hash único para no chocar con otras. Se crean archivos con extensión .module.css:

// app/components/Tarjeta.module.css
.tarjeta {
  border: 1px solid #ddd;
  border-radius: 8px;
  padding: 16px;
  background: #f9f9f9;
}
.titulo {
  font-size: 1.25rem;
  color: #333;
}

Importar y usar los estilos

// app/components/Tarjeta.jsx
import styles from "./Tarjeta.module.css";

export default function Tarjeta({ titulo, children }) {
  return (
    <div className={styles.tarjeta}>
      <h3 className={styles.titulo}>{titulo}</h3>
      {children}
    </div>
  );
}
Las clases de un CSS module se acceden como propiedades del objeto `styles` importado.

7.2 CSS global y Tailwind CSS

CSS global

Los estilos globales se importan en el layout.tsx y aplican a toda la app:

// app/globals.css
body {
  margin: 0;
  font-family: system-ui, sans-serif;
  background: #fff;
}
a {
  color: #0070f3;
}
// app/layout.tsx
import "./globals.css";

export default function RootLayout({ children }) {
  return (
    <html lang="es">
      <body>{children}</body>
    </html>
  );
}

Tailwind CSS (preconfigurado)

create-next-app puede configurar Tailwind que permite estilizar con clases utilitarias directamente en JSX:

// app/page.tsx
export default function Home() {
  return (
    <div className="min-h-screen flex items-center justify-center bg-gray-100">
      <h1 className="text-3xl font-bold text-blue-600">
        Hecho con Tailwind
      </h1>
    </div>
  );
}

Comparativa

EnfoqueVentaja
CSS ModulesÁmbito local y ordenado en archivos
CSS globalValores por defecto y reset en todo el sitio
TailwindUtilidades rápidas sin escribir CSS propio

7.3 Estilado condicional y dinámico

Clases condicionales

// app/components/Boton.tsx
"use client";

import { useState } from "react";

export default function Boton() {
  const [activado, setActivado] = useState(false);

  return (
    <button
      onClick={() => setActivado(!activado)}
      className={`btn ${activado ? "btn-activo" : "btn-inactivo"}`}
    >
      {activado ? "Activado" : "Desactivado"}
    </button>
  );
}

Combinar con la librería clsx (opcional)

import clsx from "clsx";

className={clsx("base", activado ? "activo" : "inactivo", {
  "oculto": !visible,
})}

Estilos inline dinámicos

const estilo = {
  color: riesgo ? "red" : "green",
  fontWeight: "bold",
};

return <p style={estilo}>Estado del servicio</p>;
Para combinar varias clases de forma sencilla y segura usa la librería `clsx` o `tailwind-merge`.

7.4 Optimización de imágenes con next/image

Ventajas del componente Image

Next.js trae un componente Image que optimiza las imágenes automáticamente: carga diferida, redimensionado y formato WebP:

// app/page.tsx
import Image from "next/image";

export default function Home() {
  return (
    <Image
      src="/hero.png"
      alt="Imagen de portada"
      width={800}
      height={400}
      priority
    />
  );
}

Opciones principales

PropDescripción
srcRuta o URL de la imagen
altTexto alternativo (obligatorio)
width / heightDimensiones para evitar saltos de layout
priorityCarga prioritaria (imágenes clave)
sizesDefine tamaños para imágenes responsive

Rotación automática a WebP

<Image
  src="/paisaje.jpg"
  alt="Paisaje"
  fill
  style={{ objectFit: "cover" }}
/>
Con `fill` la imagen ocupa todo el contenedor padre y con `objectFit: "cover"` se recorta para cubrirlo.

7.5 Fuentes optimizadas con next/font

Usar fuentes de Google sin coste de red

next/font carga fuentes de Google de forma optimizada: se auto-alojan y no bloquean el renderizado:

// app/layout.tsx
import { Inter } from "next/font/google";

const inter = Inter({ subsets: ["latin"] });

export default function RootLayout({ children }) {
  return (
    <html lang="es">
      <body className={inter.className}>{children}</body>
    </html>
  );
}

Configurar peso y estilos

import { Roboto } from "next/font/google";

const roboto = Roboto({
  weight: ["400", "700"],
  subsets: ["latin"],
  style: ["normal", "italic"],
});

Variables de fuente

const inter = Inter({
  subsets: ["latin"],
  variable: "--font-inter",
});

// Uso en CSS: font-family: var(--font-inter);
Al autohospedar las fuentes mejoras el rendimiento y el SEO porque evitas llamadas externas.

7.6 Tema claro/oscuro con CSS

Variables CSS para temas

/* app/globals.css */
:root {
  --color-fondo: #ffffff;
  --color-texto: #111111;
  --color-primario: #0070f3;
}

@media (prefers-color-scheme: dark) {
  :root {
    --color-fondo: #111111;
    --color-texto: #eeeeee;
  }
}

body {
  background: var(--color-fondo);
  color: var(--color-texto);
}

Aplicar el tema en los componentes

// app/components/Encabezado.tsx
import styles from "./Encabezado.module.css";

export default function Encabezado() {
  return (
    <header className={styles.header}>
      <h1 className={styles.logo}>Mi App</h1>
    </header>
  );
}
