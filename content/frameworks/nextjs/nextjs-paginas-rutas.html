3.1 El sistema de ficheros como enrutador

Rutas basadas en archivos

En Next.js no se configuran rutas en un archivo central. Cada carpeta con un page.tsx dentro de app/ se convierte en una ruta de la URL:

Archivo/carpetaURL resultante
app/page.tsx/
app/about/page.tsx/about
app/blog/page.tsx/blog
app/contacto/page.tsx/contacto

Estructura de ejemplo

app/
├── page.tsx          # /
├── layout.tsx        # Layout raíz
├── about/
│   └── page.tsx      # /about
└── blog/
    └── page.tsx      # /blog
La ruta que devuelve JSX se nombra siempre `page.tsx`. No uses otros nombres para las páginas.

---

3.2 Crear páginas básicas en app/

Crear una página "Acerca de"

// app/about/page.tsx
export default function About() {
  return (
    <div>
      <h1>Acerca de nosotros</h1>
      <p>Somos una empresa que usa Next.js.</p>
    </div>
  );
}

Varias rutas hijas

app/
└── productos/
    ├── page.tsx      # /productos
    ├── destacados/
    │   └── page.tsx  # /productos/destacados
    └── ofertas/
        └── page.tsx  # /productos/ofertas

Rutas anidadas

Las carpetas se anidan para crear rutas jerárquicas de forma natural:

# /productos/destacados
app/productos/destacados/page.tsx

3.3 Rutas dinámicas con corchetes

Segmentos dinámicos [id]

Para rutas que cambian según un parámetro, usa corchetes en el nombre de la carpeta:

app/
└── posts/
    ├── page.tsx       # /posts
    └── [id]/
        └── page.tsx   # /posts/1, /posts/2, ...

Acceder al parámetro

// app/posts/[id]/page.tsx
export default async function Post({
  params,
}: {
  params: { id: string };
}) {
  const res = await fetch(
    `https://api.example.com/posts/${params.id}`
  );
  const post = await res.json();

  return (
    <article>
      <h1>{post.title}</h1>
      <p>{post.body}</p>
    </article>
  );
}

Rutas dinámicas múltiples

# app/blog/[year]/[slug]/page.tsx -> /blog/2024/titulo-post
En Next.js 15 los parámetros de una página deben declararse como `async` y acceder a ellos mediante `params`.

---

3.4 Catch-all y rutas opcionales

Catch-all con tres puntos

Una carpeta [...slug] captura todos los segmentos restantes:

app/docs/[...slug]/page.tsx

# /docs -> []
# /docs/guia -> ["guia"]
# /docs/guia/instalacion -> ["guia", "instalacion"]

Rutas opcionales [[...slug]]

Con doble corchete el segmento puede no existir:

app/shop/[[...filtros]]/page.tsx

# /shop -> []
# /shop/hombre -> ["hombre"]
# /shop/hombre/zapatos -> ["hombre", "zapatos"]

Ejemplo de catch-all

// app/docs/[...slug]/page.tsx
export default function Docs({
  params,
}: {
  params: { slug: string[] };
}) {
  const ruta = params.slug.join(" / ");
  return <p>Documento en: {ruta}</p>;
}

3.5 Navegación con el componente Link

Cómo navegar entre páginas

Sustituye las etiquetas <a> por el componente Link para navegación en cliente sin recargar la página:

// app/components/Nav.tsx
import Link from "next/link";

export default function Nav() {
  return (
    <nav>
      <Link href="/">Inicio</Link>
      <Link href="/about">Acerca de</Link>
      <Link href="/blog">Blog</Link>
    </nav>
  );
}

Rutas dinámicas con Link

import Link from "next/link";

export default function PostList({ posts }) {
  return (
    <ul>
      {posts.map((post) => (
        <li key={post.id}>
          <Link href={`/posts/${post.id}`}>
            {post.title}
          </Link>
        </li>
      ))}
    </ul>
  );
}
El componente `Link` hace prefetch de las rutas visibles, mejorando la velocidad de navegación.

3.6 Navegación programática con useRouter

Redireccionar desde el código

Para redirigir tras una acción (submit, login, etc.) usa useRouter en un componente cliente:

// app/components/Formulario.tsx
"use client";

import { useRouter } from "next/navigation";

export default function Formulario() {
  const router = useRouter();

  const alEnviar = (e) => {
    e.preventDefault();
    // ... validación y envío ...
    router.push("/gracias");
  };

  return (
    <form onSubmit={alEnviar}>
      <button type="submit">Enviar</button>
    </form>
  );
}

Métodos de useRouter

MétodoQué hace
router.push()Navega a una nueva ruta
router.replace()Reemplaza la ruta sin historial
router.refresh()Recarga los datos de la página
router.back()Vuelve a la página anterior
`useRouter` de `next/navigation` funciona en componentes cliente marcados con `"use client"`.

---

Resumen

**Lo que aprendiste en esta sección:** - El enrutamiento se basa en el sistema de ficheros con page.tsx - Cada carpeta dentro de app/ es una ruta de la URL - Las rutas dinámicas usan corchetes tipo [id] - Catch-all con [...slug] y opcionales con [[...slug]] - El componente Link navega sin recargar la página - useRouter permite navegación programática en client components
