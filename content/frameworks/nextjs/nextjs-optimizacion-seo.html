9.1 Metadatos dinámicos para SEO

Por qué importan los metadatos

Los metadatos (título, descripción, canónicos) ayudan a los buscadores a indexar y mostrar tu página correctamente:

// app/blog/[slug]/page.tsx
import type { Metadata } from "next";

export async function generateMetadata({
  params,
}: {
  params: { slug: string };
}): Promise<Metadata> {
  const res = await fetch(
    `https://api.example.com/posts/${params.slug}`
  );
  const post = await res.json();

  return {
    title: `${post.title} | Mi Blog`,
    description: post.excerpt,
    openGraph: {
      title: post.title,
      description: post.excerpt,
      images: [post.imagen],
    },
    alternates: {
      canonical: `/blog/${post.slug}`,
    },
  };
}

export default async function Post({ params }) {
  const res = await fetch(
    `https://api.example.com/posts/${params.slug}`
  );
  const post = await res.json();

  return (
    <article>
      <h1>{post.title}</h1>
      <p>{post.body}</p>
    </article>
  );
}
Usa `generateMetadata` cuando el SEO de la página dependa de datos dinámicos.

9.2 Sitemap y robots.txt

Generar un sitemap

Un sitemap lista todas las rutas de tu sitio para que los buscadores las encuentren:

// app/sitemap.ts
import type { MetadataRoute } from "next";

export default function sitemap(): MetadataRoute.Sitemap {
  return [
    {
      url: "https://mitienda.com",
      lastModified: new Date(),
      changeFrequency: "weekly",
      priority: 1,
    },
    {
      url: "https://mitienda.com/blog",
      lastModified: new Date(),
      changeFrequency: "daily",
      priority: 0.8,
    },
  ];
}

Configurar robots.txt

// app/robots.ts
import type { MetadataRoute } from "next";

export default function robots(): MetadataRoute.Robots {
  return {
    rules: {
      userAgent: "*",
      allow: "/",
      disallow: "/admin",
    },
    sitemap: "https://mitienda.com/sitemap.xml",
  };
}

Opciones del sitemap

CampoDescripción
urlURL absoluta de la página
lastModifiedFecha de última actualización
changeFrequencyFrecuencia de cambios
priorityPrioridad de 0 a 1

9.4 Carga diferida (lazy loading)

Cargar componentes bajo demanda

Usa next/dynamic para cargar componentes pesados solo cuando el usuario los necesite:

// app/page.tsx
import dynamic from "next/dynamic";

const GraficoPesado = dynamic(() =>
  import("../components/Grafico"),
  {
    loading: () => <p>Cargando gráfico...</p>,
    ssr: false,
  }
);

export default function Home() {
  return (
    <div>
      <h1>Panel</h1>
      <GraficoPesado />
    </div>
  );
}

Imágenes con carga diferida

import Image from "next/image";

// Por defecto las imágenes usan lazy loading
<Image
  src="/galeria/imagen-2.jpg"
  alt="Imagen de la galería"
  width={600}
  height={400}
  loading="lazy"
/>;
`next/dynamic` y `next/image` integran la carga diferida por defecto para mejorar el rendimiento.

9.5 Optimización automática y streaming

Optimizaciones automáticas de Next.js

  • Code splitting: cada página carga solo su JavaScript
  • Prefetch: Link precarga las rutas visibles
  • Compresión: respuestas gzip/brotli automáticas
  • Minificación: JS y CSS se comprimen al compilar

Streaming con Suspense

Suspense permite mostrar parte de la página mientras el resto se carga:

// app/blog/page.tsx
import { Suspense } from "react";
import ListaPosts from "./ListaPosts";
import Skeleton from "./Skeleton";

export default function Blog() {
  return (
    <div>
      <h1>Blog</h1>
      <Suspense fallback={<Skeleton />}>
        <ListaPosts />
      </Suspense>
    </div>
  );
}
El streaming con Suspense mejora la percepción de velocidad y el primer pintado (FCP).
