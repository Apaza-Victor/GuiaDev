8.1 Sistema de autenticación integrado

Qué incluye Django

Django trae un sistema de autenticación completo, sin instalar nada extra. Forma parte de django.contrib.auth y de django.contrib.sessions.

Componentes disponibles

ComponenteFunción
Modelo UserUsuarios con username, password, email y permisos
Vistas de login/logoutFunciones y vistas listas para usar
Decoradores@login_required para proteger vistas
Permisos y gruposControl de acceso por modelo y por grupo
Hashing de contraseñasCon hash seguros y actualizables

Instalar y preparar

# Las migraciones crean las tablas de autenticación
python manage.py migrate

# Crear un superusuario para probar
python manage.py createsuperuser

Con esto ya puedes entrar en el admin y gestionar usuarios.

8.2 Login y logout

Usar las vistas integradas

# urls.py del proyecto
from django.urls import path, include

urlpatterns = [
    path("accounts/", include("django.contrib.auth.urls")),
]

Esta línea incluye rutas ya hechas:

URLVista
/accounts/login/Formulario de login
/accounts/logout/Cerrar sesión
/accounts/password_change/Cambiar contraseña

Login manual con authenticate + login

# blog/views.py
from django.contrib.auth import authenticate, login, logout
from django.shortcuts import render, redirect

def iniciar_sesion(request):
    if request.method == "POST":
        username = request.POST["username"]
        password = request.POST["password"]
        usuario = authenticate(request, username=username, password=password)
        if usuario is not None:
            login(request, usuario)
            return redirect("inicio")
        # Credenciales inválidas
        return render(request, "blog/login.html", {"error": True})
    return render(request, "blog/login.html")

def cerrar_sesion(request):
    logout(request)
    return redirect("inicio")
`login()` guarda la sesión del usuario; `logout()` la cierra. Verifica siempre primero con `authenticate()` que las credenciales sean válidas.

8.4 Permisos y grupos

Permisos por modelo

Django crea permisos automáticos para cada modelo: add, change, delete y view.

Asignar y comprobar permisos

# Asignar un permiso directo
from django.contrib.auth.models import Permission

permiso = Permission.objects.get(codename="change_articulo")
usuario.user_permissions.add(permiso)

# Comprobar permisos en el código
def vista_editor(request):
    if request.user.has_perm("blog.change_articulo"):
        # Puede editar artículos
        pass

Grupos

# Los grupos agrupan permisos y se asignan a usuarios
from django.contrib.auth.models import Group, User

editores, _ = Group.objects.get_or_create(name="Editores")

# Añadir un permisos al grupo
permiso = Permission.objects.get(codename="change_articulo")
editores.permissions.add(permiso)

# Asignar el grupo a un usuario
usuario.groups.add(editores)

Permisos en plantillas

{% if perms.blog.change_articulo %}
  <a href="{% url 'editar' articulo.pk %}">Editar</a>
{% endif %}

8.5 Proteger vistas con login_required

Decorador login_required

El decorador @login_required redirige al login si el visitante no está autenticado.

# blog/views.py
from django.contrib.auth.decorators import login_required
from django.shortcuts import render

@login_required
def mi_perfil(request):
    return render(request, "blog/perfil.html", {
        "usuario": request.user,
    })

# Redirigir a otra URL tras el login
@login_required(login_url="/accounts/login/")
def perfil_admin(request):
    return render(request, "blog/admin.html")

Redirigir después del login

# 1. En las vistas integradas de auth, la URL
#    /accounts/login/?next=/perfil/ te devuelve a /perfil/

# 2. Configura el LOGIN_URL y LOGIN_REDIRECT_URL en settings.py
LOGIN_URL = "/accounts/login/"
LOGIN_REDIRECT_URL = "/inicio/"
LOGOUT_REDIRECT_URL = "/"

Proteger vistas por clase (CBV)

from django.contrib.auth.mixins import LoginRequiredMixin
from django.views.generic import TemplateView

class Perfil(LoginRequiredMixin, TemplateView):
    template_name = "blog/perfil.html"
    login_url = "/accounts/login/"
Para controlar además por permisos usa `PermissionRequiredMixin` y el atributo `permission_required` en vistas por clase.

8.6 Ejemplo completo: registro de usuarios

Formulario de registro con ModelForm de User

# blog/forms.py
from django import forms
from django.contrib.auth.models import User

class FormularioUsuario(forms.ModelForm):
    password = forms.CharField(widget=forms.PasswordInput)
    confirmar = forms.CharField(widget=forms.PasswordInput)

    class Meta:
        model = User
        fields = ["username", "email"]

    def clean(self):
        datos = self.cleaned_data
        if datos.get("password") != datos.get("confirmar"):
            raise forms.ValidationError("Las contraseñas no coinciden")
        return datos

    def save(self, commit=True):
        usuario = super().save(commit=False)
        # Guarda la contraseña con hash seguro
        usuario.set_password(self.cleaned_data["password"])
        if commit:
            usuario.save()
        return usuario

Vista de registro

# blog/views.py
from django.shortcuts import render, redirect
from django.contrib.auth import login
from .forms import FormularioUsuario

def registrar(request):
    if request.method == "POST":
        form = FormularioUsuario(request.POST)
        if form.is_valid():
            usuario = form.save()
            # Inicia sesión automáticamente tras registrarse
            login(request, usuario)
            return redirect("inicio")
    else:
        form = FormularioUsuario()
    return render(request, "blog/registro.html", {"form": form})
Nunca guardes contraseñas en texto plano. Usa siempre set_password() para almacenar el hash.

Resumen

**Lo que aprendiste en esta sección:** - Django incluye autenticación completa en `django.contrib.auth` - Login con vistas integradas o manualmente con `authenticate` y `login` - El modelo User trae campos y flags como `is_staff` y `is_superuser` - Permisos por modelo y grupos con `groups` y `user_permissions` - Proteger vistas con `@login_required` y `LoginRequiredMixin` - Registrar usuarios con `set_password()` para cifrar contraseñas
