6.1 Qué es el ORM de Django

Definición

El ORM (Object Relational Mapper) de Django traduce las clases de Python (modelos) en tablas de la base de datos y permite consultarlas sin escribir SQL. Cada operación se resuelve en SQL de forma automática.

Ventajas

VentajaDescripción
ProductividadNo necesitas escribir SQL para el 95% de las consultas
PortabilidadCambia de SQLite a PostgreSQL sin cambiar el código
SeguridadPreviene SQL injection con consultas parametrizadas
Mapeo automáticoLas relaciones entre modelos se vuelven atributos Python

Modelo de ejemplo

# blog/models.py
from django.db import models

class Articulo(models.Model):
    titulo = models.CharField(max_length=200)
    contenido = models.TextField()
    publicado = models.BooleanField(default=False)

    def __str__(self):
        return self.titulo
El manager `Articulo.objects` es el punto de entrada para todas las consultas y devuelve QuerySets.

---

6.2 Qué es un QuerySet

Definición

Un QuerySet es una colección perezosa de objetos de un modelo. "Perezoso" significa que la consulta a la base de datos solo se ejecuta cuando realmente necesitas los datos (por ejemplo, al iterar o convertirlo a lista).

Ejemplo básico

# Consulta que NO se ejecuta aún (es perezosa)
articulos = Articulo.objects.all()

# La consulta se ejecuta aquí, al iterar
for articulo in articulos:
    print(articulo.titulo)

# Convertir a lista fuerza la ejecución
lista = list(Articulo.objects.all())

Métodos que devuelven QuerySet

MétodoFunción
all()Todos los registros
filter()Registros que cumplen condiciones
exclude()Registros que NO cumplen condiciones
order_by()Ordenar resultados
values()Devuelve diccionarios en vez de objetos
distinct()Eliminar duplicados
count()Cuenta de registros

Encadenar consultas

articulos = Articulo.objects.filter(publicado=True).order_by("-fecha_publicacion")

6.3 Filtrar y buscar registros

Métodos principales

# filter: devuelve los que cumplen (puede haber varios)
publicados = Articulo.objects.filter(publicado=True)

# exclude: devuelve los que NO cumplen
borradores = Articulo.objects.exclude(publicado=True)

# get: devuelve UN solo registro (error si hay 0 o más de 1)
articulo = Articulo.objects.get(pk=1)

Lookups (búsquedas) frecuentes

LookupDescripciónEjemplo

Ejemplo combinado

resultados = Articulo.objects.filter(
    publicado=True,
    titulo__icontains="django",
    precio__gte=50,
).exclude(categoria__nombre="privada")

print(resultados.count())
El doble guion bajo (`__`) pasa de un campo a un lookup o a un campo de una relación, como `categoria__nombre`.

6.4 Crear, actualizar y eliminar registros

Crear registros

# Opción 1: crear una instancia y guardarla
articulo = Articulo(titulo="Nuevo artículo", publicado=False)
articulo.save()

# Opción 2: método create (lo hace en un paso)
articulo = Articulo.objects.create(
    titulo="Otro artículo",
    contenido="Contenido",
    publicado=True,
)

# get_or_create: busca o crea
articulo, creado = Articulo.objects.get_or_create(titulo="Único")

Actualizar registros

# Actualizar un campo y guardar
articulo.titulo = "Título modificado"
articulo.publicado = True
articulo.save()

# Actualizar con QuerySet (más rápido en lote)
Articulo.objects.filter(publicado=False).update(publicado=True)

Eliminar registros

# Eliminar un objeto
articulo.delete()

# Eliminar varios según filtro
Articulo.objects.filter(publicado=False).delete()

Métodos de QuerySet útiles

Articulo.objects.count()                       # Número total
articulos = Articulo.objects.first()           # Primer registro
Articulo.objects.latest("fecha_publicacion")   # Último por campo
Articulo.objects.all().order_by("?")           # Orden aleatorio

6.5 Relaciones entre modelos

Tipos de relaciones

RelaciónCampoEjemplo real
Muchos a unoForeignKeyUn artículo pertenece a una categoría
Uno a unoOneToOneFieldUn usuario tiene un perfil
Muchos a muchosManyToManyFieldUn artículo tiene varias etiquetas

Ejemplo de modelos con relaciones

from django.db import models
from django.contrib.auth.models import User

class Categoria(models.Model):
    nombre = models.CharField(max_length=100)

class Etiqueta(models.Model):
    nombre = models.CharField(max_length=50)

class Articulo(models.Model):
    titulo = models.CharField(max_length=200)
    autor = models.ForeignKey(
        User, on_delete=models.CASCADE, related_name="articulos"
    )
    categoria = models.ForeignKey(
        Categoria, on_delete=models.SET_NULL, null=True
    )
    etiquetas = models.ManyToManyField(Etiqueta, related_name="articulos")

class Perfil(models.Model):
    usuario = models.OneToOneField(User, on_delete=models.CASCADE)
    biografia = models.TextField(blank=True)

Consultar a través de las relaciones

# Acceso hacia delante (artículo -> autor)
autor = articulo.autor.username

# Acceso hacia atrás (relación inversa con related_name)
articulos_de_autor = autor.articulos.all()

# Filtro por relación
articulos_python = Articulo.objects.filter(categoria__nombre="Python")

# Agregar y quitar relaciones many-to-many
articulo.etiquetas.add(etiqueta_django)
articulo.etiquetas.remove(etiqueta_obsoleta)
articulo.etiquetas.clear()
El parámetro `on_delete` es obligatorio en ForeignKey y OneToOne. Usa `CASCADE` para borrar en cadena o `PROTECT` para impedir el borrado si existen dependencias.

6.6 Ejemplo práctico de consultas

Escenario: librería de artículos

# Todas las consultas sobre la base de datos

# Los 5 artículos más recientes publicados
recientes = Articulo.objects.filter(
    publicado=True
).order_by("-fecha_publicacion")[:5]

# Artículos que mencionen "python" en el título o contenido
busqueda = Articulo.objects.filter(
    models.Q(titulo__icontains="python") |
    models.Q(contenido__icontains="python")
)

# Artículos por autor con conteo
autores = User.objects.annotate(num_articulos=models.Count("articulos"))

# Agregar una relación many-to-many
etiqueta_django = Etiqueta.objects.create(nombre="Django")
articulo.etiquetas.add(etiqueta_django)

# Consulta con valores concretos (no objetos)
valores = Articulo.objects.values("titulo", "fecha_publicacion")

# Combinar varios QuerySets (union)
total = Articulo.objects.filter(publicado=True).union(
    Articulo.objects.filter(titulo__startswith="Guía")
)

Operadores Q para búsquedas complejas

from django.db.models import Q

# AND se simula con comas en filter; OR con Q y |
resultados = Articulo.objects.filter(
    Q(publicado=True) & Q(categoria__nombre="Python")
)
Puedes probar todas estas consultas en la consola interactiva con `python manage.py shell`.

Resumen

**Lo que aprendiste en esta sección:** - El ORM traduce modelos Python a SQL de forma automática y segura - Un QuerySet es perezoso: la consulta se ejecuta al evaluarlo - `filter`, `exclude` y `get` son los métodos básicos de consulta - Crear, actualizar y eliminar registros con `save`, `create`, `update` y `delete` - Relaciones: `ForeignKey`, `OneToOneField` y `ManyToManyField` - Usar `Q` para consultas OR y `related_name` para la relación inversa
