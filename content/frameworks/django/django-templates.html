5.1 Qué es el sistema de plantillas (DTL)

Definición

Aunque puedes usar cualquier motor (como Jinja2), Django incluye su propio sistema llamado Django Template Language (DTL). Son archivos HTML con marcadores especiales que se rellenan con datos.

Sintaxis básica

SintaxisQué haceEjemplo
{{ variable }}Muestra el valor de una variable{{ usuario.nombre }}
{% etiqueta %}Ejecuta lógica (if, for, block){% if usuario %}
{{ dato|filtro }}Transforma el valor con un filtro{{ precio|floatformat:2 }}
{# comentario #}Comentario ignorado al renderizar{# solo desarrollo #}

Características

  • Diseñado para separar lógica de presentación: no permite código Python arbitrario
  • Muy seguro: escapa HTML automáticamente
  • Rápido de aprender y con amplia documentación

---

5.2 Variables con {{ }}

Cómo funciona

Las variables se escriben entre dobles llaves {{ }}. Django busca el valor en el contexto pasado por la vista y lo imprime.

Acceso a datos

<!-- templates/blog/detalle.html -->
<p>Título: {{ articulo.titulo }}</p>
<p>Slug: {{ articulo.slug }}</p>
<p>Categoría: {{ articulo.categoria.nombre }}</p>
<p>Precio: {{ articulo.precio }}</p>

{# Acceso a índices y claves #}
{{ lista.0 }}          {# Primer elemento de una lista #}
{{ diccionario.clave }} {# Valor de una clave #}

Desde la vista

# views.py
def detalle(request, pk):
    articulo = Articulo.objects.get(pk=pk)
    return render(request, "blog/detalle.html", {
        "articulo": articulo,
        "etiquetas": ["django", "python", "web"],
    })

Variables condicionales (default)

{{ articulo.resumen|default:"Sin resumen" }}
{{ user.username|default:"Invitado" }}

5.3 Etiquetas con {% %}

Etiquetas más usadas

EtiquetaFunción
{% if %}Condicional
{% for %}Recorrer listas o querysets
{% url %}Generar una URL por su nombre
{% extends %}Heredar de una plantilla base
{% block %}Definir una zona reemplazable
{% include %}Insertar otra plantilla
{% load %}Cargar filtros o etiquetas de apps
{% static %}Apuntar a archivos estáticos

Ejemplo: condicional y bucle

<ul>
  {% for articulo in articulos %}
    {% if articulo.publicado %}
      <li>{{ articulo.titulo }} - {{ articulo.fecha_publicacion }}</li>
    {% else %}
      <li>{{ articulo.titulo }} (borrador)</li>
    {% endif %}
  {% empty %}
    <li>No hay artículos disponibles.</li>
  {% endfor %}
</ul>

Variables del bucle

  • forloop.counter: Número de iteración (1, 2, 3...)
  • forloop.counter0: Número de iteración empezando en 0
  • forloop.first: Verdadero en la primera vuelta
  • forloop.last: Verdadero en la última vuelta

5.4 Herencia de plantillas (extends y block)

Qué es

La herencia te permite definir una plantilla base con la estructura común (header, nav, footer) y que cada página solo rellene sus bloques específicos.

Plantilla base

<!-- templates/base.html -->
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>{% block titulo %}Mi Sitio{% endblock %}</title>
</head>
<body>
  <header>Logo y navegación</header>
  <main>
    {% block contenido %}{% endblock %}
  </main>
  <footer>&copy; 2026 Mi Sitio</footer>
</body>
</html>

Plantilla hija

<!-- templates/blog/lista.html -->
{% extends "base.html" %}

{% block titulo %}Listado de artículos{% endblock %}

{% block contenido %}
  <h1>Artículos</h1>
  <ul>
    {% for articulo in articulos %}
      <li><a href="{% url 'detalle' articulo.slug %}">{{ articulo.titulo }}</a></li>
    {% endfor %}
  </ul>
{% endblock %}
La plantilla hija debe empezar con `{% extends %}` y solo puede definir bloques: cualquier otro contenido externo se ignora.

5.5 Includes y reutilización

Qué es un include

La etiqueta {% include %} inserta el contenido de otra plantilla dentro de la actual. Ideal para componentes repetidos como una tarjeta o un formulario parcial.

Componente de tarjeta

<!-- templates/blog/tarjeta_articulo.html -->
<article>
  <h3>{{ articulo.titulo }}</h3>
  <p>{{ articulo.contenido|truncatewords:20 }}</p>
  <a href="{% url 'detalle' articulo.slug %}">Leer más</a>
</article>

Usar el include

<!-- templates/blog/inicio.html -->
{% extends "base.html" %}
{% block contenido %}
  <h1>Últimos artículos</h1>
  {% for articulo in articulos %}
    {% include "blog/tarjeta_articulo.html" %}
  {% endfor %}
{% endblock %}

Pasar variables extra

{% include "blog/tarjeta_articulo.html" with titulo_personalizado="Destacado" %}
Diferencia clave: `{% extends %}` construye un documento a partir de la base; `{% include %}` reutiliza un fragmento dentro de un documento.

5.6 Filtros de plantilla

Qué son

Los filtros transforman el valor de una variable antes de mostrarlo. Se aplican con el símbolo |.

Filtros más usados

FiltroQué haceEjemplo
lowerConvierte a minúsculas{{ nombre|lower }}
upperConvierte a mayúsculas{{ nombre|upper }}
titleCapitaliza cada palabra{{ nombre|title }}
lengthCuenta caracteres o elementos{{ texto|length }}
defaultValor si está vacío{{ email|default:"—" }}
dateFormatea fechas{{ fecha|date:"d/m/Y" }}
truncatewordsCorta por número de palabras{{ texto|truncatewords:30 }}
floatformatRedondea decimales{{ precio|floatformat:2 }}
safeMarca HTML como seguro{{ html|safe }}

Encadenar filtros

{{ articulo.resumen|truncatewords:20|title }}
{{ usuario.email|lower|default:"Sin correo" }}
Usa `|safe` solo con contenido en el que confíes: evita que Django escape el HTML, lo que puede abrir brechas XSS si el dato es de usuarios.

---

Resumen

**Lo que aprendiste en esta sección:** - El motor de plantillas de Django se llama DTL (Django Template Language) - Las variables se escriben con `{{ }}` y las etiquetas con `{% %}` - La herencia con `{% extends %}` y `{% block %}` evita repetir HTML - `{% include %}` reutiliza fragmentos de plantilla - Los filtros permiten transformar valores con `|` - Django escapa el HTML por defecto para proteger contra XSS
