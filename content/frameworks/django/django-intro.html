1.1 Qué es Django

Definición

Django es un framework web de alto nivel escrito en Python que permite desarrollar aplicaciones web completas de forma rápida y segura. Fue creado en 2003 por Adrian Holovaty y Simon Willison en el periódico Lawrence Journal-World y liberado como código abierto en 2005 bajo licencia BSD.

Sigue el principio de DRY (Don't Repeat Yourself) y está pensado para proyectos de todos los tamaños, desde pequeños sitios hasta grandes plataformas.

Características principales

CaracterísticaDescripción
Python puroEstá escrito íntegramente en Python y se programa en Python
MVTPatrón Modelo-Vista-Template para separar responsabilidades
Baterías incluidasAdmin, ORM, auth, serializers y más integrados
SeguroProtege contra CSRF, XSS y SQL injection por defecto
EscalableUsado por empresas con millones de visitas diarias

Ejemplo: Vista mínima en Django

    return HttpResponse("¡Hola, Django!")

1.2 El patrón MVT

Qué es el patrón MVT

Django sigue el patrón MVT (Model - View - Template), una adaptación del clásico MVC adaptada a Python:

ComponenteRolArchivo típico
ModelDefine la estructura de datos y la comunicación con la base de datosmodels.py
ViewContiene la lógica de negocio y procesa las peticionesviews.py
TemplateGenera el HTML que ve el usuariotemplates/

Flujo de una petición

  • 1. URL: El navegador pide una URL como /productos/
  • 2. Patrón: urls.py busca el patrón que coincida
  • 3. Vista: La vista asociada procesa la petición
  • 4. Modelo: Si se necesitan datos, la vista consulta el modelo
  • 5. Template: La vista renderiza un template con los datos
  • 6. Respuesta: El usuario recibe el HTML final

Ejemplo: Flujo MVT

# models.py
from django.db import models

class Producto(models.Model):
    nombre = models.CharField(max_length=100)
    precio = models.DecimalField(max_digits=8, decimal_places=2)

# views.py
from django.shortcuts import render
from .models import Producto

def lista_productos(request):
    productos = Producto.objects.all()            # Model
    return render(request, "productos.html", {    # Template
        "productos": productos                     # Datos a la vista
    })

1.3 Baterías incluidas (batteries included)

Qué significa

El enfoque "batteries included" significa que Django incluye por defecto muchas herramientas que en otros frameworks hay que instalar y configurar aparte:

HerramientaQué aporta
AdminPanel de administración generado automáticamente
ORMAcceso a la base de datos sin escribir SQL
AutenticaciónLogin, logout, permisos y grupos listos para usar
MigracionesGestión del esquema de la base de datos
PlantillasMotor de templates propio (DTL)
SeguridadProtección CSRF, XSS y SQL injection
InternacionalizaciónSoporte multi-idioma integrado
Otros frameworks como Flask o FastAPI son más ligeros, pero dejan la integración de admin, ORM y auth en manos de librerías de terceros.

1.4 Por qué usar Django

Ventajas principales

  • Rapidez de desarrollo: Muchas funcionalidades listas desde el primer día
  • Seguridad por defecto: La mayoría de vulnerabilidades web están mitigadas
  • Comunidad enorme: Documentación oficial excelente y miles de recursos
  • Escalabilidad: Proyectos como Instagram o Pinterest lo usan a gran escala
  • Versatilidad: Sirve para blogs, e-commerce, APIs REST, paneles y más
  • Mercado laboral: Alta demanda de desarrolladores Python/Django

Cuándo elegir Django

Ideal paraMenos indicado para
Sitios web completos con panel de administraciónAPIs ultra-livianas de un solo endpoint
Proyectos que requieren autenticación y rolesMicroservicios mínimos y aislados
Tareas de contenido intensivas (CMS, marketplaces)Realtime puro con WebSockets masivos

1.5 Diferencias entre Django y Flask

Comparativa

AspectoDjangoFlask
TipoFull-stackMicroframework
Admin Integrado No tiene
ORM IntegradoOpcional (SQLAlchemy)
Migraciones AutomáticasManuales (Alembic)
Auth IntegradoOpcional (Flask-Login)
Curva de aprendizajeMayorMás baja
EstructuraDefinida por convenciónTotalmente libre

Qué usa cada uno

  • Flask: Prototipos rápidos, APIs simples, servicios muy pequeños
  • Django: Aplicaciones completas que crecen con el tiempo y requieren admin
No hay un ganador absoluto: la elección depende de la complejidad del proyecto y de tu gusto por la libertad (Flask) o la estructura (Django).

Resumen

**Lo que aprendiste en esta sección:** - Django es un framework full-stack de Python con filosofía "batteries included" - Usa el patrón MVT: Model, View y Template - Incluye admin, ORM, autenticación y seguridad de serie - Es ideal para aplicaciones web completas que deben crecer - Flask es más ligero, pero requiere integrar más piezas a mano - Lo usan grandes empresas como Instagram, Pinterest y Spotify
