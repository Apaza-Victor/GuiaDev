1.1 Qué es Rails

Definición

Ruby on Rails (o simplemente Rails) es un framework de desarrollo web full-stack escrito en Ruby. Fue creado por David Heinemeier Hansson en 2004 y se basa en el principio de convención sobre configuración (CoC) para que los desarrolladores escriban menos código y hagan más.

Características principales

CaracterísticaDescripción
Convención sobre configuraciónRails asume convenciones por defecto para evitar configuración excesiva
DRYDon't Repeat Yourself: evita la duplicación de código
MVCArquitectura Modelo-Vista-Controlador integrada
Full-stackIncluye ORM, migraciones, vistas, rutas y más

1.2 Filosofía de Rails

Convención sobre configuración

En lugar de configurar cada detalle, Rails sigue convenciones establecidas. Si respetas las convenciones, Rails hace gran parte del trabajo por ti:

  • Una tabla products se mapea a un modelo Product
  • Una columna created_at se gestiona automáticamente
  • Un controlador ProductsController se asocia a un recurso /products

DRY (Don't Repeat Yourself)

Rails promueve la reutilización del código y la eliminación de repeticiones. Ejemplos:

  • Los partials reutilizan fragmentos de vistas
  • Los helpers centralizan lógica de presentación
  • Los concerns comparten lógica entre modelos

MVC (Modelo-Vista-Controlador)

CapaResponsabilidadEjemplo
ModeloLógica de negocio y datosProduct
VistaPresentación al usuarioapp/views/products/index.html.erb
ControladorRecibe peticiones y orquestaProductsController

1.3 Ventajas de Rails

Rapidez de desarrollo

Rails permite construir aplicaciones completas en muy poco tiempo gracias a los generadores y las convenciones:

rails new tienda
cd tienda
rails generate scaffold Producto nombre:string precio:decimal
rails db:migrate
rails server

Ventajas clave

VentajaDescripción
ProductividadMenos código para lograr lo mismo
Ecosistema maduroMiles de gemas disponibles
Testing integradoMiniTest incluido desde el inicio
Comunidad grandeMucha documentación y soporte
Filosofía pragmáticaEnfocado en resultados y buenas prácticas
SeguridadProtección integrada contra CSRF y XSS

Ejemplo: Generador de migración

rails generate migration AddPrecioToProductos precio:decimal
# db/migrate/20260101120000_add_precio_to_productos.rb
class AddPrecioToProductos < ActiveRecord::Migration[7.0]
  def change
    add_column :productos, :precio, :decimal
  end
end

Ejemplo: Modelo con validación

# app/models/producto.rb
class Producto < ApplicationRecord
  validates :nombre, presence: true, length: { maximum: 100 }
  validates :precio, numericality: { greater_than_or_equal_to: 0 }
  validates :sku, uniqueness: true
end

Ejemplo: Uso de Active Record

# Consultas con Active Record
productos = Producto.where("precio > 100").order(:nombre)

# Crear un registro
Producto.create(nombre: "Laptop", precio: 999.99)

# Buscar por id
producto = Producto.find(1)

# Actualizar
producto.update(precio: 899.99)

# Eliminar
producto.destroy
Rails incluye todas las gemas necesarias para construir una aplicación web completa sin dependencias externas obligatorias.

1.6 Estructura de Rails

Organización del proyecto

Un proyecto Rails generado con rails new tiene una estructura clara:

mi_app/
├── app/
│   ├── controllers/
│   ├── models/
│   ├── views/
│   ├── helpers/
│   └── jobs/
├── bin/
├── config/
│   ├── routes.rb
│   └── database.yml
├── db/
│   ├── migrate/
│   └── seeds.rb
├── test/
├── public/
└── Gemfile

Resumen

**Lo que aprendiste en esta sección:** - Rails es un framework full-stack escrito en Ruby creado en 2004 - Se basa en convención sobre configuración y DRY - Usa arquitectura MVC (Modelo-Vista-Controlador) - Es ideal para marketplaces, SaaS y e-commerce - Incluye Active Record, Action Cable, Action Mailer y más - Grandes empresas como GitHub y Shopify lo usan
