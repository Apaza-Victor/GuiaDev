8.1 Integrar Bootstrap en Rails

Al crear el proyecto

La forma más sencilla es crear el proyecto con Bootstrap desde el inicio:

rails new mi_app --css bootstrap
<!-- Dentro del layout el CSS ya está enlazado -->
<%= stylesheet_link_tag "application", "data-turbo-track": "reload" %>
<%= javascript_importmap_tags %>

Añadir Bootstrap a un proyecto existente

# Instalar la gema bootstrap
bundle add bootstrap

# Añadir la importación del Sass
rails css:install:bootstrap

Verificar que funciona

rails server

Abre http://localhost:3000 y comprueba que las clases de Bootstrap (por ejemplo btn btn-primary) se ven correctamente.

Con --css bootstrap, Rails configura el pipeline de CSS (dart-sass o importmap) y deja los estilos listos dentro de app/assets.

8.4 Formularios con Bootstrap

form_with con estilos Bootstrap

<!-- app/views/productos/new.html.erb -->
<h1>Nuevo producto</h1>

<%= form_with model: @producto, class: "row g-3" do |form| %>
  <% if @producto.errors.any? %>
    <div class="alert alert-danger">
      <h4>¡Revisa los errores!</h4>
      <ul>
        <% @producto.errors.full_messages.each do |msg| %>
          <li><%= msg %></li>
        <% end %>
      </ul>
    </div>
  <% end %>

  <div class="col-md-6">
    <%= form.label :nombre, class: "form-label" %>
    <%= form.text_field :nombre, class: "form-control" %>
  </div>

  <div class="col-md-6">
    <%= form.label :precio, class: "form-label" %>
    <%= form.number_field :precio, step: "0.01", class: "form-control" %>
  </div>

  <div class="col-12">
    <%= form.submit "Guardar", class: "btn btn-primary" %>
  </div>
<% end %>

Campos con validation-required en Bootstrap

<div class="mb-3">
  <%= form.label :nombre, class: "form-label" %>
  <%= form.text_field :nombre, class: "form-control", required: true %>
</div>

<div class="form-check">
  <%= form.check_box :publicado, class: "form-check-input" %>
  <%= form.label :publicado, class: "form-check-label" %>
</div>
Rails añade automáticamente la clase is-invalid en los formularios de error si configuras un helper, o puedes aplicar form-control para que Bootstrap lo estilice de forma consistente.

8.5 Helpers de Rails

Helpers más usados

HelperQué hace
number_to_currencyFormatea un número como moneda
truncateCorta un texto con puntos suspensivos
pluralizePluraliza una palabra según el número
link_toGenera un enlace con URL helper
content_tagCrea una etiqueta HTML con contenido
tagGenera etiquetas HTML simples

Ejemplos de uso

# app/helpers/productos_helper.rb
module ProductosHelper
  def precio_formateado(valor)
    number_to_currency(valor, unit: "S/", precision: 2)
  end

  def resumen(texto, largo = 80)
    truncate(texto, length: largo, separator: " ")
  end
end
<!-- Uso en la vista -->
<p>Precio: <%= precio_formateado(@producto.precio) %></p>
<p><%= resumen(@producto.descripcion) %></p>
<p><%= pluralize(@productos.count, "producto") %></p>

Helpers de enlaces y contenido

<%= link_to "Ver", producto_path(@producto), class: "btn" %>
<%= content_tag :span, "Nuevo", class: "badge bg-success" %>
<%= tag.strong "Importante" %>

8.6 Generadores de vistas y Stimulus

Generador de vistas

rails generate controller Productos index show new create
# Genera app/views/productos/index.html.erb, show.html.erb, etc.
# Ver las rutas asociadas
rails routes --controller productos

Uso de Stimulus para interactividad

Stimulus es el framework de JavaScript mínimo incluido por defecto en Rails 7+. Se conecta a elementos del DOM mediante atributos de datos:

<!-- Vista con controlador Stimulus -->
<div data-controller="contador" class="row align-items-center g-2">
  <div class="col-auto">
    <button data-action="click->contador#restar" class="btn btn-secondary">-</button>
  </div>
  <div class="col-auto">
    <span data-contador-target="valor" class="fs-4">0</span>
  </div>
  <div class="col-auto">
    <button data-action="click->contador#sumar" class="btn btn-primary">+</button>
  </div>
</div>
// app/javascript/controllers/contador_controller.js
import { Controller } from "@hotwired/stimulus"

export default class extends Controller {
  static targets = ["valor"]

  sumar() {
    this.valorTarget.textContent = parseInt(this.valorTarget.textContent) + 1
  }

  restar() {
    this.valorTarget.textContent = parseInt(this.valorTarget.textContent) - 1
  }
}
Combinar Bootstrap (estilos y componentes) con Stimulus (interactividad) cubre la mayoría de necesidades de una interfaz sin frameworks de JavaScript pesados.

Resumen

**Lo que aprendiste en esta sección:** - rails new --css bootstrap integra Bootstrap desde el inicio - Los layouts combinan navbar, grid y footer con clases Bootstrap - Los botones, cards y alertas se construyen con clases como btn y card - Los formularios usan form_with junto a form-control y form-label - Los helpers (number_to_currency, truncate, link_to) generan HTML - Stimulus añade interactividad mínima sin frameworks pesados
