2.1 Instalar Ruby

Instalación según el sistema operativo

SistemaMétodo de instalación
WindowsRubyInstaller
macOSrbenv o Homebrew
Linuxrbenv, RVM o apt

Instalar con rbenv en macOS/Linux

# Instalar rbenv
brew install rbenv ruby-build

# Instalar una versión de Ruby
rbenv install 3.2.2
rbenv global 3.2.2

# Verificar
ruby -v

Instalar en Windows con RubyInstaller

# Descargar RubyInstaller desde rubyinstaller.org
# Ejecutar el instalador y marcar la opción de MSYS2

# Verificar instalación
ruby -v
gem -v
Se recomienda usar un gestor de versiones como rbenv o RVM para poder cambiar entre versiones de Ruby según el proyecto.

2.2 RubyGems y Bundler

RubyGems

RubyGems es el gestor de paquetes de Ruby. Las gemas son bibliotecas que se instalan y se usan en tus proyectos:

# Instalar una gema
gem install rails

# Ver gemas instaladas
gem list

# Actualizar una gema
gem update rails

Bundler

Bundler gestiona las dependencias de un proyecto a partir del archivo Gemfile:

# Gemfile
source "https://rubygems.org"

ruby "3.2.2"

gem "rails", "~> 7.1"
gem "sqlite3"
gem "puma"
# Instalar las gemas del Gemfile
bundle install

# Ejecutar un comando con las gemas del proyecto
bundle exec rails server

Comandos útiles de Bundler

ComandoDescripción
bundle installInstala las gemas del Gemfile
bundle add gemaAñade una gema y la instala
bundle updateActualiza las gemas
bundle execEjecuta un comando con el entorno del proyecto

2.3 Crear un proyecto con rails new

Instalar Rails y crear el proyecto

# Instalar Rails
gem install rails

# Crear un nuevo proyecto
rails new mi_tienda

# Entrar en el directorio
cd mi_tienda

Opciones de rails new

OpciónDescripción
-d postgresqlUsa PostgreSQL como base de datos
--apiCrea un proyecto modo API
--skip-testOmite la estructura de testing
--skip-gitNo crea repositorio git
--css bootstrapConfigura Bootstrap desde el inicio

Ejemplo: Proyecto con PostgreSQL y Bootstrap

rails new blog -d postgresql --css bootstrap

cd blog

# Este comando crea la base de datos
rails db:create

# Iniciar el servidor
rails server

Carpetas clave y su función

CarpetaFunción

La convención MVC de Rails organiza el código de forma que cada capa vive en su propia carpeta, lo que facilita el mantenimiento y la escalabilidad.

2.5 Generadores de Rails

Tipos de generadores

Rails incluye generadores que crean código automáticamente según las convenciones:

# Generar un controlador
rails generate controller Bienvenidos index

# Generar un modelo con migración
rails generate model Producto nombre:string precio:decimal

# Generar scaffold completo (CRUD + vistas)
rails generate scaffold Cliente nombre:string email:string

# Generar una migración
rails generate migration AddStockToProductos stock:integer

Qué genera un scaffold

Archivo generadoDescripción
app/models/cliente.rbModelo con validaciones básicas
app/controllers/clientes_controller.rbControlador con las 7 acciones CRUD
app/views/clientes/*.erbVistas para index, new, edit, show
db/migrate/xxx_create_clientes.rbMigración para crear la tabla
test/*Tests del modelo y controlador
config/routes.rbRutas del recurso añadidas

Forma abreviada

# g y m son atajos
rails g controller Bienvenidos
rails g model Producto
rails g migration AddCampo

2.6 Iniciar el servidor (rails server)

Arrancar la aplicación

# Iniciar el servidor en localhost:3000
rails server

# Con puerto específico
rails server -p 4000

# En modo de desarrollo visible en la red
rails server -b 0.0.0.0

Verificar el proyecto

  • Abre http://localhost:3000 en tu navegador
  • Verás la página de bienvenida de Rails
  • Puedes seguir el flujo de trabajo indicado

El modo de desarrollo

En desarrollo, Rails recarga automáticamente los cambios de código sin reiniciar el servidor:

FunciónComportamiento
Recarga en calienteRefresca el código de la app automáticamente
Logs detalladosMuestra consultas SQL y errores en consola
Página de errorMuestra detalles de excepciones en el navegador
AssetsSirve JS y CSS sin precompilar
Rails tiene tres entornos: development, test y production. Usa RAILS_ENV=production rails server solo en producción real.

Resumen

**Lo que aprendiste en esta sección:** - Ruby se instala con RubyInstaller (Windows) o rbenv (macOS/Linux) - RubyGems y Bundler gestionan las gemas del proyecto - rails new crea un proyecto completo con estructura MVC - La estructura de carpetas organiza el código por capas - Los generadores crean controladores, modelos y scaffolds automáticamente - rails server inicia la aplicación en http://localhost:3000
