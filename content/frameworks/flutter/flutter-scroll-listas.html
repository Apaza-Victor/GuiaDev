1.1 ListView

¿Qué es ListView?

ListView es un widget que muestra una lista desplazable de elementos. Es uno de los widgets más usados en Flutter para mostrar colecciones de datos.

Formas de construir un ListView

TipoUso
ListView()Con hijos explícitos (lista estática)
ListView.builder()Con generador (lista dinámica y eficiente)
ListView.separated()Con separadores entre elementos

Ejemplo: ListView estática

import 'package:flutter/material.dart';

class ListaEstatica extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return ListView(
      children: [
        ListTile(
          leading: Icon(Icons.home),
          title: Text('Inicio'),
        ),
        ListTile(
          leading: Icon(Icons.person),
          title: Text('Perfil'),
        ),
        ListTile(
          leading: Icon(Icons.settings),
          title: Text('Configuración'),
        ),
      ],
    );
  }
}

1.2 ListView.builder

Listas dinámicas y eficientes

ListView.builder construye los elementos solo cuando son visibles. Es la opción recomendada para listas con muchos elementos, ya que es eficiente en memoria.

import 'package:flutter/material.dart';

class ListaDinamica extends StatelessWidget {
  final List<String> nombres = [
    'Ana', 'Carlos', 'Luis', 'María', 'Pedro',
    'Sofía', 'Javier', 'Lucía', 'Andrés', 'Valentina',
  ];

  @override
  Widget build(BuildContext context) {
    return ListView.builder(
      itemCount: nombres.length,
      itemBuilder: (context, indice) {
        return ListTile(
          leading: CircleAvatar(child: Text(nombres[indice][0])),
          title: Text(nombres[indice]),
          trailing: Icon(Icons.arrow_forward_ios, size: 16),
        );
      },
    );
  }
}

Parámetros clave

ParámetroDescripción
itemCountNúmero total de elementos
itemBuilderFunción que construye cada elemento según su índice
separatorBuilderConstruye separadores entre elementos (con separated)

1.3 GridView

¿Qué es GridView?

GridView muestra los elementos en una cuadrícula de varias columnas. Es ideal para galerías, catálogos de productos, etc.

import 'package:flutter/material.dart';

class Galeria extends StatelessWidget {
  final List<String> colores = [
    'FF0000', '00FF00', '0000FF', 'FFFF00',
    'FF00FF', '00FFFF', 'FFA500', '800080',
  ];

  @override
  Widget build(BuildContext context) {
    return GridView.builder(
      gridDelegate: SliverGridDelegateWithFixedCrossAxisCount(
        crossAxisCount: 2, // Número de columnas
        crossAxisSpacing: 8, // Separación horizontal
        mainAxisSpacing: 8, // Separación vertical
      ),
      itemCount: colores.length,
      itemBuilder: (context, indice) {
        return Container(
          color: Color(int.parse('0xFF${colores[indice]}')),
        );
      },
    );
  }
}

SliverGridDelegate

DelegateDescripción
SliverGridDelegateWithFixedCrossAxisCountNúmero fijo de columnas
SliverGridDelegateWithMaxCrossAxisExtentTamaño máximo de cada celda

1.4 onTap y callbacks

Interacción con elementos de la lista

Cada elemento de una lista puede responder a eventos de toque mediante callbacks como onTap.

import 'package:flutter/material.dart';

class ListaInteractiva extends StatelessWidget {
  final List<Map<String, dynamic>> productos = [
    {'nombre': 'Laptop', 'precio': 999.99},
    {'nombre': 'Mouse', 'precio': 29.99},
    {'nombre': 'Teclado', 'precio': 89.99},
  ];

  void _mostrarDetalle(context, producto) {
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(content: Text('Seleccionaste ${producto['nombre']}')),
    );
  }

  @override
  Widget build(BuildContext context) {
    return ListView.builder(
      itemCount: productos.length,
      itemBuilder: (context, indice) {
        final producto = productos[indice];
        return Card(
          child: ListTile(
            leading: Icon(Icons.shopping_bag),
            title: Text(producto['nombre']),
            subtitle: Text('\$${producto['precio']}'),
            trailing: Icon(Icons.chevron_right),
            onTap: () => _mostrarDetalle(context, producto),
          ),
        );
      },
    );
  }
}

Callbacks comunes

CallbackEvento
onTapToque corto
onLongPressMantener presionado
onDoubleTapDoble toque

1.5 Listas anidadas

Anidar listas y otros widgets

A veces necesitas combinar una lista con otros elementos, como encabezados, o anidar secciones. Para ello usa CustomScrollView o listas separadas.

// Combinar título con lista usando Column y Expanded
class PantallaConEncabezado extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Column(
      children: [
        // Encabezado fijo
        Padding(
          padding: EdgeInsets.all(16),
          child: Text(
            'Mis contactos',
            style: TextStyle(fontSize: 24, fontWeight: FontWeight.bold),
          ),
        ),
        // Lista desplazable
        Expanded(
          child: ListView.builder(
            itemCount: 20,
            itemBuilder: (context, indice) {
              return ListTile(
                leading: Icon(Icons.person),
                title: Text('Contacto $indice'),
                onTap: () {},
              );
            },
          ),
        ),
      ],
    );
  }
}

CustomScrollView con slivers

Para composiciones más avanzadas, CustomScrollView permite combinar encabezados fijos, listas y grids:

CustomScrollView(
  slivers: [
    SliverAppBar(
      title: Text('Tienda'),
      expandedHeight: 150,
    ),
    SliverList(
      delegate: SliverChildBuilderDelegate(
        (context, indice) => ListTile(
          leading: Icon(Icons.store),
          title: Text('Producto $indice'),
        ),
        childCount: 10,
      ),
    ),
    SliverGrid(
      gridDelegate: SliverGridDelegateWithFixedCrossAxisCount(crossAxisCount: 3),
      delegate: SliverChildBuilderDelegate(
        (context, indice) => Container(color: Colors.primaries[indice % 18]),
        childCount: 9,
      ),
    ),
  ],
)

1.6 Personalización de listas

Diseño avanzado de elementos

Puedes personalizar completamente cada elemento con Containers, Cards y otros widgets de layout.

import 'package:flutter/material.dart';

// Elemento de tarjeta personalizado
class TarjetaProducto extends StatelessWidget {
  final String nombre;
  final String imagen;
  final double precio;
  final VoidCallback onTap;

  TarjetaProducto({
    required this.nombre,
    required this.imagen,
    required this.precio,
    required this.onTap,
  });

  @override
  Widget build(BuildContext context) {
    return Card(
      elevation: 3,
      shape: RoundedRectangleBorder(
        borderRadius: BorderRadius.circular(12),
      ),
      child: InkWell(
        onTap: onTap,
        borderRadius: BorderRadius.circular(12),
        child: Padding(
          padding: EdgeInsets.all(12),
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.start,
            children: [
              // Imagen con esquinas redondeadas
              ClipRRect(
                borderRadius: BorderRadius.circular(8),
                child: Image.network(
                  imagen,
                  height: 120,
                  width: double.infinity,
                  fit: BoxFit.cover,
                ),
              ),
              SizedBox(height: 12),
              Text(
                nombre,
                style: TextStyle(fontWeight: FontWeight.bold, fontSize: 16),
              ),
              SizedBox(height: 4),
              Row(
                mainAxisAlignment: MainAxisAlignment.spaceBetween,
                children: [
                  Text(
                    '\$$precio',
                    style: TextStyle(
                      color: Colors.green,
                      fontWeight: FontWeight.bold,
                    ),
                  ),
                  Icon(Icons.add_shopping_cart, color: Colors.blue),
                ],
              ),
            ],
          ),
        ),
      ),
    );
  }
}

// Uso en GridView
class Catalogo extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return GridView.builder(
      padding: EdgeInsets.all(12),
      gridDelegate: SliverGridDelegateWithFixedCrossAxisCount(
        crossAxisCount: 2,
        childAspectRatio: 0.8,
        crossAxisSpacing: 12,
        mainAxisSpacing: 12,
      ),
      itemCount: 10,
      itemBuilder: (context, indice) {
        return TarjetaProducto(
          nombre: 'Producto $indice',
          imagen: 'https://via.placeholder.com/300',
          precio: 49.99 + indice,
          onTap: () {},
        );
      },
    );
  }
}

Buenas prácticas

  • Usa ListView.builder para listas largas
  • Extrae elementos complejos en widgets dedicados
  • Aprovecha Card y InkWell para interacción
  • Mantén los callbacks como parámetros para desacoplar

Resumen

**Lo que aprendiste en esta sección:** - ListView muestra listas desplazables de elementos - ListView.builder es eficiente para listas dinámicas grandes - GridView muestra elementos en cuadrícula - onTap y otros callbacks permiten interactuar con los elementos - Puedes combinar listas con otros widgets usando Expanded - CustomScrollView con slivers permite composiciones avanzadas
