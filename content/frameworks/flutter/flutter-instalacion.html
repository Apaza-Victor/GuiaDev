1.1 Requisitos previos

Sistema operativo

Flutter se puede instalar en Windows, macOS y Linux. Cada sistema tiene requisitos específicos:

SistemaRequisitos
WindowsWindows 10/11 (64-bit), PowerShell 5.0+, Git
macOSmacOS 10.14+, Xcode, CocoaPods
LinuxDebian/Ubuntu, clang, cmake, ninja-build

Herramientas necesarias

  • Git: Para descargar el SDK de Flutter
  • Editor de código: VS Code o Android Studio
  • Dispositivo o emulador: Para ejecutar la aplicación

Ejemplo: Verificar Git instalado

git --version
# git version 2.43.0.windows.1

---

1.2 Instalar Flutter SDK

Pasos de instalación en Windows

Descarga Flutter desde la página oficial y extrae el SDK en un directorio permanente:

# 1. Descargar Flutter SDK
git clone https://github.com/flutter/flutter.git -b stable

# 2. Agregar Flutter al PATH (PowerShell)
$env:PATH += ";C:\flutter\bin"

# 3. Verificar instalación
flutter doctor

Resultado de flutter doctor

Este comando verifica que todas las dependencias estén instaladas correctamente:

[✓] Flutter (Channel stable, 3.19.0)
[✓] Windows Version (11, 64-bit)
[✓] Android toolchain
[✓] Visual Studio
[✓] Android Studio
[✓] VS Code
[✓] Connected device

Verificar versión de Dart

# Dart viene incluido con Flutter
dart --version
# Dart SDK version: 3.3.0

1.3 Configurar el editor

VS Code

VS Code es el editor más popular para Flutter. Configúralo así:

  • Extensiones necesarias: Flutter, Dart
  • Atajos útiles: Ctrl+F5 (run), F5 (debug)
  • Configuración: Habilitar auto-save y formateo al guardar

Android Studio

Android Studio viene con soporte completo para Flutter:

  • Plugin de Flutter: Instalar desde Settings > Plugins
  • Plugin de Dart: Se instala automáticamente
  • Emulador: Crear dispositivo virtual desde AVD Manager

Ejemplo: Configuración de VS Code

// settings.json
{
  "dart.runPubGetOnSave": true,
  "dart.formatOnSave": true,
  "dart.lineLength": 80,
  "editor.suggestSelection": "first"
}

1.4 Crear el primer proyecto

Comando flutter create

Flutter genera automáticamente la estructura del proyecto con todos los archivos necesarios:

# Crear un nuevo proyecto
flutter create mi_primera_app

# Entrar al directorio
cd mi_primera_app

Estructura del proyecto generada

Carpeta/ArchivoDescripción
lib/main.dartArchivo principal de entrada
android/Configuración específica de Android
ios/Configuración específica de iOS
web/Configuración para web
test/Tests de la aplicación
pubspec.yamlDependencias y configuración

Ejemplo: Contenido de main.dart

import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Mi Primera App',
      theme: ThemeData(
        colorSchemeSeed: Colors.blue,
        useMaterial3: true,
      ),
      home: const MyHomePage(title: 'Mi Primera App'),
    );
  }
}

1.5 Ejecutar la aplicación

Comando flutter run

Para ejecutar la aplicación en un dispositivo o emulador:

# Ver dispositivos disponibles
flutter devices

# Ejecutar en el dispositivo específico
flutter run

# Ejecutar en Chrome (web)
flutter run -d chrome

# Ejecutar en Windows desktop
flutter run -d windows

Atajos en la consola durante ejecución

TeclaAcción
rHot Reload
RHot Restart
qSalir
dDetach (mantener ejecutando)

1.6 Estructura de carpetas

Estructura de un proyecto Flutter

Un proyecto Flutter tiene una estructura organizada para separar el código de cada plataforma:

CarpetaContenido
lib/Código fuente Dart (la más importante)
lib/main.dartPunto de entrada de la aplicación
lib/screens/Pantallas de la app (convención)
lib/widgets/Widgets reutilizables (convención)
lib/models/Modelos de datos (convención)
test/Tests unitarios y de widget

Ejemplo: Organización por carpetas

mi_primera_app/
├── lib/
│   ├── main.dart
│   ├── screens/
│   │   ├── home_screen.dart
│   │   └── login_screen.dart
│   ├── widgets/
│   │   ├── custom_button.dart
│   │   └── custom_text_field.dart
│   └── models/
│       └── user.dart
├── test/
│   └── widget_test.dart
├── android/
├── ios/
├── web/
└── pubspec.yaml

Archivo pubspec.yaml

Este archivo define las dependencias y configuración del proyecto:

name: mi_primera_app
description: Mi primera aplicación Flutter
version: 1.0.0+1

environment:
  sdk: '>=3.0.0 <4.0.0'

dependencies:
  flutter:
    sdk: flutter
  cupertino_icons: ^1.0.2

dev_dependencies:
  flutter_test:
    sdk: flutter
  flutter_lints: ^3.0.0

---

Resumen

**Lo que aprendiste en esta sección:** - Los requisitos previos para instalar Flutter incluyen Git y un editor de código - Flutter SDK se instala con git clone y se verifica con flutter doctor - Puedes usar VS Code o Android Studio como editor principal - flutter create genera automáticamente la estructura del proyecto - flutter run ejecuta la aplicación en dispositivos o emuladores - La estructura incluye lib/, test/, android/, ios/, web/ y pubspec.yaml
