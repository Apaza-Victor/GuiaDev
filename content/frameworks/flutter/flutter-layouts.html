1.1 Estructuras de layout

Widgets de layout principales

Flutter ofrece varios widgets para organizar los elementos en pantalla. Los más importantes son Row, Column, Stack y Expanded.

WidgetDirecciónUso
RowHorizontalElementos en línea
ColumnVerticalElementos apilados
StackSuperposiciónElementos encima de otros
ExpandedEspacio flexibleReparto proporcional del espacio

Ejemplo: Row y Column

import 'package:flutter/material.dart';

class LayoutBasico extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Column(
      mainAxisAlignment: MainAxisAlignment.center,
      children: [
        // Fila horizontal
        Row(
          mainAxisAlignment: MainAxisAlignment.spaceEvenly,
          children: [
            Icon(Icons.star, color: Colors.amber),
            Icon(Icons.favorite, color: Colors.red),
            Icon(Icons.thumb_up, color: Colors.blue),
          ],
        ),
        SizedBox(height: 20),
        // Columna vertical
        Text('Elemento 1'),
        Text('Elemento 2'),
        Text('Elemento 3'),
      ],
    );
  }
}

1.2 Row y Column

Row (fila horizontal)

Row coloca a sus hijos en una línea horizontal. Útil para elementos que van de izquierda a derecha.

Row(
  mainAxisAlignment: MainAxisAlignment.spaceBetween,
  children: [
    Text('Izquierda'),
    Text('Centro'),
    Text('Derecha'),
  ],
)

Column (columna vertical)

Column coloca a sus hijos de arriba hacia abajo. Ideal para listas o paneles.

Column(
  crossAxisAlignment: CrossAxisAlignment.start,
  children: [
    Text('Primer elemento'),
    Text('Segundo elemento'),
    Text('Tercer elemento'),
  ],
)

Propiedades de alineación

PropiedadOpcionesDescripción
mainAxisAlignmentstart, center, end, spaceBetween, spaceEvenlyAlineación en el eje principal
crossAxisAlignmentstart, center, end, stretchAlineación en el eje cruzado
mainAxisSizemin, maxTamaño en el eje principal

1.3 Stack

¿Qué es Stack?

Stack permite superponer widgets uno encima de otro. El primer hijo está al fondo, y los siguientes se apilan encima. Útil para overlays, badges, capas de diseño.

import 'package:flutter/material.dart';

class EjemploStack extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Stack(
      clipBehavior: Clip.none,
      children: [
        // Fondo: imagen o color
        Container(
          width: 200,
          height: 200,
          color: Colors.blueGrey,
        ),
        // Encima: un círculo
        Positioned(
          top: 20,
          left: 20,
          child: CircleAvatar(
            radius: 40,
            child: Text('Logo'),
          ),
        ),
        // Encima: badge
        Positioned(
          top: 10,
          right: 10,
          child: Container(
            padding: EdgeInsets.all(8),
            decoration: BoxDecoration(
              color: Colors.red,
              shape: BoxShape.circle,
            ),
            child: Text('3'),
          ),
        ),
      ],
    );
  }
}

Widget Positioned

Dentro de un Stack puedes usar Positioned para colocar elementos en coordenadas específicas:

  • top: Distancia desde arriba
  • bottom: Distancia desde abajo
  • left: Distancia desde la izquierda
  • right: Distancia desde la derecha

1.4 Expanded

¿Qué es Expanded?

Expanded hace que un widget dentro de un Row o Column ocupe todo el espacio disponible, repartiéndolo proporcionalmente entre las Expanded presentes.

import 'package:flutter/material.dart';

class EjemploExpanded extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Row(
      children: [
        // Ocupa 1 parte del espacio
        Expanded(
          flex: 1,
          child: Container(
            color: Colors.red,
            height: 100,
          ),
        ),
        // Widget fijo
        Container(
          width: 100,
          color: Colors.green,
        ),
        // Ocupa 2 partes del espacio
        Expanded(
          flex: 2,
          child: Container(
            color: Colors.blue,
            height: 100,
          ),
        ),
      ],
    );
  }
}

Propiedad flex

El parámetro flex determina la proporción del espacio que ocupa cada Expanded:

  • flex: 1: Ocupa 1 parte del espacio disponible
  • flex: 2: Ocupa 2 partes (el doble que flex: 1)
  • Sin flex: Todas las Expanded se reparten en partes iguales

1.5 Padding y EdgeInsets

Padding

Padding agrega espacio interno alrededor de un widget. Se usa para separar contenido del borde de su contenedor.

Padding(
  padding: EdgeInsets.all(16),
  child: Text('Contenido con padding'),
)

EdgeInsets

EdgeInsets define cuánto padding agregar en cada lado:

ConstructorEfecto
EdgeInsets.all(16)16px en los 4 lados
EdgeInsets.only(top: 8)Solo 8px arriba
EdgeInsets.symmetric(horizontal: 16)16px izquierda y derecha
EdgeInsets.fromLTRB(t,r,b,l)Valores individuales

Ejemplo: Combinar Padding y Container

Container(
  margin: EdgeInsets.all(12),
  decoration: BoxDecoration(
    color: Colors.blueGrey.shade50,
    borderRadius: BorderRadius.circular(8),
  ),
  padding: EdgeInsets.symmetric(horizontal: 16, vertical: 12),
  child: Text('Tarjeta con padding y margen'),
)

1.6 Alineación y diseño de interfaces

Controlando la alineación

Para alinear un solo widget dentro de un área, usa Center, Align o Align con Alignment.

// Centrar un widget
Center(child: Text('Centrado'))

// Alinear a una esquina
Align(
  alignment: Alignment.topRight,
  child: Text('Esquina superior derecha'),
)

// Alinear con coordenadas (-1 a 1)
Align(
  alignment: Alignment(0.5, 0.5),
  child: Text('Centrado con coordenadas'),
)

Ejemplo: Diseño completo de una pantalla

class DiseñoCompleto extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Padding(
        padding: EdgeInsets.all(16),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.stretch,
          children: [
            // Título
            Text(
              'Mi perfil',
              style: TextStyle(fontSize: 28, fontWeight: FontWeight.bold),
              textAlign: TextAlign.center,
            ),
            SizedBox(height: 24),
            // Avatar centrado
            Center(
              child: CircleAvatar(
                radius: 40,
                child: Icon(Icons.person, size: 50),
              ),
            ),
            SizedBox(height: 24),
            // Nombre
            Text(
              'Ana García',
              style: TextStyle(fontSize: 22),
              textAlign: TextAlign.center,
            ),
            SizedBox(height: 8),
            Text(
              'Desarrolladora Flutter',
              style: TextStyle(color: Colors.grey),
              textAlign: TextAlign.center,
            ),
            SizedBox(height: 32),
            // Estadísticas con Expanded
            Row(
              children: [
                Expanded(
                  child: _Estadistica(valor: '12', etiqueta: 'Proyectos'),
                ),
                Expanded(
                  child: _Estadistica(valor: '98', etiqueta: 'GitHub'),
                ),
                Expanded(
                  child: _Estadistica(valor: '150', etiqueta: 'Seguidores'),
                ),
              ],
            ),
          ],
        ),
      ),
    );
  }
}

// Widget reutilizable de estadística
class _Estadistica extends StatelessWidget {
  final String valor;
  final String etiqueta;

  _Estadistica({required this.valor, required this.etiqueta});

  @override
  Widget build(BuildContext context) {
    return Card(
      child: Padding(
        padding: EdgeInsets.all(12),
        child: Column(
          children: [
            Text(
              valor,
              style: TextStyle(fontSize: 24, fontWeight: FontWeight.bold),
            ),
            Text(etiqueta, style: TextStyle(color: Colors.grey)),
          ],
        ),
      ),
    );
  }
}

Buenas prácticas de diseño

  • Usa EdgeInsets en lugar de valores hardcodeados
  • Extrae secciones en widgets privados
  • Usa Expanded para layouts responsivos
  • Mantén un espaciado consistente con SizedBox

Resumen

**Lo que aprendiste en esta sección:** - Row dispone hijos horizontalmente y Column verticalmente - Stack superpone widgets uno sobre otro - Expanded reparte el espacio disponible flexiblemente - Padding y EdgeInsets controlan el espaciado interno - Center y Align controlan la posición de un widget - Combinando estos widgets puedes crear interfaces completas
