1.1 Qué es Flutter

Definición

Flutter es un SDK de UI de código abierto de Google para la creación de aplicaciones nativas para Android, iOS, Linux, macOS, Windows y web a partir de una única base de código. Está escrito en el lenguaje de programación Dart.

Características principales

CaracterísticaDescripción
MultiplataformaUna sola base de código para múltiples plataformas
Hot ReloadRecarga instantánea de cambios sin perder estado
Widgets personalizadosConstruye UI con componentes reutilizables
Rendimiento nativoCompila a código ARM nativo
Gratuito y open sourceSin costos de licencia

Ejemplo: Widget básico

import 'package:flutter/material.dart';

void main() => runApp(MiApp());

class MiApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(title: Text('Mi primera app')),
        body: Center(child: Text('¡Hola, Flutter!')),
      ),
    );
  }
}

1.2 Lenguaje Dart

¿Qué es Dart?

Dart es un lenguaje de programación optimizado para la construcción de aplicaciones en múltiples plataformas. Es el lenguaje que usa Flutter para desarrollar aplicaciones.

Características de Dart

CaracterísticaDescripción
Tipado estáticoLos tipos se verifican en tiempo de compilación
Orientado a objetosBasado en clases con herencia
Sintaxis familiarParecido a Java, C# y JavaScript
Soporte asyncasync/await y Futures integrados
Null safetyProtección contra errores de null

Ejemplo: Sintaxis básica de Dart

// Variables
String nombre = 'Ana';
int edad = 25;
double precio = 19.99;
bool activo = true;

// Función
String saludar(String nombre) {
  return 'Hola, $nombre';
}

// Clase
class Persona {
  String nombre;
  int edad;

  Persona(this.nombre, this.edad);

  String describir() => '$nombre tiene $edad años';
}

1.3 Compilación nativa y multiplataforma

Modelo de compilación

Flutter compila tu código de diferentes maneras según la plataforma destino:

PlataformaTipo de compilación
iOSARM nativo (compilación AOT)
AndroidARM nativo (compilación AOT)
WebJavaScript/WebAssembly
DesktopCompilación nativa

Ventajas de la compilación nativa

  • Rendimiento superior: Ejecución directa en hardware nativo
  • Sin dependencia de intérpretes: No necesita un runtime pesado
  • Arranque rápido: Tiempo de inicio reducido
  • Uso eficiente de memoria: Optimizado para cada plataforma

Ejemplo: Target de compilación

// Compilar para Android (debug)
flutter run --target-platform android

// Compilar para iOS (release)
flutter build ios --release

// Compilar para web
flutter build web

// Compilar para Windows desktop
flutter build windows

1.5 Hot Reload

¿Qué es Hot Reload?

Hot Reload es una de las características más poderosas de Flutter. Permite ver los cambios en la UI casi instantáneamente sin perder el estado de la aplicación.

Cómo funciona

OperaciónResultado
Hot ReloadInyecta código compilado sin reiniciar
Hot RestartReinicia la app desde cero
Full RestartRecompila y reinicia todo

Cuándo usar cada uno

  • Hot Reload: Cambios en UI, widgets, colores, estilos
  • Hot Restart: Cambios en estado o inicialización
  • Full Restart: Cambios en main() o configuración

Ejemplo: Diferencia entre Hot Reload y Hot Restart

// Cambios que funcionan con Hot Reload:
// - Modificar propiedades de widgets
// - Cambiar textos, colores, márgenes
// - Agregar nuevos widgets al árbol

// Cambios que requieren Hot Restart:
// - Modificar variables globales
// - Cambiar el estado inicial de la app
// - Modificar main()
