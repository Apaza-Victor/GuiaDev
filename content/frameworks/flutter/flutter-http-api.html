1.1 Paquete http

¿Qué es el paquete http?

http es el paquete oficial de Dart para realizar peticiones HTTP. Permite hacer GET, POST, PUT y DELETE a servidores web.

Instalación

Agrega la dependencia a tu archivo pubspec.yaml:

dependencies:
  flutter:
    sdk: flutter
  http: ^1.1.0

Luego ejecuta flutter pub get para instalar.

Ejemplo: Petición GET básica

import 'package:http/http.dart' as http;

Future<void> obtenerDatos() async {
  final url = Uri.parse('https://jsonplaceholder.typicode.com/posts');
  final respuesta = await http.get(url);

  if (respuesta.statusCode == 200) {
    print('Datos obtenidos: ${respuesta.body}');
  } else {
    print('Error: ${respuesta.statusCode}');
  }
}

1.3 Peticiones GET y POST

Petición GET

GET se usa para obtener datos del servidor. No modifica el estado del servidor.

import 'dart:convert';
import 'package:http/http.dart' as http;

Future<List<dynamic>> obtenerUsuarios() async {
  final url = Uri.parse('https://api.example.com/usuarios');
  final respuesta = await http.get(url);

  if (respuesta.statusCode == 200) {
    // Decodificar el JSON
    final datos = jsonDecode(respuesta.body) as List;
    return datos;
  } else {
    throw Exception('Error al obtener usuarios: ${respuesta.statusCode}');
  }
}

Petición POST

POST se usa para enviar datos al servidor y crear recursos.

Future<Map<String, dynamic>> crearUsuario(String nombre, String email) async {
  final url = Uri.parse('https://api.example.com/usuarios');
  final respuesta = await http.post(
    url,
    headers: {'Content-Type': 'application/json'},
    body: jsonEncode({
      'nombre': nombre,
      'email': email,
    }),
  );

  if (respuesta.statusCode == 201) {
    return jsonDecode(respuesta.body) as Map<String, dynamic>;
  } else {
    throw Exception('Error al crear usuario: ${respuesta.statusCode}');
  }
}

1.4 FutureBuilder

¿Qué es FutureBuilder?

FutureBuilder es un widget que se conecta a un Future (una operación asíncrona) y reconstruye su contenido según el estado del Future (esperando, error, éxito).

import 'dart:convert';
import 'package:flutter/material.dart';
import 'package:http/http.dart' as http;

class PantallaUsuarios extends StatefulWidget {
  @override
  _PantallaUsuariosState createState() => _PantallaUsuariosState();
}

class _PantallaUsuariosState extends State<PantallaUsuarios> {
  late Future<List<Usuario>> _futureUsuarios;

  @override
  void initState() {
    super.initState();
    _futureUsuarios = _cargarUsuarios();
  }

  Future<List<Usuario>> _cargarUsuarios() async {
    final url = Uri.parse('https://jsonplaceholder.typicode.com/users');
    final respuesta = await http.get(url);
    final datos = jsonDecode(respuesta.body) as List;

    return datos.map((item) => Usuario.fromJson(item)).toList();
  }

  @override
  Widget build(BuildContext context) {
    return FutureBuilder<List<Usuario>>(
      future: _futureUsuarios,
      builder: (context, snapshot) {
        if (snapshot.connectionState == ConnectionState.waiting) {
          // Mientras carga
          return Center(child: CircularProgressIndicator());
        }

        if (snapshot.hasError) {
          // Si hay error
          return Center(
            child: Text('Error: ${snapshot.error}'),
          );
        }

        // Cuando hay datos
        final usuarios = snapshot.data ?? [];
        return ListView.builder(
          itemCount: usuarios.length,
          itemBuilder: (context, indice) {
            return ListTile(
              leading: CircleAvatar(
                child: Text(usuarios[indice].nombre[0]),
              ),
              title: Text(usuarios[indice].nombre),
              subtitle: Text(usuarios[indice].email),
            );
          },
        );
      },
    );
  }
}

class Usuario {
  final String nombre;
  final String email;

  Usuario({required this.nombre, required this.email});

  factory Usuario.fromJson(Map<String, dynamic> json) {
    return Usuario(
      nombre: json['name'],
      email: json['email'],
    );
  }
}

1.5 Decodificación JSON

Parsear JSON en Dart

Para convertir JSON en objetos Dart, usas jsonDecode y luego creas tus modelos con fábricas (factory constructor).

Ejemplo: Modelo con fromJson

import 'dart:convert';

// Modelo
class Producto {
  final int id;
  final String nombre;
  final double precio;
  final bool disponible;

  Producto({
    required this.id,
    required this.nombre,
    required this.precio,
    required this.disponible,
  });

  // Crear una instancia desde un Map JSON
  factory Producto.fromJson(Map<String, dynamic> json) {
    return Producto(
      id: json['id'],
      nombre: json['nombre'],
      precio: (json['precio'] as num).toDouble(),
      disponible: json['disponible'],
    );
  }

  // Convertir a Map para enviar
  Map<String, dynamic> toJson() {
    return {
      'id': id,
      'nombre': nombre,
      'precio': precio,
      'disponible': disponible,
    };
  }
}

// Uso
void procesarProductos(String respuestaJson) {
  // JSON es una lista de objetos
  final datos = jsonDecode(respuestaJson) as List;

  // Convertir cada elemento a Producto
  final productos = datos
      .map((item) => Producto.fromJson(item as Map<String, dynamic>))
      .toList();

  for (final producto in productos) {
    print('${producto.nombre} - \$${producto.precio}');
  }
}

Métodos de la librería convert

MétodoFunción
jsonDecode(texto)Convierte JSON string a objetos Dart
jsonEncode(objeto)Convierte objetos Dart a JSON string

1.6 Consumo de APIs REST

Estructura completa de consumo

Organiza tu código de consumo de APIs en servicios separados para mantener limpia la separación de responsabilidades.

import 'dart:convert';
import 'package:http/http.dart' as http;

// Servicio de API
class ApiServicio {
  static const String baseUrl = 'https://api.example.com';
  static const headers = {'Content-Type': 'application/json'};

  // GET: Obtener todos
  Future<List<Producto>> obtenerProductos() async {
    final url = Uri.parse('$baseUrl/productos');
    final respuesta = await http.get(url, headers: headers);

    if (respuesta.statusCode == 200) {
      final datos = jsonDecode(respuesta.body) as List;
      return datos.map((e) => Producto.fromJson(e)).toList();
    }
    throw Exception('Error al obtener productos');
  }

  // GET: Obtener uno
  Future<Producto> obtenerProducto(int id) async {
    final url = Uri.parse('$baseUrl/productos/$id');
    final respuesta = await http.get(url, headers: headers);

    if (respuesta.statusCode == 200) {
      return Producto.fromJson(jsonDecode(respuesta.body));
    }
    throw Exception('Producto no encontrado');
  }

  // POST: Crear
  Future<Producto> crearProducto(Producto producto) async {
    final url = Uri.parse('$baseUrl/productos');
    final respuesta = await http.post(
      url,
      headers: headers,
      body: jsonEncode(producto.toJson()),
    );

    if (respuesta.statusCode == 201) {
      return Producto.fromJson(jsonDecode(respuesta.body));
    }
    throw Exception('Error al crear producto');
  }

  // PUT: Actualizar
  Future<Producto> actualizarProducto(int id, Producto producto) async {
    final url = Uri.parse('$baseUrl/productos/$id');
    final respuesta = await http.put(
      url,
      headers: headers,
      body: jsonEncode(producto.toJson()),
    );

    if (respuesta.statusCode == 200) {
      return Producto.fromJson(jsonDecode(respuesta.body));
    }
    throw Exception('Error al actualizar producto');
  }

  // DELETE: Eliminar
  Future<void> eliminarProducto(int id) async {
    final url = Uri.parse('$baseUrl/productos/$id');
    final respuesta = await http.delete(url, headers: headers);

    if (respuesta.statusCode != 204) {
      throw Exception('Error al eliminar producto');
    }
  }
}

Manejo de errores

// Captura de errores en la UI
Future _cargar() async {
  try {
    final productos = await ApiServicio().obtenerProductos();
    setState(() {

Resumen

**Lo que aprendiste en esta sección:** - El paquete http es la opción oficial para peticiones HTTP - dio ofrece funciones avanzadas como interceptores y cancelación - GET obtiene datos y POST crea recursos en el servidor - FutureBuilder conecta un Future a la UI con estados de carga y error - jsonDecode y jsonEncode transforman entre JSON y objetos Dart - Organiza el consumo de APIs en servicios separados
