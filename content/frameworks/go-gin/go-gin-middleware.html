4.1 Qué es middleware

Definición

Un middleware es una función que se ejecuta antes o después de un handler. Permite agregar funcionalidades transversales como autenticación, logging, compresión y protección contra errores sin repetir código en cada handler.

Flujo de ejecución

Cliente -> Request -> Middleware 1 -> Middleware 2 -> Handler -> Response -> Cliente
               ^                                        |
               +------------- c.Next() -----------------+

Firma de un middleware

func miMiddleware() gin.HandlerFunc {
    return func(c *gin.Context) {
        // Código ANTES de llegar al handler
        // Ej: registrar la hora de inicio

        c.Next()  // Continúa con el siguiente middleware/handler

        // Código DESPUÉS de ejecutarse el handler
        // Ej: registrar la duración
    }
}

Funciones clave

FunciónDescripción
c.Next()Pasa el control al siguiente middleware o handler
c.Abort()Detiene la cadena y termina la respuesta
c.AbortWithStatusJSON()Aborta y responde JSON con un código de estado
c.Set()Guarda datos en el contexto para el siguiente handler
c.Get()Recupera datos guardados en el contexto

4.2 Middleware global

Uso global

Un middleware global se aplica a todas las rutas del router:

r := gin.New()

// Logger: registra cada request
r.Use(gin.Logger())

// Recovery: captura panics y devuelve 500
r.Use(gin.Recovery())

// Middleware del router (solo para un router específico)
router.Use(miMiddleware())

// Middleware global (aplica a todos los routers)
gin.SetMode(gin.ReleaseMode)

Middleware personalizado global

// middleware/request_id.go
package middleware

import (
    "github.com/google/uuid"
    "github.com/gin-gonic/gin"
)

func RequestID() gin.HandlerFunc {
    return func(c *gin.Context) {
        c.Set("request_id", uuid.New().String())
        c.Next()
    }
}

func main() {
    r := gin.New()
    r.Use(gin.Recovery())
    r.Use(RequestID())
    r.GET("/", func(c *gin.Context) {
        id, _ := c.Get("request_id")
        c.JSON(200, gin.H{"request_id": id})
    })
    r.Run(":8080")
}

Orden de ejecución

Los middlewares se ejecutan en el orden en que se registran con Use. Para la misma ruta, se ejecutan en el orden definido.

4.3 Middleware por grupo

Aplicar a grupos específicos

Es la forma más común de proteger rutas: el middleware de autenticación solo se aplica a ciertos grupos:

r := gin.Default()

// Rutas públicas (sin auth)
api := r.Group("/api")
{
    api.POST("/login", loginHandler)
    api.POST("/registro", registroHandler)
}

// Rutas protegidas (con auth)
protegido := r.Group("/api/protegido", requireAuth())
{
    protegido.GET("/perfil", perfilHandler)
    protegido.GET("/config", configHandler)
}

// También se puede agregar después de crear el grupo
privado := r.Group("/api/privado")
privado.Use(requireAuth(), requireAdmin())
{
    privado.GET("/admin", adminHandler)
}

Middleware con parámetros

// Middleware factory con configuración
func limitadorPorIp(maxRequests int) gin.HandlerFunc {
    return func(c *gin.Context) {
        c.Set("max_requests", maxRequests)
        c.Next()
    }
}

r := gin.Default()
r.Use(limitadorPorIp(100))

4.4 CORS

Qué es CORS

CORS (Cross-Origin Resource Sharing) controla qué dominios pueden acceder a tu API desde el navegador. Sin configuración CORS, los navegadores bloquean peticiones entre dominios distintos.

Instalación del middleware

go get github.com/gin-contrib/cors

Configuración

package main

import (
    "github.com/gin-gonic/gin"
    "github.com/gin-contrib/cors"
)

func main() {
    r := gin.Default()

    // Configuración permitida (todas las origenes)
    r.Use(cors.Default())

    // Configuración personalizada
    r.Use(cors.New(cors.Config{
        AllowOrigins:     []string{"https://miapp.com", "http://localhost:3000"},
        AllowMethods:     []string{"GET", "POST", "PUT", "PATCH", "DELETE", "OPTIONS"},
        AllowHeaders:     []string{"Origin", "Content-Type", "Authorization"},
        ExposeHeaders:    []string{"Content-Length"},
        AllowCredentials: true,
        MaxAge:           12 * 3600, // Caché de la preflight (horas en segundos)
    }))

    r.GET("/", func(c *gin.Context) {
        c.JSON(200, gin.H{"mensaje": "CORS configurado"})
    })
    r.Run(":8080")
}

Alternativa manual

func corsMixto() gin.HandlerFunc {
    return func(c *gin.Context) {
        c.Header("Access-Control-Allow-Origin", "*")
        c.Header("Access-Control-Allow-Methods", "GET, POST, PUT, DELETE, OPTIONS")
        c.Header("Access-Control-Allow-Headers", "Content-Type, Authorization")
        if c.Request.Method == "OPTIONS" {
            c.AbortWithStatus(204)
            return
        }
        c.Next()
    }
}
No uses cors.Default() en producción sin restringir las origenes. Permitir cualquier origen (*) puede ser un riesgo de seguridad.

4.5 Logging y panic recovery

gin.Logger()

Genera un log por cada request con método, ruta, status, latencia y IP. Puedes personalizar su formato:

r := gin.Default()

// Formato personalizado
r.Use(gin.LoggerWithFormatter(func(param gin.LogFormatterParams) string {
    return log.Printf("[%s] %s %s - %d - %s\n",
        param.TimeStamp.Format("2006-01-02 15:04:05"),
        param.Method,
        param.Path,
        param.StatusCode,
        param.Latency,
    )
}))

gin.Recovery()

Captura panics (errores que detendrían el programa) y devuelve un error 500 sin matar el proceso:

r.Use(gin.Recovery())

Logger personalizado

func registroTiempo() gin.HandlerFunc {
    return func(c *gin.Context) {
        inicio := time.Now()
        c.Next()
        latencia := time.Since(inicio)
        c.Header("X-Latencia", latencia.String())
        fmt.Printf("%s %s en %s\n", c.Request.Method, c.Request.URL.Path, latencia)
    }
}

Manejo de errores global

r := gin.New()
r.Use(gin.Recovery())
r.Use(gin.ErrorLoggerT(gin.ErrorTypePrivate))

r.GET("/panico", func(c *gin.Context) {
    // Si algo lanza un panic aqui, Recovery lo captura
    panic("error inesperado")
})

4.6 Ejemplo práctico

Middleware aplicados juntos

package main

import (
    "fmt"
    "time"
    "net/http"
    "github.com/gin-gonic/gin"
    "github.com/gin-contrib/cors"
)

func latencia() gin.HandlerFunc {
    return func(c *gin.Context) {
        inicio := time.Now()
        c.Next()
        fmt.Printf("Latencia: %s\n", time.Since(inicio))
    }
}

func autenticar() gin.HandlerFunc {
    return func(c *gin.Context) {
        token := c.GetHeader("Authorization")
        if token == "" {
            c.AbortWithStatusJSON(http.StatusUnauthorized, gin.H{
                "error": "token requerido",
            })
            return
        }
        c.Set("usuario", "juan")
        c.Next()
    }
}

func main() {
    r := gin.Default()

    // Middleware global
    r.Use(latencia())
    r.Use(cors.Default())

    // Rutas públicas
    r.POST("/login", func(c *gin.Context) {
        c.JSON(200, gin.H{"mensaje": "inicia sesión"})
    })

    // Grupo con middleware de auth
    privado := r.Group("/api", autenticar())
    {
        privado.GET("/perfil", func(c *gin.Context) {
            usuario, _ := c.Get("usuario")
            c.JSON(200, gin.H{"usuario": usuario})
        })
    }

    r.Run(":8080")
}

Probar flujo

ComandoResultado
curl http://localhost:8080/api/perfil401 sin token
curl -H "Authorization: Bearer abc" http://localhost:8080/api/perfil200 con usuario
Los middlewares bien diseñados eliminan la duplicación de código y centralizan la lógica transversal de tu aplicación.

---

Resumen

**Lo que aprendiste:** - El middleware ejecuta código antes y después de los handlers - c.Next() continúa la cadena; c.Abort() la detiene - Los middleware globales se registran con r.Use() - Los middleware por grupo protegen subsets específicos de rutas - CORS se configura con gin-contrib/cors - gin.Recovery() evita que los panics detengan el servidor
