10.1 go build: el binario

Compilar para producción

go build genera un único binario ejecutable sin dependencias externas. Go compila directamente a código de máquina, por lo que no necesitas instalar Go ni gestionar librerías en el servidor de destino.

# Compilar en el directorio actual
go build

# Nombre del binario personalizado
go build -o mi-api

# Reducir el tamaño (quitar símbolos de depuración)
go build -ldflags="-s -w" -o mi-api

# Compilar para otra arquitectura (cross-compiling)
GOOS=linux GOARCH=amd64 go build -o mi-api-linux
GOOS=windows GOARCH=amd64 go build -o mi-api.exe
GOOS=darwin GOARCH=amd64 go build -o mi-api-mac

Binarios por plataforma

VariableValorResultado
GOOSlinuxBinario para GNU/Linux
GOOSwindowsBinario para Windows (.exe)
GOOSdarwinBinario para macOS
GOARCHamd64 / arm64Arquitectura de 64 bits

Verificar el binario

# Ejecutar el binario en el servidor
./mi-api

# Ver el tamaño del archivo
ls -lh mi-api
# Normalmente menos de 20 MB para una API Gin
Un binario Go es estático: no requiere un runtime, dependencias ni instalar nada en el servidor. Solo lo copias y lo ejecutas.

# 3. Ejecutar (preferiblemente con un daemon/systemd)

Servicio con systemd

# /etc/systemd/system/mi-api.service
[Unit]
Description=API Gin
After=network.target

[Service]
WorkingDirectory=/opt/mi-api
ExecStart=/opt/mi-api/mi-api
Restart=always
User=www-data
EnvironmentFile=/opt/mi-api/.env

[Install]
WantedBy=multi-user.target
# Activar el servicio
sudo systemctl daemon-reload
sudo systemctl enable --now mi-api
sudo systemctl status mi-api
sudo journalctl -u mi-api -f  # ver logs
Usa un reverse proxy (Nginx/Caddy) delante de Gin para TLS/SSL, HTTP/2 y balanceo de carga. Gin escucha en 127.0.0.1:8080 y Nginx reenvía el tráfico.

10.3 Variables de entorno

os.Getenv()

Las variables de entorno guardan configuración sensible (claves, conexiones, puertos) fuera del código. Se leen con os.Getenv():

import (
    "os"
)

func main() {
    // Leer con valor por defecto
    puerto := os.Getenv("PORT")
    if puerto == "" {
        puerto = "8080"
    }

    // Forma compacta con default
    puerto = getEnv("PORT", "8080")
    modo := getEnv("GIN_MODE", "release")
}

func getEnv(clave, porDefecto string) string {
    if v := os.Getenv(clave); v != "" {
        return v
    }
    return porDefecto
}

Variables típicas de una API

VariableUso
PORTPuerto en que escucha el servidor
GIN_MODEdebug o release
DATABASE_URLCadena de conexión a la base de datos
JWT_SECRETClave secreta para firmar tokens
ALLOWED_ORIGINSOrígenes permitidos para CORS

Archivo .env

# .env (nunca commits en git)
PORT=8080
GIN_MODE=release
DEBUG=false
JWT_SECRET=cambiar_por_un_valor_largo_y_seguro
# Cargar en Linux (desde systemd o script)
set -a; source .env; set +a
./mi-api
Nunca subas claves ni secretos a un repositorio. Agrega .env a tu .gitignore y usa variables de entorno o un gestor de secretos (SOPS, Vault, secrets de la plataforma).

10.4 Docker

Dockerfile de una API Go

Docker empaqueta la aplicación con su entorno en un contenedor reproducible. Go es ideal porque produce binarios estáticos pequeños.

# Dockerfile
# Etapa 1: compilar
FROM golang:1.22 AS build
WORKDIR /app
COPY go.mod go.sum ./
RUN go mod download
COPY . .
RUN CGO_ENABLED=0 GOOS=linux go build -ldflags="-s -w" -o mi-api .

# Etapa 2: imagen final mínima
FROM alpine:latest
RUN adduser -D appuser
WORKDIR /app
COPY --from=build /app/mi-api .
COPY --from=build /app/.env .env
USER appuser
EXPOSE 8080
CMD ["./mi-api"]

Construir y ejecutar

# Construir la imagen
docker build -t mi-api .

# Ejecutar con variables de entorno
docker run -p 8080:8080 --env-file .env mi-api

# Ejecutar en modo detached
docker run -d --name api -p 8080:8080 --restart unless-stopped mi-api

# Ver logs del contenedor
docker logs -f api

docker-compose.yml

version: "3.9"

services:
  api:
    build: .
    ports:
      - "8080:8080"
    env_file:
      - .env
    restart: unless-stopped
El CGO_ENABLED=0 desactiva el binding con C, lo que produce un binario totalmente estático que funciona en casi cualquier imagen base (como alpine).

10.5 Testing con httptest

httptest

La standard library net/http/httptest permite probar handlers de Gin sin levantar un servidor real. Es rápido y no requiere conexiones de red:

// main_test.go
package main

import (
    "bytes"
    "encoding/json"
    "net/http"
    "net/http/httptest"
    "testing"
)

func TestApiSaludo(t *testing.T) {
    // Crear el router
    r := gin.Default()
    r.GET("/saludo", func(c *gin.Context) {
        c.JSON(200, gin.H{"mensaje": "hola"})
    })

    // Simular una petición GET
    req := httptest.NewRequest("GET", "/saludo", nil)
    w := httptest.NewRecorder()
    r.ServeHTTP(w, req)

    // Verificar el código de estado
    if w.Code != http.StatusOK {
        t.Errorf("se esperaba 200, se obtuvo %d", w.Code)
    }

    // Verificar el cuerpo
    var resp map[string]string
    json.Unmarshal(w.Body.Bytes(), &resp)
    if resp["mensaje"] != "hola" {
        t.Errorf("mensaje inesperado: %v", resp)
    }
}

Probar un POST con JSON

func TestCrearUsuario(t *testing.T) {
    r := gin.Default()
    r.POST("/usuarios", crearUsuarioHandler)

    cuerpo := `{"nombre":"Ana","email":"ana@mail.com"}`
    req := httptest.NewRequest(
        "POST", "/usuarios", bytes.NewBufferString(cuerpo),
    )
    req.Header.Set("Content-Type", "application/json")
    w := httptest.NewRecorder()
    r.ServeHTTP(w, req)

    if w.Code != http.StatusCreated {
        t.Errorf("se esperaba 201, se obtuvo %d: %s", w.Code, w.Body.String())
    }
}

Tabla de casos de prueba

func TestValidacionUsuario(t *testing.T) {
    casos := []struct {
        nombre   string
        cuerpo   string
        esperado int
    }{
        {"datos válidos", `{"nombre":"Ana","email":"ana@mail.com"}`, 201},
        {"sin nombre", `{"email":"ana@mail.com"}`, 400},
        {"email inválido", `{"nombre":"Ana","email":"no-es-email"}`, 400},
        {"cuerpo vacío", `{}`, 400},
    }

    r := gin.Default()
    r.POST("/usuarios", crearUsuarioHandler)

    for _, c := range casos {
        t.Run(c.nombre, func(t *testing.T) {
            req := httptest.NewRequest("POST", "/usuarios",
                bytes.NewBufferString(c.cuerpo))
            req.Header.Set("Content-Type", "application/json")
            w := httptest.NewRecorder()
            r.ServeHTTP(w, req)
            if w.Code != c.esperado {
                t.Errorf("%s: se esperaba %d, se obtuvo %d",
                    c.nombre, c.esperado, w.Code)
            }
        })
    }
}

Ejecutar las pruebas

# Probar todos los paquetes
go test ./...

# Probar con cobertura
go test -cover ./...

# Probar una función específica
go test -run TestCrearUsuario -v

10.6 Buenas prácticas

Configuración del modo producción

func main() {
    // Modo release (sin logs de debug)
    gin.SetMode(gin.ReleaseMode)
    // O mediante variable de entorno
    // GIN_MODE=release ./mi-api
}

Guía de buenas prácticas

ÁreaRecomendación
SeguridadSecretos en variables de entorno, HTTPS, headers de seguridad
RendimientoCompilar con -ldflags="-s -w", usar modo release
ConfiguraciónPuerto y claves configurables, nunca hardcodear
ErroresLoggear con contexto, responder JSON consistente
PruebasEscribir tests con httptest para cada handler
LogsLogs estructurados, incluir request_id y timestamps

Checklist antes de desplegar

  • Usa gin.SetMode(gin.ReleaseMode) o GIN_MODE=release
  • Configura PORT y JWT_SECRET como variables de entorno
  • Valida todos los inputs de usuario (body, query, headers)
  • Limita los tamaños de archivos y requests (MaxMultipartMemory)
  • Configura CORS solo con los orígenes permitidos
  • Restringe cabeceras expuestas y usa HTTPS con certificado válido
  • Prueba con go test ./... antes de compilar
  • Crea backups de la base de datos y revisa los logs

Headers de seguridad recomendados

func headersSeguridad() gin.HandlerFunc {
    return func(c *gin.Context) {
        c.Header("X-Content-Type-Options", "nosniff")
        c.Header("X-Frame-Options", "DENY")
        c.Header("Referrer-Policy", "no-referrer")
        c.Next()
    }
}

r.Use(headersSeguridad())
