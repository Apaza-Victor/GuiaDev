3.1 Métodos de ruta (GET, POST, PUT, DELETE)

Qué son los métodos de ruta

Los métodos de ruta definen cómo responde el servidor ante las diferentes acciones HTTP. Express proporciona un método para cada verbo HTTP.

MétodoFunciónUso típico
GETObtener datosListar o consultar recursos
POSTCrear datosCrear un nuevo recurso
PUTActualizar datosActualizar un recurso completo
DELETEEliminar datosBorrar un recurso

Ejemplo de rutas básicas

const express = require('express');
const app = express();

app.get('/usuarios', (req, res) => {
  res.send('Lista de usuarios');
});

app.post('/usuarios', (req, res) => {
  res.send('Crear un usuario');
});

app.put('/usuarios/:id', (req, res) => {
  res.send(`Actualizar usuario ${req.params.id}`);
});

app.delete('/usuarios/:id', (req, res) => {
  res.send(`Eliminar usuario ${req.params.id}`);
});

app.listen(3000);

3.2 Parámetros de ruta (/:id)

Qué son los parámetros de ruta

Los parámetros de ruta son segmentos dinámicos de la URL que se capturan con el prefijo dos puntos :. Se acceden a través de req.params.

const express = require('express');
const app = express();

app.get('/usuarios/:id', (req, res) => {
  const id = req.params.id;
  res.send(`Mostrando el usuario con id: ${id}`);
});

app.get('/productos/:categoria/:productoId', (req, res) => {
  res.json(req.params);
});

app.listen(3000);

Reglas de los parámetros

  • Siempre van precedidos por :
  • Son valores de cadena (string), aunque contengan números
  • Pueden combinarse varios en una misma ruta
  • Se recorren con req.params
Con valores como id numérico, recuerda convertirlos con Number(req.params.id) antes de compararlos o usarlos en cálculos.

3.3 Query string (req.query)

Qué es la query string

La query string es la parte de la URL que va después del signo ? y permite enviar parámetros adicionales, como filtros o paginación. Se accede a ella mediante req.query.

const express = require('express');
const app = express();

// URL: /productos?categoria=electronica&limite=10
app.get('/productos', (req, res) => {
  const { categoria, limite } = req.query;
  res.json({
    categoria,
    limite: limite || 20,
    mensaje: 'Filtrando productos'
  });
});

app.listen(3000);

Ejemplos de query string

URLreq.query
/buscar?q=express{ q: "express" }
/listar?pagina=2&tam=10{ pagina: "2", tam: "10" }
/filtro?a=1&a=2{ a: ["1", "2"] }
A diferencia de los parámetros de ruta, la query string es opcional y suele usarse para filtros, orden y paginación.

3.4 Respuestas con res.json y res.send

Métodos de respuesta

Express ofrece varios métodos en el objeto res para enviar respuestas al cliente:

MétodoDescripción
res.send()Envía una respuesta de texto o HTML
res.json()Envía una respuesta en formato JSON
res.redirect()Redirige a otra URL
res.status()Establece el código de estado HTTP

Ejemplos de respuestas

const express = require('express');
const app = express();

app.get('/texto', (req, res) => {
  res.send('Esto es texto plano');
});

app.get('/html', (req, res) => {
  res.send('<h1>Página en HTML</h1>');
});

app.get('/json', (req, res) => {
  res.json({
    nombre: 'Ana',
    rol: 'admin',
    activo: true
  });
});

app.get('/error', (req, res) => {
  res.status(404).json({ error: 'Recurso no encontrado' });
});

app.listen(3000);
res.json() y res.send() cierran la respuesta automáticamente. Solo debes llamar a uno por petición.

3.5 Multiple manejo y orden de rutas

Encadenar handlers

Express permite pasar varios callbacks a una misma ruta, que se ejecutan en orden. Esto es útil para validar o transformar datos.

const express = require('express');
const app = express();

const verificarAdmin = (req, res, next) => {
  if (req.query.rol !== 'admin') {
    return res.status(403).json({ error: 'No autorizado' });
  }
  next();
};

// Varios handlers para una misma ruta
app.get('/admin', verificarAdmin, (req, res) => {
  res.json({ mensaje: 'Bienvenido, administrador' });
});

app.listen(3000);

Enrutamiento con app.route

app.route('/libros')
  .get((req, res) => res.send('Listar libros'))
  .post((req, res) => res.send('Crear libro'));
El orden de definición de las rutas importa. Express evalúa las rutas en el orden en que se declaran, por lo que las rutas específicas deben ir antes que las genéricas.

Resumen

**Lo que aprendiste en esta sección:** - Express ofrece métodos de ruta para cada verbo HTTP (GET, POST, PUT, DELETE) - Los parámetros de ruta (:id) se acceden con req.params - La query string se accede con req.query - res.send() envía texto/HTML y res.json() envía JSON - Se pueden encadenar varios handlers en una misma ruta - Los códigos de estado comunican el resultado de la operación
