6.1 Servir HTML estático (express.static)

Qué es express.static

express.static() es un middleware integrado que sirve archivos estáticos (HTML, CSS, imágenes, JavaScript del cliente) desde una carpeta del proyecto.

const express = require('express');
const app = express();

// Sirve todo lo que esté en la carpeta /public
app.use(express.static('public'));

app.listen(3000);

Estructura de ejemplo

public/
|-- index.html
|-- css/
|   `-- estilos.css
|-- js/
|   `-- app.js
`-- imagenes/
    `-- logo.png

Con esto, http://localhost:3000/index.html, http://localhost:3000/css/estilos.css y los demás archivos serán accesibles directamente.

El parámetro de express.static es la carpeta relativa al directorio desde donde se ejecuta Node, por lo que es mejor usar rutas absolutas con path.join.

---

6.2 Prefijo virtual con express.static

Montar estáticos en una ruta

Puedes hacer que los archivos estáticos se sirvan bajo un prefijo de URL específico pasando la ruta como primer argumento de app.use.

const express = require('express');
const path = require('path');
const app = express();

// /public/... mapea a la carpeta public
app.use('/public', express.static(path.join(__dirname, 'public')));

// /assets/... mapea a la carpeta estilos
app.use('/assets', express.static('estilos'));

app.listen(3000);

Acceso a archivos

http://localhost:3000/public/css/estilos.css
http://localhost:3000/assets/app.js
Usar path.join(__dirname, 'public') garantiza que la carpeta se encuentre incluso si ejecutas Node desde otro directorio.

6.3 Template engines (EJS y Pug)

Qué son los motores de plantillas

Un template engine permite generar HTML dinámico combinando plantillas con datos. En lugar de escribir HTML estático, usas sintaxis especial para insertar variables y lógica.

Motores más usados con Express

MotorSintaxisCurva
EJSHTML con <%= %>Baja
PugIndentación y etiquetas abreviadasMedia
HandlebarsLlaves dobles {{}}Media

Configurar EJS en Express

npm install ejs
const express = require('express');
const app = express();

// Indica a Express que use EJS
app.set('view engine', 'ejs');
app.set('views', './views');

app.get('/', (req, res) => {
  res.render('inicio', { titulo: 'Mi app' });
});

app.listen(3000);

---

6.4 Renderizar vistas con res.render

Cómo funciona res.render

res.render(nombreVista, datos) renderiza una plantilla y envía el HTML resultante al cliente. El primer argumento es el nombre del archivo (sin extensión) dentro de la carpeta views.

Plantilla EJS (views/inicio.ejs)

<!DOCTYPE html>
<html>
<head>
  <title><%= titulo %></title>
</head>
<body>
  <h1>Bienvenido a <%= titulo %></h1>
  <p>Número de usuarios: <%= usuarios.length %></p>
</body>
</html>

Manejador en Express

app.get('/panel', (req, res) => {
  const usr = [{ nombre: 'Ana' }, { nombre: 'Carlos' }];
  res.render('inicio', { titulo: 'Panel de control', usuarios: usr });
});
La carpeta que contiene las plantillas debe llamarse views por defecto, o configúrala con app.set('views', ...).

---

6.5 Envío de variables a plantillas

Pasar datos a la vista

Puedes pasar cualquier tipo de dato (strings, números, objetos, arrays) como segundo argumento de res.render, y usarlos dentro de la plantilla.

const express = require('express');
const app = express();

app.set('view engine', 'ejs');

const productos = [
  { nombre: 'Laptop', precio: 999 },
  { nombre: 'Mouse', precio: 29 }
];

app.get('/productos', (req, res) => {
  res.render('productos', {
    titulo: 'Catálogo',
    productos,
    usuario: { nombre: 'Ana', admin: true }
  });
});

app.listen(3000);

Plantilla productos.ejs

<ul>
  <% productos.forEach(p => { %>
    <li><%= p.nombre %> - $<%= p.precio %></li>
  <% }) %>
</ul>
El bloque <% %> contiene código JavaScript que no imprime salida, mientras que <%= %> imprime el valor escapado.

6.6 Ejemplo combinado de plantillas y estáticos

Aplicación con estilos, plantilla y datos

const express = require('express');
const path = require('path');
const app = express();

app.set('view engine', 'ejs');
app.use(express.static(path.join(__dirname, 'public')));

const tareas = [
  { id: 1, texto: 'Estudiar Express', done: true },
  { id: 2, texto: 'Hacer práctica de plantillas', done: false }
];

// Página principal con la lista de tareas
app.get('/', (req, res) => {
  res.render('tareas', { tareas });
});

app.listen(3000);

views/tareas.ejs

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <link rel="stylesheet" href="/css/estilos.css">
  <title>Mis tareas</title>
</head>
<body>
  <h1>Mis tareas</h1>
  <ul>
    <% tareas.forEach(t => { %>
      <li class="<%= t.done ? 'completada' : '' %>"><%= t.texto %></li>
    <% }) %>
  </ul>
</body>
</html>
Esta combinación permite construir aplicaciones web completas con una parte estática, una capa de plantillas dinámicas y el servidor Express detrás.

Resumen

**Lo que aprendiste en esta sección:** - express.static sirve archivos estáticos como HTML, CSS y JS - Puedes montar estáticos bajo un prefijo virtual de URL - EJS y Pug son motores de plantillas para HTML dinámico - res.render() renderiza una vista y envía el HTML - Se pueden pasar variables, arrays y objetos a las plantillas - Plantillas y estáticos se combinan en aplicaciones completas
