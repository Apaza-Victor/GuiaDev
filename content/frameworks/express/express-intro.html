1.1 Qué es Express

Definición

Express es un framework web minimalista y flexible para Node.js. Se trata de un conjunto de herramientas y utilidades que facilitan la creación de servidores HTTP, APIs y aplicaciones web de forma rápida y sencilla. Es el framework más popular del ecosistema Node.js y la base sobre la que se construyen muchos otros frameworks.

Características principales

CaracterísticaDescripción
MinimalistaProporciona solo lo esencial, sin capas innecesarias
FlexiblePermite organizar la aplicación a tu manera
MiddlewareSistema de middleware en línea para procesar peticiones
RuteoGestión de rutas HTTP (GET, POST, PUT, DELETE) muy intuitiva
Gran comunidadMillones de usuarios y abundante documentación

Ejemplo mínimo

const express = require('express');
const app = express();

app.get('/', (req, res) => {
  res.send('Hola desde Express');
});

app.listen(3000, () => {
  console.log('Servidor escuchando en el puerto 3000');
});

1.2 Por qué usar Express

Ventajas de Express

  • Simplicidad: Pocas líneas de código para un servidor funcional
  • Curva de aprendizaje corta: Ideal para quienes empiezan con Node.js
  • Ecosistema enorme: Miles de paquetes npm compatibles
  • Sin opiniones: No te obliga a seguir una estructura rígida
  • Rendimiento: Ligero y rápido para la mayoría de aplicaciones

Dónde se usa

Express se utiliza para crear APIs REST, servidores web, aplicaciones de tiempo real (con Socket.io) y como base para backends de aplicaciones móviles y de escritorio.

Ejemplo: servidor con una ruta adicional

const express = require('express');
const app = express();

app.get('/', (req, res) => {
  res.send('Página de inicio');
});

app.get('/acerca', (req, res) => {
  res.send('Página acerca de nosotros');
});

app.listen(3000);
Express es una excelente opción para empezar, ya que no impone restricciones y te permite aprender los fundamentos de HTTP y Node.js de forma natural.

1.3 Diferencias con NestJS y Fastify

Comparativa de frameworks de Node.js

AspectoExpressNestJSFastify
TipoMinimalistaEstructuradoRendimiento
Curva de aprendizajeBajaAltaMedia
RendimientoBuenoBuenoMuy alto
EstructuraLibreObligatoria (módulos)Libre
TypeScriptOpcionalNativoSoporte
PopularidadMuy altaAltaMedia

Cuándo elegir cada uno

  • Express: Proyectos pequeños y medianos, empezar con Node.js
  • NestJS: Aplicaciones empresariales con arquitectura robusta
  • Fastify: APIs con requisitos extremos de rendimiento
La elección depende de los requisitos del proyecto. Express gana en simplicidad y comunidad; NestJS en estructura; Fastify en velocidad.

1.4 Middleware en línea

Qué es el middleware

Un middleware es una función que se ejecuta entre la petición del cliente y la respuesta del servidor. Puede modificar la petición (req), la respuesta (res) o llamar a la siguiente función con next(). Express procesa los middleware en orden, formando una pipa de procesamiento.

Tipos de middleware en Express

TipoDescripción
De aplicaciónSe aplica a todas las rutas con app.use()
De rutaSolo se aplica a una ruta concreta
De errorManeja errores con cuatro parámetros
De tercerosProvenientes de paquetes npm (morgan, cors)

Ejemplo: middleware simple

const express = require('express');
const app = express();

// Middleware de aplicación: registra cada petición
app.use((req, res, next) => {
  console.log(`Petición recibida: ${req.method} ${req.url}`);
  next(); // Continúa con la siguiente función
});

app.get('/', (req, res) => {
  res.send('Página con middleware');
});

app.listen(3000);

1.5 Ecosistema npm

Paquetes esenciales con Express

El ecosistema de npm ofrece cientos de paquetes que se integran con Express para cubrir funcionalidades comunes:

PaqueteFunción
morganRegistro de peticiones (logs) en consola
corsPermite peticiones desde otros dominios
dotenvCarga variables de entorno desde un archivo .env
mongooseODM para conectar con MongoDB
bcryptjsHash seguro de contraseñas
jsonwebtokenAutenticación mediante tokens JWT

Instalar un paquete

// Desde la terminal, dentro de tu proyecto
npm install morgan cors dotenv
Verifica siempre la página oficial de cada paquete en npm para conocer su licencia, mantenimiento y seguridad antes de usarlo en producción.

1.6 Cuándo usar Express

Casos de uso recomendados

  • APIs REST: Backends para aplicaciones web y móviles
  • Servidores web: Aplicaciones que sirven HTML, CSS y JS
  • Microservicios: Servicios ligeros e independientes
  • Aplicaciones en tiempo real: Con WebSockets o Socket.io

Cuándo no usarlo

Para proyectos muy grandes con arquitectura estricta (mejor NestJS), o cuando los requisitos de rendimiento son extremos (mejor Fastify). También se puede considerar http puro de Node para casos muy simples.

Ejemplo: API básica de productos

const express = require('express');
const app = express();

let productos = [
  { id: 1, nombre: 'Laptop', precio: 999 },
  { id: 2, nombre: 'Mouse', precio: 29 }
];

app.get('/productos', (req, res) => {
  res.json(productos);
});

app.listen(3000, () => console.log('API de productos en línea'));

Resumen

**Lo que aprendiste en esta sección:** - Express es un framework minimalista y flexible para crear servidores con Node.js - Se destaca por su simplicidad, su gran comunidad y su enorme ecosistema npm - A diferencia de NestJS y Fastify, no impone una estructura rígida - Usa un sistema de middleware en línea para procesar las peticiones - Existen paquetes npm complementarios para logs, CORS, bases de datos y más
