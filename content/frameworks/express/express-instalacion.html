2.1 Requisitos: Node.js y npm

Qué necesitas instalar

Para trabajar con Express necesitas tener instalado Node.js y su gestor de paquetes npm. Express es una librería de Node, por lo que ambos son obligatorios.

Verificar la instalación

// Desde la terminal, comprueba las versiones
node --version
npm --version

Requisitos mínimos

HerramientaVersión recomendadaFunción
Node.js18 o superiorRuntime de JavaScript del lado del servidor
npm9 o superiorGestión de dependencias del proyecto
Puedes descargar Node.js desde su sitio oficial. Al instalarlo, npm se instala automáticamente.

---

2.2 Inicializar el proyecto con npm init

Crear el archivo package.json

El comando npm init genera un archivo package.json que contiene la información del proyecto y sus dependencias.

// Crea el archivo de forma interactiva
npm init

// O crea uno con valores por defecto
npm init -y

Ejemplo del package.json generado

{
  "name": "mi-primer-servidor",
  "version": "1.0.0",
  "description": "Primer servidor con Express",
  "main": "index.js",
  "scripts": {
    "start": "node index.js"
  },
  "license": "ISC"
}
El campo scripts permite definir comandos abreviados. Por ejemplo, npm start ejecutará node index.js.

---

2.3 Instalar Express

Comando de instalación

Para instalar Express como dependencia del proyecto ejecuta:

npm install express

Esto descarga Express y crea la carpeta node_modules con todas sus dependencias. Además, registra la dependencia en package.json.

Resultado en package.json

{
  "name": "mi-primer-servidor",
  "version": "1.0.0",
  "dependencies": {
    "express": "^4.19.0"
  }
}

Instalar dependencias de desarrollo

Algunos paquetes solo se usan durante el desarrollo. Nodemon, por ejemplo, se instala así:

npm install --save-dev nodemon
Nunca subas la carpeta node_modules a tu repositorio Git. Debe incluirse en el archivo .gitignore.

---

2.4 Crear el primer servidor

Código del servidor

Crea un archivo index.js en la raíz del proyecto y escribe el siguiente código:

const express = require('express');
const app = express();

app.get('/', (req, res) => {
  res.send('¡Hola, mundo con Express!');
});

const PORT = process.env.PORT || 3000;
app.listen(PORT, () => {
  console.log(`Servidor corriendo en http://localhost:${PORT}`);
});

Ejecutar el servidor

node index.js

Luego abre http://localhost:3000 en tu navegador. Verás el mensaje de bienvenida.

El método app.listen(puerto, callback) inicia el servidor. El callback se ejecuta cuando el servidor está listo para recibir peticiones.

---

2.5 Uso de Nodemon (recarga automática)

Qué es Nodemon

Nodemon es una herramienta que observa tus archivos y reinicia el servidor automáticamente cada vez que realizas un cambio. Evita tener que detener y volver a ejecutar node index.js manualmente.

Instalación y uso

npm install --save-dev nodemon

// Ejecutar con nodemon
npx nodemon index.js

Agregar script en package.json

"scripts": {
  "start": "node index.js",
  "dev": "nodemon index.js"
}

Ahora, para modo desarrollo ejecuta npm run dev.

Nodemon reinicia el proceso cada vez que guardas un archivo, mostrando un mensaje en la consola para indicar el reinicio.

2.6 Estructura básica de un proyecto

Estructura recomendada para empezar

mi-proyecto/
|-- node_modules/
|-- public/
|   |-- index.html
|   |-- css/
|   `-- js/
|-- views/
|-- routes/
|-- middleware/
|-- .gitignore
|-- package.json
`-- index.js

Propósito de cada carpeta

CarpetaContenido
publicArchivos estáticos (HTML, CSS, imágenes)
viewsPlantillas (EJS, Pug) si usas templates
routesDefinición de rutas de la aplicación
middlewareFunciones middleware personalizadas

Archivo .gitignore

node_modules/
.env
.DS_Store
La estructura puede variar según el tamaño del proyecto. Empieza simple y añade carpetas solo cuando sean necesarias.

Resumen

**Lo que aprendiste en esta sección:** - Necesitas Node.js y npm para trabajar con Express - npm init crea el archivo package.json del proyecto - npm install express añade Express como dependencia - El método app.listen() inicia el servidor HTTP - Nodemon permite recarga automática durante el desarrollo - Una estructura de carpetas ordenada facilita el mantenimiento
