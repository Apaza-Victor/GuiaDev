4.1 Qué es el middleware

Definición

Un middleware es una función que se ejecuta en algún punto del flujo entre la petición del cliente y la respuesta del servidor. Puede leer y modificar la petición (req), la respuesta (res) y decidir si continúa con la siguiente función mediante next().

Firma de un middleware

function miMiddleware(req, res, next) {
  // Trabajo a realizar
  next(); // Pasa al siguiente middleware o ruta
}

Para qué se usa

  • Registro de peticiones (logs)
  • Autenticación y autorización
  • Parsing de datos (JSON, formularios)
  • Manejo de CORS
  • Manejo de errores
Piensen en el middleware como capas de una cebolla: cada petición atraviesa las capas en orden, desde afuera hacia la ruta final.

4.2 Middleware de aplicación (app.use)

Qué es y cómo se usa

El middleware de aplicación se registra con app.use() y se ejecuta en cada petición entrante, sin importar la ruta. Se usa para lógica común a toda la aplicación.

const express = require('express');
const app = express();

// Este middleware se ejecuta en todas las peticiones
app.use((req, res, next) => {
  const ahora = new Date().toISOString();
  console.log(`[${ahora}] ${req.method} ${req.url}`);
  next();
});

app.get('/', (req, res) => {
  res.send('Página principal');
});

app.listen(3000);

Aplicar a una ruta específica

app.use('/api', (req, res, next) => {
  console.log('Solo para rutas que empiezan con /api');
  next();
});
El orden importa: los middleware registrados antes se ejecutan primero. Registra el middleware global antes de las rutas.

4.3 express.json() para datos JSON

Para qué sirve

express.json() es un middleware integrado que analiza el cuerpo de las peticiones en formato JSON y lo pone a disposición en req.body.

const express = require('express');
const app = express();

// Habilita la lectura de cuerpos JSON
app.use(express.json());

app.post('/usuarios', (req, res) => {
  // req.body contiene los datos enviados en JSON
  console.log(req.body);
  res.json({
    mensaje: 'Usuario recibido',
    datos: req.body
  });
});

app.listen(3000);

4.4 Orden de ejecución del middleware

Cómo fluye la petición

Las peticiones pasan por los middleware y rutas en el orden exacto en que se registran. Cuando un middleware llama a next(), la petición continúa; si no lo llama, la respuesta queda detenida en ese middleware.

const express = require('express');
const app = express();

// 1º: primer middleware
app.use((req, res, next) => {
  console.log('Middleware 1');
  next();
});

// 2º: segundo middleware
app.use((req, res, next) => {
  console.log('Middleware 2');
  next();
});

// 3º: ruta final
app.get('/', (req, res) => {
  console.log('Ruta /');
  res.send('Respuesta final');
});

app.listen(3000);
// Salida en consola: Middleware 1, Middleware 2, Ruta /

Reglas clave

  • Sin llamar a next(), el flujo se detiene
  • Cada middleware puede terminar la respuesta (por ejemplo, con un error)
  • Los middleware de error tienen 4 parámetros

4.5 Middleware personalizado

Crear tu propio middleware

Puedes crear middleware reutilizables para autenticación, logs o validaciones específicas.

const express = require('express');
const app = express();

// Middleware de autenticación personalizado
function autenticar(req, res, next) {
  const token = req.headers['authorization'];

  if (!token) {
    return res.status(401).json({ error: 'Token requerido' });
  }

  if (token !== 'secreto123') {
    return res.status(403).json({ error: 'Token inválido' });
  }

  req.usuario = { id: 1, nombre: 'Ana' };
  next();
}

// Ruta protegida
app.get('/perfil', autenticar, (req, res) => {
  res.json({ mensaje: 'Bienvenido', usuario: req.usuario });
});

app.listen(3000);

Middleware separado en archivo

// middleware/auth.js
module.exports = function autenticar(req, res, next) {
  // lógica de autenticación
  next();
};

// index.js
const autenticar = require('./middleware/auth');
app.use(autenticar);

4.6 Morgan (registro de peticiones)

Qué es Morgan

Morgan es un popular middleware de terceros que registra cada petición HTTP en la consola, mostrando información como el método, la URL, el estado y el tiempo de respuesta.

Instalación y uso

npm install morgan
const express = require('express');
const morgan = require('morgan');
const app = express();

// Modo 'dev' para desarrollo: logs concisos y de colores
app.use(morgan('dev'));

app.get('/', (req, res) => {
  res.send('Hola mundo');
});

app.listen(3000);
// Salida: GET / 200 3.25 ms - 11

Resumen

**Lo que aprendiste en esta sección:** - El middleware son funciones entre la petición y la respuesta - app.use() registra middleware de aplicación para todas las rutas - express.json() permite leer el cuerpo JSON en req.body - El orden de registro determina el orden de ejecución - Puedes crear middleware personalizados reutilizables - Morgan registra automáticamente las peticiones en consola
