7.1 Orientación general a bases de datos

Por qué usar una base de datos

Una base de datos permite guardar, consultar, actualizar y eliminar información de forma persistente. Sin ella, los datos se pierden al reiniciar el servidor.

Tipos de bases de datos

TipoEjemplosCaracterística
Relacionales (SQL)MySQL, PostgreSQLTablas, filas y relaciones
Documentales (NoSQL)MongoDBDocumentos tipo JSON
Clave-valorRedisMuy rápidas en memoria
Express no incluye una capa de base de datos integrada. Debes elegir el driver u ODM/ORM según la base de datos que uses.

7.2 MongoDB con Mongoose

Qué son MongoDB y Mongoose

MongoDB es una base de datos NoSQL orientada a documentos. Mongoose es un ODM (Object Document Mapper) que facilita modelar los datos y realizar operaciones de forma cómoda desde Node.

npm install mongoose
const mongoose = require('mongoose');

// Conectar a MongoDB
mongoose.connect('mongodb://localhost:27017/miapp', {
  useNewUrlParser: true,
  useUnifiedTopology: true
}).then(() => console.log('Conectado a MongoDB'))
  .catch(err => console.error('Error:', err.message));

Definir un modelo

const usuarioSchema = new mongoose.Schema({
  nombre: { type: String, required: true },
  email: { type: String, required: true, unique: true },
  edad: Number
});

const Usuario = mongoose.model('Usuario', usuarioSchema);

7.3 MySQL y PostgreSQL

Bases relacionales desde Node

Para bases SQL puedes usar el paquete mysql2 (MySQL) o pg (PostgreSQL), o un ORM como Sequelize que funciona con ambas.

npm install mysql2
// conectar-mysql.js
const mysql = require('mysql2/promise');

async function main() {
  const conexion = await mysql.createConnection({
    host: 'localhost',
    user: 'root',
    password: 'clave',
    database: 'miapp'
  });

  const [filas] = await conexion.execute(
    'SELECT * FROM usuarios WHERE id = ?',
    [1]
  );
  console.log(filas);
  conexion.end();
}

main();

Sequelize (ORM)

npm install sequelize mysql2
const { Sequelize, DataTypes } = require('sequelize');
const db = new Sequelize('miapp', 'root', 'clave', {
  host: 'localhost',
  dialect: 'mysql'
});

const Usuario = db.define('Usuario', {
  nombre: { type: DataTypes.STRING, allowNull: false },
  email: { type: DataTypes.STRING }
});

7.4 Operaciones CRUD

Qué es CRUD

CRUD son las cuatro operaciones básicas sobre los datos: Create (crear), Read (leer), Update (actualizar) y Delete (eliminar).

CRUD con Mongoose

const Usuario = require('./models/Usuario');

// Crear (Create)
async function crearUsuario(datos) {
  const usuario = new Usuario(datos);
  await usuario.save();
  return usuario;
}

// Leer (Read)
async function obtenerUsuarios() {
  return await Usuario.find();
}

async function obtenerPorId(id) {
  return await Usuario.findById(id);
}

// Actualizar (Update)
async function actualizarUsuario(id, cambios) {
  return await Usuario.findByIdAndUpdate(id, cambios, { new: true });
}

// Eliminar (Delete)
async function eliminarUsuario(id) {
  return await Usuario.findByIdAndDelete(id);
}
Estas funciones se usan dentro de los handlers de las rutas Express para conectar los endpoints con la base de datos.

7.5 Integración de la base de datos con Express

Ejemplo: API conectada a MongoDB

const express = require('express');
const mongoose = require('mongoose');
const app = express();

app.use(express.json());

mongoose.connect('mongodb://localhost:27017/miapp');

const Usuario = mongoose.model('Usuario', new mongoose.Schema({
  nombre: String,
  email: String
}));

app.post('/usuarios', async (req, res) => {
  try {
    const usuario = new Usuario(req.body);
    await usuario.save();
    res.status(201).json(usuario);
  } catch (error) {
    res.status(400).json({ error: error.message });
  }
});

app.get('/usuarios', async (req, res) => {
  const usuarios = await Usuario.find();
  res.json(usuarios);
});

app.listen(3000);
Al trabajar con operaciones asíncronas es recomendable usar async/await y envolverlas en try/catch para manejar los errores.

7.6 Variables de entorno (.env)

Por qué usar variables de entorno

Los datos sensibles como cadenas de conexión, contraseñas y puertos no deben estar escritos en el código. Se almacenan en un archivo .env y se acceden mediante process.env.

npm install dotenv

Archivo .env

PORT=3000
MONGO_URI=mongodb://localhost:27017/miapp
DB_USER=root
DB_PASS=clave_secreta

Cargar y usar las variables

require('dotenv').config();

const express = require('express');
const mongoose = require('mongoose');
const app = express();

const PORT = process.env.PORT || 3000;
const MONGO_URI = process.env.MONGO_URI;

mongoose.connect(MONGO_URI);

app.listen(PORT, () => console.log(`Servidor en el puerto ${PORT}`));
El archivo .env nunca debe subirse al repositorio. Agrégalo siempre al .gitignore para no exponer credenciales.
