7.1 Conexión a TypeORM

Qué es TypeORM

TypeORM es un ORM (Object Relational Mapper) para TypeScript y JavaScript que permite trabajar con bases de datos relacionales usando clases y decoradores en lugar de SQL manual.

Instalar las dependencias

# Módulo de TypeORM para NestJS
npm install @nestjs/typeorm typeorm

# Driver de la base de datos (elige el tuyo)
npm install pg            # PostgreSQL
npm install mysql2        # MySQL
npm install sqlite3       # SQLite

Configurar la conexión en el módulo raíz

import { Module } from '@nestjs/common';
import { TypeOrmModule } from '@nestjs/typeorm';
import { GatosModule } from './gatos/gatos.module';

@Module({
  imports: [
    TypeOrmModule.forRoot({
      type: 'postgres',
      host: 'localhost',
      port: 5432,
      username: 'postgres',
      password: 'secret',
      database: 'catalogo',
      autoLoadEntities: true,
      synchronize: true,
    }),
    GatosModule,
  ],
})
export class AppModule {}
La opción `synchronize: true` crea y modifica las tablas automáticamente. Úsala solo en desarrollo; en producción, usa migraciones.

Opciones principales

OpciónDescripción
typeMotor: postgres, mysql, sqlite, mssql, etc.
host / portDirección y puerto del servidor
username / passwordCredenciales de acceso
autoLoadEntitiesCarga las entidades registradas con forFeature
synchronizeSincroniza el esquema automáticamente (solo desarrollo)

7.2 Entidades (Entities)

Definición

Una entidad es una clase que representa una tabla de la base de datos. Cada propiedad de la clase se mapea a una columna, y cada instancia a una fila.

Decoradores principales

DecoradorFunción
@Entity()Marca la clase como tabla
@PrimaryGeneratedColumn()Columna clave primaria autogenerada
@Column()Columna normal de la tabla

Ejemplo: entidad Gato

// gato.entity.ts
import { Entity, PrimaryGeneratedColumn, Column } from 'typeorm';

@Entity('gatos')
export class Gato {
  @PrimaryGeneratedColumn()
  id: number;

  @Column({ length: 50 })
  nombre: string;

  @Column({ type: 'int' })
  edad: number;

  @Column({ nullable: true })
  raza: string;

  @Column({ default: true })
  activo: boolean;
}

Tipos comunes de columna

TipoDescripción
varchar / textCadenas de texto
int / bigintEnteros
float / decimalDecimales y precios
booleanVerdadero o falso
timestampFechas y horas

7.3 Repositorios

Definición

Un repositorio es el objeto que TypeORM ofrece para hacer operaciones contra una entidad: consultas, inserciones, actualizaciones y borrados, sin escribir SQL.

Registrar entidades en el módulo

import { Module } from '@nestjs/common';
import { TypeOrmModule } from '@nestjs/typeorm';
import { Gato } from './gato.entity';
import { GatosController } from './gatos.controller';
import { GatosService } from './gatos.service';

@Module({
  imports: [TypeOrmModule.forFeature([Gato])],
  controllers: [GatosController],
  providers: [GatosService],
})
export class GatosModule {}

Inyectar el repositorio en el servicio

import { Injectable } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { Gato } from './gato.entity';

@Injectable()
export class GatosService {
  constructor(
    @InjectRepository(Gato)
    private readonly repositorio: Repository<Gato>,
  ) {}
}

Métodos principales del repositorio

MétodoQué hace
find()Devuelve todas las filas
findOne(...)Devuelve una fila que cumple condiciones
save(entity)Inserta o actualiza
remove(entity)Elimina
count(...)Cuenta filas
createQueryBuilder(...)Consultas avanzadas

7.4 CRUD con TypeORM

Servicio con operaciones completas

import { Injectable, NotFoundException } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { Gato } from './gato.entity';

@Injectable()
export class GatosService {
  constructor(
    @InjectRepository(Gato)
    private readonly repositorio: Repository<Gato>,
  ) {}

  crear(datos: Partial<Gato>): Promise<Gato> {
    return this.repositorio.save(datos);
  }

  listar(): Promise<Gato[]> {
    return this.repositorio.find();
  }

  async obtenerUno(id: number): Promise<Gato> {
    const gato = await this.repositorio.findOne({ where: { id } });
    if (!gato) {
      throw new NotFoundException('Gato no encontrado');
    }
    return gato;
  }

  async actualizar(id: number, datos: Partial<Gato>): Promise<Gato> {
    const gato = await this.obtenerUno(id);
    Object.assign(gato, datos);
    return this.repositorio.save(gato);
  }

  async eliminar(id: number): Promise<void> {
    const gato = await this.obtenerUno(id);
    await this.repositorio.remove(gato);
  }
}

Controlador que expone el CRUD

import { Controller, Get, Post, Put, Delete, Body, Param } from '@nestjs/common';
import { GatosService } from './gatos.service';
import { Gato } from './gato.entity';

@Controller('gatos')
export class GatosController {
  constructor(private readonly gatosService: GatosService) {}

  @Post()
  crear(@Body() datos: Partial<Gato>): Promise<Gato> {
    return this.gatosService.crear(datos);
  }

  @Get()
  listar(): Promise<Gato[]> {
    return this.gatosService.listar();
  }

  @Get(':id')
  obtenerUno(@Param('id') id: string): Promise<Gato> {
    return this.gatosService.obtenerUno(Number(id));
  }

  @Put(':id')
  actualizar(@Param('id') id: string, @Body() datos: Partial<Gato>) {
    return this.gatosService.actualizar(Number(id), datos);
  }

  @Delete(':id')
  eliminar(@Param('id') id: string) {
    return this.gatosService.eliminar(Number(id));
  }
}

7.5 Migraciones

Concepto

Una migración es un archivo que describe cambios controlados del esquema de la base de datos: crear tablas, agregar columnas, índices o claves foráneas. Permiten evolucionar el esquema de forma segura en equipos y en producción.

Sincronización automática vs migraciones

AspectosynchronizeMigraciones
EnfoqueAutomático en cada arranqueArchivos versionados
ProducciónRiesgosoRecomendado
ControlNuloTotal
ColaboraciónProblemas entre equiposConflictos detectables

Comandos típicos

# Generar una migración a partir de las entidades
npm run typeorm migration:generate -- src/database/migrations/Inicial

# Ejecutar las migraciones pendientes
npm run typeorm migration:run

# Revertir la última migración
npm run typeorm migration:revert

Ejemplo de archivo de migración

import { MigrationInterface, QueryRunner } from 'typeorm';

export class CrearTablaGatos1234567890123 implements MigrationInterface {
  public async up(queryRunner: QueryRunner): Promise<void> {
    await queryRunner.query(`
      CREATE TABLE "gatos" (
        "id" SERIAL PRIMARY KEY,
        "nombre" character varying(50) NOT NULL,
        "edad" integer NOT NULL
      )
    `);
  }

  public async down(queryRunner: QueryRunner): Promise<void> {
    await queryRunner.query(`DROP TABLE "gatos"`);
  }
}

7.6 Relaciones entre entidades

Tipos de relación

RelaciónDecoradoresEjemplo
Uno a uno@OneToOneUn usuario y su perfil
Uno a muchos@OneToMany / @ManyToOneUn dueño y sus gatos
Muchos a muchos@ManyToManyGatos y adoptantes

Ejemplo: dueño con varios gatos

// dueno.entity.ts
import { Entity, PrimaryGeneratedColumn, Column, OneToMany } from 'typeorm';
import { Gato } from './gato.entity';

@Entity('duenos')
export class Dueno {
  @PrimaryGeneratedColumn()
  id: number;

  @Column()
  nombre: string;

  @OneToMany(() => Gato, (gato) => gato.dueno)
  gatos: Gato[];
}
// gato.entity.ts (fragmento)
import { Entity, ManyToOne, JoinColumn } from 'typeorm';
import { Dueno } from './dueno.entity';

@Entity('gatos')
export class Gato {
  // columnas anteriores...

  @ManyToOne(() => Dueno, (dueno) => dueno.gatos)
  @JoinColumn({ name: 'dueno_id' })
  dueno: Dueno;
}

Consultar con la relación

// Cargar los gatos junto con su dueño
const gatos = await repositorio.find({
  relations: { dueno: true },
});
Genera el módulo de base de datos de una aplicación completa con `nest g resource nombre`: el CLI crea la entidad, el DTO, el servicio y el controlador con CRUD listos para editar.

Resumen

**Lo que aprendiste en esta sección:** - TypeORM mapea clases a tablas de bases de datos relacionales - La conexión se configura con `TypeOrmModule.forRoot` - Las entidades usan `@Entity`, `@PrimaryGeneratedColumn` y `@Column` - Los repositorios se inyectan con `@InjectRepository` para hacer CRUD - Las migraciones versionan los cambios del esquema en producción - Las relaciones (`@OneToMany`, `@ManyToOne`, etc.) modelan los vínculos
