4.1 Qué es un controlador

Definición

Un controlador en NestJS es una clase anotada con @Controller que se encarga de recibir las peticiones HTTP, aplicar los decoradores de ruta y devolver la respuesta. Es la primera capa que procesa una solicitud entrante.

Responsabilidades

ResponsabilidadDescripción
Definir rutasMapea URLs y métodos HTTP a funciones
Recibir datosExtrae params, query y body de la petición
ResponderDevuelve datos, códigos de estado y encabezados
Delegar lógicaLlama a los servicios para la lógica de negocio

Cómo crear un controlador

# Generar con el CLI
nest g co gatos

Ejemplo: controlador con prefijo de ruta

import { Controller, Get } from '@nestjs/common';

@Controller('gatos')
export class GatosController {
  @Get()
  obtenerTodos() {
    return ['Gato 1', 'Gato 2'];
  }
}

El prefijo 'gatos' hace que el controlador responda en GET /gatos.

4.2 Decoradores de métodos HTTP

Decoradores disponibles

DecoradorMétodo HTTPUso típico
@Get()GETObtener recursos
@Post()POSTCrear recursos
@Put()PUTActualizar recursos completos
@Patch()PATCHActualizar parcialmente
@Delete()DELETEEliminar recursos
@All()CualquieraResponder a todos los métodos

Ejemplo: CRUD básico

import { Controller, Get, Post, Put, Patch, Delete } from '@nestjs/common';

@Controller('gatos')
export class GatosController {
  @Get()
  obtenerTodos() {
    return 'Lista de gatos';
  }

  @Post()
  crear() {
    return 'Gato creado';
  }

  @Put()
  actualizar() {
    return 'Gato actualizado';
  }

  @Patch()
  actualizarParcial() {
    return 'Gato actualizado parcialmente';
  }

  @Delete()
  eliminar() {
    return 'Gato eliminado';
  }
}
Puedes combinar cada decorador con una subruta: `@Get('buscar')` se mapea a `GET /gatos/buscar`.

4.3 Parámetros de ruta

Capturar valores de la URL

Los parámetros de ruta son valores dentro de la URL definidos con : y extraídos con el decorador @Param().

Ejemplo: obtener un recurso por id

import { Controller, Get, Param } from '@nestjs/common';

@Controller('gatos')
export class GatosController {
  @Get(':id')
  obtenerUno(@Param('id') id: string) {
    return `El gato solicitado es el ${id}`;
  }

  @Get(':id/historial')
  historial(@Param('id') id: string) {
    return `Historial del gato ${id}`;
  }
}

Varios parámetros

import { Controller, Get, Param } from '@nestjs/common';

@Controller('tienda')
export class TiendaController {
  @Get(':categoria/:producto')
  obtenerProducto(
    @Param('categoria') categoria: string,
    @Param('producto') producto: string,
  ) {
    return `Producto ${producto} de la categoría ${categoria}`;
  }
}

Todo el objeto de parámetros

import { Controller, Get, Param } from '@nestjs/common';

@Controller('tienda')
export class TiendaController {
  @Get(':categoria/:producto')
  obtenerTodo(@Param() params: Record<string, string>) {
    return params;
  }
}

4.4 Query params y request body

Parámetros de consulta (query params)

Los parámetros de consulta llegan después del signo ? en la URL y se capturan con @Query(). Son ideales para filtros y paginación.

import { Controller, Get, Query } from '@nestjs/common';

@Controller('gatos')
export class GatosController {
  @Get()
  filtrar(
    @Query('edad') edad?: string,
    @Query('raza') raza?: string,
  ) {
    return `Filtros aplicados: edad=${edad}, raza=${raza}`;
  }
}

Body de la petición

Los datos enviados en el cuerpo de la petición (normalmente JSON) se capturan con @Body(). En aplicaciones reales se valida con un DTO.

import { Controller, Post, Body } from '@nestjs/common';

interface CrearGatoDto {
  nombre: string;
  edad: number;
  raza?: string;
}

@Controller('gatos')
export class GatosController {
  @Post()
  crear(@Body() datos: CrearGatoDto) {
    return `Gato creado: ${datos.nombre} (${datos.edad} años)`;
  }
}

Extraer una propiedad concreta

@Post()
crear(@Body('nombre') nombre: string) {
  return `Nombre recibido: ${nombre}`;
}

4.5 Acceso al objeto Request y Response

Objeto Request

El decorador @Req() inyecta el objeto Request de Express, que contiene toda la información de la petición: encabezados, método, cookies y URL.

import { Controller, Get, Req } from '@nestjs/common';
import { Request } from 'express';

@Controller('gatos')
export class GatosController {
  @Get('info')
  informacion(@Req() req: Request): string {
    const ip = req.ip;
    const metodo = req.method;
    const url = req.originalUrl;
    return `Petición ${metodo} a ${url} desde ${ip}`;
  }
}

Decoradores específicos compositivos

NestJS ofrece atajos para no depender del objeto completo:

DecoradorQué expone
@Req() / @Request()Objeto request completo
@Res() / @Response()Objeto response completo
@Headers('nombre')Un encabezado concreto
@Ip()Dirección IP del cliente
@HostParam()Parámetro de host

Leer un encabezado

import { Controller, Get, Headers } from '@nestjs/common';

@Controller('gatos')
export class GatosController {
  @Get('lenguaje')
  idioma(@Headers('accept-language') idioma: string) {
    return `Idioma preferido: ${idioma}`;
  }
}
Evita usar `@Res()` fuera de librerías específicas (como descargas de archivos), porque obligas a NestJS a devolver la respuesta manualmente y pierdes interceptores y filtros de respuesta automáticos.

4.6 Respuestas con códigos de estado

Códigos de estado HTTP más usados

CódigoSignificadoUso
200OKRespuesta correcta
201CreatedRecurso creado (POST)
204No ContentEliminación correcta
400Bad RequestDatos inválidos
401UnauthorizedNo autenticado
403ForbiddenSin permisos
404Not FoundRecurso inexistente
500Internal Server ErrorError del servidor

Cambiar el código por defecto

Por defecto, POST devuelve 201 y el resto 200. Se puede cambiar con @HttpCode().

import { Controller, Get, Post, HttpCode } from '@nestjs/common';

@Controller('gatos')
export class GatosController {
  @Get('especial')
  @HttpCode(202)
  aceptado() {
    return 'Solicitud aceptada en proceso';
  }

  @Post()
  crear() {
    return 'Creado (201 por defecto)';
  }
}

Lanzar excepciones

import { Controller, Get, NotFoundException, Param } from '@nestjs/common';

@Controller('gatos')
export class GatosController {
  @Get(':id')
  obtenerUno(@Param('id') id: string) {
    if (id === '0') {
      throw new NotFoundException('Gato no encontrado');
    }
    return `Gato ${id}`;
  }
}

---

Resumen

**Lo que aprendiste en esta sección:** - Los controladores usan `@Controller` y manejan las peticiones HTTP - Los decoradores `@Get`, `@Post`, `@Put`, `@Patch` y `@Delete` definen los métodos - `@Param` captura parámetros de ruta y `@Query` los parámetros de consulta - `@Body` recibe el cuerpo de la petición, normalmente con un DTO - `@Req` y `@Res` dan acceso directo a los objetos de Express - `@HttpCode` cambia el estado de respuesta y `NotFoundException` envía errores
