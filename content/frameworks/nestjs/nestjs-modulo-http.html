9.1 Cliente HTTP de NestJS

Qué es @nestjs/axios

@nestjs/axios es el módulo oficial que envuelve la biblioteca Axios dentro de NestJS. Permite hacer peticiones HTTP a servicios externos (APIs REST, servicios de terceros, microservicios) de forma integrada con la inyección de dependencias.

Instalar la dependencia

npm install @nestjs/axios axios

Registrar el módulo HttpModule

import { Module } from '@nestjs/common';
import { HttpModule } from '@nestjs/axios';
import { ClimaService } from './clima.service';

@Module({
  imports: [HttpModule],
  providers: [ClimaService],
})
export class ClimaModule {}

Principales métodos del servicio

MétodoPetición HTTPUso
get(url)GETObtener datos
post(url, data)POSTCrear recursos
put(url, data)PUTActualizar recursos
patch(url, data)PATCHActualización parcial
delete(url)DELETEEliminar recursos

9.2 Inyección del servicio HTTP

Inyectar HttpService

El HttpService se inyecta como cualquier provider. Sus métodos devuelven un Observable de RxJS, por lo que suelen convertirse a Promise con firstValueFrom.

import { Injectable } from '@nestjs/common';
import { HttpService } from '@nestjs/axios';
import { firstValueFrom } from 'rxjs';

@Injectable()
export class ClimaService {
  constructor(private readonly httpService: HttpService) {}

  async obtenerClima(ciudad: string) {
    const url = `https://api.clima.com/actual?ciudad=${ciudad}`;
    const { data } = await firstValueFrom(this.httpService.get(url));
    return data;
  }
}

Manejar la respuesta

La respuesta de Axios contiene data (el cuerpo), status, headers y statusText. Solo: qué deseo extraer habitualmente es data.

Controlador que usa el servicio

import { Controller, Get, Param } from '@nestjs/common';
import { ClimaService } from './clima.service';

@Controller('clima')
export class ClimaController {
  constructor(private readonly climaService: ClimaService) {}

  @Get(':ciudad')
  clima(@Param('ciudad') ciudad: string) {
    return this.climaService.obtenerClima(ciudad);
  }
}

9.3 Configuración del cliente HTTP

Opciones de configuración

Con HttpModule.register se configuran opciones globales del cliente: baseURL, timeout, encabezados por defecto, autenticación y más.

import { Module } from '@nestjs/common';
import { HttpModule } from '@nestjs/axios';
import { FacturasService } from './facturas.service';

@Module({
  imports: [
    HttpModule.register({
      baseURL: 'https://api.proveedor.com',
      timeout: 5000,
      headers: {
        'Content-Type': 'application/json',
        'X-Api-Key': process.env.PROVEEDOR_API_KEY,
      },
    }),
  ],
  providers: [FacturasService],
})
export class FacturasModule {}

Opciones más comunes

OpciónDescripción
baseURLURL base para todas las peticiones
timeoutTiempo máximo de espera en milisegundos
headersEncabezados enviados por defecto
authCredenciales básicas HTTP
validateStatusQué códigos se consideran exitosos

Configuración asíncrona con variables de entorno

HttpModule.registerAsync({
  useFactory: () => ({
    baseURL: process.env.PROVEEDOR_URL,
    timeout: +process.env.HTTP_TIMEOUT,
  }),
})

9.4 Manejo de errores en peticiones

Errores de Axios

Cuando un servicio externo responde con un código de error o falla la conexión, Axios lanza una excepción. Es importante capturarla y transformarla en excepciones HTTP de NestJS.

import { Injectable, HttpException, HttpStatus } from '@nestjs/common';
import { HttpService } from '@nestjs/axios';
import { firstValueFrom } from 'rxjs';
import { AxiosError } from 'axios';

@Injectable()
export class ProveedorService {
  constructor(private readonly httpService: HttpService) {}

  async consultar() {
    try {
      const { data } = await firstValueFrom(
        this.httpService.get('/estado'),
      );
      return data;
    } catch (error) {
      if (error instanceof AxiosError) {
        const status = error.response?.status ?? HttpStatus.BAD_GATEWAY;
        throw new HttpException(
          `El proveedor respondió con error: ${error.message}`,
          status,
        );
      }
      throw error;
    }
  }
}

Códigos de error típicos

CódigoSignificado
400Petición inválida al proveedor
401 / 403Autenticación o permisos del proveedor
404Recurso inexistente
500 / 502 / 503Error del servidor del proveedor
Nunca dejes que errores crudos de Axios lleguen al cliente final: transforma los mensajes internos en respuestas claras y seguras.

9.5 Interceptores y Observables

Por qué RxJS

HttpService devuelve Observable en lugar de Promise, lo que permite aplicar operadores RxJS como map, retry, catchError o timeout antes de resolver la respuesta.

Operadores útiles

import { Injectable } from '@nestjs/common';
import { HttpService } from '@nestjs/axios';
import { firstValueFrom, timeout, retry, catchError, map } from 'rxjs';
import { NotFoundException } from '@nestjs/common';

@Injectable()
export class TiendaService {
  constructor(private readonly httpService: HttpService) {}

  async producto(id: number) {
    const observable = this.httpService.get(`/productos/${id}`).pipe(
      timeout(3000),
      retry(2),
      map((respuesta) => respuesta.data),
      catchError(() => {
        throw new NotFoundException('Producto no disponible');
      }),
    );
    return firstValueFrom(observable);
  }
}

Tabla de operadores

OperadorFunción
mapTransforma los datos de la respuesta
retry(n)Reintenta la petición n veces
timeout(ms)Falla si tarda más de ms milisegundos
catchErrorCaptura el error y lanza una excepción
Usa `firstValueFrom` (o `lastValueFrom`) para convertir el `Observable` en `Promise` y poder usar `async`/`await`.

9.6 Consumir una API externa

Ejemplo completo con una API pública

Un servicio que consulta usuarios de una API pública de ejemplo y los expone en un endpoint propio.

import { Injectable } from '@nestjs/common';
import { HttpService } from '@nestjs/axios';
import { firstValueFrom } from 'rxjs';

@Injectable()
export class UsuariosExternosService {
  private readonly base = 'https://jsonplaceholder.typicode.com';

  constructor(private readonly httpService: HttpService) {}

  async listar() {
    const { data } = await firstValueFrom(
      this.httpService.get(`${this.base}/users`),
    );
    return data.map(({ id, name, email }: any) => ({
      id,
      nombre: name,
      email,
    }));
  }

  async uno(id: number) {
    const { data } = await firstValueFrom(
      this.httpService.get(`${this.base}/users/${id}`),
    );
    return data;
  }
}

Controlador

import { Controller, Get, Param, ParseIntPipe } from '@nestjs/common';
import { UsuariosExternosService } from './usuarios-externos.service';

@Controller('externos')
export class UsuariosExternosController {
  constructor(private readonly service: UsuariosExternosService) {}

  @Get('usuarios')
  listar() {
    return this.service.listar();
  }

  @Get('usuarios/:id')
  uno(@Param('id', ParseIntPipe) id: number) {
    return this.service.uno(id);
  }
}

Probar el endpoint

GET /externos/usuarios        # lista todos
GET /externos/usuarios/1      # el usuario con id 1

Resumen

**Lo que aprendiste en esta sección:** - `@nestjs/axios` envuelve Axios e integra las peticiones HTTP en NestJS - `HttpService` se inyecta como provider y usa Observables de RxJS - `HttpModule.register` configura baseURL, timeout y encabezados - Los errores de Axios se transforman en excepciones HTTP de NestJS - RxJS permite mapear, reintentar y poner tiempo límite a las peticiones - Consumir una API externa es tan simple como inyectar el servicio y llamar a get/post
